## 1. LiFTER: A Grounded Neuro-Symbolic Microscope for Continuous-Time Dynamic Graph Forecasting
- arXiv: https://arxiv.org/abs/2608.06765 （cs.AI；首版 2026-08-07）
- 作者：Minwoo Yu, Young-guk Ha
- **TL;DR**：连续时间动态图（CTDG）模型把历史交互压进神经状态来预测未来链接，好用但**看不出"哪些实体、哪段时间模式"在为预测负责**；LiFTER 把观测交互保留为"有据可查的时序事实"，用**可执行的时序规则**对事实打分——每个分数是一组"历史事实/实体绑定/时间序都被显式满足"的规则执行的带符号求和，从而**可被独立重算、审计、干预**。
- **解决什么问题 / 为什么重要**：这是今日最贴我方向的一篇，**同时压中 A 的两条主线**——CTDG/动态图链接预测（核心方法），以及"内生/自解释"横切重点。它的立场正是我偏好的那种：把可解释性当作**预测架构本身的属性**，而非事后（post-hoc）归因去补救。更难得的是它给出**可验证性**这个硬指标——不是"给了个理由"，而是"这个理由能被独立重算出完全一致的分数"。对做时序图/动态图且想要"结构可控 + 解释可检验"的人，这是一个把预测变成"可核验的 grounded 计算"的范式样例。
- **核心方法**：Link-Fact Temporal Rule Inducer——将过去交互保留为 grounded temporal facts；归纳出可执行时序规则，对 pre-query 事实做规则匹配；预测分数 = 满足"历史事实 + 实体绑定 + 时间顺序"约束的规则执行之带符号求和；证据与规则可被检视、独立重算、干预。
- **主要结果**：在 **4 个 CTDG 基准**上，historical-negative 预测有竞争力，且取得**最高的宏解释准确率与 deletion fidelity**；对 **19,664 条测试预测**用独立执行重构全部 logits，最大误差仅 **0.0000131**；该架构还能当"显微镜"分离 recurrence / history position / transition 三者的贡献并追溯到单条事实。
- **值得追问 / 局限**：规则式打分的**表达力上界**——在需要复杂高阶/连续数值动力学的场景，符号规则相对纯神经 CTDG 是否会掉点，摘要只说"competitive"，未给绝对 SOTA 对比；规则归纳的**可扩展性与规则数膨胀**、在大规模稠密动态图上的开销待考；"解释准确率"的评测标准本身如何定义（金标从何而来）也值得追问。

## 2. When GNNs Fail: Quantifying and Overcoming Temporal Correlation Volatility in Time Series
- arXiv: https://arxiv.org/abs/2608.07333 （cs.LG；首版 2026-08-07）
- 作者：Chen Shao, Yue Wang, Zhenyi Zhu, Zhanbo Huang, Tobias Käfer, Zonghan Wu, Danai Koutra
- **TL;DR**：把多变量时序建成图（序列为节点、成对时序相关为边）再用 GNN 预测已成主流，但主流做法**假设静态图拓扑**；本文指出当成对相关随时间**剧烈演化**时现有架构会失效，提出模型无关的 **Temporal Correlation Volatility（TCV）** 指标量化这种"潜在结构的分布演化"，并给出新的 GNN 层 **GLIDE** 来应对动态拓扑。
- **解决什么问题 / 为什么重要**：这是 A 方向里少见的"**先做失效诊断、再给方法**"的机制型工作，正合我"时序图/时空图 GNN + 机制/现象分析"的偏好。它的第一层价值是**可证伪的负面结果**——用 TCV 把"结构在变"这件事量化，并建立"TCV 高 → 性能退化"的清晰关联，直指一个反直觉现象：**在高 TCV 场景，Transformer 等强模型反而被"结构无关"的简单基线打败**。这对"遇事就上时空图/注意力"的默认做法是一记提醒；第二层价值才是 GLIDE 这个补救层。
- **核心方法**：提出模型无关指标 TCV 度量潜在图结构的分布演化，并与性能退化建立关联；提出 GLIDE 层，含两个有理论支撑的机制——(D1) **Path-based Message Passing**（捕获基于路径的邻域）与 (D2) **Static and Dynamic Propagation Separation**（用局部静态近似识别最优动力学），在保持鲁棒性的同时改善动态拓扑下的学习。
- **主要结果**：论证多种流行模型（含 Transformer）在高 TCV 下**泛化差、常被结构无关基线超越**；GLIDE 的两项设计在动态拓扑下显著改善学习并保持鲁棒性（摘要末句被截断，具体增益幅度待正文核对）。
- **值得追问 / 局限**：TCV 作为"相关结构演化"的度量，其对**相关性估计窗口/方法**的敏感性需交代（窗口选择会直接改变"结构在不在变"的判断）；GLIDE 相对纯"结构无关"强基线在高 TCV 下能否真正翻盘、还是只是缩小差距，需要正文定量；"局部静态近似识别最优动力学"的假设在强非平稳/突变场景是否成立值得追问。

## 3. Edge Sparsification via Temporal Forman-Ricci Curvature for Dynamic Graph Learning
- arXiv: https://arxiv.org/abs/2608.07158 （cs.LG；首版 2026-08-07）
- 作者：Poupak Azad, Cuneyt Gurcan Akcora, Kiarash Shamsi
- **TL;DR**：大规模、稠密且快速变化的时序图（金融交易网、通信网、社交平台）训练/推理开销大；本文把经典 **Forman-Ricci 曲率**扩展到**有向加权时序图**，提出 **TRicci** 稀疏化框架——用"结构支撑 + 时间新近性 + 局部交互竞争"给边打曲率分，据此剪边而尽量不掉预测性能。
- **解决什么问题 / 为什么重要**：命中 A 的动态图/时序图学习，且给出一条**几何驱动的可扩展性**路线。价值在于它不是又一个更大的模型，而是把**离散几何（Ricci 曲率）**这一有原理的工具落到"哪些边可以安全删"上——曲率把"这条边是否承载了不可替代的结构-时间信息"变成可计算量。对我关心的"在动态图上做可控结构注入/裁剪"的思路，这是一个"用几何先验决定图结构"的干净样例，且直接服务于工程落地（训练/推理提速）。
- **核心方法**：将 Forman-Ricci 曲率从无向图推广到**有向加权时序图**，曲率同时编码结构支撑、时间新近性与局部交互竞争；据曲率对边做稀疏化，保留携带关键时序-结构信息的边。
- **主要结果**：在 **9 个交易网络 + 3 个时序图基准**上，稀疏化约 **80%** 的边、端到端训练与推理时间平均降低 **55.94%**，而多种图级预测任务的性能无显著退化。
- **值得追问 / 局限**：评测集中在**图级预测任务与交易类网络**，能否推广到**节点级/链接预测**及非交易域（如脑网络、通信流）需另证；曲率计算本身在超大图上的开销与稀疏化收益的净账要算清；"新近性 + 竞争"权重如何设定、是否需按数据集调参，摘要未展开。

## 4. FedDOSE: Federated Learning Framework Decomposing Site Effects for Modeling Brain Dynamic Functional Connectivity
- arXiv: https://arxiv.org/abs/2608.07393 （cs.LG / eess.SP / q-bio.NC；首版 2026-08-07）
- 作者：Deepank Girish, Yi Hao Chan, Yubin Zheng, Sukrit Gupta, Jagath C. Rajapakse
- **TL;DR**：多站点 fMRI 联邦学习既受**站点差异（统计异质性）**困扰，又普遍只用**静态功能连接（FC）**、丢掉脑网络的动态信息；FedDOSE 显式**分解站点差异**并对**动态功能连接（dFC）**建模——用"模块引导的 Tucker 分解"编码高维 dFC 张量抓时空模块模式，再用最优传输重心 + Procrustes 对齐各站点的类原型。
- **解决什么问题 / 为什么重要**：作为今日 **B 方向脑网络/神经影像**的补位（fNIRS 无直接命中、q-bio.NC 列表限流未取到，此篇为最近邻），它同时**在方法侧咬合 A**：把 dFC 当**时空张量**、用张量分解抽"模块级时空模式"，正是我关心的"显式结构（模块）+ 数据驱动表示"的耦合；而"用原型 + 最优传输对齐"处理跨站点/跨分布，也是可迁移到多源时序场景的通用招式。对做脑网络分析、又想兼顾隐私与动态信息的人很对味。
- **核心方法**：Modularity-Guided Tucker Decomposition 块编码高维 dFC 张量、捕获模块级时空模式；跨站点生成类特定原型（class-specific prototypes），用 **Optimal Transport 重心公式 + Procrustes 分析**在全局层面对齐原型，以此缓解站点差异下的联邦训练异质性。
- **主要结果**：在 **ABIDE-I / ABIDE-II / ADHD-200** 三个多站点静息态 fMRI 数据集上诊断**自闭症谱系（ASD）与多动症（ADHD）**，均优于 SOTA。
- **值得追问 / 局限**：是 **fMRI（非我 B 首选的 fNIRS 慢血氧信号）**，时间尺度/噪声结构不同，迁移需另证；"分解站点差异"与真实生物学个体差异的**可分性**存疑——分解出的到底是采集设备效应还是被试异质，摘要未给消融；Tucker 秩、原型数等超参对小站点的鲁棒性，以及联邦下通信/计算开销待补。

## 5. Transformers Struggle to Use Their Emergent World Models: Revisiting the Tower of Hanoi, and the Illusion of Thinking
- arXiv: https://arxiv.org/abs/2608.07077 （cs.AI / cs.LG；首版 2026-08-07）
- 作者：Devin Pereira, Willem Zuidema
- **TL;DR**：用汉诺塔（尤其更难的 flat-to-flat 变体）当探针，作者发现从零训练的小 Transformer 会**涌现出一个线性可解码、几何忠实的"世界模型"（状态空间 = Sierpiński 三角）且因果参与解题**；但把同样技术用到前沿推理大模型上，它们**在提示末端几乎完美编码了这个世界模型，却仍在 >3 环时大面积失败**——失败根源被定位为**规划过程中世界模型表征的衰减**。
- **解决什么问题 / 为什么重要**：这是今日 C 方向最"优先"的一篇——**机制可解释性 + 表征几何 + 因果探针**，完全不是 prompt 工程。它给出一个很锋利的现象学结论：模型**"知道"世界（表征在）却"用不起来"（决策不调用）**，即"能表征 ≠ 能利用"。而且做了**因果闭环**——通过在规划各阶段探测表征、并**回注 prompt-time 表征来提升性能**，把"表征衰减导致失败"从相关升级为因果。这直击我关心的"表征里到底内化了什么、又是否被下游真正使用"的问题，对理解"illusion of thinking"提供了机制层面的证据。
- **核心方法**：先从零训练小 Transformer 于预计算解题轨迹，用多种可解释性技术证明其习得**线性可解码、几何忠实**的状态表征（Sierpiński 三角）且因果参与解题；再把技术用于两个前沿推理模型（Qwen3.6-27B、DeepSeek-R1-Distill-Qwen-32B），在规划不同阶段探测世界模型表征，并通过**回注 prompt-time 表征**建立"表征衰减→失败"的因果证据。
- **值得追问 / 局限**：结论建立在**汉诺塔这一高度结构化玩具任务**上，"世界模型衰减"能否推广到开放式长程规划待证；"回注表征提升性能"是干预有效性的证据，但**回注的工程可用性**（需要 white-box 访问与探针方向）限制了其作为通用修复手段；对闭源前沿模型（如需 logits/激活）的可复现实施细节值得追问。

## 6. Explicit, Not Longer: What Makes Epistemic Stance Survive Memory Compression
- arXiv: https://arxiv.org/abs/2608.06953 （cs.CL / cs.AI / cs.LG；首版 2026-08-07）
- 作者：Alex Kwon
- **TL;DR**：agent 记忆系统会**压缩**存储内容，而压缩天生倾向丢弃限定词，于是一条主张的**"认识论立场（epistemic stance，如是确信、猜测还是转述）"往往在写入记忆时就丢了**；本文用严格配对实验问：什么决定它能不能存活？结论——**把立场写成"带标签的字段"而非"括号里的旁注"，能显著提高保留率；关键是"显式"，不是"更长"**。
- **解决什么问题 / 为什么重要**：命中 C 方向"优先"型的 **memory 机制 + 现象分析**，且方法学极其克制、可信——这正是我想要的"机制/科学问题优先"。它的实验设计是亮点：**配对笔记**只改"立场放在哪"、同预算压缩、盲评打分，跨 60 条主张/7 种语域；还做了**预注册复现**（在 Haiku 上先锁定预测与判定规则再跑，得 +15.6 分）。更诚实的是它**只认两模型的交集结论**（"显式而非更长"），对分歧部分（整句表述在一个模型 +12.5、在另一个几乎无效）明确不过度声称。对做 agent 长期记忆的人，这给出一条可操作准则：**立场要结构化存字段，别指望靠多写字幸存**。
- **核心方法**：构造仅在"立场位置/形式"上不同的配对笔记，在相同 filler 与相同预算下压缩，盲读者打分；跨 60 主张 × 7 语域测"标签字段 vs 括号旁注"；做格式消融拆分"标签 / 长度 / 整句表述"各自贡献；并用**无模型的确定性 readout** 作对照，看哪些效应源于机制、哪些源于模型。
- **主要结果**：写成带标签字段相比括号旁注，两模型上保留率各约 **+15 分**（37→2、30→8，置换检验 p=0.00005）；预注册复现 **+15.6 分**（38→1）；消融显示**标签在两模型都有效**（+9.7 / +12.8）、**长度在两者都无效**，而"整句表述"贡献因模型而异；无模型 readout 复现了方向与 7 个消融对比中的 5 个（但不含长度/标签项）。
- **值得追问 / 局限**：样本量（60 主张）与任务域偏窄，"认识论立场保留"到**真实多轮 agent 记忆栈**的外推性待证；两模型交集虽稳，但"最佳显式方式因模型而异"意味着**难有通用最优格式**，需按骨干模型各自校准；压缩器/评分器都由 LLM 承担，评分-写入同源是否引入系统性偏差值得追问。
