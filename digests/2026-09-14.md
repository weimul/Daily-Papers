## A. 核心方法（内生自解释 · 不规则时序 · 概念表征几何）

### 1. Prism-SQA: An Interpretable and Adaptable Neural Framework for Surface Electromyography Quality Assessment
- 链接：https://arxiv.org/abs/2609.12724
- 作者：Kuan-Chen Wang, Kai-Chun Liu, Ping-Cheng Yeh, Sheng-Yu Peng, Yu Tsao（主类 eess.SP，跨列 cs.LG；生医信号 / 语音-信号处理社区，机构未在摘要页逐一标注）
- **TL;DR**：把表面肌电（sEMG）的信号质量评估从"黑盒打分"改造成"生理感知的源分离 + 污染指纹核验"，让质量分数天生自带可解释证据，并且不重训就能适配不同临床场景的质量定义。
- **解决什么问题 / 为什么重要**：sEMG 易受多种污染，质量评估直接决定后续临床分析是否可信；现有神经网络方法准但不可解释、也难以在不重训的情况下适配不同质量标准。本文正好命中"内生/自解释可解释性"这一横切重点——不是事后归因，而是把可解释性写进结构，且方法论可迁移到 fNIRS / EEG 等其它生理时序的质量把关。
- **核心方法**：用带双向 LSTM 的 U-Net 把输入信号分解为一个"干净 sEMG 分量"加五个"污染专属分量"；每个污染分量交给一个"污染指纹核验器"（Contaminant Fingerprint Verifier），通过与标准污染的时/频结构比对来强制生理合理性；再由核验后的分量计算质量指数，从而支持跨临床语境自定义质量准则而无需重训。
- **主要结果**：在 Ninapro 公开数据合成的含噪 sEMG 上做连续质量分回归、在一个临床吞咽障碍数据集上做二分类，性能与当代黑盒神经方法相当或更好，同时提供显式的可解释性与可适配性。
- **值得追问 / 局限**：① "源分离 + 指纹核验"依赖对污染类型的先验刻画（这里是五类），遇到未建模的新型污染时可解释性与鲁棒性如何；② 该范式能否直接迁移到 fNIRS / EEG 等信噪结构不同的脑功能信号，值得实证。

### 2. DynSHAP: Towards Explainable Dynamic Survival Analysis
- 链接：https://arxiv.org/abs/2609.13042
- 作者：Nastasya Anokhina, Jonas Jürß, Pietro Liò（剑桥大学 Pietro Liò 组）
- **TL;DR**：为"动态生存分析"（吃纵向、不规则病历、输出随时间变化的生存函数）量身做一个 SHAP 框架，把"时间-特征对"当作博弈中的玩家，从而能同时解释不规则输入与函数型输出。
- **解决什么问题 / 为什么重要**：深度动态生存模型预测强但是黑盒，而现有可解释方法无法同时处理"纵向、不规则采样输入"和"函数型生存输出"，在临床上难落地。本文命中核心方向里的"不规则/异步采样时间序列"，并给出面向该场景的解释工具——虽属事后归因（用户对纯 post-hoc 降权），但针对不规则纵向 + 生存输出的适配是较新的切入点。
- **核心方法**：把常见的边际 SHAP 估计器扩展到动态生存设定，将"时间-特征对"作为 Shapley 博弈的玩家；进一步提出 Temporal DynSHAP，学习特征随时间的线性依赖，并用条件采样在解释中处理这些时间相关性。
- **主要结果**：在有已知真值归因的合成数据上，Temporal DynSHAP 比边际估计器更准地找回"时间相关特征"；在两个真实临床数据集、两种动态生存架构上，DynSHAP 产出的归因忠于模型学到的规律，能让医生看到"哪些信息、在什么时间"驱动了预测。
- **值得追问 / 局限**：① 本质仍是事后归因，"忠于模型"不等于"忠于生理因果"，与内生自解释模型的对比价值有限；② 时间相关性只建模到线性依赖，遇到强非线性/长程时序耦合时的近似质量待检验。

### 3. MAxBench: A Multinomial Concept Recovery Benchmark
- 链接：https://arxiv.org/abs/2609.13072
- 作者：Divya Appapogu, Freya Behrens, Yonatan Belinkov, Aaron Mueller（机制/概念可解释性社区，含 Belinkov、Mueller 等）
- **TL;DR**：面向"多类别概念"（如 Animals、Countries 这类有很多子类、每类多实例的非二元概念）提出一个几何无关的评测框架，系统比较 10 种定位方法在何种表征几何下最能被找回与操控（steering）。
- **解决什么问题 / 为什么重要**：二元概念（如"拒答"）常常一个方向就能 steering，但真实概念大多非二元，其表征几何的搜索空间大得多，学界并不清楚"该用什么几何、什么方法最有效"。这直接对应用户关心的"概念/自解释 + 表征几何"横切重点，是把可解释性从二元推向结构更丰富概念的一次元评测。
- **核心方法**：MAxBench 基于"从被找回的概念表征里采样"来做几何无关评测，覆盖 5 类几何（rank-one / linear subspace / affine subspace / manifold 等）、10 种定位方法，在 6 个概念、4 个模型上系统对比。
- **主要结果**：① 仿射子空间（affine subspace）比 rank-one / 线性子空间 steering 更可靠、召回更高；② 这种优势主要来自更好的非零偏移（offset）而非基向量选择；③ 流形（manifold）steering 在适用时可与最好方法竞争；④ 没有任何方法能一致优于直接 prompting——与二元概念上的既有结论一致。
- **值得追问 / 局限**：① "没方法能稳定超过 prompting"提示当前表征操控范式的天花板，值得追问是评测口径问题还是几何刻画不足；② 结论建立在 6 概念 / 4 模型上，向更大模型、更抽象或组合式概念的外推性待验证。

## B. 应用场景（神经影像 / 脑）

### 4. Geometric-to-Semantic Spherical Transfer Learning for Cortical Sulci Labeling
- 链接：https://arxiv.org/abs/2609.12627
- 作者：Saeb Tounsi, Joël Chavas, Pietro Gori, Vincent Frouin, Denis Rivière, Jean-François Mangin（CEA NeuroSpin / Télécom Paris 等，法国脑影像团队）
- **TL;DR**：针对"每半球 60+ 沟回、专家标注却只有 62 例"的极端数据稀缺，先用 UK Biobank 约 3 万无标注被试自监督预训练一个球面几何编码器，再把解剖学"沟底线"作为语义输入软注入，跨越"几何→语义"的域差来做皮层沟回标注。
- **解决什么问题 / 为什么重要**：皮层沟回（cortical sulci）标注是脑形态学/神经影像的基础任务，高容量模型 + 极少标注必然过拟合，稀有/多变的小沟尤其难。这属于核心方向 B 里的神经影像时序/脑结构应用，方法上"自监督几何先验 + 拓扑先验注入"对脑网络/脑功能建模也有借鉴意义。
- **核心方法**：第一步用海量无标注数据、仅凭连续表面特征（曲率、深度）以局部优化策略预训练球面编码器（能检测沟中断等局部稀有拓扑特征）；第二步把提取的沟底线作为显式语义输入，通过"软初始化的拓扑先验注入器"（Topological Prior Injector）接入预训练骨干，避免灾难性遗忘。
- **主要结果**：整体平均 Dice 0.77，优于从零训练的全监督基线；局部分析显示自监督几何先验在多变的三级沟（tertiary sulci）上收益最大（最高 +14.8%），印证"先学皮层形状"对识别最稀有部分尤其有益。
- **值得追问 / 局限**：① Dice 0.77 对最难的小沟是否够临床可用，稀有沟的误标模式与不确定性刻画待补；② 方法依赖"沟底线"这类工程化语义输入，端到端从原始表面直出的可行性、以及跨扫描仪/人群的迁移稳定性值得追问。

## C. 机制 / 表征几何（高优先级，取 2 篇）

### 5. Where Decoder Cosine Similarity Fails for SAE Feature Flow Discovery
- 链接：https://arxiv.org/abs/2609.12591
- 作者：Hendrik Droste, Christian Medeiros Adriano, Kathrin Korte, Holger Giese（Hasso Plattner Institute 等）
- **TL;DR**：用稀疏自编码器（SAE）在残差流里构建"状态特征 s + 更新特征 u → 目标特征 t"的转移图谱，并通过消融验证；发现绝大多数被因果验证的强转移，其解码器余弦相似度都很低——说明"用解码器方向余弦"这一常用启发式会漏掉真实的特征流机制。
- **解决什么问题 / 为什么重要**：模型经微调/编辑/对齐后仍保留旧能力，理解其内部计算对"持续演化的模型"越来越重要。本文正对核心方向里的"机制/现象分析、残差流结构、表征几何"——它给出一个可用于诊断"表征-更新机制"的特征流图谱，并直接指出流行相似度度量的失效边界。
- **核心方法**：以 MLP 更新为首个测试场景，构造三元组 $s_k + u_j \rightarrow t_\ell$（残差态特征 + MLP 更新特征联合预测目标残差特征），通过消融被解码的更新特征来因果验证候选三元组。
- **主要结果**：在 Pythia-160M（$L_7\to L_8$，20M token）上找到 38,125 个强消融效应转移，其中 88.0% 的"态-目标"与"更新-目标"解码器余弦都低于 0.7；在 Gemma-3-4B（$L_{21}\to L_{22}$）跨模型初检里，强效应三元组中 53.6% 同样双低于 0.7，方向上与 Pythia 一致但更弱。
- **值得追问 / 局限**：① 仅以 MLP 更新为首个案例、且 Gemma 只验证了 top 排名候选（非全图谱因果验证），跨层/跨模型/跨 SAE 家族的普适性待补；② "余弦失效"提示需要更贴合因果的度量，如何据此构建可靠的"更新操控"工具是关键下一步。

### 6. Benign Loss Landscapes Can Coexist with Worst-Case Hardness
- 链接：https://arxiv.org/abs/2609.13057
- 作者：Zach Furman, Stephan Wäldchen, Yangda Bei, Liam Hodgkinson
- **TL;DR**：用树张量网络（TTN）作可解代理模型，证明"损失地形对每个可实现目标都是（条件）良性的——最小范数的局部极小都是全局极小"，却同时嵌入了梯度下降在多项式时间内学不会的最坏情况目标；因此困难并非来自坏的局部极小，而是来自秩亏引发的高阶退化鞍点。
- **解决什么问题 / 为什么重要**：神经网络对真实任务学得好、却存在多项式时间可评估却学不会的最坏目标，这一张力此前缺乏能同时"含难目标 + 可高效评估"的代理模型。本文命中核心方向 C 的"训练动态、损失地形几何、机制分析"，把地形几何与计算困难的关系讲清楚，对理解"何种结构让真实目标可学"很有价值。
- **核心方法**：研究推广了深度线性网络与 Tucker 分解的树张量网络（TTN），证明其可嵌入任意 read-once 布尔公式（从而含有与神经网络同机制、不可多项式时间学习的多项式规模目标）；再证明其损失地形对每个可实现目标条件良性，并以奇偶（parity）函数为案例，把学习困难归因于秩亏导致的高阶退化鞍点。
- **主要结果**：给出"良性地形 + 最坏情况困难"可共存的构造性证明；关键结论是——区分典型问题与最坏问题的不是坏局部极小，而是高阶退化鞍点（由秩亏引起）。
- **值得追问 / 局限**：① TTN 作为代理与真实深网之间的机制对应有多强，结论向标准架构/优化器（含 SGD 噪声、过参数化）的外推需谨慎；② "高阶退化鞍点"能否给出可操作的可学性判据或初始化/正则化建议，是理论落地的关键。
