## A. 核心方法 · 时空图 GNN × 连续时间（液态时间常数 + 不规则采样 + 跨域记忆）

### 1. Continuous Cross-Domain Traffic State Prediction via Memory-Augmented Graph Liquid Time-Constant Networks
- 链接：https://arxiv.org/abs/2606.15807
- 作者：Jinrong Xiang, Ming Xu
- submit 日期：2026-06-14
- **TL;DR**：把"图耦合的交通演化"建成**连续时间液态时间常数网络（GLTC）**，在节点状态里引入泄漏、自适应时间常数与邻域反馈，再配跨域记忆库做数据稀缺区域的跨域迁移预测。
- **解决什么问题 / 为什么重要**：几乎正中你方向 A 的多个核心点——**spatio-temporal GNN + 连续时间建模 + 不规则/异质时间条件**。它针对"传感稀疏区域观测不足→跨域知识迁移"的现实痛点，且明确区别于"通用 graph neural ODE"模型：用图耦合的循环电导把 liquid time-constant 动力学搬进图节点，是 ODE 类连续时间图模型的一个具体变体，对你思考"连续时间 + 时空图"如何落地有参考价值。
- **核心方法**：① 构造时空单元（STU）把交通网络分解为可迁移的局部单元，做细粒度跨域对齐；② GLTC 在连续时间里建模图耦合演化，引入泄漏、自适应时间常数与邻域感知反馈；③ 基于记忆的迁移存储（MTS）保存源域知识、检索匹配模式、在出现未见状态时更新可靠的目标域模式。
- **主要结果**：在 5 个公开交通数据集上、短期与长期预测均一致优于域内与跨域基线；相对次优方法平均误差分别降低 3.02%、0.33%、8.92%、10.09%、2.11%（数据集差异明显）。
- **值得追问 / 局限**：① 各数据集增益跨度极大（0.33% vs 10%），说明收益高度依赖源-目标域相似性，何时几乎无效需看分项；② "液态时间常数 vs 标准 neural ODE"在求解开销、长程稳定性上的对比，摘要未给量化。

## A. 核心方法 · 时空图学习 × 跨城少样本迁移（混沌-波干涉）

### 2. CIWI-CKT: Chaos-Informed Wave Interference Feature Fusion and Cross-City Knowledge Transfer for Traffic Flow Forecasting
- 链接：https://arxiv.org/abs/2606.15642
- 作者：Abdul Joseph Fofanah, Lian Wen, David Chen, Shaoyang Zhang（据作者背景推断为澳大利亚 Griffith University 相关）
- submit 日期：2026-06-14
- **TL;DR**：把交通流当作"自适应波分量"，用混沌不变量驱动波生成、再用元学习做支撑域/查询域之间的"波干涉"建模，实现数据稀缺下的跨城少样本预测，并带可预测性置信分。
- **解决什么问题 / 为什么重要**：落在方向 A 的 **spatio-temporal graph learning + 跨域/少样本**。它的差异化在于不把交通当纯确定性序列，而显式建模"波状干涉"以刻画跨工况（cross-regime）动力学，并给出混沌→波稳定性、波诱导降维、元学习泛化界等理论保证——对你关心的"时空建模如何注入物理/动力学先验"是另一条思路。
- **核心方法**：三件套——① 混沌-感知波生成：提取可测混沌不变量，把交通建成自适应波分量；② 元-干涉处理：捕捉支撑域与查询域工况间的波相互作用，并产出可预测性置信分；③ 混沌-感知元学习：在保留混沌特性的前提下做高效跨城知识迁移。
- **主要结果**：在 4 个真实交通数据集上显著优于 SOTA 时空图学习、迁移学习、prompt 类与少样本方法，在提升精度的同时大幅减少所需训练数据。
- **值得追问 / 局限**：① "混沌不变量 + 波干涉"框架相对常规 STGNN 的可解释性与工程复杂度权衡如何，摘要未展开；② 理论保证（稳定性/泛化界）的假设强度与真实交通的吻合度需看正文。

## A×C 横切 · 动态时序知识图谱作为情节记忆（增强 LLM 持续学习）

### 3. DYNA: Dynamic Episodic Memory Networks for Augmenting Large Language Models with Temporal Knowledge Graphs in Continuous Learning
- 链接：https://arxiv.org/abs/2606.15778
- 作者：Ali Sarabadani, Mahtab Tajvidiyan
- submit 日期：2026-06-14
- **TL;DR**：给冻结的 LLM 外挂一张**时序知识图谱**（事件为节点、带时间戳的有向边为时序关系）当可更新的外部"情节记忆"，查询时用随机游走 + 中心性检索相关节点来增强回答，免重训地缓解灾难性遗忘。
- **解决什么问题 / 为什么重要**：横跨方向 A（**temporal/dynamic graph、timestamped edges**）与方向 C（**agent memory**，且是"记忆机制"而非纯 prompt 技巧）。它把"情节记忆"显式实例化为动态时序图，并实证"图结构性质（聚类系数）可预测检索表现"，对你关心的"记忆到底如何起作用 + 图结构与检索的关系"有机制层面的启发。
- **核心方法**：① 用时序知识图谱表示情节记忆；② 免重训的 LLM 增强（冻结主干 + 外部可更新图）；③ 查询时经随机游走与中心性度量检索节点再增强生成；并把图属性作为检索性能的预测指标。
- **主要结果**：在 3 个时序回忆任务上，相对微调减少约 7% 灾难性遗忘，相对标准 RAG 提升约 5% 时序排序；更高的图聚类系数与更好的检索相关。
- **值得追问 / 局限**：① 评测仅 3 个时序回忆任务、提升幅度温和（~5–7%），跨更复杂多跳推理是否成立未知；② "随机游走 + 中心性"检索在大规模动态图上的更新/检索成本与时效性，摘要未量化。

## B. 应用 · 脑影像 AD 进展的贝叶斯结构因果建模（neuroimaging 时序）

### 4. Bayesian Networks with Latent Time Embedding for Stage-Aware Causal Modeling of Alzheimer's Disease Progression
- 链接：https://arxiv.org/abs/2606.15784
- 作者：Nguyen Linh Dan Le
- submit 日期：2026-06-14
- **TL;DR**：用带"潜时间嵌入"的贝叶斯网络（BN-LTE）从基线生物标志物估计疾病伪时间，并按 AT(N) 级联的生物学顺序约束有向依赖，做阶段感知的 AD 进展因果建模与未来局部 tau 变化预测。
- **解决什么问题 / 为什么重要**：落在方向 B 的 **neuroimaging / 纵向脑影像时序**，且方法学上很对你横切重点的胃口——不是黑盒预测，而是**自带结构/可解释的因果建模**：把 AT(N) 级联从"固定序列"或"黑盒预测"升级为带阶段依赖效应的后验结构方程，识别出"淀粉样蛋白敏感的中段伪时间窗"。对你思考"脑网络/脑影像时序 + 内生可解释结构"是一个范例。
- **核心方法**：BN-LTE 由基线多模态测量估计疾病伪时间（latent time embedding），按生物学合理的 AT(N) 顺序约束有向依赖；用后验样条-变系数结构方程把初始测量与未来年化局部 tau-PET 变化相连。
- **主要结果**：在 ADNI 数据、受试者不相交的重复评测下，tau 进展的空间重建强于纳入的预测基线；并恢复出阶段-变化的 AT(N) 受约束效应、识别出中段伪时间淀粉样敏感窗，且经 g-formula 对比、root-adjusted AIPW、机制敏感性消融与先验/样条鲁棒性分析支持。
- **值得追问 / 局限**：① 用的是纵向**生物标志物/PET**而非功能时序（fNIRS/fMRI 动态），对"脑功能时序结构建模"的直接迁移有限；② 因果结论建立在 AT(N) 顺序约束 + 观测数据上，未观测混杂与 AT(N) 先验设定的敏感性仍是开放问题。

## B. 监控/AIOps · 软件定义车的多模态因果根因在线诊断

### 5. SDVDiag: Multimodal Causal Discovery for Online Diagnosis in Software-defined Vehicles
- 链接：https://arxiv.org/abs/2606.15559
- 作者：Matthias Weiß, Athreya Hosahalli Prakash, Falk Dettinger, Nasser Jazdi, Michael Weyrich（德国斯图加特大学 IAS 自动化所，据作者背景推断）
- submit 日期：2026-06-14
- **TL;DR**：把日志模态与指标模态先融合进共享嵌入空间再建因果图，配"异常驱动触发器"把根因诊断从离线人工批处理变成持续在线系统，定位往往离表面症状好几跳的真实根因。
- **解决什么问题 / 为什么重要**：正中方向 B 的 **root cause analysis / AIOps / anomaly detection**。它指出现有因果 RCA 两大短板：只用单一可观测模态、且离线人工驱动——与持续运行的车载场景不匹配。**多模态融合 + 异常触发的在线化**这一组合，对你做监控告警/根因定位的系统设计很有参考。
- **核心方法**：多模态因果发现流水线——在建图前把基于日志与基于指标的服务表示融合到共享嵌入空间；异常驱动触发器把诊断平台从手动批处理工具转为持续在线系统。
- **主要结果**：在自主代客泊车（AVP）测试台上，多模态比纯指标基线产出更稀疏的因果图（平均 134 vs 182 条边），在对照专家知识图的边加权奖励上每个阶段都更优，经 60 次人类反馈后达 2.4 倍提升；端到端故障注入显示触发器能正确恢复位于可观测症状上游两跳的真实根因。
- **值得追问 / 局限**：① 评测集中在单一 AVP 测试台，跨车型/跨故障类型的泛化与误报率未充分展示；② 依赖专家知识图作为奖励参照与人类反馈精修，在缺专家先验的新系统上冷启动表现如何，摘要未给。

## C. Agent/机制 · LLM 重分词对称性的涌现现象（现象/机制分析 + 新采样轴）

### 6. Emergent retokenization symmetry in large language models: phenomenology and applications
- 链接：https://arxiv.org/abs/2606.15521
- 作者：Kanishk Jain, Matthew Day, Tankut Can
- submit 日期：2026-06-14
- **TL;DR**：同一字节串有多种合法分词，模型训练只见"规范分词"，本不该对其它分词稳健——但作者发现**这种分词对称性在训练中部分涌现**，并据此提出一种与温度采样正交的"重分词采样"新轴。
- **解决什么问题 / 为什么重要**：属你方向 C 偏好的"**机制/现象分析 + 表征**"类——不是 prompt 技巧，而是探究模型内部计算的一个干净现象。**重分词**（替换为等价分词、字节完全不变）是异常干净的探针：不改语法/语义/表面形式，只隔离分词效应，因此能纯粹度量模型对"语义等价输入表示"的敏感性与鲁棒性，对你关心的"表征结构/内部计算"很贴。
- **核心方法**：以 retokenization 为核心探针，在保持字节不变的前提下用替代分词替换规范分词；横跨 token 组合理解、表示多样性、任务基准三类实验，比较预训练与后训练阶段的敏感性/鲁棒性；并提出"重分词采样"——从模型对语义等价输入的内部计算中产生多样性（区别于温度采样从输出分布产生多样性）。
- **主要结果**：分词对称性在训练中部分涌现；重分词采样在简单题上可能损害性能，但能找回常规采样找不到的解，呈现一个独立于温度的采样维度。
- **值得追问 / 局限**：① "部分涌现"的程度与模型规模/分词器的关系，以及对称性破缺在何处最严重，需看分项；② 重分词采样"伤简单题、救难题"的取舍如何自动判别、何时启用，仍是工程开放问题。
