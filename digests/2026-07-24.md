## 1. Smooth Neural Point Processes via B-Splines
- arXiv: https://arxiv.org/abs/2607.21098
- 作者：Michele Bellomo, Riccardo Ramaschi, Alberto Dolara, Tomaso Aste（共 4 位）
- **TL;DR**：神经时序点过程（TPP）用 MLE 训练要同时算条件强度函数（CIF）及其积分（compensator），主流做法为了免数值积分只好去建模 compensator、约束网络结构、还得逐事件串行算 NLL；本文改成把 CIF 直接参数化为一组非负 B 样条基的线性组合、系数由神经网络预测，一次性拿回"精确 NLL + 任意网络结构 + 训练可并行 + 天然平滑正则"。
- **解决什么问题 / 为什么重要**：正对 A 方向"时序点过程 / 连续时间事件流"核心方法。神经 TPP 领域长期的工程摩擦是"精确似然"与"建模灵活性/训练效率"三者难兼得——为了闭式积分就得牺牲对 CIF 的直接建模和架构自由。B 样条基让强度函数解析可积（积分即基函数积分的线性组合），从而把三难题解耦，对建连续时间事件流（社交/金融/系统日志/神经脉冲）的人是干净的新基座。
- **核心方法**：CIF = 非负 B 样条基函数的非负系数线性组合，系数由任意神经网络输出；因 B 样条解析可积，compensator 闭式可得、NLL 精确无需数值积分；事件贡献可并行计算；并借"二阶导平方积分"这一自然量对 CIF 施加平滑正则。
- **主要结果**：在合成与真实数据集上，相比参考神经 TPP 基线，计算效率与预测精度均有提升；平滑正则由 B 样条形式天然支持。
- **值得追问 / 局限**：B 样条节点数/位置是超参，对多尺度或高度突发（burst）强度的表达力与节点配置的敏感性未展开；对比主要围绕单一"参考基线"，与 Transformer/Neural-ODE 系 TPP 的横评缺失；高维标记（marked TPP）下基组合的可扩展性待验。

## 2. CASC: Causal Adversarial Subspace Clustering for Multivariate Spatiotemporal Data
- arXiv: https://arxiv.org/abs/2607.21088
- 作者：Francis Ndikum Nji, Vandana Janeja, Jianwu Wang（共 3 位；UMBC 方向）
- **TL;DR**：深度子空间聚类在多元时空数据（海冰监测、疾病传播、神经退行追踪）上大多靠几何自表达、假设静态子空间，抓不住因果依赖、局部空间交互与长程时序动态；CASC 用 U-Net 式对抗聚类 + 堆叠 FAConvLSTM 保时空结构，配图注意力 Transformer 自表达网络，并引入"因果子空间保持损失"和"动态时序子空间演化损失"，把子空间聚类从相关驱动升级为因果—时序 regime 发现。
- **解决什么问题 / 为什么重要**：正对 A 方向"时空 GNN / 演化子空间"。传统子空间聚类的自表达系数只反映特征相似度，无法解释"哪些簇由同一潜在因果过程驱动"、也无法刻画非平稳环境下的 regime 切换。CASC 把因果对齐与时序演化显式写进损失，对做时空系统的无监督结构发现（气候、流行病、神经退行）提供了"可反映底层因果机制"的聚类范式。
- **核心方法**：U-Net 启发的深度对抗聚类主干 + 堆叠 FAConvLSTM 保空间/时间结构；图注意力 Transformer 自表达网络联合建模局部空间关系、全局依赖与长程时序交互；两个新目标——(1) 因果子空间保持损失，让自表达系数对齐潜在因果关系；(2) 动态时序子空间演化损失，捕捉演化子空间结构与非平稳环境下的 regime 切换。
- **主要结果**：作者定位为把深度子空间聚类"从相关驱动范式转为因果—时序 regime 发现框架"的方法贡献，各组件（对抗聚类 + FAConvLSTM + 图注意力自表达 + 两个损失）协同支撑高维时空数据的演化潜在 regime 发现。
- **值得追问 / 局限**：摘要未给具体基准数据集与量化对比数字，"因果"更多来自损失设计的对齐约束而非可识别性证明，需追问其因果解释的可验证性；组件较多（U-Net + FAConvLSTM + 图注意力 + 双损失）带来的调参与消融复杂度、以及在真实高噪非平稳数据上的稳健性待看正文。

## 3. Emergent Misalignment Recruits a Pre-existing Persona Subspace
- arXiv: https://arxiv.org/abs/2607.21356
- 作者：Mohammed Suhail B Nadaf（1 位）
- **TL;DR**：在一小撮"坏建议"上窄域微调会让对齐模型在无关问题上广域失配（emergent misalignment）；本文追问"窄课为何能泛化"，发现窄域微调是在**调用**微调前就已存在的低秩"人格子空间"——4 个无关领域共享一个低秩核（达随机子空间零假设的 657 倍），把该子空间从残差流里投影掉可把广域失配从 27.7% 压到 0.0%，而匹配秩的随机子空间毫无作用；反向把它注入未微调模型则按剂量诱发失配、最高 45.4%（超过被对照的微调模型）。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"里的表征几何 / 残差流 / 机制分析，是今天最强的机制类论文。它把"涌现失配"从行为现象推进到因果机制层面——不是微调"写入"了坏人格，而是"招募/放大"了预存的人格结构。方法学上给出可干预的抓手（残差流投影预防、注入诱发、剂量—响应），对对齐与可解释安全都是重要证据。
- **核心方法**：从冻结的指令微调模型（Qwen2.5-14B-Instruct）用对比 teacher forcing 抽取各领域人格子空间；量化其低秩共享核相对随机零假设的倍率、及其中落在"风格核"之外的比例（82%）；训练全程把该子空间从残差流投影掉做预防实验，向未微调模型注入做诱发实验；并对比"权重梯度投影""三种事后权重编辑"的失效情况。
- **主要结果**：4 个无关领域共享的低秩核为随机零假设的 657 倍、82% 位于风格核之外；投影消除该子空间使被判失配的生成从 27.7% 降到 0.0%（随机匹配秩子空间无效）；注入诱发失配随剂量升至 45.4%；对权重梯度做同样投影无效，三种事后权重编辑都不能真正移除倾向——最锐利的编辑只是压制、被清掉的结构会在同一子空间内重新形成；把固定坏数据预算摊到 4 个领域比机械权重叠加 + 匹配多样性联合解释的失配更多。
- **值得追问 / 局限**：作者自陈全部测量来自单个 14B 模型、抽取自已对齐检查点故"结构来源（预训练 vs 对齐）"仍开放；能预防失配的投影干预同时也抹掉了被训练的窄域行为（预防与能力不可兼得），实用化需解耦；结论向其它架构/规模的外推性待验。

## 4. Weight-norm Criticality: A Mechanism for Loss Spikes Induced by the Normalization and Weight Decay
- arXiv: https://arxiv.org/abs/2607.21005
- 作者：Xiaolong Li, Zhangchen Zhou, Zhi-Qin John Xu（共 3 位；上海交大 许志钦 方向）
- **TL;DR**：训练不稳定的主流解释多聚焦"学习率临界"（Edge of Stability）；本文指出还有一个被忽视的"权重范数临界"——归一化引入尺度不变分量、权重衰减持续缩小参数范数，当衰减系数变大、尺度不变权重范数被逼向零时，损失景观 sharpness 快速升高、优化被破坏、出现突发 loss spike。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"里的训练动态 / 机制分析。它给"权重惩罚能改善泛化却不能无限加大"提供了机制解释：过强衰减把尺度不变权重范数推过临界边界就会破坏训练。对预训练/微调里调 weight decay、排查 loss spike 的人有直接的机制直觉与可测预测。
- **核心方法**：分析归一化（scale-invariant 分量）与权重衰减的相互作用——衰减系数增大 → 尺度不变权重范数趋零 → 损失 sharpness 急升 → 优化失稳、loss spike；由此提出"权重范数临界"视角并给出可检验预测。
- **主要结果**：在含尺度不变分量的网络上实证验证了该机制的可检验预测，为"权重范数临界诱发 loss spike"提供经验支持；给出"衰减不能任意加大"的临界边界解释。
- **值得追问 / 局限**：验证网络规模与真实大模型预训练（更复杂的优化器状态/学习率调度耦合）之间的差距待补；"临界边界"是否可事前估计并转化为 weight decay 的安全上界、与学习率临界如何联合作用，摘要未展开。

## 5. MSBraM: A Multi-scale Self-supervised Brain Foundation Model for Hierarchical EEG Dynamics Learning
- arXiv: https://arxiv.org/abs/2607.21402
- 作者：Tao Zhou, Jing Han, Lingyu Shu, Zixing Zhang（共 4 位）
- **TL;DR**：EEG 信号本质多尺度（局部神经模式与长程依赖共同编码任务信息），现有自监督基础模型难以跨尺度学习、泛化受限；MSBraM 用两阶段预训练——先用多尺度神经分词器把原始 EEG 在不同时间分辨率上向量量化离散为语义码，再用课程式多尺度掩码预测被掩码，逐步把细粒度局部模式与全局时序上下文融合。
- **解决什么问题 / 为什么重要**：正对 B 方向"神经影像时间序列 / brain"应用。EEG 基础模型的通用性瓶颈在于跨尺度表征——只抓局部或只抓长程都会限制下游迁移。MSBraM 把"多尺度"显式写进 tokenizer 与掩码课程，并在超大规模（2400+ 小时）无标注数据上预训练，对做脑功能时序表征、跨数据集/任务迁移的人是可复用 backbone；其多尺度时序建模思路对 fNIRS 等其它脑功能时序也有借鉴。
- **核心方法**：两阶段自监督——(1) 多尺度神经 tokenizer 用 VQ 重建把 EEG 在多个时间分辨率上离散为语义码；(2) 课程式多尺度掩码预测被掩码码，渐进整合局部与全局时序上下文；在 2400+ 小时 EEG 上预训练。
- **主要结果**：在 12 个公开数据集的 10 个下游任务上评测，性能优于其它 SOTA 预训练模型，展现强泛化与可迁移性；结论指出"显式建模多尺度时序动态"对有效 EEG 基础模型至关重要。
- **值得追问 / 局限**：多尺度 tokenizer 的分辨率档位与 VQ 码本规模如何选、对不同采样率/导联配置的鲁棒性未展开；下游 10 任务的逐任务增益分布（是普遍领先还是被少数任务拉动）、以及向 fNIRS/MEG 等异构脑信号的直接迁移性待看正文。

## 6. Drift-Aware RL-based Wavelet Denoising for Network-Traffic Anomaly Detection
- arXiv: https://arxiv.org/abs/2607.20011
- 作者：Priyalakshmi Sheela, Indrakshi Dey（共 2 位）
- **TL;DR**：网络流量利用率测量同时受加性噪声与统计漂移（均值/方差/分布形状/尾部随时间变）污染，按平稳 i.i.d. 高斯假设标定的静态小波去噪在中高 SNR 下会过度抑制有用结构、拖累监控决策；本文把自适应小波去噪当作预处理层，用四检测器门控决定何时启用一个 PPO 智能体、按窗口选择小波配置，奖励用"下游任务效用"而非重建保真度。
- **解决什么问题 / 为什么重要**：正对 B 方向"AIOps / time-series anomaly"。核心洞见是"去噪的目标应是下游监控决策、而非信号重建"——局部突发（load burst）正是小波保留、低通滤除的多尺度结构，因此检测任务能区分不同去噪器族。方法把"漂移检测门控 + RL 自适应去噪"拼成非循环的两阶段（异常目标定义在干净信号、漂移门定义在污染信号），对做网络监控/时序异常预处理的人有可直接借鉴的设计。
- **核心方法**：自适应小波去噪作为异常检测与容量估计（C95，利用率 95 分位）两任务的预处理层；四检测器门控（Page-Hinkley、方差比、Jensen-Shannon、Anderson-Darling）决定何时调用学习策略；PPO 智能体在混合离散—连续动作空间上选择每窗口小波配置；奖励为下游任务效用而非重建保真度。
- **主要结果**：按漂移类型与输入 SNR，逐条与低通移动平均、VisuShrink、SureShrink、BayesShrink、Wiener 滤波器基准对比；"异常目标定义在干净信号、漂移门定义在污染信号"保证两阶段非循环（避免评测泄漏）。
- **值得追问 / 局限**：评测围绕流量利用率这一类信号，向更异构的监控指标（延迟、错误率、多维遥测）迁移性待验；PPO 策略的训练成本与在线推理时延、四检测器门控阈值的整定与误触发代价、以及真实生产漂移下的稳定性，摘要未展开。
