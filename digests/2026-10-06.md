## A. 核心方法（时空图 / 时空传播）

### 1. WaveGSSM: Graph Wave State Space Models for Propagating Spatio-Temporal Patterns
- 链接：https://arxiv.org/abs/2610.06540
- 作者：Junyou Zhu, Fenying Cai, Ping Xiong, Christian Nauck, Langzhou He, Chao Gao 等（8 位；cs.LG）
- **TL;DR**：主流时空图模型是"先空间后时间"（每帧过 GNN 再接时序模块），并不显式表示"模式如何在图上移动"；WaveGSSM 提出**二阶图状态空间模型**，在每个节点维护"当前模式"与"模式的时间变化率"两个耦合隐状态，用一个图-波传播把运动显式卷进预测。
- **解决什么问题 / 为什么重要**：正中 A 的时空图 / 时空传播方向。作者先给出一个经验观察——**相同的当前场，若近期变化率不同，会导向不同的未来**，说明只编码"现在"的快照式表示丢失了动力学信息；把"运动状态"显式纳入预测态，是对 STGNN 建模范式的一个有针对性的改进。
- **核心方法**：每个节点保留两路隐状态（模式 + 其时间变化率）；**图-波转移**先通过图上相互作用更新运动状态，再用它推进模式状态，从而在单次 rollout 内把空间传播与时间演化耦合在一起（二阶、类波动方程的结构）。
- **主要结果**：在四个时序图基准上平均性能均为最优；在全球天气预报上，相对"骨干匹配的快照模型"把 1–5 天位势高度 RMSE 平均降低 20.2%，且更好地保持了大尺度大气结构。
- **值得追问 / 局限**：① "二阶 / 运动状态"带来的增益是否主要来自强传播型数据（天气、交通）？在弱物理传播、以突发事件为主的动态图上是否仍有优势需看更多消融；② 与显式 PDE / 波动算子类方法（如图上波方程、神经 ODE）相比，计算成本与长程 rollout 稳定性如何尚待对照。

## B. 应用场景（时序异常 / 监控告警 / 根因 / 脑成像）

### 2. Normality Constraint Learning: Adapting Foundation Models for Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2610.06453
- 作者：Xiaohui Zhou, Yijie Wang, Hongzuo Xu, Weixuan Liang, Guansong Pang（5 位；cs.AI）
- **TL;DR**：时间序列基础模型（TSFM）泛化太强，连**异常模式也能被精准重建/预测**，导致基于重建误差的异常分数失效；NCL 是一个**即插即用、不改预训练参数**的框架，把 TSFM 的宽泛模式空间约束到目标序列的"正常结构"上，放大正常与异常之间的差异。
- **解决什么问题 / 为什么重要**：直接命中 B 的"时序异常检测 + 监控"。它点破了用基础模型做异常检测的一个核心悖论——模型越强，异常越容易被"学会"而不被标记；把焦点从"建模一切"收窄到"只建模正常"，对用 TSFM 做告警的工程实践很有指导意义。
- **核心方法**：从少量正常 patch 特征构造一个**紧凑的"正常子空间"**；在该子空间内，用对比约束把每个 patch 特征自适应地**向正常流形引导**（形成紧致且判别的正常流形）；校准后的特征聚合以强化正常分量，再与原始 TSFM 输出融合，放大重建/预测误差分数上的正常-异常落差。
- **主要结果**：在多个 TSFM 家族与多个基准上，NCL 一致提升异常检测性能，作为通用适配框架有效。
- **值得追问 / 局限**：① "正常子空间"靠少量正常 patch 构造，对正常样本本身含噪声或概念漂移（运行工况切换）时的鲁棒性需关注；② 论文强调一致提升但摘要未给绝对数值与关键基线的差距，实际告警场景下的误报率/召回权衡仍需看正文。

### 3. Rethinking Tool Design for Agentic RCA: A Controlled Empirical Study
- 链接：https://arxiv.org/abs/2610.05009
- 作者：Yu Luo, Rongchen Gao, Zhenhui Zhou, Changchang Liu, Yuliang You, Yongqian Sun 等（10 位；cs.SE）
- **TL;DR**：针对微服务**根因分析（RCA）**的 LLM agent，做了一个关于"**工具抽象与组合该怎么设计**"的受控实证研究：实现 24 个结构化工具（指标访问 L1 / 证据分析 L2 / 诊断 L3）外加 Python 参考设置 L0，在 375 个故障案例、多模型多系统上系统比较。
- **解决什么问题 / 为什么重要**：命中 B 的"根因分析 / AIOps"，且是**机制/实证导向而非 prompt 工程**——它回答的是 agentic RCA 的工程基础问题：加更多工具一定更好吗？工具收益是否随模型和目标系统而变？这对做 AIOps agent 的人很有参考价值。
- **核心方法**：四级工具抽象（L0–L3）的 8 种配置，用 Qwen3.7-Plus 评测，并在共享子集上对比 4 个 Qwen 模型；辅以**轨迹分析**，看 agent 在查更多证据后是否反而推翻了正确诊断。
- **主要结果**：L3 达到 82.8% top-1 定位准确率（L0 为 85.4%），但耗时不到一半；**加工具层能提升故障类型识别却可能降低定位准确率**；模型选择改变工具收益（给 L1+L2 加 L3 对三个模型有益，却伤害很少调用 L3 的 Qwen3-8B）；工具配置的排名还随微服务系统而变。轨迹里确有"agent 查了更多证据后推翻正确建议"的案例。
- **值得追问 / 局限**：① "更多工具 ≠ 更好"的结论提醒告警/诊断系统别盲目堆工具，但结论绑定在 Qwen 系与三个微服务系统上，跨厂商模型/真实生产拓扑的外推需谨慎；② 定位 vs 类型识别的权衡说明没有万能配置，如何按"模型 × 目标 × 系统"自动选工具仍是开放问题。

### 4. Decoupling Time and Space: A Temporally Conditioned Refinement for EEG Source Imaging
- 链接：https://arxiv.org/abs/2610.06726
- 作者：Marco Morik, Jesse Palarus, Carmen Vidaurre, Klaus-Robert Müller, Shinichi Nakajima（5 位；cs.LG）
- **TL;DR**：EEG 时间分辨率极高但"从头皮信号反推神经源"是严重病态的空间逆问题；本文提出**双流框架**，把"全局时间表示学习"与"逐时间点空间细化"显式解耦——Transformer 时间条件编码器先吃整段序列，再把特征作为条件喂给逐时间步的源空间细化器。
- **解决什么问题 / 为什么重要**：命中 B 的神经成像 / 脑功能时间序列（与 fNIRS 同属脑成像时序逆问题家族），同时在方法上跨到 A——它正面处理了时空网络"精度 vs 推理成本"的架构权衡，给出"时间作条件、空间逐点细化"的折中，对做不规则/多源时空逆问题的人有借鉴。
- **核心方法**：**时间条件编码器**用因子化时空注意力处理整段 EEG 并保留传感器分辨特征；一个固定逆映射把这些特征转成"源索引化"的条件，驱动逐时间步的**源空间 Transformer / 体卷积细化器**；训练时跨多种 leadfield 与显式算子失配，以提升对未见头部几何的迁移。
- **主要结果**：在真实合成数据上，时间先验显著改善空间定位，在高噪声、多源场景尤其优于经典与时空基线；跨未见头部几何迁移更好，模板重建接近个体化逆解；把仅在合成 EEG 上训练的模型用于真实 EEG，用源功率差做逻辑回归能在睁眼/闭眼条件下区分年龄组。
- **值得追问 / 局限**：① 主体验证在合成数据，真实 EEG 只做了睁眼/闭眼这类相对粗的下游验证，源级定位的真值难核验；② "固定逆映射"这一先验的选择对结果影响多大、能否迁移到 fNIRS 等其它模态的前向模型，需看正文。

## C. 机制 / 表征分析 + Agent（高优先级，取 2 篇）

### 5. Separators Make Carry Propagation Learnable: The Geometry of Latent Carry in a Multiplication Transformer
- 链接：https://arxiv.org/abs/2610.06605
- 作者：Sama Satariyan, Raphael Cousin, Gérard Biau（3 位；cs.LG）
- **TL;DR**：从头训练小型 Llama 式 Transformer 做 4×4 乘法（无思维链），发现**输入格式决定成败**——在数字间插入一个空格 token 就把精确匹配率从 1% 抬到 89%；并在残差流里找到"进位"被编码成**环上角度**的几何结构。
- **解决什么问题 / 为什么重要**：正中 C 的机制 / 表征几何。它把"Transformer 单前向做多位乘法为何常失败"落到可观测、可干预的机制上：进位（carry）这个长程依赖量是如何、在哪里被表示与使用的——对理解算术能力、残差流表征几何与因果电路很有价值。
- **核心方法**：对比有/无分隔符的输入格式；分析输出位置的学习顺序；在残差流中定位**预测槽（分隔符 token）把"进位输入"编码为环上角度**（进位取值越多，环被填得越满）；用**激活补丁（activation patching）**在列和匹配的样本间验证该状态在末层前被因果使用。
- **主要结果**：插分隔符使准确率 1%→89%；输出位按**进位链顺序**被学会，长程依赖最强的中间位最后才学会；对某中间列，第 4 块之后单独 patch 预测槽即可在高达 84% 的样本中迁移源进位；剩余错误几乎全是"差一"（off-by-one），与进位或环状数字编码上的小误差一致。
- **值得追问 / 局限**：① 结论基于小模型 + 4×4 合成乘法，能否外推到大模型/自然语言算术（预训练模型常用"输入范围启发式"而非显式进位）存疑；② "分隔符让进位可学"是否只是缓解了 token 化/位置对齐问题，而非揭示通用的算术表征原理，值得进一步对照。

### 6. Capability-Driven Self-Evolution of Agent Memory
- 链接：https://arxiv.org/abs/2610.06361
- 作者：Yaoqi Chen, Yuru Feng, Qianxi Zhang, Baotong Lu, Jianan Lu, Zhirui Wang 等（11 位；cs.AI）
- **TL;DR**：记忆自进化用任务反馈迭代改进"可执行的记忆程序"，但主流做法是**整体式进化**（从混合反馈里推修改方向、按总体性能判进步），会掩盖优化方向、让"某能力的提升被别处的回退抵消"；本文提出**能力驱动进化**，把搜索指引从总体性能细化到单个能力维度。
- **解决什么问题 / 为什么重要**：命中 Agent 方向的"记忆"优先类，且是机制/方法导向（非 prompt 工程）。它针对记忆自进化的一个真实失效模式——整体指标把能力级的得失混在一起，导致有前景的修改方向被过早放弃——给出更细粒度的搜索与整合机制。
- **核心方法**：提出 **PrisMem**：用**依赖感知的能力选择**优先挑"可能带来跨能力收益"的目标；用**历史引导的诊断**精修各"能力专家"；再用**轨迹引导的整合**在配对差分案例上比较已评估程序，依据行为差异把互补收益合并进统一的记忆程序。
- **主要结果**：在百万 token 历史的 BEAM-1M 与 LongMemEval-M 上，PrisMem 分别比最强基线高 10.54 和 7.83 个百分点。
- **值得追问 / 局限**：① "能力维度"如何界定、是否需要人工预设——若能力划分本身依赖任务先验，开放任务上的可迁移性存疑；② 多路能力专家 + 配对差分整合带来的搜索/评估开销（尤其百万 token 场景）未在摘要中量化，成本-收益比待看正文。
