## A. 核心方法（动态图基础模型 / 谱-时序图预测，取 2 篇）

### 1. A Common Language for Dynamic Graphs: Interaction Tokenization Enables Foundation Models
- 链接：https://arxiv.org/abs/2611.03246
- 作者：Fuyuan Ma, Yili Wang, Xin He, Xin Zhang, Ying Wang, Xin Wang（cs.LG / cs.SI）
- **TL;DR**：动态图上的节点身份是"图特有"的，相似的交互模式又出现在不同的时间/活跃尺度上，使得历史难以跨网络一致表示，图基础模型很难迁移。本文提出 **CL-DGFM**——用一套"**通用交互语言**"把动态历史编码成校准后的**表格输入**，让已有预测器（乃至冻结的表格基座模型）无需额外可训练图编码器就能做时序链接预测。
- **解决什么问题 / 为什么重要**：**正中 A 的"动态图 / 时序链接预测 / 连续演化交互"，并切中"基础模型可迁移性"这一横切难点**。它绕开"为每张图训练专用图编码器"的惯例，把动态图统一翻译成表格化 token，使在多样交互过程上预训练的能力可直接迁移到真实图上，且**无需对目标图更新参数**——为动态图基础模型给出一条"图→表格"的轻量路线。
- **核心方法**：Dynamic Interaction Tokenizer 把交互记忆、历史连通性、有序目的地转移编码成校准表格输入 → Dynamic Interaction Prior 用一个预训练表格基础预测器在多样合成动态上训练 → 用带标签的历史上下文引导预测，Contextual Value Adapter 调制注意力 value → 直接迁移到真实图而不更新目标图参数。
- **主要结果**：在 TGB 与 TGB-Seq 上取得有竞争力的表现；对比实验进一步表明这套"通用语言"既能支撑基础机器学习与神经模型，也**能让冻结的表格基础模型直接用于动态图**。
- **值得追问 / 局限**：① "表格化 token" 必然丢弃部分图结构/高阶拓扑信息，在强结构依赖（如社群演化、motif 级动态）的任务上是否仍够用，需更细粒度评测；② 迁移性能对"合成动态先验"的分布覆盖度可能敏感，真实图若落在先验之外（分布外交互过程）时的退化行为值得压力测试。

### 2. ST-GFM: Spectral-Temporal Graph Forecasting with Measured Perturbation Bounds and Masked Spectral Reconstruction
- 链接：https://arxiv.org/abs/2611.03512
- 作者：Aashish Bohra, Vivek Vijay（cs.LG / eess.SP / stat.ML）
- **TL;DR**：传感器网络的图预测器常"在一个工况训练、在另一个工况部署"，此时传感器耦合与信号频率成分都会漂移。本文把这种**谱漂移**拆成"算子通道"与"频率通道"两个带量纲的度量，提出 **ST-GFM**：在同一个学到的非对称算子上用 Chebyshev 与双向扩散滤波，并与逐节点时间注意力交替，同时给出**可测的 Frobenius 范数扰动界**与**掩码谱重构（MSR）**自监督。
- **解决什么问题 / 为什么重要**：命中 A 的**时空图 / 谱-时序图预测**，难得地把"分布/谱漂移下的鲁棒性"做成**可量化、可验证**的对象。它不止给出一个预测网络，还证明两条图分支的扰动界、并用训练后权重与实测算子范数算出常数（METR-LA 17.9、PEMS-BAY 21.5），再实测随机丢边时该层仅移动界的 2.0%–3.1%——把"谱漂移敏感度"从定性讨论变成可测数。
- **核心方法**：把输入每步用 Chebyshev + 双向扩散滤波器在单一学到的非对称算子上滤波，并与逐节点时间注意力交替 → 证明两条图分支的 Frobenius 扰动界（Chebyshev 界一阶可达）→ MSR 自监督（前 40 epoch）让编码器输出的对数功率谱匹配输入谱，小残差时一阶等价于 Itakura-Saito 散度。
- **主要结果**：同一评测管线下，60 分钟 MAE 在 METR-LA 比重训的 STAEformer 低 3.5%、在 PEMS-BAY 低 13.0%；PEMS-BAY 上 60 分钟 MAE 为 1.576±0.006，是 12 个已发表基线中**最低**；移除 MSR 会让 METR-LA 的 60 分钟 MAE 上升 0.30（接近移除全部三项自监督损失的 0.33）。
- **值得追问 / 局限**：① 扰动界与常数均在特定图算子/数据集（METR-LA、PEMS-BAY 两类交通传感网）上给出，界的"实际漂移预测力"能否迁移到非交通型时空图待验证；② MSR 以匹配对数功率谱为目标，对强非平稳或突变频谱（事件/故障诱发）的时序是否反而抑制有用高频成分，值得追问。

## B. 应用场景（脑动态功能连接状态切换机制 / 句级 EEG-to-text 检索，取 2 篇）

### 3. Intrinsic network dynamics catalyze switching in functional connectivity states of the brain
- 链接：https://arxiv.org/abs/2611.03071
- 作者：Steven S. Kang, Dae-Jin Kim（q-bio.NC）
- **TL;DR**：动态功能连接（dFC）反映大尺度脑网络的持续重构，但自发状态转换背后的时间组织与网络过程仍不清楚。本文提出 **FCSS（功能连接状态切换）**——一个基于**相位相干**的框架，追踪全脑主导连接构型的多尺度变化，并在 HCP fMRI 上揭示切换事件前的网络级机制。
- **解决什么问题 / 为什么重要**：命中 B 的**脑网络 / 神经影像时间序列**，且聚焦"状态切换的时序机制"而非静态连接。它把 dFC 的"何时/如何切换"做成可时间锁定（time-locked）的事件分析，发现切换前存在**显著性网络（salience）上升、默认模式网络（DMN）下降**的相反动态，为自发 FC 重构给出一个网络级候选机制——对脑状态时序建模与可解释脑网络分析都有参考价值。
- **核心方法**：以相位相干构建 FCSS 框架，追踪全脑主导连接构型的多尺度变化 → 在 HCP fMRI 上检验认知状态/条件切换对 FCSS 的诱发 → 分析静息态下接近切换事件时的网络隔离/整合/跨网络通信的渐进变化 → 以事件相关分析时间锁定到自发 FCSS，刻画切换前各网络贡献的对立演化。
- **主要结果**：FCSS 被认知状态与条件切换强烈诱发，且不同转换动态能**差异化预测工作记忆表现**；静息态下自发 FCSS 伴随网络隔离/整合/跨网络通信的渐进变化；切换前显著性网络贡献上升、DMN 贡献下降，呈现两网络"协同参与/撤出"的互逆再加权。
- **值得追问 / 局限**：① 结论基于 HCP fMRI 的群体统计，salience↑/DMN↓ 的"因果催化"解释仍属相关性推断，需干预或建模验证；② 相位相干框架对预处理（全局信号回归、滤波带）与 TR 分辨率可能敏感，能否迁移到 fNIRS / EEG 等更高时间分辨率但空间受限的模态值得追问。

### 4. Thought-deciphering via hierarchical EEG-to-text alignment
- 链接：https://arxiv.org/abs/2611.03623
- 作者：Xiaopeng Mao, Morten Mørup, Xin Xu, Sang Wan Lee, Sadasivan Puthusserypady（cs.LG / eess.SP）
- **TL;DR**：非侵入脑到文本 BCI 能为语言障碍者（闭锁综合征、脑瘫、构音障碍）提供替代沟通通道，但高性能方案多依赖笨重昂贵的 fMRI/MEG，轻便廉价的 EEG 解码效果一直落后，且缺乏对"EEG 与文本在字母/词/句/语义各层级如何关联"的理解。本文提出一个**层级对齐框架**，主攻此前研究较少的**句级 EEG-to-text 分类（检索）**——用上下文 + EEG 作为输入检索出被读的句子。
- **解决什么问题 / 为什么重要**：命中 B 的**神经影像时间序列 / 脑机接口**应用。它把研究重心从"字母/词级解码"上移到更贴近真实沟通的**句级**，并明确区分"句子该检索还是该生成"这一被忽视的问题——在 EEG-to-text 中优先把句级分类/检索做扎实，对评估 EEG 承载的语义信息上限有方法论意义。
- **核心方法**：提出层级对齐框架，在字母/词/句/语义多层级上建立 EEG 与文本的对应 → 聚焦句级，把"读过的句子检索"形式化为以上下文与 EEG 为输入的检索任务 → 利用句子"即使缺词缺字母仍可理解"的高层信息冗余性支撑检索。
- **主要结果**：论文定位为句级 EEG-to-text **分类/检索**的研究，主张在该设定下用上下文 + EEG 检索被读句子；（具体数值指标以原文为准，摘要未给出完整对比数字）。
- **值得追问 / 局限**：① "检索"范式本质是在候选句集合里匹配，开放词表/开放句的真实沟通场景下能否推广到生成，是核心外推问题；② EEG 句级解码长期受个体差异与信噪比限制，框架在跨被试/跨会话的泛化与对"上下文泄漏"（检索是否部分靠语言先验而非脑信号）的消融需重点审视。

## C. 机制 / Agent（LLM 自我承诺方向的残差流定位 / 预训练规模逆转 Muon-AdamW 微调差，取 2 篇；均为"优先"机制类，非 prompt 工程）

### 5. Written Once, Read Differently: How Language Models' Own Answers Steer Their Next Ones
- 链接：https://arxiv.org/abs/2611.03198
- 作者：Marcus Armstrong（cs.CL / cs.AI）
- **TL;DR**：当语言模型回答一个是非题后，这个答案会改变它对"同一实体另一个问题"的回答。本文研究这种**自我承诺（self-commitment）**：在 4 个家族、22 个开源模型（0.5B–72B）、120 个实体 3600 对问题上固定第一答案、测量第二答案的偏移，发现每个答案都会往**残差流**写入一个"**承诺方向**"。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / 表征几何 / residual-stream 干预**（正中"优先"）。它把"模型被自己此前输出带偏"这一现象拆成"**写入（表征）**"与"**读出（电路）**"两层：写入是稳定的单一方向（跨主题共享、可被单方向消融），读出却高度不稳定（随规模、指令微调、甚至系统提示翻转符号）——对理解一致性/自洽偏置的内部来源给出因果级证据。
- **核心方法**：固定模型第一答案、测量其对第二问的偏移以量化自我承诺 → 用两问"承诺方向"的相似度预测它们在留出实体上的耦合 → 消融跨主题共享的单一方向、并对比"保留 / 不保留 attention sink"两种消融 → 考察读出电路随规模、指令微调、系统提示的变化。
- **主要结果**：两问方向相似度能预测留出实体上的耦合（ρ=0.43–0.85）；消融跨主题共享的单一方向后，各模型残留效应 ≤17%；"读出"远不稳定——读出电路随模型增大分散到更多注意力头，指令微调让更多问题以**相反**意义读取它，某模型仅改系统提示即可翻转电路符号；在保留 attention sink 的前提下消融该方向，可在 <1.3% 困惑度代价下移除 18/19 个指令微调模型的大部分耦合。
- **值得追问 / 局限**：① "写入稳定、读出不稳定"若普遍成立，意味着靠对齐/提示来抑制自我承诺偏置可能治标不治本（方向仍被写入），这对一致性审计的含义值得单独追问；② 结论基于是非题这一受控设定，能否推广到开放生成、多轮推理中的"自我一致性/自我强化"仍待检验，且 attention sink 的作用在不同架构上可能不一致。

### 6. Pretraining Data Scale Reverses the Muon-AdamW Fine-Tuning Gap
- 链接：https://arxiv.org/abs/2611.03633
- 作者：Catherine Li, Jingchu Gai, Andrej Risteski, Jacob Mitchell Springer, Aditi Raghunathan（cs.LG）
- **TL;DR**：Muon 作为预训练优化器近来在最小化预训练损失上快过 AdamW，但其优势在**微调后**是否仍在并不清楚。本文发现一个反直觉趋势：**预训练数据预算足够大后，AdamW 在微调后反超 Muon**；且模型越大，AdamW 在越小的 token-参数比上就实现反超。
- **解决什么问题 / 为什么重要**：命中 C 的**训练动态 / 优化器现象分析**（正中"优先"，非 prompt 工程）。它不止报告一个经验反转，还提出**margin-to-spread 比**（正确 logit 高出错误 logit 的幅度 ÷ 错误 logit 的分散程度）作为解释变量，并在"线性联想记忆"玩具模型上**证明**随数据预算增大、GD 的该比值会反超 Muon——把"预训练用哪种优化器更利于下游"这一实践问题接上了可分析的理论。
- **核心方法**：系统比较 Muon 与 AdamW 预训练后再微调的下游表现，扫预训练数据预算与模型规模 → 把微调视作对输出的扰动，定义 margin-to-spread 比并测量其随数据预算的变化 → 在线性联想记忆上证明一步更新后 GD 的该比值随数据预算增大而反超 Muon，并以仿真验证长训练后趋势持续。
- **主要结果**：超过某预训练数据预算后 AdamW 微调表现反超 Muon，且随模型增大反超点前移到更小 token-参数比；语言模型中 Muon 在小数据预算下 margin-to-spread 比更大、AdamW 在大数据预算下更大，与微调趋势吻合；线性联想记忆上理论与仿真均支持该反转。
- **值得追问 / 局限**：① 核心理论基于线性联想记忆这一高度简化设定，margin-to-spread 比能否在真实大模型/复杂下游任务上稳定作为"预测反转点"的充分指标仍需更多实证；② 结论对微调方式（全参/LoRA、学习率、步数）与下游任务类型的敏感性未充分展开，"该用哪种预训练优化器"的实践建议需按预算/规模分层给出。
