## 1. STST-JEPA: Shallow-Target Spatio-Temporal Joint Embedding Prediction Architecture For EEG Self-Supervised Learning
- arXiv：https://arxiv.org/abs/2607.06629 （cs.LG, q-bio.NC）
- 作者：Roy Segal, Yoni Svechinsky, Tomer Fekete
- **TL;DR**：把 JEPA 式潜空间预测自监督用到静息/任务态 EEG 上，在 4.7 万+ 会话（年龄 5–81 岁）上预训练一个时空 Transformer，冻结表征即可做到脑龄回归 MAE 3.06 岁，并在多项脑电基准上拿到第一。
- **解决什么问题 / 为什么重要**：脑龄（physiological age 与实际年龄之差）是追踪神经/精神负荷的新兴生物标志物，但 EEG 建模苦于跨站点导联异构、有标注队列小、被试级非平稳占主导，少有基础模型能覆盖儿童到老年的全龄段。这篇正好落在"时空掩码建模 + 脑功能时序"的交叉点，对 fNIRS/脑网络这类同源神经影像时序方向有直接方法借鉴。
- **核心方法**：对 30 秒多通道窗口施加时空块掩码，用"预测被掩 token 表征、对齐 EMA-tokenizer 目标"的潜预测目标，外加一个信号重建辅助项；下游只在冻结表征上训练一个轻量注意力探针（或微调最后几层）。
- **主要结果**：3367 会话上脑龄回归 held-out MAE 3.06 岁（r=0.924，均值基线约 10 岁）；轻微调后在公开 NeuralBench×brain.space 榜单的性别分类（均衡准确率 0.911）、年龄预测（r=0.749）、精神病理综合回归（r=0.215）均登顶；脑龄残差与多任务认知效率负相关。
- **值得追问 / 局限**：脑龄残差与认知效率的相关是否有混杂（如唤醒度、伪迹）？潜预测 vs 信号重建两目标各贡献多少？能否迁移到通道更少、信噪更差的 fNIRS。

## 2. Drift-Aware Temporal Graph Rewiring (DATGR) for Adaptive Semantic Modeling in Biomedical Text
- arXiv：https://arxiv.org/abs/2607.08490 （cs.AI）
- 作者：Bharathwaj Vijayakumar, Sahana K. Varadaraju
- **TL;DR**：生物医学语义随新发现快速漂移，静态嵌入/共现图会失真；DATGR 不重训嵌入，而是按估计的语义漂移用逻辑斯蒂更新规则动态重连共现图的边权，做轻量、可解释的时序图自适应。
- **解决什么问题 / 为什么重要**：这是"动态图 / 时序图 + 边级演化 + 链接预测"的直接实例——把概念随时间演化建成边权的连续更新，而非逐时间片重训，属于低成本的持续图学习思路，对时序图建模的工程可行性有参考价值。
- **核心方法**：在共现图上以反馈驱动方式对边权施加逻辑斯蒂更新，按估计的语义漂移增删/加权边（rewiring），避免为每个时间片重训嵌入；整体保持轻量、可解释。
- **主要结果**：在 BIOMRC（生物医学多关系语料）上，AUROC 从 0.633 提升到 0.699（+0.066 绝对值），AUPRC 基本持平（0.738 vs 0.744），说明漂移感知重连主要提升了链接预测召回而不损精度。
- **值得追问 / 局限**：单一数据集、增益中等，是否泛化未知；"语义漂移"的估计信号来自何处、如何避免噪声反馈放大？逻辑斯蒂更新规则相对更强的时序图神经网络（TGN 类）缺少对照。

## 3. CAAD: Causality-Aware Multivariate Time Series Anomaly Detection via Multi-Scale Alignment and Structural Causal Consistency
- arXiv：https://arxiv.org/abs/2607.08555 （cs.LG）
- 作者：Xin Wang, Yunshi Wen, Yanan He, Haotian Xu, Youlan Zhao, Michel Ferreira Cardia Haddad
- **TL;DR**：不再只盯表征的时序相似性，而是把异常检测重构成"对 Granger 因果一致性的持续验证"——把外生变量建成残差，用梯度矩阵监控内部因果关系的崩解来定位异常。
- **解决什么问题 / 为什么重要**：工业系统失效往往表现为内部因果关系被破坏，而大多数方法只捕捉表征相似度、忽略这一点，对潜伏异常不敏感。把"因果拓扑变化"显式量化，对监控告警的根因可解释性和微妙故障的早发现有实用价值。
- **核心方法**：将外生时序变量建模为残差，把由外部干预导致的显著偏差判为异常；用多尺度对齐把系统动力学内化，再用基于梯度的矩阵监控内部因果关系的断裂；同时量化"动态演化偏差"与"关系拓扑偏差"以捕捉细微因果漂移。
- **主要结果**：在多个真实工业数据集上实现高精度异常检测，优于多数 SOTA 基线。
- **值得追问 / 局限**：Granger 因果在强非线性/高维系统上的适用性与误报控制如何？"因果崩解"与单纯分布漂移能否可靠区分？缺少对定位（根因）而非仅检测的量化评估。

## 4. Self-Adaptive Anomaly Detection with Reinforcement Learning and Human Feedback in Connected Vehicles
- arXiv：https://arxiv.org/abs/2607.08373 （cs.LG, cs.AI）
- 作者：Matthias Weiß, Athreya Hosahalli Prakash, Maurice Artelt, Falk Dettinger, Nasser Jazdi, Michael Weyrich
- **TL;DR**：面向会随 OTA 更新/配置变化而"正常态漂移"的自治 CPS，搭一个在线异常检测闭环：用带自注意力的因子化 DQN 为每个微服务选检测器、三重漂移检测器齐发才告警、并配人在环重训以纳入专家知识且不遗忘旧分布。
- **解决什么问题 / 为什么重要**：这是很典型的 AIOps/监控问题——系统自身在演化，静态诊断会"悄悄失效"；已有工作要么只做自动模型自适应、要么只做操作员集成，很少把两者合成一个协调的监督闭环。对告警降噪、概念漂移下的持续可用性有直接工程意义。
- **核心方法**：①因子化深度 Q 网络 + 自注意力，利用微服务拓扑的服务间依赖，为每个受监控服务从候选池选最合适的检测器；②三个统计漂移检测器组成集成，三者一致才报警（重精度轻召回）；③围绕待定转移缓冲 + 60/40 优先回放的人在环重训，纳入专家知识同时保留对旧数据分布的响应。
- **主要结果**：在自动代客泊车、七个后端微服务的联网车测试床上，注意力增强 agent F1=0.69（任一单检测器统一使用最多 0.11）；一次真实软件更新引入可测概念漂移后 F1 降到 0.52，操作员触发重训后在新分布回升到 0.65、旧分布仍保持 0.69——展示了无灾难性遗忘的持续自适应。
- **值得追问 / 局限**：单一测试床、单应用，跨车队/跨场景可扩展性存疑；"三检测器一致才告警"在真实高频漂移下是否漏报严重？人在环标注成本与延迟未量化。

## 5. Towards Mechanistically Understanding Why Memorized Knowledge Fails to Generalize in Large Language Model Finetuning
- arXiv：https://arxiv.org/abs/2607.08393 （cs.AI, cs.CL）
- 作者：Lu Dai, Ziyang Rao, Yili Wang, Hanqing Wang, Hao Liu, Hui Xiong
- **TL;DR**：把"微调后 LLM 能背下新事实却用不出来"形式化为 Knowing–Using Gap（存在准确率差和记忆→泛化的时间滞后），用一种叫 self-patching 的干预技术追踪知识在网络内部的空间渗透，提出"知识-电路错位"假说。
- **解决什么问题 / 为什么重要**：向 LLM 注入新知识时"记住≠会用"是微调的核心痛点。这篇是机制/现象分析（非 prompt 技巧）：它不只描述现象，还给出可干预的内部诊断，直接触及"表征存在但未被路由到能参与计算的层"这一表征几何/训练动态问题。
- **核心方法**：用未见知识微调 LLM，监控知识在内部的空间渗透动态；self-patching 找出"把表征搬到该处能显著修复失败泛化"的激活位置，据此支持"记忆表征存在于内部、却未被路由到计算有效层"的知识-电路错位假说；再据诊断设计一个简单启发式修复策略。
- **主要结果**：启发式策略在泛化失败样本上恢复了 58–75% 的 oracle 提升空间；跨域实验验证了该发现的稳健性。
- **值得追问 / 局限**：self-patching 定位到的"计算有效层"是否随模型规模/知识类型迁移？启发式修复能否在不牺牲既有能力下规模化？"知识-电路错位"仍是相关性证据，缺反事实的充分性验证。

## 6. Remember When It Matters: Proactive Memory Agent for Long-Horizon Agents
- arXiv：https://arxiv.org/abs/2607.08716 （cs.AI, cs.CL）
- 作者：Yifan Wu, Lizhu Zhang, Yuhang Zhou, Mingyi Wang, Bo Peng, Serena Li
- **TL;DR**：长时程任务里决策相关状态散落在不断增长的轨迹中、易被挤出上下文（作者称之为"行为状态衰减"）；本文把记忆当作主动干预：一个独立记忆 agent 与未改动的行动 agent 并行，从近期轨迹更新结构化记忆库，并自行决定"注入一条有据的提醒还是保持沉默"。
- **解决什么问题 / 为什么重要**：这是 agent 方向里"优先"的机制类工作——把记忆从被动检索重构为主动、选择性的干预机制，即插即用于前沿行动 agent 与现有 harness，直指长时程决策中信息何时该被"翻出来用"的核心问题。
- **核心方法**：独立记忆 agent 从近期轨迹维护结构化记忆库，并做二元决策——注入记忆锚定的提醒或沉默；与行动 agent 解耦、即插即用。作为迈向开放权重记忆策略的一步，在 SETA 上用 SFT+GRPO 训练 Qwen3.5-27B。
- **主要结果**：在 Terminal-Bench 2.0 与 τ²-Bench 上对强弱两类行动 agent 的 pass@1 均有提升（+8.3pp / +6.8pp）；消融显示"选择性干预"优于被动记忆库暴露、始终注入、仅建议、通用检索；训练所得开放权重策略提升验证奖励并部分迁移到 Terminal-Bench。
- **值得追问 / 局限**：记忆 agent 的"何时注入"决策本身的错误率与开销如何？在更长（数十步以上）或多智能体环境下是否仍稳？+6~8pp 的增益对不同基座 agent 的方差有多大。
