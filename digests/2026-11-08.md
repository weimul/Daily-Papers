## A. 核心方法（自解释交互律 / 通用图级异常检测，取 2 篇）

### 1. Interpretable many-body interaction laws for collective motion from few trajectories
- 链接：https://arxiv.org/abs/2611.08314
- 作者：Timon S. Gutleb（cs.LG）
- **TL;DR**：群体运动模型通常把社会交互简化为两两成对力，但实证上存在多体效应。本文把物理里的**原子团簇展开（ACE）** 迁移到自驱动智能体，提出 **dACE**——一个精确等变、可系统性改进、并**唯一分解为 1 体 / 2 体 / 3 体及更高阶**贡献的加速度展开，另设一个"自项"刻画智能体自身过去运动且被约束为不吸收交互信息。
- **解决什么问题 / 为什么重要**：命中 A 的**内生 / 自解释**横切重点——它不是对黑箱模型做事后归因，而是把"交互律"本身设计成按体阶可读的闭式展开，天然自解释。对"想从轨迹数据里学出**机制上可解释、可按阶拆分**的动力学 / 交互结构"（含时空多智能体、群体 / 脑网络耦合）是直接的方法学样板。
- **核心方法**：以 ACE 的等变多体基展开智能体加速度 → 唯一拆分为 1/2/3+ 体贡献 + 一个被约束不吸收交互的自项 → 在已知规则的 2D/3D 模拟群体上按体阶逐级恢复交互律 → 在真实斑马鱼 / 金鱼群轨迹上检验稳定性。
- **主要结果**：在已知规则的模拟群体上，dACE 用很少数据即可逐阶恢复交互律，相比当前最接近的神经模型 **SocialNet** 数据需求更低、在多体 / 手性规则上误差显著更小、且不受 2D 限制；真实鱼群数据上，dACE 学到的律在数据两不相交半区间的一致性优于 SocialNet；在金鱼群中 **3 体项**随邻域变密而**反向抵消**成对响应。作者还指出"下一步预测精度"主要测的是自驱动与噪声、而非交互，并建议更稳健的交互学习评测组合。
- **值得追问 / 局限**：① 体阶展开的阶数截断与计算开销如何随群体规模 / 维度扩展，强各向异性或长程交互下是否仍"少数据可辨"，论文以中小群体为主；② 真实数据验证限于鱼群，迁移到人群 / 细胞 / 脑区耦合等"交互噪声更大、观测更不规则"的场景，稳健性仍待检验。

### 2. Towards Generalist Graph-Level Anomaly Detection (GenGLAD)
- 链接：https://arxiv.org/abs/2611.07706
- 作者：Junjun Pan, Yixin Liu, Yu Zheng, Fuyi Li, Alan Wee-Chung Liew, Shirui Pan（cs.AI）
- **TL;DR**：图级异常检测（GLAD）要识别整体偏离多数的异常图，但现有方法多是"每个数据集单独训"的范式，换新场景就要大量域内数据与训练开销。本文研究**通用 GLAD**：学一个统一模型，在**最少目标监督**下跨多个域检测异常图，核心机制是**判别性子图提取**学可迁移异常知识 + 测试时自适应。
- **解决什么问题 / 为什么重要**：命中 A 的**图神经网络方法**，同时是 B 的**异常检测**（A/B 交叉）。它把"异常=可迁移的判别子结构"这一归纳偏置显式化，直击真实部署里"标注稀缺、域持续涌现"的痛点；对监控 / 告警里"新系统上来就缺历史异常样本"的冷启动场景有迁移价值。
- **核心方法**：用 GNN 的**判别性子图提取模型**学"区分异常图 vs 正常图"的跨域可迁移子结构 → 测试时自适应阶段，计算提取子图与**多层级上下文信息**的多维差异来刻画异常 → 引入轻量打分模块自动挑选最有信息量的信号、抑制误导性模式。
- **主要结果**：在多个基准数据集上取得强性能、**更优的泛化能力与数据效率**（相较现有方法），验证了"单一统一模型跨域少监督检测异常图"的可行性。
- **值得追问 / 局限**：① 摘要未给与各域专训 SOTA 的逐项数值差，"通用性"相对"专训"的性能代价需看正文；② 判别性子图 + 测试时自适应的计算 / 稳定性开销，以及能否推广到**时序图 / 动态图**（传播结构随时间变化）这类设定，论文未覆盖。

## B. 应用场景（非线性神经动力学辨识 / 域无关残差异常检测，取 2 篇）

### 3. Identifying Neural Dynamics Using Nonlinear Interventional State Space Models
- 链接：https://arxiv.org/abs/2611.08113
- 作者：Hanna M. Tolle, Carles Balsells-Rodas, Yixin Wang, Pedro A. M. Mediano, Amin Nejatbakhsh（stat.ML）
- **TL;DR**：状态空间模型（SSM）从高维观测里恢复低维潜在动力学，但仅凭观测数据潜变量一般**不可辨识**。干预式 SSM（iSSM）用扰动打破观测对称性、把参数辨识到"置换 / 缩放 / 平移"等价类。此前 iSSM 只能保证**线性**潜在动力学 + 分段线性发射，排除了许多神经回路行为。本文把可辨识性**推广到一般非线性潜在动力学**。
- **解决什么问题 / 为什么重要**：命中 B 的**脑 / 神经时间序列**，并与 A 的**潜在 / 连续动力学辨识**强交叉。它给"用隐变量动力学模型解释神经记录"补上了一块理论地基——在有干预（刺激）时，即便潜在动力学是一般非线性、发射是一般单射，也能辨识到置换 / 缩放 / 平移；这对任何"想用潜在动力学模型做脑 / 神经时序、并关心参数是否真的被辨识出来"的工作（含 fNIRS / EEG 潜态建模的类比思路）有方法学意义。
- **核心方法**：证明两条结论——(i) 在**一般单射发射 + 高斯潜在转移**下仿射可辨识；(ii) 有干预时，在**一般非线性潜在动力学**下保持"置换 / 缩放 / 平移"可辨识 → 在模拟 FitzHugh–Nagumo 动力学上验证 → 两个应用：裁决相互竞争的决策模型、在猕猴与人类神经记录上预测**未见微刺激**的响应 → 由模拟给出"如何设计刺激协议以提升可辨识性"的实操指引。
- **主要结果**：理论在 FitzHugh–Nagumo 模拟上得到验证；在真实神经记录上成功预测对未见微刺激的响应，人类数据上对**留出刺激位点**有概念验证级泛化；并给出改进可辨识性的刺激设计建议。
- **值得追问 / 局限**：① 可辨识性依赖"有干预（刺激）"，在只能被动观测、无法主动扰动的脑成像场景（如多数 fNIRS / 静息态）能走多远未明；② 真实数据仍是 proof-of-concept 规模，跨被试 / 跨任务态、以及发射函数单射假设被破坏时的鲁棒性待验证。

### 4. DART: Domain-Agnostic Residual Transfer for Generalist Anomaly Detection
- 链接：https://arxiv.org/abs/2611.08271
- 作者：Muhammad Aqeel, Maham Nazir, Marco Cristani, Francesco Setti（cs.CV）
- **TL;DR**：通用异常检测（GAD）要在**未见域**上只用少量参考样本检测异常。近期"正常-异常引导"方法虽借助异常参考提升效果，但其残差常把"可迁移的异常线索"与"域特定外观因素（纹理、几何、采集条件）"混在一起，这种**残差的域纠缠**限制跨域迁移、还可能在新域上产生虚假激活。DART 学着把残差**拆成"异常相关"与"域特定"两部分**。
- **解决什么问题 / 为什么重要**：命中 B 的**异常检测 / 监控**线。它把"残差解耦"这一思路引入少样本跨域异常检测，正面回应"参考引导类方法为何换域就飘"的结构性问题；对"监控 / 质检里设备 / 环境条件一变就误报"的跨域告警有直接借鉴，且是可插拔模块、易接入现有管线。
- **核心方法**：**残差解耦模块（Residual Disentanglement Module）** 保留异常判别信息、抑制域信息 + **跨域元训练（Cross-Domain Meta-Training）** 跨源域构造 episode 让解耦更有效 → 模块**架构无关**，可插在"残差计算"与"检测头"之间接入既有 GAD 管线。
- **主要结果**：在 **MVTec AD、VisA、BraTS** 上相对多个基线方法一致提升，且**域偏移越强增益越大**；开源地址 https://github.com/aqeeelmirza/DART 。
- **值得追问 / 局限**：① 评测集中在工业缺陷与医学影像（图像域），对**多变量时间序列 / 监控告警**这类时序异常是否同样奏效，论文未直接覆盖（需迁移验证）；② 解耦质量依赖"跨源域有足够多样性"构造 episode，源域过少 / 同质时解耦是否退化，摘要未展开。

## C. 机制（neural collapse 特征几何 / 机制可解释性现状综述，取 2 篇；均"优先"机制类，非 prompt 工程）

### 5. Comparing Classification and Feature Learning by Analyzing Their Loss Functions in Normalized Spaces with Different Scale Factors
- 链接：https://arxiv.org/abs/2611.07741
- 作者：Qiufu Li, Huibin Xiao, Linlin Shen, Weijia Fan, Xi Jia, Yongdong Huang（cs.LG）
- **TL;DR**：分类与特征学习紧密相关，常默认"分类精度越高、特征越好"。本文指出：分类精度反映的是**样本级局部性质**，而特征学习要的是**数据集级全局性质**（类内紧致、类间可分）。据此在归一化特征空间重设 BCE 损失（对应分类里的 CE），分析二者极小点与 **neural collapse**，并揭示尺度因子 γ 如何让"分类精度"与"特征质量"在**不同大小的空间里差异化变化**。
- **解决什么问题 / 为什么重要**：命中 C 的**表征几何 / neural collapse**，正中"优先"机制类。它把"精度 ≠ 特征质量"这件事做了可控的几何刻画：通过调 γ 分离"达到完美分类"与"收敛到理想特征几何（neural collapse）"两个目标，解释了为什么高精度模型的特征几何未必好——对任何"用分类头顺带学表征、却想要良好类内 / 类间结构"的做法（含下游检索 / 开集 / 长尾）有直接启示。
- **核心方法**：从特征学习第一性原理重设 BCE 损失 → 在归一化特征空间分析 BCE 与 CE 的极小点，证明两者都可导致 neural collapse（类间最大紧致 + 最大可分）→ 随尺度因子 γ 变化考察二者收敛行为：γ 过大→完美分类但收敛到理想特征几何变慢；γ 过小→分类对微扰高度敏感；**中等 γ** 才能兼顾可靠分类与良好结构。
- **主要结果**：实验验证上述几何分析；且 BCE 损失在**长尾与开集识别**上表现出优势，因其更契合特征学习的全局性要求。
- **值得追问 / 局限**：① 分析在归一化特征空间 + 固定训练策略下成立，去掉归一化 / 换优化器与数据增强后，γ–几何关系是否稳健未充分讨论；② neural collapse 刻画的是训练末期理想态，对"中途表征 / 迁移性"的指导需进一步连接。

### 6. Understanding AI from the Inside: The State of Mechanistic Interpretability for AI Safety
- 链接：https://arxiv.org/abs/2611.08438
- 作者：Fazl Barez, Tung-Yu Wu, Hunar Batra, Gabriele Dominici, Florent Draye, Yanai Elazar 等（cs.CL）
- **TL;DR**：一篇**面向 AI 安全的机制可解释性现状综述 / 技术报告**，核心追问："理解模型如何工作，是否真的让它更安全？" 它把机制可解释性放进更大的可解释性版图，对比其"机制证据"与"行为评测"，系统梳理特征 / 多义性 / Transformer 计算 / 电路等基础，并提出**统一的主张评估框架**与**六类研究取向**。
- **解决什么问题 / 为什么重要**：命中 C 的**机制 / technical report**，正是"优先"机制类。对把"内生 / 可验证可解释性"当研究主线的人，它是一份高密度的地图：覆盖特征抽取与分析、电路发现与**因果验证**、**用自然语言解释中间表征**、**学习动态**、训练数据归因等——正好横跨我关注的 residual stream / 机制 / 自解释诸线；并给出"如何评估一条机制解释主张是否成立"的统一判据，可直接拿来审视自己和他人的解释工作。
- **核心方法**：把机制可解释性置于可解释性整体脉络、与行为评测对照 → 梳理基础概念（features、polysemanticity、transformer 计算、circuits）与方法族（特征抽取 / 电路发现 / 因果验证 / 自然语言解释中间表征 / 学习动态 / 训练数据归因）→ 提出**统一评估框架** + 按目标 / 假设 / 权衡刻画**六类研究取向** → 讨论机制理解如何支撑知识编辑、steering、监控，并评估其失效模式与开放问题 → 配套可复现关键发现的代码 notebook 仓库。
- **主要结果**：产出一套评估机制可解释性主张的统一框架与六类研究取向的分类，并随附可动手复现的 notebook，便于读者建立直觉、对照各方法的证据强度与局限。
- **值得追问 / 局限**：① 综述性质决定其"结论"多为框架与判断而非新实证，具体方法的有效边界仍需回到各原始工作；② 作者对"机制证据 vs 行为评测"的权衡给出立场，但"理解是否真的带来更强安全保证"仍是开放问题，需结合干预 / 监控的实测来落地。
