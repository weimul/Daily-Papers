## A. 核心方法（连续时间 Koopman 生成子的随机特征逼近 / 跨本体时空动力学先验的连续动作世界模型，取 2 篇）

### 1. Data-driven Random-feature Approximation of Koopman Generators of Nonlinear Continuous-time Systems
- 链接：https://arxiv.org/abs/2610.39897
- 作者：Ana Čukarska, Maximilian Gollwitzer, Viola Muning Li, Vladyslav Fediukov, Zahra Monfared, Felix Dietrich（6 位；cs.LG）
- **TL;DR**：从数据学**连续时间**动力学时，Koopman 形式把系统表示为作用在函数空间上的线性算子，但数值逼近最大的痛点是"字典"（有限维函数表示）的选取；本文给 **Koopman 生成子**（而非算子，因为是连续时间）提出一套**数据驱动的随机特征**方法，为 gEDMD 这类 Galerkin 逼近构造出"数据知情、简约而有效"的函数表示，并证明了逼近的收敛性。
- **解决什么问题 / 为什么重要**：直击 A 的**连续时间模型（核心方法）**这一支，且走的是"可解释、数学稳健"的路线而非黑箱拟合——Neural ODE / latent ODE 之外，Koopman 是另一条学连续时间动力学的主线，本文把它的工程瓶颈（字典选取）用数据驱动随机特征一次性缓解，还配了收敛性证明与反例（指出 gEDMD 一般**不保指数有界性**），对你关注的"连续时间 / 不规则采样建模"提供了一个有理论担保、比迭代优化更快的替代算子视角。
- **核心方法**：① 针对连续时间，逼近 **Koopman 生成子**（半群的无穷小生成元）而非算子；② 用**数据驱动随机特征**构造 Galerkin / gEDMD 的有限维字典，让表示"数据知情"从而优于数据无关方法；③ 理论侧给出 gEDMD 逼近所生成半群的**一般收敛判据**，并证明向量场与由此得到轨迹的收敛，另附"gEDMD 不保指数有界"的反例。
- **主要结果**：在预测任务与系统分析上实证有效，**精度高且比迭代优化更快**；理论上证明了对向量场及轨迹的收敛，给出半群收敛的一般判据。
- **值得追问 / 局限**：① 随机特征的"数据知情"构造在**高维 / 强非线性**系统下，字典维度与采样覆盖如何权衡、随机特征数怎么定，摘要未给可操作选型准则；② 反例已表明 gEDMD 不保指数有界，意味着长时程外推/稳定性在某些系统上仍无保证，落地前需对目标系统单独验证轨迹稳定性。

### 2. Continuous-Action World Models: Learning Cross-Embodiment Spatiotemporal Dynamics Priors
- 链接：https://arxiv.org/abs/2610.40401
- 作者：Liangyu Li, Qingwen Liu（2 位；cs.RO，交叉 cs.LG）
- **TL;DR**：CoAWM 学一套**跨本体的时空动力学先验**——核心是一个**共享潜函数空间**捕捉机器人动作的空间与时间结构：先做"函数预训练"把不同本体、不同采样频率的轨迹拉进同一表示，再把该函数空间接到世界模型骨干，用观测/语言指令/当前状态来条件化地预测一个**潜动作函数**，单解码器对**任意查询时刻**返回对应末端执行器动作。
- **解决什么问题 / 为什么重要**：命中 A 的**时空结构 + 连续时间采样**——它把"动作"建成连续时间上的函数（任意 query time 解码），而非固定频率的离散序列，正好对上你关注的"不规则采样 / 连续时间模型"思路，只是落在机器人动作域。方法论上值得借鉴的是**"共享动力学先验"与"任务条件化动作选择、时间采样"解耦**：前者可跨异构数据源扩规模预训练，后者按任务条件生成，这种分离对任何"先学通用时空先验、再按场景条件化"的时序/时空建模都有参照价值。
- **核心方法**：① **函数预训练**：通过动作重构 + 跨时间采样视图的一致性，把不同本体/采样频率的轨迹带入共享潜函数空间，学到共享动力学先验；② 把预训练函数空间接到**世界模型骨干**，由观测、语言指令、当前机器人状态条件化地预测潜动作函数；③ **单解码器 + 任意查询时刻** → 对应末端执行器动作，从而把"共享先验"与"任务条件化动作/时间采样"解耦。
- **主要结果**：给出一个可跨本体、跨控制频率迁移机器人经验的统一基础框架；通过兼容异构轨迹，拓宽了预训练可用的数据来源并利于向更大更多样数据集扩展（摘要为框架性陈述，未列定量基准表）。
- **值得追问 / 局限**：① 摘要**未给定量对比/消融**，"跨本体迁移"与"任意频率解码"的实际收益、相对现有世界模型（Dreamer 系等）的优劣仍待看正文数据；② 共享潜函数空间靠"动作重构 + 时间采样一致性"学成，在本体差异极大（自由度/动力学迥异）时，该空间是否仍能同时容纳而不互相污染，需看跨本体泛化的失败模式。

## B. 应用场景（EEG 实时概率预测的 RVQ 一次生成 / fMRI 的 JEPA 自监督跨被试对齐，取 2 篇）

### 3. REVBRAIN: Real-time Probabilistic EEG Forecasting Using Residual Vector Quantization
- 链接：https://arxiv.org/abs/2610.38558
- 作者：Hanna Pankka, Jaakko Lehtinen, Timo Roine（3 位；cs.LG，交叉 eess.SP / q-bio.NC）
- **TL;DR**：脑状态依赖刺激（brain-state-dependent stimulation）等应用需要**实时预测**静息态 EEG，此前的 WaveNet 虽比线性 AR 准、还自带不确定度，但逐样本自回归太慢无法实时；REVBRAIN 用**残差向量量化（RVQ）** 把输出空间 token 化、**一次性生成整段预测窗口**，从而实现实时概率预测。
- **解决什么问题 / 为什么重要**：直接贴合你的**脑功能 / 神经影像时间序列**方向，且是把"生成式 token 化 + 概率预测"用到脑信号实时闭环的务实工作。它解决的是一个真实落地瓶颈：BCI / 闭环刺激要求预测必须跟得上在线神经振荡，而逐样本自回归天然做不到——用 RVQ 把"整段预测窗口"变成在 token 空间里一次生成，是绕开自回归延迟的关键思路，对任何需要"实时 + 带不确定度"的时序预测都有迁移价值。
- **核心方法**：① 用 **RVQ** 把输出（预测窗口）空间 token 化；② 在 token 化空间里**对整个预测时段一次性生成**，而非逐样本自回归；③ 保留概率建模框架，从而内生地给出不确定度度量；在 alpha 频段（8–13 Hz）预测 200 ms EEG 上与 WaveNet 对比。
- **主要结果**：在笔记本 GPU 上达到**实时推理**，相对 WaveNet **提速 50 倍以上**，同时预测精度**更优**；由此让"准确 + 概率化"的 EEG 预测可嵌入 BCI 实时应用。
- **值得追问 / 局限**：① 评测聚焦**静息态 alpha 频段、200 ms 短窗**，对任务态、宽频 / 跨频耦合、以及更长预测时程的表现未知，RVQ 码本容量在更复杂信号上可能成为瓶颈；② "一次性生成整段窗口"牺牲了自回归的逐步条件化，在信号突变（如伪迹、事件相关去同步）时，整段预测的误差结构与不确定度校准是否仍可靠，值得在闭环刺激场景实测。

### 4. Latent Prediction Yields Cross-Subject Alignable Representations in Sensory-Evoked fMRI
- 链接：https://arxiv.org/abs/2610.40280
- 作者：Serwan Jassim, Victoria Bosch, Daniel Anthes, Elia Bruni, Tim Kietzmann（5 位；cs.LG，交叉 cs.AI / q-bio.NC）
- **TL;DR**：解码感觉诱发 fMRI 是认知神经科学的核心工具，但自监督学习（SSL）在此几乎没被探索；本文把 **JEPA（联合嵌入预测架构）** 搬到 fMRI，**只用脑数据**（从不看刺激图像或其派生表示）训练个体专属编码器，在 NSD 数据集上做脑字幕 / 图像重建，并实现**全无监督的跨被试对齐**。
- **解决什么问题 / 为什么重要**：命中 B 的**神经影像 / 脑网络**，而且方法论很对你的内生表征口味——它追问"在不借助刺激监督的前提下，纯脑数据 SSL 能否学出支撑强下游表现的表征"，答案是**能**：自监督编码器与"端到端、能看图像和语言的参数量大监督管线"**性能相当**。更关键的是跨被试那一步——不同被试独立训练的编码器可**仅用脑数据、无共享刺激**对齐，对齐后一个被试上训的解码头**不微调**就能用到另一人并保住大部分性能，这为"跨人 / 跨数据集池化 fMRI"扫清了"必须共享刺激"的障碍。
- **核心方法**：① 把 **JEPA** 适配到 fMRI，训练**个体专属编码器**，输入仅脑数据、绝不接触刺激图像或其派生表示；② 在 NSD 上评 brain captioning 与图像重建两类下游任务；③ **跨被试对齐**：对独立训练的各被试编码器做全无监督对齐（既不用图像也不用共享刺激），再把一个被试的解码头迁移到另一人。
- **主要结果**：自监督方案与**参数量大、端到端且可见图像+语言的监督管线性能相当**；跨被试对齐后，单被试训练的解码头**无需微调**迁移到他人，在图像重建与脑字幕上**保住大部分同被试性能**。
- **值得追问 / 局限**：① 结论基于 **NSD 单数据集的感觉诱发 fMRI**，"跨数据集"仍只是展望，不同扫描仪/范式/预处理下对齐是否成立未验证；② "无共享刺激即可对齐"很强，但对齐质量对被试数、脑区覆盖、以及个体编码器初始表征的依赖关系未充分刻画，样本少时对齐可能退化，需看规模曲线。

### 5. world2vec: Mechanistic world models through latent dynamics learning
- 链接：https://arxiv.org/abs/2610.40637
- 作者：Tobias Schmidt, Rodrigo Gonzalez Laiz, Krisztián Szuppinger, Steffen Schneider（4 位；cs.LG）
- **TL;DR**：现有世界模型往往"不忠实还原环境动力学也能控制得好"，这限制了它们用于机制可解释与科学发现；world2vec **不用奖励信息、直接从观测与动作**学"机制性世界模型"，其潜动力学能在**长程预测**上忠实复现真系统，参数比 DreamerV3 / TD-MPC2 / LeWM **少至少一个数量级**。
- **解决什么问题 / 为什么重要**：命中 C 的**表征 / 机制 + 科学发现（优先类）**——它不是又一个"控制得好"的世界模型，而是把目标换成"忠实还原底层动力学"，从而让世界模型**可被用于系统辨识与科学发现**。这与你关注的"机制 / 现象分析、表征几何"同源：忠实的潜动力学是"从数据反推机制"的前提，本文还证明少一个数量级的参数即可做到，兼有 A 的"从观测学连续控制潜动力学"味道，是连接"可解释动力学建模"与"世界模型"的一篇。
- **核心方法**：① **无奖励**，仅从观测与动作学潜动力学（面向机制还原而非回报最大化）；② 目标是潜动力学在**长程预测**上忠实复现真系统，而非只服务控制；③ 以远少于主流世界模型的参数量实现，并在系统辨识基准上评估。
- **主要结果**：以像素输入控制连续环境达到 **SOTA**；在 **71 个吸引子**的基准上做准确的系统辨识；参数量比 DreamerV3 / TD-MPC2 / LeWM **少至少一个数量级**，展示世界模型可服务科学发现。
- **值得追问 / 局限**：① "忠实还原动力学"在 71 个吸引子这类**低维、确定性**系统上验证充分，但高维、随机、部分可观的真实环境里，长程忠实度与可辨识性是否仍成立需进一步看；② 摘要强调参数少、长程忠实，但"忠实还原"与"控制性能"二者的权衡（忠实是否总利于控制，还是某些任务下反而牺牲控制）尚未展开。

### 6. Reasoning or Pattern Exploitation? Mechanistic Insights from RL-Trained Language Models
- 链接：https://arxiv.org/abs/2610.39182
- 作者：Aishik Nagar, Cheston Tan（2 位；cs.AI，交叉 cs.CL）
- **TL;DR**：LLM 经可验证奖励的 RL 后常被说成"学会了推理"，但到底是真推理还是更肤浅的适应仍不清楚；本文在**有限且可穷举分析的逻辑域（井字棋）**上训练 LLM，用 **SAE 稀疏自编码器**追踪 GRPO 训练中内部表征的演化——定量上 RL 确实带来高准确与跨提示鲁棒（像"学会了"），机制上却发现模型主要是**更依赖提示里已显式的信息**（该谁走、进度、占位），而"棋盘对称性、战略分叉"等高层概念**仍弱表示**。
- **解决什么问题 / 为什么重要**：命中 C 的**训练动态 + 机制 / 现象分析（优先类）**，是一篇干净的可解释性实验而非 prompt 技巧——它用一个能穷举真值的玩具逻辑域，把"RL 到底改变了什么表征"落到 SAE 特征层面，给出反直觉且可操作的结论：RL 后训练**既不增也不删概念信息，只是重排哪些特征主导表征**，而决策被因果地定位在**晚层状态**的下游。对你做"表征几何 / 机制分析"，这提供了一套"训练过程中表征动力学"的可解释性流水线模板，也给"推理基准可能高估模型能力"一个机制证据。
- **核心方法**：① 在井字棋这一**有限可穷举**逻辑域训练小规模 LLM，用 **GRPO** 做 RL；② 用 **SAE** 提取特征、追踪 RL 训练中表征的演化，并把 SAE 特征发现扩展为**假设驱动的检验**；③ 用**因果干预**定位决策位置。
- **主要结果**：RL 带来高准确与跨提示变体鲁棒，但 SAE 显示模型主要**加重依赖提示中已显式的信息**，高层概念（对称性、分叉）仍弱表示；RL 后训练**不增删概念信息，只重排主导特征**，因果干预把决策定位在**晚层状态**下游——提示"推理"可能被混淆为"对输入信息的任务特定适应"，基准或高估模型能力。
- **值得追问 / 局限**：① 结论基于**井字棋这一极小、完全可观的逻辑域 + 小规模 LLM**，对大模型、开放式多步推理是否同样"只重排不新增概念"，外推性存疑；② "高层概念弱表示"由当前 SAE 特征集判定，可能受字典容量/稀疏度与特征可识别性影响——弱表示到底是"模型没学到"还是"SAE 没抓到"，需要更强的探针交叉验证。
