## 1. Topological Neural Dynamics: A Neuron-wise Framework for Sequence Modeling
- 链接：https://arxiv.org/abs/2606.21295
- 作者：Borui Cai, Yao Zhao
- 方向：A（图耦合动力系统 / 时序建模的内生结构）
- **TL;DR**：把序列模型从"逐层共享算子"改成"逐神经元在有向图上各自演化"，每个神经元有独立的局部动力学，整体计算由显式图拓扑上的相互作用涌现。
- **解决什么 / 为什么重要**：RNN/LSTM/连续时间网络/Transformer 都共用一个结构原则——同层神经元被同一参数化算子裹挟着一起演化，单个神经元没有独立演化的自由度。但很多复杂动力系统的全局行为恰恰来自局部单元通过结构化连接的相互作用。这把"动态图 + 连续/离散动力系统"的思路下沉到神经元粒度，正对我关注的时序图 / 内生结构方向。
- **核心方法**：TND 把神经系统表示为〈有向神经元图 + 交互算子 + 局部动力学函数〉三元组；实例化为离散时间的图耦合动力系统，每个神经元独立演化、经图拓扑交互形成集体计算。
- **主要结果**：在单人 Pong 的行为克隆任务上，对比 Vanilla/Sparse RNN、LSTM、闭式连续时间网络（CfC）、Transformer，TND 取得最佳接球率，平均每轮连续接球 17.47 次，超过最强基线 3 倍。
- **追问 / 局限**：(1) 目前只在单一玩具任务（Pong 行为克隆）验证，规模化到真实长序列 / 大图的可扩展性与训练成本未知；(2) 神经元图拓扑如何获得、是否可学，决定了这套归纳偏置能否迁移。

## 2. Continuous-Time Probabilistic Correctors for Uncertainty-Aware Physics-Based Spacecraft Trajectory Forecasting
- 链接：https://arxiv.org/abs/2606.21021
- 作者：Muhammad Bilal Shahid, Zhanhong Jiang, Soumik Sarkar, Cody Fleming
- 方向：A（Latent NCDE / 连续时间 + 不规则采样 + 不确定性）
- **TL;DR**：用 Latent Neural Controlled Differential Equations 给确定性物理预报器套一个连续时间"概率校正器"，在连续时间里建模预报误差的演化，输出锐利且校准的全协方差不确定性。
- **解决什么 / 为什么重要**：长时程预报因缺乏校正观测而误差累积，高保真物理传播器准但没有校准的不确定性。把 Latent NCDE 当作"误差动力学"的连续时间概率模型，可即插即用地包裹现有传播器——这正是我关心的连续时间 + 不规则采样 + 标定不确定性的组合，方法本身可迁移到监控/不规则时序场景（不限于航天）。
- **核心方法**：Predictor–Corrector 框架，物理确定性预报器 + 学习型连续时间概率校正器（Latent NCDE），天然支持不规则采样与缺失特征；并设计了促进长时程不确定性"校准 + 锐利"的损失。
- **主要结果**：在 NASA CDDIS 真实数据 + GMAT 传播器上，2–4 天无观测、6 个滚动测试窗内，相比确定性基线与 Latent ODE 校正器一致提升精度与不确定性校准。
- **追问 / 局限**：(1) 校正器质量依赖底层确定性预报器，预报器系统性偏差较大时校正能否兜住？(2) 与纯数据驱动连续时间模型相比，"物理 + 校正"分解带来的样本效率收益有多大。

## 3. A Topology-Aware, Memory-Centric Architecture that Separates Root-Cause Derivation from Root-Cause Explanation
- 链接：https://arxiv.org/abs/2606.20758
- 作者：Momil Seedat
- 方向：B（根因分析 / AIOps）× C（操作记忆）
- **TL;DR**：微服务根因系统（OpsCortex）把"推导根因"和"解释根因"显式拆开——根因由学习到的依赖图 + 阈值越界的时间先后确定性地算出，LLM 只负责解释、确认与给建议。
- **解决什么 / 为什么重要**：故障沿服务依赖传播时告警刷屏，工程师被迫重建监控栈丢弃的上下文。作者主张缺的不是更强的异常检测器或更大的模型，而是"操作记忆"：系统正常如何运行、各部件如何依赖、历史如何故障的持久结构化表示。这把图定位 + 时序因果 + 记忆 + LLM 解释拆得很清楚，正对我监控告警 + 内生结构的取向。
- **核心方法**：多智能体原型，记忆分四层；根因从学习到的依赖图与阈值越界的时间排序确定性计算，再让 LLM 仅基于系统已组装好的证据做解释/确认/推荐，避免把推导与解释混为一谈。
- **主要结果**：以两起真实级联故障为动机驱动设计，每个架构选择对应一类故障模式；在插桩的电商基准（8 个可注入故障场景）上完成验证。
- **追问 / 局限**：(1) 偏架构/原型论文，定量对比与可复现规模有限，缺与现有图定位基线的硬指标对照；(2) "确定性根因 = 依赖图 + 越界时序"在并发故障 / 部分可观测 / 图本身有误时的鲁棒性存疑。

## 4. B[FM]²: Brain Foundation Model via Flow Matching with SplitUNet
- 链接：https://arxiv.org/abs/2606.20812
- 作者：Jaedong Hwang, Kathleen Zhang, Wei Dai, Konstantinos Kontras, Maarten Vanmarcke, Maarten De Vos（等 8 人）
- 方向：B（脑功能时序 / 脑电）× A（连续时间生成 / 自监督内生偏置）
- **TL;DR**：不做 patch/tokenization/masking，直接在原始多通道 EEG 波形上用连续时间 Flow Matching 预训练脑基础模型，让归纳偏置与"连续脑节律"对齐。
- **解决什么 / 为什么重要**：现有 EEG 基础模型把连续波形离散成 patch/codebook token，碎掉了连续脑节律、糊掉了细粒度时间动态。直接在连续时间上建模是更贴近数据的做法。虽然是 EEG 而非 fNIRS，但"连续时间 + 多通道脑信号 + 自监督 + 保留电极拓扑"这套思路可直接迁移到我做的 fNIRS / 脑网络分析。
- **核心方法**：连续时间 Flow Matching 直接在原始信号上预训练；针对"时间密集自相关、电极轴短"的非对称，提出 SplitUNet 速度网络——把每个块分解为 1D 时间卷积 + 1D 电极卷积、只沿时间下采样，全程保留电极拓扑。
- **主要结果**：9 个标准下游 EEG 分类任务中 7 个达 SOTA，且预训练预算仅约 36,895 段（≈307 小时），比现有 EEG 基础模型少 1–2 个数量级（≈30×）；生成的合成 EEG 两位执业神经科医生无法与真实脑信号区分（Cohen's κ=-0.096）。
- **追问 / 局限**：(1) fNIRS 通道更少、时间更慢、血氧动力学不同，SplitUNet 的"时间-电极非对称"假设是否还成立？(2) Flow Matching 学到的连续表征对下游解释性（脑区/网络层面洞察）能提供多少。

## 5. Towards Anomaly Detection on Relational Data
- 链接：https://arxiv.org/abs/2606.18621
- 作者：Shiyuan Li, Yunfeng Zhao, Yue Tan, Qingfeng Chen, Yixin Liu, Shirui Pan
- 方向：B（异常检测）× A（多关系图 / 结构化数据）
- **TL;DR**：面向关系数据库的异常检测框架 RelAD，从"属性重构 + 多关系边重构"双视角抓异常，既看属性反常也看跨外键关系的反常连接模式。
- **解决什么 / 为什么重要**：关系数据异常（欺诈、风险、异常行为）很重要却被低估；多表属性高维异质、稀疏异常易被淹没，且异常常表现为跨外键关系的反常连接——这是现有表格/图异常方法都不擅长的。把"多关系图结构 + 异常检测"拼在一起，正落在我图 × 监控的交叉点。
- **核心方法**：重构式框架，两个核心模块——条件稀疏门控属性重构（抑制冗余多表属性、突出异常语义块）+ 双视角多关系边重构（从内在与行为画像检测关系特异的异常连接）；再用轻量融合得到最终异常分。
- **主要结果**：自建 6 个带系统化注入异常的基准上，RelAD 一致超过基线，同时保持有竞争力的效率。
- **追问 / 局限**：(1) 异常由"系统化注入"生成，与真实欺诈/故障分布的差距有多大？(2) 双重构对异常类型的覆盖（点异常 vs 关系异常 vs 群组异常）是否均衡。

## 6. AtomMem: Building Simple and Effective Memory System for LLM Agents via Atomic Facts
- 链接：https://arxiv.org/abs/2606.19847
- 作者：Yanyu Yao, Shangze Li, Zhi Zheng, Hui Zheng, Qi Liu, Tong Xu（等 7 人）
- 方向：C（agent —— 记忆机制，"优先"类）
- **TL;DR**：面向 LLM agent 的长期记忆系统，以"原子事实"为价值密集的记忆单元，组织成层级事件结构 + 时间画像，检索时再用联想记忆图把碎片连起来。
- **解决什么 / 为什么重要**：固定上下文窗限制了跨会话的长期信息积累与复用；现有记忆系统要么表示粗糙低效，要么更新无约束、不稳定。AtomMem 把"提取什么、怎么稳定演化、怎么检索"拆清楚，是 agent 方向我看重的"记忆机制"而非 prompt 技巧。
- **核心方法**：Fact Executor 从长交互中选择性抽取高价值原子事实作记忆表示；把事实组织成层级事件结构与时间画像，捕捉情节上下文并跟踪用户属性随时间演化；检索时激活联想记忆图连接碎片记忆。
- **主要结果**：在 LoCoMo 基准上多类推理任务取得 SOTA，作者主张其在存储密度与经济性上更适合个性化 agent 部署。
- **追问 / 局限**：(1) "原子事实"抽取与冲突/过期事实的更新策略在长程下是否真稳定、会不会累计漂移？(2) 仅在 LoCoMo 单一对话记忆基准上验证，迁移到工具调用 / 任务型 agent 的程序性记忆尚待检验。
