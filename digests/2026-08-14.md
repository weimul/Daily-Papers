## 1. JAPE: Joint Anomaly Prediction and Intrinsic Explanation in Multivariate Time Series
- **链接**：https://arxiv.org/abs/2608.11801 （arXiv:2608.11801，2026-08-12）
- **作者**：Yian Wei, Yuanyuan Yao, Lu Chen, Xiangmin Zhou, Tianyi Li
- **TL;DR**：把多变量时序异常「预测」从建模未来数值偏差，升级为建模演化中的依赖结构，并直接复用预测出的依赖图给出变量级内生解释。
- **解决什么问题 / 为什么重要**：现有异常预测把异常刻画为未来数值的偏离，容易漏掉弱前兆引起的细微依赖变化，且报警时不带原生的变量级解释。这正好落在你关注的「时序异常 + 内生/自解释」交叉点，是把 spatio-temporal 结构证据用于早期预警的一次尝试。
- **核心方法**：(1) Decoupled Spatio-Temporal Representation (DSTR) 主干，时间与空间建模解耦，用可学习的滞后聚合捕捉 lag-aware 依赖，从而在数值偏差出现前感知结构性前兆；(2) 双视角报警机制，把数值预测与演化依赖图融合做逐点异常预测；(3) Native Predictive Explanation (NPE)，直接复用预测的依赖图按结构偏差对变量排序，无需额外模型或训练（真·内生解释）。
- **主要结果**：五个真实基准、三个预测视野上，平均 F1 / AUC-PR 分别提升 19.7% / 41.3%；可解释性指标 MRR 提升 26.6%。
- **值得追问 / 潜在局限**：(1) 「结构前兆先于数值偏差」的说法需要看在不同异常类型上是否稳健，还是主要吃了某几类依赖突变；(2) NPE 的解释忠实性只用 MRR 衡量，缺少与真实根因标注或扰动式验证的对照。

## 2. FedDOSE: Federated Learning Framework Decomposing Site Effects for Modeling Brain Dynamic Functional Connectivity
- **链接**：https://arxiv.org/abs/2608.07393 （arXiv:2608.07393，2026-08-07，近日更新出现在 recent 列表）
- **作者**：Deepank Girish, Yi Hao Chan, Yubin Zheng, Sukrit Gupta, Jagath C. Rajapakse
- **TL;DR**：面向多站点 fMRI 的联邦学习框架，显式分解站点效应并建模动态功能连接（dFC），兼顾隐私、异质性与时空动态。
- **解决什么问题 / 为什么重要**：多站点脑影像联邦学习普遍受统计异质性（站点差异）拖累，且多数方法只用静态 FC、丢掉了脑网络的动态信息。对你的脑功能/脑网络方向，这篇同时踩中「动态连接 + 时空建模 + 原型对齐」三点。
- **核心方法**：引入 Modularity-Guided Tucker Decomposition 块，把高维 dFC 张量编码为模块级时空模式；各站点生成类别原型，再用最优传输（OT）重心 + Procrustes 分析在全局对齐，从而把站点差异从判别信息中剥离。
- **主要结果**：在 ABIDE-I、ABIDE-II、ADHD-200 三个多站点静息态 fMRI 数据集上诊断 ASD 与 ADHD，均优于 SOTA。
- **值得追问 / 潜在局限**：(1) dFC 的时间窗划分与 Tucker 秩的选择对结果敏感度未知；(2) 原型 + OT 对齐在站点数更多、样本更不平衡时能否扩展，值得看通信/计算开销。

## 3. Faithful, Sufficient and Understandable: Rethinking Graph Counterfactual Explanations via Discrete Diffusion Inversion
- **链接**：https://arxiv.org/abs/2608.12083 （arXiv:2608.12083，2026-08-12）
- **作者**：David Bechtoldt, Sidney Bender
- **TL;DR**：用离散去噪扩散 + 新的离散反演（inversion）方案生成图反事实解释，既贴合数据流形又能覆盖完整编辑空间。
- **解决什么问题 / 为什么重要**：GNN 预测缺乏内生解释，反事实解释给出「改动哪些最小结构会翻转预测」。但图上编辑空间离散且组合爆炸，还要满足节点/边类型、化学价键等域约束；现有方法要么编辑脱离流形，要么搜索不完整。对你「图 + 自解释/可解释」的横切重点是一篇偏方法的新工作（虽属反事实解释，但通过生成式建模显著更新了做法）。
- **核心方法**：Graph Diffusion Counterfactual Explanation via Inversion (GDCE-I)——离散去噪扩散模型配合新颖的离散反演，实现分布感知（distribution-aware）的编辑，利用整个域编辑空间；同时提出一套解释「期望属性（desiderata）」框架，把所有方法放在统一协议下评测。
- **主要结果**：四个基准上按该框架大幅超越相关工作；分子域定性展示能得到可解释、且在分布内（in-distribution）的解。
- **值得追问 / 潜在局限**：(1) 扩散反演的计算成本与单纯搜索式解释相比是否划算；(2) 「期望属性框架」由作者自定，需警惕评测标准与方法互相塑造带来的偏向。

## 4. Beyond Local Power: Functional Connectivity Analysis for Subject-Independent Learning Style Recognition
- **链接**：https://arxiv.org/abs/2608.12000 （arXiv:2608.12000，2026-08-12）
- **作者**：Wiga Maulana Baihaqi, Indriana Hidayah, Sri Kusrohmaniah, Noor Akhmad Setiawan
- **TL;DR**：用 EEG 的相位锁值（PLV）连接特征而非局部功率，做跨被试的学习风格识别，并揭示个体连接签名与群体边界系统性反相的现象。
- **解决什么问题 / 为什么重要**：学习风格识别传统靠问卷或长期行为日志；本文尝试用客观 EEG 脑网络特征、并强调「连接」优于「局部功率」。对你脑网络方向，价值更多在方法学教训——跨被试泛化的天花板与个体差异。
- **核心方法**：28 名被试在 Raven 高级推理矩阵任务下记录 EEG；在 Felder-Silverman 的 Active-Reflective（AR）与 Verbal-Visual（VV）两维上，比较 PLV 连接特征与局部化特征；SVM 分类，用留一被试交叉验证（LOSO-CV）与 70:30 组内划分。
- **主要结果**：VV 维靠额-枕极化达到 70.00% 被试级准确率；AR 维仅 55.56%，因执行网络重叠及「系统性神经反相」现象——稳定的个体连接签名相对全局边界恰好反向（投票裕度高达 20-0）。
- **值得追问 / 潜在局限**：(1) 28 人样本偏小，PLV 在体积传导/参考电极下的伪相关需谨慎；(2) 「一刀切分类器被生物多样性限制」的结论指向自适应特征变换，但本文尚未给出可行方案。

## 5. Orientation, not magnitude: the causal structure of task-vector interference in merged language models
- **链接**：https://arxiv.org/abs/2608.11797 （arXiv:2608.11797，2026-08-12）
- **作者**：Chencheng Zhu
- **TL;DR**：对 task arithmetic 模型合并中的干扰做因果剖析，发现真正「载荷」的是被前向传播放大的交叉项方向，而非幅值——一个可预注册、可证伪的机制研究。
- **解决什么问题 / 为什么重要**：模型合并常在某处失效，主流诊断都归因于幅值（层间表征偏置、跨任务线性偏离、参数重叠）。本文用逐层交叉项的精确分解与直接干预，论证幅值不足以做诊断轴。属你重点关注的「表征几何 / 机制与现象分析 / residual stream 结构」类。
- **核心方法**：用「因子账本（factorial ledger）」精确追踪合并 LLM 的逐层交叉项并对其直接干预；对层间通量做精确分解，识别放大式传输主导（两个模型族中约占 65-70%，后段每块增益 >1）；用六个起始位移的 basin 测试确立被携带方向是前向传播的吸引子；再用范数匹配的「错误方向」对照验证因果性。所有 46 条预测在见数据前预注册冻结。
- **主要结果**：沿该方向擦除会剂量依赖地消除干扰并在精确擦除处饱和，而错误方向对照失败或反噬；指令包装（wrapper）会通过模板固定的主效应「淹没」交互，使同样擦除少去除 13× 相对干扰；局部交叉项生成仅差 ≤1.9× 的任务对，其可因果移除的干扰却相差 14×–337×；所谓 bfloat16 生成的「±15% 普适性」实为量化粗糙度。
- **值得追问 / 潜在局限**：(1) 结论目前限于两个模型族与 task arithmetic 设定，能否推广到更多合并算法待验；(2) 预注册 + 报告自我证伪的做法很扎实，但行为层恢复的连续端点结论偏保守，实用增益有多大仍需下游任务佐证。

## 6. Massive Activations in Hybrid Linear Attention Large Language Models: Pre-Attention Spikes and Inter-Spike Plateaus
- **链接**：https://arxiv.org/abs/2608.12149 （arXiv:2608.12149，2026-08-12）
- **作者**：Zunhai Su, Bohan Sun, Xialie Zhuang, Shuibai Zhang, He Xiao, Jing Xiong, Hengyuan Zhang, Zhongzhu Zhou, Tiantian Zhang, Ngai Wong, Chuan-Wei Kuo
- **TL;DR**：首次系统研究层间交错的混合线性注意力（HLA）LLM 中的「巨激活（massive activations）」，发现与架构对齐的两种形态并给出「write-sink-cancel」生命周期解释。
- **解决什么问题 / 为什么重要**：巨激活是理解 LLM 内部机制、也直接影响量化/推理的关键现象。混合（线性 + 全）注意力架构日益普及，其巨激活行为此前无人系统刻画。属你偏好的「机制/现象分析、technical report」类。
- **核心方法**：在多种混合模型配置、规模与数据域上做受控实验与机制分析，识别两种形态——巨激活在全注意力层前一致地尖峰（pre-attention spikes, PAS），并可穿过中间线性注意力层持续存在（inter-spike plateaus, ISP）；进一步用「write-sink-cancel」时序动态解释其产生-维持-消除的生命周期。代码已开源。
- **主要结果**：PAS/ISP 两种形态在不同配置、规模、数据域上一致复现，并被受控实验归因于由时序动态支配的「写入-汇聚-抵消」机制。
- **值得追问 / 潜在局限**：(1) 结论对具体混合层排布（线性/全注意力比例与顺序）的依赖程度需要更多消融；(2) 对下游量化/低比特推理的实际收益，摘要未量化，需看正文实验。
