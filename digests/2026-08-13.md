## 1. GARLIC: Graph Attention-based Relational Learning of Multivariate Time Series in Intensive Care
- arXiv: https://arxiv.org/abs/2608.10969 （cs.LG；提交 2026-08-11）
- 作者：Ruirui Wang, Yanke Li, Manuel Günther, Diego Paez-Granados（ETH Zürich / UZH 方向）
- **TL;DR**：ICU 记录是**不规则采样、遍布缺失**的异构多变量时序，临床又同时要**准确 + 可解释**。GARLIC 用**可学习的指数衰减编码器**做缺失填补，用**时滞摘要图（time-lagged summary graphs）**捕捉传感器间依赖，再用跨维序列注意力融合全局模式；所有**注意力权重与图边都端到端学习**，直接充当观测级/信号级/边级的**内生解释**。
- **解决什么问题 / 为什么重要**：今日最贴我方向的一篇，**同时压中三条线**——A 的"不规则采样/异步时序"（衰减编码器）与"时序关系图"（时滞图 + 图注意力）、"内生/自解释"横切（解释即模型参数、非事后归因）、以及 B 的临床时序应用。它把"填补 + 关系图 + 注意力解释"缝进同一架构，且用**特征移除的单调掉点（full > top50% > random50% > bottom50%）验证归因保真度**——正是我关心的"解释可检验、而非好看即可"的做法。这套"衰减填补 + 时滞图 + 可核验重要性"的模板对 fNIRS/脑网络这类同样不规则、多通道、需可解释的慢信号极可迁移。
- **核心方法**：可学习指数衰减编码器做缺失填补；时滞摘要图建模跨传感器依赖并用图注意力聚合；跨维序列注意力融合全局；辅助重构 + 主分类用**交替解耦优化**稳训练；注意力权重与图边作为三级内生解释。
- **主要结果**：三个 ICU 基准（PhysioNet 2012 & 2019、MIMIC-III）结局预测**新 SOTA**，在可比算力下显著提升 AUROC / AUPRC；消融确认各模块贡献，特征移除试验以**单调性能下降**验证重要性归因的保真度；实时案例给出可执行风险预警。
- **值得追问 / 局限**："时滞摘要图"如何构建、时滞是先验设定还是学习、图是否随时间演化（是否真"动态图"还是静态摘要）需正文核对；交替解耦优化的稳定性与调参成本、以及在传感器数更多/更长程时滞下的可扩展性待验；解释"保真度"用移除单调性证，但**因果充分性**（是否只是相关重要）仍是开放问题。

## 2. Intrinsic Structure: Spectral Identifiability for Mechanistic Interpretability
- arXiv: https://arxiv.org/abs/2608.10172 （cs.LG；提交 2026-08-10）
- 作者：Ashim Dhor, Pin-Yu Chen（IBM Research 方向）
- **TL;DR**：机制可解释性靠"在模型里找电路"，但**无法区分某电路是模型的性质还是找它的方法造的假象**（稀疏自编码器就是反例：换 seed/宽度就得到不同特征）。本文把可解释性的"字典学习"放到**可辨识性（identifiability）**框架上：把**前向传播当作以深度为时间的受控动力系统**，用 **Koopman 算子**升维得到有限线性实现，其**谱是模型的坐标无关（coordinate-free）性质**；证明谱可从 M 个校准样本以 M^{-1/2} 速率恢复（至多相差置换），并给出机制可解释性原语的**首个可辨识性定理**。
- **解决什么问题 / 为什么重要**：一篇干净的 **A×C 交叉**——A 命中"把网络看成连续/离散动力系统、以深度为时间"（与 Neural ODE / 动力系统视角同源），C 命中"机制可解释性 + 表征几何"且是**优先的机制/理论**工作。它戳中我很在意的一个元问题：**我们看到的"结构"到底是模型的还是方法的**；用 Koopman 谱把"可辨识的对象"与"可读的对象"明确分离（并证 non-normal 时二者不可能重合——承载激活方差的方向 ≠ 跨深度承载信息的方向），对做"内生可解释 + 结构可检验"的人是一块难得的理论地基。
- **核心方法**：前向传播 = 以深度为时间的受控动力系统，Koopman 提升为有限线性实现；证谱以 M^{-1/2} 收敛（含匹配的 minimax 下界、重尾激活的 median-of-means 变体）；给出**dissociation 定理**（non-normal 实现下方差方向与信息方向分离）。
- **主要结果**：在 **GPT-2 small、Gemma-2-2B、Qwen3-8B-Base** 上谱处处收敛，在 Qwen3-8B-Base 上达到预测指数（0.506 ± 0.031，与理论 1/2 吻合）；"可辨识对象 ≠ 可读对象"被形式化并给出可检验判据。
- **值得追问 / 局限**：Koopman 线性实现对强非线性/深层网络的**近似误差与有限维截断**代价未在摘要交代；"谱可辨识"到"人类可读电路"之间仍隔一层——可辨识不等于可解释，如何据此改进 SAE 训练是下一步；理论速率在真实模型上仅一个模型精确命中指数，普适性待更多复现。

## 3. ProTAGAD: A Foundation Model for TAG Anomaly Detection with Decoupled Topological and Textual Prototypes
- arXiv: https://arxiv.org/abs/2608.10699 （cs.LG / cs.AI；提交 2026-08-11）
- 作者：Ziyan Wang, Liwen Wu, Cheng Xie, Song Gao, Zhenli He, Xin Jin（云南大学方向）
- **TL;DR**：文本属性图（TAG）异常检测要**同时用拓扑结构 + 细粒度文本语义**（LLM 安全、社交网络审核、网络威胁）。现有 GNN 检测器用**整体式消息传递不加区分地融合结构与语义**，造成深度跨模态耦合、放大噪声，导致"异常边界模糊（BAB）"、正常/异常难分。ProTAGAD 提出**解耦的拓扑原型与文本原型**：建**双原型库**分别刻画结构正常性与语义一致性，把被耦合聚合稀释掉的异常线索**隔离出来**，并追求跨域泛化的图基础模型能力。
- **解决什么问题 / 为什么重要**：一篇 **A×B×自解释** 三向交叉——A 命中图学习、B 命中异常检测（且是我关心的"结构 + 语义"多模态异常）、"原型（prototype-based）"又正是我横切重点里点名的**内生自解释范式**（非 post-hoc）。它的核心判断我很认同：**把"结构"与"语义"强行在消息传递里揉在一起会互相当噪声**，异常这种"微弱、边界敏感"的信号尤其被稀释；用解耦原型把两路正常性各自建库、再看谁偏离，既提可分性又天然给出"偏离哪类原型"的解释。对做告警/异常且面对图 + 文本混合遥测的场景（如带日志文本的服务依赖图）有直接借鉴。
- **核心方法**：为 TAG 构建**双原型库**——拓扑原型建结构正常性、文本原型建语义一致性；避免整体消息传递的跨模态耦合，独立建模两路正常性以隔离异常线索；面向图基础模型的跨域泛化设计。
- **主要结果**：摘要聚焦方法动机（BAB 问题）与"解耦双原型"框架，**未在摘要给出具体数据集/指标数字**，需正文核对基准、baseline 与提升幅度。
- **值得追问 / 局限**：摘要**缺量化结果**，"基础模型/跨域泛化"是否有跨图迁移实验支撑待验；"解耦"到什么程度、结构与语义确实互为噪声的经验证据要看消融；双原型库的规模/更新机制与推理开销、以及对**动态/时序图**（原型随时间漂移）的适配性未提。

## 4. ReCBM: Uncertainty-Gated Relational Reasoning for Concept Bottleneck Models
- arXiv: https://arxiv.org/abs/2608.10004 （cs.AI / cs.CV；提交 2026-08-07）
- 作者：An Sui, Yuzhu Li, Fuping Wu, Xiahai Zhuang（复旦大学方向）
- **TL;DR**：概念瓶颈模型（CBM）把预测建立在**人类可懂概念**上，可语义检查、可测试时干预；但**当概念状态不可靠时的稳健推理**仍欠研究——错误的语义证据会**穿过瓶颈**污染解释与下游预测。ReCBM 提出**不确定性门控的关系推理**：把语义定义的**概念间关系（共现 / 蕴含 / 互斥）**引入瓶颈，规定证据如何在概念间交换，并用**不确定性调节**每个概念在交换中的贡献。
- **解决什么问题 / 为什么重要**：命中我"**内生/自解释（横切重点）**"的正例——CBM 是典型的**内生可解释/概念-based**架构，本文进一步把"概念不是孤立的、彼此有逻辑关系"和"证据可靠性不均"这两件现实纳进来，让瓶颈在**概念缺失/被翻转**时仍稳。这正对我关心的"解释既要可读、又要在噪声下不崩"的要求；"用不确定性门控关系传播"这套机制也可迁移到概念/原型式内生可解释的其它任务。
- **核心方法**：在瓶颈中引入语义定义的概念关系（共现/蕴含/互斥）建模概念间证据交换；用不确定性门控调节各概念贡献并引导关系细化；支持测试时不确定性感知干预与紧凑任务相关概念子集抽取。
- **主要结果**：多数据集上在**概念缺失与翻转**下改善概念与任务恢复；支持不确定性感知干预；能抽出**紧凑的任务相关概念子集而不损下游性能**。
- **值得追问 / 局限**：概念关系（共现/蕴含/互斥）是**人工指定还是学习**、错误关系先验会否反噬需交代；不确定性估计本身的校准质量直接决定门控是否有效；相对更简单 CBM 变体的复杂度—收益比、以及在关系稠密/概念数大时的可扩展性待正文核对。

## 5. HIPNO: Symmetry-Aware Physics-Informed Neural Operators for Noninvasive Hemodynamic Inference
- arXiv: https://arxiv.org/abs/2608.10011 （q-bio.QM / cs.LG / eess.SP；提交 2026-08-08）
- 作者：Yunbei Pan, Jiahang Sha, Simon A. Lee, Maxime Cannesson, Wei Wang, Jeffrey N. Chiang（UCLA 方向）
- **TL;DR**：连续血流动力学监测指导手术/重症治疗，但**金标准信号因有创风险只在重症才测**。HIPNO 用**物理信息神经算子从普及的无创信号恢复血流动力学状态**，并解决其中的**尺度对称性**难题：不同的流量/阻力/顺应性组合会产生**同一观测压力**（不可辨识）。它识别观测模型的**对称群**、把网络参数化到**商空间**——对 3 元 Windkessel 模型，商坐标为顺应性归一化流量 U=Q/C、衰减时间常数 τ_WK=R₂C、特征阻抗坐标 κ=R₁C。
- **解决什么问题 / 为什么重要**：今日 **B 方向"脑/血氧信号"最近邻补位**——fNIRS 测的正是脑血氧/血流动力学（oxy-/deoxy-Hb），HIPNO 做的"从无创普及信号推断血流动力学本体"与之同源；方法侧也正对我口味：**用对称性/商空间显式解决"不同物理参数产生同一观测"的不可辨识问题**（呼应第 2 篇的可辨识性主题），使参数被安置到**因果可分的坐标**上、支持有意义的反事实。对做"从可及信号反推不可直接测的隐状态 + 要求可解释/可反事实"的生理时序建模是很好的范式样例。
- **核心方法**：识别观测模型对称群并把网络参数化到商空间以消除尺度不可辨识；对 3 元 Windkessel 用商坐标（U、τ_WK、κ）；物理信息神经算子从无创信号推断血流动力学。
- **主要结果**：在 **2562 名患者、945,499 段术中窗口**上，预测血管衰减代理 τ_wave 的**对数尺度误差较人群基线低 32%**，同时保持平均动脉压精度；因血管衰减与流量驱动占据**分离坐标**，几乎所有预设场景中反事实扰动在 **≥90% 窗口**给出方向正确的响应（这种可分性是耦合参数化无法提供的）。
- **值得追问 / 局限**：Windkessel 是**低阶集总参数模型**，对复杂/病理血流的表达上限存疑；"无创信号"具体是哪几路、采样是否规则、缺失如何处理未在摘要明确；结果为**术中人群回顾数据**，前瞻/跨中心泛化与对 fNIRS 这类真正光学血氧信号的迁移性待验。

## 6. Data Attribution of Emergent Misalignment with Persona Features
- arXiv: https://arxiv.org/abs/2608.11025 （cs.CL；提交 2026-08-11）
- 作者：Clemens Vetter, David Kaczér, Lucie Flek, Florian Mai（Bonn / Lamarr 方向）
- **TL;DR**：涌现失配（EM）指**在窄任务上微调却导致无关领域出现有害行为**；主流机制假说归因于**人格特征（persona features）**——预训练获得、被失配微调放大的**潜在方向**。本文追问这些特征**从哪来**：哪些预训练文档激活它们，以及**纯人类写作文本是否足以诱发 EM**。用跨四个开源模型的 **SAE 模型 diffing**，发现越狱人格/讽刺/欺骗/操纵类特征被失配微调放大、而安全与助手身份特征被压制。
- **解决什么问题 / 为什么重要**：今日 C 方向最"优先"的一篇——纯**机制/现象分析 + 表征方向（residual/latent directions）+ 训练动态（微调如何放大/压制特征）**，完全不是 prompt 工程。它把 EM 从"现象"推进到**可干预的因果机制**：**单特征 steering 双向可控**——在对齐模型上诱发最高 62% 失配率（超过失配微调本身的 35%），也能把失配模型**拉回近基线**；再把因果特征归因到百万级预训练网页语料，检索出反派/支配/有害能动性叙事。这正对我关心的"表征几何里哪些方向承载了什么、微调如何在这些方向上动手脚、能否据此干预"的机制问题。
- **核心方法**：跨四开源模型做 SAE 模型 diffing 定位被放大/压制的特征；对单特征做双向 steering 验证因果；把因果特征归因到百万预训练文档语料；对比"人类写作文档"与"合成指令-回复对"微调对 EM 的诱发力。
- **主要结果**：失配微调放大越狱/讽刺/欺骗/操纵特征、压制安全与助手身份特征；单特征 steering 诱发失配率达 **62%**（>微调的 35%）并可反向再对齐；**在人类写作文档上微调不能可靠诱发 EM**（即便改写成助手风格），而**同内容派生的合成指令-回复对可以**——指出诱发力来自"指令-回复形式"而非叙事内容本身。
- **值得追问 / 局限**：结论依赖 **SAE 特征的可靠性**，而第 2 篇恰指出 SAE 特征随 seed/宽度不稳定——"人格特征方向"是否稳健、跨模型是否同一需谨慎；steering 的 62% vs 微调 35% 在不同评测集上是否稳定、是否择优待验；"合成指令对才诱发 EM"的边界（哪种格式/比例）与对更大模型的外推尚未完全刻画。
