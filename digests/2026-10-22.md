## A. 核心方法（动态图局部社区追踪的增量 RL / 潜空间瓶颈+原型做缺模态鲁棒，取 2 篇；今日 A 偏薄）

### 1. DISRL: Dual-Scale Incremental Semi-Supervised Reinforcement Learning for Dynamic Community Tracking
- 链接：https://arxiv.org/abs/2610.29315
- 作者：Tianming Zhang, Jinxu Wang, Yixuan Zhang, Zhengyi Yang, Chenyu Hou（7 位；cs.LG）
- **TL;DR**：动态局部社区检测要在一串图快照上追踪给定种子节点所属社区的演化，但面临两难——拓扑变化下稀疏/过时标签给不出种子专属监督（时序监督不确定性），以及顺序策略迁移沿长时间轴累积探索误差（无界误差级联）；DISRL 用"动态生成种子专属监督 + 短期窗内适应与长期跨窗参数固化解耦"的双尺度增量半监督 RL 同时缓解这两点。
- **解决什么问题 / 为什么重要**：命中 A 的**动态图 / 时序演化图学习**。它把"随时间演化的图上做 seed-anchored 社区追踪"显式建成一个 RL 序列决策问题，并直指动态图序列学习里两个通用痛点——监督随时间失效、误差沿快照累积——这两点对任何在动态图/事件流上做顺序预测的人都有迁移价值。
- **核心方法**：① **监督构造模块**：从稀疏的已知社区里动态生成种子专属引导信号，缓解标签稀疏/过时；② **双尺度社区探索模块**：把时序窗口内的短期适应与跨窗口的长期参数固化解耦，稳定策略演化、抑制长时程误差级联；③ 构建了一个含多样社区演化场景的动态图基准用于评测。
- **主要结果**：在多种动态设定下，DISRL 一致优于 SOTA 基线。
- **值得追问 / 局限**：① 摘要只给了"一致优于基线"的定性结论，缺具体指标幅度与基线构成，真实增益与可复现性要看正文/所建基准；② "双尺度解耦"引入的窗口粒度、固化频率等超参对不同演化速率的敏感性，以及在突变式（而非渐变）社区演化上是否仍稳，值得压测。

### 2. MERP: A Latent-Bottleneck Framework for Robust Multi-Modal Multi-Label Emotion Recognition
- 链接：https://arxiv.org/abs/2610.29430
- 作者：Chuangxin Zhao, Meimei Zhang, Canran Xiao, Jiachen Luo, Jiajun He（9 位；cs.AI）
- **TL;DR**：多模态多标签情感识别在文本/视觉/声学全模态下训练，但部署时某些流缺失就急剧退化；MERP 把联合序列映射进一个**定长潜向量库（latent bank）**，让重复推理与原始输入长度解耦，并在潜推理前后各抽一次标签专属证据、用重建对齐两级，再配正/负类**原型**、噪声门控特征增强与置信度感知的类级融合，从而在不需要"缺模态训练样本"的前提下对任意可用模态子集都保留情感证据。
- **解决什么问题 / 为什么重要**：命中 A 的**信息瓶颈 / prototype-based（内生约简横切重点）**——"定长潜库"本质是一个容量受限的瓶颈表征，迫使模型压出与情感相关的紧致证据，这与你关注的"用瓶颈/原型做内生约简与可解释"一脉相承；同时它给出一个很实用的卖点：**不靠见过缺模态样本，也能对测试期模态缺失鲁棒**，这对任何多模态生理/行为信号系统都有借鉴。注意本质仍偏应用（情感识别），放在 A 是取其方法视角。
- **核心方法**：① **Perceiver 式定长潜库**：把变长多模态联合序列压进固定大小的潜表征，使反复的跨模态推理独立于输入长度；② 潜推理**前后各抽标签专属证据并用重建对齐**两级表征；③ 正/负**类原型** + 频域扰动的噪声门控特征增强（仅训练期）+ 置信度感知类级融合，提升可分性、降对缺模态的敏感度。
- **主要结果**：20% 测试期随机模态丢弃下，CMU-MOSEI / M3ED 的 micro-F1 为 **0.563 / 0.780**，分别超最强基线 0.004 / 0.005；在 CMU-MOSEI 仅音频的极端设定下仍保 **0.473** micro-F1，而对照 LDDU 仅 0.022。代码已开源。
- **值得追问 / 局限**：① 在常规（非丢弃）设定下相对最强基线仅高约 0.004–0.005，提升主要体现在"缺模态鲁棒"这一维度上，整体 SOTA 优势不大；② "瓶颈 + 原型"带来的可解释性在文中并未作为主要评测对象（主打鲁棒性），其原型是否真忠实、是否可用于内生解释，仍待像专门的自解释工作那样接地检验。

## B. 应用场景（多教师蒸馏做轻量时序异常检测 / 离散神经编码的轻量 EEG 基座模型，取 2 篇）

### 3. Distilling Multi-Teacher Scoring Principles for Unsupervised Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2610.29063
- 作者：Dongchan Cho, Jiho Han, Juwon Hwang, Changhee Min, Minsang Kim（6 位；cs.LG，NeurIPS 2026）
- **TL;DR**：不同时序异常检测器各自编码不同的"异常打分原则"、很难覆盖所有异常类型，拼成集成虽互补却要承担每个检测器的推理与维护成本；AnoMix 在**无标签**设定下，把多个冻结教师在训练集上的异常分**归一化后转成成对弱监督**，用 CoRank 排序蒸馏目标把"教师共识的分差"变成 pairwise 监督，训练出一个 **<80k 参数**的轻量学生。
- **解决什么问题 / 为什么重要**：正中 B 的**time-series anomaly / 监控告警**主线。它解决一个很现实的落地矛盾：集成能融合互补打分原则但太贵；AnoMix 用无监督排序蒸馏把这些原则压进一个极小模型，还能**零样本迁移**——对在线监控/边缘部署这种既要覆盖多类异常又要低成本的场景直接有用。
- **核心方法**：① 从冻结教师在训练集上的异常分里抽**成对弱监督**（无需任何异常标签）；② 对每个教师分数序列**独立归一化**，用 **CoRank** 多教师排序蒸馏目标，把教师分差经"教师共识"转为 pairwise 监督；③ 学生为紧凑模型（基准设定下 < 80k 参数），可直接部署、并支持零样本变体迁移到未见数据集。
- **主要结果**：7 个基准上，AnoMix 把互补的教师打分原则融进单个可部署模型，优于单个检测器与静态分数集成；零样本变体迁移到未见数据集，并能超过用于异常检测的大型时序基座模型。
- **值得追问 / 局限**：① "教师共识"做弱监督的前提是多数教师在该样本上不系统性同错——当异常类型恰好是所有教师共同盲区时，共识会把错误固化进学生，摘要未讨论这种失败模式；② 7 个基准多为公开时序异常集，其标签/评测本身的已知缺陷（点调整等）是否影响"超过基座模型"的结论，值得按正文的评测协议核对。

### 4. BrainCodes: A Lightweight EEG Foundation Model over Discrete Neural Codes
- 链接：https://arxiv.org/abs/2610.29320
- 作者：Kleanthis Avramidis, Ivan Tashev, Dimitra Emmanouilidou（3 位；cs.LG）
- **TL;DR**：近期 EEG 基座模型越做越大、难落到资源受限的日常可穿戴设备；BrainCodes 主张用紧凑结构也能学到可迁移的 EEG 特征——在 800+ 小时、1000+ 被试上自监督预训练，核心是**量化式神经分词器 + 支持任意电极配置的时空编码器**，并显式鼓励表征捕获空间连通性（通道位置编码）与窄带神经振荡（辅助目标）。
- **解决什么问题 / 为什么重要**：命中 B 的**neuroimaging 时间序列 / brain network**，与你关注的 **fNIRS / 可穿戴脑功能监测**同源（都要在少电极/少通道、低算力的真实场景里学可迁移脑信号表征）。它给出的"离散神经编码 + 任意电极配置 + 显式空间连通性/频段先验"的轻量路线，对 fNIRS 这类通道受限、需跨设备迁移的信号同样有参考价值。
- **核心方法**：① **量化式神经 tokenizer**把连续 EEG 离散成神经编码；② **时空编码器**支持任意电极布局；③ 预训练目标显式注入两类归纳偏置——通道位置编码捕获**空间连通性**、辅助目标捕获**窄带神经振荡**；④ 配套一个表征评测框架，刻画学到的 EEG 表征在空间/时间/频谱信号属性上的几何与不变性。
- **主要结果**：在睡眠分期、注意力评估、认知负荷估计等多种神经监测任务上匹配或超过 SOTA；迁移到低资源可穿戴设备时**可训练参数最多减少 97%**。
- **值得追问 / 局限**：① 任务集中在"神经生理监测"类（睡眠/注意/负荷），迁移到情绪/BCI 控制/临床诊断等语义更强的任务，离散编码是否仍够用，待验证；② "量化分词"天然有信息损失，极低算力下的码本大小与下游精度的权衡曲线，以及跨采集设备（不同电极/采样率）时离散码的稳定性，是落到真实可穿戴场景最该追的点。

## C. Agent / 机制（Transformer MLP 的 reader–writer 耦合 / "新数据进上下文还是进权重"的可认证判据，取 2 篇）

### 5. Reader–Writer Coupling in Transformer MLPs
- 链接：https://arxiv.org/abs/2610.29340
- 作者：Giyeong Oh, Sunghee Ahn, Youngjae Yu（3 位；cs.LG）
- **TL;DR**：把 Transformer MLP 的每个隐通道看成一对角色——决定"何时响应"的 reader 与决定"向残差流写回什么"的 writer；二者的配对只靠共享下标，单看任一因子都看不见。本文借 MLP"写回它所读的同一条残差流"这一结构，构造一个**方阵 Jacobian**，用其与自身转置的一致性把更新分解成 reader–writer 项，给每个通道一个**带符号的配对坐标**，据此发现一个普遍存在的"writer 指向其 reader 响应反方向"的强耦合核。
- **解决什么问题 / 为什么重要**：命中 C 的**残差流 / 表征几何 / 机制分析（优先类）**。它提供了一个可直接计算、不依赖探针训练的**内生机制量**（配对坐标），把"MLP 到底在残差流里读写了什么耦合结构"变成可测对象；而且发现的规律跨尺度稳健（从头训小模型到发布 checkpoint），对理解 MLP 作为 key–value 记忆、以及后续块如何"接走"前块写回的量，很有解释价值。
- **核心方法**：① 把 MLP 读成 key–value 记忆，指出 reader↔writer 配对只由共享下标承载、单因子不可见；② 利用"写回即所读之流"构造**方阵精确 Jacobian**，用其与转置的一致性分解出 reader–writer 项，得到每通道**带符号配对坐标**；③ 按该坐标排序，检查强耦合核的符号结构与其在训练早期的形成与持续，并做翻转/置换扰动验证因果作用。
- **主要结果**：每个被测块都有一小撮**强耦合通道核**；在初始化对两种符号等概率处（排除初始化偏置）该核几乎全为"反向"——writer 指向 reader 响应方向的反面；该反向核从最小的从头训练模型到发布 checkpoint 反复出现，训练进度前几个百分点内就定型并随耦合增长持续；多数通道把贡献写回"点燃它的 reader"的反方向、由后续块的 reader 接走、少数才显现在 logits；翻转反向 writer 会把输出推向高频 token，而把 writer 置换到另一 reader 上会重新长成适配后者。
- **值得追问 / 局限**：① 方阵 Jacobian 的构造依赖"MLP 写回同一残差流"这一结构假设，推广到含强注意力路由、MoE 或跨层残差变体时该分解是否仍成立，值得界定；② "反向耦合核"目前是一个被反复观察到的现象 + 若干因果扰动证据，但它在功能上到底承担什么计算（为何多数不显现在 logits、却被后续块接走），尚未给出任务层面的功能解释。

### 6. When Thoughts Become Memory: Unifying In-Context Learning and Fine-Tuning
- 链接：https://arxiv.org/abs/2610.29419
- 作者：Leon Chlon, Julie Huang（2 位；stat.ML）
- **TL;DR**：面对一批新数据，到底该把它放进模型的**上下文**还是写进**权重**（微调）？本文声称给出首个可认证的判据：建立一条"信息价值"精确律——该价值（在留出查询上节省的编码长度）在期望意义上等于"关于查询存储的比特数 + 先验修正 − 解码损失"，对任意模型/架构/数据/任务成立；其上界据此从一次测量就能认证选择，并配一个 anytime-valid 的留出查询检验，在停止时控制误差。
- **解决什么问题 / 为什么重要**：命中 C 的**memory / 训练动态 / 机制（优先类）**，且直指 agent 工程的一个核心取舍：**上下文（情境记忆）vs 权重（参数记忆）**该怎么选。它把这个经验性决策变成一个有理论上界、可用一次留出测量认证的量，并顺带把 ICL 与微调统一到同一条信息价值定律下——对做检索增强/长上下文/持续学习 agent 的"什么该记在哪"给出可量化依据。
- **核心方法**：① 建立"信息价值 = 留出查询上节省的码长"的精确律，并拆成"存储比特 + 先验修复 − 解码损失"三项；② 由该律的上界（ceiling）从单次测量**认证**"进上下文还是进权重"的选择；③ 配 anytime-valid 检验，用留出查询在线判定、停止时控误差；④ 把"删一段上下文=对该段做留出验证、逐段加入=描出上下文内学习曲线"作为诊断工具。
- **主要结果**：在 trained transformer / TabPFN / occupancy network / stereo network 上发出的认证全部正确；检验在表格任务上选 TabPFN 优于 XGBoost、在翼型压强上选训练代理优于 ICL；在 GPT-2 的"缓存 vs 微调"上，64,000 条查询流中 61,948 条判对、零假流上误差 ≤3.3%；信息价值还能无标签地给支持样本排序、并复现一个已发表的证据裁决器（AUROC 0.91）。
- **值得追问 / 局限**：① 摘要写得极度压缩、术语自造（"prior repair""decoding loss""ceiling"），这条"精确律"在何种独立性/可交换性假设下成立、上界有多紧，必须回正文核对，否则"首个可认证判据"的强主张难以直接采信；② 实验多在中小模型与结构化任务（表格/占据/立体视觉 + GPT-2），在大规模 LLM 的真实"长上下文 vs 持续微调"决策上是否仍给出可操作、低成本的认证，是落地最该追的点。
