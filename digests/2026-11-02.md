## A. 核心方法（不规则采样 Neural ODE / 无限深 ResNet 训练动态，取 2 篇）

### 1. PCD: Predictive Coding Dynamics for Irregularly Sampled Time Series
- 链接：https://arxiv.org/abs/2610.41506
- 作者：Tianrui Gou, Jiayangmei Xu, Xingzhou Zhang, Lei Sha（cs.LG）
- **TL;DR**：真实场景的观测往往稀疏、不规则、异步，连续动态模型要在观测之间推断潜态演化。本文提出 **PCD（预测编码动态）**——一种给不规则连续动态模型的**残差反馈机制**：保留历史重构、从中预测已观测项、再把带符号的掩码残差经能量惩罚注入状态识别；在 ODE-RNN 与 Latent ODE 上实现，支持事件驱动的隐状态更新。
- **解决什么问题 / 为什么重要**：**正中 A 的"不规则采样时间序列 + Neural ODE / Latent ODE / 连续时间模型"**。它不另造骨干，而是给现有连续时间骨干加一层"预测误差反馈"，把预测编码（predictive coding）的思想迁移到稀疏异步时序的潜态估计上——当观测约束当前轨迹时，误差反馈能改善潜态估计，这是对 Latent ODE 系方法的一个通用增强点。
- **核心方法**：维护历史重构 → 从重构预测已观测条目 → 将掩码后的带符号残差通过能量惩罚并入状态识别 → 在 ODE-RNN / Latent ODE 骨干上做事件式隐状态更新与潜态识别，联合支持轨迹生成、观测一致性检查与状态精修。
- **主要结果**：在预测（forecasting）与轨迹恢复（trajectory recovery）两类任务上，PCD 在稀疏/不规则采样下一致改善连续动态骨干；结果进一步表明，当观测对当前轨迹有约束时，预测误差反馈能提升潜态估计。（代码匿名开源）
- **值得追问 / 局限**：① 增益主要在"观测能约束轨迹"的情形下显现，长空窗、极稀疏或高噪声下残差反馈是否反而放大误差，需进一步压力测试；② 论文以残差反馈机制为主，未见与最新 CTDG / 神经控制微分方程（Neural CDE）等强基线的系统对比，相对定位待补。

### 2. Infinite ResNets are Gaussian Mean ODEs
- 链接：https://arxiv.org/abs/2610.41514
- 作者：Louis-Pierre Chaintron, Lénaïc Chizat, Javier Maass（cs.LG）
- **TL;DR**：理解深网在大规模极限下的训练动态既有理论也有实用价值。本文给出一个**干净的极限描述**：在标准 shape scaling 与允许"最大局部特征更新"的 $1/\text{深度}$ 分支缩放下，用梯度下降从随机初始化训练的 ResNet，其极限动态就是**在一个"神经均值 ODE（Neural Mean ODE）"上做梯度下降、初始权重为高斯**——相比动态平均场理论（DMFT）给出的非马尔可夫动态，这个描述简单、保留了优化结构。
- **解决什么问题 / 为什么重要**：横跨 A（连续时间 / ODE 视角）与 C（**训练动态**，正中"优先"）。既有 DMFT 结果难分析、掩盖了原动态的优化结构；本文在宽度、深度、嵌入/输入/输出维度**联合趋于无穷**的极限下，把 ResNet 训练动态化归为一个可解释的均值 ODE 上的 GD，并给出依赖网络形状与数据协方差谱的**逼近缩放律**。
- **核心方法**：在 $1/\text{深度}$ 分支缩放（最大局部特征更新）下取大规模极限 → 证明总体风险/经验风险 GD 的极限等价于在 Neural Mean ODE 上对高斯初始权重做 GD → 推导与 ResNet 形状和数据协方差谱相关的逼近缩放律 → 并以 Mixture-of-Experts 展示方法弹性（极限为嵌套的 Mean ODE）。
- **主要结果**：给出 ResNet 大规模极限训练动态的均值 ODE 描述与逼近缩放律；将框架推广到 MoE，极限同样允许直观的（嵌套）Mean ODE 描述。
- **值得追问 / 局限**：① 结论建立在特定缩放（$1/\text{深度}$ 分支缩放 + 标准 shape scaling）下，是否覆盖实际常用的残差缩放与归一化方案，影响其实用外推；② 作为极限理论，有限深度/宽度下的收敛速率与缩放律的实证吻合程度，论文需更多数值验证支撑。

## B. 应用场景（自闭症脑功能网络连接 / 邻域型异常检测压缩，取 2 篇）

### 3. Expression of White and Gray Matter Autism Functional Network Connectivity Signatures in Infancy
- 链接：https://arxiv.org/abs/2610.40839
- 作者：Qiang Li, Jingyu Liu, Zening Fu, Armin Iraji, Sarah Shultz, Vince D. Calhoun（q-bio.NC）
- **TL;DR**：既往功能连接研究多只看灰质（GM）区域或只看白质（WM）纤维束、且局限于特定年龄段。本文把**白质+灰质整合的功能网络连接（FNC）**与**全脑风险分数（BRS）**结合，在 ABIDE I/II 与一个独立婴儿队列上量化自闭症（ASD）相关的模式表达，考察 GM-WM 功能交互如何随发育演化。
- **解决什么问题 / 为什么重要**：命中 B 的**脑网络 / 神经影像时间序列**应用。它突破"只看 GM 或只看 WM"的惯例，用 NeuroMark 框架（预定义 WM/GM 本征连接网络模板）估计被试级 FNC，揭示 WM-GM 功能交互在刻画 ASD 连接改变中的作用，并把成人发现的模式回溯到婴儿期做早期风险关联。
- **核心方法**：NeuroMark 框架 + 预定义 WM/GM 本征连接网络模板估计被试级 FNC → 识别 ASD 相关的 WM+GM FNC 改变模式 → 用全脑风险分数（BRS）量化模式表达 → 在成人（ABIDE）与婴儿独立队列间比较表达强度。
- **主要结果**：识别出两类 ASD 相关 WM+GM FNC 改变——以旁边缘网络为中心的 **GM 低连接**、以额叶网络为中心的 **WM-GM 高连接**，凸显高阶认知网络与 WM-GM 交互的作用；家族自闭症高风险婴儿比低风险婴儿表现出更强的 ASD 相关 FNC 模式表达（以 BRS 量化）。
- **值得追问 / 局限**：① 作者自述婴儿期组间差异为群体层面关联，**不足以确立发育持续性**（需纵向随访）；② WM 的"功能"信号本身在方法学上仍有争议，GM-WM FNC 的生理机制解释需谨慎，是否可迁移到 fNIRS / 任务态 fMRI 等其它功能成像模态待验证。

### 4. Anomalies as Residuals: Cauchy Displacement Networks
- 链接：https://arxiv.org/abs/2610.41387
- 作者：Yang Cao, Zihao Guo（cs.LG）
- **TL;DR**：KNN / LOF / LUNAR 等邻域型检测器在表格异常检测上仍属最准一档，但推理要逐一比对训练集、代价与内存随数据增长且部署时须保留数据。本文提出 **Cauchy Displacement Network（CDN）**：用单隐层 Cauchy 激活网络把每个正常点回归到其 $k$ 近邻均值，用预测位移向量的**长度**作为异常分数——把邻域几何"编译"进一个一次前向即可打分的小网络。
- **解决什么问题 / 为什么重要**：命中 B 的**异常检测**（监控方向），同时兼具方法论价值。它直面邻域型检测器"快但重、须留数据"的部署痛点，给出理论支撑：位移即经验均值漂移向量，其固定半径总体对应物局部逼近对数密度梯度的缩放；并证明 Cauchy 单元能精确表示一类 Student-$t$ 专家密度的分数场，给出单隐层 Cauchy 网络对邻域均值映射的构造性逼近界。
- **核心方法**：对每个正常点用单隐层 Cauchy 网络回归其 $k$ 近邻均值（学习均值漂移/位移场）→ 查询时以预测位移长度为异常分数 → 理论上将 Cauchy 单元与 Student-$t$ 专家密度分数场对应，并证明有界输出保证沿任意固定方向的渐近线性残差分数增长。
- **主要结果**：在 46 个基准数据集、对比 28 个基线下，CDN 在 AUC-ROC 与 AUC-PR 上均取得**最佳平均排名**；单 CPU 线程上数毫秒内可对 $10^4$ 个查询打分，比邻域型检测器快达**三个数量级**，且部署时无须保留训练数据。
- **值得追问 / 局限**：① 聚焦**表格**异常检测，对时间序列异常/根因定位（AIOps 场景）这类有时序结构的数据是否同样有效，论文未涉及；② "位移长度"作为分数假设正常点邻域均值可被平滑逼近，强簇边界或多模态分布下的误报行为值得追问。

## C. 机制 / Agent（LLM 成员信号的表征-读出分析 / KV-Cache 补丁定位微调行为，取 2 篇；均为"优先"机制类，非 prompt 工程）

### 5. From Representation to Readout: Mechanistic Analysis of Membership Signals in Language Models
- 链接：https://arxiv.org/abs/2610.41445
- 作者：Wenxi Dai, Jingyu Hu, Yanting Yang, Mengnan Du（cs.LG / cs.AI）
- **TL;DR**：成员推断判断某样本是否在训练集中，常被笼统称作"记忆"，但其机制同时涉及"信息如何在内部表征"与"模型如何访问它产生行为"两层。本文做 LLM 成员信号的机制研究，提出 **DUG** 一组互补度量——可解码信息分数、被使用信息分数、读出可达性差距——分别量化"从内部表征可解码的成员信息"与"经模型读出暴露出来的部分"。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / 表征几何**（正中"优先"）。它把"记忆"拆成**表征层**与**读出层**两个可分别度量的维度，而非停留在黑箱成员推断分数，用激活补丁（activation patching）把成员特异效应**定位到中间层**，对"隐私泄露到底发生在哪一层"给出机制级答案。
- **核心方法**：定义 DUG 三度量（可解码信息分数 / 被使用信息分数 / 读出可达性差距）→ 在监督微调（SFT）与基于 RL 的成员推断方法上分别测量表征可解码量与读出暴露量 → 用激活补丁定位成员特异效应所在层 → 进一步在可验证奖励 RL（RLVR）污染设置下考察行为变化与似然型成员信号是否解耦。
- **主要结果**：SFT 下成员特异效应同时出现在"可解码信息量"与"读出"中，而基于 RL 的成员推断方法下主要出现在**读出**；激活补丁把该效应定位到**中间层**；在 RLVR 污染设置下，行为改变可在"似然型成员推断信号不升高"的情况下出现（即行为污染与似然信号解耦）。
- **值得追问 / 局限**：① DUG 度量依赖探针/补丁的具体实现，"可解码 ≠ 被使用"的区分对探针容量与补丁粒度可能敏感，稳健性需交叉验证；② RLVR 下"行为变化与似然信号解耦"若成立，意味着现有似然型成员推断会**漏检**一类污染，这对审计方法的影响值得单独追问。

### 6. KV-Cache Patching: Tracing How and Where Fine-Tuned Behaviors Arise
- 链接：https://arxiv.org/abs/2610.41480
- 作者：Jonas Loos, Oliver Eberle（cs.CL / cs.LG）
- **TL;DR**：微调改变了模型的回应方式，但这种行为"落在哪里"——只在生成答案 token 时产生，还是经注意力机制、通过对**先前 token** 的不同处理间接导致？本文把 LoRA 微调模型的 **KV cache 补丁**到未改动的基座模型（及反向），以此定位微调行为的实例化位置。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / residual-stream 式干预**（"优先"类）。它用 KV-cache 作为可移植的"状态载体"，直接检验微调行为是"生成时才产生"还是"已写入对历史 token 的表征"，对理解 LoRA 微调、乃至**涌现式错位（emergent misalignment）**的产生位置给出因果性证据。
- **核心方法**：从 LoRA 微调模型抽取 KV cache 补丁进未改动基座模型（并做反向补丁）→ 观测特定行为（如用德语回应、涌现式错位）能否被转移或移除 → 系统改变被补丁的 KV cache 比例与位置，测量效应随之如何变化。
- **主要结果**：对部分行为（德语回应、涌现式错位），把微调模型的 KV cache 补丁进基座模型可**转移**该行为；反向（基座→微调）补丁可**部分或完全移除**微调行为；补丁效应随被补丁比例增大而增强，并**集中在少数关键位置**，其中系统提示与 chat 模板 token 影响不成比例地大。
- **值得追问 / 局限**：① 结论基于若干特定行为（语言切换、涌现错位），能否推广到更复杂的推理/工具调用行为，外推性待检验；② "系统提示 / chat 模板 token 影响过大"提示微调行为可能高度依赖模板上下文，这对部署时的提示变动鲁棒性与安全审计都有含义，值得深挖。
