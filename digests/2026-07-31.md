## 1. Enhancing Irregular Time Series Forecasting with Continuous-Time Modeling Framework (WrapFlow)
- arXiv: https://arxiv.org/abs/2607.28035
- 作者：Tianen Shen, Zhengyu Li, Yutong Li, Xiangfei Qiu, Xingjian Wu, Bin Yang, Jilin Hu（东华大学等）
- **TL;DR**：不规则多变量时间序列（异步观测、非均匀采样间隔）预测，现有做法要么靠插值/填补离散化破坏连续时间语义，要么用 ODE 框架但算力开销大。WrapFlow 用"连续时间 token + 免仿真残差流匹配"绕开数值求解器，在标准 Transformer 骨干上做连续预测。
- **解决什么问题 / 为什么重要**：正中 A 方向"不规则采样时间序列 / 连续时间模型"最优先项。它的立意就是替代 Neural ODE 那条线——保留连续时间建模的好处，同时甩掉数值求解器带来的架构专用性与训练/推理开销，对做异步医疗监测、活动识别、环境传感的连续时间预测很有参考价值。
- **核心方法**：输入侧提出 Continuous-Time Tokenization，直接编码原始观测事件，并用 gap-aware token 显式建模长的未观测间隔；所得连续时间 token 交给标准 Transformer 捕获长程依赖。输出侧提出免仿真的 Residual Flow Matching，围绕基准预测学习条件残差向量场，训练时不做数值仿真与反传，推理只需少量固定 rollout 步。
- **主要结果**：在多个真实数据集上取得 SOTA 预测性能。
- **值得追问 / 局限**：摘要未给与 ODE/latent-ODE 类基线的算力—精度定量对比曲线，"省多少、掉不掉点"需看正文；gap-aware token 对超长空窗与极端稀疏采样的外推能力、以及固定少步 rollout 的误差累积如何，待验。

## 2. Dynamic Spectral Filtering for Temporal Graph Learning: Learning Evolving Propagation Operators
- arXiv: https://arxiv.org/abs/2607.27891
- 作者：Yan Kong
- **TL;DR**：时序图学习通常围绕"节点状态演化"或"交互历史编码"展开，这篇换一个算子中心的问题：图传播机制本身该不该随时间演化？提出 Dynamic Spectral Filtering (DSF)，把每个快照的传播表示为系数随时间变化的 Chebyshev 多项式谱滤波器。
- **解决什么问题 / 为什么重要**：正对 A 方向"时序图 / 动态图 GNN"，且切入点新颖——不是让表征动、而是让"传播算子（谱响应）"动，作为一种时间归纳偏置。难得的是它把计算效率当一等目标：紧凑的多阶系数作为循环时间状态，状态维度与节点数无关，可扩展性友好。
- **核心方法**：用向量值、时间相关的 Chebyshev 系数表示快照 t 的传播；把这些紧凑的多阶系数当作循环时间状态，一个循环分支提出更新，全局门与阶特定门以乘性方式调节其幅度；时间状态独立于节点数量。
- **主要结果**：在 MOOC / Wikipedia / Reddit 时序链路预测上 AP 分别为 0.7851 / 0.9088 / 0.9860，参数仅 93K–133K、峰值显存 68–182 MB、每 epoch 1.6–2.1 秒。相较近邻 baseline DEFT，MOOC 更优、Reddit 差距在 0.001 AP 内、Wikipedia 略低，但参数少 8.3–8.6×、显存少 25–33×、时间少 5–19×；相对所有对比方法显存少 3.3–38.6×。
- **值得追问 / 局限**：单作者、benchmark 限于三个经典时序链路预测集，向大规模/工业图与其它任务（节点分类、事件流）的迁移未验；效率优势突出但精度未全面超过 DEFT，属"以少量精度换大幅省资源"，是否值得取决于场景。

## 3. Back to All-Entity Ranking: Sampler-Dependent Evaluation in Continuous-Time Dynamic Graphs
- arXiv: https://arxiv.org/abs/2607.27861
- 作者：Minwoo Yu, Young-guk Ha（建国大学，韩国）
- **TL;DR**：CTDG 的"下一目的地预测"普遍用"观测交互 vs 采样负例"来排名打分，但分数同时取决于负例分布与候选数量。本文证明采样负例基准会让模型排名与消融结论失稳，呼吁改用"全实体排名"。
- **解决什么问题 / 为什么重要**：属 A 方向"CTDG / 动态链路预测"的方法学纠偏。它直接动摇了这一子领域大量论文的评测根基——如果模型优劣与消融方向会随候选集配置改变，那既有 SOTA 结论就带条件；对任何在 CTDG 上做基准比较、或想复现/挑 baseline 的人，这是必读的评测警示。
- **核心方法**：用"重复/新正例 × 已见/未见负例"的因子化评测、一个仅基于 pair-history 成员关系的极简打分器、以及受控的表征干预，剖析采样器影响如何经"时变的源-目的地历史成员关系"直接传导到评测分数；进而主张全实体排名——在固定目录上枚举每个目的地，消除负例选择自由度与采样波动，同时保留原 CTDG 打分器。
- **主要结果**：在 LastFM / MOOC / Reddit / Wikipedia 上跨六个模型，四个数据集里有三个出现"Uniform-20 指标 vs 全目录"下至少一对模型相对排名反转；同一模块的测得效应也随候选集大小与训练目标改变幅度乃至方向。
- **值得追问 / 局限**：全实体排名仅适用于"可枚举、固定目的地目录"的场景，对开放/超大目录（真实推荐、超大图）不可直接照搬，成本也更高；结论基于四个经典基准，是否所有 CTDG 任务都如此敏感需更广验证。

## 4. Information Bottleneck Learning for Faithful Time Series Forecasting Explanations (IB-Forecast)
- arXiv: https://arxiv.org/abs/2607.28124
- 作者：Xu Zheng, Wei Cheng, Zhuomin Chen, Mo Sha, Jingchao Ni, Dongsheng Luo（FIU / NEC Labs / 休斯顿大学等）
- **TL;DR**：预测越来越驱动决策，但"可解释设计"的预测器只暴露内部结构、不保证它忠实反映真正驱动预测的证据；而面向保真度的方法几乎只为事后分类设计。IB-Forecast 用信息瓶颈把"内生可解释 + 解释保真"同时做进多变量时间序列预测。
- **解决什么问题 / 为什么重要**：正对我的横切重点"内生/自解释 + 信息瓶颈"，且落在时间序列预测（而非常见的分类）这一少有人做保真解释的场景。它主打"native 解释在匹配稀疏预算下胜过梯度/遮挡/优化类事后归因"，正是我"事后归因降权、内生自解释优先"取向的对味样例。
- **核心方法**：把预测分解为"学得的周期分量 + 用可解释掩码在输入 token 上算出的残差分量"；用带预算约束的信息瓶颈做端到端优化，让用户直接控制解释稀疏度；配一套严格的保真度评测协议。
- **主要结果**：预测误差与领先黑箱模型持平，同时零额外推理成本给出忠实解释；在匹配稀疏预算下，native 解释在所有数据集上稳定超过梯度/遮挡/优化类 baseline；仅需 14–20% 的观测即可达成低误差预测。
- **值得追问 / 局限**："周期 + 残差"分解假设对强非平稳/多尺度周期数据是否成立需验；保真度提升依赖其自定义评测协议，跨协议一致性待考；掩码稀疏预算与预测精度的权衡曲线在更高稀疏度下如何退化，摘要未展开。

## 5. S-CEReBrO: Breaking the Memory Barrier in Continuous EEG Monitoring
- arXiv: https://arxiv.org/abs/2607.27913
- 作者：Glenn Anta Bucagu, Thorir Mar Ingolfsson, Yawei Li, Luca Benini（ETH Zürich / 博洛尼亚大学）
- **TL;DR**：脑电（EEG）基础模型用 Transformer 全局注意力时，注意力显存与信号时长耦合，连续监测会显存溢出。S-CEReBrO 用"窗口交替注意力"把注意力分解到固定大小的时空窗口，保证 KV cache 显存恒定，从而支持流式连续监测。
- **解决什么问题 / 为什么重要**：正对 B 方向"neuroimaging 时间序列 / 脑信号 / 脑网络"。虽是 EEG 而非 fNIRS，但"脑信号基础模型 + 连续监测显存墙"这一痛点与近红外脑功能监测高度同构，其窗口交替注意力的显存-时长解耦思路可直接迁移到 fNIRS 长程建模；且它是在 2.5 万小时、1.2 万被试上预训练的大规模基础模型，方法与数据都有参考价值。
- **核心方法**：提出 Windowed Alternating Attention，把注意力计算分解为固定大小的时空窗口，仅活动窗口需驻留注意力图，从而保证常数级 KV cache 显存；在 CEReBrO 架构上演化为流式版本。
- **主要结果**：可处理比全自注意力长 100×、比低秩线性注意力长 3× 的信号；长上下文下相比低秩线性注意力仅用 55% 显存、推理吞吐提升 2.1×；在 11 个下游任务中 7 个达到 SOTA，参数最多少 60%；附代码仓库。
- **值得追问 / 局限**：窗口化以固定窗切分时空，跨窗的长程脑网络依赖是否被削弱、对需要全局同步性的任务（如跨脑区功能连接）影响如何，需看下游细分；SOTA 覆盖 7/11 任务，另外 4 个落后于谁、差距多大，值得追问。

## 6. ChronoMem: Version Control and Semantic Rollback for Large Language Model Agent Memory
- arXiv: https://arxiv.org/abs/2607.27773
- 作者：Yongye Su, Wujiang Xu, Chaoji Zuo, Elisa Bertino（普渡大学 / 罗格斯大学）
- **TL;DR**：LLM agent 的长期记忆多是"只进不退"地累积、整合、覆盖，缺乏检查、版本化、回退旧状态的机制，导致在纠错、概念漂移、记忆污染下很脆弱。ChronoMem 给 agent 记忆加一层"语义版本控制 + 自然语言回滚"。
- **解决什么问题 / 为什么重要**：属 C 方向"优先（memory 机制）"那类，明显非 prompt 工程。它把软件工程的"版本控制/回滚"范式引入 agent 记忆，主打机制而非模板，并集成进 Google 生产级开源 ADK；对做长期记忆、持续学习、记忆鲁棒性/可控性研究是一个可复现的系统与基准样例。
- **核心方法**：每次记忆写入提交整体记忆快照、维护结构化版本历史；把自然语言的"撤销意图"经混合词法+语义检索、rank fusion 与重排映射到具体历史版本以支持回滚；并提出"暴露后（post-exposure）"评测协议，测试 agent 在回滚后能否反事实地作答与总结历史（就像后续更新从未发生）。
- **主要结果**：在增强了演化记忆状态与回滚任务的长程对话基准上，回滚一致的问答与历史总结相对 prompt-only、retrieval-only 基线显著提升，且语义版本选择表现强；号称是首个面向 LLM agent 全局记忆语义回滚的开源系统与基准。
- **值得追问 / 局限**："每次写入提交整体快照"在长程/高频写入下的存储与检索开销如何扩展，摘要未量化；回滚粒度是整体记忆而非局部条目，细粒度纠错（只撤某条错误事实、保留其余更新）是否支持待看正文。
