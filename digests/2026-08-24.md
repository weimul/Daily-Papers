## A. 核心方法

### 1. Online Test-Time Adaptation for Generalizable Dynamic Graph Anomaly Detection
- arXiv：https://arxiv.org/abs/2608.19858 （cs.LG）
- 作者：Jialun Zheng, Hanchen Yang, Jiannong Cao, Yankai Chen, Yuanjing Feng, Philip S. Yu（含香港理工、UIUC 等）
- **TL;DR**：把动态图异常检测（DGAD）放进"数据分块顺序到达、无法拿全量目标域"的在线测试时适应设定，用从时序自我图里抽出的"演化原型 + 记忆缓冲"边跑边更新，兼顾通用模式与目标域特有的漂移模式。
- **解决什么问题 / 为什么重要**：预训练检测器迁到新域时，现有方法要么只学域无关的通用模式、漏掉不断演化的域特有模式，要么假设能一次拿到整个目标域——这在真实监控/风控里不成立。该工作同时踩中你 A 方向的「动态图/事件流」与 B 方向的「异常检测」，且用"原型 + 记忆"这类内生结构承载可迁移知识，思路上很对味。
- **核心方法**：从时序自我图（temporal ego-graph）中提取正常/异常的"动态原型"存入记忆缓冲，缓冲区选择性保留源域共享的通用模式、同时吸收目标域新模式；异常打分器把进来的边表征与原型比对，识别通用与域特有两类异常；适应阶段用基于置信度的可靠伪标签更新缓冲，并用此前分块保留的相关表征回补当前分块，缓解顺序到达带来的信息损失。
- **主要结果**：在严格的 test-then-adapt OTTA 设定下，跨十个不同域的真实数据集取得 SOTA。
- **值得追问 / 局限**：①置信度伪标签驱动的自更新在异常率极低或概念漂移剧烈时可能自我强化偏差，缓冲区如何抗污染值得看细节；②"通用 vs 域特有"原型的容量分配与遗忘策略在长期在线流下的稳定性文中未充分展开。

### 2. Rethinking Patch Based Multivariate Time Series Forecasting with Semantic Structured Partitioning (SCPaT)
- arXiv：https://arxiv.org/abs/2608.19966 （cs.AI）
- 作者：Jiazhe Wang, Zhiquan Huang, Linjing Xue, Ming Liu, Meiwen Li, Ruijuan Zheng
- **TL;DR**：不再用固定/多尺度/可扩展的 patch 切分，而是把序列自适应地切成"语义一致单元"，再在单元间建一张有向动态语义图，并用重要性路由把不同语义块分派给不同专家建模。
- **解决什么问题 / 为什么重要**：现有 patch 切分要么切断有意义的时间边界、要么跨尺度冗余、要么缺一个"显式组织语义结构、刻画异质模式间交互"的机制。SCPaT 把"结构如何组织"直接做进模型（语义单元 + 动态语义图），带有内生结构/可解释的味道，贴合你 A 方向对"时序 × 图结构 × 显式结构组织"的偏好。
- **核心方法**：先经自适应语义单元生成把输入分解为语义一致单元；再构建动态语义图建模单元间有向依赖、并聚成更高阶的语义块；最后用重要性感知路由把不同语义块分派给不同专家做定制化建模。
- **主要结果**：在 12 个真实数据集上验证了框架有效性（摘要未给出具体数值增益）。
- **值得追问 / 局限**：①"语义一致单元"的划分依据与稳定性（是否对噪声/非平稳敏感）是文中关键，需看消融；②动态语义图 + MoE 路由的额外计算与可解释性收益是否成正比，缺少与轻量 patch 基线的效率对照。

## B. 应用场景

### 3. Decoding silent reading from non-invasive EEG
- arXiv：https://arxiv.org/abs/2608.20186 （cs.LG / q-bio.NC）
- 作者：Ingo Marquardt, Anthilia Alchanat, Priyanka Jain
- **TL;DR**：把"静默阅读"当作内部言语解码的可扩展代理任务，用 CLIP 式对比目标把短时 EEG 窗口对齐到 LLM 的词表征，在约 24 万次单词呈现的单被试密集数据上做开放词表词级解码。
- **解决什么问题 / 为什么重要**：无创解码"内心独白"面临根本性数据难题——自发内语无法成对采集，现有代理范式慢、时间对齐差、依从性不可验证。作者转而用静默阅读做代理，量化能从 EEG 里恢复多少词汇/语义信息。对你 B 方向的神经影像时序解码是很直接的范式参考（19 通道干电极 EEG，虽非 fNIRS，但脑功能时序 + 对比表征对齐的思路对 fNIRS 管线可迁移）。
- **核心方法**：单被试 393 次 run（约 49 小时）19 通道干电极 EEG，narrative 文本经 RSVP 快速呈现、每 trial 随机排版以部分解耦词身份与低级视觉形态；卷积 EEG 编码器（可接因果 transformer）用 CLIP 式对比目标，把短 EEG 窗与 LLM 隐状态词嵌入对齐。
- **主要结果**：以词分组 top-10 检索评估，稳定高于置换基线，可延伸到中频与罕见词；性能随训练数据量呈对数线性增长、未见饱和；去掉枕区/后颞电极使词级增益降约 1/3 但语境追踪不变；对照分析把词级解码与叙事语境追踪、以及 transformer 位置嵌入引入的非神经位置先验分离开。
- **值得追问 / 局限**：①单被试、单被试内密集采样，跨被试泛化与被试间差异完全未验证；②"数据受限而非饱和"意味着结论强依赖数据规模，实用系统的采集成本与可迁移性仍是问号。

### 4. From Noise to Signal: Improving Security Log Anomaly Detection Using LLMs with Endpoint-Specific Logs
- arXiv：https://arxiv.org/abs/2608.19938 （cs.CR / cs.LG）
- 作者：Christopher Henshaw, Gour Karmakar
- **TL;DR**：针对端点鉴权行为，用指令微调 LLM 做标准化分类框架检测异常（含边界样本），在自建可控测试床数据上大幅超越规则型（Wazuh）与统计型（OpenSearch）异常检测。
- **解决什么问题 / 为什么重要**：规则型只认预定义规则、统计型只认偏离历史模式，都难覆盖端点特异的鉴权行为；LLM 又易受 prompt 构造、噪声日志、通用数据集不匹配影响。这直接命中你 B 方向监控告警/AIOps 的痛点——尤其"边界/暧昧样本"的检出能力。
- **核心方法**：搭建可控网络安全测试床生成端点特异的鉴权数据（正常/边界/异常三类），设计标准化指令式 LLM 分类框架，用统一 ground-truth 严重度基准对比三款指令微调 LLM（Llama 3.1 8B、Qwen 2.5 7B、GPT-OSS 20B）与 Wazuh、OpenSearch。
- **主要结果**：Llama 3.1 8B 端到端最强（准确率 89.3%、召回 88.2%、F1 91.8%、漏报率 11.8%），远超 Wazuh（准确率 52.0%、漏报 68.6%）与 OpenSearch（49.3%、漏报 74.5%）；边界异常场景 Llama 检出 80%，Wazuh 20%、OpenSearch 15%；Qwen 延迟最低且结构化响应 100% 有效。
- **值得追问 / 局限**：①结论基于自建测试床数据，真实生产日志的分布漂移、告警风暴与规模化下的表现存疑；②以准确率/F1 为主，缺少大规模低基率下的告警量/误报成本分析，落地选型仍需补齐时序上下文建模。

## C. Agent / 机制与表征

### 5. Reliable Neural Collapse Approximation for Open-World Test-Time Adaptation (ReNC)
- arXiv：https://arxiv.org/abs/2608.19890 （cs.LG）
- 作者：Jia-Qi Lin, Yuangang Pan, Chang-Dong Wang, Haizhang Zhang, Ivor W. Tsang, Joey Tianyi Zhou
- **TL;DR**：把"神经坍缩（NC）"当作结构先验用于开放世界测试时适应——由 NC 论证可直接把预训练分类器权重当作源域原型，据此过滤 OOD 样本、再用 NC 近似机制在适应中维持坍缩结构。
- **解决什么问题 / 为什么重要**：传统 TTA 在出现标签分布漂移（开放世界）时失效。ReNC 用表征几何里的神经坍缩作为可靠适应的锚，正对你 C 方向明确点名的「表征几何（neural collapse）」这一优先项；且它把"结构当先验"的思路做成可解释的适应机制，而非纯经验 trick。
- **核心方法**：以 NC 为结构先验，论证预训练分类器权重可作源域原型；用样本-原型相似度过滤 OOD 样本以做可靠更新；再提出神经坍缩近似机制精修原型，使其在向目标域适应的同时保持 NC 结构。
- **主要结果**：多个开放世界基准上优于现有方法；实证分析显示 ReNC 更好地保持了目标域中的 NC 相关性质，为"可靠 OWTTA 为何成立"提供了可解释证据，也为模型设计给出新洞见（附代码）。
- **值得追问 / 局限**：①"分类器权重即原型"依赖源模型确实达到较好的 NC 状态，源训练不充分或类别极不均衡时该前提可能不成立；②NC 结构主要在分类几何中成立，迁到强时序/图结构任务（你更关心的模态）是否仍是合适先验，需要额外验证。

### 6. Mechanistic Tomography: Designed Measurement for Control-Oriented Interpretability
- arXiv：https://arxiv.org/abs/2608.19338 （cs.LG / cs.AI）
- 作者：Vijay Erramilli
- **TL;DR**：把机制可解释性里各种探测手段（patching、梯度、Hessian-向量积、子集干预）统一成一个"设计测量"问题 y = Ax + w，给出从最省成本测量起步、按结构残差逐步扩展测量族的实操流程，并用"控制"作为苛刻的验证场景。
- **解决什么问题 / 为什么重要**：不同可解释性测量在不同访问假设下测的其实是不同量，彼此难比较、难判定何时够用。该工作把它们纳入统一测量论框架，正属于你 C 方向偏好的「机制/现象分析」——不是刷某个电路，而是给"如何测量内部机制"立方法论，对可靠内生解释很有基础价值。
- **核心方法**：对给定基与干预族，测量写成 y = Ax + w（A 描述干预、x 是目标映射、w 含非线性响应/采样误差/基失配）；流程是先做最省测量、在目标尺度的留出干预上检验、校准简单失配、当结构化残差仍在则扩展测量族。用控制做验证：因为指导干预的估计相当于一个观测者，控制误差随观测者误差上升，能暴露"目标改善却掩盖了冗余状态移动"。
- **主要结果**：双 HMM 模型中控制误差随观测者误差上升；仅前向访问时稀疏聚合测量能以更少干预恢复有限效应图；GPT-2-small 的 IOI 任务上，Name Mover–Negative Name Mover 交互是三对跨组中最大的留出预测项；Qwen-2.5-7B 上有限校准使加性"拒答响应"图即已足够，留出误差不支持成对提升。
- **值得追问 / 局限**：①框架偏理论与小规模案例（HMM、GPT-2、单个 7B 现象），大模型上"何时该扩展测量族"的可操作判据是否稳健待观察；②以"控制表现"为验证虽苛刻，但把可解释性成败绑定到某个下游控制任务，可能低估与控制无关但重要的机制。
