## A. 核心方法（时空 GNN 负荷预测的因果归因祛魅 / 免回放持续图学习的瓶颈+原型，取 2 篇）

### 1. A Diagnostic Protocol for GNNs in Electricity Load Forecasting: Separating Parameter Sharing from Neighborhood Access
- 链接：https://arxiv.org/abs/2610.35074
- 作者：Eloi Campagne, Yvenn Amara-Ouali, Yannig Goude, Itai Zehavi, Argyris Kalogeratos（5 位；cs.AI）
- **TL;DR**：一个 GNN 在预测一组负荷序列时同时做了两件事——**跨序列共享参数**与**读取邻居序列**，相对非图模型的增益可能来自其中任意一条；本文提出一套**诊断协议**，用三类参照模型（逐节点网络、无邻居的共享网络、去掉边的同一 GNN）+ **保度数重连**把两条通路拆开，结论是在三个真实数据集上"边"都**没有**贡献 GNN 相对逐节点模型的主要优势。
- **解决什么问题 / 为什么重要**：直击 A 的**时空/图 GNN（核心方法）**，而且是难得的**批判性因果澄清**——时空图预测文献长期把"用了图就归功于图结构"，本文给出一个可操作的归因协议，逼问"这张图到底值不值得维护"。对你关注的 spatio-temporal GNN，它提供了一个方法论先验：报告图增益前必须先和"逐节点 / 仅共享参数"两个参照比过，否则增益可能只是参数共享的功劳。
- **核心方法**：① 三参照对照（per-node、shared-no-neighbor、same-GNN-no-edges）分离"参数共享"与"邻居访问"两条增益来源；② **保度数重连（degree-preserving rewiring）** 检验"邻居身份是否真的重要"——若重连后增益消失，则边只是在借度数/平滑之力；③ 在法国区域负荷与英国低压馈线上做调参基准，并特意构造"短历史/非平稳"场景压测。
- **主要结果**：馈线上**参数共享就恢复了逐节点模型与 GNN 之间约三分之二的误差差距**；加边带来的增益更小，且其中**一半以上在重连后消失**；客户序列上"邻居均值"在短窗反而**损害**逐节点模型、边的增益与零不可区分；合成实验指出"局部测量噪声大"是邻居真正有用的一个 regime。三个数据集中边都未解释 GNN 相对逐节点模型的大部分优势。
- **值得追问 / 局限**：① 结论基于电力负荷这一类**强自相关、同质性**的序列，能否迁移到交通/脑网络等"邻居语义更强"的时空图，需按该协议各自重测；② "保度数重连使增益消失"是判定边无用的关键证据，但重连只检验了"邻居身份"，对"边权/动态边"承载的信息是否也被覆盖，值得进一步拆。

### 2. CoPE-CGL: Community-aware Prototype Extraction for Replay-Free Continual Graph Learning
- 链接：https://arxiv.org/abs/2610.35313
- 作者：Bo-Young Lim, Seokhwan Kim, Kisung Lee, Hyuk-Yoon Kwon（4 位；cs.LG）
- **TL;DR**：持续图学习（CGL）要在图不断演化时维护模型、又不灾难性遗忘，已有方法多需存旧子图或推理时要任务 ID；CoPE-CGL 是一个**免回放**框架，用**多跳 Laplacian 平滑预计算的无参结构先验**锚定学习/记忆/推理，并组合**拓扑注入瓶颈适配 + 社区级原型 + 节点-原型匹配多数投票的动态路由**，每个任务只加常数存储、不留旧图数据。
- **解决什么问题 / 为什么重要**：命中 A 的**动态/演化图**，同时踩中 A 的**信息瓶颈 + 原型的内生自解释横切**——"社区级原型 + 节点到原型的匹配投票"本身就是一种**可读的自解释路由**（看一个节点匹配到哪个社区原型即知其归类依据），比纯事后归因更内生。对关注"连续时间/演化图 + 内生可解释"的你，它示范了如何在不存历史、不要任务 ID 的约束下把"结构先验 + 原型"做成同时解决记忆与解释的锚点。
- **核心方法**：① **无参结构先验**（多跳 Laplacian 平滑预计算）锚定学习与推理；② **拓扑注入瓶颈适配**（topology-infused bottleneck adaptation）压缩表征；③ **社区级原型** + 按"节点-原型匹配多数投票"的**动态路由**分类；默认假设每张测试图来自一个已学任务，另给"节点级变体"处理混合任务图。
- **主要结果**：等存储、无任务 ID 下，**追平**拿到真任务 ID 的最强回放基线（Arxiv/CoraFull 上 AP 95.17%/95.72% vs 94.28%/95.82%），且**运行快 5.9–14 倍、零遗忘**；跨 4 直推 + 3 归纳基准及混合流，比次优（至多 11 个基线）高出至多 1.41 / 6.32 / 9.33 AP 点，端到端快 1.3–7.9 倍。
- **值得追问 / 局限**：① 作者明确"设计面向**同质性 + 有社区结构**的图"，在异质图或社区结构弱的场景上，社区原型路由的有效性与可解释性都会打折；② "每张测试图来自单一任务"是默认协议的强假设，混合任务要靠节点级变体兜底，真实演化流里任务边界模糊时的退化行为值得压测。

## B. 应用场景（rs-fMRI 脑网络的检索增强帕金森分类 / 多元时序异常的"可恢复性×一致性"双任务，取 2 篇）

### 3. Retrieval-Augmented Parkinson's Disease Classification from Resting-State Functional Connectivity
- 链接：https://arxiv.org/abs/2610.35107
- 作者：Tara Niknam, Sana Hassan Imam, Daniel Kristanto（3 位；q-bio.NC）
- **TL;DR**：静息态**功能连接（FC）**是帕金森（PD）诊断的候选标记，但公开 PD 数据集小且跨站点/扫描仪/临床标准碎片化；本文提出**检索增强分类（RAC）**——用图卷积自编码器（GAE）把外部队列编码成"神经知识库"，对每个目标个体检索最近邻、把邻居嵌入与目标嵌入聚合后分类，但诚实报告"检索/注意力**并未稳定超过**纯预训练变体"。
- **解决什么问题 / 为什么重要**：直接贴合你的**神经影像时间序列 / 脑网络**方向，且是一篇**诚实的负面/混合结论**论文：它想把"群体学到的单一权重"补上"个体特异的检索上下文"（精准神经影像动机），但系统对照（编码器预训练 / 检索 / 注意力 / 部分微调）后发现只有**预训练**稳定有效（准确率 60.5%→66.0%），检索与注意力都没带来一致增益。这类"把 RAG 范式搬到小样本脑网络"的尝试与它的边界，正是你评估"脑功能连接 + 外部知识库"可行性时该先看的。
- **核心方法**：① GAE 在外部 PD/对照队列上预训练，编码为**神经知识库**；② 目标个体经同一 GAE 编码后检索最近邻，用均值聚合或注意力把邻居嵌入与目标嵌入融合做分类；③ 在 TaoWu 队列上系统拆解预训练/检索/注意力/部分微调各自贡献，并做检索邻域分析。
- **主要结果**：**预训练**把平均准确率从 60.5% 提到 66.0%；**检索与注意力未稳定超过纯预训练**，仅若干检索配置在 ROC-AUC 上略高于随机初始化基线；改变检索邻居数、部分微调编码器均无一致额外增益；邻域分析显示检索到的近邻**诊断标签混杂**。
- **值得追问 / 局限**：① 评测只在单一 TaoWu 队列、样本量小，"检索无稳定增益"很可能是**数据规模**所限而非范式本身失败——作者亦称需更大数据才能判定何时个体检索有用；② "邻域标签混杂"暗示 FC 嵌入空间里**相似≠同病**，检索要生效可能需更强的疾病判别性编码器或度量学习，而非直接用重构式 GAE 嵌入。

### 4. CLOSURE: Cross-Channel Closure for Multivariate Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2610.35753
- 作者：Fan Xu, Hao Wu, Zhi Song, Hanbo Huang, Wenzhuo Ma, Nan Wang（8 位；cs.AI）
- **TL;DR**：无监督多元时序异常检测的主流是"在正常数据上训重构模型、用残差打分"，但**残差只证明"能被恢复"、不证明"变量之间仍像正常时那样互相解释"**——协调式但陌生的运行切换会抬高残差却不破坏关系，而某个传感器悄悄偏离同伴却可能让残差沉默；CLOSURE 把**可恢复性**与**跨通道一致性**拆成两个独立学习的正常数据预测任务。
- **解决什么问题 / 为什么重要**：命中 B 的**时序异常检测**，概念上很对你的监控/告警口味：它点破了"把变量间依赖折进重构目标"的根本模糊——关系证据最终仍被同一重构损失监督，所以无法独立判断"关系是否还成立"。把"关系闭合"单独做成一个任务（每个通道**只用其它通道**预测、withhold 自身轨迹），正是 root-cause 式"谁偏离了同伴"的可用信号，兼有 A 的**离散记忆 + 校准**横切。
- **核心方法**：① **可恢复性任务**：由条件在"正常时序基的离散记忆"上的扩散重构器求解；② **一致性任务**：**关系闭合算子**用"除自身外的全部通道"预测每个通道（目标自身轨迹被扣除），用**稀疏带符号门**决定真正用到哪些同伴；③ 两个分数只通过在正常数据上的**校准**来调和，不混入同一损失。
- **主要结果**：在公开基准流上，CLOSURE **一致优于**近期基于重构、频域、拓扑的检测器，印证"在可恢复性之外同时检查一致性"的价值。
- **值得追问 / 局限**：① "一致性任务"依赖稀疏带符号门选出的同伴集合，在**高维、强耦合或关系本身随工况漂移**的系统里，门的稳定性与"正常关系"的定义都更难，需看门在工况切换下的误报；② 摘要只给"一致优于"的定性结论，缺具体数据集 F1/AUC 表与阈值/校准敏感性，落地到真实告警前要看清一致性分数对正常漂移的鲁棒性。

## C. Agent / 机制（"把模型从正确答案说服走"的因果解剖：位置>信道 / 含噪线性 RNN 学习动力学的可解析理论，取 2 篇）

### 5. Position Matters More Than Channel: Talking a Language Model Out of a Correct Answer
- 链接：https://arxiv.org/abs/2610.34809
- 作者：Xinyi Ni（1 位；cs.CL）
- **TL;DR**：语言模型如今要在"系统提示里的旁注、其它 agent 的消息、自己先前的回答"等并列断言中作答；本文**把三类此前被混在一起变动的因素拆开**——建议**放在 prompt 哪里（位置）**、说是**谁写的（信道/权威）**、模型**已经写了什么**——系统地问"要把一个它本来答对的题说服成答错，需要什么"。
- **解决什么问题 / 为什么重要**：命中 C 的**机制/现象分析（优先类）**，而非 prompt 技巧——它做的是干净的**因子分离实验**，回答"谄媚/被诱导"到底受什么支配。核心反直觉结论：**位置远比 API 信道重要**，且对"裸断言"与"带（错误）论证的断言"方向相反。对做 agent 记忆/多轮上下文的你，这给出一个可操作先验：危险不在"谁说的 channel"，而在**建议相对问题/答案的摆放位置**，以及模型**是否已先写下正确推理**。
- **核心方法**：① 在 Qwen3.5-27B + MMLU-Pro 四选一上，每次对照**只变一个因素**、其余建议文本固定；② 分离位置（系统 vs 用户、问题前 vs 答案前）、权威署名（权威 vs 普通参与者、断言式措辞）、以及"先重放一段正确作答"三者的独立效应；③ 位置结论在**独立改写的 prompt** 上复现。
- **主要结果**：**裸"答案是 X"在模型作答前最有害**；而**同一断言配假论证则在问题前最有害**，把模型几乎从不做错的题错误率从 **1% 抬到 67%**；同位置下在系统/用户消息间移动只改几个点；署名权威/断言式措辞各抬高错误 **10–27 点**，但两种权威彼此差不到 2 点；**先重放一段正确作答**无论标为"模型自己的"还是"别人的"都能保护正确答案，同样的重放也让裸正确提示**改不动**已有的错答。
- **值得追问 / 局限**：① 结论基于**单模型（Qwen3.5-27B）+ 四选一选择题**，开放式生成里的谄媚/诱导是否同样"位置 > 信道"仍需验证；② "重放正确作答可保护答案"很诱人，但这也意味着**先写下错误推理会被同样锁定**——该机制是双刃的，用于 agent 自一致性设计前要量化它对错误的固化。

### 6. A theory of noisy linear recurrent neural network learning dynamics
- 链接：https://arxiv.org/abs/2610.35785
- 作者：John J. Vastola, Kanaka Rajan（2 位；cs.LG，兼 q-bio.NC）
- **TL;DR**：生物神经网络本身有噪声（不止混沌，还来自各种底层生物物理过程），但**内生噪声对"学习/表征"的理论后果**仍不清楚；本文用一个**可解析**的含噪线性 RNN 模型（线性激活 + 白噪声输入）论证：内生噪声能**强烈打破解空间简并**，在某些情形下甚至决定**非简并解是否存在**。
- **解决什么问题 / 为什么重要**：命中 C 的**训练动态 + 表征几何（优先类）**，且跨到 q-bio.NC、与你的脑信号主线同源。它把"噪声是不是只是讨厌的干扰"这一问题正面回答为"**噪声是表征的根本决定因素之一**"：在富（rich）区（小初始化权重）下，噪声强烈调制 read-in/readout/recurrent 三类权重的**对齐方向**；并给出一个**相变**——噪声足够大时，若参数尺度受限（如正则），非简并解甚至不再是最优。这对理解"带噪动力系统里表征怎么长出来"有直接的几何启发。
- **核心方法**：① 可解析的含噪线性 RNN 学习模型（线性激活、白噪声输入），推导学习动力学闭式结构；② 聚焦**富区**（小初始化）分析噪声如何调制 read-in / readout / recurrent 权重的对齐方向；③ 刻画一个由噪声强度与参数尺度（正则）共同触发的**相变**——高噪声下非简并解不再最优。
- **主要结果**：在富区，**噪声强烈调制三类权重的对齐方向**（即决定学到什么表征）；存在**相变**：噪声足够高且参数尺度受限时，非简并解甚至不是最优；结论扩展了近期关于 RNN 表征学习的解析工作，表明噪声可作为表征的**基本决定因素**。
- **值得追问 / 局限**：① 结论建立在**线性激活 + 白噪声**的可解析简化上，非线性 RNN / 结构化（时间相关）噪声下"噪声打破简并、触发相变"是否保持，是最该追问的推广性问题；② "富区"结论对初始化尺度敏感，惰性（lazy）区或大初始化下噪声的作用可能完全不同，需与经验训练对照。
