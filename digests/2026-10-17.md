## A. 核心方法（时序图早筛 / 概念瓶颈的内生可解释，取 2 篇）

### 1. GraphBEAT: Graph-based Bucketized Event Aggregation Over Time for Early Risk Stratification of Gastrointestinal Cancers
- 链接：https://arxiv.org/abs/2610.22014
- 作者：Leo Y. Li-Han, Chris Varghese, Elizabeth B. Habermann, Mark J. Truty, William R. G. Perry, Cornelius A. Thiels 等（7 位；cs.LG，兼 cs.AI / eess.SP）
- **TL;DR**：纵向电子病历（EHR）不规则、稀疏、异质且记录不全，难以建模；**GraphBEAT** 把临床事件按时间分桶、将观测特征转成**患者专属、时间有向的图**（每个节点编码特征身份、观测值与时间位置），配时间衰减的上下文消息传递 + 多头注意力池化做患者级表征，用于消化道癌症的早期风险分层。
- **解决什么问题 / 为什么重要**：命中 A 的**时序图表征学习 + 不规则采样时间序列**。它把"不规则/稀疏/异质"的纵向 EHR 这一经典痛点，用"时间分桶 + 桶间时间衰减消息传递"的时序图结构直接消化——相比把病历拉平成序列喂给 Transformer/LSTM，图结构更自然地表达"同一时间窗内多源事件 + 跨窗转移"，且参数与算力极省，对临床场景的可部署性是实打实的加分。
- **核心方法**：① 将临床事件分到时间桶，构造患者专属的时间有向图，节点编码（特征身份、观测值、时间位置）；② **上下文感知、时间衰减的消息传递**建模相邻桶之间的转移；③ 多头注意力池化聚合成患者级表征；④ 在多中心纵向诊断码 + 实验室检查上训练，预测胰腺癌、肝癌、肠癌在 12/24/36 个月的诊断提前期。
- **主要结果**：在全部实验设置下稳定优于图基线（GraphSAGE / GAT / GCN）与序列基线（Transformer / LSTM）；相比 Transformer/LSTM，**每位患者浮点运算量少 250 倍以上、参数量少 20 倍以上**。
- **值得追问 / 局限**：① 以准确率 + 计算量为卖点，但摘要未给具体 AUROC/AUPRC 与跨站点泛化数字，提前期越长（36 月）越依赖弱信号，实际早筛收益需看正文；② "时间分桶"的桶粒度是关键超参，桶过粗会抹平时序、过细则重新遇到稀疏问题，分桶策略对不同癌种/站点的敏感性未交代。

### 2. Harmful Partial Interventions and Benign Leakage in Concept-based Models
- 链接：https://arxiv.org/abs/2610.21750
- 作者：Gregory Verghese, Christopher J. Soelistyo, Mateo Espinosa Zarlenga, Alessandro Barp, Christopher R. S. Banerji（5 位；cs.LG，兼 cs.AI）
- **TL;DR**：概念瓶颈类模型（CMs）允许人检查并干预中间的"人类可理解概念"，但干预有时反而**恶化**下游预测（作者形式化为 intervention harm）；本文证明此前提出的"充分性 + 局部性"两条件**并不足以**保证干预有益，尤其在更贴近实际的**部分干预**下，并给出一个直接惩罚"沿部分干预轨迹任务损失上升"的**单调干预目标**。
- **解决什么问题 / 为什么重要**：正中 A 的横切重点**内生/自解释可解释性（concept-based / 内生可解释）**。概念瓶颈是"内生可解释"的代表范式，而"人去纠正一个概念、模型却更错了"直接动摇其可用性前提。本文把"概念泄漏（leakage）何时良性"从直觉判断推进到**可证伪的理论 + 可训练的缓解目标**，对任何想靠概念干预做人机协同监督的高风险部署都有直接意义。
- **核心方法**：① 区分"所有概念都被干预后的端点 harm"与"部分干预下的 harm"（后者是现实用例）；② 证明已有的充分性 + 局部性条件**不足以**保证干预改善下游性能；③ 实证发现**概念监督不完整**与干预 harm 升高相关；④ 指出此前的"全干预优化"缓解目标能降端点 harm 但**不能可靠防住部分纠正的 harm**；⑤ 引入**单调干预目标**直接惩罚部分干预轨迹上任务损失的上升，与端点目标联合训练。
- **主要结果**：端点目标 + 单调干预目标联合训练，在受控与真实设置下**大幅降低部分干预 harm 的发生率与幅度**，同时保持概念与任务预测性能。
- **值得追问 / 局限**：① 单调干预目标需沿"部分干预轨迹"施加惩罚，训练开销与对干预顺序/子集采样的依赖未量化，大概念集下轨迹空间组合爆炸如何近似值得追问；② "概念监督不完整 ↔ 干预 harm"是相关性结论，补全概念标注在现实高风险领域代价高昂，何种最小标注即可把 harm 压到可接受区间尚无操作准则。

## B. 应用场景（想象言语 EEG-文本对齐 / 可迁移脑常模，取 2 篇）

### 3. Semantic Alignment of EEG and Text: A Contrastive Learning Framework for Decoding Imagined Speech
- 链接：https://arxiv.org/abs/2610.20766
- 作者：Shahryar G. Namdari, Francesco Iacomi, Riccardo Barbieri, Luca Mainardi（4 位；cs.LG，兼 q-bio.NC）
- **TL;DR**：传统想象言语 EEG 解码把语义类别当成互相独立的标签、不利用意图之间的语言学关系；本文把 EEG 试次与**冻结预训练文本编码器**的语言表征在嵌入空间对齐，用"语义重加权的 EEG-句子对齐 + 文本原型类判别"的复合目标训练 EEG 编码器，在保持 39 类可分的同时注入语义结构。
- **解决什么问题 / 为什么重要**：贴近你的**脑功能/脑信号解码主线（fNIRS 的近亲：同属无创神经时间序列解码）**。它把 BCI 解码从"闭集分类"推向"与语言嵌入空间对齐"，从而支持**基于相似度的检索、对未见候选句的泛化、以及内生的可靠性排序**——"用冻结语言空间做锚、让神经信号对齐"的思路可直接迁移到 fNIRS 等其它神经时间序列。
- **核心方法**：① EEG 编码器把试次映射到冻结文本编码器的嵌入空间；② 复合目标 = 语义重加权的 EEG-句子对齐 + 基于文本原型的类判别（保留 39 类意图的可分性）；③ 提出 **MaxCosine**（EEG-文本最大余弦相似度）作为内生的解码可靠性指标；④ 用 5 个评测期语义轴 + 定性"语义画廊探针（SGP）"在类标签之外探查语义结构。
- **主要结果**：在 Chisco 想象言语数据集 5 名被试上，解码性能**与任务专用闭集分类器相当**，同时把 EEG 映进冻结语言空间；MaxCosine 能挑出 Top-1/Top-5 更高的留出试次子集；5 个语义轴上平均一致性均高于 50% 随机基线。
- **值得追问 / 局限**：① 只在 Chisco 单数据集、5 名被试上评估，跨被试/跨数据集的域偏移与小样本稳健性未知，想象言语 EEG 信噪比本就低；② "与闭集分类器相当"意味着对齐范式**尚未带来准确率净增**，其价值主要体现在检索/可靠性排序等灵活性上，纯识别任务是否值得换范式需权衡。

### 4. Transferable conditional brain charts link cortico-subcortical structure to Alzheimer's disease progression
- 链接：https://arxiv.org/abs/2610.21660
- 作者：Nitin Sharma, Sicheng Dai, Francesco A. Mallus, Atharva Kand, Marc Lemnitzer, Minh-Hieu Nguyen 等（32 位；q-bio.NC）
- **TL;DR**：脑常模（normative model）把每个个体表达为相对健康参照的偏差，但多数皮层厚度区域模型**忽略皮层与皮层下结构的依赖**、且跨站点迁移往往要重训；本文把皮层厚度的终身常模**条件化于皮层下体积**，并通过只重拟合极少量健康样本的分布参数截距实现**免重训迁移**。
- **解决什么问题 / 为什么重要**：命中 B 的**neuroimaging / 脑网络**，且解决两个真实痛点——结构耦合建模缺失与跨站点可迁移性差。它把"给定皮层下解剖、你的皮层是否落在健康区间"这种**结构耦合的个体化偏差**做成临床可用信号，并用开源包 NormGAMLSS 以约 20 个健康个体即可校准新站点，对多中心神经影像研究的落地价值很高。
- **核心方法**：① 将皮层厚度终身常模**条件化于 10 个皮层下结构体积**，偏差表示"给定皮层下解剖后皮层是否在健康范围"；② 迁移时只在约 20 个健康个体上**重拟合四个分布参数的截距**（位置+尺度+形状），无需重训，基模型与条件模型皆适用（开源 NormGAMLSS）；③ 在 ADNI 上用全局偏差 + 结构解离（条件化带来的平均绝对偏差下降）预测向 MCI/痴呆的转化。
- **主要结果**：21,351 名健康个体、216 站点上，条件化于皮层下结构平均改善样本外预测（**杏仁核、海马最明显**）；仅重拟合截距即校准了 6 个未见站点中的大多数；ADNI 中全局偏差与结构解离能在 CDR 之外预测转化，**解离在痴呆上带来超越全局偏差的增量**。
- **值得追问 / 局限**：① 条件化与迁移均在"健康参照"上定义与校准，对站点间扫描协议/设备差异极端时，仅调截距是否够用需更广验证；② 结构解离作为新信号其临床增量虽显著，但相对已有生物标志物（如 tau/Aβ、海马体积本身）的增量价值与可解释性仍需对照确认。

### 5. Language Models Share a Readout Bottleneck in Working Memory
- 链接：https://arxiv.org/abs/2610.21176
- 作者：Dongyu Gong（1 位；cs.LG，兼 cs.AI / cs.CL / q-bio.NC）
- **TL;DR**：LLM 在 N-back 任务上复现人类工作记忆特征（随记忆负荷 N 上升性能下降、错误集中在"诱饵 lure"上）；本文追问这是否源于共享机制，用 15 个预训练 LLM（三族、7000 万–140 亿参数）+ 从零训练的极简 transformer，把"**精度（定位不准）**"与"**干扰（读出被竞争项污染）**"两种解释**机制层面分离**。
- **解决什么问题 / 为什么重要**：正中 C 的**机制/现象分析 + 表征几何（优先类）**，而非 prompt 技巧。它不止描述"LLM 像人一样会错"，而是用因果探针定位到瓶颈本质：**注意力其实找对了目标，错在干扰下的读出**。这对理解 LLM 的记忆容量极限、以及"为何更大模型把任务摊到更多头上"给出了可操作的机制图景，也为人类工作记忆的"干扰说"提供跨系统证据。
- **核心方法**：① 在三族 LLM 中，承载任务的注意力头在多数漏配时仍**注意到目标**；② 线性探针近乎完美地解码"匹配字母出现在目标位还是诱饵位"——即便在模型误报诱饵的试次上也如此（而模型自身的决策几乎分不清两者）；③ **锐化注意力几乎无增益**，而**抑制非目标项的字母身份（去干扰）**在几乎所有"模型×负荷"条件下提升敏感度 d′；④ 极简 transformer 中单层受精度所限、加第二层即解除该约束。
- **主要结果**：三族模型里，注意力定位正确但读出被干扰污染；去干扰普遍提升 d′、锐化注意力收益可忽略；更大模型任务摊到更多头、去干扰收益更大——结论是**工作记忆极限在"干扰下的读出"而非定位**，与人类工作记忆的干扰说一致。
- **值得追问 / 局限**：① 结论基于 N-back 这一受控任务，是否推广到真实长上下文/多跳记忆任务（干扰来源更复杂）需验证；② "抑制非目标字母身份"是机制验证式干预，如何在不损害正常语言建模的前提下把"去干扰"做成可用的推理期增强，仍是开放工程问题。

### 6. Lexical Reference Frames: Interpreting LM Residual Streams in Native Semantics
- 链接：https://arxiv.org/abs/2610.22169
- 作者：Jian Gu, Hongyu Zhang, Chunyang Chen, Aldeida Aleti（4 位；cs.CL，兼 cs.LG）
- **TL;DR**：语言模型的词表是其"原生语义"，embedding 与 unembedding 固定了 residual stream 两端状态的含义；现有方法要么用固定 logit lens、要么把隐状态当点云，都**不按模型自己的方式读取状态**。本文提出每个隐状态有一个由"接下来读它的那些层"诱导的**原生参照系**，用 **Lexical Reference Frames** 近似它——即用模型自身的剩余层来读状态。
- **解决什么问题 / 为什么重要**：命中 C 的**residual stream / 表征几何 + 内生可解释（优先类机制分析）**。它给出一个理论上限论证——**任何固定方向的 lens 其相干度都不超过原生参照系相干度的平方根**，从而系统性地解释了 logit lens 一类方法为何读不准，并给出一个逼近原生参照系、无需拟合模型输出的读法，让隐状态同时变得**可读、可归因、可操控**。
- **核心方法**：① 定义隐状态的**原生参照系**：由"接下来读取该状态的层"诱导、随上下文自适应；② **LexFrame** 用模型自身剩余层读状态（指定若干轮跨位置注意力 + 其余用典型注意力输出近似），不拟合模型输出；③ 理论证明固定方向 lens 相干度 ≤ 原生参照系相干度的平方根；④ 用其系数做归因、用其词表基做"只改目标 token 而不动其它"的操控、用其高置信读数做早退（early exit）。
- **主要结果**：中深度下固定 lens 相干度上界为 0.30/0.35（SmolLM3-3B / OLMo3-7B），而一阶参照系 **LexFrame[1] 达 0.97/0.97**、读数距模型输出仅 0.16 nats；其系数归因比 attribution patching 更忠实、词表基操控能定向改预测而不伤其它 token、高置信读数可让早退**跳过 0.45 / 0.42 的层**（lens 几乎跳不了）。
- **值得追问 / 局限**：① 方法需"用模型自身剩余层重跑"，相比一次性 logit lens 的计算开销更高，大模型上做逐状态读取的实用成本未量化；② 实验在 SmolLM3-3B / OLMo3-7B 两个中小模型上，"原生参照系"在更大模型、更深层处的相干度是否仍压倒固定 lens，以及早退跳层比例能否维持，需进一步验证。
