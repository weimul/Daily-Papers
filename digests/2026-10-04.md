## A. 核心方法

### 1. Spatio-temporal coarse-grained Hawkes processes
- 链接：https://arxiv.org/abs/2610.01151 （stat.ME，2026-10-01）
- 作者：Tomoya Uda, Shinsuke Koyama（共 2 位）
- **TL;DR**：时空 Hawkes 自激过程常规推断要求知道每个事件的精确时间与位置，但很多场景只拿得到"按时间区间 + 空间区域聚合后的计数"；本文提出一个离散时间计数模型，直接对聚合计数建模，且显式计入"同一时间窗内发生的自激"。
- **解决什么问题 / 为什么重要**：现实的事件流/点过程数据（地震、监控告警、交通事件）常以分箱计数形式出现，引入潜在事件时刻会很贵；把粗粒化做成有理论保证的逼近，正切中"事件流/时间点过程"这一核心方向，并给出一条比朴素分箱 Poisson 更准的聚合推断路线。
- **核心方法**：通过在时空分箱上对时间与空间触发效应取平均构造"有效激发核"，同时显式纳入同一时间箱内的激发项；刻画过程的一、二阶性质，并在时空离散同时趋细的联合极限下推导平稳均值与自协方差相对于对应聚合 Hawkes 过程的渐近逼近误差。
- **主要结果**：理论证明该模型因计入箱内自激而比传统分箱 Poisson 逼近阶数更高；数值实验在大范围聚合尺度上确认了理论；进一步给出基于矩的估计流程，并用聚合版 ETAS 模型应用于地震发生数据，作为从时空聚合事件数据做推断/预测的高效替代方案。
- **值得追问 / 局限**：(1) 逼近误差分析建立在"时空分箱趋细"的联合极限上，在实际较粗的聚合尺度（监控按分钟/区域聚合）下 bias 是否仍可控？(2) 矩估计相比似然/变分推断在高维空间网格、强非平稳触发核下的统计效率与可扩展性如何。

### 2. ProtoFlow: Prototype-Guided Flow Matching for Multivariate Time Series Forecasting
- 链接：https://arxiv.org/abs/2610.01320 （cs.AI，2026-10-01）
- 作者：Shibo Feng, Wanjin Feng, Yang Qiu, Deheng Ye, Peilin Zhao, Chunyan Miao（共 6 位）
- **TL;DR**：VQ 类非自回归时序预测靠离散 token 的自回归生成，受暴露偏差与训练-推断不匹配之苦；ProtoFlow 观察到"训练好的 VQ 码本本身就是一组有代表性的潜在原型"，用它当 flow matching 的结构化先验，取代通用高斯噪声初始化。
- **解决什么问题 / 为什么重要**：既要生成式 MTS 预测的高维表达力，又要避开扩散的多步采样和 AR token 的 rollout 失配；用"学到的原型先验"引导输运，兼顾效率与质量，而"码本原型"这一设计也带有内生可解释（prototype-based）的横切味道。
- **核心方法**：先把多元序列映射到离散潜空间（VQ 自编码），再用学到的码本构造结构化先验，最后训练一个基于 DiT 的 rectified flow，在历史观测条件下把样本从该原型先验输运到未来潜表示；以原型先验替换通用噪声初始化，规避 AR token 预测的 rollout 失配并加速训练收敛。
- **主要结果**：在多个基准数据集上，预测性能持续优于对照，同时保持高效推断（相对扩散的多步采样）。
- **值得追问 / 局限**：(1) "码本原型"是否真能作为可被人读懂的预测模式单元，还是仅作为更好的数值先验——其可解释性宣称需要可视化/归因验证；(2) VQ 码本的容量与崩塌问题在高维、强非平稳 MTS 下是否会反过来限制原型先验的覆盖面。

## B. 应用场景

### 3. Information Bottleneck-Guided Adaptive Hypergraph Transformer for Brain Disease Diagnosis
- 链接：https://arxiv.org/abs/2609.37220 （cs.AI，2026-09-29）
- 作者：Jingxi Feng, Xudong Chen, Yifan Zhang, Heming Xu, Hongcheng Han, Xijing Wang 等（共 8 位）
- **TL;DR**：脑网络诊断既要高阶相关（超图）又要长程依赖（Transformer），但二者缺乏统一整合且信息冗余严重；IBAHGT 用信息瓶颈原则在统一框架内自适应学习高阶与长/短程依赖，做高精度脑疾病诊断并抽生物标志物。
- **解决什么问题 / 为什么重要**：直接把"脑网络 + 高阶超图 + 长程依赖 + 信息瓶颈去冗余"整合，既对口 B 方向的 neuroimaging / brain network 应用，又带强内生可解释（IB 做 MIMR 去冗余 + 可定位生物标志物）的横切重点，对我方向双重命中。
- **核心方法**：三组件——(i) IB 引导的自适应超图卷积，提出超图信息瓶颈（HIB）原则自适应学习节点-超边的消息传递权重，捕获"最大信息、最小冗余"（MIMR）的高阶信息；(ii) Transformer 编码器用注意力建模短/长程全局依赖；(iii) IB 引导的节点级自适应融合，为每个节点学独立权重，细粒度整合高阶与全局信息得到下游高效表示。
- **主要结果**：在脑疾病诊断上超过当前 SOTA，并能识别可用于临床的生物标志物。
- **值得追问 / 局限**：(1) HIB 的"最小冗余"目标抽出的生物标志物是否经神经科学验证（可读≠因果相关）？(2) 超图构造（超边定义）对结果敏感度，以及在样本量有限的小规模临床数据集上 IB 约束是否会过度压缩掉罕见但关键的病理模式。

### 4. Have an LLM Write Your Anomaly Detector: Autonomous Discovery of Compact, Interpretable Detectors for Time Series
- 链接：https://arxiv.org/abs/2610.01223 （cs.LG，2026-10-01）
- 作者：David Berghaus（共 1 位）
- **TL;DR**：时序异常检测要在准确率、算力、可解释性间取舍；本文让 LLM 不当检测器，而当"检测器的作者"——在无泄漏目标下反复编辑一段短 NumPy 程序，保留得分最高者，自动搜出紧凑可读的检测器。
- **解决什么问题 / 为什么重要**：把"用 LLM 做 AD"从"LLM 直接打分"转为"LLM 做程序搜索产出白盒检测器"，兼得准确、高效、透明，直接对口监控告警/AIOps，且不训网络、不用 GPU，部署与可审计性强。
- **核心方法**：自主研究循环，在无泄漏（leakage-free）目标函数下迭代改写单个短 NumPy 程序；搜出两个紧凑检测器（单变量、多变量各一），均用"短窗口的局部谱特征 + 协方差感知距离"与训练区分布比较。
- **主要结果**：在 TSB-AD 基准上，两个检测器跨指标领先，超过最强的经典、深度与基础模型基线（含 Time-RCD），却完全不训网络、不用 GPU；多变量检测器比所有性能相近基线更快。
- **值得追问 / 局限**：(1) "无泄漏目标 + 保留最优"的搜索是否在基准上过拟合搜索目标，换到真实运维分布漂移时谱特征检测器的鲁棒性如何？(2) 程序由 LLM 生成虽可读，但其发现过程对 LLM 先验/训练数据的依赖，以及能否泛化到带复杂季节性/多源告警的工业多元序列。

## C. Agent / 机制分析

### 5. Beyond Memory: Harnessing Long-Horizon Agents with Explicit Belief States
- 链接：https://arxiv.org/abs/2610.01415 （cs.AI，2026-10-01）
- 作者：Yu Luo, Jiamin Jiang, Yimin Zuo, Xidao Wen, Rongchen Gao, Yongqian Sun 等（共 12 位）
- **TL;DR**：LLM agent 把交互历史组织成记忆，但这不保证对"当前世界"的连贯理解；PoS 在推断期构造并持续维护显式信念状态作为决策上下文，把 agent"还需知道/完成什么"显式化。
- **解决什么问题 / 为什么重要**：长程任务里纯靠历史保留/压缩的记忆会失去对世界状态的连贯把握；用显式信念（当前世界状态估计 + 未解决任务需求）替代堆叠记忆，属 C 方向偏好的"memory / planning + 机制"优先类，且与诊断类任务（含运维故障诊断）结合紧密。
- **核心方法**：每条信念结合"当前世界状态估计"与"未解决任务需求"；PoS 校验信念一致性、监控任务进度以检测 Belief Trapping（agent 持续行动却无实质进展），并针对陷阱模式与未解决需求类型定制化恢复策略。
- **主要结果**：在覆盖执行与诊断的四个基准、三种 LLM 后端上均取得最高综合性能；消融证明一致性校验与恢复的重要性，上下文缩放实验显示对上下文增长的鲁棒性。
- **值得追问 / 局限**：(1) 信念状态的构造/校验本身由 LLM 完成，信念错误（幻觉的世界状态）如何被独立检测而非自证？(2) "Belief Trapping"检测依赖进度度量，在开放式、无明确进度信号的任务上是否仍可靠。

### 6. Rules Amortize, Pairings Don't: Linguistic Structure Determines What Latent Task Representations Can Replace In-Context Learning
- 链接：https://arxiv.org/abs/2610.00526 （cs.CL，2026-09-30）
- 作者：Gunmay Jhingran（共 1 位）
- **TL;DR**：ICL 可被摊销成潜在对象（task/function/context vector）以零样本成本复现 few-shot 行为，但静态向量只相当于"一个合成示例"，在高秩映射上必然失败；本文问一个语言学版本的问题——哪些语言操作能被摊销出 prompt。
- **解决什么问题 / 为什么重要**：把"潜 task 表征能否替代 ICL"从笼统结论细化为"取决于语言结构（规则 vs. 任意配对）"，并给出对 residual stream 做输入条件化更新的机制证据，属 C 方向"机制/现象分析 + 表征结构"优先类，直接触及 ICL 可替代性的边界。
- **核心方法**：训一个 2.6M 参数小网络，读取 few-shot 支撑集的几何（质心、主子空间、谱，一次算好并缓存），对冻结 GPT-2-large/XL 中层的 query residual stream 产生"输入条件化的加性更新"；在八个屈折方向 + 一个词汇关系上、用禁止反向配对泄漏的规范切分做评测。
- **主要结果**：出现三类 regime——(i) 前向屈折（ICL 强、抽出的 task vector 崩溃）下该变换以严格零样本单query成本追平 ICL；(ii) 词形还原方向（GPT-2 能做但 10 示例系统性传不进去，ICL 0.13–0.48）下变换不受 ICL 上限约束，达 0.78–0.92，最多 +72 分；(iii) 任意配对（反义）下所有摊销器在各规模/容量/种子下都卡在约 ICL 一半。对照显示支撑流形是因果必要的"任务指纹"（错任务流形把准确率压到 ≤0.06）。结论：能产的规则可摊销（有时比 prompt 传得更好），记忆型配对不能。
- **值得追问 / 局限**：(1) 结论建立在 GPT-2 规模与屈折/词形等结构化任务上，在更大模型、更复杂语义任务上"规则 vs. 配对"的二分是否仍清晰？(2) "支撑流形=任务指纹"是相关性证据还是因果充分——加性更新注入点（中层）的选择对结论敏感度如何。
