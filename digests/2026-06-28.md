## 1. LMs as Task-Specific Knowledge Bases: An Interpretability Analysis
- 链接：https://arxiv.org/abs/2606.27237
- 作者：Amit Elhelo, Amir Globerson, Mor Geva（Tel Aviv University / Google 一系）
- 方向：C（机制可解释 + 训练动态 + 参数定位，"优先"类现象分析）
- **TL;DR**：人们常把 LM 参数当成"知识库"，但知识库的一个核心性质是"同一事实、不同查询给一致答案、共享单一真值源"。本文用行为 + 机制双重分析表明：LM 其实是**按任务（task-specific）分散存储**事实的——同一事实在不同任务上并不共享同一份参数。
- **解决什么 / 为什么重要**：直击我关心的"表征 / 知识在网络里到底怎么组织、训练中怎么涌现"这条机制线。它给"参数即知识库"这个流行隐喻打了个问号：知识不是集中、可一致检索的，而是被任务上下文切碎、定位在不同参数子集里——这对理解 LM 表征几何、知识编辑的可迁移性、以及 CoT 为何有效都有直接含义。
- **核心方法**：(1) 行为分析——观察训练过程中，在某一任务上习得的事实是否会在其它任务上**同步涌现**（co-emerge）；(2) 参数定位实验——为"同一事实的不同任务"分别定位负责的参数子集，看是否重叠；(3) 把上述视角用于解释 chain-of-thought：检验 CoT 的有效性是否部分来自"调动了评测任务本身之外的任务专属参数"。
- **主要结果**：行为上，一个任务上获得的事实**经常不会**在其它任务上一并出现；参数定位显示同一事实在不同任务下由**不同参数子集**支撑（机制层面的解释）；CoT 的部分增益来自它能额外激活这些任务专属参数。
- **追问 / 局限**：(1) "参数定位"方法本身的因果强度——定位到的子集是相关还是充分必要，换一种定位 / 剪除手段结论是否稳健，值得追问。(2) 结论若成立，对"知识编辑改一处即可全局生效"这类假设是坏消息；这种任务碎片化在多大模型尺度 / 多自然的预训练分布下依然成立，需要进一步验证。

## 2. Beyond the Hard Budget: Sparsity Regularizers for More Interpretable Top-k Sparse Autoencoders
- 链接：https://arxiv.org/abs/2606.27321
- 作者：Nathanaël Jacquier, Maria Vakalopoulou, Mahdi S. Hosseini（CentraleSupélec / Concordia 一系）
- 方向：C（机制可解释 / SAE 方法改进，"优先"类——直接关乎"单义特征"的质量）
- **TL;DR**：Top-k SAE 现在是把基础模型多义（polysemantic）激活拆成稀疏单义特征的标准工具，但它的硬预算 $k$ 对所有输入一刀切、且容易过拟合到训练时的 $k$。作者提出**两个与 Top-k 架构兼容的稀疏正则项**（作用在 Top-k 选择之前的激活上），让稀疏度能随输入复杂度自适应。
- **解决什么 / 为什么重要**：SAE 是我这条"内生 / 自解释 + 信息瓶颈"横切线在大模型上的主力抓手，而 Top-k 的"固定预算"恰是它最被诟病的限制之一。本文不是又训一套 SAE，而是回到**稀疏性建模本身**——把"该用多少个特征"从超参变成数据自适应量，直指单义性与可解释性的根。视觉基础模型上的设定也提示这套方法不限于语言模型。
- **核心方法**：在标准 Top-k SAE 上，对 Top-k 选择**之前**的激活施加两类稀疏正则：其一是对"未被选中"潜变量的 $\ell_1$ 惩罚（在保留 Top-k 避免 $\ell_1$ 经典缺陷的同时，重新引入软稀疏压力），其二为另一种与之配套的正则形式；目标是缓解固定 $k$ 与对训练 $k$ 过拟合的问题，使每个输入按其复杂度激活合适数量的特征。
- **主要结果**：在视觉基础模型表征上，所提正则化的 Top-k SAE 相比原始 Top-k 在稀疏–保真权衡与特征可解释性上有改善，并降低了对训练时 $k$ 取值的敏感度（具体指标以原文为准）。
- **追问 / 局限**：(1) 评测落在视觉基础模型上，迁到语言模型残差流（我更关心的站点）后，"自适应稀疏"带来的单义性增益是否一致、有没有新的崩塌模式，值得追问。(2) 新增正则引入额外超参，"用自适应稀疏换掉固定 $k$"是否只是把调参负担换了个地方，需要看其稳健性。
