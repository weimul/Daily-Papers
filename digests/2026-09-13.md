## A. 核心方法（时空图 / 图学习 / 连续计算）

### 1. A Dataset and Model for Imputing Water Surface Elevation on a Large and Extremely Sparse Spatiotemporal Graph
- 链接：https://arxiv.org/abs/2609.11580
- 作者：Ruben Cartuyvels, Karim Douch, Gabriele Bertoli, Mounia El Baz, Artemis Vrettou, Sébastien Lefèvre, Diego Fernandez Prieto（机构未在摘要页明确列出；数据源涉及 SWOT 卫星测高）
- **TL;DR**：把"用卫星测高监测河网水位"建成一个极端稀疏的时空图插补问题——发布覆盖亚马逊流域、逾 1.9 万条河段、跨越十年的 AmazonSWE 数据集，并用带拓扑感知位置编码的选择性状态空间模型（selective SSM）做插补。
- **解决什么问题 / 为什么重要**：每天被观测到的河段不足 1%，比现有插补基准稀疏得多；这正是"不规则/稀疏采样的时空信号"在真实地理网络上的硬样本。它同时命中"时空图 GNN"与"不规则采样时序"两条核心线，且给出可复用的公开基准（含 SWOT 传感器数据），对 ST-GNN / 图上插补研究是稀缺的稀疏场景试金石。
- **核心方法**：将河网组织为图，节点为河段；用选择性状态空间模型沿时序建模，配合拓扑感知的位置编码注入河网结构先验，在几乎全缺失的观测下对所有河段做水位插补，而非只覆盖被观测子集。
- **主要结果**：相对已有基于 SWOT 的方法，对照实测水位站（in-situ gauges）的 RMSE 降低约 18–39%，同时把预测扩展到全部河段。
- **值得追问 / 局限**：① SSM + 位置编码相对成熟 ST-GNN（如时空图卷积/图 Transformer）的消融对比、以及在如此稀疏观测下的不确定性刻画（覆盖率/校准）值得补齐；② 亚马逊流域的水文/拓扑先验能否零样本迁移到其它河网、乃至更一般的稀疏地理传感网。

### 2. Reification as a Transferable Vocabulary: Zero-Shot Link Prediction with Vanilla GNNs
- 链接：https://arxiv.org/abs/2609.11347
- 作者：Camille Pradel
- **TL;DR**：与其把知识图谱的"可迁移性"塞进专用架构，不如把它挪进表征——用图具体化（reification）把每条事实变成一个节点，经六种元关系连到主体/客体/关系类型，关系类型作为"匿名共享节点"而非模型参数，于是普通 GNN 也能零样本做链接预测。
- **解决什么问题 / 为什么重要**：知识图谱基础模型（如 ULTRA）通常靠特制架构 + 多图预训练获得跨图迁移；本文主张迁移能力可以完全由"输入表征的词汇表"承载，架构则退化为标准 GNN。这对"动态链接预测 / 图上归纳泛化"很有启发：把关系语义写进图结构，天然利于对未见关系/图的泛化。
- **核心方法**：对每个三元组做 reification，引入事实节点与六种元关系，关系类型建模为共享的匿名节点；在单个仅 4,245 条三元组的知识图上训练 5 种标准 GNN（GAT、两种 GINE 变体、GraphSAGE、R-GCN），单卡 A100 训练约 30 分钟，然后在 40 个归纳基准上零样本评测。
- **主要结果**：表现最好的 GAT 可与专门在三个图上预训练的基础模型 ULTRA 打平；方法还可延伸到关系型数据库，对外键预测给出初步结果；代码、checkpoint 与评测流程均开源。
- **值得追问 / 局限**：① "单个 4k 三元组小图训练即可匹配多图预训练的基础模型"这一结论的稳健性，需在更大/更异质的归纳基准与更强基线上复核；② reification 使图规模显著膨胀（每条事实多出一个节点与多条边），大规模知识图或时序知识图上的可扩展性与推理开销待评估。

### 3. When does a spectral prior help graph learning? Connectivity-loss estimation under road-network disruptions
- 链接：https://arxiv.org/abs/2609.11166
- 作者：Van-Truong Le
- **TL;DR**：在路网多边同时中断时，快速估计"相对代数连通性（algebraic connectivity）损失"需要在精确谱重算与局部近似之间折衷；本文让 GNN 学习一个对一阶 Fiedler 灵敏度的有界修正项，并系统回答"谱先验到底什么时候有用"。
- **解决什么问题 / 为什么重要**：多条道路同时失效的连通性评估是交通/基础设施韧性的典型问题，纯谱重算太贵、纯一阶近似不够准。本文把"谱先验"当作可插拔的归纳偏置来量化其收益/失效，对"在图学习里注入结构/物理先验"这一方法论问题给出难得的实证边界，也贴近路网这类时空图应用底座。
- **核心方法**：以一阶 Fiedler 灵敏度为解析先验，用 GNN（GCN、GraphSAGE、edge-aware MPNN）学一个有界残差修正；构造图不相交的合成划分，考察独立失效、空间聚集失效、边介数定向失效三种情形，并零样本迁移到六国 13 个 OpenStreetMap 区域，与解析基线对比。
- **主要结果**：在扩展 OSM 测试上，残差 GCN 把空间失效 MAE 改善 0.0391，残差 GraphSAGE 把定向失效 MAE 改善 0.0257；相较之下二阶扰动仅改善 0.0028–0.0053。留一国迁移（leave-one-country-out）结果不一：残差 GCN 在定向失效上改善 0.0622 但恶化空间点估计——说明谱残差是"有用但对域敏感"的先验；稀疏实现可扩到 2 万节点。
- **值得追问 / 局限**：① 收益量级偏小且随定向迁移出现"修正斜率收缩"，泛化到分布外路网时先验何时反而有害仍需刻画；② 只估"连通性损失"这一标量目标，能否推广到更丰富的时空图动态（流量、时延）尚不清楚。

### 4. Thinking with Looped Flows
- 链接：https://arxiv.org/abs/2609.11801
- 作者：Ayhan Suleymanzade, Chanhyuk Lee, Floor Eijkelboom, Nicholas M. Boffi, İsmail İlkan Ceylan, Jinwoo Kim（含 Oxford / CMU 等）
- **TL;DR**：循环（looped）模型靠反复更新隐藏态在推理时"多算多想"，但训练常只回传一两步梯度，早期更新学不到"为后续服务"；本文用局部去噪目标训练循环，把推理重构成对"学到的去噪器所参数化的概率流"做速度积分，从而以更细时间网格换更强推理。
- **解决什么问题 / 为什么重要**：这是"用连续/迭代计算换性能"的一条干净路线：把循环状态的时间关联通过"逐步降低噪声 + 共享噪声"的去噪目标显式建立，绕开长程反传难题。它同时贴近核心方向里的"连续时间/概率流建模"，也回应了近期对循环/潜空间推理机制的兴趣。
- **核心方法**：在递归的各步施加局部去噪目标，用逐步减小的噪声级与共享噪声施加时间关联，激励模型学到"能把有用计算跨步传递"的循环状态；推理时把过程写成对去噪器所定义概率流的速度积分（配合循环状态），可通过更细时间网格投入更多计算，并由不同初始噪声给出多个有效预测。
- **主要结果**：在六个推理基准（含两个多解基准）上整体优于既有 SOTA 循环模型，在 ARC-AGI-1 上达 58.8%、ARC-AGI-2 上达 12.2% 测试准确率。
- **值得追问 / 局限**：① "局部去噪 + 概率流"相对直接长程反传/深度监督的优势，主要在特定推理基准上体现，跨任务普适性与推理时的积分开销（细网格的算力-精度折衷）待系统评估；② 多解生成的质量-多样性权衡与校准如何量化尚不清晰。

## C. 机制与表征（Agent / 机制分析）

### 5. The information geometry of large language models is shared, learned, and controllable
- 链接：https://arxiv.org/abs/2609.11063
- 作者：Dario Picozzi
- **TL;DR**：用 Fisher–Rao 信息几何分析 LLM 的"下一 token 概率分布"，发现"行为决定这套几何（差一个保输出的对称性），而激活几何依赖坐标系"——即输出空间几何是跨架构共享、可迁移、且可用来做温和干预的。
- **解决什么问题 / 为什么重要**：不同 LLM 会习得相近能力，但其"共享结构"一直缺乏刻画。本文把度量放到输出概率流形（Fisher–Rao），给出一个坐标无关、跨 Transformer/状态空间/循环架构可比的几何对象，正落在"表征几何 / 机制分析"这一高优先级方向，并直接连到可控编辑与知识迁移。
- **核心方法**：以 Fisher–Rao 度量刻画 next-token 分布构成的流形；对比输出几何与激活几何在不同架构间的一致性；用几何引导的干预做受控修改，并检验"在 donor prompt 上学到的更新迁移到未见 prompt"的效果。
- **主要结果**：输出几何比激活几何在 Transformer/SSM/RNN 之间更一致；几何结构有助于语义知识迁移；与人类语言模式的吻合度随模型准确率、规模、训练时长上升；几何引导干预能在最小行为扰动下实现受控修改，且相较欧氏对照更好地保留参考 prompt 上的行为。
- **值得追问 / 局限**：① 结论多为跨模型的相关性/几何观测，"输出几何共享"能否落到可复用的编辑/对齐工具、其因果性需干预实验进一步坐实；② Fisher–Rao 计算在超大词表/超大模型上的可扩展性，以及"保输出对称性"在实际编辑中的边界。

### 6. Data Scarcity and Model Sparsity: Mixtures-of-Experts Overfit More to Repeated Data
- 链接：https://arxiv.org/abs/2609.11917
- 作者：Atindra Jha, Margaret Li, Jure Leskovec, Percy Liang, Luke Zettlemoyer（含 Stanford / University of Washington 等）
- **TL;DR**：高质量人写文本枯竭后，重复训练数据已成常态；本文系统证明——稀疏的 MoE 在数据重复下比稠密 Transformer 退化更快，且退化程度由"总参数量而非激活参数量"主导。
- **解决什么问题 / 为什么重要**：数据重复对稠密模型已有研究，但对当下主流的 MoE 稀疏架构几乎空白。这是"训练动态 + 稀疏性机制"的现象级分析：从 80M 到 1B 激活（8.5B 总）参数一致成立，直接关系到未来"数据受限时代"的架构选择与正则化设计。
- **核心方法**：在单域/多域数据混合、不同专家数与粒度下改变数据重复率，测量性能退化；实验多种正则化（如 dropout、强 masking 正则）作为缓解手段；并分析高重复区间与 MoE 过拟合相关的内部机制（路由是否稳定、专家专业化程度）。
- **主要结果**：80M 稠密模型可重复 8× 仍几乎不退化，MoE 在 4× 即开始受损、32× 后甚至落后稠密模型；稀疏度越高退化越重。强 masking 正则可让 MoE 在重复 64× 以上仍胜过稠密模型，但没有任何方法能追平"全新数据"训练。机制上：MoE 路由普遍在训练早期就稳定下来，且专家专业化程度与对重复数据的过拟合正相关。
- **值得追问 / 局限**：① "早期路由固化 + 专家专业化 → 记忆/过拟合"是相关性证据，破坏该结构（如延迟路由固化）能否因果性降低过拟合，值得干预实验；② 结论主要在 ≤1B 激活参数规模验证，是否外推到前沿规模 MoE、以及与数据配比/课程学习的交互仍待检验。
