## 1. TS-RAG: Retrieval Augmented Generation for Time Series Forecasting
- arXiv: https://arxiv.org/abs/2608.06223
- 作者：Yixiong Xiao, Congxi Xiao, Jingbo Zhou
- **TL;DR**：把 RAG 引入时序预测：检索与当前输入相似的历史序列作参考，但作者指出时序模型参数小、无 LLM 那种生成能力，"像语言模型那样把参考序列直接拼进 prompt"并不奏效，故设计专门的"参考 token"来融合输入序列与检索序列的信息。
- **解决什么问题 / 为什么重要**：属 A 方向"时序建模"这条线，落点是"检索增强在时序预测里到底该怎么接"。它与昨日报道的 Align-RAG（免训练的闭式对齐、主张冻结骨干本就能吸收上下文）恰好构成一组有意思的对照：TS-RAG 的立论是"简单拼接不够、需要可学的融合结构"，而 Align-RAG 走的是"无需可学参数的对齐"。两条路线并读，能更清楚地看到"检索上下文该由模型隐式利用，还是由显式模块融合"这一分歧。
- **核心方法**：在预测框架中引入检索模块取回相似"过去序列"，再用专门设计的参考 token 将输入序列与检索序列的信息融合，以更稳健地刻画复杂时间动态。
- **主要结果**：在多个真实世界预测基准上取得一致的 SOTA 表现。
- **值得追问 / 局限**：摘要未给检索库规模、检索开销与延迟的量化，也未说明与"训练式融合适配器 / 简单拼接基线"的差距分解；"参考 token 融合"相对昨日 Align-RAG 式免训练对齐在同基准上的胜负关系，需要正文/交叉实验才能定论。

## 2. Multivariate Time Series Forecasting needs Cross Variable Loss
- arXiv: https://arxiv.org/abs/2608.05742
- 作者：Kuiye Ding, Yifan Hu, Hanchen Wang, Hao Xue
- **TL;DR**：多变量预测里未来的变量常在共享系统动力学下"共同演化"，但主流的直接预测（DF）范式用逐点损失，不对未来值之间的跨变量结构加约束——存在"目标缺口"。作者提出即插即用的跨变量损失 CvLoss：在跨变量图上约束预测残差，惩罚 patch 上不一致的逐边残差差异，兼顾同步与异步交互。
- **解决什么问题 / 为什么重要**：正中 A 方向——它把"图结构"和"异步依赖"两个我关心的点接进了时序预测的损失设计。价值在于把问题从"改架构"转到"改目标函数"：既然逐点 DF 目标本身与跨变量/滞后依赖错配，就用一个跨变量图上的结构正则去补，且作为 plug-in 兼容多种预测骨干，代价低、可迁移。
- **核心方法**：构造跨变量图，在其上对预测残差施加结构正则；对 forecast patch 上"逐边残差差异"进行惩罚，鼓励跨变量在同步与异步（滞后）交互上的一致性；以插件形式挂到既有预测模型上。
- **主要结果**：一致地提升多个有竞争力的预测模型，优于代表性的学习目标，并与多种预测骨干兼容。
- **值得追问 / 局限**：摘要未给"跨变量图"如何构建（先验/数据驱动/可学）及其对结果的敏感性，也未量化在变量数很大时逐边正则的计算开销；"异步交互一致性"的收益在弱耦合/近独立变量场景是否仍成立，值得看消融。

## 3. D-CLOT: Double Closed Loop Optimal Transport for Unsupervised Action Segmentation
- arXiv: https://arxiv.org/abs/2608.05877
- 作者：Elena Bueno-Benito, Mariella Dimiccoli
- **TL;DR**：基于最优传输（OT）的无监督动作分割里，定义 OT 代价的"潜在动作原型"从不按精炼后的帧几何重新估计，只靠伪标签损失的梯度漂移。作者把这一"表示—原型不一致"点破为核心瓶颈，在 CLOT 基础上进一步用精炼后的帧嵌入重估原型，并加图约束保持局部邻域几何。
- **解决什么问题 / 为什么重要**：虽是视觉动作分割，但正踩我 A 方向的横切重点——**原型化表示 + 表征几何的自洽性**。它的观察具方法论普适性：当"表示在被精炼、原型却被钉死"时，模糊过渡段与短/罕见动作最受害；解法是让原型周期性地"重锚"到稳定后的表示几何上（k-means 版 vs. OT 重心版）。这套"表示与原型互相校准"的思路，对任何用原型/概念做内生自解释的时序模型都有借鉴意义。
- **核心方法**：在 CLOT（用估计的段嵌入精炼帧嵌入）之上，加一个图约束模块正则化 OT 精炼后的帧/段表示以保持编码器输出的局部邻域几何；再周期性地把原型重锚到该稳定表示——D-CLOT 用 k-means 更新原型，D-CLOT_B 用按精炼传输计划加权的 OT 重心更新（与当前传输几何一致的、可分配感知的原型更新）。
- **主要结果**：在五个基准上两种变体均优于 CLOT，单视频最高 +12.7 F1 / +10.2 mIoU（YTI）、活动级最高 +8.9 F1（FS-Eval）；并在更细粒度的 Assembly101 上建立首个无监督动作分割基线；消融显示两种精炼机制互补且稳健。
- **值得追问 / 局限**：为视觉/程序化动作域，迁到一般时序/事件流时"局部邻域几何"的定义与噪声鲁棒性需另证；原型重锚的周期与 OT 计算开销的折中、以及在类高度不均衡时重心更新的稳定性，摘要未展开。

## 4. The Illusion of Visual Tool-Use: A Causal Audit of Thinking with Images
- arXiv: https://arxiv.org/abs/2608.06270
- 作者：Zhiheng Wang, Bo Peng, Lai Wei, Chaochao Lu
- **TL;DR**："think-with-images"给多模态 LLM 配了裁剪-放大等主动视觉操作，但常常只带来边际甚至负收益、还徒增 token。作者把视觉工具使用建成因果图，区分"观测中介路径"与"动作诱导的捷径"，在 policy / trajectory / step 三个层级做干预审计，提出 step 级估计量 Visual Evidence Gain 来隔离每次返回观测的因果贡献。
- **解决什么问题 / 为什么重要**：属 C 方向"优先"里的机制/现象分析（明确不是 prompt 工程），是那种"发现反直觉现象并做严格因果对照"的工作。它给出两类失败模式——**Calling Without Looking**（返回的观测对答案无因果作用）与 **Looking Without Planning**（观测有信息量但调用时机不连贯），并指出总体准确率增益其实集中在少数"校准良好"的样本，从而把"视觉工具有效"证伪为一种幻觉。对做多模态 agent、工具调用与 planning 机制的人，这套"把工具使用当因果图来审计"的方法论很有迁移价值。
- **核心方法**：将视觉工具使用形式化为因果图；在三层级做干预——policy（工具使用 vs 直接推理）、trajectory（rollout 中破坏所有观测）、step（固定前缀下反事实替换单个观测）；用 Visual Evidence Gain 度量单次观测的因果贡献，并用 trajectory 级诊断分解 policy 级准确率增益。代码开源（OpenCausaLab/CauAudit）。
- **主要结果**：横跨六个代表模型、五个细粒度感知基准，普遍存在 policy 误校准；总体准确率增益集中在"校准的少数派"，多数 rollout 上视觉工具使用并非因果有效。
- **值得追问 / 局限**：结论建立在细粒度感知类基准上，能否外推到需要多步视觉推理/长程规划的任务待验证；Visual Evidence Gain 依赖反事实替换观测，其对替换构造方式的敏感性、以及"如何据此改进调用策略/训练"而不止于诊断，值得追问。

## 5. Comparative Approaches to Agent Retrieval over Large Skill Libraries
- arXiv: https://arxiv.org/abs/2608.06196
- 作者：Indivara Kolluru, Nathan Sportsman
- **TL;DR**：当 agent 背靠大技能库时，得决定加载哪些技能、以何顺序加载。作者在 690 个技能的语料上对比两套系统——词法+稠密检索的混合 ranker（稀疏按需加载）与编码"前置条件/数据流/顺序"等工作流关系的类型化知识图，得到一个机制性结论：在强 ranker 之上叠加图结构并不能扩展检索可达性。
- **解决什么问题 / 为什么重要**：属 C 方向"优先"里的机制分析（agent memory / 检索 + 知识图），且难得地对"加结构是否真有用"给出可证伪的量化答案。它诚实地指出问题所在：图的候选边取自 ranker 已在搜的同一嵌入邻域，98.6% 的类型化边连接的技能是 ranker 早已一起召回的——存在"预过滤拓扑上界"，图能丰富关系语义却无法扩展检索"够得到的范围"。它还揭示评测陷阱：用作者自撰 query 评测会把 hit@5 高估多达 44 分。对做 agent 记忆/技能库/工具检索的人，这是一份关于"结构增益边界"的清醒参考。
- **核心方法**：在 690 技能语料、117 条真实非回声 query 上，对比混合 ranker 与类型化知识图；在匹配 token 预算下用图邻居替换额外排名结果，量化增益/损失，并给出"预过滤拓扑上界"的机制解释。
- **主要结果**：混合 ranker 在 top-5 命中率约 73.5%±8.0，仍有约四分之一 query 未被服务；按设计用法引入图反而显著更差（−11.2 分，p=0.0007），其 LLM 生成的边层相对本地嵌入免费得到的邻居毫无增益，ranker 漏掉的 query 有 73% 在图上根本不可达。
- **值得追问 / 局限**：结论基于单一 690 技能语料与特定 ranker，换更大/更异构技能库或更强图构建（真正引入 ranker 邻域之外的边）时是否仍成立待验证；"何时加入结构性依赖才最优"作者虽给出条件，但仍需在更多真实 agent 工作流上检验。

## 6. Is Self-Pretraining really useful to improve diagnosis in medical Time Series?
- arXiv: https://arxiv.org/abs/2608.06122
- 作者：Omar Coser, Antonio Orvieto, Paolo Soda, Loredana Zollo
- **TL;DR**：受"Transformer 在长上下文基准上受益于自预训练（SPT）"启发，作者系统检验 SPT 能否推广到多模态/多变量乃至简单单变量的医疗时序，覆盖康复机器人、压力检测与帕金森步态三类任务，并系统变化模型深度考察容量与预训练收益的交互。
- **解决什么问题 / 为什么重要**：作为今日 B 方向（fNIRS/脑网络、异常检测/AIOps 均未取到干净命中）的**神经退行/生理时序邻域补位**收录。它对我关心的"数据受限下时序表示学习"有直接参考：SPT 是无需改架构的通用策略，在数据稀缺的临床场景可稳定提升，且深模型更能吃到预训练富化的时间表示带来的红利。方法论上（掩码式自监督目标 + 深度扫描）对 fNIRS 等低资源脑功能时序也有可迁移性。
- **核心方法**：在三类医疗时序任务上，用四种基于掩码的自监督目标做 SPT（促进时间与跨模态表示学习），对比"从零训练"，并系统变化模型深度以考察容量—预训练收益的交互。
- **主要结果**：跨数据集与配置，SPT 一致提升分类准确率 0–6 个百分点（随掩码策略/数据集/架构而变），在多变量与简单单变量输入下均有增益；深模型收益更大。
- **值得追问 / 局限**：任务为压力/帕金森步态/康复等生理时序，非 fNIRS/脑网络本身，能否迁到血氧慢信号、噪声结构不同的 fNIRS 需另证；0–6 pp 的增益区间较宽、下界近乎为零，何种掩码目标在何种数据上稳定有效仍需更细的条件刻画。
