## A. 核心方法（时空图 / 不规则时序）

### 1. Spatio-temporally complementary feature propagation on graphs for longitudinal AADT estimation
- 链接：https://arxiv.org/abs/2609.29906
- 作者：Linghang Sun, Qishen Zhou, Michail A. Makridis, Anastasios Kouvelas（4 位；cs.LG）
- **TL;DR**：在**有向图**上做"时空互补"的特征传播——用空间稀疏但时间稠密的线圈检测器数据，去补全空间完整但时间稀疏的宏观交通模型，从而低成本估计整网多年的年均日交通量（AADT）。
- **解决什么问题 / 为什么重要**：命中 A 的时空图方向。物理传感器昂贵且空间稀疏，单一数据源无法覆盖"全网 × 多年"；本文把两类互补数据在图上融合，是时空图信号补全 / 传播的一个务实范式，对做 STGNN、图上缺失值填补的人有参考价值。
- **核心方法**：将特征传播建模为**有向图上的泊松能量最小化（含残差项）**；关键改动是用"流量比矩阵"替代标准二值邻接矩阵，以刻画交叉口真实的车辆转向比例；据此在时空维度互补地扩散特征。
- **主要结果**：在苏黎世市验证，算法数分钟内收敛，归一化平均绝对误差低于 10%，有效调和了理论交通模型与实测地面真值，方法可扩展到全网范围。
- **值得追问 / 局限**：① 这是基于能量最小化的图信号传播，而非可学习的时序图神经网络，缺乏对时间动态的显式建模（"longitudinal/多年"更多靠数据拼接而非时序模型）；② 依赖流量比矩阵这一先验结构，其在缺少精细转向数据的城市能否泛化，需看正文。

## B. 应用场景（远程监测 / 时序异常告警）

### 2. AI-based detection of worsening heart failure from low-resolution telemonitoring data
- 链接：https://arxiv.org/abs/2609.29742
- 作者：Erik Aerts, Yinan Yu, Annika Rosengren, Michael Fu, Martin Lindgren 等（8 位；cs.AI）
- **TL;DR**：提出 **TRACER**（Transformer + 对比事件表征），在**低分辨率、不规则采样**的心衰远程监测生物标志物序列上，预测通往罕见住院事件的时间线，以便及早告警、减轻医护负担。
- **解决什么问题 / 为什么重要**：一篇同时命中 A（不规则采样时间序列 / 事件表征）与 B（时序异常检测 + 监控告警）的交叉工作。远程监测数据稀疏、不规则且事件极度不平衡，直接做窗口预测信号弱；本文把问题重构为**事件检测**，正对应我关心的"异常/恶化早期定位 + 告警生成"场景。
- **核心方法**：为每个生物标志物设计**时间感知嵌入**；用**对比预训练**做表示学习以增强异常检测；再接独立的二元分类器做检测。数据来自 276 名心衰患者的远程记录序列，按时间规则切成重叠窗口，以窗口末端是否发生心衰相关住院来打标。
- **主要结果**：在高度不平衡的真实数据上正确预测了 66.7% 通往住院的时间线，过估率 7.9%；把训练从"直接预测窗口"改为"事件检测"显著提升了性能，能更有效利用有限的住院事件；整体优于其它对比模型。
- **值得追问 / 局限**：① 仅 276 名患者、住院事件稀少，66.7% 命中 + 7.9% 过估的临床可用阈值仍需更大队列验证；② "对比事件表征"相对普通时序模型的增益来源（是时间感知嵌入还是对比预训练）未充分消融，跨疾病/跨设备的迁移性存疑。

## C. 机制 / 表征分析 + Agent（高优先级，取 4 篇）

### 3. Your Transformer Can Hold Two Thoughts at Once: Evidence of Linear Superposition in LLMs
- 链接：https://arxiv.org/abs/2609.29845
- 作者：Pavel Tikhonov, Anton Korznikov, Matvey Mikhalchuk, Nikita Dragunov, Temurbek Rahmatullaev 等（9 位；cs.AI / cs.CL）
- **TL;DR**：提出**"叠加线性假设"**——当把两条不同文本流的输入线性组合送入 LLM 时，模型输出近似为两者各自 next-token 分布的**叠加**；并论证这是 Transformer 架构的**内生**属性而非训练涌现，且可通过轻量微调恢复、进而用引导解码"一次前向生成两段连贯续写"。
- **解决什么问题 / 为什么重要**：正中 C 的表征结构 / 机制分析。它把"模型能否同时承载两个语义"从直觉变成可度量的线性性质，并给出一个反直觉观察：**叠加线性随预训练进行反而减弱**——这对理解表征几何、叠加态（superposition）与容量分配很有价值。
- **核心方法**：构造线性组合输入，度量模型输出分布与"两路各自分布均值"之间的散度；比较不同预训练阶段的线性程度以论证内生性；用轻量微调显著降低该散度；提出**引导解码**从单次前向中解耦两路叠加输出。
- **主要结果**：线性叠加在多种设置下成立且为架构内生；随预训练推进倾向减弱，但轻量微调可大幅恢复线性；引导解码能同时产出两段各自连贯的续写。
- **值得追问 / 局限**：① "内生而非涌现"的判据依赖散度度量与所选模型，是否对所有规模/架构稳健需更多验证；② 引导解码的实用价值（相比直接两次前向）以及叠加线性与下游能力（如干扰、越狱）的关系尚待展开。

### 4. ALOE: Semantically Addressed Low-Rank Operators for Knowledge Editing
- 链接：https://arxiv.org/abs/2609.29269
- 作者：Zeyan Li, Hu Xu, Jianfeng Xu（3 位；cs.AI）
- **TL;DR**：把知识编辑从"写问题"重构为"**寻址问题**"——决定哪些隐藏状态该接收新残差；提出 **ALOE**，从复述与同主语难负例中学习语义地址，并把门控低秩算子嵌入单个 MLP 层，部署时单次前向、无需外部检索器或路由器。
- **解决什么问题 / 为什么重要**：命中 C 的机制/表征分析。作者指出编辑的核心张力在"激活范围"：太窄只记住单条 prompt，太宽会破坏相邻知识；参数式编辑隐式编码范围、记忆式编辑显式但在模型外——ALOE 把"显式范围选择"内化进模型，是对编辑几何的机制性刻画。
- **核心方法**：从复述与硬同主语负例学习**语义地址**；通过 rollout 精修与门控校准把地址对齐到自回归隐藏状态；将门控低秩算子嵌入一层 MLP，实现无检索器的单前向部署。
- **主要结果**：在 CounterFact / ZSRE / KnowEdit、三个 7–8B 模型族上，编辑有效性 0.955–0.999、局部性 0.981–1.000；机制分析显示学到的几何能分离竞争性编辑、校准能抑制越界激活；残余误差集中在复述覆盖与写入拟合。
- **值得追问 / 局限**：① 指标很高但主要在合成/受控编辑基准，连续大量编辑下的累积干扰与遗忘未充分测试；② "复述覆盖不足"是明确短板，真实用户表述的多样性可能击穿学到的语义地址边界。

### 5. Scope Before You Persist: Preventing Cross-Family Interference in Agent Memory
- 链接：https://arxiv.org/abs/2609.29144
- 作者：Yezhou Cheng, Runjia Du, Zeming Liu, Qibai Chen, Hang Lyu 等（8 位；cs.AI）
- **TL;DR**：面向"冻结模型 + 持久记忆"的 agent，提出**把检索作用域匹配到认证作用域**——每条被接受的技能只在其"原生任务族"内被检索，从而阻止跨族干扰、支持可靠的重复自适应。
- **解决什么问题 / 为什么重要**：命中 Agent 方向的"记忆"优先类，且是机制/受控实验导向（非 prompt 工程）。持久记忆能让 agent 不改权重就积累技能，但"局部有效的编辑会干扰无关任务族"是核心失效模式；本文给出**执行接地的门控（ORC）+ 作用域匹配**这一可复现的机制性控制。
- **核心方法**：在 ProcStream-RSI（12 轮代码修复流）上用 **Orthogonal Regression Control (ORC)** 作为执行接地的持久技能编辑门；在保持"提案 + 门决策"不变的干预中，仅让每条被接受技能在其原生族内被检索（Scoped-ORC vs Global-ORC）。
- **主要结果**：作用域匹配把隐藏轨迹效用从全局记忆的 0.713 提到 0.816，有害部署从 8 例中的 6 例降到 0；27 条配对随机序列上，Scoped-ORC 平均效用比 Global-ORC 高 0.063 [0.037, 0.094]，接受 63 条更新（vs 12 条）且 0/63 有害接受；全局控制的 0.713 反而低于静态 agent 的 0.775，印证"局部有效编辑会干扰无关族"。
- **值得追问 / 局限**：① 结论建立在单一代码修复流基准，"任务族"边界在开放世界里往往模糊，如何自动界定作用域是关键未解问题；② 认证门 ORC 依赖可执行验证，缺少可执行信号的领域（如开放对话）该机制如何迁移待验证。

### 6. ERRAND: Budgeted Maintenance of Agent Memory
- 链接：https://arxiv.org/abs/2609.29545
- 作者：Beining Wu, Zihao Ding, Jun Huang（3 位；cs.AI）
- **TL;DR**：部署后的 agent 靠"交接时写好的记忆简报"运行，但世界在变、记忆在旧——**失效来自陈旧而非无知**；ERRAND 把"再校验"当作**有价的差事**：一次复查要和它保护的任务竞争同一份稀缺动作预算，只有当"每动作解疑价值"超过运行工资时才出资。
- **解决什么问题 / 为什么重要**：命中 Agent 方向的"记忆"优先类，聚焦一个被忽视的机制问题——**记忆维护的预算分配**。它把"何时该花动作去再校验旧知识"形式化为一个单峰的差事指数（在信念两端都趋零，即"任一方向的确定都免费"），是对 agent 记忆生命周期管理的机制性建模。
- **核心方法**：差事指数单峰、两端消失；途中"免费回执"维护在途知识；修复以"写新版本"而非删除来完成；在两个漂移的工具使用世界里，于等动作预算下与各类再校验策略对比。
- **主要结果**：等预算下 ERRAND 在预注册指标上胜过所有非 oracle 策略，在基准上限处领先"积极再校验"10.0pp；不设上限时 ERRAND 自行停止，仅花 11.0% 步数，而无上限的积极再校验花 70.7% 步数却仍落后设限 ERRAND 4.5pp；增益集中在"简报覆盖最薄"的长尾知识处。
- **值得追问 / 局限**：① 评测在两个合成"漂移工具世界"，真实部署中"漂移速率 / 陈旧代价"难以先验定价，运行工资阈值如何自适应是落地关键；② "写版本不删除"利于可追溯，但长期会累积存储与检索开销，与预算化初衷是否冲突需看正文。
