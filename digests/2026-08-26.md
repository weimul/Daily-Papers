## A. 核心方法

### 1. HAWKEYE: Seeing One Layer Deeper — A Cohesion-Aware Structural Channel for Temporal Link Prediction
- arXiv：https://arxiv.org/abs/2608.22727 （cs.DB / cs.LG）
- 作者：Jiacheng Ding, Xiaofei Zhang
- **TL;DR**：指出主流时序图链接预测（TLP）模型的"结构通道"长期被当作粗糙附属品（DyGFormer 只用 1–2 bit 的邻居共现），提出 HAWKEYE——一个即插即用的"内聚感知结构通道"，用经典 k-core / k-truss 增量维护"2 跳内聚桥"特征，显著提升预测精度。
- **解决什么问题 / 为什么重要**：正落在你 A 方向最优先的「时序图 / 动态链接预测」。它先做了一个有说服力的测量：在稀疏时序图上经典 1 跳共同邻居信号近乎随机（判别 AUC≈0.50，因为两点几乎不共享直接邻居），真正有判别力的信号在再深一跳的"2 跳内聚桥"（discAUC 达 0.73–0.98）。这把"该往结构通道里放什么"从工程直觉变成可测量的设计依据。
- **核心方法**：增量维护经典 k-家族内聚指标（degree → k-core → k-truss），据此构造 2 跳内聚桥特征；作为 drop-in 替换现有时序图模型（如 DyGFormer）的原生结构通道，主干不改；流式管线支持大规模增量更新。
- **主要结果**：换入 DyGFormer 后，在 uci/enron/USLegis/CanParl/reddit/mooc 六个数据集上 test AP/MRR 相对共现通道提升 +0.6 ~ +10.8 分；在二部推荐基准 tgbl-subreddit 上仅用结构通道就把 test MRR 从 0.103 提到 0.204（近乎翻倍）；流式管线在 6700 万边的 tgbl-flight 上每遍约 5 分钟；并刻画了增益边界——增益随图的"免训练 2 跳 discAUC"变化，在退化/饱和图上消失。
- **值得追问 / 局限**：①增益依赖"2 跳内聚结构确实携带信号"这一前提，作者已给出可预测边界，但对高度动态、结构快速漂移的连续时间图（CTDG）是否仍稳定值得看；②仍是"补通道"式改进而非重构骨干，与端到端学习结构表征的方案相比，可解释性收益与表达力上限如何权衡尚待对比。

### 2. Symbolic Neural ODEs: Learning interpretable models from time-series data
- arXiv：https://arxiv.org/abs/2608.22112 （cs.LG / eess.SY / math.DS / stat.ML）
- 作者：Nibodh Boddupalli, Jeff Moehlis
- **TL;DR**：直接从时序数据辨识稀疏、可解释的动力系统模型——用神经网络参数化向量场、以"多步预测损失 + 训练中逐步加长预测视野 + 稀疏正则"训练，得到既稳定又简洁的符号化 Neural ODE。
- **解决什么问题 / 为什么重要**：命中你 A 方向的「Neural ODE / 连续时间模型」叠加「内生 / 自解释」两个重点。它针对一步回归向量场易发散的老问题，用多步复合一致性约束把长期稳定性做进训练目标，并借稀疏正则得到可读的符号形式——即模型本身就是可解释的动力学，而非事后归因。
- **核心方法**：神经架构参数化向量场；训练目标是有限视野上的多步预测的平均绝对误差（MAE），并在训练中渐进增大预测步数，从而强制"重复复合学到的动力学时保持一致"；配合稀疏促进正则得到 parsimonious 模型；给出把轨迹误差与统计精度联系起来的理论界。
- **主要结果**：在稳定/不稳定不动点、周期轨道乃至混沌吸引子等多种行为上都能准确恢复系统；对混沌系统，虽然长期逐点轨迹受初值敏感性限制，但多步训练得到的模型短期动力学准确、且在长时统计量（均值、方差、Lyapunov 指数）上高度吻合。
- **值得追问 / 局限**：①"符号可解释"的程度取决于稀疏正则强度与字典/架构选择，面对高维、多变量强耦合系统时可读性能否维持存疑；②方法在干净/低噪仿真系统上验证充分，对真实世界不规则采样、含噪、非平稳观测的鲁棒性尚未展开。

## B. 应用场景

### 3. A Tensor Network Framework for Interpretable Graph Analysis of Brain Networks
- arXiv：https://arxiv.org/abs/2608.21368 （q-bio.NC / physics.data-an）
- 作者：Domenico Pomarico, Giuseppe Magnifico, Alessandro Grecucci, Loredana Bellantuono, Jesus M. Cortes, Marianna La Rocca 等
- **TL;DR**：用量子启发的张量网络（Matrix Product State）学脑灰质特征的分布式表征，再从训练好的模型里抽取"量子连通关联"来编码高阶特征交互、映成加权图，从而在同一表征里同时给出全局谱性质与节点级中心性——既是分类器又是可解释脑区分析工具。
- **解决什么问题 / 为什么重要**：正对你 B 方向的「神经影像时序 / 脑网络」（结构 MRI 脑网络，方法学与 fNIRS 血氧连接分析同源），且同时踩中 A 的「内生 / 自解释 + 图」。它不满足于事后 Shapley 归因，而是把"高阶特征交互 → 图 → 中心性签名"做进模型表征本身，给出比 Shapley 更稳定的可解释信号。
- **核心方法**：把灰质特征编码进 MPS 变分拟设（源自量子多体系统）学分布式表征；训练后不仅当分类器，还提取特征间的 quantum connected correlations（编码高阶交互）映成加权图；在单一表征里同时追踪 (i) 网络全局谱性质（刻画集体学习动态）与 (ii) 节点级中心性（个体脑区的可解释签名）；用重复 train-test 重采样评估。
- **主要结果**：在结构 MRI 上做健康对照 vs 精神分裂、vs 双相障碍两个分类任务；节点级分析稳定识别出一组灰质特征（以 Heschl 回、岛叶、额区为主）在多种中心性度量与多次重采样下都充当枢纽；这些中心性跨重采样的方差低于 Shapley 值，支持网络表征的可解释价值；双相的特征集是精神分裂特征集的子集，与神经影像报道的层级化解剖学改变一致。
- **值得追问 / 局限**：①以结构 MRI 的静态特征交互为主，尚非时变连接的动态脑网络，迁到 fNIRS/EEG 的时序有效连接还需引入时间维；②"量子连通关联 → 图"这一步的高阶交互解释力，需与直接图神经网络/高阶 GNN 建模做对照来定位其独特价值。

### 4. The Abstention Protocol: RCA for Clos Fabrics
- arXiv：https://arxiv.org/abs/2608.21412 （cs.AI / cs.DC / cs.NI）
- 作者：Madhava Gaikwad, Deepak Pandey
- **TL;DR**：面向大型数据中心 Clos 网络的根因分析（RCA），提出生产系统 CoreSec——用"PAM 式弃权代数"替代加权分数融合：证据模糊时显式"弃权"而非硬给归因，配合拓扑感知配置随证据单调收敛，得到稳定且可解释的根因定位。
- **解决什么问题 / 为什么重要**：直接命中你 B 方向的「监控告警 / 根因定位 / AIOps」。它抓的是真实告警场景的核心痛点：遥测噪声大、部分缺失、异步到达，导致基于分数的方法归因不稳、易错。用"可弃权的确定性代数"把不确定性显式化，是一种偏"内生可解释"的根因框架，与你偏好的结构化/可解释路线一致。
- **核心方法**：遥测代理用控制标志组合，产生确定性决策，并在证据模糊时显式弃权（abstention algebra）；把该代数与拓扑感知配置结合，刻画 Clos fabric 上的故障面，并随证据累积单调收敛；已在超大规模生产环境部署，跨环境无需重新调参。
- **主要结果**：作为生产 RCA 系统在 hyperscale 部署，跨多样环境给出稳定、可解释的根因行为，且无需针对环境重新调参；作者以工程经验论证"带弃权的结构化组合"是真实云网络自动化 RCA 的实用基础。
- **值得追问 / 局限**：①偏系统/经验论文，缺与学习式或因果图式 RCA 基线的定量对照，"可解释=可弃权"的收益难与统计方法量化比较；②弃权代数依赖人工设计的控制标志与拓扑配置，面对未建模的新故障模式时覆盖度与可迁移性存疑。

## C. Agent / 机制与表征

### 5. Mechanistic Interpretability of Chain-of-Thought Reasoning via Sequential Activation Patching
- arXiv：https://arxiv.org/abs/2608.22332 （cs.CL）
- 作者：Murat Dura, Serkan Öztürk, Selma Tekir
- **TL;DR**：CoT 推理跨多个生成 token 展开，单一静态位置的激活修补不足以刻画其"时序分布式"因果效应；提出序列化激活修补（sequential activation patching）沿生成轨迹追踪 CoT 条件下的注意力头激活，用词性引导聚合，定位对最终答案有贡献的注意力头子电路。
- **解决什么问题 / 为什么重要**：正属你 C 方向优先的「机制 / 现象分析」。它把机制可解释性的经典工具（activation patching）从"单 token 位置"扩展到"沿推理轨迹的多位置序列"，回答"CoT 的因果效应在推理轨迹的哪里、由哪些头承载"，比只看最终 token 更贴合 CoT 的时序本质，方法可迁移到其它多步生成的机制分析。
- **核心方法**：沿 token 位置追踪 CoT 条件下的注意力头激活，用词性（POS）引导聚合其效应；进一步提出 Sequential Multi-Head Patching 评估分布式头集合的联合贡献，并设跨问题与随机激活对照；用定向零消融（zero-ablation）验证所识别头的功能重要性。
- **主要结果**：识别出的注意力头对成功答案生成确有功能作用，且影响多个重叠机制——推理轨迹维持、答案锚定、示例-目标分离、数值生成；总体为"存在与 CoT 条件计算相关的分布式推理支持子电路"提供证据。
- **值得追问 / 局限**：①结论建立在特定模型与任务集上，识别出的"子电路"跨模型规模/跨任务是否稳定、是否为该模型族特有，需更广验证；②POS 引导聚合与零消融是相关性+干预证据，但"头承载某机制"到"该机制因果驱动答案"之间仍有解释空间。

### 6. Why Does Robustness Reduce Superposition?
- arXiv：https://arxiv.org/abs/2608.22155 （cs.LG / cs.AI）
- 作者：Adam Elimadi
- **TL;DR**：接着 Gorton & Lewis (2025)"对抗样本源于叠加、且对抗训练会降低叠加"的经验发现，本文补上机制解释——给出一条因果链：对抗训练抛弃非鲁棒特征 → 需要表示的特征总数变少 → 叠加（superposition）随之减少。
- **解决什么问题 / 为什么重要**：命中你 C 方向的「机制 / 表征（叠加即表征几何的核心现象之一）」。它不是刷某个电路，而是为一个已被观察但"没说清为什么"的现象立机制解释，把对抗鲁棒性、特征叠加、Ilyas et al. (2019) 的"鲁棒 vs 非鲁棒特征"三条线索串成可检验的因果链，对理解"表征里塞了多少特征"这一几何问题有直接价值。
- **核心方法**：借鉴 Ilyas et al. (2019) 的特征分类学（鲁棒 / 非鲁棒特征），提出并经验追踪一条因果链——对抗训练放弃非鲁棒特征，使需要表示的特征总数下降，从而降低叠加程度；以此对 Gorton & Lewis 的经验现象给出机制层面的解释。
- **值得追问 / 局限**：①属较短的机制解释性工作，"特征总数下降"需要可操作的度量来与叠加程度定量对齐，因果链的每一环是否都有干预证据值得看细节；②在更大模型 / 更复杂数据分布上，"非鲁棒特征被抛弃"是否总是净减少表示负担（而非被别的特征替代）仍需验证。
