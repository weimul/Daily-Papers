## 1. MissHyper: Restoring Clinical Synchronicity in Missingness-Guided Hypergraph Forecasting
- arXiv: https://arxiv.org/abs/2607.21922
- 作者：Mingyi Ma, Qingxiong Tan（共 2 位）
- **TL;DR**：临床不规则多变量时序里，"同一时间戳采到哪些指标"本身就带信息；事件式模型却常把同时刻的测量当成孤立节点、要等到后面的消息传递层才恢复病人状态上下文。MissHyper 在消息传递"开始之前"就把同时间戳的记录聚合回上下文，并用缺失感知门控自适应融合，缓解这一"传播前表征瓶颈"。
- **解决什么问题 / 为什么重要**：正对 A 方向"不规则采样 / 缺失时间序列"这一核心重点，且落在时空图（超图）建模上。真实 ICU/病房数据天然稀疏、异步、缺失，测量过程（何时测、测什么）与病理动态耦合；现有事件中心模型把 co-timestamp 结构过早"拍平"，导致早期节点缺乏局部病人状态，损害稀疏前向预测。MissHyper 指出"事件初始化"是被忽视的关键设计轴，无需重构下游传播架构就能提升，思路对做医疗/工业稀疏传感时序的人有迁移价值。
- **核心方法**：三件事——为每个事件加"局部支持密度（support-density）"线索；把同时间戳记录聚合以恢复病人状态上下文（snapshot restoration）；用"缺失感知门控"自适应融合节点自有证据与恢复出的上下文，再进入超图消息传递。
- **主要结果**：在 PhysioNet 2012、MIMIC-III、MIMIC-IV 三个基准上，多步预测一致优于一个强超图基线；消融显示快照恢复、自适应融合、支持密度编码三者均有贡献。
- **值得追问 / 局限**：摘要未给具体量化数字与对比幅度，"consistent gains / outperform"的强度需看正文；只对比"一个强超图基线"，与非超图的不规则时序 SOTA（如 latent-ODE、注意力插补类）的对照未提；"支持密度"这一手工线索在不同科室/采样习惯下的稳健性待验。

## 2. MA-DAR: Manifold-Aligned Dynamic Adaptive Routing for Continual Temporal Knowledge Graph Reasoning
- arXiv: https://arxiv.org/abs/2607.21949
- 作者：Xiangjun Shi, Chong Mu, Jinchuan Zhang, Lizong Zhang, Yuefeng He, Shang Liu（共 6 位）
- **TL;DR**：连续时序知识图谱（TKG）推理要边吸收新事实边不忘旧知识；重放法一直在纠结"重放什么"，却忽视"重放的表征该怎么和当前表征融合"。MA-DAR 指出直接融合会引发两类表征冲突——范数支配（norm domination）与语义模糊（semantic blurring），并用流形对齐 + 动态门控路由来化解。
- **解决什么问题 / 为什么重要**：正对 A 方向"时序图 / 动态图 / continual"。这是把持续学习里的"表征冲突"问题在时序知识图谱上做细的一篇：不改编码器、以即插即用方式解决"replay 表征与当前表征怎么合"这个此前被略过的环节。对做动态图/事件流上的持续推理、以及一般 replay-based CL 的表征融合都有借鉴。
- **核心方法**：先把重放表征与当前表征对齐到共享流形以缓解分布差异；再用动态门控学习"逐维度"融合权重，自适应决定重放/当前各自贡献；并加"极化正则（polarization regularizer）"惩罚模糊的门控决策、鼓励更果断的路由，从而更稳定地整合知识。整套为轻量、即插即用框架。
- **主要结果**：在四个公开 continual TKG 基准上，一致提升多种代表性 TKG 编码器的表现，且在不同 replay 设定下均有效；消融与可视化验证了流形对齐与动态自适应路由确实缓解了表征冲突。
- **值得追问 / 局限**：摘要未给具体指标数字，提升幅度与相对基线的显著性需看正文；"逐维度门控 + 极化正则"引入的额外超参与训练成本、以及对不同重放采样策略的敏感性未展开；范数支配/语义模糊两类冲突的度量方式（如何量化）也待正文确认。

## 3. Local-Global Geometric Insights for Graph Neural Networks via Entropic Curvature
- arXiv: https://arxiv.org/abs/2607.22381
- 作者：Rachid Caich, Yassine Abbahaddou（共 2 位）
- **TL;DR**：图上的 Ollivier-Ricci / Forman 曲率几乎都是"局部边比较"，管不了信息在长程上如何传播。本文把 Lott-Sturm-Villani 的最优传输框架搬到图上，定义"全局、基于传输的熵曲率（Entropic Curvature）"，用它把 GNN 的过平滑与过压缩统一成同一曲率谱的两端。
- **解决什么问题 / 为什么重要**：正对 A 方向"时空/图 GNN"的方法与理论侧，属较硬的几何/理论工作。它给"过平滑 vs 过压缩"一个统一的、可证明的全局刻画，而非各自的局部启发式；并把理论落成可用的模块（聚合器/结构编码/重连），对想从几何角度理解并改进图消息传递的人有较高参考价值。
- **核心方法**：沿 Wasserstein 测地线用熵的位移凸性把 LSV 框架推广到图，得到"全局熵曲率"；定义可计算的"弱熵曲率（Weak Entropic Curvature）"下界代理，由此推出（i）控制过平滑的 Poincaré 型不等式、（ii）传输—熵泛化界、（iii）一个"扩张悖论"——大图中稀疏、强谱扩张与正熵曲率不能共存，从而统一过平滑与过压缩。再落成三种机制：E-Gate 聚合器、ENT 结构编码、Midpoint-Completion Rewiring（MCR）。
- **主要结果**：在六个节点分类基准 + 图分类上，与 SDRF、FoSR、BORF、LCP、Graph Ricci Flow 等重连/曲率方法对比（摘要末尾未给出具体获胜数字，定位为理论 + 基准验证）。
- **值得追问 / 局限**：摘要在"benchmark"处戛然而止、未列具体胜负与幅度，实证强度需看正文；"弱熵曲率代理"作为下界的紧致度、以及在大图上的计算可扩展性未展开；理论假设（如位移凸性成立条件）对真实异质图的适配性值得追问。

## 4. Interpretable EEG biomarkers with bag-of-waves: Spatial and temporal waveform dictionaries for low-data regimes
- arXiv: https://arxiv.org/abs/2607.22508
- 作者：Athanasios Papastathopoulos-Katsaros, Steven T. Lee, Lin Yao, Ajay Thomas, Junseok Park, Matthew J. McGinley, Zhandong Liu（共 7 位）
- **TL;DR**：EEG 分析要么靠预设频谱特征、要么靠深网，各有短板。bag-of-waves 无监督地学一小册"反复出现的 EEG 波形模板（atoms）"，把连续 EEG 转成 atom 词元序列做分类/聚类；每个 atom 都是可直接检视、对应临床可识别形态的波形，兼顾性能与可解释性，尤其适合小数据场景。
- **解决什么问题 / 为什么重要**：正对 B 方向"neuroimaging / brain time series"，同时命中 A 方向"内生/自解释（原型/概念式）"横切重点——atom 即原型式的可检视基元。它给出一条"不堆大模型也能有竞争力、且天然可解释"的脑信号路线，对样本稀缺、需要临床可读性的脑功能时序（含 fNIRS 一类）建模有直接借鉴。
- **核心方法**：用 shift-invariant k-means 无标签地学一小册 atom 字典（对时间平移不变）；将连续 EEG 编码为 atom 词元序列用于分类/聚类；扩展包括用 n-gram 捕捉时间模式、用"空间 atoms"处理多通道数据。
- **主要结果**：在三个数据集上与深度模型/基础模型相比取得有竞争力的表现，同时保持可解释性（每个 atom 对应可检视、临床可识别的波形形态）；在"重模型不适配"的低数据场景尤其有价值。
- **值得追问 / 局限**：摘要未给具体指标与对手模型的量化差距，"competitive"的边界需看正文；字典大小、shift-invariant k-means 的稳定性/初始化敏感性未展开；能否迁移到 fNIRS 等其它模态（其波形/时间尺度与 EEG 不同）尚待验证。

## 5. Agentic Root Cause Analysis through Evidence-Grounded Reasoning
- arXiv: https://arxiv.org/abs/2607.22385
- 作者：Amaury Wei, Olga Fink（共 2 位）
- **TL;DR**：工业异常的根因诊断至今大多靠人工"提假设—找证据"，成瓶颈；纯数据驱动法又多是黑箱、且需要稀缺的故障标注。AgentRCA 提出零样本智能体框架：把"刻画正常动态的数据驱动数字孪生"与"工具增强的大模型"结合，在推理时迭代收集统计证据、比较竞争假设，定位最能解释观测的物理故障。
- **解决什么问题 / 为什么重要**：正对 B 方向"根因分析 / 定位 / 监控告警（AIOps 味）"，且带 C 方向的 agent 机制色彩（推理时的证据收集 + 假设检验）。它同时解掉两个部署痛点：无需故障标注（zero-shot）、且产出可解释的推理链（把症状显式连到物理原因），对做工业/系统监控的根因定位很有参考价值。
- **核心方法**：不学"故障→标签"的映射，而在推理时做假设驱动推理——用数据驱动数字孪生建模系统正常动态，配一个工具增强的 LLM 智能体，迭代收集统计证据、评估竞争假设、选出最能解释异常行为的物理故障，并留下透明推理轨迹。
- **主要结果**：在一个真实多相流设施与一个大规模化工厂上评估，诊断表现可与"全监督基线"竞争，却不依赖故障专属训练；并给出把观测症状显式链接到底层物理原因的透明推理轨迹。
- **值得追问 / 局限**：摘要未给量化指标，"competitive with supervised"的具体差距需看正文；方法强依赖一个刻画正常动态的数字孪生，在缺乏可靠物理/数据孪生的系统（如纯软件/云原生 AIOps）上的可迁移性存疑；LLM 假设生成的可靠性、以及推理链"看似合理但错误"的风险需要评估。

## 6. Procedural Knowledge Is Not Low-Rank: Why LoRA Fails to Internalize Multi-Step Procedures
- arXiv: https://arxiv.org/abs/2607.21612
- 作者：Simon Dennis, Kevin Shabahang, Hao Guo, Rivaan Patil（共 4 位；本条为近期更新版，原提交 2026-05-23）
- **TL;DR**：LoRA 已是微调默认，但本文发现：对"过程性知识"（按多步、带条件分支的流程走到终态）这类能力，LoRA 在其保持效率优势的秩下无法追平全量微调——而且秩越高分数反而略降。SVD 分析给出机制解释：全量微调的权重更新有效秩高达 761–1026，秩 128 只能覆盖约 43–51% 的能量，所以过程性知识"本就不是低秩的"。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"里的机制/表征几何分析——用有效秩这一表征几何量，把一个 agentic 应用的关键失败模式讲清楚。多步、带分支的流程正是智能体的核心能力；如果参数高效微调在这类任务上系统性失手，对"如何给 agent 内化流程"有直接的方法论含义（该用全量微调、还是别的机制）。这类"现象定位 + 几何解释"正是我偏好的 C 类。
- **核心方法**：在过程性任务（旅行预订，14 节点）上系统消融 LoRA 秩 r=16–128 对比全量微调；再在 Zoom 客服（14 节点）、保险理赔（55 节点）跨域、3B/8B 复现；对全量微调产生的权重变化做 SVD，量化有效秩与能量覆盖。
- **主要结果**：所有 LoRA 配置一致失败（任务成功 ≤2.54 vs 全量微调 4.11，p<0.001），且高秩反而更差——尽管对话完成率仍达 95–99%；跨域复现证实泛化（r=32 与 r=128 下平均落后 0.8–2.2 分，最复杂流程差距最大）；秩从 32 翻到 128 仅边际改善、无法弥合。SVD 显示更新的平均有效秩 761–1026，秩 128 只覆盖 43–51% 的平方 Frobenius 范数。
- **值得追问 / 局限**：结论基于对话式流程任务与 3B/8B 规模，向更大模型、代码/工具调用型 agent 的外推待验；"高秩反而更差"的成因（优化/正则 vs 表达力）值得深挖；本条为更新版（原 05-23），非全新提交，收录理由是其机制结论对 A/C 高度相关。
