## A. 核心方法（图结构先验 / 动态图 / 自解释，均跨脑成像）

### 1. Sensor Geometry as a Flow-Matching Prior for Multi-Channel Brain Signals
- 链接：https://arxiv.org/abs/2610.08355
- 作者：Jaedong Hwang（1 位；cs.LG / cs.AI）
- **TL;DR**：流匹配（flow-matching）生成模型默认从各向同性高斯出发，但多通道信号的空间相关结构其实**先验已知**——传感器坐标固定、相邻通道因容积传导而共变；本文直接把这个结构塞进"源分布"：用传感器坐标的 kNN 图、取图拉普拉斯的 **graph-Matérn 函数**作为源协方差，让流从"空间相干的模式"而非通道独立噪声出发。
- **解决什么问题 / 为什么重要**：这是把**图结构作为时空信号生成先验**的干净做法，且**不加任何可学习参数**、与任意耦合/漂移网络兼容、全数据集共用同三个超参。它最贴近 A 方向里"用图结构刻画空间依赖"的思路，并明确泛化到**交通传感器网络**（经典时空图场景），说明不是脑信号专属 trick。
- **核心方法**：仅凭传感器坐标建 kNN 图 → 取图拉普拉斯的 Matérn 谱函数作源协方差 → 流匹配从该相关高斯出发生成多通道信号。关键证据：把特征向量随机打乱但保留特征值谱后增益消失，说明收益来自**局部传感器图的空间特征向量**；而直接拟合经验数据协方差反而比各向同性噪声更差。
- **主要结果**：在 8 个 EEG 数据集 × 4 种流匹配方法上，五个临床频段的谱差异（PSD-KL）在多数数据集下降；几何平均降 12%–17%，在最密集导联 PhysioNet-MI 上最高降 40%。同一构造原封不动迁到 MEG、患者特异网格的颅内 EEG、以及交通传感器网络，均降低 PSD-KL。
- **值得追问 / 局限**：① 收益主要体现在谱匹配（PSD-KL），对下游判别/重建任务（分类、源定位）是否同样受益未充分展开；② "拟合经验协方差反而更差"提示先验要的是**结构**而非精确幅值，但这一取舍对强噪声/非平稳信号是否稳健仍需更多场景验证。

### 2. CoHyFuse: Condition-wise Hypergraph Fusion with Global Connectome in Task-fMRI
- 链接：https://arxiv.org/abs/2610.05913
- 作者：Boseong Kim, Haejun Chung, Ikbeom Jang（3 位；cs.LG / q-bio.NC）
- **TL;DR**：任务态 fMRI 的连接组会随任务状态重构，但常规做法把不同条件聚合成**静态成对图**，抹掉了条件特异的多脑区（多-ROI）组织；CoHyFuse 用**条件感知、以 ROI 为中心的超图**，由各条件的功能连接（FC）画像嵌入构造任务态特异的关联矩阵，让同一 ROI 在不同任务阶段形成不同的多-ROI 超边。
- **解决什么问题 / 为什么重要**：同时命中 A 的"动态图 / 超图结构 + 内生可解释"与 B 的脑网络应用。超边随任务阶段变化即一种**动态图**建模；且条件特异邻域规模 K_q 自适应、再与整段会话 FC 分支融合，给出的是**状态可分、可解释**的连接组视图，而非 post-hoc 归因。
- **核心方法**：从条件级 FC 画像嵌入构造任务态关联矩阵 → 条件特异邻域规模 K_q 自适应超边尺度 → 条件嵌入与整段会话 FC 双分支融合做预测；配合遮挡分析识别驱动预测的条件与 ROI-集合基序。
- **主要结果**：在 AABC 队列（N=1,074）上，流体认知综合分预测 MAE 7.83±0.10 / R² 0.439±0.026、年龄预测 MAE 7.52±0.37 / R² 0.592±0.022，均为所评基线中最优；在 CMI-HBN 的 ADHD 分类（N=223）上 macro-AUC 72.0±2.1%、准确率 74.2±2.9%。遮挡分析指向 Distraction 条件为主要驱动，并定位到 SAN–FPN 与 SAN 内超边基序。
- **值得追问 / 局限**：① 超边由条件级 FC 嵌入构造，对条件划分粒度、样本量较小队列（N=223）的稳定性与过拟合风险需关注；② 可解释性来自遮挡/基序分析，属"模型内结构读出"，其与真实神经机制的对应仍需神经科学侧证据支撑。

## B. 应用场景（根因分析 / AIOps + 脑源成像）

### 3. Agentic RCA for Internet-Scale Services Using Constrained Creativity (E4)
- 链接：https://arxiv.org/abs/2610.08622
- 作者：Sayan Sinha, Vipul Harsh, B. Aditya Prakash, Vyas Sekar, Hui Zhang（5 位；cs.NI / cs.AI）
- **TL;DR**：互联网级服务的故障排障系统理想上要同时满足四点——对已知/未知故障都表达力强且准、规模化下成本低、输出可解释可执行、对运维人力要求低；现有 LLM agentic 流程与结构化 RCA 框架都难四者兼得。E4 提出"**受约束的创造力**"：不让 agent 写任意代码或自由作答，而是给它一套**受限 DSL**，只能生成无循环的数据流程序。
- **解决什么问题 / 为什么重要**：正中 B 的"根因分析 / AIOps / 告警"，且是**系统/机制导向而非 prompt 工程**——它用 DSL 把 LLM 的探索力与结构化方法的可验证、可解释、低成本结合起来，直接回答"怎样让 agentic RCA 既准又可审计又便宜"。
- **核心方法**：给 agent 一套配有排障高层算子的受限 DSL，让其以**无循环数据流程序**的形式产出诊断；由此输出天然可验证、可解释，避免自由代码/自由文本带来的不可控与高成本。
- **主要结果**：在合成 + 真实世界混合负载上，相比 SOTA 方案准确率最高提升 **62%**，同时给出更可解释的响应，成本最低降至 **1/12**。
- **值得追问 / 局限**：① 受限 DSL 的表达力边界决定了"未知故障"的覆盖上限——哪些故障类型落在 DSL 算子之外、需要人工扩展算子集，是工程落地关键；② 62% 的相对提升绑定在其评测负载上，面向真实生产拓扑/跨厂商遥测的外推仍需更多现场验证。

### 4. CANDLE: Cortical Null-Space Decomposition for Noninvasive Brain Source Imaging
- 链接：https://arxiv.org/abs/2610.07824
- 作者：Shuntaro Suzuki, Yuiga Wada, Komei Sugiura（3 位；cs.LG / eess.SP / q-bio.NC；庆应）
- **TL;DR**：从无创电生理（如 EEG）反推皮层源活动（ESI）是严重病态逆问题（源维度远高于传感器、解不唯一）；学习型方法引入数据先验，却难以跨被试的个体皮层几何泛化。CANDLE 只在由 T1 MRI 导出的**源-到-传感器映射的零空间**上学习先验——把学习限制在"不可观测的源分量"上，同时保留几何约束。
- **解决什么问题 / 为什么重要**：命中 B 的脑功能时序逆问题（与 fNIRS 同属脑成像反演家族）。把先验限定在**零空间**是个利落的设计：可观测分量由前向模型/测量直接约束，学习只补"测不到"的那部分，从原理上缓解了学习型 ESI 的跨个体几何泛化难题。
- **核心方法**：由 T1-MRI 导出源-传感器前向映射并取其零空间 → 在零空间上学习源先验（保留几何约束）→ 用一个覆盖 1,100+ 个体皮层几何、源配置取自 26,000+ 统计脑图的全脑模拟器**仅用仿真数据**训练。
- **主要结果**：仅在仿真上训练即在仿真源估计上超越既有 ESI 方法，并泛化到两项真实任务：① 同步头皮 EEG 下的颅内电刺激定位；② 术前发作间期 EEG 的致痫区估计。
- **值得追问 / 局限**：① 训练完全依赖仿真器与统计脑图，真实场景的定位真值难核验，仿真-真实差距对致痫区等临床判读的影响需谨慎；② "零空间先验"依赖准确的前向模型（leadfield/MRI 配准），前向误差如何传导到源估计、能否迁移到 fNIRS 等不同前向物理尚待验证。

## C. 机制 / 表征分析 + Agent（高优先级，取 2 篇）

### 5. How Learning Governs Unlearning across the Memorization-Generalization Spectrum
- 链接：https://arxiv.org/abs/2610.08577
- 作者：Hwiyeong Lee, Hyelim Lim, Ingyu Bang, Hoki Kim, Taeuk Kim（5 位；cs.LG）
- **TL;DR**：机器遗忘（unlearning）研究大多只盯"怎么删"，很少问"模型当初**怎么学**的会如何影响后续能不能干净地删"。本文从**记忆（memorization）vs 泛化（generalization）**这对竞争性训练策略切入，发现**越偏泛化的模型在遗忘时对保留集（retain set）的损伤越大**。
- **解决什么问题 / 为什么重要**：正中 C 的训练动力学 / 机制分析。它把"学习方式 → 遗忘代价"这一被忽视的因果链，落到可控、可度量的 grokking / 模加法玩具系统上，再验证到 LLM 的逐字背诵与事实回忆遗忘，给遗忘方法设计提供了"要考虑学习动力学"的新维度。
- **核心方法**：用模加法上的 **grokking** 把模型分为偏记忆/偏泛化两类比较其遗忘反应；再提出**分桶模加法（bucketed modular addition）**，让两种策略的贡献可沿记忆-泛化谱系显式调控，观察遗忘损伤的变化；最后在 LLM 的逐字/事实回忆设置上复现同一趋势。
- **主要结果**：偏泛化模型遗忘后在保留集上的性能跌幅更大；在分桶设置下该趋势**近乎单调**地随"偏泛化程度"上升；LLM 的逐字与事实回忆遗忘中同一关系成立。作者据此给出两条改进遗忘方法的实践启示。
- **值得追问 / 局限**：① 核心机制证据来自模加法这类合成/可控任务，"记忆-泛化谱系"在真实大规模预训练里如何界定与测量仍有距离；② "偏泛化→保留集损伤更大"是否依赖具体遗忘算法（梯度上升类 vs 其它），跨方法的普适性需进一步对照。

### 6. Identifying Introspection From the Inside
- 链接：https://arxiv.org/abs/2610.07186
- 作者：David I. Atkinson, Dillon Plunkett, David Bau（3 位；cs.CL；Bau Lab）
- **TL;DR**：大模型会对"自己"做出难以从行为上核验的论断——如何区分**似是而非的编造**与**真正的自省**？本文在受控设置里找到**忠实自我报告的机制特征**：用低秩适配器训练模型替虚构角色按隐式线性偏好决策，发现充分微调能让模型"自发"准确报告其习得偏好，即使没有显式自我报告监督。
- **解决什么问题 / 为什么重要**：强命中 C 的机制 / 表征几何，且与 agent 的"自我报告可信度"直接相关（非 prompt 工程）。它不满足于"行为上看模型是否忠实"，而是问：忠实自省在**网络内部结构**上长什么样、能否仅凭结构把忠实模型与不忠实模型区分开。
- **核心方法**：① 权重消融 + 冻结层实验表明，随训练推进**偏好表征向更早层迁移**——与"忠实自省需要偏好落在已有言语化机制可及之处"的假设一致；② 用**归因补丁（attribution patching）**度量"决策任务"与"自我报告任务"之间的归因相似度，发现**忠实模型的两任务归因相似度显著更高**，构成一个无需理解报告内容即可识别的忠实自省机制签名。
- **主要结果**：准确自我报告可在无显式监督下随隐式决策任务的持续微调而涌现；忠实模型表现出偏好表征前移 + 决策/报告归因高相似这两类结构差异，可据此在该受控设置下把忠实与不忠实的计算模式区分开。
- **值得追问 / 局限**：① 结论基于低秩适配器 + 虚构角色线性偏好的受限设置，能否外推到真实预训练模型对自身能力/状态的自述尚不确定；② "归因相似度"作为忠实签名是相关性证据，是否存在"高相似但仍不忠实"的反例、阈值如何定仍需更多对抗性验证。
