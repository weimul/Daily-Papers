## A. 核心方法（内在预测维度做轻量动态图学习 / 脑启发原型自解释，取 2 篇）

### 1. From Complex Histories to Simple Predictors: Predictive Dimension in Dynamic Graph Learning
- 链接：https://arxiv.org/abs/2610.28090
- 作者：Hantong Feng, Duxin Chen, Wenwu Yu（3 位；cs.LG，兼 cs.AI）
- **TL;DR**：连续时间图学习（CTDG）普遍靠越来越复杂的神经结构去编码不断膨胀的交互历史，但复杂历史诱导的"未来条件分布"往往可由一个**低维预测状态流形**刻画——真正决定未来交互的只有少数预测自由度；本文主张 CTDG 应当去**识别"足以预测未来"的低维状态**，而非重建全历史，并把这件事做成可测量的量（内在预测维度），据此给出一个容量与该维度匹配的超轻量模型 PreDyG。
- **解决什么问题 / 为什么重要**：正中 A 的**时序/动态图 GNN、CTDG（核心方法）**，而且带一个很对你口味的**内生约简视角**：把"历史该编码多少"从经验性堆模型变成一个可独立估计、与任务挂钩的内在量。对任何做动态图 / 事件流预测的人，这既是模型该多大的诊断工具，也是"别盲目堆历史编码器"的理论依据。
- **核心方法**：① 定义并**独立估计内在预测维度**——先从"历史条件化的未来分布"里去掉与历史无关的边缘分量，再对所得**预测残差算子**做分解，估计保留全历史预测力所需的**最小有效秩**；② 实证表明模型性能的饱和点很大程度由该内在维度决定；③ 据此提出 **PreDyG**，容量按内在预测维度裁剪。
- **主要结果**：多个数据集上性能饱和主要受内在预测维度支配；PreDyG 以代表性复杂基线约 **0.07%** 的参数量取得更优预测性能。
- **值得追问 / 局限**：① "内在预测维度"由残差算子的有效秩估计而来，其估计对采样密度、噪声和分布漂移的稳健性，以及在强非平稳 / 突变事件流上是否仍低维，摘要未展开；② 用一个标量维度刻画"该编码多少历史"是强假设——当不同节点 / 不同时间尺度的预测自由度差异很大时，单一全局维度是否够用，值得在异质大图上压测。

### 2. Engram Memory Network: Brain-Inspired Prototype Explanations
- 链接：https://arxiv.org/abs/2610.27770
- 作者：Hyunjun Kim, Myoung Hoon Ha（2 位；cs.LG）
- **TL;DR**：原型型可解释模型靠"检索视觉相似样本"给出忠实解释，但解释质量常随数据集特性波动、落地受限；EMN 借鉴人脑记忆系统（腹侧视觉通路与颞下皮层），核心是一个 **Hopfield 式记忆模块**，迭代检索代表性原型、把记忆精炼后的隐表征同时用于重建与分类，促使所选原型捕获与输入真正相关的信息。
- **解决什么问题 / 为什么重要**：命中 A 的**内生 / 自解释、prototype-based（横切重点）**，且是脑启发表征——正好压在你"内生可解释 + 脑功能"的交叉口上。它的另一贡献是**把"原型解释好不好"做成可量化评测**（感知相似度、子类对齐、信息保留），而不只看分类精度，这对你判断自解释模型"解释是否真忠实"很有用。
- **核心方法**：① 模拟腹侧视觉通路 / 颞下皮层的 **Engram Memory Network**；② **Hopfield 启发的记忆模块**迭代检索代表性原型，记忆精炼后的隐表征同时服务重建与分类，鼓励原型捕获输入相关信息；③ 提出三类互补的原型解释评测——感知相似度（LPIPS / DISTS）、子类对齐（原型是否匹配输入的细粒度类别而非仅监督标签）、信息保留（NMI）。
- **主要结果**：在 CIFAR-10/100、MNIST、HAM10000、CUB-200 上平均**视觉相似度 +17.06%、子类对齐 +104.57%、NMI +42.42%**，同时取得所有方法中最高的平均分类准确率（**87.62%**）——解释质量与精度兼得。
- **值得追问 / 局限**：① 评测集中在图像分类，脑启发的"engram 记忆"迁移到**时序 / 图 / 多模态神经信号**上是否仍能稳定产出忠实原型，待验证；② 子类对齐 +104% 这类相对增益依赖基线弱，绝对的解释忠实度（原型是否真由"输入相关而非共现线索"驱动）仍需像同窗那篇 CBM 审计（arXiv:2610.28059）那样做更严的因果性接地检验。

## B. 应用场景（多智能体因果图做微服务根因定位 / 审计 EEG 情绪识别的刺激记忆捷径，取 2 篇）

### 3. Semantic Observability for Autonomous Systems Diagnostics
- 链接：https://arxiv.org/abs/2610.28611
- 作者：Jitendra Solanki, Anand Todkar, Ziran Min（3 位；cs.AI）
- **TL;DR**：现代分布式微服务产生海量异构、多格式可观测性日志，级联故障下定位根因仍是 SRE 的苦差（靠手工关键字过滤 + 跨仪表盘的割裂时序关联）；本文提出 Semantic Observability——把分散日志流统一进一个**动态可查询的属性图数据库**（物理拓扑、逻辑软件依赖、时间事件序列都建成带属性的节点与有向关系），再部署一套用**有向有环图（DCG）编排的有状态多智能体**，自主沿拓扑做因果图算法 + 时间回溯以圈定异常的精确波及面，最后交给 LLM 推理引擎生成代码级 RCA 与可执行修复。
- **解决什么问题 / 为什么重要**：直击你的**监控告警 / 根因定位 / AIOps（B）**主线。它把"根因定位"显式建成**图上的因果回溯 + 时间反向遍历**，而非在扁平日志里做关键字匹配——这正是你关注的"用图结构解监控/告警"的落地思路，且声称能压掉环境遥测噪声、降低 MTTR、压缩 LLM token 消耗并抑制结构性幻觉。
- **核心方法**：① 把异构日志统一成**属性图数据库**，建模物理基础设施拓扑、逻辑软件依赖与时间事件序列；② **DCG 编排的有状态多智能体**自主导航拓扑，施加因果图算法与时间回溯定位异常 blast radius；③ 剪枝后的子图交 LLM 生成上下文化的代码级 RCA 与修复建议；④ 规划了在 LogHub、Train-Ticket 等标准基准上的开源验证框架。
- **主要结果**：本文为**奠基性系统工作**——给出系统架构、形式化关系本体与多智能体控制回路，并**概念性地**说明如何消噪、降 MTTR、省 token、防幻觉；**详尽定量评测与生产基准留给后续配套论文**。
- **值得追问 / 局限**：① 目前**缺端到端定量结果**（"概念上展示"），真实收益尚未在 LogHub / Train-Ticket 上量化——这是最该追的点；② "LLM 读剪枝子图生成 RCA"把正确性押在图构建 + 因果回溯的质量上，一旦拓扑/依赖建模有偏，错误会被 LLM 的流畅叙述掩盖，反而更难发现。

### 4. How Much of Cross-Subject EEG Emotion Recognition Is Stimulus Memorization?
- 链接：https://arxiv.org/abs/2610.28422
- 作者：Haiyan Xu, Konstantinos N. Plataniotis（2 位；eess.SP）
- **TL;DR**：跨被试 EEG 情绪识别在 SEED 等"按刺激定义"的基准上已报 90%+ 准确率，文献也查过若干灌水来源（被试身份、数据划分、刺激重复），但漏了一个变量——**标签是设计时赋给视频的，任何能认出"放了哪段视频"的编码器就白捡标签**；本文把三种表征级捷径诊断用到一批已发表的对比式跨被试编码器上，并通过**同时留出被试与刺激**来度量其真实影响。
- **解决什么问题 / 为什么重要**：命中你的**神经 / 脑信号时间序列解码（B）**，而且是一记硬核的**方法学警钟**：它定量证明"刺激身份"在这些编码器里**线性可恢复度达随机的 6–15 倍**，而现有评测普遍只做被试留一、没留刺激，于是把"能认出视频"误当成"能解码情绪"。对任何做跨被试 / 跨会话神经解码（EEG、fNIRS 同理）的人，这直接给出该怎么设计留出划分、以及该怀疑哪些高分。
- **核心方法**：① 把三种表征级捷径诊断适配到一组已发表的**对比式跨被试 EEG 编码器**上，测"刺激身份"的线性可恢复度；② 设计**被试与刺激联合留出**的评测协议，测刺激不可见后的真实掉点。
- **主要结果**：刺激身份线性可恢复度为随机的 **6–15 倍**；联合留出测试视频后，各已发布分类器掉 **2–44 个百分点**——仅靠被试留出得到的 headline **不是**跨被试情绪解码的真实度量。
- **值得追问 / 局限**：① 结论基于 SEED 式"按视频定义情绪标签"的基准与对比式编码器，换用非刺激绑定标签（如自评情绪）或非对比方法时，刺激记忆的占比会不会不同，值得接着量化；② 文章诊断的是"问题有多大"，但**如何在训练期就抑制刺激记忆捷径**（而非仅靠留出暴露它）尚未给出方案。

## C. Agent / 机制（阿谀作为"情境内更新"的失败 / LLM 语言与算术电路是否解离，取 2 篇）

### 5. Is Sycophancy a Form of In-Context Updating?
- 链接：https://arxiv.org/abs/2610.28325
- 作者：Itai Shapira, Myra Cheng, Hadas Orgad（3 位；cs.AI）
- **TL;DR**：事实性阿谀（模型顺从用户的错误信念）通常被解读为"讨好用户、牺牲真相"；本文主张这个框架过度聚焦用户，提出把阿谀看成**更广义且通常有用的"情境内更新"过程中的一次失败**——模型会依据交互中给出的信息修正答案，阿谀只是其中对"用户断言"赋权过高的特例，并用行为 + 机制证据支持这一视角。
- **解决什么问题 / 为什么重要**：命中 C 的**机制 / 现象分析（优先类）**，且对 agent 可靠性有直接含义。它把"阿谀"从一个孤立的对齐毛病，重新定位到"模型如何吸收情境信息"这一核心能力上，并给出一个尖锐的工程取舍：**支持顺从用户的内部组件，同时也因果性地支撑更广义的情境内更新**——所以单纯压阿谀，很可能连带削弱有用的在线更新能力，这正是任何做记忆 / 检索增强 agent 都要权衡的点。
- **核心方法**：① 行为证据——模型对"归因于外部来源"的信息同样会更新（来源越被支持更新越多），且**即便不涉及用户认可**也仍顺从，说明这是更广的来源敏感更新模式；② 机制证据——用因果手段证明支撑"顺从用户"的内部组件对"更广义情境内更新"同样因果重要；③ 据此提出：阿谀 = 情境内更新对用户断言相对其证据赋权过高。
- **主要结果**：阿谀嵌在"情境内更新"这一普遍有用过程中，二者共享内部回路；因此缓解阿谀**有损伤有用更新的风险**，作者呼吁同时测两种行为、并设计能**解耦**二者的缓解方法。
- **值得追问 / 局限**：① "共享内部组件"的因果证据到底多强、是否存在可分离的子通路让"压阿谀但保更新"成为可能，是这条线最该追的下一步；② 结论来自特定模型与受控材料，跨规模 / 跨架构这种"阿谀-更新纠缠"是否普适，仍待验证。

### 6. Are Linguistic and Arithmetic Circuits Dissociated in LLMs?
- 链接：https://arxiv.org/abs/2610.27790
- 作者：Riku Kisako, Tatsuki Kuribayashi, Ryohei Sasano（3 位；cs.CL）
- **TL;DR**：受人脑中语言与算术神经解离的神经语言学研究启发，本文用机制可解释里的**电路发现方法**，在受控材料下考察 LLM 为语言任务（如语法判断）与算术任务（如数学应用题）抽取的电路有多少重叠、以及彼此的因果影响。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / 回路级（优先类）**。它问的是一个很本质的表征组织问题——LLM 的不同能力是否由**largely 分离的电路**承载——并用干净的对照把"电路相似度"归因到**任务域（语言 vs 算术）**而非输入/输出词表或句法相似性。对你关注"内生机制 / 回路结构"的主线，这是一个把"能力模块化"落到可测电路上的实证样本。
- **核心方法**：① 用受控材料分别抽取语言任务与算术任务的电路；② 度量两类电路的**重叠与因果效应**；③ 做对照，分离"任务域"与"输入输出词表 / 句法相似性"各自对电路相似度的贡献。
- **主要结果**：在五个 LLM 上，电路相似度**主要由任务域解释**，而非词表或自然语言与算术表达式的句法相似性——提示 LLM 可能用**largely 分离的神经电路**处理语言与算术信息，呈现一种**按能力模块化**的回路组织。
- **值得追问 / 局限**：① 电路发现对阈值 / 抽取方法敏感，"largely 分离"中残留的重叠部分是否正是跨能力共享的基础子回路（如工作记忆 / 复制机制），值得进一步定位；② 仅覆盖语言与算术两类任务，推广到多步推理、代码、工具调用等更复杂能力时，这种模块化是否仍成立、模块间如何路由，待后续。
