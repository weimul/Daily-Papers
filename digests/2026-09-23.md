## B. 应用场景（脑功能 / 神经影像时序）

### 1. MMAP: Multimodal Missing-Aware Pretraining for Longitudinal Alzheimer's Prediction
- 链接：https://arxiv.org/abs/2609.26617
- 作者：Fiona Kekwick, Matthew Baugh, Bernhard Kainz, Paul M. Matthews, Wenjia Bai（5 位；Imperial College London 等）
- **TL;DR**：面向"影像 + 表格"多模态医学数据常见的**模态缺失 / 表格不完整**问题，提出 **MMAP** 缺失感知对齐预训练：图像编码器用 sigmoid 对比学习 + 生成式重建预训练，表格编码器基于表格基础模型，并用一个"缺失 token 生成器"让两侧编码器都能吃不完整输入，从而对缺图像或缺表格都鲁棒，用于阿尔茨海默病的纵向进展预测。
- **解决什么问题 / 为什么重要**：直接命中应用方向 B 的神经影像 / 纵向临床时序。真实临床数据里模态缺失、表格残缺极常见，且"仅用疾病标签"监督信号太弱，难从高维多模态数据学到有用表示。MMAP 把"缺失鲁棒的自监督对齐预训练"作为落地路径，贴合脑疾病进展建模这一核心兴趣。
- **核心方法**：图像编码器 = 高效 sigmoid 对比学习 + 生成重建；表格编码器 = 表格基础模型；缺失 token 生成器统一处理缺模态输入；预训练得到的图像-表格联合表示再迁移到下游纵向任务。
- **主要结果**：在两个高难度纵向临床任务（疾病阶段转化预测、淀粉样蛋白 amyloid 状态预测）上，优于多模态与单模态强基线。
- **值得追问 / 局限**：① 该工作是"影像 + 表格"多模态，而非严格的脑信号时间序列（如 EEG/fNIRS），与 B 的"时序"侧重略有偏差，纵向建模的时间维度是如何处理的需看正文；② 缺失 token 生成器在极端高缺失率或系统性（非随机）缺失下的鲁棒性、以及对下游校准的影响未在摘要给出。

### 2. Attention Guided Conditional Adversarial Learning for EMG Artifact Suppression in Single Channel EEG
- 链接：https://arxiv.org/abs/2609.26772
- 作者：Haoyi Wang, Haowei Wang, Yihang Li, Wenjie Zhang, Yibo Wang（5 位）
- **TL;DR**：肌电（EMG）活动会在宽频段压过头皮 EEG、掩盖神经结构，本文评估 **P2P-Trans** 条件对抗去噪器——U 形编解码器 + 瓶颈处多头自注意力 + 交叉注意力引导的跳连融合 + PatchGAN 判别器——用于单通道 EEG 的 EMG 伪迹抑制。
- **解决什么问题 / 为什么重要**：命中 B 的脑信号 / EEG 预处理。EEG 去伪迹是脑机接口与神经分析的上游关键，单通道、低信噪比场景尤难；把注意力引导 + 对抗恢复引入该问题，对下游脑信号建模的质量有直接影响。
- **核心方法**：在 EEGdenoiseNet 片段（1024 采样点序列）上，按 -7 至 2 dB 十个信噪比合成配对混合信号；P2P-Trans 以条件对抗方式学习从含噪到干净的映射，注意力机制聚焦被 EMG 污染的时频结构。
- **主要结果**：训练 50000、测试 5980 样例；对比五个卷积编解码基线，P2P-Trans 取得最高平均相关系数 0.8645、最低平均频谱 RRMSE 0.3596；但平均时域 RRMSE 为 0.5797 并未领先——即在"频谱抑制"与"逐点波形保真"之间存在权衡；优势在强污染下最明显。
- **值得追问 / 局限**：① 作者自陈需要**被试无关（subject-independent）评估、直接一维建模、下游任务验证**——当前仅在合成配对、段级指标上验证，泛化与实用性尚未证实；② 时域保真落后意味着若下游任务依赖精确波形（如 ERP 成分），该去噪可能引入偏差。

## C. 机制 / 表征分析 + Agent（高优先级，取 4 篇）

### 3. A Spectral Theory of Grokking: Weight Decay induces Feature Learning
- 链接：https://arxiv.org/abs/2609.26679
- 作者：Lenz Pracher, Pascal de Jong, Oskar Lieshaus, Alan Jeffares, Steffen Rulands（5 位）
- **TL;DR**：给出 **grokking（延迟泛化）的定量谱理论**：对齐次网络 + 平方损失 + L2 权重衰减，证明记忆之后仍残留有限残差（NTK 小特征值方向残差更大），这些残差反馈驱动 NTK 自身演化；把动力学投影到任务相关谱方向得到一个约化系统——"残差驱动的核增长"与"权重衰减"相互竞争，从而机制性地解释了从惰性（lazy/NTK）到富特征学习（rich）的相变如何产生延迟泛化。
- **解决什么问题 / 为什么重要**：正中 C 方向的训练动态 + 表征几何 + 机制推导。grokking 是理解"泛化何时/为何发生"的经典现象，此前多为经验观察；本文把它落成可预测的谱动力学理论，直接连接"记忆后的特征学习"与"泛化起点及其相图"。
- **核心方法**：齐次网络平方损失 + L2 的残差分析；将 NTK 演化投影到任务相关谱方向得约化 ODE；在模块化加法（modular addition）上验证——齐次 MLP 与单块 Transformer。
- **主要结果**：① 预测 grokking 时间标度由 **学习率 × 权重衰减** 的乘积控制，且在临界衰减附近特征学习按对数变慢、超过临界则任务对齐 NTK 结构无法支撑泛化、更强衰减甚至完全阻止拟合；② MLP 上 84×90 网格（学习率 × 权重衰减）复现了预测的相图几何与泛化时间的"逆乘积"标度；③ 单块 Transformer 在 42×45 网格上呈现同样的宏观相结构与相变时间标度（尽管不严格满足齐次性）。
- **值得追问 / 局限**：① 理论建立在齐次网络 + 平方损失 + 模块化加法这一受控设定，向交叉熵、真实大模型/自然任务的外推仍需检验（Transformer 结果已是初步松绑齐次性的证据）；② "任务相关谱方向"在真实高维任务里如何识别、理论对架构/初始化的敏感度仍开放。

### 4. SpeakerMem-R1: Speaker-Centered Dual-Track Memory for Multi-Party Dialogue
- 链接：https://arxiv.org/abs/2609.26780
- 作者：Haobo Zheng, Tan Tang, Yan Chen, Weijie Wang, Yingcai Wu（5 位）
- **TL;DR**：面向多方对话的长期记忆，指出通用 LLM 记忆系统常丢失"谁说了什么、涉及谁、彼此如何看待、群体共享什么、状态如何随时间变化"，提出 **SpeakerMem-R1** 双轨记忆：一轨存说话人标注的逐字消息、一轨存派生状态并按人物级 / 群体级视图组织，查询时按实体、事件、时间融合两轨证据；并训练 Writer-R1（SpeakerLevenshtein + 说话人条件 GRPO）以降低结构化记忆构建时的归属/更新错误、支持本地部署。
- **解决什么问题 / 为什么重要**：命中 Agent 方向的"优先：memory"。多方对话把"消息归属 + 关系理解 + 从交错历史重建状态"变成核心瓶颈，纯检索式文本记忆易丢人物/群体关系。SpeakerMem-R1 用"逐字轨 + 结构化状态轨 + 人物/群体视图"直面这两个瓶颈，是 agent 长期记忆机制上的具体推进。
- **核心方法**：双轨存储（说话人标注逐字消息 + 派生状态，人物级/群体级视图）→ 查询时按实体/事件/时间跨轨融合；Writer-R1 用 SpeakerLevenshtein 与说话人条件 GRPO 进行强化学习，减少归属与状态更新错误。
- **主要结果**：GroupMemBench / SocialMemBench / EverMemBench 二元准确率分别 47.9% / 69.2% / 61.9%；EverMemBench 公开榜达 62.33%（最新 SOTA 框架中最佳）；LoCoMo 全部 1986 题达 70.85%；305 题受控评测中 RL 把 SFT Writer 均准从 57.38% 提到 68.20%；消融显示逐字轨与结构化轨、人物级与群体级视图互补。
- **值得追问 / 局限**：① 双轨 + 双视图带来的存储/查询开销随对话人数与时长如何增长、是否有可扩展性瓶颈，摘要未量化；② 多方基准上的绝对准确率仍偏低（GroupMemBench 47.9%），说明"消息归属 + 关系状态重建"远未解决，Writer 的归属错误上限有多硬需看正文。

### 5. Capable yet Parsimonious: Extracting and Characterizing Hidden Chain-of-Thought in Frontier Models
- 链接：https://arxiv.org/abs/2609.26637
- 作者：Xiaoyu Luo, Tao Ren, Wenrui Yu, Xiao Li, Qiongxiu Li, Johannes Bjerva（6 位）
- **TL;DR**：闭源前沿模型的原始 CoT 被隐藏、无法核验；本文**通过标准 API 注册一个简单自定义工具**诱导前沿模型把中间推理外化，并先在开源模型上对照"原生 CoT"验证抽取到的推理确实反映真实推理（而非事后合理化），再扩展到含 GPT-6 Astra 的闭源模型，系统刻画前沿模型如何组织中间推理。
- **解决什么问题 / 为什么重要**：命中 C 的机制/现象分析。前沿模型能力提升普遍归因于"推理增强"，但闭源系统隐藏 CoT 使这一点无法验证。本文提供一个"行为透镜"——在不接触权重的前提下抽取并结构化分析前沿模型推理，对理解"能力从何而来"及推理可审计性有价值。
- **核心方法**：借标准 API 的自定义工具特性诱导模型外化中间推理；先在开源模型上以原生 CoT 为基准验证抽取推理的有效性（对比无推理基线）；再在竞赛数学、科学、代码生成上刻画 token 效率、推理步类型与诱导出的推理树。
- **主要结果**：抽取到的推理性能匹配原生推理、显著优于无推理基线（跨数学/科学/代码）；不同模型在外化、压缩、组织推理上有系统差异；GPT-6 Astra 表现出**token 高效的定向推理**——更早锁定正确轨迹、内部消化初等步、只外化关键推理。
- **值得追问 / 局限**：① "自定义工具诱导外化"得到的痕迹是否等同于模型内部真实计算，仍是根本性开放问题（开源对照缓解但不等于证明）；② 结论依赖特定 API 特性与被测模型，跨厂商/版本的稳健性、以及"外化推理"是否可被模型策略性伪装，需谨慎。

### 6. Greedy Decoding Is Not Precision-Invariant: Cross-Precision Output Divergence in LLM Inference
- 链接：https://arxiv.org/abs/2609.26621
- 作者：Gaoyuan Du, Anam Nawaz Khan, Rex Zhou, Xiaoyang Liu, Deepayan Chakrabarti, Fnu Suya（7 位）
- **TL;DR**：贪心解码常被当作确定性输出，本文证明它**并非精度不变**——同一模型、prompt、解码算法在同一硬件上，BF16 与 FP16 会产生不同输出；给出误差传播分析，指出翻转与否主要取决于 **LM head 处 top-2 logit 边距**相对于扰动方向，并提出低开销的"边距触发式 FP32 LM head 重算"作为部分缓解。
- **解决什么问题 / 为什么重要**：命中 C 的机制/现象分析。可复现性与确定性是评测、审计、调试的基础假设，本文用受控实验 + 误差传播理论揭穿"贪心=确定"的迷思，并定位到 LM head logit 边距这一可解释的因果因子，对推理系统设计与结果可信度有直接含义。
- **核心方法**：跨 6 个模型（1.1B–7B，四个家族；12B 上补充刻画）、3 个基准比较 BF16/FP16 输出；构建经验误差传播分析（发现 22 层累积体误差不区分翻转步，关键在 LM head top-2 边距与 top-2 候选间方向扰动的关系）；据此做出五条可检验预测并逐一验证。
- **主要结果**：49–100% 的 prompt 发生发散，单 token 翻转常级联为轨迹级发散；五条预测（含"更多 FP32 计算反而更差"）全部命中；"边距低于阈值才触发的选择性 FP32 LM head 重算"在 A10G 上 +22–36pp 精确一致（L4/A100 +12–21pp），延迟开销 <4%（低批 batch≤4）；但在 batch≥8 或端到端 FP8 下体误差主导时收益消失——属部分缓解而非通用确定性保证。
- **值得追问 / 局限**：① 缓解仅在低批、体误差不主导时有效，高吞吐服务（大 batch / FP8）场景基本失效，实用边界较窄；② 作者假设"训练期精度稳定性"是决定因素但未证实，跨更大模型 / 更多精度格式的规律仍待验证。
