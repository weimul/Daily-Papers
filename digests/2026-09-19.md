## A. 核心方法（联邦时空预测 · 关系对齐的时序目标）

### 1. FedeRICo: Federated Region-Influenced Coupling for Traffic Flow Prediction
- 链接：https://arxiv.org/abs/2609.20026
- 作者：Fermin Orozco, Man Luo, Johan Wahlström（3 位作者；机构未在元数据中给出）
- **TL;DR**：面向"数据无法互通"的联邦时空交通预测——每个客户端只看到自己那块传感器子图，路网被切开导致跨边界的交通传播断裂；本文用"梯度级协作 + 边界残差通信"在不共享原始数据、也不粗暴聚合参数的前提下把跨客户端空间依赖接回来。
- **解决什么问题 / 为什么重要**：正落在核心方向 A 的时空建模面。现有联邦时空方法多靠模型参数聚合，既会稀释客户端各自的表征，又因路网切分破坏了跨边界的动态传播。FedeRICo 给出一条"既保私有特性、又恢复跨界空间耦合"的路线，对隐私/商业约束下的多方时空图学习有参考价值。
- **核心方法**：双分支预测架构——全局引导分支捕获可迁移的预测结构、私有残差分支保留客户端特定修正并吸收边界残差信号；全局分支经跨客户端**梯度对齐**协调优化，避免破坏性的参数干扰；跨界依赖则通过**趋势-残差分解**抽取边界消息，压掉周期结构、只在物理相邻客户端间传瞬态时空残差。
- **主要结果**：在四个真实交通预测基准上一致超过 SOTA 联邦时空基线，同时训练运行时间保持竞争力。
- **值得追问 / 局限**：① 只在"物理相邻"客户端间传边界残差，对拓扑重叠/跨区长程依赖是否够用？② 趋势-残差分解压掉周期结构后，遇到强周期主导的路段是否会丢掉有用信号，值得看正文的消融。

### 2. CoRe: Coherence and Relational Alignment for Multivariate Time Series Forecasting
- 链接：https://arxiv.org/abs/2609.19670
- 作者：Xiaoyu Lin, Huiran Duan, Yining Liu, Zhixiang Wu, Chu Lin, Lin Lu（6 位作者；机构未在元数据中给出）
- **TL;DR**：直接多步预测虽一次吐出整段未来，但训练目标常仍被拆成逐点 MSE，既不保每个变量内部的时间连贯、也不保跨变量的关系一致；CoRe 用两项输出空间约束替代逐点监督，且不引入任何可训练参数、只改损失即可插到现有骨干上。
- **解决什么问题 / 为什么重要**：命中 A 的"关系结构先验"横切。逐点误差是稳定却"结构盲"的监督；CoRe 把"未来轨迹的结构"显式写进目标，属于方法论层面的即插即用改造，对时序/图时序预测骨干普遍适用。
- **核心方法**：① 频域相干损失，对齐预测谱与目标谱以保时间连贯；② 低秩关系图损失，在由目标导出的 PCA 子空间里匹配采样得到的成对差异，以保跨变量关系一致。整体无可训练参数，仅替换损失函数即可用于既有骨干。
- **主要结果**：在标准基准上提升多个强基线，与近期预测目标相比表现占优，并在不同骨干、数据集与超参设置下保持稳定有效。
- **值得追问 / 局限**：① 关系图从目标数据的 PCA 子空间导出，属"数据驱动的静态关系"，对随时间演化的动态依赖（更接近动态图场景）能否刻画尚不清楚；② 低秩假设在强非线性/高秩耦合系统上的适用边界值得追问。

## B. 应用场景（脑功能：EEG 认知态分类与便携头环心流检测）

### 3. Deep Learning-Based Classification of Cognitive and Resting States Using Electroencephalography Signals
- 链接：https://arxiv.org/abs/2609.20467
- 作者：K. A. Januka S. Fernando, Harshit Srivastava（2 位作者；机构未在元数据中给出）
- **TL;DR**：用 CNN+GRU 加时频分析，从 EEG 里区分"静息态 vs 三类认知任务态（数学 / 记忆 / 听音乐）"，验证信号处理与深度学习结合在脑活动状态判别上的有效性。
- **解决什么问题 / 为什么重要**：落在应用方向 B 的"脑功能 / 神经影像时序"面，与我关注的 fNIRS / 脑功能状态解码在任务范式（静息 vs 任务态）上高度邻近，可作为跨模态迁移（EEG→fNIRS）时的方法与基线参考。
- **核心方法**：CNN 堆叠 GRU 抽取 EEG 时空/时序特征；先做时频分析凸显信号显著成分，再把特征喂给包括所提 2D-Net 在内的多种深度/传统分类器对比评估。
- **主要结果**：静息 vs 数学任务 83.18%、静息 vs 记忆任务 76.11%、静息 vs 听音乐任务 83.43% 准确率，均优于所比较方法。
- **值得追问 / 局限**：① 记忆任务准确率明显偏低（76%），说明不同认知负荷的可分性差异大，泛化到更细粒度状态时挑战更大；② 摘要未说明是否做被试独立评测（跨被试），若为被试内划分则实际部署泛化性需打折。

### 4. Practical flow state detection: Entropy-based EEG classification from portable EEG headbands
- 链接：https://arxiv.org/abs/2609.19737
- 作者：Matin Beiramvand, Reijo Koivula, Tarmo Lipping（3 位作者；机构未在元数据中给出）
- **TL;DR**：用两款消费级可穿戴 EEG 头环（Muse-S、Emotiv Insight），在 45 名被试玩自适应俄罗斯方块时采集数据，验证"熵类生物标志物 + 随机森林"能否做鲁棒、被试独立的心流状态检测。
- **解决什么问题 / 为什么重要**：命中 B 的脑功能时序方向，且强调"消费级设备 + 真实部署"的可落地性——这正是脑功能状态解码走向现场应用（含 fNIRS 便携化）最关心的问题：跨被试到底还剩多少准确率。
- **核心方法**：去噪后用离散小波变换（DWT）分解到多个频率子带；每个子带抽取通道内熵（Slope / Distribution / Spectral Entropy）与跨通道熵（Cross Distribution / Cross Spectral Entropy），送入随机森林，并用随机采样（RS）与留一被试（LOSO）两种方案评估。
- **主要结果**：随机采样交叉验证下 RF 平均 97%；更严格的 LOSO 下平均 75%，显示真实的跨被试泛化能力；多分类器验证（SVM-RBF、GentleBoost、k-NN、判别分析、朴素贝叶斯）确认熵标志物在不同建模框架下稳健。
- **值得追问 / 局限**：① RS 97% 与 LOSO 75% 差距 22 个百分点，提醒随机划分会严重高估现场表现——评测方案的选择比模型更影响结论；② 单一任务范式（俄罗斯方块诱导心流）下的标志物，能否迁移到学习/康复等真实场景仍待验证。

## C. Agent / 机制分析（激活转向的自动发现 · Agent harness 价值拆解）

### 5. Deep Noir: Autonomous Steering Discovery via Architectural Chronometry in Transformer Models
- 链接：https://arxiv.org/abs/2609.20722
- 作者：Frank E. Bobe, Gregory D. Vetaw, Darshan W. Bryner, Matthew G. Cook, Jose L. Salas-Vernis（5 位作者；机构未在元数据中给出）
- **TL;DR**：激活转向（activation steering）能在推理时改 LLM 行为，但"在哪一层、加多强"至今靠手工试；Deep Noir 用 Logit Lens 收敛 + 因果性的注意力头级归因，自动发现最优转向参数。
- **解决什么问题 / 为什么重要**：命中方向 C 的"机制/现象分析、残差流/表征结构"优先项——把可解释性里的 Logit Lens 与因果头归因用作"自动定位干预点"的工具，而非事后归因，属机制驱动的方法工作。
- **核心方法**：以 Logit Lens 在层间的收敛行为定位"何处该转向"，用因果性的 head-level 归因确定强度；跨 1B×3、2–3B×2、7–9B×4 三档规模与多种架构验证其自动发现的干预点可跨任务/跨架构泛化。
- **主要结果**：spam 任务在 1B 上提升 16.7 个百分点（39 次运行，SD 4.7），7–9B 四种架构上提升 21–42 个百分点；SST-2 情感任务零代码改动提升 13.1 个百分点，且在无 head masking 时 RepE 无提升而 Deep Noir 对所有模型都改善（p<0.01）。此外发现转向会制造可预测的 prompt-injection 攻击面，脆弱性随转向幅度单调上升——对部署"被转向分类器"的 agent 系统是重要安全提示。
- **值得追问 / 局限**：① 转向幅度越大越有效、但注入攻击面也越大，二者的安全-效用权衡如何定量取舍未展开；② "架构计时学（architectural chronometry）"这一定位信号在更长上下文/更深模型上的稳定性需要更多验证。

### 6. How Do Agent Harnesses Create Value? Planning Information and Release Control in Stateful LLM Agents
- 链接：https://arxiv.org/abs/2609.20474
- 作者：Yukun Zhang, Kemu Xu, Yishen Chen（3 位作者；机构未在元数据中给出）
- **TL;DR**：Agent harness 提供规划指导、组织执行、检查完成——本文用对照实验把"规划指导的内容"与"验证器"各自的贡献分离开，量化它们对成功率、错误接受、成本的影响。
- **解决什么问题 / 为什么重要**：命中 C 的"planning / 机制现象分析"优先项，且刻意避开纯 prompt 技巧：核心对照是把预写的任务专属计划（Fixed）与"字数匹配但打乱的政策文本"（Sham）对比，从而干净地隔离"规划内容本身"的因果贡献——这是把 agent harness 当科学对象来拆的实证工作。
- **核心方法**：在 τ²-bench 的两个 Retail 实验与一个 Airline 试点上，用 Fixed vs Sham 隔离规划内容贡献；并评估一个只读终端验证器的收益/代价，跨 265 个匹配单元做任务聚类自助法置信区间。
- **主要结果**：Fixed 相比 Sham 把 oracle 验证的成功率提升 7.17 个百分点（90% 任务聚类自助区间 1.15–13.36），增益集中在高复杂度任务；只读验证器以每回合<1 美分的额外成本，拒掉 61% 的 oracle-无效回合、同时误扣 17% 的正确回合。关键结论：哪个组件更重要取决于"错误接受"的代价——低责任场景规划增益主导，高责任场景验证器避免的误通过主导，且独立验证器能以整套"规划+验证"栈一小部分的成本捕获几乎全部误通过收益。
- **值得追问 / 局限**：① 结论基于 τ²-bench 的 Retail/Airline 场景，向工具更丰富、状态更长的真实 agent 任务迁移性待验证；② "独立验证器几乎复现全栈误通过收益"是否意味着规划指导在高责任场景性价比偏低，需结合具体任务的成功增益与验证成本再判断。
