## A. 核心方法（时变图信号 / 时空点过程，取 2 篇）

### 1. Unrolled Time-Varying Graph Signal Restoration under Spatiotemporal Smoothness Priors
- 链接：https://arxiv.org/abs/2610.11359
- 作者：Hayate Kojima, Hikari Noguchi, Koki Yamada, Yuichi Tanaka（4 位；eess.SP）
- **TL;DR**：传感器网络这类"空间上非均匀分布、时间上成序列"的信号常含噪声与缺失，恢复必须同时吃进空间与时间关系；本文把一个带**时空正则项**（空间用 Sobolev 算子、时间用多抽头 FIR 滤波器）的优化问题，用**深度算法展开（DAU）**把共轭梯度迭代逐步"拆开"成可学习层，在每次迭代里学正则参数与滤波系数。
- **解决什么问题 / 为什么重要**：正中 A 的时空图学习 + 不规则采样时序。它不堆黑箱网络，而是把图信号恢复的凸优化求解器展开成可训练结构，既保留优化问题的可解释先验（空间平滑 + 时间平滑），又让参数端到端可学；对"图上随时间演化的信号"（动态图信号）给出一个有原理且轻量的恢复范式。
- **核心方法**：时空正则化优化问题（Sobolev 空间平滑 + 多抽头 FIR 时间平滑）→ 展开共轭梯度迭代为可学习层，逐迭代学正则系数与滤波器 → 支持有监督批处理 / 有监督在线 / 无监督批处理三种设置。
- **主要结果**：在多个合成与真实数据集上，有监督批处理法几乎在所有情形取得最低 RMSE；有监督在线与无监督批处理法各自在其设置下超越现有方法，且常能与现有批处理法竞争。
- **值得追问 / 局限**：① 时间平滑用固定 FIR + Sobolev 空间先验，面对突变/非平稳事件（如告警尖峰）这类"反平滑"信号是否会过度抹平值得追问；② 展开层数、图规模与在线设置下的实时性/内存成本文中以 RMSE 胜负为主，大规模动态图上的可扩展性细节偏少。

### 2. ISBO: Scalable Spatio-Temporal Bayesian Optimization with Log Gaussian Cox Process Models via the INLA-SPDE Approach
- 链接：https://arxiv.org/abs/2610.12213
- 作者：Kaichuang Yang, Håvard Rue, Jakob Zeitler（3 位；stat.ML / cs.LG，含 INLA 奠基人 Håvard Rue）
- **TL;DR**：标准高斯过程贝叶斯优化（BO）不适配时空问题里常用的**双随机 Cox 点过程**；ISBO 是首个面向时空数据的可扩展 BO 框架，用**对数高斯 Cox 过程（LGCP）**建模对数强度，并用 **INLA-SPDE**（积分嵌套拉普拉斯近似 + 随机偏微分方程）做推断。
- **解决什么问题 / 为什么重要**：命中 A 的连续时空建模 + 点过程族（时间/时空点过程是 A 的关注点之一）。它用 Matérn 场在网格上得到稀疏高斯马尔可夫随机场，INLA 在序贯优化中反复给出快速且精确的后验，从而能在"事件强度随时空变化"的场景里，以极少评估次数稳定定位高强度区域与隐强度峰值——把点过程推断与黑箱优化干净地接在一起。
- **核心方法**：LGCP 建对数强度 → Matérn/SPDE 得稀疏 GMRF、INLA 做快速后验 → 时变 UCB 采集函数 + 掩码避免重复采样、惩罚复杂度（PC）先验正则化早期轮次。
- **主要结果**：在合成与真实时空数据集上实现精确的峰值发现与强度恢复，并相对基于 RKHS 的基线有显著加速，定位为点过程数据 BO 的实用选择。
- **值得追问 / 局限**：① INLA-SPDE 对网格分辨率与 Matérn 参数化较敏感，高维时空或强非平稳强度场下的近似质量与可扩展性需进一步验证；② "少量评估定位峰值"的结论依赖隐强度相对平滑的假设，面向尖锐/多峰强度（如突发事件簇）时的鲁棒性尚待展开。

## B. 应用场景（通用图异常检测 / agent 轨迹实时监控，取 2 篇）

### 3. Is Real-World Training Data Necessary for Generalist Graph Anomaly Detection?
- 链接：https://arxiv.org/abs/2610.12167
- 作者：Yujing Liu, Yixin Liu, Yue Tan, Xiaofeng Cao, Alan Wee-Chung Liew, Heng Tao Shen 等（7 位；cs.LG）
- **TL;DR**：通用图异常检测（GAD）想训一个"无需重训/微调即可在任意未见图上检测异常"的基座，但真实异常图稀缺且标注昂贵；本文提出 **AG-FORGE** 合成异常图"锻造厂"探索纯合成数据训练的可行性，并发现合成数据能逼近真实数据的效果、但受限于现有方法容量而难再突破，遂设计 **TS-GGAD**（拓扑-语义协同）进一步释放容量。
- **解决什么问题 / 为什么重要**：正中 B 的异常检测，且是 A×B 交叉（图学习 + 异常检测基座模型）。它直面"基座训练缺数据"这一现实瓶颈，用可控合成数据替代昂贵真实异常标注，并通过拓扑/语义两路互补证据 + 课程学习把合成规模化训练的红利吃满——对把异常检测做成"开箱即用基座"这一方向有实证价值。
- **核心方法**：AG-FORGE 自动合成异常图（供规模化训练）→ TS-GGAD 以拓扑与语义协同捕捉互补异常证据 → 面向大规模合成训练的课程学习策略。
- **主要结果**：在 14 个真实数据集上，用 AG-FORGE 合成数据训练的 TS-GGAD 显著优于 SOTA 方法；同时实证"合成数据可达到与真实训练可比的效果"。
- **值得追问 / 局限**：① 合成图的异常先验来自人为生成器，是否覆盖真实世界异常的分布（尤其罕见/对抗性异常）决定了泛化上限，合成-真实分布差距需量化；② "无需微调即泛化到任意图"的通用性主要在静态属性图上验证，迁到时序图/动态图或领域外结构时是否仍稳健尚未展开。

### 4. OnTrack: Real-Time Monitoring and Intervention in LLM Agent Trajectories via Streaming Structure-Aware Optimal Transport
- 链接：https://arxiv.org/abs/2610.12375
- 作者：Babak Barazandeh, Connor Swanson, Chinmay Kulkarni, Nikhil Mungel（4 位；cs.AI / cs.CL / cs.LG）
- **TL;DR**：LLM agent 常以最少规则护栏自主执行（行程规划、股票交易、IT 事件分诊等），不可逆动作带来成本与安全隐患；现有做法要么用守卫 agent 每步监控（加成本与延迟）、要么事后查日志（代价已付）。OnTrack 用**流式监控**把当前步骤与依赖同"历史成功轨迹"对比，约 1 毫秒/步即可告警或拦截。
- **解决什么问题 / 为什么重要**：命中 B 的监控告警-干预闭环（IT incident triage 即 AIOps 同族），且是**机制 / 系统导向而非 prompt 工程**——它不靠提示词约束模型，而是把 agent 步骤序列与依赖结构建成可比对象、用结构感知最优传输在线判定偏离。论文还系统地研究了"访问权递减"三档（全参考访问 / 仅工具 schema / 仅步骤日志）下监控能力如何退化，给出可落地的分级监控图景。
- **核心方法**：把 agent 步骤 + 依赖与录制的成功轨迹做流式结构感知最优传输比对 → 约 1ms/步给出告警/拦截 → 三档访问（历史运行 + 工具 schema / 仅 schema / 仅步骤日志）下分别支持从计划违背检测到识别死循环、卡顿、重复工具调用。
- **主要结果**：在 SWE-bench 轨迹上，仅凭前 8 步即把失败轨迹排在成功轨迹之下（较内容相似度基线 +0.057 AUROC）；配合中止策略约省下 18% 本会烧在失败运行上的算力，被中断运行中 83% 确实在走向失败（6 次中止里 5 次正确）。
- **值得追问 / 局限**：① 监控依赖"录制的成功轨迹"作参考，面对全新任务/无历史参考时能力退化到仅能抓循环/卡顿等结构性异常，语义层面的偏离仍难判；② 评估主要在 SWE-bench 编程轨迹，样本规模（如 6 次中止）偏小，跨任务域（交易、分诊）与对抗性绕行下的误拦/漏拦率尚待验证。

## C. 机制 / 表征分析（高优先级，取 2 篇）

### 5. The Ball and the Box: Two Geometries of Computation in Superposition
- 链接：https://arxiv.org/abs/2610.11744
- 作者：Xiaoyu Li, Lequan Lin, Dai Shi, Jiaojiao Jiang, Junbin Gao, Andi Han（6 位；cs.LG）
- **TL;DR**：神经表征能在维度之外多塞特征（叠加 / superposition）；本文问：从这种叠加表征里**计算 Boolean 逻辑门**到底需要多少维度？在单阈值层 + 高斯随机字典 + 稀疏布尔输入下，作者在两种误差判据下推出**尖锐的维度相变阈值**。
- **解决什么问题 / 为什么重要**：强命中 C 的表征几何（叠加、可靠计算的维度下界），纯理论机制分析、非 prompt 工程。它揭示"期望错误计数消失"与"高概率逐输出全对"所需维度不同——差距来自**共享读出**：罕见实现可一次性引发多处错误。前者呈"球几何"、后者（对每个特征元组都评估门时）呈"盒几何"，并对合取/析取/多数门给出显式阈值，为"叠加下计算的容量"给出可验证的几何刻画。
- **核心方法**：单阈值层 + 高斯随机字典 + 均匀稀疏布尔输入 → 两种误差判据（期望错误计数 vs 联合可靠性）各自的尖锐维度阈值 → 优化共享读出权重与偏置得合取/析取/多数门显式阈值，并刻画成对合取在阈值附近的相变（与精确模拟吻合）。
- **主要结果**：给出两判据下的尖锐维度阈值与门类型相关的显式表达，理论相变与精确仿真一致；明确"球几何（期望计数）"与"盒几何（联合可靠）"的分野及其由共享读出导致的差距。
- **值得追问 / 局限**：① 结论建立在高斯随机字典 + 单阈值层的理想设定上，真实网络的学习字典、多层组合与非布尔计算下几何是否仍成立需验证；② "盒几何需要更多维度"主要对逻辑门这类离散计算成立，对连续特征回归/生成类计算的推广未展开。

### 6. Looking Inside LLMs: Small-World Connectivity as a Signature of Reasoning Performance
- 链接：https://arxiv.org/abs/2610.12304
- 作者：Zheng Huang, Sansheng Cao, Enpei Zhang, Weikang Qiu, Elynn Chen, Xiang Zhang 等（10 位；cs.AI）
- **TL;DR**：受神经科学"更高智力对应脑功能网络更强小世界组织"启发，本文把 LLM 注意力头激活相似度构成**功能图**，发现更高的**小世界指数（SWI）**（高局部聚类 + 短全局路径）跨模型与训练检查点一致地与更强流体推理相关，并据此做剪枝验证因果性。
- **解决什么问题 / 为什么重要**：强命中 C 的表征几何 / 机制分析（内部组织结构作为能力签名），同时借用脑网络（brain network）视角，是难得的"神经科学×LLM 可解释性"交叉。它超越行为评测，把"推理能力"落到可测量的内部连接结构上，并提出重要注意力头倾向"社区内高核心分数、跨社区低桥接分数"的结构指标——给 LLM 能力一个可操作的结构性解释。
- **核心方法**：由注意力头激活相似度建功能图 → 算小世界指数（局部聚类 + 短路径）并与流体推理相关联 → 用核心分数 / 桥接分数刻画重要头的社区内/跨社区连接 → 据此提出 Small-World Allocation（SWA）分层稀疏分配做剪枝验证。
- **主要结果**：SWI 跨模型与训练检查点与推理表现一致正相关；重要头呈高核心分数 + 低桥接分数；SWA 在六个 LLM 上比竞争的稀疏分配策略更好地保住小世界组织与性能，WikiText 困惑度最多降低 20%。
- **值得追问 / 局限**：① "小世界组织 ↔ 推理能力"主要是相关性 + 剪枝干预证据，是否存在混杂因素（如规模、数据量同时驱动二者）需更严格的因果分离；② 功能图由注意力头激活相似度构建，对相似度度量与阈值的选择较敏感，不同建图方式下 SWI 结论的稳健性尚待系统检验。
