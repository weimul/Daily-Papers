## A. 核心方法（时序点过程/事件流 · 图信息流与信息瓶颈自解释）

### 1. Probabilistic Forecasting of Business Process Executions with Neural Temporal Point Processes
- 链接：https://arxiv.org/abs/2609.21382
- 作者：Jiaxin Yuan, Daniela Grigori, Han van der Aa（3 位作者；过程挖掘方向）
- **TL;DR**：把"运行中业务流程接下来会怎样"的预测，从主流的判别式/确定式（只吐一个下一活动 + 一个剩余时间点估计）改成用**标记时序点过程（marked TPP）**做生成式序列建模，从而"按构造"给出下一事件类型与到达时间的联合预测分布。
- **解决什么问题 / 为什么重要**：服务化系统的运维决策依赖"接下来如何"的预测，而只有当预测带可靠性（分布/校准）时才可操作。这篇正中核心方向里的事件流 / 连续时间点过程建模，把预测过程预测（PPM）与 TPP 打通；且直面真实事件日志里"连续事件常带相同时间戳"这一违背简单点过程假设的现实问题。
- **核心方法**：Transformer 编码器 + 对到达间隔的混合密度解码器，定义"下一标记 + 事件间隔"的联合密度，用精确对数似然训练；显式处理时间戳并列（ties）这一简单点过程被违背的情形；单次前向即得完整预测分布，无需采样。
- **主要结果**：在 10 个公开日志上，点预测精度与判别式基线持平，但在剩余时间分布的**校准度与锐度**上明显占优；且推理最省——一次前向拿到完整分布，无采样开销。
- **值得追问 / 局限**：① 混合解码器对"长尾/多峰间隔"与并发/交错轨迹（非严格顺序流程）的建模能力有多强；② 校准优势是否随日志规模、概念漂移（流程随时间变化）而退化，缺少在线/流式设定的验证。

### 2. Detecting Hallucination in LLMs: Tracing the Topological Signatures of Impaired Context Sharing
- 链接：https://arxiv.org/abs/2609.21096
- 作者：Amir Jalilifard, Anderson Rocha, Eric Wong, Marcos Medeiros Raimundo（含 UPenn Eric Wong、UNICAMP 等）
- **TL;DR**：把注意力矩阵看成图，用 **Forman-Ricci 曲率**刻画"信息瓶颈/过度压缩（over-squashing）"这类图结构信号，单次前向就把幻觉回答从正常回答里区分出来。
- **解决什么问题 / 为什么重要**：幻觉检测多靠多次采样一致性或事后归因，代价高且非内生。本文命中核心方向的"信息瓶颈 + 图（GNN 概念）+ 内生自解释"横切——它不引入外部裁判、不做多次生成，而是直接读注意力图的拓扑，把"token 间上下文共享受损"作为幻觉的结构证据，兼具可解释性与低成本。
- **核心方法**：分析注意力图的 Forman-Ricci 曲率以定位信息瓶颈；再设计一种同时捕捉注意力头"半局部 + 全局"信息流特征的表示，用于分类幻觉/非幻觉响应；全程单次前向（single-pass）。
- **主要结果**：在两个幻觉检测基准、多种 LLM 架构上，单次前向法一致优于已有的基于注意力与多响应一致性的基线；分析显示幻觉回答一致表现为**过度依赖自注意力、对早前 token 的上下文检索弥散、信息在最后一层过度压缩**。
- **值得追问 / 局限**：① 曲率/拓扑特征是否会随模型规模、领域（长上下文 vs 短问答）漂移，跨架构阈值迁移性如何；② "过度压缩→幻觉"是相关还是因果，能否据此做内生干预（而非仅检测）仍待验证。

## B. 应用场景（fNIRS 脑机接口 · 微服务根因分析 AIOps）

### 3. Bio-MF: Low-Latency and High-Fidelity EEG-to-fNIRS Cross-Modal Generation for Hybrid Motor-Imagery Brain–Computer Interfaces
- 链接：https://arxiv.org/abs/2609.20904
- 作者：Boyuan Zhao, Sifan Zhang, Luping Chen（3 位作者）
- **TL;DR**：面向 EEG+fNIRS 混合运动想象脑机接口，当难以同步采集 fNIRS 时，用**一步生成（MeanFlow）**框架从 EEG 直接合成高保真 fNIRS 信号，单次网络评估 7 ms 完成，兼顾实时性与下游解码收益。
- **解决什么问题 / 为什么重要**：直接命中应用方向 B 的 fNIRS / 脑功能近红外专题。混合 MI-BCI 能靠电生理 + 血流动力学互补信息胜过纯 EEG，但真机同步采集 fNIRS 不便；已有 EEG→fNIRS 跨模态生成又慢、常需预训练，难以实时。本文给出低延迟、免预训练、且保留任务相关血流结构的合成路径。
- **核心方法**：Bio-MF 是 latent-free 的一步 MeanFlow 框架——在信号空间直接做 x-prediction，再把信号空间输出转成 MeanFlow 速度监督，一次网络评估完成推理；为在异构传感器布局下保留任务相关血流结构，集成时空交互 4D 编码、跨模态 classifier-free guidance、噪声级门控 FFT 正则。
- **主要结果**：Dataset 1 上 "EEG + 合成 fNIRS" 相对纯 EEG，HbR/HbO 分别提升 3.37 / 4.15 个百分点准确率；Dataset 2 在未见的 64 通道 EEG 布局下仍有 2.98 / 2.50 个百分点增益；单试次生成仅 7.0 ms，相对 1000 步 SCDM 提速约 857×；代码开源。
- **值得追问 / 局限**：① 合成 fNIRS 的"任务相关结构"是否在被试间/跨数据集稳健，会不会学到与真血流动力学不符但对分类有利的捷径特征；② 一步生成省了迭代精修，但对更长时程、静息态或非运动想象范式的保真度未知。

### 4. EviRCA: Decoupling Evidence Extraction from Reasoning for Microservice Root-Cause Analysis
- 链接：https://arxiv.org/abs/2609.19825
- 作者：Yuhao Wang, Zhen Qin, Xingliang Wang, Guochang Li, Weize Li, Shuiguang Deng（浙江大学 Shuiguang Deng 组等）
- **TL;DR**：面向微服务根因分析（RCA/AIOps），把"确定性证据抽取"与"LLM 推理"解耦——先用系统无关的抽取阶段把原始 metrics/traces/logs 压成一组忠实的多模态"证据卡片"，LLM 只在这些结构化观测上用少量只读工具推理，不再直接读原始遥测、也不执行代码。
- **解决什么问题 / 为什么重要**：正中应用方向 B 的监控告警 / 根因定位 / AIOps。当前 agentic RCA 让单个 LLM 一边生成执行代码检索原始遥测、一边定位故障、一边推因，导致算力高、行为不稳、准确率受限。本文指出瓶颈其实在"判断已抽取到的证据"而非"检索证据"，据此重排流程。
- **核心方法**：系统无关的抽取阶段把数值指标、结构化调用链、机器日志转成紧凑且忠实的多模态证据卡片；LLM 通过一小组预定义只读工具仅在这些结构化观测上推理，不访问原始遥测、不执行代码。
- **主要结果**：在 OpenRCA（三套企业真实异构遥测）上正确率 40.6%–43.9%（两种 LLM），远超此前基线最高 15.2%，同时 token 消耗降 15–26×、执行时间降 3–20×；且能解决需"同时对时间、组件、根因联合推理"的硬样本（此前方法近乎零分）。
- **值得追问 / 局限**：① 证据抽取阶段是"系统无关"但仍需为 metrics/traces/logs 设计抽取规则，向新遥测模式/新系统的迁移成本与漏抽风险如何；② 正确率四成余仍有较大提升空间，作者也指出瓶颈在"判证据"，说明推理侧仍是主要短板。

## C. 机制 / 表征分析（高优先级，取 2 篇）

### 5. World Modeling in Transformers
- 链接：https://arxiv.org/abs/2609.21748
- 作者：Pierre Beckmann, Matthieu Queloz, Andre Freitas（含伯尔尼大学 / 曼彻斯特大学等）
- **TL;DR**：通过机制分析与因果干预证明——一个在曼哈顿随机游走上训练的 Transformer（TaxiGPT）其实**学到了忠实的环境地图**，之前被当作"没有世界模型"的行为失败，根因是叠加（superposition）的路口特征相互干扰破坏了定位，而非内部地图不连贯。
- **解决什么问题 / 为什么重要**：正中核心方向 C 的机制/现象分析 + 表征几何 + 叠加/残差结构 + 训练涌现。它直接反驳"行为失败即无世界模型"的推断，主张把问题从"有没有世界模型"改成"机制上如何进行世界建模"，并给出可用于跨模型比较的机制指标。
- **核心方法**：在 TaxiGPT 上做机制解剖与因果干预，验证模型确实表示了路口与街道、跟踪自身位置、并用"目标罗盘"导航；把失败溯源到叠加路口特征之间的干扰对定位的破坏；指出"功能可供性打包（affordance packing）"（把合法移动相同的路口表示聚在一起）能限制此类错误的后果；最后提出机制指标，展示世界建模能力在训练不同阶段涌现。
- **主要结果**：定位失败被归因为叠加特征干扰而非地图缺失；affordance packing 缓解错误后果；世界建模的各项能力在训练中于不同阶段先后涌现，可用所提机制指标做模型间比较。
- **值得追问 / 局限**：① 结论建立在合成网格导航这一受控环境，向真实语言/多任务模型的"世界模型"外推需谨慎；② "叠加干扰"是失败主因的判定依赖特定干预设计，是否存在其它并行机制（如注意力路由）共同致因尚待排除。

### 6. A Lie Detector Test for Language Models: Reading Knowledge a Model Won't Reveal
- 链接：https://arxiv.org/abs/2609.21996
- 作者：Hiskias Dingeto（单作者）
- **TL;DR**：借鉴取证学的"隐匿信息测试（Concealed Information Test）"，提出 PIR（Probe of Internal Recognition）——把问题连同候选答案一起喂给模型，从其**内部状态**读出它"认得"哪个是正确项，从而区分"不肯答"与"确实不会"，且无需诚实参考模型、无需标注真值。
- **解决什么问题 / 为什么重要**：正中核心方向 C 的机制/表征探针 + 现象分析（sandbagging 审计、遗忘验证）。模型可能持有却不报告某知识（能力评测中故意藏拙、或口是心非），仅看输出无法判断是"藏"还是"没有"。PIR 提供一个 reference-free、因果性的内部识别信号。
- **核心方法**：把候选答案中真项与似真诱饵一起呈现，测量模型对"认得的正确项"是否有更强内部响应（复刻 CIT）；PIR 从内部状态读取被识别的候选，无需诚实参考模型、无需标注真值语料；在多种"隐匿"形式下测试。
- **主要结果**：跨 5 个模型家族 8 个模型，PIR 以 0.70–0.87 平衡准确率恢复被识别答案，远高于 unknown-item 基线（0.28–0.40）与随机（0.25）；在提示式欺骗、训练式 sandbagging、外部 password-locked 与 circuit-broken 检查点下识别率 0.85–0.93；当知识被 unlearning 移除后识别率降到"从未知晓"的水平；信号具因果性，且可从选择题扩展到自由生成。
- **值得追问 / 局限**：① "内部认得"与"真正掌握/会用"是否等价，识别高但生成仍错的样本如何解释；② 探针依赖能构造"真项 + 似真诱饵"的题面，向开放式、无明确候选的知识审计的可扩展性与被对抗规避的风险待评估。
