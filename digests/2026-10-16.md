## A. 核心方法（时序图知识迁移 / 图神经 ODE / 时空层网络，取 3 篇）

### 1. Learning Across Temporal Graph Representation Silos
- 链接：https://arxiv.org/abs/2610.19576
- 作者：Minwoo Yu, Young-guk Ha（2 位；cs.LG）
- **TL;DR**：时序图数据被记录成不同表征——连续时间动态图（**CTDG**）与时序知识图（**TKG**）——本文系统检验"从关系历史学到的预测结构，能否跨这两种表征边界复用甚至融合"，结论是**双向复用确实存在**，且独立预训练的 TKG 与 CTDG 学习器可在分数层面融合、无需实体/关系语义对齐就能提升第三个数据集上的预测。
- **解决什么问题 / 为什么重要**：正中 A 的 **CTDG / 动态图 / 时序知识图 + 跨表征迁移**。长期以来 CTDG 和 TKG 被当成两个割裂的"表征孤岛"各自建模，本文把"关系动态（Relational Dynamics）"抽象成一种可跨边界复用的预测结构，意味着**外部无对齐的时序源也能当作预训练资源**——对数据稀缺的时序图任务是很实用的迁移思路，也为"动态图基础模型"提供了一个表征无关的视角。
- **核心方法**：① 在保留各自输入/预测接口与独立词表的前提下，检验 CTDG↔TKG 的双向知识复用；② 通过**受控地重组源历史**，验证"哪种组织方式贡献复用"随源-目标条件而变（同表征的源并不总是更有用）；③ 把独立预训练的两类学习器**在分数层面融合**，在第三个数据集上提升预测；④ 在推荐与安全检测两个概念验证上展示无直接对齐的外部时序源也能成为有用预训练资源。
- **主要结果**：双向复用在保持各自接口与词表的情况下成立；分数级融合无需实体/关系语义对齐即可改善第三数据集预测；推荐 + 安全检测两个 PoC 验证无对齐外部源的可迁移性。
- **值得追问 / 局限**：① 摘要以"现象揭示 + 概念验证"为主，缺少统一基准上的量化增益与强基线对比，复用幅度到底多大需看正文；② "同表征源不总更有用"说明迁移收益高度依赖源历史的组织方式，如何**事先判断**某个外部源是否值得迁移（而非试错）尚未给出可操作准则。

### 2. Learning and Forecasting Multiscale Spatiotemporal Epidemic Dynamics with Lagrangian-Eulerian Graph Neural ODEs
- 链接：https://arxiv.org/abs/2610.21223
- 作者：Jinyi Duan, Qian Li, Biao Tang（3 位；cs.LG）
- **TL;DR**：中长程传染病预测要从部分观测里外推高维、异质、非平稳动态；本文提出 **LE-EpiGNODE**，用**过程专属、机理引导的神经算子**替代通用消息传递——年龄-接触信息驱动拉格朗日式感染生成、人口流动驱动守恒的欧拉式种群输运，统一在一个保结构的通用微分方程里。
- **解决什么问题 / 为什么重要**：强命中 A 的**时空 GNN + 图神经 ODE（连续时间）+ 内生/机制级可解释**三重横切。它针对混合模型"说不清哪些观测驱动哪些流行病过程、学到的图交互如何改变系统状态"的通病，把**可检验的过程级机制解释**做成模型结构的一部分（而非事后归因）——这正是你关注的"内生可解释 + 连续时间动力学"的典范组合。
- **核心方法**：把消息传递拆成两类机理对齐的神经算子——**拉格朗日项**（age-contact 驱动感染生成）与**欧拉项**（mobility 驱动守恒的人口输运），嵌入**保结构的通用微分方程（universal differential equation）**；在 14 个受控合成机制（含时变、状态依赖、非线性、耦合动态）、3 个 COVID-19 真实设置、21 个对比模型、5 组定向消融上评估。
- **主要结果**：预测增益随预测时程拉长更明显；**最长时程下在 3 个真实数据集上均取得最低 WMAPE，相对最佳基线降低 17.7–40.0%**；消融证实增益来自拉格朗日-欧拉分解与过程对齐先验；合成真值显示学到的算子与诱导的状态通量能追踪已知生成动态（即机制解释可检验）。
- **值得追问 / 局限**：① 机理算子依赖 age-contact 与 mobility 等外生结构信息，缺这些数据的地区/病种能否泛化、对输入噪声多敏感需验证；② 短时程相对基线优势不明显（增益集中在长时程），实时疫情响应更看重的近程预测收益有限。

### 3. ChronoSheaf: Joint Spatio-Temporal Spectral Filtering on Cellular Sheaves
- 链接：https://arxiv.org/abs/2610.21958
- 作者：Abeer Mostafa, Zahra Ahmadi（2 位；cs.LG）
- **TL;DR**：层神经网络（sheaf NN）用每条边上学到的线性限制映射缓解过平滑，但现有层 Laplacian 是**瞬时空间算子**、无法显式建模信号随时间演化；本文提出**时空联合的谱层 Laplacian**，用单一算子同时调控空间图与时间域上的信号传播，并配一个谱滤波器在不增大底层层结构的前提下扩张双向感受野。
- **解决什么问题 / 为什么重要**：命中 A 的**时空 GNN + 图谱方法**，属于把 sheaf NN（抗过平滑的 GNN 推广）从纯空间推向时空的结构创新。直接在空间或时间扩张感受野需要越来越复杂的 sheaf，本文改用谱滤波绕开这一复杂度爆炸，对"长程时空依赖 + 不想堆深/堆复杂"的场景有借鉴意义。
- **核心方法**：① 定义**时空联合的谱层 Laplacian**，单算子统管空间图与时间域传播；② **Transitional Restriction Maps（TRM）**：把每节点限制映射拆成一个空间项 + 前后两个时间帧，分别控制与前一/后一时刻邻居的关系，实现**非对称时间影响**；③ **Dual Spectral Filter（DSF）**：对联合时空算子施加单个有界次数多项式滤波器、谱半径自适应估计，扩张双向有效感受野而不增大 sheaf。
- **主要结果**：在多样的时空预测基准上**优于 SOTA 基线**；代码已匿名开源。
- **值得追问 / 局限**：① 摘要给"outperform SOTA"的定性结论，缺具体数据集/指标/幅度，需看正文；② sheaf 的限制映射学习与谱滤波叠加后的训练稳定性、参数量与算力开销相对标准时空 GNN 的性价比，摘要未交代。

## B. 应用场景（异构 fNIRS 预训练 / 大规模运维 Agentic RCA，取 2 篇）

### 4. GeoNIRS: Geometry-Aware Pretraining for Heterogeneous fNIRS Representation Learning
- 链接：https://arxiv.org/abs/2610.17845
- 作者：Zongsheng Li, Shengyuan Zhu, Zimo Zhang, Hanyao Li, Shengming Wang, Quanying Liu（6 位；cs.LG）
- **TL;DR**：fNIRS（功能性近红外）提供便携、空间定位的皮层血流动力学测量，但各数据集通道数、探头布局、信号分布、任务类型迥异，阻碍联合预训练；**GeoNIRS** 用**源-探测器物理位置作为跨异构布局的共享空间参照**，把变长通道集压成定长潜表征，并用 HbO/HbR 双向交叉重建 + 连续时间掩码做自监督预训练。
- **解决什么问题 / 为什么重要**：**直击你的 fNIRS / 脑功能近红外 / 脑网络主线**。作者自称是**第一个在跨异构通道配置的联合预训练中显式建模物理通道几何**、也是第一个完整开源代码 + 可下载预训练权重的 fNIRS 框架——对 fNIRS 这个数据碎片化、缺统一基础模型的领域是基础设施级贡献，且"用几何做跨布局对齐"的思路可迁移到其它探头/电极布局异质的生理信号。
- **核心方法**：以 source-detector 坐标为共享空间参照 → 把变长通道集压缩为**定长潜表征** → **双向 HbO/HbR 交叉重建** + 连续时间片段掩码做自监督；GeoNIRS-base 在 8 个异构数据集上预训练，GeoNIRS-large 扩到 22 个；预训练不用下游数据与标签，支持严格的跨任务评估。
- **主要结果**：在 8 个留出任务（临床/听觉评估、疼痛与情感加工、语义解码、运动功能）上取得评测中**最高的任务平均平衡准确率**；相比随机初始化，线性探测 +4.12、全量微调 +3.30 个百分点，**标签稀缺时收益更大**；对缺失输入通道鲁棒；几何扰动与预训练消融证实通道几何与跨色团重建都有贡献。
- **值得追问 / 局限**：① 仍是"编码器预训练 + 下游分类"范式，对 fNIRS 常见的被试间/设备间域偏移、运动伪迹的鲁棒性需进一步看；② 定长潜表征压缩变长通道集可能丢失高密度布局的细粒度空间信息，高通道数场景的信息瓶颈值得评估。

### 5. Diviner: Agentic RCA with Human-Governed Adaptation for Large-Scale Infrastructure
- 链接：https://arxiv.org/abs/2610.21281
- 作者：Pradipta Ghosh, Gaurav Mitra, Shripad Nadgowda, Akshil Shah, Junyu Liu, Canturk Isci 等（cs.AI）
- **TL;DR**：大规模分布式系统的根因分析（RCA）要跨服务、数据、配置、算力、组织多重边界拼凑不完整证据，通用 LLM Agent 仅靠工具访问解决不了（会用过时/错时上下文、把失败查询当成"无症状"、报告无依据的系统状态、还会压垮为人速设计的可观测服务）；**Diviner** 是 Meta 在产的 Agentic RCA 系统，围绕"编码-执行-评估-适配"四阶段可靠性生命周期组织。
- **解决什么问题 / 为什么重要**：命中 B 的 **root cause analysis / AIOps / 告警定位**，且是**真实大规模生产落地（Meta）**而非 benchmark 玩具。它点出的"LLM Agent 在真实运维里的四类失效模式"本身就是很有价值的问题刻画，且其**人类治理的知识适配**（更新须经回放、质检、owner 审批才准入）对"Agent 自我演化不失控"是可借鉴的工程范式。
- **核心方法**：**Encode** 把大量已复盘事件 + 服务 owner 专识编成有作用域、带版本的 skills / workflows / 类型化工具 + 事件知识图谱；**Execute** 用自适应 Lead + 上下文隔离的 worker 把相关知识应用到**时点对齐的证据**上、维护证据链接的假设；**Evaluate** 比较保存的调查轨迹与复盘结论，衡量精确根因、有用方向与 Groundedness；**Adapt** 用复发缺口与 on-call 反馈导出聚焦的运维知识更新，经回放/质检/owner 审批后才准入。
- **主要结果**：摘要以系统架构与方法论描述为主，未在此给出量化命中率/MTTR 改善等指标（需看正文评估章节）。
- **值得追问 / 局限**：① 强依赖 Meta 内部的已复盘事件语料、服务 owner 专识与自建可观测栈，方法论可迁移但**系统本身难直接复现**；② "点时对齐证据 + 证据链接假设"是对抗 LLM 幻觉系统状态的关键，但其在证据本身缺失/冲突时的表现、以及知识图谱维护成本需关注。

## C. Agent / 机制（表征几何的闭式缩放律，取 1 篇）

### 6. A Closed Form Depth-Width Law for Neural Collapse in Deep Linear Networks
- 链接：https://arxiv.org/abs/2610.21820
- 作者：Pankhil Gawade, Kirsten Fischer, Guy Wolf, Ewa Szczurek（4 位；cs.LG）
- **TL;DR**：深度与宽度如何塑造学到的表征通常只能在训练后研究；本文在一个可解析的特征学习设定里，证明这一依赖关系可**闭式求得**——用**神经坍缩（neural collapse）作为表征几何探针**，把 NC1–NC3 直接写成学到的特征核的函数，得到类内变异随层演化的几何定律。
- **解决什么问题 / 为什么重要**：命中 C 的**表征几何 / neural collapse / 训练动态的理论机制**，属于"优先"类机制分析而非经验现象描述。它把"深宽比如何决定表征压缩"从**训练后测量**提升到**理论上闭式预测**，给出一个从特征学习理论推导、而非事后拟合的**表征级缩放律**——对理解"为什么更深更窄的网络压缩更强"提供了可计算的锚点。
- **核心方法**：① 把 NC1–NC3 直接用学到的特征核表达（将 NC1 已知恒等式扩展到 NC2 的角度部分与 ridge 读出下的 NC3）；② 对具可交换类结构的**深度线性网络**，核方程给出类内变异逐层演化的几何定律（理论内精确）；③ 大宽度下累积压缩成为**深宽比 L/N 的函数**，其速率由数据、先验、架构自洽决定；④ 数值实验验证对深度、宽度、信噪比的依赖。
- **主要结果**：导出的层间类内变异演化律在理论内精确，数值实验支持其对深度/宽度/SNR 的预测依赖；得到的是从特征学习理论推导的表征级缩放律。
- **值得追问 / 局限**：① 核心结果建立在**深度线性网络 + 可交换类结构**的可解析设定上，向非线性激活、真实数据的类不平衡/相关结构外推时定律是否近似成立是关键开放问题；② 以 NC 作为表征几何代理，能在多大程度上预测下游泛化（而非仅几何本身）仍需连接。
