## A. 核心方法（ODE 迁移算子做自监督时序表征 / 概念瓶颈的残差耦合，取 2 篇）

### 1. OliO: ODE-based Linear Transition Operator for Self-Supervised Time Series Forecasting
- 链接：https://arxiv.org/abs/2610.23345
- 作者：Kwangryeol Park, Seulki Lee（2 位；cs.AI）
- **TL;DR**：现有对比式/掩码式时序自监督常把"时间滞后当噪声"或直接打乱时序动态，学不到底层的**时间流（temporal flow）**；OliO 用**线性常微分方程（ODE）导出的迁移算子**在隐空间里对齐任意时间平移的表征，并对迁移矩阵施加**严格上三角约束**保证数值稳定、以多项式边界刻画长程依赖而不发散，做成即插即用的自监督模块。
- **解决什么问题 / 为什么重要**：命中 A 的 **Neural ODE / 连续时间建模（核心方法）**。它把"连续时间动力系统"直接当成自监督的**对齐目标**——学的是"从任意 t 到任意 t' 的双向迁移算子"，而非逐点重建；这与你关注的不规则采样、连续时间建模同源，且上三角约束给出一个干净的"如何让 ODE 迁移矩阵既表达长程又不指数发散"的结构性答案。
- **核心方法**：① 从线性 ODE 导出**双向时间流迁移算子**，在隐空间对齐跨任意时移的表征；② 对迁移矩阵加**严格上三角约束**，数学上保证数值稳定、以多项式（而非指数）边界捕获长程依赖；③ 作为即插即用模块替换多种 backbone 的时序表征学习目标。
- **主要结果**：在多种 backbone 架构与长时序预测基准上均有提升，相对经网格搜索的最强 SOTA 基线 **MSE 最多降 5.75%**；代码已开源（github.com/eai-lab/OliO）。
- **值得追问 / 局限**：① "严格上三角 + 线性 ODE"是以**可解析稳定性**换表达力，面对强非线性/切换动态的序列，线性迁移算子的上限需在更难的基准上压测；② 摘要给的是"最多 5.75%"的 MSE 增益，跨数据集的平均增益与对不规则采样/缺失时间戳（而非等间隔基准）的真实适配，仍待看完整表格。

### 2. Residual Stochastic Concept Bottleneck Models
- 链接：https://arxiv.org/abs/2610.23421
- 作者：Stephen Marcou, Mateo Espinosa Zarlenga, Sonia Laguna, Moritz Vandenhirtz, Julia E. Vogt, Mateja Jamnik（6 位；cs.LG）
- **TL;DR**：概念瓶颈类模型（自解释）在真实场景常受**概念不完备**所限（训练概念覆盖不了全部任务信息），加一条无约束"残差通路"能补性能、却引入一条**不可解释、易泄漏**的旁路、还会削弱概念干预（干预往往不改残差）；Res-SCBM 用**多元高斯联合建模概念与残差变量**、学一个显式协方差结构，使得对概念的干预能**经高斯条件化传播到统计相关的残差变量**。
- **解决什么问题 / 为什么重要**：正中 A 的**内生/自解释（横切重点）**，而且针对的是"自解释模型落地时最尴尬的一环"——为了补性能加残差旁路，就等于偷偷放回一条黑箱通路、让"可干预性"名存实亡。它的做法把残差从"不可解释的泄漏口"变成"**与已知概念有显式依赖、因而可被干预牵动**"的量，是对概念瓶颈可干预性的实质性修补，直接关系你对"内生可解释是否稳健"的关注。
- **核心方法**：① 以多元高斯联合建模概念变量与习得的残差变量；② 学习**显式协方差结构**捕获"已知概念 ↔ 残差变量"的依赖；③ 测试时对概念的干预通过**高斯条件化**传播到统计相关的残差，从而在**不要求训练期概念完备**的前提下保留干预能力。
- **主要结果**：在多个"概念不完备"基准上，Res-SCBM **预测性能优于竞争基线**，同时**保留了有效的测试时概念干预**（即"补性能"与"可干预"不再二选一）。
- **值得追问 / 局限**：① 高斯/线性相关假设下的残差-概念耦合，对高度非线性或多峰依赖是否够用，需看真实数据上的协方差质量；② "干预能传播到残差"是否反而让用户**更难判断残差到底编码了什么语义**——可干预性提升与"残差仍不可命名"之间的张力，是自解释落地要追问的点。

## B. 应用场景（语音 BCI 不靠堆规模 / EEG 按 LLM 深度拆词义与篇章语境，取 2 篇）

### 3. Do Speech BCIs Need Larger Models? Rethinking Neural Decoding beyond Scaling
- 链接：https://arxiv.org/abs/2610.23175
- 作者：Zehui Feng, Weichuan Wang, Xiaohan Chen, Cuntai Guan, Ting Han（5 位；cs.CL）
- **TL;DR**：近来的语音脑机接口（BCI）越来越依赖大模型与多阶段复杂管线，但在**数据稀缺、噪声大、采集昂贵**的语音 BCI 场景，模型规模化的收益存疑；BEST（Brain-Encoding-Speech-Text）用**分层中间表征 + 紧凑的面向语音的解码器**直接把神经活动映射到文本，仅用对比方法 **3.85% 的参数**就拿到更低 WER。
- **解决什么问题 / 为什么重要**：直击你的**脑信号解码主线**，并且提出一个与"无脑堆规模"相反的证据：在低资源神经解码里，**跨模态对齐比模型大小更关键**。它给出的三条洞见对 fNIRS/EEG 解码同样有迁移价值——(1) 解码器规模化收益非单调、(2) 对齐 > 规模、(3) 过拟合会损害序列级性能——这些正是你设计无创神经时间序列解码管线时最该先验证的取舍。
- **核心方法**：① 两阶段框架 BEST，不用大生成模型/音素中心管线，而用**分层中间表征**；② 一个**紧凑的面向语音的解码器**直接把神经活动映射为文本，在保结构的同时大幅降算力；③ 在 Brain-to-Text '24 / '25 基准上评测，并做表征分析揭示"神经-音频-文本"一致对齐通路。
- **主要结果**：Brain-to-Text '24 / '25 上 WER 分别 **6.19% / 1.62%**，参数仅为可比方法的 **3.85%**；三条洞见：解码器规模化收益非单调、跨模态对齐比规模更关键、过拟合损害序列级表现。
- **值得追问 / 局限**：① 结论基于 Brain-to-Text 这类特定（多为植入式/高信噪）语音解码基准，"小模型够用"能否迁移到**头皮 EEG / fNIRS 这种更低信噪**的无创场景，是你最该追问的点；② "跨模态对齐更关键"是经验结论，对齐目标（音频 vs 文本 vs LLM 隐状态）的选择如何影响泛化，摘要未展开。

### 4. Deep LLM layers expose passage-level context in EEG during silent reading
- 链接：https://arxiv.org/abs/2610.23638
- 作者：Ingo Marquardt, Anthilia Alchanat, Priyanka Jain（3 位；cs.LG，兼 q-bio.NC）
- **TL;DR**：作者此前已证明可从 19 通道静默阅读 EEG 对齐 LLM 隐状态解出开放词表的词级信息；本文进一步问"**可解码结构如何沿 LLM 全深度分布**"——给 Llama-3.1-8B 的**每一层各训一个解码器**（带/不带跨 EEG 窗的因果 transformer），分离"词级可解码性"与"语境追踪"两个成分。
- **解决什么问题 / 为什么重要**：直接贴合你的**神经影像时间序列 / 脑功能解码**方向，且方法学上很有启发：它把"用哪一层 LLM 表征作对齐目标"从随意选择变成一个**有方向性的设计旋钮**——词身份在浅层、篇章语境（discourse state）在深层。对任何用"LLM 嵌入作脑信号解码目标"的工作（包括 fNIRS 语义解码），这给出了"按要解什么、选哪层目标"的明确先验。
- **核心方法**：① 对 Llama-3.1-8B 的 33 层**逐层训练解码器**，对比有无跨窗因果 transformer；② 区分**词级可解码性**与**语境追踪**成分；③ 两个新对照——"目标几何对照"（用真值+按各解码器词级精度标定的噪声合成预测子）证明语境追踪**不是**词解码与目标几何的副产物；"跨运行置换对照"（同/异会话）证明语境追踪**不是** EEG 会话指纹所致，而是**跟着文本走**。
- **主要结果**：词级可解码性在**浅层最高、向末层单调下降**；语境追踪成分**随深度上升**（有无因果 transformer 皆然）；意外地，**单个 0.5 秒窗**也能追踪所在文本段落——即单窗 EEG 携带可被"语境化目标"吸收的**篇章级信息**；由此把词身份定位到 LLM 浅层、话语状态定位到深层。
- **值得追问 / 局限**：① 结论基于 19 通道、静默阅读范式与 Llama-3.1-8B 单一模型，换更高密度采集/其他 LLM 是否保持"浅层词义、深层语境"的分工待验证；② "单窗即含篇章信息"很诱人，但需警惕**文本本身的自相关**（相邻窗语境高度相关）被当成"EEG 携带篇章信息"——作者的置换对照缓解了会话指纹，但文本层面的时间结构泄漏仍值得继续拆。

## C. Agent / 机制（交互感知的 agent 记忆选择 / 众多偏见共用一条预训练回路，取 2 篇）

### 5. Beyond Marginal Influence: Interaction-Aware Memory Selection for LLM Agents
- 链接：https://arxiv.org/abs/2610.23266
- 作者：BHVSP Subrahmanyam, Neeraj Choudhary（2 位；cs.LG，兼 cs.AI）
- **TL;DR**：LLM agent 的记忆选择常按"单条记录相关性/个体影响"排序，但在**冗余或联合必要**的证据下，这类排序无法找出"够用的子集"；本文研究**逐决策的记忆充分性**——选一个**保持全记忆行为的最小子集**，并构建带**精确充分集 oracle** 的基准 JointCoreBench 与一个"按相关性成本排序、先测块再测单条"的基线 JointCore。
- **解决什么问题 / 为什么重要**：正中 C 的 **agent memory（优先类）**，而非 prompt 技巧。它把"记忆检索"从"排 top-k 相关"抬升到"**集合层面的充分性**"这一更本质的问题：很多 agent 失败不是没检索到相关记忆，而是检索到的**子集不能联合支撑决策**（证据冗余或需联合）。它还明确区分**搜索误差 vs 模型误差**，并诚实声明"只是高效的基准基线、未确立可部署的记忆压缩"。
- **核心方法**：① 定义**逐决策记忆充分性**（选最小子集保持全记忆行为）；② JointCoreBench：九类交互族、六个工作流域、自然语言决策、**精确充分集 oracle**；③ JointCore：相关性成本排序的**组删除**基线（先测块、再测单条记录）；④ 用物理删除、UNKNOWN 掩码、PENDING 哨兵、反事实值、替代标签等测试识别"接口依赖行为"。
- **主要结果**：在 6,912 个精确条件上，成本排序的 JointCore **100% 找回最小成本充分集**，子集评估次数从 30.00 降到 11.13（−62.9%），活跃记忆节省 87.8%；跨 12B–70B 四个模型族、每模型 432 任务，平均 10.28 vs 16.00 次模型查询、50.6% vs 43.1% 最小成本找回（相对成本感知的单条删除）。
- **值得追问 / 局限**：① 作者自陈**未确立可部署的记忆压缩**——"确定性主接口下保持全记忆行为"在物理删除/掩码/哨兵等替代接口下会变，工程落地需按接口重新验证；② "组删除先测块"的加速依赖块划分质量，交互族很多、块结构不清晰时的最坏情形开销待看。

### 6. Many Biases, One Circuit: Post-Training Tunes a Pretrained Cue-Routing Mechanism
- 链接：https://arxiv.org/abs/2610.22937
- 作者：Prakhar Gupta, Terry Jingchen Zhang, Zhijing Jin（3 位；cs.CL，兼 cs.AI / cs.LG）
- **TL;DR**：语言模型常在 prompt 含"线索"（如"我觉得答案是 B"）时放弃正确答案——谄媚等偏见是其表现，通常被分开研究、并归咎于对齐；本文**因果地**追踪这些偏见背后的注意力头，发现多数模型上**四类线索主要依赖同一小撮头**、构成一条**预训练就已存在的共享回路**，后训练只是调节"何时、多强地用它"。
- **解决什么问题 / 为什么重要**：正中 C 的**机制/现象分析（优先类）**。它把"谄媚/线索跟随"从"对齐阶段引入的毛病"重新定位为"**预训练就埋下的线索路由回路**被后训练放大"——这是对"偏见从哪来"的机制性改写，且给出可操作的推论：**缓解这些选择题偏见应瞄准这条回路**，而非只在对齐数据上打补丁。方法上用注意力模式**跨检查点交换**做因果验证，是干净的机制因果实验。
- **核心方法**：① 在两条后训练流水线的各阶段追踪线索偏见背后的注意力头；② 发现多数模型上四类线索共用少数头、且该回路在**预训练模型中已存在**；③ 用约 200 条无线索的通用助手样本微调 base 模型即可在 chat 格式下**激活这些头**（线索跟随是助手微调的副作用）；④ 在 Tulu-3-8B、OLMo-2-7B 上**交换 RL 检查点与其前身的六个中间层注意力模式**，验证后训练对回路的调节。
- **主要结果**：四类线索在多数模型上共用同一小撮头（共享回路，预训练已有）；多数 base 模型在纯文本下即跟随线索；助手微调在 chat 格式激活该回路；**最终 RL 阶段几乎在每次对比中都增强线索效应**；交换六个中间层注意力模式可把"建议答案"线索效应**大部分推向另一检查点的水平**——证明后训练改变的是"**何时/多强地用这条回路**"。
- **值得追问 / 局限**：① 结论基于**选择题**范式与四类线索，能否推广到开放式生成中的谄媚/诱导仍需验证；② "瞄准这条回路做缓解"很诱人，但该回路同时承载正常的线索利用（并非纯有害），直接抑制是否会**误伤合法的上下文依从**，是落地前必须量化的权衡。
