## 1. CircuitKIT: Circuit Discovery, Evaluation, and Application Toolkit for Mechanistic Interpretability
- arXiv: https://arxiv.org/abs/2607.19317
- 作者：Pratinav Seth, Hem Gosalia, Aditya Kasliwal, Vinay Kumar Sankarapu（共 4 位；Lexsi Labs）
- **TL;DR**：机制可解释性里"电路发现—诊断评估—下游干预（剪枝/编辑/引导/选择性微调）"目前要各自拼接不同实现、还得手写对比 prompt；CircuitKIT 用一套类型化、可序列化的统一表示把整条工作流连起来，让不同电路分析方法能公平比较、也能跳出教科书任务落到真实数据上。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"机制类（circuit discovery / mechanistic interpretability）。当前电路分析的最大摩擦不在算法本身，而在工程碎片化——发现、评估、干预分属不同代码库，导致方法难复现、难横向比较、难迁移。一个把"结构化数据→发现任务"声明式映射、并内置多种发现算法与干预模块的公共基础设施，对把机制可解释性做成可复用工具链（而非一次性 notebook）很有价值。
- **核心方法**：提供一套发现算法集合 + 电路诊断工具；用类型化、可序列化的电路表示贯穿全流程；用声明式接口把结构化数据映射为发现任务（免去手写对比 prompt）；再接剪枝/编辑/引导/选择性微调等下游应用模块。源码、示例与文档已在 GitHub（Lexsi-Labs/CircuitKIT）开放。
- **主要结果**：这是一篇工具/基础设施论文，主要贡献是把发现—评估—干预统一到同一表示与接口下，使多种电路分析方法可在同一框架内实施与对比；随库发布示例、notebook 与文档。
- **值得追问 / 局限**：偏工程整合，缺跨方法的定量基准/排行来量化"统一表示"带来的可比性收益；统一类型化表示对新型发现算法（尤其非注意力/非 Transformer 架构）的可扩展性、以及大模型规模下的可用性，摘要未展开。

## 2. Train the Model, Not the Reader: Decodability Supervision for Verifiable Activation Explanations
- arXiv: https://arxiv.org/abs/2607.20379
- 作者：Hiskias Dingeto（1 位）
- **TL;DR**：用"自然语言自编码器"给隐层激活写解释、再靠"能否从解释重建出激活"来判定忠实度——这套重建式打分对单条虚假声明结构性不敏感：翻转某个声明若不改变重建，该错误就永远不被惩罚。作者证明高重建分可由两种都不忠实的方式取得，并提出 RECAP：训练目标模型时并行挂一组线性头，把指定内容"保持可解码"，让内部内容可被独立探针核验，而非仅由模型能操纵的文字断言。
- **解决什么问题 / 为什么重要**：正对 C 方向"内生/自解释"横切重点与机制可解释性——把"解释是否可信"从"读起来合理/整体能重建"推进到"单条声明可被独立核验"。在一个开源 Qwen-2.5-7B verbalizer 上，解释重建远高于随机，但只有约 2% 的具体声明是"重建依赖"的，说明分数只抓住 gist、不抓具体事实；在精确合成 ground truth 下，标准配方 5/5 次都长出"共适应的私有编码"（重建所依赖的错误措辞）。这对"用 LLM 给自己写可信解释"的可解释性/安全路线是重要警示与修法。
- **核心方法**：提出两个审计协议——grounded-vs-true 交叉检验与 evaluator swap；RECAP（Readable Encodings via Co-trained Auxiliary Predictors）在训练目标模型时并行训练线性预测头，使指定内容保持可探针解码；代价极小（+0.001 nat）。在 RECAP 训练的 sandbox 模型上，新 verbalizer 能如实陈述指定内容、私有编码消失；在预训练 Pythia-160M 上复现（内容可靠可探针解码，但新 verbalizer 仅部分传达，truth 0.44–0.46 对近零对照）。
- **主要结果**：独立探针给 verbalizer 的真声明打分高于假声明 AUC 0.96（无 RECAP 为 0.82）；面对"专为最大化重建分而说谎、压掉约 87% 谎言惩罚"的对抗性编辑，RECAP 探针仍能标出谎言 AUC 0.95，而对照探针塌到随机 0.51。结论：高重建不等于逐条为真——可解释性要"可核验"，安全上要让内部内容可被独立探针检查。
- **值得追问 / 局限**：RECAP 需要在训练期介入并预先指定"要保持可解码的内容"，对已部署/黑箱模型不适用；Pythia-160M 上"新 verbalizer 仅部分传达"说明可解码≠可自然复述，二者差距的根因待挖；实验规模偏小，向大模型与更丰富语义内容的外推性待验。

## 3. Supra Cognitive Modes: A Routed Architecture for Agent Memory
- arXiv: https://arxiv.org/abs/2607.19096
- 作者：Joshua Tobkin, David Yang（共 2 位）
- **TL;DR**：智能体记忆的负载其实很杂——直接事实查找、关系链/当前状态推理、长历史上的广域综合各不相同；SCM（Supra Cognitive Modes）在一套共享摄入底座上，按显式或自动选择的"每查询模式"把请求路由到不同的检索与综合策略：融合的词法+稠密查找、图/迭代多跳、分层长文综合。
- **解决什么问题 / 为什么重要**：命中 C 方向 agent"优先"里的 memory——把"记忆"从单一 RAG 管道升级成"按查询类型分模式路由"的架构问题。用一个冻结的语义分类器 + 运行时门控做分派，底座融合多粒度嵌入、抽取三元组、事实版本元数据与可选异步富化，兼顾事实查准、关系推理与长程综合。对做长期对话记忆 / 长历史智能体的人有直接架构参考。
- **核心方法**：冻结语义分类器 + 运行时 gate 将查询分派到三类处理（融合词法与稠密的查找 / 图或迭代多跳 / 分层长文综合）；共享摄入底座含多粒度嵌入、抽取三元组、事实版本元数据与可选异步富化；支持显式或自动的每查询模式选择。
- **主要结果**：在三个基准上给出参考运行——LoCoMo 事实类 84.87%、对抗性弃答 68.61%；MemoryAgentBench 两次重复 61.49%；LongMemEval 86.00%；并有仓库级复现给出相近聚合分与按任务/模式的失败分析。作者明确声明：端到端计时、完整 token 账本、部分最终运行决策缺失，因果路由效应、效率增益与统计显著性均在现有证据之外。
- **值得追问 / 局限**：作者自陈证据链不完整（无对照消融证明"路由"本身的因果贡献、无显著性检验、时延/成本账本缺失），因此各模式相对单一强 RAG 基线的真实增益无法判定；"冻结分类器 + 门控"的路由错误如何传播、错配代价多大，未量化。

## 4. GUIDED: Network-Agnostic Feature Initialization for Spatial Transferability in GNN-based Models
- arXiv: https://arxiv.org/abs/2607.19270
- 作者：Alessandro Scalese, Santhanakrishnan Narayanan, Constantinos Antoniou（共 3 位；慕尼黑工业大学方向）
- **TL;DR**：GNN 做交通分配（Traffic Assignment）虽快，但受"空间泛化鸿沟"制约——标准的直推式特征初始化把出行需求绑死在固定网络拓扑上，换城市就失效；GUIDED 把需求作为标量属性注入到"辅助虚拟边"上（而非特定节点特征），从而与网络规模无关地标准化输入空间，实现真正归纳、可跨网迁移的模型。
- **解决什么问题 / 为什么重要**：正对 A 方向"图神经网络 / 空间泛化"——核心是把 transductive 初始化改造成 inductive，让图模型能零改动迁移到新拓扑。交通分配是交通规划里昂贵的基础组件，GNN 代理模型的落地瓶颈正是换网即崩；GUIDED 提出的"虚拟边承载需求"这一拓扑抽象，对一切 origin-destination 型空间问题（货运物流、多模态网络）都是可复用蓝图。
- **核心方法**：提出网络无关的归纳式需求嵌入层（Geometrically Unconstrained Inductive Demand EmbeDding），把出行需求作为标量注入辅助虚拟链路而非节点特征，标准化输入空间；与异构图注意力网络（HetGAT）集成；用优化的 scatter 操作提升效率。
- **主要结果**：在多个城市拓扑上，HetGAT+GUIDED 在单网任务上保持 SOTA 精度，同时对分布外需求模式更稳健、在严重数据稀缺下仍显著优于基线；支持参数高效的跨网域自适应而无需人为输入同质化；初始化层的 scatter 优化使每 epoch 训练时间约降 50%。
- **值得追问 / 局限**：验证集中在车辆交通分配这一任务族，向货运/多模态等其它 OD 问题的迁移仍是"蓝图"而未实证；"虚拟边注入标量需求"是否会丢失需求的空间结构信息、在更强异质需求下的表达力上限，摘要未展开；对比主要围绕自家基线，与其它 inductive GNN 方案的横评缺失。

## 5. Real-time Optimal Control with Shallow Recurrent Decoder Networks
- arXiv: https://arxiv.org/abs/2607.19302
- 作者：Matteo Tomasetto, Francesco Braghin, J. Nathan Kutz, Andrea Manzoni（共 4 位；Politecnico di Milano / U. Washington 方向）
- **TL;DR**：高维时空动力学的实时最优控制，传统上每换一个场景就要多次系统仿真、代价高昂；本文用 SHRED-ROM（浅层循环解码器降阶模型）只凭有限的状态传感器读数，就地合成一个实时闭环控制器，模仿专家示范在新场景下给出有效的分布式控制动作，并配一个传感器预测器在潜空间闭环、兜底传感失效或延迟。
- **解决什么问题 / 为什么重要**：贴合 A 方向"时空动力学 / 传感器时间序列 + 潜空间建模"。要点有两个：一是只用稀疏传感读数（而非全场状态）驱动控制，规避高维时空系统的维数灾；二是显式处理传感器失效/延迟——用潜层传感器预测器补上缺失读数，这与"不规则/异步采样、传感缺失"的现实场景相通。
- **核心方法**：用 SHallow REcurrent Decoder（SHRED）做降阶建模（SHRED-ROM），在少量专家最优示范上训练后模仿专家给出闭环控制；额外合成一个传感器预测器（sensor forecaster），在潜空间闭环以缓解传感器失效或延迟；面向高维、参数化动力学的实时闭环控制。
- **主要结果**：在三个高维挑战案例（参数化密度控制、流体流动控制）上评估，SHRED-ROM 能实时复现专家最优行为、给出有效分布式控制，并在传感失效/延迟下借潜空间预测器维持闭环。
- **值得追问 / 局限**：属"模仿专家示范"的策略，性能上限受专家示范质量约束、且对示范未覆盖的场景外推性存疑；传感器数量/布点与潜空间预测精度、失效兜底能力之间的权衡未系统量化；评测为仿真物理系统，向真实含噪、非平稳传感环境的迁移待验。

## 6. Toward Auditable Fraud Detection: Combining Graph Features, Model Explanations, and Agentic Case Investigation
- arXiv: https://arxiv.org/abs/2607.19266
- 作者：Rahil Sharma（1 位）
- **TL;DR**：一篇难得诚实的分层欺诈检测实证——把梯度提升分类器、图结构特征、自编码器异常信号、TreeSHAP 解释与一个"有界 LLM 调查智能体"（只处理分类器打分不确定的案例）拼成流水线，结果是：每个组件只在特定条件下有用，而调查智能体给出的"看似合理的理由"并不等于更好的决策。
- **解决什么问题 / 为什么重要**：命中 B 方向应用（异常/欺诈检测），且横切 A_graph（图结构特征）与可解释性（TreeSHAP + agentic 复核）。价值在方法论上的清醒：作者先揪出并移除 PaySim 模拟器特有的"余额捷径"（否则会虚高基线），再做公平比较，示范了监控/风控类系统里"消融要先去污、理由≠正确"的严谨范式，对做异常检测+可审计性的人是很好的反面教材与检查清单。
- **核心方法**：分层流水线 = 梯度提升分类器 + 图派生结构特征 + 自编码器异常信号 + TreeSHAP 解释 + 仅作用于不确定案例的有界 LLM 调查智能体；先识别并移除模拟器特有的余额捷径再做评测；并设计一个"基于分歧的升级规则"把智能体可疑改判送人工复核。
- **主要结果**：去污后，图特征与异常信号都未在全测试集上提升 AP，但都能在"中间分数"子集内更好地排序欺诈；在注入多账户欺诈环的受控实验中，工程化结构特征召回全部注入交易，而表格基线漏掉约四分之一；调查智能体反而不如对其依赖的分类器直接阈值化（65.0% vs 71.7%），它改动的 8 个决策里 6 个把正确改成了错误；分歧升级规则标出了其中 2 个智能体错误、且未误伤任何正确决策。
- **值得追问 / 局限**：结论基于单一合成数据集 PaySim，向真实交易分布（更强非平稳、真实标签噪声）的外推性有限；"调查智能体拖后腿"是否与本文所用智能体设计/提示预算强相关、更强工具化智能体能否翻盘，未展开；分歧升级规则样本量小（60 例平衡子集），其筛出效率的统计稳健性待验。
