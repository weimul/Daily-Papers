## A. 核心方法

### 1. ConceptTS: LLM-Guided Concept Bottlenecks for Interpretable Multivariate Time-Series Forecasting
- arXiv：https://arxiv.org/abs/2608.21277 （cs.LG）
- 作者：Yichen Jiang, Yueqiao Chen, Dongyu Liu
- **TL;DR**：把多元时序预测组织在一组"命名、人类可读的概念"之上——用 LLM 提出任务相关概念并生成可执行的打标规则，做成三层"概念瓶颈"，让预测过程显式化、可在概念层做干预。
- **解决什么问题 / 为什么重要**：SOTA 时序预测器能建复杂的时间与跨变量依赖，但表征不透明、说不清"为什么这么预测"，在需要理解驱动因素的场景难落地。ConceptTS 属于你 A 方向最看重的「内生 / 自解释」横切重点——不是事后归因，而是把可解释结构（概念瓶颈）直接嵌进预测通路，且用 LLM 领域知识替代昂贵的人工概念标注。
- **核心方法**：LLM 先提出任务相关概念、并生成可执行的 labeling rules，把语言模型的领域知识转成对概念激活的直接监督；概念被组织成三个互补瓶颈，分别刻画历史上下文、局部预测区间、整段预测视野；一个共享解码器把各瓶颈预测激活得到的表征组合成最终预测，使决策过程显式、支持概念级直接干预。
- **主要结果**：在北京多站点空气质量数据集上，预测精度与强黑盒基线相当，同时给出语义上有意义的概念激活。
- **值得追问 / 局限**：①概念与打标规则由 LLM 生成，规则质量、概念是否互斥/完备、以及"概念激活正确≠因果正确"的可靠性需看细节；②仅在单一数据集（空气质量）上验证，跨领域概念可迁移性与在强非平稳序列上的稳健性尚未展开。

### 2. TH-GNN: Heterogeneous Temporal Graph Neural Networks for LLM-Agent Shilling Attack Detection
- arXiv：https://arxiv.org/abs/2608.20376 （cs.CL / cs.LG）
- 作者：Shivam Swarup, Divya Prakash Shrivastava, Rakesh Thakur
- **TL;DR**：用异构时序图神经网络联合建模"时间 × 结构 × 语义"三路信号，检测 LLM 智能体批量生成的托评/刷单攻击——每条边带可学习正弦时间编码，GRU 建模到达间隔的时序突发性。
- **解决什么问题 / 为什么重要**：LLM agent 能规模化生成逼真的刷单画像、流畅评论与一致评分，纯文本检测器看不到图结构与时序协同，纯图检测器又读不懂评论语义与跨模态不一致。该工作正落在你 A 方向的「时序图 / 动态图 + 事件流突发性」——用 per-relation attention + 边级时间编码 + inter-arrival GRU 把动态图与事件流特征做进一个骨干。
- **核心方法**：两层 Heterogeneous Graph Transformer 骨干，做按类型/按关系的注意力，并在每条边上加可学习正弦时间编码；跨模态注意力融合结构化用户嵌入与冻结 RoBERTa 的评论/物品描述表征；一个作用于对数到达间隔（log inter-arrival time）的 GRU 捕捉时序突发性。
- **主要结果**：在 5 类攻击家族、4 个基准上评测，宏平均 F1 达 0.870；在 Agent4SR 攻击、最低注入率下比最强纯文本基线分别高 10.9 / 11.5 个百分点。
- **值得追问 / 局限**：①对抗方是 LLM，攻击者一旦适配到达间隔分布/协同模式，边级时间编码与突发性特征是否会失效值得看鲁棒性；②依赖冻结 RoBERTa 语义表征，面对更强的 LLM 生成文本（语义漂移更小）时文本通路增益能否维持存疑。

## B. 应用场景

### 3. NeuroStrata: An Electroencephalographic Connectivity-Aware Deep Representation Learning Framework for Dynamic Brain Network Analysis of Mental Stress
- arXiv：https://arxiv.org/abs/2608.20354 （q-bio.NC / cs.AI / cs.LG）
- 作者：Sayantan Acharya, Hamzeh Asgharnezhad, Abbas Khosravi, Douglas Creighton, Roohallah Alizadehsani, U Rajendra Acharya（Deakin 大学等）
- **TL;DR**：用时变偏定向相干（TV-PDC）把 EEG 建成随时间演化的、频段特异的有向脑连接图，再用预训练 CNN/ViT 提"连接嵌入"、轻量 ML 分类器判定精神压力，强调动态脑网络而非静态特征。
- **解决什么问题 / 为什么重要**：常规 EEG 分类多用静态特征，忽略连接的时间演化与方向性。NeuroStrata 显式建模"频段特异的有向连接随时间演化"，正对你 B 方向的神经影像时序 / 脑网络（EEG，紧邻 fNIRS）——其"时变有效连接 → 图 → 深度表征"的管线思路对 fNIRS 血氧动态连接分析可直接迁移。
- **核心方法**：32 通道 SAM 40 心算任务数据集 → 生成 TV-PDC 连接图；用预训练 CNN 与 ViT 提取深度连接嵌入；再接轻量机器学习分类器做压力判别；对不同频段/骨干做系统对照。
- **主要结果**：beta 频段连接判别力最强，LAION-CLIP-ViT-L14 + SVM 峰值准确率 97.3%；alpha 频段表现最稳；连接分析显示以额区驱动的 alpha 影响与中央整合的 beta 连接模式；时序上分类性能在中后期时间窗趋稳，提示压力相关连接特征的渐进固化。
- **值得追问 / 局限**：①单数据集、被试规模有限，97.3% 是否含被试内泄漏、跨被试/跨任务泛化未验证；②TV-PDC → 图像化 → 视觉骨干这一步引入的表征损失与可解释性折衷，值得与直接图神经网络建模做对照。

### 4. Root cause analysis via difference graph discovery from linear time-series data
- arXiv：https://arxiv.org/abs/2608.21117 （cs.AI）
- 作者：Anouk Ruer, Timothée Loranchet, Daria Bystrova, Charles K. Assaad
- **TL;DR**：把根因分析看成"正常 vs 异常两种状态间的差异因果图发现"，专门锁定"效应反常"的根因——即因果系数在异常状态下发生改变的变量，用线性离散时间动态结构因果模型形式化。
- **解决什么问题 / 为什么重要**：根因分析要在复杂动力系统里定位异常的成因机制。该工作把"两总体差异图发现"迁到时序设定（两总体换成正常/异常两种状态），直接命中你 B 方向的监控告警 / 根因定位，且方法内核是"时序 × 因果图"，与你 A 方向的图/时序偏好天然衔接。
- **核心方法**：用线性离散时间动态结构因果模型（SCM）刻画问题，聚焦 effect-defying root causes（正常与异常状态间因果系数变化的变量）；把若干原为"两总体差异图发现"的方法适配到时序，用正常/异常两段替代两总体，从而直接定位系数发生改变之处。
- **主要结果**：先在仿真数据上评估各方法，再在 IT 监控与重症监护（ICU）两类真实数据上验证，结果显示差异图发现能帮助定位导致异常行为的因果机制。（ECML-PKDD CAESAR Workshop 2026 接收）
- **值得追问 / 局限**：①线性 + 已知/可估结构的假设较强，真实告警场景常是非线性、含隐藏混杂与时延，可扩展性待看；②"效应反常型根因"只是根因的一类，对结构未变但输入分布漂移导致的异常覆盖有限。

## C. Agent / 机制与表征

### 5. Who Do Language Models Think Is Competent? A Mechanistic Analysis of Occupational Bias
- arXiv：https://arxiv.org/abs/2608.20347 （cs.CL / cs.AI / cs.CY）
- 作者：Keren Fuentes, Aaron Mueller
- **TL;DR**：用因果框架把"职业偏见"拆成两个测量点——模型对用户能力的内部表征、与其可观测输出，导出"用户专业度"的引导向量并验证其因果中介作用，发现即便行为层看不出偏见，表征层偏见依然可检测。
- **解决什么问题 / 为什么重要**：模型常能通过行为层的偏见测评，但说不清它是"真的不再表征这些关联"还是"只学会不表达"。这篇用机制/因果视角把表征与行为分离，正属于你 C 方向优先的「机制/现象分析 + 表征」——而且方法是引导向量 + 因果中介，可迁移到你更关心的表征几何分析。
- **核心方法**：提出因果框架，把职业偏见分解为"模型对用户能力的内部表征"与"可观测输出"两个测量点；为"用户专业度"表征导出引导向量（steering vectors），并在问答与招聘两个任务上验证其对模型行为的因果中介；把框架用到多个开源权重模型上。
- **主要结果**：性别、种族、社会经济地位等人口属性会影响模型对用户专业度的内部表征——即使行为指标在不同人群间检测不到差异；干预表明这些表征在干预下能影响下游行为，揭示了纯行为指标测不出的失效模式。
- **值得追问 / 局限**：①引导向量方向的可识别性与跨模型/跨层稳定性，决定"表征层偏见"结论的强度，需看鲁棒性分析；②"表征里有偏见但行为未表达"到何种程度构成实际风险，需要与部署场景的实际决策链路挂钩评估。

### 6. Approximate Homomorphisms and Convergent Representations in Transducers
- arXiv：https://arxiv.org/abs/2608.20428 （cs.LG / cs.AI）
- 作者：Santiago Cifuentes
- **TL;DR**：研究受控随机过程（transducer）最小表征在扰动下的稳定性——提出"近似同态"刻画不同实现间的局部结构相似，证明有限秩接口下最小线性/预测 transducer 会以扰动线性的误差收敛到规范实现，为"神经网络隐层存在预测态结构"提供理论支撑。
- **解决什么问题 / 为什么重要**：近来实验发现神经网络的隐层表征里存在"预测态（predictive-state）"结构。这篇从理论上问：这种规范最小表征在扰动下稳不稳？正落在你 C 方向的「表征几何 / 机制」优先项——它不是刷某个电路，而是给"隐层表征为何会结构性收敛"立可证明的条件，对内生结构/自解释表征有基础价值。
- **核心方法**：考虑 standard / linear / predictive 三类 transducer；引入"近似同态"捕捉不同实现动态（称作 interface）之间的局部结构相似，并给出比较其诱导动态的度量，证明近似同态可组合等性质；对 standard transducer 给出反例（存在简单 interface 之间无近似同态），对每个有限秩 interface 则证明足够接近的最小线性 transducer 都存在误差随扰动线性的近似同态，并在温和的信念态可区分性假设下给出预测 transducer 的类似稳定性结论。
- **主要结果**：识别出"规范 transducer 表征对扰动稳健"的条件，同时表明缺少额外结构限制时这种收敛会失败；在"此类抽象嵌入现代 AI 模型隐层"的假设下，为"隐层表征呈结构性收敛"的猜想提供理论支持（40 页，含 17 页附录）。
- **值得追问 / 局限**：①核心结论建立在 transducer/有限秩接口的抽象与若干假设（如信念态可区分性）之上，与真实 Transformer 隐层的对应仍是"假设"层面，缺经验验证；②对 standard transducer 的反例说明结构收敛并非普适，实践中如何判定某模型是否满足"足够接近有限秩接口"缺可操作判据。
