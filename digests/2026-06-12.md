## A. 核心方法 · 时空图 GNN / 连续时间 Neural ODE

### 1. MP3: Multi-Period Pattern Pre-training for Spatio-Temporal Forecasting
- 链接：https://arxiv.org/abs/2606.13119
- 作者（前几位）：Lilan Peng, Yandi Liu, Qingren Yao, Chongshou Li, Tianrui Li（西南交大等）
- **TL;DR**：提出一个即插即用的"多周期模式预训练"插件 MP3，专治城市时空数据里的"时间海市蜃楼"（相似短窗输入未来走势却南辕北辙），给现有 STGNN 骨干普遍涨点。
- **解决什么问题 / 为什么重要**：短窗输入存在周期观测不完整、全局空间相关异质、跨周期叠加因果三大缺陷，导致 STGNN 无法分辨"短窗相似但未来发散"的样本。这正是你时空图 GNN 方向的核心痛点，而且做成了与骨干无关的预训练插件，迁移成本低。
- **核心方法**：三件套——(1) 多周期时间建模用 edge convolution 从长序列里抽不同周期模式；(2) 多周期空间建模用 bottleneck 投影 + 全局 memory bank 高效刻画异质全局空间关系；(3) 跨周期交互用 causality-enhanced Transformer 捕捉不同周期模式间依赖。预训练后无缝插入已有 STGNN。
- **主要结果**：在 5 个 STGNN 基线 × 5 个真实数据集（含大规模 CA）上一致涨点，平均 MAE↓4.7%、RMSE↓5.0%，展现可扩展性与适配性。代码已开源（GitHub: YAN-outlook/MP3）。
- **值得追问 / 局限**：① "全局 memory bank + causality Transformer" 带来的预训练开销 vs. 4–5% 的平均增益，性价比在大图上是否仍成立；② "temporal mirage" 的判别力提升有多少来自周期先验、多少来自更大的参数/预训练数据，消融上还可更细。

### 2. COGENT: Continuous Graph Emulators with Neural Ordinary Differential Equations for Long-Term Physical Forecasting
- 链接：https://arxiv.org/abs/2606.11162
- 作者（前几位）：Zesheng Liu, Maryam Rahnemoonfar（Lehigh University）
- **TL;DR**：把图表示 + 隐空间 Neural ODE + 连续时间 rollout 统一进一个网格物理仿真 emulator，可在不规则地理网格上做任意时刻、长程稳定的预测。
- **解决什么问题 / 为什么重要**：传统自回归图模型在长程 rollout 上会误差累积、且只能在固定时间离散点取值。COGENT 用连续时间隐动力学直接生成轨迹，一次性多步预测、还能查询任意未来时刻——同时命中你方向 A 里的"图 + Neural ODE + 不规则采样/连续时间"三个关键词。
- **核心方法**：图历史编码器把有限历史状态与外强迫编码成节点级 context 向量，初始化并 condition 一个 latent Neural ODE；ODE 动力学由插值后的未来强迫和显式相对 rollout 时间驱动，残差 decoder 把隐轨迹映回物理状态。训练上提出 rollout-horizon 采样 + 渐进式 horizon 调度来稳住长程监督。
- **主要结果**：在 Ice-sheet and Sea-level System Model 生成的瞬态冰盖仿真上，长程稳定性优于自回归图基线，支持任意时刻查询。
- **值得追问 / 局限**：① 评测目前只在冰盖单一物理系统上，跨物理场景（流体/气象）泛化与刚性动力学下 ODE 求解稳定性待验证；② "渐进 rollout 调度"对长程稳定的贡献需与 ODE 本身解耦，否则难判断增益来源。

## A×B 横切 · 内生自解释 + 时序异常检测

### 3. ProtoX-AD: Self-Explainable Time Series Anomaly Detection and Characterization
- 链接：https://arxiv.org/abs/2606.13277
- 作者（前几位）：Aitor Sánchez-Ferrera, Elisabeth Wetzer, Kristoffer Wickstrøm, Michael Kampffmeyer, Robert Jenssen（UiT 挪威北极大学等）
- **TL;DR**：给自监督时序异常检测装上原型（prototype）自解释能力——检测准的同时，能用可解释原型刻画"这是哪一类异常"。
- **解决什么问题 / 为什么重要**：当前 SOTA 的自监督分类式 TSAD（对正常样本做变换、训分类器、用分类误差判异常）效果好但是黑箱，说不清被标异常长什么样。这一篇正落在你的横切重点——**内生/自解释（prototype-based）**，且应用场景就是 B 的时序异常检测，是 A×B 的标准结合点。
- **核心方法**：在自监督 TSAD 框架内同时学习"变换感知"的隐表征与一组可解释原型；异常既由分类误差判定，也通过原型匹配给出"异常画像"。框架还能系统分析变换设计如何影响检测性能与可解释性。
- **主要结果**：合成 + 真实数据上检测性能与黑箱版本相当，但解释比现有可解释基线更一致、语义更清晰。代码开源（GitHub: Aitorzan3/ProtoX-AD）。
- **值得追问 / 局限**：① 原型自解释相对黑箱"性能持平"——但持平是否意味着自解释约束没有反过来提分？理想的内生可解释应能借结构化先验提升而非仅不掉点；② 原型数量、变换族的选择对解释质量的敏感性，摘要层面未交代。

## B. 应用场景 · 监控告警异常检测 / 神经成像

### 4. CRAFTIIF: Cross-Resolution Analytic Four-Type Interpretable Isolation Forest for Multivariate Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2606.13486
- 作者：William Smits
- **TL;DR**：一个全无监督、零数据集调参的多变量时序异常检测框架，把异常拆成四种结构类型分别用解析小波特征 + 结构化 Isolation Forest 检测，靠"哪条分支触发"天然给出异常类型归因。
- **解决什么问题 / 为什么重要**：多变量时序异常有点异常、分布漂移、节律变化、传感器间相关性崩溃四种结构本质不同，多数无监督方法只覆盖一两种且不可解释。AIOps/监控告警最需要的恰是"既能覆盖多类异常、又能直接说清是哪类异常"——这篇用"by construction 的分支归因"省掉了 post-hoc 解释。
- **核心方法**：对 4 个小波族（Morlet/DOG/Haar/Coiflet）各采 K=500 个随机解析特征、每族针对一种异常类型，喂给 5 个结构化 Isolation Forest（四类型各一 + 一个 meta-IF 处理复合异常）；自适应 Otsu/MAD 阈值在 0.1%–69.2% 异常率间自动标定。
- **主要结果**：在 mTSBench 全部 19 个数据集上，VUS-PR=0.463 在 25 个方法中排第一（较此前最佳 0.329 提升 +40.7%）；均值 F1=0.228（19 集）/0.322（13 个可检测集）。诊断框架还判定其中 6 个数据集对任何无监督方法都"本质不可检测"。消融确认自适应阈值（+38% F1）、四分支结构（+20%）、meta-IF（+23%）各自必要。代码开源（GitHub: smitswil/craftiif）。
- **值得追问 / 局限**：① 绝对 F1 仍偏低（0.22–0.32），说明无监督多变量异常本身上限有限，"排第一"更多是相对优势；② K=500 随机小波 draw × 5 个 IF 的计算/内存开销在高维实时监控下能否在线跑，待看延迟数字。

### 5. Beyond Representational Alignment with Brain-Guided Language Models for Robust Reasoning
- 链接：https://arxiv.org/abs/2606.11893
- 作者（前几位）：Mingqing Xiao, Kai Du, Zhouchen Lin（北京大学）
- **TL;DR**：不止于"测量"LLM 与人脑表征的对齐，而是用推理相关脑区的 task-fMRI 信号**主动引导**并提升 LLM 的演绎推理能力。
- **解决什么问题 / 为什么重要**：以往 LLM-脑研究停在"相关性/对齐度"测量。这篇把它推进到"引导（guidance）"——用脑信号 steer 模型表征并在推理上拿到实打实增益，对你 neuroimaging time series / brain network 方向是"神经信号反哺模型"的新范式；fMRI 时序作为监督信号的用法也值得借鉴到脑信号建模。
- **核心方法**：先用 neural-predictivity 指标量化 LLM 内部表征对推理脑区可解释方差的解释程度（发现聚合层面对齐、细分推理类型上发散）；再提出 brain-guided 框架——沿"模型表征 × 脑表征联合结构"诱导的方向 steer，推理时干预、训练时微调。
- **主要结果**：跨 10 个 LLM（1.5B–72B）拿到与纯语言监督正交的增益，可在推理类型间迁移，最高绝对准确率 +13%；把 LLM-脑关系从"相关"推进到"引导"。
- **值得追问 / 局限**：① 脑信号增益"与语言监督正交"很关键，但 +13% 是否依赖特定脑区/被试，跨数据集稳健性需更多验证；② 推理时干预需要的脑信号来源（是否需配对 fMRI）决定该方法是研究范式还是可落地工具。

## C. Agent · 技能 / 记忆自演化

### 6. SkillCAT: Contrastive Assessment and Topology-Aware Skill Self-Evolution for LLM Agents
- 链接：https://arxiv.org/abs/2606.13317
- 作者（前几位）：Kunfeng Chen, Qihuang Zhong, Juhua Liu, Bo Du（武汉大学）
- **TL;DR**：让 LLM agent 把执行轨迹沉淀成可复用"技能"的 training-free 框架——多轨迹对比抽取因果证据、先验证再合并技能补丁、按拓扑只加载相关技能节点。
- **解决什么问题 / 为什么重要**：现有技能自演化管线有三大毛病：每个任务只学一条轨迹、补丁先合并后验证、推理前要加载整个技能库。SkillCAT 对应你 C 方向偏好的"memory（技能记忆组织）+ 机制"，而非纯 prompt 技巧——它是无需训练、围绕"经验如何被结构化、验证、检索"的机制设计。
- **核心方法**：三阶段——(1) Contrastive Causal Extraction：对每个任务采多条轨迹，比对同任务的成功/失败对，定位解释结果差异的证据；(2) Assessment-Augmented Evolution：每个候选补丁在源任务克隆上重放，只保留提升或维持结果的补丁，再做分层补丁合并；(3) Topology-Aware Task Execution：把演化出的技能编译成可路由的子技能拓扑，推理只加载相关能力节点。
- **主要结果**：在 SpreadsheetBench、WikiTableQuestions、DocVQA 等 agent 基准上，平均分较基线最高提升 40.40%，并在跨模型与 OOD 设定下验证泛化，全程无需模型训练。
- **值得追问 / 局限**：① "training-free + 多轨迹采样 + 补丁重放验证" 把成本从训练转移到了推理期采样/重放，实际 token/时延开销与收益的净账需看清；② "成功/失败对的因果证据抽取"本质仍依赖 LLM 自评，因果归因可能不稳——这恰是该类记忆机制最该被压力测试的点。
