## 1. HierSTT: Hierarchical Spatio-Temporal Transformer for Coherent Emergency Department Forecasting
- arXiv: https://arxiv.org/abs/2607.27106
- 作者：Filipa Lino, Bárbara Tavares, Carlos Santiago, Cláudia Soares, Manuel Marques（IST / NOVA，葡萄牙）
- **TL;DR**：急诊（ED）需求预测需要同时服务医院、区域、全国三个决策层级，各自独立建模会导致"下级预测加总对不上上级"的不一致。HierSTT 用一个端到端的分层 Transformer 同时预测三层需求，并用一致性损失把各层级绑在一起。
- **解决什么问题 / 为什么重要**：正对 A 方向"时空建模"。它把分层时间序列的"coherence（层级一致性）"问题用深度时空模型直接内建：不靠事后的 reconciliation（协调），而是让全国动态、区域、医院三级在训练时相互条件化并互相约束——这对任何"多粒度时空预测需保持加总一致"的场景（交通、能耗、跨机构监控聚合）都有迁移价值。
- **核心方法**：用 Temporal Fusion Transformer 建全国层动态；区域与医院层用时空 Transformer 编码器-解码器建模，且以更高层级的预测作为条件输入；再加一个"coherence-aware loss"在训练时惩罚跨层级不一致。配套发布覆盖 5 大区、81 家医院的葡萄牙全国 ED 数据集（各层级有异质协变量）。
- **主要结果**：相对最强的非分层深度基线，平均 WAPE 降低 32%；同时优于所有经典分层协调方法，并产出跨层级近乎一致的预测。
- **值得追问 / 局限**：一致性靠软惩罚而非硬约束，无法保证严格可加；单一国家单一数据集，跨国/跨系统迁移未验；三级联动的收益中，多少来自"层级条件化"、多少来自 Transformer 本身，摘要未做消融拆分。

## 2. Neural Architecture Search for Traffic Prediction: A Survey of Methods, Challenges, and Future Directions
- arXiv: https://arxiv.org/abs/2607.26467
- 作者：Truong Giang Vu, Li Yang, Richard W. Pazzi（Ontario Tech，加拿大）
- **TL;DR**：交通预测里的时空模型（GCN / RNN / Transformer）架构大多靠专家手工设计、跨城市泛化差。这篇综述系统梳理了"用神经架构搜索（NAS）自动搜时空模型"的工作，按搜索策略分类并指出开放问题。
- **解决什么问题 / 为什么重要**：属 A 方向"时空 GNN 方法学"。价值不在提新方法，而在把"如何为时空数据设计搜索空间（覆盖空间/时间算子）"和"如何权衡搜索成本与架构质量"讲清楚；并明确点名"动态图结构"和"面向时空基座模型的 NAS"为待解难题——正好对上我关心的动态图 / 时空基座方向，可当作找 baseline 与研究缺口的地图。
- **核心方法**：按搜索策略把 NAS 方法分成三类——基于梯度、进化、one-shot 权重共享；对每类分析其搜索空间如何覆盖空间与时间算子、搜索策略如何在成本与质量间权衡。
- **主要结果**（综述类）：归纳出若干开放挑战：对大规模路网的计算可扩展性、搜索空间仍需人工设计、跨城市泛化、动态图结构建模，以及"时空基座模型的 NAS"这一开放问题。
- **值得追问 / 局限**：综述无实验，方法优劣的定量对比需回到原论文；范围限定交通预测，向脑网络/事件流等其它时空图任务的结论迁移需谨慎；"NAS 能否真正带来跨城市泛化"仍是开放问题，未有定论。

## 3. Conformal Changepoint Localization and Root Cause Analysis with Corrupted Observations
- arXiv: https://arxiv.org/abs/2607.26481
- 作者：Seunghun Yu, Meiyi Zhu, Petar Popovski, Joonhyuk Kang, Osvaldo Simeone（KAIST / Aalborg / KCL）
- **TL;DR**：监控工程系统时既要判"何时发生了变化（变点）"，又要判"哪个组件是根因（RCA）"，且在安全攸关场景需要统计保证而非点估计。共形变点定位（CONCH）与共形根因分析（CROC）能给出带覆盖率保证的置信集，但数据被离群/传感器故障/对抗扰动污染时置信集会大到没用。本文提出加权版 W-CONCH / W-CROC 来缩小污染下的置信集。
- **解决什么问题 / 为什么重要**：正对 B 方向"异常检测 / 根因定位 / AIOps"，且难得地带严格覆盖率保证。它把"污染鲁棒性"引入共形监控：既保住有限样本覆盖率，又在有污染时把置信集收窄到可用——对做告警/RCA、又不愿放弃可靠性保证的监控系统很对味。
- **核心方法**：采用 Huber 型污染模型，对"可能被污染"的观测降权；权重由对未知污染数据密度的形式化上界导出，并复用已有的二阶分类器不确定性信号（如证据深度学习/贝叶斯学习）。进一步用元学习优化一个"置信集大小"的可微替代目标来学权重。
- **主要结果**：在图像类与真实变点/根因基准上，基于不确定性的加权在维持目标覆盖率的同时显著缩小了置信集。
- **值得追问 / 局限**：依赖"二阶不确定性信号可得且校准良好"这一前提，信号本身若被污染带偏，权重也会失真；Huber 污染模型对真实告警数据中相关/结构化异常的贴合度需验证；元学习权重的额外训练成本与在线可用性摘要未量化。

## 4. An Attention-Based Framework for Alzheimer's Disease Classification Using Resting-State fMRI
- arXiv: https://arxiv.org/abs/2607.26746
- 作者：Harshiddhi Pathak, Gowtham Reddy N, Mrinal Acharya, Manjunatha Mahadevappa（IIT Kharagpur）
- **TL;DR**：用静息态 fMRI 做阿尔茨海默（AD）分类，难在功能连接高维、噪声大、脑区间依赖复杂。本文把脑区当作 token、用 Transformer 式自注意力直接在功能连接矩阵上建模长程/全局依赖，端到端学判别性表征，不做手工特征工程。
- **解决什么问题 / 为什么重要**：正对 B 方向"neuroimaging / 脑网络时序"。虽是 fMRI 而非 fNIRS，但"把脑区当 token、自注意力建功能连接"的范式与 fNIRS 脑网络分析高度同构，可直接借鉴到近红外脑功能建模；且它强调 subject-wise 划分防止跨 visit 信息泄漏，评测协议规范。
- **核心方法**：直接在 rs-fMRI 功能连接矩阵上操作，把每个脑区作为一个 token，用 Transformer 式自注意力建模脑区间长程与全局依赖；采用 subject-wise 评测协议避免同一被试多次 visit 造成泄漏；用类加权优化缓解轻度类别不平衡。数据取自 ADNI 纵向队列（正常认知 vs AD）。
- **主要结果**：AD vs 认知正常的二分类达到准确率 88.95%、ROC-AUC 0.90，精确率-召回率平衡良好。
- **值得追问 / 局限**：仅二分类（AD vs CN），未含 MCI 等更难的中间态；样本规模与外部队列泛化未在摘要交代；作者称自注意力"可解释"，但注意力权重是否真对应可信的脑网络机制、而非仅关联，需要归因验证。

## 5. Metis: Memory Foundation Model
- arXiv: https://arxiv.org/abs/2607.26760
- 作者：Zeyu Zhang, Ziliang Guo, Yihang Sun 等（含 Junchi Yan、Zhi-Qin John Xu、Xu Chen、Tat-Seng Chua 等，共 17 位；上海算法创新研究院 / SJTU / 人大 / NUS 等）
- **TL;DR**：当前 AI agent 的"记忆"大多是外挂模块，基础模型自身缺乏原生记忆能力。本文提出"记忆基础模型"，把持久、动态演化的记忆状态与"自主存取信息的记忆过程"内生进骨干网络，并给出首个原型 Metis。
- **解决什么问题 / 为什么重要**：属 C 方向"优先（memory / 架构 / 训练动态）"那类，明显非 prompt 工程。它把 agent 记忆从"检索外挂"转为"模型内生状态"，主打架构、端到端优化与效率上的优势——对做长期记忆、持续学习、以及"记忆几何/表征"研究的人是一个可对照的新范式。
- **核心方法**：从两视角形式化原生记忆——骨干内部一个持久且动态演化的记忆状态，以及通过模型计算自主存取信息的"原生记忆过程"。Metis 新架构为基础模型配一个原生记忆状态，把历史信息压缩进模型、经"记忆注意力"访问；构造大规模记忆专用训练数据并用多目标 mid-training 习得记忆过程。在线记忆维护无需梯度、更新只需一次前向；推理时权重全冻结，记忆状态经标准前向自主变换。
- **主要结果**：实验证实 Metis 具备原生记忆能力，并给出对其优势、局限与行为的细致分析；开源项目与模型 checkpoint。
- **值得追问 / 局限**：摘要以能力展示与分析为主，缺与主流"外挂记忆/长上下文"基线的正面量化对比（收益幅度不明）；"把历史压缩进固定权重的记忆状态"面对长时程时的容量/遗忘上界如何，需看正文；无梯度在线更新的稳定性与可控性（防漂移/污染）待验。

## 6. From Representations to Behaviors: Exploring the Person-Situation-Behavior Triad in LLMs
- arXiv: https://arxiv.org/abs/2607.26853
- 作者：Ruikang Zhang, Shuo Wang, Qi Su（北京大学）
- **TL;DR**：既有 LLM 人格研究多停留在"人格条件下的输出表现"，缺乏"内部确有人格表征、且跨情境表达、并塑造具体行为"的机制证据。本文借 Funder 人格三元（Person=内部表征 / Situation=情境 / Behavior=行为）搭一套"发现—干预—验证"的框架。
- **解决什么问题 / 为什么重要**：属 C 方向"优先（机制/表征几何、residual/表征结构）"那类。它不是描述现象，而是用稀疏自编码器（SAE）把特质表征分离出来、并做因果干预验证其跨情境一致性与行为后果——对做 LLM 表征可解释、特质/概念方向的可控性研究是一个方法完整的样例。
- **核心方法**：① 用共享情境下的对比行为对，经 SAE 分解找到与人格特质"两极"关联的稀疏内部特征，并从"对情境的行为影响、token 级激活模式、抗改写鲁棒性"三方面验证其特质相关性；② 对特征做干预，在另一批多样情境上诱导双向的特质偏移且保持回答有效性；③ 把同样干预施于社会智能任务，观察到与人类人格研究一致的"收益-权衡"行为改变。
- **主要结果**：给出证据表明 LLM 内部含有可控的类特质表征，连接了内部状态、情境表达与行为结果三者。
- **值得追问 / 局限**：SAE 特征的"特质"语义解读带主观性，是否稳定于不同 SAE 训练/模型规模未知；干预在多样情境下"保持回答有效性"的边界（何时会损伤能力）需量化；人格框架源自人类心理学，套到 LLM 是否只是有用的隐喻、还是真有对应机制，仍可质疑。
