## 1. Intervention-Aware Clinical World Model for Post-Op Outcome Forecasting in Cardiology
- **链接**：https://arxiv.org/abs/2608.13518 （arXiv:2608.13518，cs.LG，2026-08-13）
- **作者**：Yunsung Chung, Yingshuo Liu, Abboud F. Hassan, Han Feng 等
- **TL;DR**：不要把术后预后当成「基线 → 未来端点」的一步映射，而把康复看成一条不规则轨迹——用一个「介入感知的临床世界模型」把每个病人表示为结构化潜状态，再沿着时间排序的术后事件（用药变更、复查、生理测量）逐步演化这个状态来预测远期复发风险。
- **解决什么问题 / 为什么重要**：真实术后康复里，临床观测、用药调整、二次介入、生理测量都是异步记录、且会随时间改写风险评估，传统一步预测模型抓不住这种动态。这篇正落在你重点关注的「不规则采样 / 异步时序 + 连续时间演化」交叉点，而且给了可直接落地的心脏消融临床价值。
- **核心方法**：先把基线影像编码成 3D 空间潜状态；随后用「手术上下文 + 静态协变量 + 流逝时间 + 事件周边生理嵌入」逐事件更新该状态；复查影像只在训练时通过潜空间预测目标做监督（推理时不需要复查 MRI 强度）。学到的状态支持不同时间horizon 的复发风险查询，以及对空窗期记录的回溯性输入编辑。
- **主要结果**：在 DECAAF-II 房颤消融数据上重复内部交叉验证，复发预测 AUROC 0.756、AUPRC 0.777；在不需推理期复查 MRI 的前提下，瘢痕范围 MAE 2.971 个百分点。
- **值得追问 / 潜在局限**：(1) 单中心 / 单队列（DECAAF-II）验证，样本量与外部泛化性未知；(2) 「流逝时间 + 事件嵌入」的更新是显式连续时间建模（如 ODE/衰减）还是离散事件步进，摘要未细说，迁移到更稀疏 / 更长异步序列时的时间外推能力需验证。

## 2. Perturbation-based Regional Interpretability through Subtraction Mapping (PRISM): naming-error dissociations in language models and post-stroke aphasia
- **链接**：https://arxiv.org/abs/2608.12717 （arXiv:2608.12717，cs.LG，2026-08-13）
- **作者**：Xiang Guan, Roger D. Newman-Norlund, Yong Yang, Saeed Ahmadi 等
- **TL;DR**：把人脑功能神经影像里成熟的「减法分析（subtraction mapping）」范式原样搬到被逐层扰动的 Transformer 上——把每个扰动种子当作一个「被试」，沿层轴做组分析 + 无阈值簇增强，从而给「某内部组件是否专门负责某认知操作」这类功能特化主张一个可证伪、有空间分辨率的检验。
- **解决什么问题 / 为什么重要**：机制可解释性长期缺乏「空间可定位、可证伪」的工具。这篇把神经影像的实验逻辑并行套到大模型与真实失语症患者两个基质上，直接命中你的「内生 / 自解释 × 机制分析」横切重点，同时又横跨 fNIRS/神经影像时序这条应用线，方法学上很对你的胃口。
- **核心方法**：基于 Brain-LLM 统一模型（BLUM，此前已显示逐层扰动 LLaVA-1.6-Vicuna-13B 的错误谱与失语患者病灶谱吻合），PRISM 把费城命名测试 7 类临床错误两两相减，每个扰动种子视作一个被试，沿层轴做阈值无关簇增强的组分析；同时在 213 名慢性卒中后失语患者上用「相关差异的病灶-症状映射」做结构对齐的平行分析，两侧都在留出集上复现。两侧对比算子不同（LLM 用被试内错误比例差、皮层用被试间相关差），但被试维、空间维、阈值化设计一一对应。
- **主要结果**：两个基质都稳健复现出「偏音位」的双重分离——一个深层簇 + 一个额-外侧裂周皮层簇，且都在留出集复现；「偏语义」方向则在两侧都是符号一致但不显著的趋势。作者明确把最强因果机制主张（ROI 级干预，PRISM 第 3 阶段）留待后续。
- **值得追问 / 潜在局限**：(1) 目前只给出相关性 / 分离证据，真正的因果干预（Stage 3）尚未做，功能特化主张仍是「可证伪但未证实」；(2) 结论绑定单一模型（LLaVA-1.6-Vicuna-13B）与命名任务，跨模型 / 跨任务的普适性、以及「层 ↔ 皮层区」类比的边界都需谨慎对待。

## 3. EGRL: Edge Generation-guided Relation-aware Learning for RNA-protein Interaction Prediction
- **链接**：https://arxiv.org/abs/2608.12906 （arXiv:2608.12906，cs.LG，2026-08-13）
- **作者**：Danyu Li, Ling Zhou, Rubing Huang, Xian Zhong 等
- **TL;DR**：给 RNA-蛋白互作预测的 GNN 去掉「预定义元路径 / 同质图」的拐杖——用隐式元路径学关系语义、多关系感知注意力做自适应融合，并额外训一个「边生成器」预测潜在软边来救冷启动节点，从而在数据稀疏、面对未知分子时也能泛化。
- **解决什么问题 / 为什么重要**：现有 GNN-RPIP 方法多依赖手工元路径或同质图，遇到数据稀疏和冷启动（未见分子）就退化。这篇落在你「图神经网络 / 关系建模 + 冷启动泛化」这条核心方法线上，「边生成救冷启动」的思路对稀疏动态图 / 事件图场景也有借鉴价值。
- **核心方法**：EGRL 含四个部件——隐式元路径学习（不用手工路径即可捕获关系语义）、多关系感知注意力（自适应融合多种互作模式）、一个预测「软边」以支撑冷启动节点的图生成器、以及做最终打分的多特征融合预测器；用「主任务损失 + 生成器辅助损失」联合训练。
- **主要结果**：四个基准上整体性能有竞争力；冷启动（未知分子）设定下优势更明显——AUROC 0.867、AUPR 0.861，较此前 SOTA 分别提升 8.6%（AUROC）与 5.0%（AUPR）。代码待放出。
- **值得追问 / 潜在局限**：(1) 生成的「软边」缺乏真值约束，可能引入结构噪声 / 假阳性关系，其对冷启动增益的贡献需消融厘清；(2) 面向静态互作图，若要迁到你更关心的时序 / 动态图，边生成器与时间演化如何耦合仍是开放问题。

## 4. Beyond Simulated Benchmarks: Evaluating Motion Representations for Fall Detection Under Real-World Data Scarcity
- **链接**：https://arxiv.org/abs/2608.13197 （arXiv:2608.13197，cs.LG，2026-08-13）
- **作者**：Timilehin B. Aderinola, Ilaria D'Ascanio, Luca Palmerini, Lorenzo Chiari 等
- **TL;DR**：系统评测穿戴式跌倒检测的四类运动表征（区间型、核方法、符号型、基础模型），核心发现是——高参数的核 / 基础模型在仿真数据上很强，一到真实数据稀缺 + 域移就严重退化；而给符号表征加上「物理接地的冲击描述子」这一可解释轻量方案，在域移下退化最小。
- **解决什么问题 / 为什么重要**：真实跌倒极其罕见（估计采集 100 次真实跌倒需约 10 万天监测），逼得大家用仿真数据，实验室指标虚高、真实泛化差。这篇同时踩中你「监控告警 / 罕见事件检测」应用线与「内生可解释表征」的横切重点，且用了临床核验的真实跌倒数据做对照，方法论警示意义强。
- **核心方法**：用加速度信号，横向比较区间型、核型、符号型与基础模型四类表征；额外引入一个「把短运动片段转成带物理接地冲击描述子的符号句子」的轻量可解释基线。在 FallAllD（仿真）与 FARSEEING（临床核验的真实跌倒）上，做交叉验证、可控数据稀缺、跨数据集迁移三种考察。
- **主要结果**：核 / 基础模型在仿真上领先，但在数据稀缺与域移下都严重退化；区间型表征取得最强的真实世界绝对性能；而「符号 + 物理冲击描述子」在域移下退化最小、极端稀缺下仍保住检测灵敏度（代价是精确率偏低）。
- **值得追问 / 潜在局限**：(1) 「符号 + 冲击描述子」灵敏度保住但精确率下降，实际部署的误报成本需权衡；(2) 结论基于加速度单模态与两个特定数据集，换传感器位置 / 采样率 / 人群时的稳健性还需验证。

## 5. Intern-S2-Preview: Scientific Agentic Foundation Model
- **链接**：https://arxiv.org/abs/2608.13505 （arXiv:2608.13505，cs.LG，2026-08-13）
- **作者**：Lei Bai, Jiaqi Cao, Chiyu Chen, Guanzhou Chen 等（上海人工智能实验室等）
- **TL;DR**：一份面向科学发现的「智能体基座」技术报告——397B 主干在渲染科学文档 + 图文交错 + 多样科学语料上做多模态预训练，再走 SFT + 多任务 RL + 黑/白盒智能体 RL + on-policy 蒸馏的统一后训练；架构上把时序建模从长序列理解扩到数值预测，并把「记忆解码器」作为不改冻结主干的记忆增强旁路。
- **解决什么问题 / 为什么重要**：科学场景需要跨异构模态推理、能调用科学工具/环境、并在长任务horizon上持续推进的系统。这篇属于你 Agent 方向里「优先」的那类——技术报告 + 记忆机制 + 训练管线，且顺带把时序建模并入基座，机制层面信息量足，远离纯 prompt 工程。
- **核心方法**：多模态科学预训练打底；后训练含 SFT、可扩展多任务 RL、黑/白盒智能体 RL、on-policy 蒸馏，并配一系列稳定/高效技巧（带 off-policy 修正的部分 rollout、自适应长度正则、在线投机解码、鲁棒多任务优化、面向智能体任务的 trace-aware 经验组装）。架构上 Intern-S2-Preview-397B 扩展时序建模到数值预测；Intern-MemDec-4B 作为不改冻结 397B 主干的记忆增强旁路。
- **主要结果**：在科学、多模态、智能体与通用基准上多处取得有竞争力或领先的结果；时序模块在 SciTS 上提升科学信号理解与预测；独立的 Intern-MemDec-4B 把 Biology-Instructions 平均分从 56.92 提到 60.32，且不改动冻结的 397B 主干。
- **值得追问 / 潜在局限**：(1) Preview 版技术报告，多为自选基准 + 内部对比，横向可比性与复现细节有待正式版；(2) 「记忆解码器不改主干即涨点」很有吸引力，但其对更长horizon、跨学科迁移的稳健性，以及与主干时序模块的协同边界尚待外部检验。

## 6. AlayaWorld: Interactive Long-Horizon World Modeling — Full Technical Report (v1.1)
- **链接**：https://arxiv.org/abs/2608.13492 （arXiv:2608.13492，cs.AI，2026-08-13）
- **作者**：AlayaWorld Team, Kaipeng Zhang, Chuanhao Li, Yifan Zhan 等
- **TL;DR**：一份交互式长时程世界模型的迭代技术报告——主干、分块自回归生成方案、训练数据都不变，只重做「条件信号怎么表示与注入」，核心原则一句话：条件信号应在潜表示与时间结构上尽量贴近被生成的内容。
- **解决什么问题 / 为什么重要**：长时程世界模型的老问题是空间记忆漂移与条件-内容表征/时间结构不匹配。这篇落在你 Agent 方向「优先」类的机制/技术报告一侧，尤其是「空间记忆的表征与时间对齐」直接关联你关注的 memory 与表征结构问题，对时空一致建模有借鉴意义。
- **核心方法**：两处大改——(1) 用「流式 3D 点缓存渲染器」替换原先基于深度扭曲（depth-warping）的空间记忆；(2) 重设计条件管线，让视觉条件编码进与生成内容同一个 causal-VAE 潜空间、且时间统计一致。具体六项修改：静态帧图像条件 → 运动感知潜条件；把重渲染的空间记忆按因果方式编码成连续序列；在像素空间对齐时间记忆窗口；采用「硬记忆丢弃」直接移除记忆 token 而非置零；训练与推理统一 VAE 编解码协议；移除相机 AdaLN 分支、视角控制完全交给重渲染的空间条件。
- **主要结果**：为纯方法/工程性技术报告，主要贡献是上述条件表征与空间记忆机制的重构；摘要侧重设计原则与六项改动，未列具体量化指标（以报告形式给出）。
- **值得追问 / 潜在局限**：(1) 摘要未给对比基准的量化增益，六项改动各自的贡献需看正文消融；(2) 「流式 3D 点缓存 + 像素空间对齐」对算力/显存与长时程漂移的实际收益边界，以及跨场景泛化性，需要正文数据支撑。
