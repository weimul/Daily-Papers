## 1. SHiPPO: Recurrent Memory with Transported Polynomial Projections
**方向 A（不规则采样 / 连续时间 / 记忆机制）** · arXiv: https://arxiv.org/abs/2607.03055
- **作者**：Tomoya Mizuguchi, Bum Jun Kim ｜ cs.LG
- **TL;DR**：把 HiPPO 的"在线多项式投影=记忆系数"这套连续时间记忆语义，从固定通道坐标提升到一个随 token 移动的通道标架上（Sylvester 动力学），让记忆先验能与选择性 SSM 的 token 相关控制、通道交互相容。
- **解决什么问题 / 为什么重要**：经典 HiPPO 给了 SSM 优雅的"记忆即投影系数"解释，但坐标是固定的；而 Mamba 式选择性 SSM 靠 token 相关的门控与通道混合，两者一直缺一个统一的机制视角。这篇正对我 A 方向"连续时间模型 + 记忆机制"的核心关切，且是**机制导向而非刷榜导向**的工作。
- **核心方法**：提出 transported projection-memory prior——沿任意"右传输路径"同时搬运逼近函数族与通道度量，条件在该路径上时状态退化为一个绑定移动标架里的普通 HiPPO，遵循 Sylvester 系数动力学；为选择性 SSM 执行给出 group-local 实现（控制器兼容的右作用、指数校正更新、精确 block-affine scan、循环解码），并给出"右传输何时坍缩为静态混合"的可约性判据。
- **主要结果**：受控诊断显示——加大当前 token 的写入秩能降普通预测误差，但**无法恢复对已写入记忆的顺序敏感修改**；而带传输的变体能恢复这一信号，且移除传输路径后信号消失。有限域联想回忆诊断（交错的绑定/操作/查询）提供互补的自回归证据。作者明确把结论限定在"记忆机制"而非"序列建模全面碾压"。
- **值得追问 / 局限**：① 全篇是受控诊断 + associative-recall 玩具任务，缺真实长序列基准（LRA、语言建模），"记忆机制更优"能否转化为端到端收益仍开放；② 最优右作用实现（preferred right-action realization）作者自承留白，工程落地路径未定。

## 2. Individual Parameters in Weight-Sparse Transformers Appear Interpretable
**方向 A（内生/自解释，横切）× C（机制可解释）** · arXiv: https://arxiv.org/abs/2607.02964
- **作者**：Arnau Marin-Llobet, Stefan Heimersheim ｜ cs.LG / cs.AI / cs.CL
- **TL;DR**：不做"某行为的电路逆向"，而是问单个权重能否在全训练分布上被全局理解——用自动化 LLM 管线为每个权重写一句"它在什么输入上起作用"的可验证描述，发现稀疏 transformer 里 12–31% 的权重可获得单一简短、可泛化的功能描述。
- **解决什么问题 / 为什么重要**：主流 circuit-finding 绑定特定行为与子分布，同一组件在不同输入子集上功能不同，难以"全局"归因。这篇把可解释性的粒度下沉到**单个权重 × 全分布**，并给出可证伪的验证协议——正对我"内生/自解释"横切重点里"结构本身即可解释"而非 post-hoc 归因的取向。
- **核心方法**：以"消融该权重会改变预测的输入集合"来刻画"它何时重要"；LLM 自动为该集合写简短人读描述，并**在留出文本上验证**，只有描述能泛化才给该权重记分（credit）。在两个稀疏 + 两个稠密 transformer 上对比。
- **主要结果**：稀疏 transformer 中可解释权重占比显著高于稠密模型，且在剔除不可靠描述后差距进一步拉大；稀疏模型有 **12–31%** 的权重拥有单一短描述能识别其用途。
- **值得追问 / 局限**：① "可解释"被操作化为"LLM 能写出并验证一句描述"，判定强依赖 LLM judge 的能力与提示，可能低估/高估真实可解释性；② 只覆盖到"稀疏更可解释"的相对结论，稀疏化本身的性能代价、以及 12–31% 之外的大多数权重仍是黑箱。

## 3. Open-Set Source Tracing as Compositional Factors via Structured Prototypes
**方向 A（prototype-/concept 自解释）** · arXiv: https://arxiv.org/abs/2607.03134
- **作者**：Santiago Rubio, Antonio Almudévar, Antonio Miguel, Eduardo Lleida, Alfonso Ortega ｜ eess.AS / cs.LG
- **TL;DR**：把合成语音的"来源"从"仅生成架构"重定义为（架构 × 训练数据 × 其它训练因素）的组合元组，用结构化正交原型 + 子空间划分把嵌入拆成架构子空间、数据子空间、残差随机子空间，实现对新因素组合的组合式泛化。
- **解决什么问题 / 为什么重要**：source tracing 常把 source 等同于架构，无法应对"没见过的架构+数据组合"。这里的价值不在语音本身，而在**结构化原型 + 子空间分解**这套内生可解释表征的构造范式——原型/概念级、正交约束、显式的组合语义，可迁移到我关心的自解释时序/图表征。
- **核心方法**：Structured Orthonormal Prototypes 最小化类间重叠与类内方差；Subspace Partitioning 将嵌入切成架构子空间 + 数据子空间，残差子空间吸收随机变异，从而对未见因素组合做 compositional generalization。
- **主要结果**：MLAAD 上 Few-Shot 开集识别显著优于角度间隔（angular-margin）基线，对部分可见来源提升、全开集下保持鲁棒。
- **值得追问 / 局限**：① 摘要偏方法直觉，缺子空间"确实解耦了架构/数据"的定量证据（正交性、可解释性度量未展开）；② 局限在语音反伪造域，跨模态（时序/图）迁移仅是猜想。

## 4. Reading Between the Dots: Decoding Hidden Computation across Filler Tokens
**方向 C（机制/现象分析，优先）** · arXiv: https://arxiv.org/abs/2607.03502
- **作者**：Kaley Brauer, Claudio Mayrink Verdun, Samuel Marks ｜ cs.CL / cs.AI / cs.LG
- **TL;DR**：前沿 LLM 能在无信息的 filler token（点、计数序列）上做多步推理却不留可见 CoT——本文证明这类"隐藏计算"其实结构清晰、可从残差流直接解码，用纯无监督管线仅凭隐藏态就能 80–95% 恢复中间值。
- **解决什么问题 / 为什么重要**：这是"行为级监督"（behavioral oversight）的极限情形——表面 token 不携带推理信息，CoT 监控失效。结论直指**可监控性是模型完整计算轨迹的性质，而非表面 token 的性质**，是我 C 方向"机制/现象分析"最想要的那类工作（而非 prompt 技巧）。
- **核心方法**：在四类任务（事实检索、并行数值组合、字符串操作、上下文内计算）上对两个开源前沿模型（DeepSeek V3、Kimi K2）做机制分析：注意力把问题经 filler 区路由到答案、logit-lens 显示事实早层浮现晚层组合结晶、KV-cache 在 filler 位的移植能因果地在样本间交换输出；再训练一个**只吃隐藏态、无标签、无训练**的无监督解码管线。
- **主要结果**：无监督管线在两模型 × 四任务上以 **80–95% 准确率**（最佳 LLM judge）恢复中间计算值；击败行为级 CoT 监控的隐藏计算，在这些任务上可直接从残差流读出。
- **值得追问 / 局限**：① 任务均为结构化、可枚举中间值的合成家族，能否推广到真实开放式推理未知；② "可从残差流读出"依赖 logit-lens / LLM judge 这套探针，探针本身的可靠性与是否引入解读偏差需要独立校验。

## 5. Stacked LoRA for Subject-Adaptive EEG Foundation Models in Motor Imagery Decoding
**方向 B（脑功能时序 / neuroimaging，fNIRS 邻域）** · arXiv: https://arxiv.org/abs/2607.03094
- **作者**：Aymen Sarhane, Fouad Lbakali, Mouad Souissi, Jonathan Lys, Giulia Lioi ｜ cs.LG
- **TL;DR**：面向 EEG 脑机接口的跨被试泛化难题，提出把每层低秩更新拆成"全局 adapter（跨被试共训）+ 被试专属 adapter"的 Stacked LoRA，从结构上解耦被试不变知识与个体神经签名。
- **解决什么问题 / 为什么重要**：EEG 强被试间变异使实用系统仍靠 from-scratch + 逐人校准；EEG 基础模型（REVE / LaBraM / LUNA）也不能直接当固定特征器。虽是 EEG 而非 fNIRS，但**"脑时序基础模型 + 个体自适应"的问题结构与我 fNIRS 方向高度同构**，其解耦范式可直接借鉴。
- **核心方法**：在 REVE/LaBraM/LUNA 之上比较三种低秩自适应——(i) 被试专属 LoRA、(ii) 全局 LoRA、(iii) Stacked LoRA（全局 + 被试专属叠加）；后者让每层更新 = Global adapter（联合训练）⊕ Subject-Specific adapter（吸收个体变异）。
- **主要结果**：在 BCI Competition IV-2a、PhysioNet Motor Imagery、临床 Zuo2025 三个基准上，Stacked LoRA 在多数 backbone×数据集组合上取得最佳精度；分析显示全局/被试路径的最优配比取决于目标人群——大而多样的队列共享 adapter 足矣，高跨 session 变异的临床数据则被试专属自适应更关键。
- **值得追问 / 局限**：① 仅运动想象分类一类范式，跨任务（如静息态、情绪、fNIRS 血氧信号）是否成立未验证；② "全局 vs 被试专属"配比随人群变化，缺自动选配机制，落地仍需人工调。

## 6. Diagnosis-Driven Automatic Repair for Agentic Workflow via Symbolic Inference (FlowFixer)
**方向 B（根因分析 / 故障定位）× C（agent 机制）** · arXiv: https://arxiv.org/abs/2607.02882
- **作者**：Xuyan Ma, Yawen Wang, Junjie Wang, Xiaofei Xie, Boyu Wu, Mingyang Li, Dandan Wang, Qing Wang ｜ cs.SE
- **TL;DR**：现有 agentic workflow 修复只靠轨迹级反馈、不显式定位根因，修补往往不对症；FlowFixer 把执行转成统一符号轨迹、做符号推理导出可执行行为规约，据此做失败归因 + 根因分析，再生成针对性补丁。
- **解决什么问题 / 为什么重要**：平台编排的 agentic workflow（Dify/Coze/n8n）可靠性差，根因藏在节点依赖与工具交互里。这篇把**根因分析/故障定位**（我 B 方向的显式关键词）落到 agent 系统上，方法是符号规约验证而非 prompt 兜底——同时命中 B（RCA）与 C（agent 机制而非 prompt 工程）。
- **核心方法**：将 workflow 执行转为统一符号轨迹 → 符号推理导出捕获节点正确性、时序依赖、因果关系的可执行行为规约 → 基于规约验证做失败归因与 root cause analysis → 生成定向修复补丁；并用多维预执行评估在动态验证前过滤不可行修复以降成本。
- **主要结果**：在 Dify、Coze、n8n 三平台收集的 workflow 失败上，修复成功率 **71.3%**，超 SOTA 基线 11.9%–27.6%；失败归因准确率提升 4.8%–33.1%，根因分析准确率提升 15.3%–38.8%。
- **值得追问 / 局限**：① 符号规约的导出质量依赖对节点/工具语义的建模覆盖，面对高度非确定的 LLM 节点，符号抽象的保真度是隐含瓶颈；② 评测集为三平台收集的失败样本，规模与代表性、以及对"未见工具/新平台"的泛化未充分交代。
