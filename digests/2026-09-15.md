## A. 核心方法（时序图/CTDG · 图结构学习异常 · 内生自解释）

### 1. From Explanations to Interventions: Execution-Guided Counterfactual Synthesis in Temporal Graphs
- 链接：https://arxiv.org/abs/2609.11170
- 作者：Minwoo Yu, Young-guk Ha（2 位作者）
- **TL;DR**：把"解释模型为何这样预测"的可执行推理迹（executable reasoning trace）直接复用为"要改成指定的另一个预测，需要在过去事件上做哪些编辑"的干预合成表征，在连续时间动态图（CTDG）与时序知识图（TKG）上都跑通。
- **解决什么问题 / 为什么重要**：动态图预测器多为黑盒，"解释"和"反事实干预"通常是两套机制。本文命中核心方向里的动态图 / CTDG，同时把内生自解释推进一步——解释迹不只是事后归因，而是能被复用来构造并验证"指定目标（specified foil）"的可执行计算表征，理论上更接近因果可操作性。
- **核心方法**：提出 trace-guided intervention search——从原始执行迹与目标 foil 执行迹中构造事实与替换值，并恢复"未满足的条件"；提案生成在固定预算内构造候选编辑，再用精确重放（exact replay）验证编辑后是否让冻结的时序预测器把 foil 顶到 top-1。分别在 CTDG（LiFTER）与 TKG（TLogic）上实现。
- **主要结果**：相对基于坐标的提案生成，成功率在 4 个 CTDG 数据集上提升 13.7–34.7 个百分点、2 个 TKG 数据集上提升 60.0–83.3 个百分点（提案上限 32）；在共享候选对比下，保留黑盒贪心 85.7–93.6% 的 CTDG 成功率，却少用 75.0–80.0% 的预测器调用；一个 Pulse 案例中 6 个干预有 5 个通过仿真级存活验证。
- **值得追问 / 局限**：① 方法依赖预测器本身能产出"可执行推理迹"（LiFTER/TLogic 这类结构），对不具备可执行迹的主流 CTDG 网络（如 TGN/TGAT 端到端嵌入）能否迁移存疑；② "指定 foil 的 top-1 反转"是否等价于业务上有意义的干预，仍需领域语义校验。

### 2. GSLAD: Prototype-Regularized Graph Structure Learning for Multivariate Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2609.15483
- 作者：Zepeng Zhang, Fuad Khuri, Keivan Faghih Niresi, Olga Fink（EPFL Olga Fink 组，IMOS 实验室）
- **TL;DR**：针对"工业故障常常先改变变量间结构关系、而单条轨迹仍看似正常"的弱信号问题，用图结构学习 + 结构原型正则，把"与正常结构原型的偏离"作为异常打分主信号。
- **解决什么问题 / 为什么重要**：主流多变量时序异常检测（预测/重构/表征差异）对"结构先变、幅值未变"的早期故障不敏感。本文既属核心方向的（时空/关系）图方法，又落在应用方向 B 的时序异常检测，且用"结构原型 + 边级不确定性"引入自解释与可诊断性（原型 = 自解释横切）。
- **核心方法**：两阶段训练——先用"条件感知图学习器 + 基于图的预测器"在预测监督下优化，得到正常图；再把正常图聚类成多个结构原型（代表不同正常工况），用边级变异刻画结构不确定性；第二阶段用"与原型的偏离"正则化图学习器，鼓励稳定且工况特定的结构。推理时把不确定性归一化的结构偏离与预测偏离结合打分。
- **主要结果**：在 4 个工业基准上整体表现强，验证了"结构偏离"对异常检测与诊断的有效性（区分不同正常工况、定位是哪些变量间关系异常）。
- **值得追问 / 局限**：① 结构原型数目与聚类质量对结果影响多大、如何在无标签下选原型个数；② "结构先变"假设在传感器噪声大或工况漂移频繁的场景下，是否会把正常的工况切换误判为结构异常。

## B. 应用场景（AIOps 根因分析 · 时空图 GNN 交通）

### 3. TriCalRAG: A Three-Strategy, Retrieval-Augmented Benchmark for On-Premise LLM-Based Root Cause Analysis in AIOps
- 链接：https://arxiv.org/abs/2609.14762
- 作者：Rohit Patel, Susil Kumar Mohanty, Jeenal Chaudhary（3 位作者）
- **TL;DR**：面向 AIOps 根因分析（RCA），系统评测"本地单卡部署的开源权重 LLM + RAG"三种提示策略在真实日志数据集上的准确率与校准表现，并与经典 LSTM 日志异常检测器（DeepLog）对比。
- **解决什么问题 / 为什么重要**：云端 LLM 做 RCA 有隐私、延迟与按次计费成本，随生产日志规模劣化。本文正中应用方向 B 的监控告警 / 根因分析 / AIOps，给出一个可复现的本地化评测口径（vLLM + 单张 96GB 工作站 GPU），关注点从"纯准确率"转向"校准与部署可预测性"，对落地更有参考价值。
- **核心方法**：在 4 个公开真实日志集（BGL、HDFS、Thunderbird、OpenStack）上评测两个开源模型（Qwen2.5-14B、Mistral-Small），比较 zero-shot / few-shot / 基于标注事件历史的 RAG 三种策略；报告带 bootstrap 95% 置信区间（3 个随机种子）的 accuracy/precision/recall/F1，并记录吞吐与显存；含 batching 与 4-bit 量化消融。
- **主要结果**：RAG 相比 zero-shot 平均 F1 提升 0.10–0.27，更关键的是显著稳住模型校准——zero-shot 会让模型退化到"几乎把所有事件都判为异常"（某些数据集高达 100%），RAG 则让预测正类率贴近真实类别比例；Mistral-Small 宏平均 F1（0.644）高于 Qwen2.5-14B（0.560），但校准失败的配置更多（12 中 7 vs 5）、吞吐约为一半；batching 单卡吞吐提升 41×，4-bit 量化降低 20% 延迟且无可测准确率损失。
- **值得追问 / 局限**：① 这是分类式异常判定基准，离真正的"根因定位到具体组件/调用链"仍有距离，标题的 RCA 更偏"是否异常 + 事件检索"；② 结论建立在两个中小开源模型上，向更大模型或流式在线日志的外推、以及 RAG 检索库时效性对校准的影响待验证。

### 4. A Graph Neural Network Surrogate Model for Incident-Based Travel Time Prediction Under Limited Sensor Data
- 链接：https://arxiv.org/abs/2609.14678
- 作者：Abhilasha Saroj, Natalie Myers, Haoran Niu（3 位作者）
- **TL;DR**：用时空图卷积网络（STGCN）替代"每个事故场景都要跑一遍微观仿真"的昂贵流程，在仅有 129 个信号交叉口方向流量的稀疏观测下，预测千级路网的路线级旅行时间及事故传播影响。
- **解决什么问题 / 为什么重要**：局部事故会把拥堵传播到远处，逐场景微观仿真代价高。本文是核心方法（时空图 GNN）的一个结果导向应用（应用即收），且在"传感器稀疏、仅有交通机构常见数据"这一现实约束下做代理建模，对交通韧性筛查/事故管理/主动改路有实用价值。
- **核心方法**：把 129 个信号交叉口建成图节点，用 STGCN 联合建模空间依赖与时间演化，学习局部扰动如何在路网（1037 交叉口、1601 路段的 Nashville 仿真网）中传播；对比"仅 80 次无事故仿真"训练的基线与额外加入"360 个车道封闭场景（12 地点 × 3 时长）"的含事故模型。
- **主要结果**：基线相对 MAE 9.94%，含事故模型整体 9.67%、事故活跃期 6.45%、在完全未参与训练的 30 个事故地点为 13.62%；受扰路线上预测平均落在实测旅行时间 2.0 分钟内（仿真本身随机种子间波动约 7.4% / 1.3 分钟）；单 CPU 核推理约 53 ms，作为代理效率很高。
- **值得追问 / 局限**：① 训练与评测均基于仿真数据，向真实路网/真实事故日志的迁移（分布偏移、传感器缺失模式）尚未验证；② 图仅由信号交叉口构成，事故位置不在建图节点上时的定位精度与外推（withheld 地点 13.62% 明显高于活跃期 6.45%）说明泛化到新地点仍有差距。

## C. 机制 / 表征几何（高优先级，取 2 篇）

### 5. What Does an LLM Learn from Reinforcement Learning? A Mechanistic Interpretability Perspective with Fixed-SAE Track
- 链接：https://arxiv.org/abs/2609.15064
- 作者：Lingheng Du, Yiming Tang, Xufeng Duan, Dianbo Liu（含新加坡国立 Dianbo Liu 等）
- **TL;DR**：提出 Fixed-SAE Track——在"基座模型 + 所有 RL 检查点"汇集的激活上训练一个共享稀疏自编码器（SAE）并冻结全部特征方向，从而在同一坐标系里严格追踪 RL 到底改变了 LLM 的哪些内部特征、是否创造了全新特征。
- **解决什么问题 / 为什么重要**：RL 广泛用于提升 LLM 能力，但"RL 在表征层面给了模型什么"仍不清楚；标准 SAE 无法直接跨训练阶段追踪特征漂移。本文正中核心方向 C 的机制/现象分析 + 训练动态 + 残差流表征，给出一个可复用的"表征漂移测量框架"，并附一个"构造上已知特征"的合成基准来检验 RL 能否真的注入新特征。
- **核心方法**：每层训练一个在基座与全部 RL 检查点激活上共享的 SAE，冻结所有特征方向，使表征变化被严格定义为可解释 SAE latent 的激活变化（含新特征的检测）；在多数据集、多 RL 算法上验证，并做特征 steering 实验与合成基准对照。
- **主要结果**：RL 引起的漂移小、渐进、概念特定且集中在后层，主要提升一小撮"阶梯 token"（步骤分隔、答案定界符等格式脚手架）的采样率，而非重塑问题内容；把这些特征 steering 进基座模型可恢复约 80% 的 RL 性能增益——提示 RL 主要是**唤起模型已有能力**，而非注入全新能力，与 steering 效果相当。
- **值得追问 / 局限**：① "约 80% 增益可由 steering 少数格式特征恢复"是否强依赖于所测任务类型（数学/推理格式化收益大）、对开放式生成或工具使用型 RL 是否成立；② 冻结 SAE 方向便于对齐坐标，但也可能低估"真正的新方向"，合成基准的构造性结论向真实 RL 的外推需谨慎。

### 6. Disentangling Representation Evolution in Transformers through Directional Decomposition
- 链接：https://arxiv.org/abs/2609.15975
- 作者：Shwai He, Haichao Zhang, Shen Yan（Findings of EMNLP 2026；代码开源）
- **TL;DR**：把 Transformer 每层的加性更新分解为"与当前表征方向平行"和"垂直（重定向）"两部分，作为一种功能几何来研究表征演化，并据此改进编辑鲁棒性、压缩诊断与预训练干预。
- **解决什么问题 / 为什么重要**：残差流里表征通过学到的加性变换要么保持方向、要么改变方向，但这两种成分此前少被显式区分。本文命中核心方向 C 的残差流结构 / 表征几何，把"表征几何"与三件实用的事——编辑鲁棒性、压缩误差诊断、训练时干预——连起来，是较扎实的机制分析。
- **核心方法**：在两个空间上做平行/垂直分解——注意力与 MLP 更新相对隐藏态，以及注意力 value 聚合相对当前 token 的 value；发现预训练模型里存在超出残差恒等路径的可观平行成分。做定向编辑实验，并在从零预训练中做"全聚合平行抑制"干预。
- **主要结果**：① 编辑存在强烈的空间依赖非对称性——在 value 空间对"排除自身"的平行成分做操控，比残差空间和垂直成分都更鲁棒（保留直接自我消息、只缩放非自身聚合）；② 垂直误差比平行误差更能区分不同压缩方法，可作压缩诊断；③ 从零预训练中做全聚合平行抑制能降低验证损失轨迹、提升下游平均，value 空间变体最强。
- **值得追问 / 局限**：① 结论主要在标准预训练 Transformer 上得出，向更大规模 / 不同架构（如 MoE、SSM 混合）的普适性待验证；② "平行抑制改善预训练"给出的是经验趋势，其为何有效、与优化器/正则的相互作用仍缺乏理论解释。
