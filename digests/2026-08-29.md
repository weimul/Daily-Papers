## 1. TraceBench: Controlled Evaluation of LLM Agents for Time-Series Root-Cause Attribution
- 链接：https://arxiv.org/abs/2608.27182
- 作者：Tommaso Bendinelli, Artur Dox, Christian Holz
- 方向：B 监控告警 / 根因分析；兼 C Agent 评测
- **TL;DR**：用可控物理动力学仿真造根因归因任务，系统评测 LLM agent 到底会不会"看时序数据找根因"。
- **解决什么问题 / 为什么重要**：LLM agent 越来越多被塞进异常检测和根因分析（RCA）流水线，但几乎没人在受控条件下量化过它们真实能力。真实系统里根因不可知、混杂多，无法干净地做消融，这篇用仿真把"哪个系统参数被改动"变成有金标准的可控任务。
- **核心方法**：TraceBench 基于三个可解释机械系统仿真生成任务，agent 拿到时序观测后要判断是否有参数被改、改的是哪一个；在受控实验条件下评测四个 agent，并开放数据集、agent 轨迹与排行榜。
- **主要结果**：agent 明显依赖领域上下文；主要靠数值控制台输出而非可视化来探索数据；当被要求产出"把每个时序样本映射到根因标签的 Python 脚本"时，表现反而比直接给预测更差。
- **值得追问 / 局限**：任务来自理想化机械系统仿真，与真实运维（噪声、缺失、多变量耦合、告警风暴）差距大，结论能否迁移到真实 AIOps 场景需谨慎；"靠数值不靠可视化"的现象可能只是当前工具接口所致。

## 2. FaulT-Bench: Towards Benchmarking Network Troubleshooting LLM Agents under Unreliable User Tickets
- 链接：https://arxiv.org/abs/2608.27021
- 作者：Kuan-Hao Tseng, Niruth Bogahawatta, Yasod Ginige, Kunjan Patel, Kosta Dakic 等
- 方向：B 监控告警 / 根因分析 / AIOps；兼 C Agent 评测
- **TL;DR**：把"用户工单本身就不可靠"这个现实条件加进网络故障排查基准，暴露 agent 在"根本没故障却被要求找故障"时的系统性崩溃。
- **解决什么问题 / 为什么重要**：已有基准都假设"工单准确且确有故障"，而真实运维里工单常常措辞含糊、误报、张冠李戴。这篇专门测 agent 在假前提工单下会不会硬把良性状态"提升"成根因。
- **核心方法**：200 个跨 8 种网络拓扑的排查场景，涵盖真故障、误报、设备归因错误、根因判断错误；把 72 个假前提工单改写成 5 种"报告人人格"（置信度、可验证细节逐一变化）；用 Kathará 部署、NIKA 工具接口交互、LLM 裁判按结果/修复/推理质量打分；评测 SADE、ReAct、Claude Code 三个 agent。
- **主要结果**：三者在准确工单上近饱和、对误导也稳健，但一旦网络健康而工单错误就急剧退化，会一路探到把良性条件当根因；"工单怎么写"比"工单说什么"更关键——自信的错误报告几乎和准确报告一样好处理，而含糊欠描述的报告让性能骤降；三者失败模式与成本差异巨大（从过度诊断到直接不作答）。
- **值得追问 / 局限**：LLM 裁判评分本身的可靠性与偏差；仿真网络（Kathará）与生产网络在规模、遥测丰富度上的差距；"人格改写"是否覆盖了真实工单的噪声分布。

## 3. When Interference Graphs Evolve: Doubly Robust Estimation of Dynamic Peer Effects
- 链接：https://arxiv.org/abs/2608.27187
- 作者：Xiaojing Du
- 方向：A 动态图 / 时序图 + 因果推断
- **TL;DR**：在会随时间演化的交互图上估计同伴效应，提出把"处理前网络历史 / 动态同伴暴露 / 处理后网络变化"分离的双重稳健估计器。
- **解决什么问题 / 为什么重要**：图会演化时，同伴效应难估——网络历史、动态暴露、赋值后网络变化有不同的因果角色，混在一起就会有偏。对做动态图/时序图建模的人，这提供了一个"结果层面因果解释"的框架而非纯预测。
- **核心方法**：提出受控对比（controlled contrast）框架，用"自身处理、时序聚合的同伴暴露、赋值后演化摘要"索引潜在结果，定义自身处理/同伴暴露/受控网络演化/联合对比；DynaNet-DR 估计器结合时序分解的倾向性与归一化增广，在结果回归或倾向性任一正确时保持一致性。
- **主要结果**：在固定真实时序图序列上的半合成基准里，相对针对"完整画像"的方法有更优的估计精度；并以 MathOverflow 做观测性示例。
- **值得追问 / 局限**：一致性依赖一系列强假设（序贯可交换性、正性、弱依赖等），现实网络未必满足；基准评的是"摘要索引对比"而非反事实边生成，外推到真正的干预式动态图仍需验证。

## 4. Inductive Correlation Clustering with Graph Neural Networks
- 链接：https://arxiv.org/abs/2608.27153
- 作者：Francesco Paolo Nerini, Francesco Bonchi, Arijit Khan, André Panisson
- 方向：A 核心方法（GNN / 图聚类）
- **TL;DR**：用 GNN 把相关性聚类从"每个实例从头跑"的直推式变成能泛化到新图的归纳式，推理提速最多 5 个数量级。
- **解决什么问题 / 为什么重要**：相关性聚类（CC）不需预设簇数、天然契合图表示，但经典算法扩展性差且是直推的——换个实例就得从头解。把它做成归纳式，等于训练一次、后续图近乎即时求解，对大规模、流式图很有价值。
- **核心方法**：提出 Inductive Correlation Clustering，用 GNN 在训练时学习通用结构模式与节点特征，从而泛化到同分布的未见图；额外展示可作为图分类里的可学习池化层。
- **主要结果**：归纳设置下推理时间最多降低 5 个数量级，同时近似比保持在最优基线约 10% 以内；在标准直推 CC 基准上也有竞争力；作为池化层能增强 GNN 捕捉层次结构的能力。
- **值得追问 / 局限**：泛化以"同分布"为前提，分布漂移下（真实网络常见）表现如何未知；近似比 10% 的差距在对聚类质量敏感的场景是否可接受需按应用判断。

## 5. Feature Transformation Enhanced Jacobi Polynomial Graph Filtering for Graph Anomaly Detection (JPGFN)
- 链接：https://arxiv.org/abs/2608.27144
- 作者：Xiang Wang, Zhijun Cheng, Zhenyu Meng
- 方向：A 图方法 × B 异常检测（交叉）
- **TL;DR**：用自适应 Jacobi 多项式图滤波 + 特征分离变换 + 节点标签约束，改进频域图异常检测。
- **解决什么问题 / 为什么重要**：频域滤波做图异常检测（GAD）近年效果不错，但静态基函数难适配图数据频域分布、忽视节点特征各维重要性、对标签利用不足。对做"图 × 异常"（监控告警可迁移）的人是一个直接可用的方法改进。
- **核心方法**：特征分离变换网络（FSTNN）对不同维度做非线性变换以学细粒度特征；基于 Jacobi 多项式的自适应图滤波模块捕捉复杂频域特征；节点标签约束模块加强标签利用。
- **主要结果**：在多个真实数据集上显著优于主流方法。
- **值得追问 / 局限**：摘要未给具体数据集/指标，"显著优于"的幅度与设置需看正文；半监督用标签的设定在标签稀缺的异常检测里可用性有限。

## 6. Circuit Condensation: Post-Training that Concentrates a Behavior's Causal Circuit
- 链接：https://arxiv.org/abs/2608.27254
- 作者：Sai Adith Senthil Kumar
- 方向：C Agent / 机制可解释性（优先类：机制/现象分析）
- **TL;DR**：不满足于"发现"庞大电路，而是后训练模型，把某个行为的因果电路"凝缩"成更小、可检验的子图。
- **解决什么问题 / 为什么重要**：机制可解释性用"电路"解释行为，但冻结发现常返回数百条边，难以逐一检查、比较、验证。把电路变小且仍保真，对内生/自解释与机制分析都是关键一步。
- **核心方法**：Circuit Condensation 每轮剪掉低归因边并训练低秩适配器（LoRA）去匹配原模型经剩余边的输出，只有当任务性能与通用能力都存活才保留该剪枝；对比"只搜索不更新权重"以确认是权重更新在驱动缩减。
- **主要结果**：4 种行为 × 8 个模型里，凝缩电路在 32 组中的 30 组比最强冻结基线更小，平均 8.1×、最高 316×；不更新权重会在 29/32 组得到更大电路；在 IOI 任务上凝缩出 24 个头（17 个有文献记载），对比匹配冻结电路的 61 个头（36 个无记载），且能追踪原模型下一 token 分布并预测其错误。
- **值得追问 / 局限**：凝缩得到的是"充分子电路"而非对已发表机制的重构，是否遗漏了对分布外行为重要的边需谨慎；后训练会改动权重，"被解释的模型"已不完全是原模型，解释对象需明确界定。
