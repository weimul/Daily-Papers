## A. 核心方法

### 1. NOAH: Learning the Full Patient Journey. A Longitudinal Multimodal Time-Aware Model for Representation and Forecasting
- 链接：https://arxiv.org/abs/2609.09140
- 作者：Tobias Susetzky, Raphael Rehms, Dmitrii Seletkov, Özgün Turgut, Michelle Espranita Liman 等（含 MIMIC 数据族背景）
- **TL;DR**：一个时间感知、任务无关的生成式 Transformer，用连续时间与变分潜空间对多模态病历"全生命周期轨迹"做统一表征与预测。
- **解决什么问题 / 为什么重要**：真实病历是纵向、多模态、且不规则采样的，现有模型多为判别式、模态少、把时间当作单调归纳偏置，难以刻画临床轨迹的连续演化与随机性。这正是"不规则采样时间序列 + 连续时间建模"方向的一个大规模落地样本。
- **核心方法**：提出双向时间整合（bidirectional time integration）与变分潜空间来捕捉状态连续演化与随机性；原生处理影像、时序/数值信号、类别事件、结构化与非结构化记录；支持带可选时间控制的自回归预测、零样本分类与反事实干预模拟。
- **主要结果**：基于 MIMIC 数据族 29.9 万患者、43.1 万次就诊、超 5.59 亿临床事件训练；在临床结局探针、15 个 ICD 章节、29 种共病及 time-to-event 预测上表现强劲。
- **值得追问 / 局限**：① "双向时间整合"具体如何编码不规则间隔、与 Neural/latent ODE 类连续时间方法的取舍如何？② 训练与评测均在 MIMIC 系内，跨机构/跨人群的外推与分布漂移稳健性仍待验证。

### 2. HOPE: Heterophily-Aware Open-Set Node Classification with Pseudo-Extrapolation
- 链接：https://arxiv.org/abs/2609.08685
- 作者：Yumeng Dai, Yue Tan, Yixin Liu, Chenxu Wang, Pinghui Wang, Tao Qin
- **TL;DR**：把开集节点分类从"同配假设"松绑到异配图，用可信邻域聚合 + 异配引导的伪外推来更可靠地拒识未知类。
- **解决什么问题 / 为什么重要**：现实图常是异配的（相连节点未必同类），跨类连边会让聚合后的表征互相纠缠、使阈值法与跨类插值失效，导致未知类拒识不可靠。对图方法在开放世界下的鲁棒性很关键。
- **核心方法**：结构增强的特征初始化层捕捉多跳结构；可信邻域聚合动态过滤噪声跨类邻居；异配引导的伪外推沿跨类邻域位移方向合成"伪未知"代理，配合分类 + logit margin 正则，把合成代理路由到专门的拒识槽位，而不在表征空间强加几何间隔约束。
- **主要结果**：多数据集上一致优于 SOTA，作者称在有效性、鲁棒性与效率上均有优势。
- **值得追问 / 局限**：① 伪外推方向依赖对"跨类位移"的估计，异配程度极高或结构噪声大时代理质量如何？② 拒识槽位阈值/占比对未知类比例是否敏感，跨数据集是否需重调。

### 3. Chimaera: A Mixture-of-Graph-Experts Architecture for Cross-Task and Cross-Dataset Graph Learning
- 链接：https://arxiv.org/abs/2609.08709
- 作者：Jonathan Frank, David Richerby, Ansgar Scherp
- **TL;DR**：把 MoE 与图基础模型（GFM）结合，混合图提示、线性 GNN 等多种专家，做跨任务/跨数据集的图学习。
- **解决什么问题 / 为什么重要**：图基础模型受困于图结构不规则、嵌入尺寸与特性各异；本文尝试用专家混合统一多架构、多来源嵌入，并把线性 GNN 扩展到链接级与图级任务。对"通用图模型"路线有参考价值。
- **核心方法**：用 LLM 生成嵌入，专家按不同策略/GFM/嵌入训练并组合；扩展线性 GNN 以支持 node/link/graph 三级任务；在 6 个文本属性图数据集上做同任务与跨任务实验。
- **主要结果**：验证了跨任务/跨数据集迁移能力；发现需同时用大、小语言模型生成嵌入，简单线性 GNN 具有强跨任务迁移性，且少样本即可取得不错结果。
- **值得追问 / 局限**：① 仅在文本属性图上验证，非文本/大规模工业图的可迁移性未知；② "线性 GNN 足够强"的结论在更复杂结构任务上是否依然成立值得追问。

## B. 应用场景（fNIRS / 神经影像 / 监控告警）

### 4. An Evidence-Aware Framework for EEG Microstate Analysis: Improved Sensitivity to Alzheimer's Disease and Ageing
- 链接：https://arxiv.org/abs/2609.08500
- 作者：Kaidong Wu, Haili Ye, Ptolemaios G. Sarrigiannis, Daniel J. Blackburn, Fei He
- **TL;DR**：不再把每个头皮拓扑硬分到单一微状态，而是保留对所有模板的"证据轨迹"，从而更灵敏地刻画脑状态动态、提升对阿尔茨海默与衰老的区分度。
- **解决什么问题 / 为什么重要**：传统 EEG 微状态用 winner-take-all 硬标签汇总，丢弃了证据强度、指派模糊性与低置信期。对脑网络/神经影像时间序列这类与 fNIRS 相邻的方向，"软证据"表示方法很有借鉴意义。
- **核心方法**：在每个全局场功率（GFP）峰点保留对所有模板/被试特异拓扑社区的证据，硬标签视为该多元轨迹的压缩读出；由此导出两类证据感知描述子——高证据片段时长与片段率（刻画强证据的时间聚集/碎片化）、以及编码"证据不足期"的 null-state Lempel-Ziv 复杂度。
- **主要结果**：在 4 个静息态 EEG 数据集（覆盖 AD 与年龄变化）、K-means/AAHC/HMM（K=4,7）及自适应 Leiden/Infomap 社区共 32 个"数据集×模型"设置中，轨迹派生的时长效应几乎全面超过硬标签；null-state LZC 多数情形优于传统 LZC，分类也有稳定小幅增益。
- **值得追问 / 局限**：① 该"证据轨迹"框架能否直接迁移到 fNIRS 的血氧动力学信号（采样率、噪声结构差异）？② 增益多为"小幅但一致"，在个体级诊断上的临床可用性仍需前瞻性验证。

## C. Agent / 机制与表征

### 5. LLM Layers Immediately Correct Each Other
- 链接：https://arxiv.org/abs/2609.07876
- 作者：Arjun Patrawala, Jiahai Feng, Erik Jones, Jacob Steinhardt
- **TL;DR**：发现相邻 Transformer 层会系统性地相互抵消对方的部分贡献（TLCM），提出"提议-否决"框架重新理解残差流。
- **解决什么问题 / 为什么重要**：主流可解释性（如 SAE）默认残差流中的特征会被后续层持续沿用；本文挑战这一假设，指出层间存在即时纠错机制，直接影响我们如何解读残差流、做特征归因与模型引导。属于"残差流/机制分析"的高优先级 Agent/机制类工作。
- **核心方法**：识别 Transformer Layer Correction Mechanism（TLCM）——相邻层系统性抵消彼此贡献；用层 Jacobian 证明它选择性纠正某些子空间、强化另一些；提出"propose-and-reject"框架：某层提议候选特征、后续层剔除不合适者。
- **主要结果**：TLCM 出现在 7 个主流开源模型族中的 5 个、在多样文本中几乎所有 token 上激活；在预训练中涌现，对上下文依赖 token 作用最强，并根据前层输出自适应调节纠正强度。该机制可解释为何 SAE 特征描述常缺乏特异性、有效引导需极端放大特征、以及 transcoder 相对 SAE 的理论优势。
- **值得追问 / 局限**：① "提议-否决"是否可用于设计更忠实的解释/引导方法（如只在"持久特征"上做 steering）？② 未出现 TLCM 的 2 个模型族差异根源为何，是否与归一化/宽度有关。

### 6. Global Divergence, Local Convergence: Representation Geometry in SSMs and Transformers
- 链接：https://arxiv.org/abs/2609.08692
- 作者：Amit Ben-Artzy, Roy Schwartz
- **TL;DR**：多尺度分析表明 SSM（如 Mamba）与 Transformer 在全局表征几何上分化明显，却在局部语义流形上高度对齐、功能趋同。
- **解决什么问题 / 为什么重要**：SSM 与 Transformer 架构迥异却性能相当，其内部表征几何/功能本质的异同此前不清楚。对理解不同序列架构的表征几何（neural collapse / 主方向支配等现象）很有价值。
- **核心方法**：对 Transformer、SSM 与混合架构做多尺度表征分析：主方向/维度分布、通过可压缩性度量有效容量、用秩约束探针看概念编码维度、并比较流形对齐（特定主题表征、token 最近邻）。
- **主要结果**：SSM 把表征信息较均匀地分布到各维，Transformer 表征则被单一主方向主导，且混合架构中每过一层注意力就更偏向单一主方向；但两者有效容量高度接近、概念子空间维度相近，且局部语义流形高度对齐——即"全局分化、局部收敛"。Transformer 的主方向并不天然编码更多概念信息。
- **值得追问 / 局限**：① "局部收敛"是否意味着两类架构在下游可解释性方法上可互通？② 结论主要基于探针与几何度量，对更大模型与更复杂任务的普适性仍需验证。
