## A. 核心方法 · 内生 / 自解释可解释性

### 1. The Standard Interpretable Model: A general theory of interpretable machine learning to deductively design interpretable methods using Lagrangian mechanics
- 链接：https://arxiv.org/abs/2606.12289
- 作者（前几位）：Pietro Barbiero, Giovanni De Felice, Mateo Espinosa Zarlenga, Francesco Giannini, Filippo Bonchi, Mateja Jamnik, Giuseppe Marra 等
- **TL;DR**：用拉格朗日力学的思路给"可解释性"立一个一般理论框架（SIM），让可解释方法可以从前提**演绎地**设计出来，而不是各做各的。
- **解决什么问题 / 为什么重要**：当前可解释性领域缺乏统一理论，方法碎片化、评测口径不一致。对你关注的"内生 / 自解释"路线而言，一个能把"对某类用户而言什么算可解释"形式化、并据此推导约束的框架，正好是把 self-explaining 从经验设计推向有原则设计的尝试。
- **核心方法**：把"对目标用户而言的可解释性"写成一组前提，从中推导出可解释性的对称性与对应约束，构造一个拉格朗日量，其极小值对应最优可解释模型；达到极小值有两条路——要么微调一个黑箱模型让它更可解释，要么把约束直接"编译"进一个可解释架构。
- **主要结果**：论文称 SIM 能统一识别并求解一类现有可解释方法（把它们看作该拉格朗日量在不同前提下的特例），并给出实证示例。
- **值得追问 / 局限**：① "前提 → 对称性 → 约束"的映射在多大程度上是唯一且可操作的，会不会换一组前提就推出完全不同的方法？② 把约束"编译进架构"相对直接微调黑箱，二者在保真度 vs. 性能上的取舍如何，是否能落到时序图 / 时序模型这类结构化场景。

## B. 应用场景 · fNIRS / 脑功能 与 监控告警异常检测

### 2. APEX: A Network-Native Time-Series Foundation Model for Forecasting and Anomaly Detection for Wireless Edge Operations
- 链接：https://arxiv.org/abs/2606.11553
- 作者（前几位）：Swadhin Pradhan, Niloo Bahadori, Peiman Amini
- **TL;DR**：面向无线网络遥测的"原生"时序基础模型，同时做预测和异常检测，把通用时序基础模型在网络数据上"水土不服"的问题对症处理。
- **解决什么问题 / 为什么重要**：通用时序基础模型在网络遥测（突发、零膨胀、跨协议层耦合）上迁移效果差。这正是 AIOps / 监控告警的典型痛点：预测 + 异常检测一体、还要能在边缘低延迟跑。
- **核心方法**：decoder-only Transformer，在约 4,500 个生产无线网络、约 10 万条 AP 时序、34 个指标上预训练（10 通道多变量遥测）；给出云端 APEX-Large（269M）与边缘 APEX-Edge（10.5M）两档。
- **主要结果**：在 192 步（4 天）DHCP 退化基准上，APEX-Large 相比最强基础模型基线（Toto）MAE 降低 18%、相比 SARIMA 降低 38%，异常检测 F1 = 0.93；APEX-Edge 可在 AP 级边缘硬件做亚秒、隐私保护推理。
- **值得追问 / 局限**：① 评测主要围绕 DHCP 退化这一代表性任务，对更广的根因定位 / 多故障类型泛化如何未充分展开；② "network-native 预训练"的增益里有多少来自数据规模、多少来自架构，缺乏消融时不易区分。

### 3. End-to-End Machine Learning for Depressive State Classification via EEG and fNIRS
- 链接：https://arxiv.org/abs/2606.11555
- 作者（前几位）：Riki Sakurai, Simon Kojima, Mihoko Otake-Matsuura, Shin'ichiro Kanoh, Tomasz M. Rutkowski
- **TL;DR**：用 EEG + fNIRS 双模态生物信号做抑郁状态的端到端分类，搭一个面向客观抑郁检测的框架雏形。
- **解决什么问题 / 为什么重要**：传统精神科诊断依赖临床访谈和自评，主观偏差大；EEG / fNIRS 作为客观替代尤其适合识别被试自己都未察觉的"潜在抑郁"，在老龄人群中对抑郁 / 痴呆共病的早期区分也有价值。直接命中你 B 方向里的 fNIRS / 脑功能近红外。
- **核心方法**：以 EEG 与 fNIRS 信号为输入做端到端机器学习分类，建立"生物信号 → 抑郁状态"的检测流水线（pilot 框架）。
- **主要结果**：在 11 名健康学生的 pilot 数据上建立并验证了该框架，作为后续自动化客观诊断工具的基础一步。
- **值得追问 / 局限**：① 样本极小（n=11）且为健康学生，标签是"诱导 / 状态"层面而非临床确诊，外推到真实患者要非常谨慎；② EEG 与 fNIRS 如何融合、各贡献多少，论文摘要层面尚未交代——这恰是你做多模态脑信号时最该追的点。

### 4. Flow Matching with In-Context Priors for Out-of-Distribution Brain Dynamics
- 链接：https://arxiv.org/abs/2606.11833
- 作者（前几位）：Sam Gijsen, Michał Łukomski, Marc-André Schulz, Kerstin Ritter
- **TL;DR**：用带 in-context 先验的 flow matching / 扩散 Transformer 生成"没见过的认知任务"下的 fMRI 脑动力学，支持组合式、零样本泛化。
- **解决什么问题 / 为什么重要**：神经时序的生成模型多停留在"类别条件"，无法组合泛化；本文让模型从语言描述（+可选空间先验）零样本生成新任务下的脑活动，指向"反事实神经科学"——在真正做实验前先在硅上设计 / 评估新认知实验。对脑网络 / 神经成像时序方向很有想象空间。
- **核心方法**：per-timestep 条件化的扩散 Transformer，把组合式语言条件与可选空间先验都以 in-context 方式注入，逐时间步生成 fMRI 动力学。
- **主要结果**：在数百个 held-out 任务条件上评测：仅凭语言就能恢复任务相关的区域募集与 held-out 的空间激活模式；加入空间先验可进一步"锚定"生成。并刻画了预测性能与训练流形的关系。
- **值得追问 / 局限**：① "零样本恢复区域募集"在多大程度上是真泛化、而非训练任务分布的插值（论文也提到与训练流形的关系，值得细看）；② 生成的脑动力学如何做生理可信度 / 下游可用性的验证，仍待更强的外部校验。

## C. Agent · 机制 / 训练动态 与 记忆

### 5. Phase Transitions in Attention: A Bayesian Theory of Copy Head Emergence
- 链接：https://arxiv.org/abs/2606.12058
- 作者（前几位）：Itay Lavie, Kirsten Fischer, Andrey Lekov, Frederic Van Maele, Zohar Ringel, Moritz Helias
- **TL;DR**：用贝叶斯特征学习理论解释 induction head 里 copy 子电路为何在训练中"突然"出现——把它刻画成随训练数据量发生的一阶相变。
- **解决什么问题 / 为什么重要**：注意力模式在训练中常被观察到"骤然涌现"，但缺乏第一性原理解释。这篇给出可解析的机制说明，正对你 C 方向偏好的"训练动态 / 机制与现象分析 / 表征几何"。
- **核心方法**：对单层 softmax 注意力在 copy 任务上的训练做贝叶斯特征学习分析，导出注意力矩阵的闭式后验，并约化到低维序参量空间。
- **主要结果**：约化揭示出随训练数据量的相变，并用贝叶斯采样与标准 Adam 训练双重验证；对比发现 softmax 注意力是**一阶相变**，而线性注意力是先二阶相变、再平滑连续演化（crossover）。给出 copy 子电路骤然涌现的首个第一性原理解释。
- **值得追问 / 局限**：① 结论建立在单层、copy 任务的简化设定上，能否外推到多层真实 LLM 里 induction head 的涌现仍需检验；② "一阶 vs 二阶相变"的区分对实际训练（学习率、优化器）有多稳健。

### 6. Organize then Retrieve: Hierarchical Memory Navigation for Efficient Agents
- 链接：https://arxiv.org/abs/2606.11680
- 作者（前几位）：Hao-Lun Hsu, Nikki Lijing Kuang, Boyi Liu, Zhewei Yao, Yuxiong He
- **TL;DR**：给 LLM agent 设计分层"文件系统式"工作记忆 HORMA——先组织、后检索，既不丢细节又能高效访问，缓解无状态导致的长程任务退化。
- **解决什么问题 / 为什么重要**：LLM agent 本质无状态，长程任务要把所有相关信息塞进越来越长的上下文，带来推理质量下降、成本与延迟上升。现有做法要么有损压缩、要么相似度检索，都难以捕捉时间结构与因果依赖。直接对应你 C 方向的"memory"机制重点。
- **核心方法**：HORMA 把经验组织成类文件系统的分层结构，摘要实体链接到对应原始轨迹；工作记忆拆成"结构化记忆构建"与"基于导航的检索"两阶段，构建模块通过区分"缺信息导致的失败"与"被误导导致的失败"来迭代优化组织方式。
- **主要结果**：摘要层面强调可在不丢失细节的前提下实现高效访问、改善多步 agent 任务（具体基准数值见原文）。
- **值得追问 / 局限**：① "组织 → 检索"两阶段的额外构建开销与它省下的上下文 / 延迟之间的净收益，需要看具体基准；② 分层结构对任务类型的依赖（强时序 / 强因果 vs 松散任务）可能差异很大。
