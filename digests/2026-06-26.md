## 1. $\text{DT}^2$: Decision-Targeted Digital Twins
- 链接：https://arxiv.org/abs/2606.25923
- 作者：Harry Amad, Mihaela van der Schaar
- 方向：A（动力学/世界模型建模 + 内生的"决策导向"训练目标）
- **TL;DR**：训练数字孪生（动力学模型）时，别再一味最小化"一步转移误差"——作者证明在模型容量受限时，这个目标对"给候选策略排序"是次优的；改成直接以"保持策略两两排序一致"为目标来训，策略选择的后悔显著下降。
- **解决什么 / 为什么重要**：数字孪生的用途是模拟不同策略、辅助决策，但常规训练只追求逐步仿真保真度，与"挑出更好的策略"这个真正目标错位。这正落在我关心的"动力学建模 + 内生/自对齐目标"这条线上——把下游用途写进损失，而不是先建一个通用动力学模型再事后用。
- **核心方法**：先用 fitted-Q-evaluation 从离线数据估计候选策略的价值，得到"代理真值"的两两排序；再用一个架构无关的损失训练孪生模型，使其 rollout 生成的轨迹保持这些排序，同时维持基本仿真保真度。
- **主要结果**：在多种设置与架构上，相比常规一步误差训练，一致提升策略排序质量、降低策略选择时的决策后悔；对训练中见过和未见过的策略都成立。
- **追问 / 局限**：(1) 排序目标依赖 FQE 给的"代理真值"，FQE 本身在分布外或高方差时是否会把错误排序固化进孪生？(2) 论文强调"容量受限时"才有此差距——容量充足、表达力强的世界模型上收益还剩多少，值得看消融。

## 2. Hierarchical Graph Learning for Calendar Spread Strategies in Commodity Futures Markets
- 链接：https://arxiv.org/abs/2606.25811
- 作者：Yoonsik Hong, Diego Klabjan
- 方向：A（层次图 + 到期日依赖的时序互联结构，graph + temporal）
- **TL;DR**：把商品期货建成两层图——上层标的资产、下层各到期合约，层内按相关性连边、跨层连"合约↔标的"边——用层次图学习预测价格走势，再把预测转成日历价差（同标的不同到期）的多空头寸做统计套利。
- **解决什么 / 为什么重要**：这批里最接近"时空/关系图建模"的一篇。它显式建模了**到期日依赖的合约间互联结构**（maturity-dependent interrelationships），本质是把一组随时间演化、按期限组织的节点关系学进图里，正对应我关注的"图 + 时序结构"这条主线，只是落在期货市场场景。
- **核心方法**：构造资产-合约两层异质图；先解析地论证日历价差策略相比纯多头能有更高信息比率、更低方差与 delta；再训练层次图模型预测价格走势，并给出"预测→价差头寸"的转换规则。
- **主要结果**：在 CME 商品期货上，预测与交易表现均优于基准模型；消融显示"到期日依赖的合约互联"对预测确实关键，基于层次图的价差交易对统计套利有效。
- **追问 / 局限**：(1) 图结构与相关性边大多是静态先验设定的，缺少"动态图/边随市场状态演化"的处理，换到 regime 切换时是否还稳？(2) 收益论证基于解析假设 + 单一交易所样本，交易成本、流动性、滑点等现实摩擦下的净收益未充分压力测试。

## 3. The Inference-Compute Frontier and a Latency-Efficient Architecture for Limit Order Book Prediction
- 链接：https://arxiv.org/abs/2606.25986
- 作者：C. Evans Hedges
- 方向：A（时间序列建模架构 + scaling-law/推理-算力前沿分析）
- **TL;DR**：在限价订单簿（LOB）预测上，作者发现"预测损失 vs 结构性前向计算量"竟服从幂律（留出 MLPLOB 族外推 $R^2=0.941$）；但同样的关系在**延迟**维度上明显变弱——说明延迟不等于带噪的算力——据此设计了一个硬件友好、低延迟的时序混合架构 FastBiNLOB。
- **解决什么 / 为什么重要**：把"scaling law / 推理-算力前沿"这套分析迁到高频时序预测上，是个有意思的机制视角；更关键的是它点出"算力前沿可外推、延迟前沿不可"，对所有**延迟敏感的时序系统**（高频、在线监控、流式）都有借鉴：堆算力换精度有规律，但换低延迟得靠架构设计而非单纯压缩计算。
- **核心方法**：在 FI-2010 上用从小决策树到神经 LOB 架构的一整套模型拟合"损失-前向计算量"幂律前沿；对比算力空间与延迟空间的拟合质量差距；据此提出 FastBiNLOB——一个稠密、轴可分的 LOB mixer，由硬件友好的时间混合与特征混合算子搭成。
- **主要结果**：算力空间幂律外推跨多个数量级、$R^2=0.941$；延迟空间拟合明显更弱。FastBiNLOB 在五个随机种子下，以**显著更低的延迟**超过已发表 SOTA 的 $y_{10}$ / $y_{100}$ macro-F1 目标。
- **追问 / 局限**：(1) 结论建立在 FI-2010 单一基准上，幂律前沿是否跨市场/跨标的可移植存疑。(2) "延迟≠带噪算力"是经验观察，缺少对延迟前沿为何不可外推的机制性解释（内存墙？算子并行度？）。

## 4. Enhancing Brain MRI Anomaly Detection and Reasoning with ROI Rethink and Synthetic Data
- 链接：https://arxiv.org/abs/2606.25894
- 作者：Shangkun Li, Jie Xu, Yi Guo, Zeju Li, Yuanyuan Wang
- 方向：B（脑影像异常检测）×（横切：内生/自解释——先定位再验证，而非单遍黑箱）
- **TL;DR**：医学多模态模型常一遍出诊断、不指出依据区域，既不可审计又会在正常片上幻觉。BrReMark 让模型**先提异常假设 → 用显式边界框标出 ROI 落地证据 → 再回看标记区域验证结论**，把"先定位后判别"的内生推理结构训进诊断流程。
- **解决什么 / 为什么重要**：这篇同时踩中我两条线——B 方向的异常检测（脑 MRI），以及横切重点的**内生/自解释**（用"假设-验证 + ROI 落地"的内建结构提供空间依据，而非事后 saliency 归因）。它把可解释性做成了流程的一部分（可审计、抑制幻觉），而不是黑箱外面再贴解释。
- **核心方法**：监督微调结构化推理轨迹 + 强化学习（复合奖励同时覆盖定位准确度与诊断推理）；并用基于域随机化的病灶合成增强提升对分布外罕见病灶的泛化。
- **主要结果**：内部基准上 mAP50 从 0.74% 提到 37.54%，Clinical F1 21.57%、诊断准确率 45.26%；在 NOVA 分布外基准上相比 SOTA 假阳性降低 45.7%，说明对罕见病灶的幻觉更少。
- **追问 / 局限**：(1) 绝对指标仍偏低（mAP50 ~37%、诊断准确率 ~45%），离临床可用还远，更适合当作"可解释性流程"的方法学验证。(2) 合成病灶增强会不会引入分布偏置、让模型对"合成式异常"过敏而对真实细微病灶钝化，需要真实 OOD 病例进一步验证。

## 5. Why Multi-Step Tool-Use Reinforcement Learning Collapses and How Supervisory Signals Fix It
- 链接：https://arxiv.org/abs/2606.26027
- 作者：Yupu Hao, Zhuoran Jin, Huanxuan Liao, Kang Liu, Jun Zhao
- 方向：C（agent —— 训练动态 / 失败机制分析，"优先"类）
- **TL;DR**：多步工具调用的 agentic RL 常出现"灾难性崩溃"——性能骤降、工具调用结构失效。作者把病因定位到**少数控制 token 上突然出现的概率尖峰**，扰乱了结构化执行；而底层工具使用能力其实没坏，只是被错乱的格式遮住了，并系统比较多种监督信号来稳住训练。
- **解决什么 / 为什么重要**：这正是我想要的"优先"类——不是又一个刷分 trick，而是**把 agent RL 的失败现象拆到 token 级机制**（控制 token 概率尖峰 → 结构崩塌，而非能力丧失）。对理解 agent 训练为何不稳、以及"崩溃可恢复"这一判断，有直接的诊断价值。
- **核心方法**：先做失败归因分析（定位控制 token 的概率尖峰）；再系统性地考察一组监督信号——off-policy 监督、提示式引导、错误样本监督等——在同步与交错（interleaved）两种训练调度下的效果，并分析学习率与跨设置泛化的影响。
- **主要结果**：把 SFT 与 RL **交错**进行能显著改善稳定性，但在格式 / 内容分布外评测下会有性能折损；不同监督信号对"引导探索式学习"作用不一。代码已开源（Tool-RL-Box）。
- **追问 / 局限**：(1) "交错 SFT-RL 提升稳定性但 OOD 变差"暴露稳定-泛化的权衡，怎么在不牺牲分布外鲁棒的前提下压住崩溃仍未解。(2) 机制解释停在"控制 token 概率尖峰"这一相关现象层面，尚缺为何这些 token 会被 RL 推到尖峰的更深因果。

## 6. Natural Ungrokking: Asymmetric Control of Which Rules Survive Pretraining
- 链接：https://arxiv.org/abs/2606.26050
- 作者：Juliana Li, Diya Sreedhar
- 方向：C（训练动态 / 现象分析，"优先"类——预注册的机制研究）
- **TL;DR**：一个小语言模型在预训练中途学会了"代词-性别"规则（给女名能正确解到 she，泛化到留出探针 0.94），但继续训到第 3500 步同一探针掉到接近零——尽管规则证据还在数据里。作者称这种**同一次训练内的反向遗忘为"自然反 grok"**，并发现一个语料统计量（规则在训练流里"获胜"的频率）就能预测哪些规则会被保留。
- **解决什么 / 为什么重要**：这是这批里方法学最扎实的一篇——**全部确认阈值与预测在读数据前已预注册**。它把"模型保留还是丢弃一条已学会的规则"还原成可测的语料统计（support frequency），且 loss 曲线上毫无痕迹；这种"训练动态 / 表征竞争"视角正是我看重的机制类工作，而非性能刷分。
- **核心方法**：在受控小模型上跟踪规则的"涌现-崩塌"动态；用 support frequency（规则在训练流中获胜的频率）预测其存亡，并在两个语料、三种预算、三个种子下验证；进一步在公开 Pythia checkpoint 上复现，崩塌深度按模型规模排序。机制上归因为"一个竞争性表层模式把规则挤掉"，两者对数概率边际在行为崩塌前后约 100 步内穿越零点。
- **主要结果**：support frequency 决定规则存亡，数据-参数比只调节"注定被丢的规则掉多深"；控制是**不对称的**——把 support 翻成反证可按剂量-反应稳定地"按需杀死"规则，但事后把 support 加回去（哪怕加到自然维持水平的 450 倍）也救不回来。
- **追问 / 局限**：(1) 实验在小模型 + 简单语言规则上做，结论能否外推到大模型的复杂能力（而非单条玩具规则）尚需验证。(2) "不可恢复的不对称性"很惊人，但其机制（为何挤占后无法重新占据表征容量）仍待更深的表征几何层面的解释。
