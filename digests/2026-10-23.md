### 1. Continuous-depth Deep Gaussian Processes
- 链接：https://arxiv.org/abs/2610.30890
- 作者：Ying Li, Sanyou Wu, Zi Yang, Qiaochu Xu, Yuhao Liu, Zhidi Lin（9 位；stat.ML）
- **TL;DR**：深度高斯过程（DGP）随层数增加越来越难优化；本文主张把"深度"从一长串离散层堆改成**潜表征沿深度的连续随机演化**——让状态服从一个带深度索引漂移族的 SDE，并给该漂移族加上**GP 先验**，从而把核心设计选择从"堆多少层神经网络"换成"给漂移族放什么先验"。
- **解决什么问题 / 为什么重要**：直接命中 A 的**连续时间 / 连续深度模型**主线，与你关注的 Neural ODE / latent ODE 同源但走了一条不同的路——它不采用"纯神经网络参数化的连续深度"（neural ODE/SDE 的做法），而是把连续演化的漂移本身放进贝叶斯 GP 先验里，这给"连续时间/连续深度 + 不确定性量化 + 结构先验"提供了一个新的组合点，对把不规则采样/连续时间建模与贝叶斯可解释性结合的方向有直接借鉴。
- **核心方法**：① 把 DGP 的潜表征写成一个 SDE，其漂移为**深度索引的漂移族 + GP 先验**（而非神经网络）；② 给出两个实例——**CDGP**：对"状态—深度"漂移直接放 GP 先验；**FlowDGP**：用流演化的先验，以更低训练成本捕获更丰富的深度依赖；③ 理论上分析单样本 DGP 目标在反复层复合下如何变得越来越敏感，指出残差 DGP 只是"有限离散"的初步修补，并给出连续深度形式的逐路径敏感性分析。
- **主要结果**：在合成、标准 benchmark、大规模回归任务上，残差 DGP 优于普通 DGP，而 CDGP / FlowDGP 在各区间给出更强的整体表现。
- **值得追问 / 局限**：① 优势以"across the regimes we study"这种整体叙述给出，缺少对每个数据集的具体指标与显著性，真实增益幅度要看正文；② "给漂移族放 GP 先验"的推断成本与可扩展性（相对纯神经 ODE/SDE）如何，尤其在高维/长深度极限下是否仍可训、先验选择对结果的敏感性，是落地最该追的点。

### 2. Visualizing and Interpreting Temporal Care Team Dynamics for Cancer Survival Risk Analysis
- 链接：https://arxiv.org/abs/2610.30748
- 作者：Yuhua Huang, Hsiao-Ying Lu, Kwan-Liu Ma（3 位；cs.LG）
- **TL;DR**：肿瘤诊疗是一个多专业人员长期协作、且协作关系随治疗阶段演化的过程；本文从电子病历（EHR）沟通数据构建**动态协作网络**，用**时序图神经网络（TGNN）** 随时间估计患者结局风险，再配代理逻辑回归做特征级解释与 what-if 探索，用于分析"协作结构变化如何与风险变化共同演化"。
- **解决什么问题 / 为什么重要**：同时命中 A 的**时序图 / 动态图学习**与你关注的**内生/自解释（横切重点）**，并落在一个真实的纵向医疗场景上。它把"随时间演化的图（这里是随诊疗阶段演化的护理团队网络）"显式建成 TGNN 时序风险模型，再用代理模型 + 可视化把时序图模型的决策变得可审视——这正是"动态图 + 可解释"的结合范式，对任何在演化网络上做风险/事件预测且需要向领域专家解释的人都有迁移价值。
- **核心方法**：① 从 EHR 的沟通数据构建随时间变化的护理团队协作网络；② 用 **TGNN** 随治疗阶段估计患者结局风险；③ 多视图交互系统：TGNN 风险建模 + 协作网络可视化 + **代理逻辑回归的特征级解释** + what-if 反事实探索；④ 在不作因果断言的前提下，考察团队构成/专科参与变化与风险估计漂移的关系。
- **主要结果**：在 505 位乳腺癌、结直肠癌、肺癌患者上做专家引导的分析场景，系统能揭示有临床意义的协作模式，并提升时序图模型在纵向、团队化医疗情境中的可解释性。
- **值得追问 / 局限**：① 可解释性依赖一个**代理（surrogate）逻辑回归**而非 TGNN 自身的内生机制，属于 post-hoc 近似，其对 TGNN 真实决策的忠实度存疑——这与你偏好的"内生/自解释"相比仍是外接解释；② 评估以"专家引导的场景 + 揭示有意义模式"为主，缺乏对风险预测本身的定量精度基线对比，模型的预测价值与解释价值需分开检验。

## B. 应用场景（免训练通用图异常检测 / BETH 上可解释且抗新型攻击的异常检测，取 2 篇）

### 3. One Pretrained Decision Model Is Enough for Training-Free Generalist Graph Anomaly Detection (Jev-GAD)
- 链接：https://arxiv.org/abs/2610.30777
- 作者：Xinyu Zhao, Qingyun Sun, Ziwei Zhang, Tianchen Zhu, Daqing Li, Jianxin Li（6 位；cs.LG）
- **TL;DR**：图异常检测（GAD）里异常模式异构、跨图分布差异大，免训练方法虽避免任务级优化但大多只靠预设数值打分规则、不碰"异构异常证据的语义解读"；Jev-GAD 把结构/属性/邻域三类互补证据转成**图相对异常百分位**，再交给**单个冻结的预训练语言模型**做证据条件化的异常判定，最后与四个统计分数做等权秩融合，全程无 GAD 专用梯度优化。
- **解决什么问题 / 为什么重要**：正中 B 的**异常检测**主线，同时命中 A 的**图学习**。它解决两个落地痛点：免训练方法只会"数值打分"没有语义、以及跨图泛化难；做法是把图证据**语义化成决策状态**喂给冻结 LLM 读 option-logit——这把"预训练决策模型 + 结构化证据"用于零训练通用异常检测，对需要跨不同图/网络快速部署异常检测（监控、风控）的场景有直接参考。
- **核心方法**：① 构建互补的**结构、属性、邻域**证据，并把异构统计量转成**图相对异常百分位**（跨图可比）；② 设计 **Graph-to-State（G2S）** 语义变换，把图上下文 + 语义标注的节点证据组织成结构化决策状态，供冻结 LLM 做**非生成式 option-logit 读出**；③ 判定分数与四个互补统计分数做**等权秩融合**，不做 GAD 专用梯度优化。
- **主要结果**：在覆盖引用网络、社交网络、共评网络的 7 个 GAD 基准上，平均 **AUROC 89.18% / AUPRC 52.40%**；消融验证了预训练决策读出与语义证据接地各自的贡献。
- **值得追问 / 局限**：① 把异常判定托付给"冻结 LLM 读 option-logit"，其判据实际依赖 LLM 对"异常"语义的先验，存在提示/表述敏感与难以审计的风险，摘要未报告对 G2S 措辞的稳健性；② AUPRC 仅 52.40% 说明在类极不平衡的真实异常场景下精确率-召回的权衡仍不理想，"免训练通用"相对针对性微调模型的代价边界需在正文核对。

### 4. Bridging the Closed-World Gap: Interpretable Anomaly Detection via a Hybrid TSK-FCM Ensemble on the BETH Dataset
- 链接：https://arxiv.org/abs/2610.30576
- 作者：Lohith Srikanth Pentapalli, Josette Riep, Justin Ouwerkerk, Kelly Cohen（4 位；cs.CR）
- **TL;DR**：安全场景里有监督模型对新型分布外（OoD）攻击泛化差、无监督模型可分性差致误报爆表；本文在 BETH 内核级基准（训练只含良性/可疑内部行为、测试几乎全是新型僵尸网络激活攻击）上，提出 **TSK 模糊分类器（懂已知内部威胁）+ 并行 FCM 模糊聚类（抓几何异常）** 的混合模糊集成，并发现模糊隶属度在高维下因维度灾难退化、用一个 **Min Distance 度量**利用僵尸网络攻击的几何孤立性来修复。
- **解决什么问题 / 为什么重要**：命中 B 的**监控/告警类异常检测**，同时命中你关注的**内生可解释（横切重点）**——它靠模糊逻辑（TSK 规则 + FCM）本身提供可读的决策依据，而非 post-hoc 归因，是"检测 + 内生透明"结合的典型。它针对的"闭世界训练、开世界测试"（训练见不到测试期的新型攻击）正是真实安全监控最难的设定。
- **核心方法**：① **TSK（Takagi-Sugeno-Kang）** 梯度优化模糊分类器，作为已知内部威胁的"专家"；② 并行 **FCM（Fuzzy C-Means）** 模块检测几何异常；③ 发现传统模糊隶属度在高维特征空间退化，引入 **Min Distance** 度量，利用僵尸网络激活攻击的原始几何孤立性；④ 整体以模糊逻辑保持内生可解释。
- **主要结果**：在 BETH 测试集上取得 **AUROC 0.9951**，比原始 Isolation Forest 基线高 **17.1%**，兼得接近完美的 OoD 检测与模糊逻辑的内生可解释性。
- **值得追问 / 局限**：① 结论高度绑定 BETH 这一个基准（且其测试几乎全是单一类型的僵尸网络激活攻击），"几何孤立"假设在更隐蔽、与正常行为重叠的攻击上是否还成立、能否迁移到其它监控数据集，存疑；② 0.9951 的近乎完美 AUROC 需警惕该基准任务本身的可分性偏易，以及阈值/评测协议对结论的影响。

### 5. Is Complex Agentic Memory Always Needed? Naive RAG Is Stronger Than We Thought
- 链接：https://arxiv.org/abs/2610.30755
- 作者：Zhengye Bao, Shengtao Zhang, Haokai Zhang, Shiqi Lou, Muning Wen, Minnan Luo（6 位；cs.AI）
- **TL;DR**：当前 agentic memory 系统普遍带 mutation、结构化组织、学习式检索等复杂操作；本文设一个极简基线 **Raw-RAG**（对原始历史做稠密检索 + 重排，直接把证据喂给 reader LLM），发现它在 LoCoMo / LongMemEval / MEME / MemoryAgentBench 的 **7 个"基准×模型"设定里有 6 个排第一**，并追问"为什么原始历史检索仍这么强"。
- **解决什么问题 / 为什么重要**：命中 C 的**memory 机制/现象分析（优先类）**——它不是又提一个 memory 方法，而是对"复杂 agentic memory 是否真有必要"做系统祛魅，并给出机制解释（见下），把朴素 RAG 确立为该领域一个必须对标的基线。这类"把流行复杂做法打回原形并解释原因"的工作，对判断 agent memory 研究的真实进展很有价值。
- **核心方法**：① 定义 **Raw-RAG**：稠密检索 + 重排原始对话历史，供 reader LLM；② 在四个长对话记忆基准 × 多模型上与多种 agentic memory 系统对比；③ 做**证据分析**解释竞争力来源——原始历史对"必要证据"的**更高覆盖率**可抵消其更低的利用率；有用证据既包括答案值、也包括推导所需的关系与依赖路径；即便完全访问"被变换过的记忆库"，相对原始证据仍存在准确率缺口。
- **主要结果**：7 个设定中 6 个 Raw-RAG 第一，比最强的被比较 agentic memory 系统高 **0.13–5.53 分**；证据分析表明"保留原始信息"至关重要——记忆变换带来的信息损失难以被复杂结构补回。
- **值得追问 / 局限**：① 结论限定在"被评估的这些长对话任务"上，对需要大规模压缩、跨会话长期演化、或存储成本敏感的场景，原始历史全量可检索的假设未必成立（Raw-RAG 的代价/可扩展性边界未充分讨论）；② "覆盖率抵消利用率"是对现象的解释，但这是否意味着复杂 memory 的失败主要来自"变换即丢信息"，还是其检索/组织策略本身设计不当，需要进一步拆分。

### 6. The Value of Memory in Language Agents
- 链接：https://arxiv.org/abs/2610.31303
- 作者：Zehao Lin, Erenkai Zhu, Helan Hu, Xixuan Hao, Chunyu Li, Kai Chen（6 位；cs.AI）
- **TL;DR**：记忆让语言 agent 把过去经验里的"有用区分"带入未来决策，但其价值取决于哪些区分能存活、受限 agent 能否用上、以及需求变化时能恢复/修订多少；本文给出一个**决策论框架**，以"**避免的任务损失**"为单位追踪记忆价值从原始历史→持久状态→实际使用→昂贵的恢复与修订的全过程，并刻画可达的风险—成本前沿。
- **解决什么问题 / 为什么重要**：命中 C 的**memory 机制/理论（优先类）**。它不提具体 memory 实现，而是回答一个更底层的科学问题：记忆在什么条件下、以多大成本才真正降低任务损失。框架给出若干反直觉但可检验的原理——例如"一个对答案**零互信息**的指针仍能降低精确恢复的成本"——这对设计 agent memory 的保留/恢复/修订策略提供了理论标尺，而非又一个经验技巧。
- **核心方法**：① 决策论框架把记忆价值分解为**原始价值与保留价值**（均以"避免的任务损失"计量），用风险—成本前沿描述可达的恢复与保留；② 需求未知时得到**价值画像**，交互反馈会改变未来工作的分布；③ 一个成本感知的仿真条件 + 五个最小反例，揭示信息时机、检索可达性、组件交互、反馈、需求不确定性各自的作用；④ 在 LoCoMo、一个两项目更新任务与纵向案例上做诊断，暴露保留/使用/测量三类失败。
- **主要结果**：给出可检验的原理：固定"已检索证据"时，一本保存的 ledger 会改变后续答案；固定"agent 输出"时，评估器的修订会改变分数；零互信息指针仍可降低精确恢复成本；框架把这些区分连到可操作的运行风险界与记忆分配/恢复选项保留/证据依赖修订的原则上。
- **值得追问 / 局限**：① 框架偏概念与最小反例，"以避免的任务损失计量价值"在真实 agent 系统里如何可靠估计（任务损失本身往往不可直接观测）尚需落地方法；② 诊断主要在 LoCoMo 等有限案例上定性展示失败模式，框架预测的风险—成本前沿在大规模真实部署中的紧致性与可操作性仍待实证。
