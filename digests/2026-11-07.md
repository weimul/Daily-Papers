## A. 核心方法（连续深度 Neural ODE Transformer / 图感知优化器，取 2 篇）

### 1. Beyond Quadratic Attention: Separable Gaussian Operators for ODE Vision Transformers
- 链接：https://arxiv.org/abs/2611.08236
- 作者：Carlos Boned Riera, David Romero Sanchez, Oriol Ramos Terrades（cs.LG）
- **TL;DR**：自注意力的 token 数二次开销限制了视觉 Transformer 向高分辨率扩展。本文提出 **SSoG**——一个**可分的"高斯之和"空间算子**，用轴向可分的高斯核混合替代稠密自注意力，把每层开销从 $\mathcal{O}(N^2)$ 降到亚二次；更关键的是它让**连续深度（Neural ODE）变体**获得解的全局存在唯一性保证。
- **解决什么问题 / 为什么重要**：命中 A 的 **Neural ODE / 连续时间模型**线。点中连续深度模型的一个理论软肋：点积自注意力的 Lipschitz 常数在紧致输入域外无界，因此连续深度变体**不保证**在整个积分区间上有唯一解；而 SSoG 用固定核时**全局 Lipschitz 连续**，经 Picard–Lindelöf 定理即得唯一解。这对"把注意力塞进 ODE 动力学、还想要可积性 / 稳定性保证"的连续时间建模有直接借鉴意义。
- **核心方法**：用**学习到的轴向因子化高斯核混合**替代稠密注意力（亚二次开销）→ 固定核保证全局 Lipschitz → 据此为连续深度变体给出全区间唯一解的理论保证 → 在离散 / 权重共享（looped）/ 连续深度三种 Transformer 变体上统一验证。
- **主要结果**：CIFAR-100（224×224）匹配设置下，Top-1 提升 2.2–4.1 点且参数少 8.8–16.6%；looped 设置提升 5.4–8.1 点；在 Neural ODE 架构、输入放大到 1024×1024 时，吞吐最高 +154%、峰值显存 −60% 以上，且差距随分辨率增大而扩大。
- **值得追问 / 局限**：① 轴向可分高斯核是强先验，面对需要各向异性 / 长程非轴对齐依赖的任务是否损失表达力，论文未深入；② 唯一性保证来自"固定核"，一旦核也可学 / 随输入变化，全局 Lipschitz 前提是否仍成立、连续深度稳定性是否退化，需进一步界定。

### 2. Module-Aware Optimization for Graph Neural Networks (GraphMuon)
- 链接：https://arxiv.org/abs/2611.08379
- 作者：Guy Hadad, Haggai Roitman, Moshe Eliasof, Bracha Shapira（cs.LG）
- **TL;DR**：不同优化器给参数更新施加不同几何——Adam 系按坐标更新，Muon 系用正交化更新利用权重矩阵结构。但对 **GNN** 而言，权重矩阵的"有效几何"不仅由学到的通道混合权重决定，还被它作用其上的**图传播表示**塑造，于是"矩阵层面归一化良好"的更新作用到图传播特征上仍可能被放大。GraphMuon 让 Muon 的矩阵更新**适配图传播层输入的协方差结构**。
- **解决什么问题 / 为什么重要**：命中 A 的**图神经网络方法**（注意：是通用 GNN 优化，非时序 / 动态图；本窗无强相关时序图新作，以此代表图方法线）。它把"优化器几何"与"图传播几何"耦合起来思考，是对"为什么 GNN 训练常不稳 / 对优化器敏感"的一个结构化解释与修正，对任何在图上训深模型（含时空图 GNN）都有迁移价值。
- **核心方法**：在由图传播表示定义的度量下做**正交化**，并按更新"对层表示的诱导效应"归一化步长 → 理论上证明 vanilla Muon 会遭"图诱导的更新放大"、而 GraphMuon 可缓解 → 得到 Muon 极性更新步的"图度量类比"。
- **主要结果**：在 3 个大规模 OGB 基准上相对 AdamW 取得 **1.32×–2.42× 的达标时间加速**；跨 15 个"数据集×架构"配置（节点分类、归纳式图分类、图回归），13 例达标时间更短，预测性能持平或更优。
- **值得追问 / 局限**：① 增益主要体现在"达标时间（收敛速度）"，最终精度多为持平，净收益需按训练预算权衡；② 协方差结构的估计 / 维护在超大图、mini-batch 子图采样下的开销与稳定性，以及能否无痛迁移到时序图 / 动态图这类"传播几何随时间变化"的设定，论文未覆盖。

## B. 应用场景（EEG 扩展源成像 / 未训练网络做异常检测，取 2 篇）

### 3. PINR-ESI: Physics-Informed Self-Supervised Implicit Neural Representation Framework for EEG Extended-Source Imaging
- 链接：https://arxiv.org/abs/2611.06700
- 作者：Zhiyong Zhou, Sheng Liao, Youshen Xiao, Xiaolin Li, Yakang Dai（cs.LG）
- **TL;DR**：EEG 扩展源成像要定位活跃皮层区域并刻画其空间范围，但有监督反演网络通常依赖合成的"EEG–源"配对、且易受"合成到真实"的分布失配影响。本文提出**物理约束自监督隐式神经表示（INR）** 框架，**无需配对源标签、也无需基于仿真的有监督预训练**即可做空间源重建。
- **解决什么问题 / 为什么重要**：命中 B 的**脑 / 神经影像时间序列**。它把"前向导联场模型"作为物理约束直接接进自监督目标，绕开了神经影像逆问题里长期头疼的"合成数据训练→真实数据失配"，对任何"想用自监督 + 物理先验做脑源 / 脑网络重建"的场景（含 fNIRS 类近红外成像的类比思路）都有方法学参考。
- **核心方法**：把皮层电流密度建模为**连续坐标条件场（INR）** → 用**导联场矩阵**（源到传感器的体积传导模型）约束 INR，使预测 EEG 与实测 EEG 一致 → 用经典反演估计做**暖启动 + 空间约束**，再用 patch 积分投影把连续场映射为离散源系数以做前向建模。
- **主要结果**：在不同噪声水平、源数目、源范围的仿真上，对识别活跃皮层区域（尤其**多源、较大源**）优势最明显；在癫痫患者真实 EEG 记录与颅内电刺激实验上的定量 / 定性评估进一步支持了其可行性。
- **值得追问 / 局限**：① 暖启动来自经典反演，最终解对该初始估计的依赖程度、以及坏初始化下的鲁棒性未充分剖析；② 真实实验以癫痫 / 颅内刺激为主，换到更广泛脑区 / 任务态、导联配置差异大时的泛化仍待验证。

### 4. How Far Can Untrained Neural Networks Go in Anomaly Detection? From Tables to Pixels
- 链接：https://arxiv.org/abs/2611.08136
- 作者：Hyojun Yi, Geunyoung Kim, Hogeon Seo, Seunghyoung Ryu（cs.LG）
- **TL;DR**：异常检测常被框定为"表征学习"问题，默认强性能需要学到的特征或 AD 专用优化。但这忽视了"异常相对正常参考的**内在可分性**"——哪怕没有任何学到的表示也可能成立。本文追问**未训练神经网络在异常检测上到底能走多远**，提出 **PRISM**：固定随机非线性特征 + 基于正常参考的马氏距离打分。
- **解决什么问题 / 为什么重要**：命中 B 的**异常检测 / 监控**线。它给出一个"**学习前基线（prior-to-learning baseline）**"——用来衡量"学到的表示"在 AD 里究竟带来多少增量价值，对"上来就堆表征学习 / 大模型做监控告警异常检测"的惯性是一次有用的对照与降温。
- **核心方法**：表格检测用 **PRISM-T**、稠密视觉定位用 **PRISM-V**，两者都用**固定随机非线性特征**配合正常参考的**马氏距离打分**，不做任何神经权重优化、也不用预训练表示 → 理论上刻画非线性变换如何影响马氏打分差的均值 / 协方差贡献，经验上检验打分可分性。
- **主要结果**：ADBench 的 47 个表格数据集上 PRISM-T 取得**最高平均 AUROC 86.4%**、第二高平均 AUPRC 65.9%；MVTec AD + VisA 的 27 个视觉类别上 PRISM-V 取得图像级 / 像素级平均 AUROC **90.4% / 96.4%**——全部在无权重优化、无预训练表示下达成。
- **值得追问 / 局限**：① 评测集中在表格与视觉（工业缺陷），对**多变量时间序列 / 监控告警**这类时序异常是否同样成立，论文未直接覆盖（需迁移验证）；② 固定随机特征的马氏打分对高维、强相关、渐变漂移场景的可分性边界在哪里，是基线还是能当真实检测器用，仍需按场景判断。

## C. 机制 / Agent（残差流方向的可验证解释 / 表征涌现压缩的两种模式，取 2 篇；均为"优先"机制类，非 prompt 工程）

### 5. Towards interpreting any residual stream direction by scaling activation inversion (MAEM)
- 链接：https://arxiv.org/abs/2611.08465
- 作者：Celeste De Schamphelaere, Juan J. Vazquez, Ari Spiesberger, Tomáš Gavenčiak, Gavin Leech, Euan Ong（cs.LG）
- **TL;DR**：要解释语言模型残差流里的一个方向，可以找"强烈激活它"的文本；但靠扫语料找，能找到的只限于语料里有的内容。本文训练 **MAEM（Maximally-Activating Example Metamodels）**——把**任意残差流方向映射成强激活它的文本样本**的语言模型，用"生成文本的激活与给定方向的余弦相似度最大化"这一**无标签 RL 目标**来扩展。
- **解决什么问题 / 为什么重要**：命中 C 的 **residual stream / 机制分析**，正中"优先"机制类。它的核心卖点是**可验证性**：与其它元模型（如自然语言自编码器 NLA）不同，MAEM 产出的样本**可用对主体模型的一次前向传播来核验**（生成的文本是否真的强激活该方向），把"解释"从不可证伪的叙述变成有 grounded 目标的工程对象——这正是内生 / 可验证可解释性路线所需要的。
- **核心方法**：训练一个元模型，最大化"所生成文本在主体模型中的激活"与"供给的残差流方向"的余弦相似度（label-free RL）→ 使该目标能在多样来源的残差流方向上扩展 → 以"前向传播核验"作为解释是否成立的判据。
- **主要结果**：Qwen3.6-27B 的 MAEM 在反演保留集激活上优于语料搜索与 NLA；在多数保留语言 / 领域上击败 10M token 的语料搜索；激活了 **89% 的保留 SAE 特征**；识别 steering 向量背后概念与 NLA 相当，恢复 **LoRA 后门载荷**比语料搜索更频繁，甚至能把部分"模型工作区内心独白"口头化。
- **值得追问 / 局限**：① 元模型本身容量很大（27B 级），训练 / 推理成本与"解释一个方向"的性价比需权衡；② "前向可核验"保证的是"该文本确实激活此方向"，但不等于该方向在因果 / 功能上就是这个语义——可验证性 ≠ 因果充分性，仍需配合干预实验。

### 6. Invariance before structure: two modes of emergent compression in representation learning (EARL)
- 链接：https://arxiv.org/abs/2611.07952
- 作者：Hardik Rajpal, Dan Goodman（cs.LG）
- **TL;DR**：学到的表示在生物与人工神经网络间表现出惊人的不变性，而差异则由漂移、异质性、初始化驱动。为理解这种不变性，本文提出 **EARL** 框架，区分表征涌现的两种模式：**状态空间压缩**（表征对自身未来的预测力超过各单元单独所能预测）与**参数空间压缩**（不同微观参数的网络收敛到同一表征），并把二者统一形式化为 **Fisher 敏感度**。
- **解决什么问题 / 为什么重要**：命中 C 的**表征几何 / 训练动态**，是"优先"机制类的典型现象分析。它给"为什么不同基底 / 不同初始化的网络会学到相似表征"提供了一个可度量的信息论框架，并把"对基底的不变性"与"任务相关的涌现结构"在训练时间轴上**拆成先后两相**——对理解表征如何、何时形成（含循环 / reservoir 这类时序结构学习）很有启发。
- **核心方法**：把两类压缩形式化为 Fisher 敏感度，并引入各自的**系综层面信息论度量** → 在"带可训练瓶颈的循环 reservoir"上观测两类压缩随训练 epoch 的演化曲线。
- **主要结果**：**参数空间压缩**在训练头几个 epoch 内就上升、且**部分独立于任务**；**状态空间压缩**约 30 个 epoch 后才上升、且**仅当网络开始学习任务的时间结构时**出现——提示"对基底的不变性"与"任务特异的涌现结构"是在学习的不同阶段分别获得的。
- **值得追问 / 局限**：① 结论基于循环 reservoir + 可训练瓶颈这一特定玩具设置，两相分离在大规模 Transformer / 真实任务上是否稳健未验证；② "参数空间压缩部分独立于任务"是诱人的观察，但其与泛化 / 可迁移性的因果联系，以及 Fisher 敏感度估计在高维下的可靠性，仍需进一步工作。
