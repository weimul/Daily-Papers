## A. 核心方法（无参数连续时间摘要做不规则时序预测 / 动态图拓扑增强用于脑网络，取 2 篇）

### 1. CTLite: Lightweight Irregular Multivariate Time Series Forecasting with Reusable Continuous-Time Summaries
- 链接：https://arxiv.org/abs/2610.26379
- 作者：Shusen Ma, Xudong Zuo, Yangchun Xie, Yun-Bo Zhao（4 位；cs.LG）
- **TL;DR**：不规则多变量时序预测（IMTSF）要从稀疏、异步的观测里同时抓时间动态与跨变量依赖，现有方法多把"历史表征构建"与"模型优化"耦合、反复处理同一批观测；CTLite 把两者**解耦**——用一个**无参数的连续时间矩编码器**在多时间尺度上总结局部水平与趋势（并抑制支撑不足的斜率估计），再配一个轻量读出头做阻尼外推 + 低秩跨变量校正，历史摘要因与可训练参数/预测查询无关而**可跨优化步与重复预测复用**。
- **解决什么问题 / 为什么重要**：正中 A 的**不规则采样 / 异步时间序列 + 连续时间建模（核心方法）**。它给出一个与"端到端学时间编码器"相反的设计取向：把连续时间的"历史摘要"做成**确定性、可缓存、与训练解耦**的一块，既绕开对等间隔的假设，又把推理成本和重复预测的开销压下来——这对你关注的不规则/缺失时间戳场景（如异步采集的神经/监控信号）是个很实用的轻量基座。
- **核心方法**：① 无参数**连续时间矩编码器**，多尺度总结局部 level / trend 并抑制弱支撑斜率；② 紧凑读出：阻尼局部外推 + **低秩跨变量校正**，显式考虑观测新鲜度、目标可得性与预测步长；③ 历史摘要独立于可训练参数与查询，故对不变历史可在多次优化步 / 重复调用间**复用**而不改预测与梯度。
- **主要结果**：四个真实基准上以仅 **88–2,537 个可训练参数**取得最优或次优的平均 MSE/MAE；batch 32 匹配 GPU 负载下推理延迟较最新模型降 **18.6–87.3%**（含历史编码成本）；同一历史 16 次预测复用摘要再降总运行时约 **52%**。代码已开源。
- **值得追问 / 局限**：① "无参数矩编码器 + 阻尼外推"是以**强归纳偏置**换极致轻量，面对强非线性/突变（regime switch）动态时，固定的矩摘要上限如何、是否需与少量可学习分量混合，值得在更难基准上压测；② 低秩跨变量校正对高维、强耦合变量集的表达力，以及"复用摘要"在历史频繁更新（流式）场景下的实际收益，摘要未展开。

### 2. MCDA: Multi-View Graph Contrastive Learning with Dynamic Topology Augmentation for Functional MRI Analysis
- 链接：https://arxiv.org/abs/2610.26322
- 作者：Hao Zhang, Xiaoyun Liu, Shuo Huang, Yue Ma, Liang Cao, Mingxia Liu（7 位；cs.CV，兼 cs.AI）
- **TL;DR**：静息态 fMRI 的图对比学习（GCL）常用固定噪声或随机丢边做增广，既没利用跨训练轮次的**增广历史**、也忽略不同增广视图间的关系；MCDA 用一个**动态增广更新（DAU）模块**迭代精炼增广后的图拓扑，并结合自感知 / 跨样本增广同时抓个体特异功能签名与被试间异质性，再做拓扑引导的多视图对比（不仅对齐原图与增广视图、也对齐各增广视图之间）。
- **解决什么问题 / 为什么重要**：一箭双雕地命中 A 的**动态图 GNN（核心方法）**与你的**脑网络 / 神经影像时间序列应用（B）**。相比把图增广当成一次性静态扰动，它把"增广拓扑"当成**随训练演化、被历史和视图间关系约束**的对象——这与"动态图结构学习"的思路同源，落在脑功能连接分析上又直接给出可做生物标志物的判别性连接模式，对你用图方法解脑功能的主线有直接借鉴。
- **核心方法**：① **DAU 模块**跨训练轮次迭代精炼增广图拓扑（而非固定噪声/丢边）；② 自感知 + 跨样本增广，兼顾个体功能签名与被试间异质性；③ 拓扑引导的**多视图对比**，同时利用原图-增广、增广-增广的互关系以最大化结构信息保留；④ 分类损失 + 对比损失联合训练，并给出分数级优化方向刻画与对比目标的下界。
- **主要结果**：在两个公开 rs-fMRI 数据集（共 **1,236 名被试**）上超越 SOTA；可给出判别性功能连接作为潜在生物标志物。代码已开源。
- **值得追问 / 局限**：① 这里的"动态"是**增广拓扑随训练演化**，并非 CTDG 意义上的时序/连续时间动态图——它刻画的是静息态功能连接的结构，而非信号的时间演化，跟真正的时空图 GNN 仍有距离；② "DAU 迭代精炼"引入额外超参与训练开销，增广拓扑的稳定性/收敛性，以及在更大、更异质多站点队列上的泛化，待看完整消融。

## B. 应用场景（训练期 logit 平均刷新无创语音 BCI / 随机模态配对做儿童睡眠多模态表征，取 2 篇）

### 3. Logit Averaging During Training Sets a New State of the Art for Non-Invasive Speech BCI
- 链接：https://arxiv.org/abs/2610.26347
- 作者：Miran Özdogan, Gereon Elvers, Michael Bronstein, Oiwi Parker Jones（4 位；cs.LG）
- **TL;DR**：无创脑机接口受信噪比所限，近来 SOTA 靠**对同一刺激的多试次做聚合**来提升，但"聚合"在文献里处理得很不一致（有人在输入端平均脑信号、有人在输出端平均预测），且从未把它当成一个**独立的架构选择**；本文首次系统比较六种聚合范式（含作者新提的训练期 logit 平均与三种注意力变体），在 3 数据集 / 4 任务 / 2 组规模上评测，发现**训练期 logit 平均**在 7 个设置里 6 个最优。
- **解决什么问题 / 为什么重要**：直击你的**无创神经时间序列解码主线**。它把"多试次聚合"从一个被随手处理的预处理细节，提升为与架构同级的**一等设计维度**，并给出一个简单到几乎零成本的强默认（训练期 logit 平均）。更有意思的是它由此对深度学习里"联合集成训练为何不如独立集成"的既有解释提出质疑——对任何做重复试次刺激/低信噪无创解码（EEG/fNIRS 同样适用）的人，这是立刻能试的取舍。
- **核心方法**：① 系统梳理六种多试次聚合范式：输入端平均、输出端平均、训练期 logit 平均，及三种基于注意力的聚合变体；② 在 3 数据集、4 任务、2 种组规模上统一评测；③ 在理论上把 logit 平均与**联合集成训练**联系起来，用实证结果反诘"联合集成为何失败"的现有解释。
- **主要结果**：聚合选择影响显著；**训练期 logit 平均**在 7 设置中 6 个最优；在 2025 PNPL 竞赛的音素分类设置上刷新 SOTA，平衡准确率较竞赛冠军**高 17.4 个绝对百分点**。
- **值得追问 / 局限**：① "训练期 logit 平均最优"建立在**需多试次重复同一刺激**的范式上，对单试次 / 不可重复刺激的真实在线 BCI 迁移性存疑，这正是你最该追问的边界；② 与联合集成的理论联系是启发式的，为何这个"最简单"的方法反而最好，其机制（是正则化、梯度平均还是别的）仍待更深入拆解。

### 4. SleepPairNet: Learning Multimodal Pediatric Sleep Representations with Random-Pair Cross-Attention
- 链接：https://arxiv.org/abs/2610.26628
- 作者：Saurav Raj Pandey, Harlin Lee（2 位；cs.LG）
- **TL;DR**：分析生理睡眠信号对评估睡眠质量、检测睡眠障碍很重要，学习信号间的**跨模态关系**能给下游更丰富的表征；SleepPairNet 是一个多模态自监督框架，用交叉注意力学习生理信号两两间的交互，并提出**随机模态配对选择**策略在预训练期暴露多样信号对，从而在测试时**灵活适配任意模态组合**。
- **解决什么问题 / 为什么重要**：落在你的**生理 / 神经时间序列表征**关注面上（EEG 与呼吸等多模态）。它的核心卖点是"**模态组合灵活性**"——不固定模态对，训练时随机配对，使模型不依赖某个固定的多模态输入布局，这对临床采集中模态经常缺失/变化的现实很实用；对你做多通道/多模态神经信号（含 fNIRS 与其他生理信号联采）的表征学习，提供了一个"模态可缺省"的自监督思路。
- **核心方法**：① 多模态自监督框架，用**交叉注意力**学习生理信号两两间的成对交互；② **随机模态对选择**策略：预训练期随机采样信号对，让模型见过多样配对、测试时可任意组合模态；③ 在 NCH 数据集预训练，并迁移到外部 CHAT 数据集评估。
- **主要结果**：在 NCH 上全部**呼吸相关任务**超过所评自监督基线、EEG 相关任务保持竞争力；迁移到外部 CHAT 数据集时结果更强（迁移鲁棒性好）。
- **值得追问 / 局限**：① 优势集中在呼吸任务、EEG 任务只是"competitive"，说明随机配对对**脑电这类高信息密度模态**未必最优，针对性配对/加权可能更好；② 评测以儿童睡眠多导（NCH/CHAT）为主，向成人、向其他生理模态组合（含 fNIRS）的泛化，以及"随机配对"相对"课程式/相关性引导配对"的真正收益，仍待对照。

## C. Agent / 机制（agent 记忆几何能否预测答对 / 检索-技能冲突下程序性幻觉的因果解剖，取 2 篇）

### 5. The Geometry of Agent Memory: Forecasting Retrieval-Bound Memory Failures, and Characterizing Its Limits
- 链接：https://arxiv.org/abs/2610.26433
- 作者：Iliya Zhechev, Radoslav Ralev, Chris Coleman, Srijith Rajamohan, Jen Agarwal, Tyler Hutcherson（7 位；cs.CL，兼 cs.IR）
- **TL;DR**：作者问一个很本质的问题——**对话轮、记忆文本、查询之间的几何关系，能否在生成前就预测答案对错**？把四种记忆实现（稠密/混合检索）嵌入共享空间、用 25 个描述查询邻近性、记忆-对话对应、对话结构的特征训一个逻辑回归分类器；结论诚实地偏否定。
- **解决什么问题 / 为什么重要**：正中 C 的 **agent memory + 表征几何（优先类）**，而且是一篇**认真做否定结论**的机制性工作。它检验了一个很诱人的直觉（"嵌入几何 = 记忆可用性诊断"），发现几何在控制了问题难度与系统身份后几乎不带来统计可确立的增益，并进一步点明"嵌入邻近既不验证事实覆盖、也分不清记忆构建/检索/生成三类误差"——这对任何想用检索几何做 agent 记忆健康度监控的人，是一个重要的"别过度相信几何"的边界刻画。
- **核心方法**：① 四种记忆实现 + 一个观察-摘要比较器，统一嵌入共享空间；② 25 维几何特征（查询邻近、记忆-对话对应、对话结构）喂逻辑回归，**只用生成前特征、不额外调用 LLM**；③ 在 LongMemEval-small、LoCoMo 上分题型评估，并设置难度 / 系统身份两个对照厘清几何的净贡献。
- **主要结果**：LongMemEval-small 上汇总 AUROC **0.640**，低于"问题难度"基线 0.655；分题型差异大（single-session-assistant 达 0.841，但仅系统身份就 0.826）；控制难度与身份后几何**净增益不可统计确立**（Δ=+0.002，95% CI [-0.010, 0.014]）；固定库实验里邻近排序优于随机子集，但这只是普通检索相关性。
- **值得追问 / 局限**：① 作者明确**不声称**这是可部署诊断，几何与正确性只是"关联"——落地监控仍需能区分记忆构建/检索/生成误差的信号，而非单看邻近；② 结论绑定两个基准与特定记忆实现，换更强记忆/检索器或更长多跳任务，几何的（有限）预测力会怎样变，值得继续量化。

### 6. When Retrieval Partially Conflicts with Skills: Understanding Procedural Hallucination in Language Models
- 链接：https://arxiv.org/abs/2610.25827
- 作者：Guanqun Jiang, Pengfei Cao, Kang Liu, Jun Zhao（4 位；cs.AI，兼 cs.CL）
- **TL;DR**：当模型选定一个"技能"（可复用的流程/规程）后，往往还要叠加检索到的任务上下文；若检索有用但含**违反技能**的线索，模型需保留兼容信息、拒掉冲突线索——本文研究模型采纳了这类冲突线索、给出"检索有支撑但违反技能"答案的失败，称为**程序性幻觉（procedural hallucination）**，并配套 SourceClash 基准与机制分析。
- **解决什么问题 / 为什么重要**：正中 C 的**机制/现象分析（优先类）**。它刻画了一类在 agent/工具调用里很常见、却少被单独命名的失败——"检索与规程部分冲突"，并用干净的机制手段（残差替换、注意力分解）把"修复"定位到**value 通路**，还证明干预该通路能真实提高答案合法性。对你关注"内生机制 / 回路级分析"的主线，这是一个把"幻觉"落到可干预内部结构上的实例。
- **核心方法**：① **SourceClash** 基准：1,271 个 bundle、6,355 条 prompt、覆盖十个程序域，固定任务/技能规格/答案空间、只变"技能与检索的关系"；② 跨九个模型测冲突 vs 支持检索下的有效答案率；③ 机制分析：**残差替换**把模型推向合法答案，**注意力分解**把多数修复归因到 **value 向量**，并在识别出的 value 通路上直接干预验证。
- **主要结果**：冲突检索下有效答案率平均仅 **25.7%**（两种支持性检索分别 78.2% / 72.8%）；答案偏好差异通常在**生成刚开始后不久达到最大**；残差替换与 value 通路干预均能提升最终答案合法性。
- **值得追问 / 局限**：① "修复主要在 value 向量"是在开源权重模型上的结论，跨架构 / 更大模型是否仍成立、query/key 通路是否在别处起更大作用，待验证；② value 通路干预提升合法性，但该通路也承载正常的上下文利用，**直接干预是否误伤合法的检索依从**，是把它变成可部署缓解前必须量化的权衡。
