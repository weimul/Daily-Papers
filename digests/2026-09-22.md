## A. 核心方法（事件流 / 时序点过程）

### 1. Universal Multi-Modal Traceformer: Integrating Heterogeneous Context for Process Event Prediction
- 链接：https://arxiv.org/abs/2609.24579
- 作者：Fabian Spaeh, Jingxing Fang, Shandian Zhe, Bin Shen（4 位作者）
- **TL;DR**：现有事件序列 / 时序点过程模型大多只建"活动类型 + 时间戳"，本文提出 **UMT**，用一个"通用特征编码器 + 逐事件 Perceiver"把数值、类别、文本、元数据等异质上下文（事件级与整条轨迹级）统一喂进 next-event 预测，并对重尾/多峰的到达间隔做多尺度联合建模。
- **解决什么问题 / 为什么重要**：正中核心方向的事件流 / 连续时间点过程建模。真实事件日志里除了"发生了什么、何时发生"，还带大量上下文信息（测量值、属性、文本描述），过去的 TPP 类方法基本忽略这些，导致下一事件预测欠拟合。UMT 把"多模态上下文"作为一等公民纳入点过程式的序列建模，是把 TPP 从纯时间戳推向"上下文感知"的一步。
- **核心方法**：Transformer 主干 + 通用特征编码器（把不同类型特征映射到共享表示空间，兼顾事件级与轨迹级上下文）；逐事件 Perceiver 模块动态加权上下文特征并自适应融入事件 token；为应对到达间隔的重尾、可能多峰分布，用多个时间尺度表示每段间隔并联合预测各尺度量。
- **主要结果**：在 13 个真实事件日志上，next-event 的活动类型预测与时间预测均优于既有方法。
- **值得追问 / 局限**：① 多尺度间隔表示相比标准混合密度/强度网络，究竟在校准还是仅点精度上占优，论文摘要未拆分；② "通用特征编码器"对新模态/缺失上下文的鲁棒性、以及上下文特征对预测的实际贡献（可解释性/消融）尚需看正文。

## B. 应用场景（脑功能时序 · EEG 微状态 / 癫痫前期）

### 2. Brain-Token Learning: Microstate-Based Tokenization and Multi-Scale Interaction for Long-Horizon EEG Sequence Modeling
- 链接：https://arxiv.org/abs/2609.24324
- 作者：Weishan Ye, Yue Pan, Li Zhang, Gan Huang, Zhen Liang（5 位作者；深圳大学等）
- **TL;DR**：不再用固定窗口 / patch 这类人为时间边界切 EEG，而是把长时程 EEG 表示成一串**脑微状态（microstate）**衍生的"脑 token"——每个 token 对应一段时长可变的准稳态大尺度脑状态，再用多尺度交互模块同时建模全局脑状态语境与局部微状态转移。
- **解决什么问题 / 为什么重要**：直接命中应用方向 B 的脑功能 / neuroimaging time series。长时程 EEG 的时间复杂度高、被试间差异大，且缺少"生物学有意义"的序列表示；固定窗/patch 会打断内在脑态动力学。本文把神经科学的 microstate 概念变成 tokenization 原语，既是应用落地也带来更可解释的表示（A×B 交叉：内生可解释的时序 token）。
- **核心方法**：Brain Tokenization 将 EEG 转成"循环出现的微状态脑 token"序列（每 token 时长可变）；其上叠加多尺度 token 交互模块——Latent State Aggregation（聚合全局脑态语境）+ State Transition Modeling（建模局部微状态转移）。
- **主要结果**：在 5 个异质 EEG 数据集（新采集的长时程 NeuroLong + SEED、DEAP、MDD、NSSI 等情感/临床数据集）上，一致优于 CNN/LSTM、Transformer 类模型与域适应方法；分析验证 microstate tokenization 与多尺度交互对稳健且可解释表示的作用。
- **值得追问 / 局限**：① 微状态提取本身（数量、聚类方式）是超参且依赖预处理，其稳定性与对下游的敏感度如何；② token 时长可变带来的序列对齐 / 批处理效率、以及跨设备通道布局的迁移性，摘要未涉及。

### 3. Chaotic Dynamics-Regulated Topological Learning for Patient-Specific Preictal State Identification
- 链接：https://arxiv.org/abs/2609.23317
- 作者：Zihan Wang, Daixin Li, Guilin Wang, Mushal Zia, Xiaoqi Wei, Xiang Xiang Wang 等（7 位作者）
- **TL;DR**：把 EEG 脑网络里每个节点建模成 **Lorenz 混沌振子**，再用**持久拉普拉斯（persistent Laplacian）**同时抽取拓扑不变量与几何形状演化，做患者特异的"癫痫前期（preictal）vs 发作间期（interictal）"通道级判别；框架统一了混沌动力学、多尺度代数拓扑与局部网络差分。
- **解决什么问题 / 为什么重要**：命中 B 的脑网络 / 神经影像时序，也贴合 A 的时空/拓扑几何。现有癫痫前期识别多把 EEG 当静态或弱时变快照，忽略内在非线性动力学、也缺乏刻画致痫区分层局部演化的几何敏感性。本文把"混沌动力学 + 拓扑谱"引入脑网络建模，试图补上这层几何/动力学结构。
- **核心方法**：按相关强度把 EEG 划成离散功能子网（捕捉多尺度连通性）；每节点用 Lorenz 振子嵌入底层混沌动力学；持久拉普拉斯经谐波/非谐波谱分析同时提取拓扑不变量与几何演化；再用"节点移除拓扑差分"隔离局部神经贡献。CHB-MIT 上做患者内、通道级分层交叉验证。
- **主要结果**：在固定的患者特异网络内，支持 preictal / interictal 的通道级离线判别。
- **值得追问 / 局限**：① 作者明确自陈：表示是在"包含被留出的未标注节点在内的完整网络"上构建后才做交叉验证，**属 transductive 设定，性能不代表对未见 EEG 窗口 / 发作 / 患者的泛化**——这也正是最该追问的点（能否改造成 inductive、在线预测）；② 仅离线、患者特异，距真正的"发作预测"仍有工程与验证差距。

## C. 机制 / 表征分析 + Agent（高优先级，取 3 篇）

### 4. RPMem: Learning Long-Term Recurrent Parametric Memory Across Sessions for LLM Agents
- 链接：https://arxiv.org/abs/2609.23466
- 作者：Fanyu Zhao, Ruike Cao, Liang Dong, Fugen Yao, Jian Xu, Guanjun Jiang 等（9 位作者）
- **TL;DR**：面向长期运行的 LLM agent，提出 **RPMem** 两阶段架构：先把每个会话经前向计算"编译"成与 backbone 无关的潜在记忆，再经任务训练的循环门（recurrent gate）选择性地与已有记忆融合；最终把整合后的记忆映射到 backbone 专属的 LoRA 参数，从而在换模型后仍能复用记忆。
- **解决什么问题 / 为什么重要**：正中 Agent 方向的"优先：memory"。文本型记忆每次查询都要检索重构历史，长时程表现越来越受检索质量拖累；已有参数化记忆又缺乏跨会话演化、且绑死特定 backbone，换模型即失效。RPMem 想同时解决"跨会话演化"和"生命周期无关（换 backbone 可迁移）"两个痛点，机制上（门控如何学习记忆整合）也有分析价值。
- **核心方法**：会话编译（forward computation 得到模型无关潜在记忆）→ 循环门跨会话巩固（selective consolidation）→ 映射为 backbone 专属 LoRA 参数；更新成本与记忆占用近似常数。
- **主要结果**：在 3 个长期记忆基准、5 种 backbone 上广泛泛化；Qwen3-8B 在 PERMA 上达 85.52%，比最强参数化 / 文本基线分别高 5.32 / 12.98 个百分点；消融验证会话编译与跨会话巩固互补，动力学分析显示门学到任务特异的记忆整合策略；代码开源。
- **值得追问 / 局限**：① "模型无关潜在记忆 + 换 backbone 重映射 LoRA"在跨架构（不同隐维/层数）迁移时的信息损失有多大，仅测同族/近族 backbone 还是真跨架构；② 循环门长期累积是否有记忆漂移 / 灾难遗忘，超长会话数下的稳定性未知。

### 5. Topographic Training Concentrates Causal Circuits Without Improving Neuron Monosemanticity
- 链接：https://arxiv.org/abs/2609.24379
- 作者：Gautam Ranka, Shubham Santosh Pandere, Aiden Dsouza（3 位作者）
- **TL;DR**：给 ViT 加一个"空间局部性"训练损失（TopoLoss）作为训练期先验，结果发现它能把**因果电路在空间上聚集**（拓扑簇的因果充分性显著提升），却**并不改善单神经元的单义性**——说明拓扑压力作用在"电路级"而非"神经元级"。
- **解决什么问题 / 为什么重要**：命中 C 的机制/现象分析 + 表征几何 + 叠加/残差流。特征叠加（superposition）常被当作可解释性的核心障碍，但主流缓解（稀疏自编码器 SAE、字典学习）都是事后、且不改网络本身。本文问：训练期加个轻量几何先验能否直接改善机制可解释工具的效果，并意外揭示"当前神经元级单义性指标对一类真实可解释性增益不敏感"。
- **核心方法**：在 ImageNet-100 上以不同权重 α 训练带 TopoLoss 的 ViT；用 activation patching 量拓扑簇的因果充分性，用 SAE 拟合同一残差流量特征几何。
- **主要结果**：α=1.0 时拓扑簇的因果充分性是同规模随机单元集的 2.79×，且随 α 单调增强；SAE 的 L0 稀疏度降 11%、死特征比例升 19 倍，但神经元级单义性分数不变——即因果质量被集中到空间局部结构里，却没解耦单个神经元；作者据此主张"廉价架构先验"可作为事后工具的训练期补充。
- **值得追问 / 局限**：① 结论在 ViT / ImageNet-100 这一视觉设定，是否迁移到语言 Transformer / 更大规模未验证；② "电路级集中但神经元不单义"意味着现有单义性指标失灵，那用什么指标衡量这类增益、以及它对下游安全/编辑是否真有用，仍开放。

### 6. On Emergent Capabilities and Model Merging
- 链接：https://arxiv.org/abs/2609.24504
- 作者：Luca Zhou, Emanuele Rodolà（罗马 Sapienza 大学）
- **TL;DR**：系统研究"模型合并（对权重做算术以廉价组装能力）"对**涌现能力**（从非显式训练目标中冒出的行为）意味着什么，给出三条结论：合并能保留双亲共有的涌现能力，却无法创造对双亲"超可加"的涌现能力，且当只有一方带该能力时，合并稀释它的速度比稀释随行的"训练得到的能力"更快。
- **解决什么问题 / 为什么重要**：命中 C 的机制/现象分析 + 训练涌现。模型合并已是仓库里最常见的权重操作，但人们主要关心它对"训练目标能力"的影响；本文把镜头对准"涌现行为"，指出涌现能力在合并下的组合规律与训练能力不同——对模型复用、对齐（尤其"涌现失配"能否被合并稀释/放大）有直接安全含义。
- **核心方法**：两个独立测试台（activation oracles、emergent-misaligned 模型）× 三个模型族；沿整个混合系数范围观测涌现能力的保留 / 创造 / 稀释。
- **主要结果**：① 合并两个失配 checkpoint，在整个混合范围内保留大部分广义失配；② 任何加权合并两个单任务 oracle 都达不到联合训练 oracle 的审计能力（不可超可加创造）；③ 单亲携带该能力时，合并对它的稀释显著快于对随行训练能力的稀释。
- **值得追问 / 局限**：① 结论基于特定测试台（oracle / emergent-misalignment）与三个模型族，向更广涌现能力（推理、工具使用）外推需谨慎；② "涌现不像训练能力那样组合"的机制原因（是权重方向的线性可加性差异？）尚待深入。
