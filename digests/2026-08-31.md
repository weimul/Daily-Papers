## A. 核心方法

### 1. Learning to Transfer Across Modes: Towards Unified Urban Mobility Forecasting
- 链接：https://arxiv.org/abs/2608.28273 （cs.LG）
- 作者：Yixuan Zhao, Man Luo
- **TL;DR**：把城市里多种出行方式（地铁/共享单车/网约车等）的需求预测统一进一个框架，用共享的区域级空间表征把异构时空系统对齐，再从数据丰富的模式向数据稀缺的新兴模式迁移时空模式。
- **解决什么问题 / 为什么重要**：现有需求预测大多针对单一出行模式，且隐含假设源系统与目标系统空间结构兼容，导致多模态、跨粒度场景下无法直接用；新兴出行方式又缺历史数据。这正是时空建模里"结构失配 + 分布漂移 + 冷启动"的典型难题，对你关注的 spatio-temporal 方向是一个偏迁移学习角度的落地样本。
- **核心方法**：构造共享的 zone-level 空间表征，把不同空间粒度的移动系统对齐到公共空间以降低结构失配与分布偏移；在此统一表征上学习可迁移的时空模式，并适配到数据稀缺的目标模式，减轻对目标域长历史的依赖。
- **主要结果**：多个真实数据集上一致优于现有方法，且在目标数据有限时仍保持稳健预测。
- **值得追问 / 局限**：（1）"共享 zone-level 表征"如何处理城市间/模式间空间语义不一致（同一网格在不同模式下的功能可能不同）？（2）迁移得到的时空模式是否可解释——哪些模式是真正跨模态共享、哪些是被强行对齐的伪共性，文中偏性能验证。

### 2. Learning to Difference: Adaptive Reversible Differencing (AdaRDiff) for Time Series Forecasting
- 链接：https://arxiv.org/abs/2608.28134 （cs.LG）
- 作者：Morad Laglil, Younes Hlal, Marouane El Hadari, Emilie Devijver, Eric Gaussier
- **TL;DR**：把经典的"差分"从手工选阶/选周期，升级成一个可学习权重、可逆、可即插即用的算子，用一次操作同时吃掉趋势与季节性，还能并行化提速。
- **解决什么问题 / 为什么重要**：长时序预测里趋势与季节性带来复杂时间结构，经典差分是老办法但依赖手调阶数/周期，因而在现代深度架构里几乎被弃用。AdaRDiff 想把这块"经典先验"重新接回深度模型，且做成任意 backbone 都能挂的模块——对你做时序方法很有工具价值。
- **核心方法**：用可学习权重对若干历史时刻做加权差分，得到稳定化残差供预测，再自回归地把移除的成分复原以重建预测，用单一算子联合捕捉趋势与季节性；该重建有闭式卷积表达，可在 GPU 上并行（比朴素递归快达 33.7×）；并用两阶段训练把"时间结构发现"与"重建学习"分开（由线性预测模型的梯度理论分析导出）。
- **主要结果**：横跨电力/天气/交通/能源八个基准取得 SOTA，参数代价极低；作为即插即用模块接到 8 种 backbone（从线性模型到 Transformer）大多有提升，线性 backbone 上最高 +25.9%、iTransformer 上 +18.3%。
- **值得追问 / 局限**：（1）"可学习差分权重"本质上学到的是什么——是否等价于一个可解释的自适应趋势/季节滤波器，能否读出周期结构？（2）在强非平稳、结构突变（regime shift）序列上，可逆重建的稳定性与误差累积如何。

## B. 应用场景

### 3. FaulT-Bench: Towards Benchmarking Network Troubleshooting LLM Agents under Unreliable User Tickets
- 链接：https://arxiv.org/abs/2608.27021 （cs.NI / cs.AI）
- 作者：Kuan-Hao Tseng, Niruth Bogahawatta, Yasod Ginige, Kunjan Patel, Kosta Dakic, Suranga Seneviratne 等
- **TL;DR**：现有网络故障诊断 benchmark 都假设"工单准确、且真的有故障"，FaulT-Bench 专门测在不可靠工单（假报障、错误归因、错误根因主张）下 LLM agent 会不会"硬把正常判成故障"。
- **解决什么问题 / 为什么重要**：真实运维里工单常常是错的或没故障，但评测从不覆盖这些情形。这直接命中你关注的监控告警/AIOps 方向，且给出一个很务实的结论——agent 的失败模式不在"能不能诊断"，而在"该不该收手"。
- **核心方法**：构建 200 个跨 8 种网络拓扑的排障场景（5 个复刻自公开实操 lab），涵盖真故障、假报障、错误设备归因、错误根因主张；再把 72 个"假前提"工单改写成 5 种报障人设，单因子地变化报障者的自信度与可核实细节、保持网络状态不变；用 Kathará 部署、经 NIKA 工具接口交互，并用 LLM judge 从结果/修复/推理三维打分。评测 SADE、ReAct 与 Claude Code。
- **主要结果**：三个 agent 在准确工单上近乎饱和、对误导也稳健，但一旦"网络本来健康而工单是错的"，性能骤降——它们会一路探测直到把某个良性状态硬提升成根因，而不肯下"没问题"的结论。人设实验显示：工单怎么写比写了什么更关键——自信但错误的报障被处理得几乎和准确工单一样好，而含糊、信息不足的报障会显著拖垮表现；三个 agent 还以很不同的方式失败（持续过度诊断 vs 无应答），成本差异很大。
- **值得追问 / 局限**：（1）"过度诊断"是 agent 缺少"允许判无故障"的显式先验，还是 RCA 训练/提示里天然的确认偏置？（2）用 LLM judge 打分自由文本诊断，其对"良性被提升为根因"这类细微错误的判别可靠性如何。

### 4. Localizing Global Discrepancies: Marginal Contributions and Contextual Anomaly Detection
- 链接：https://arxiv.org/abs/2608.28375 （stat.ML / cs.LG）
- 作者：Tommaso Dorigo
- **TL;DR**：整体拟合优度统计能说"这批样本偏离了参考分布"，却说不清是哪些样本在驱动偏离；本文给每个观测赋一个"跨随机统计上下文的边际贡献"，把全局差异定位到事件级，并统一了重采样诊断、数据估值与异常检测。
- **解决什么问题 / 为什么重要**：这是把"全局差异 → 单事件归因"做严格化的框架，事件级异常检测正是其落点之一；同时它天然带自解释色彩——不是事后再解释一个黑箱，而是从统计量本身推出每个观测的贡献。对你横切关注的"内生/自解释 + 异常检测"是一个偏理论、但根基扎实的参照。
- **核心方法**：为每个观测计算其在随机统计上下文下的条件/边际贡献，建立与投影理论、影响函数、MMD witness 的等价关系（对称统计量的定量替换 = 中心化条件定位；U-统计量的 addition score = 一阶 Hoeffding/Hájek 贡献；无偏已知背景 MMD 精确退化为 MMD witness）；用 matched-context 相减去除与该观测无关的涨落，得到更高效估计量。
- **主要结果**：在 LHC Olympics 异常检测基准上，pair 估计量以预测的 1/(R·m²) 速率收敛到直接的经验 MMD witness，在 m=1000、R=5×10⁶ 时与其相关系数 0.9993、AUC 几乎相同；并用共享隐变量玩具模型区分了 context 的两种作用——高效定位全局差异 vs 当备择假设含共享结构时提供真正额外的类别信息（孤立事件 AUC=0.5，唯有跨事件依赖能恢复判别信息）。
- **值得追问 / 局限**：（1）框架优雅但验证偏物理/合成基准，迁到监控告警那种高维、非平稳、标注稀缺的时序异常时，"随机上下文"如何构造、代价如何？（2）"边际贡献"作为解释，其对人类可读性的帮助仍需在真实运维场景验证。

## C. Agent（机制/现象类）

### 5. Blind Men and the Elephant: Probing the Epistemic Myopia of LLMs under Long-Tail Divergent Knowledge
- 链接：https://arxiv.org/abs/2608.28478 （cs.CL）
- 作者：Zhuoshi Pan, Junru Lu, Yan Qian, H. Vicky Zhao, Di Yin, Xing Sun
- **TL;DR**：事实问答默认"只有一个标准答案"，掩盖了模型是否同时记住长尾事实的多种分歧说法；ElephantBench 用可审计的图谱式流程造出"多账户"问答，专测参数化记忆里的"认知近视"。
- **解决什么问题 / 为什么重要**：这是典型的机制/现象分析（memory 主题优先类）——不是问模型答得对不对，而是问它对同一长尾事实的多个并存说法是否都记得。对理解 LLM 参数化记忆的完整性、以及 agent 知识可信度有直接价值。
- **核心方法**：构建 ElephantBench——1,094 道闭卷知识探针题，经图谱式可审计流程从低曝光网络语料检索相关文档、识别自然存在的分歧、转成多账户问答记录；每个答案对照原始文档与权威公开来源核验，再由人工标注复审。
- **主要结果**：横跨 32 个模型，即便最强模型也仅在 52.4% 的题上同时召回两种说法，其余几乎都只记一种、漏掉另一种；扩大模型规模、增加推理时算力能改善召回但消不掉这种不完整；语料分析显示曝光不均会偏向主流说法，少数派曝光越多则召回越完整。代码已开源。
- **值得追问 / 局限**：（1）"认知近视"是纯参数化记忆的容量/干扰问题，还是解码时的"标准答案先验"压制了少数派说法——两者的区分需要表征层证据。（2）多账户题依赖"低曝光语料里的自然分歧"，其覆盖偏向与标注一致性会影响结论边界。

### 6. REINS: Refusal-Enhanced Inhibitory Steering with Sparse Autoencoder Features
- 链接：https://arxiv.org/abs/2608.28233 （cs.AI）
- 作者：Kai-Xuan Ding, Hao-Xiang Xu, Ji-Hua Peng, Zi-Qi Chen, Jiaqi Wang, Zhen-Hua Ling
- **TL;DR**：现有基于稀疏自编码器（SAE）的引导只"增强拒绝方向"，在复杂包装的有害提示上会失效；REINS 在同一 SAE 特征空间里同时抑制"有害续写特征"、增强"安全拒绝特征"，用可解释特征做双向干预。
- **解决什么问题 / 为什么重要**：SAE 暴露稀疏、可解释的特征，是推理时轻量适配与安全控制的诱人接口——正切中你关注的"内生可解释 + 表征/机制"横切。本文的机制洞察是：只加强拒绝不够，因为有害续写通路仍活跃；必须在特征层面把它按下去。
- **核心方法**：构建 GUISE 数据集（带复杂包装的有害提示）系统评估失败模式，发现单方向 SAE 引导在有害提示上不能可靠产生拒绝；据此提出 REINS——在同一 SAE 特征空间内既抑制有害续写特征又增强安全拒绝特征。
- **主要结果**：在 GUISE 等数据集上，先前方法要么干预太弱、要么靠"表征坍塌"制造表面安全；REINS 显著降低有害回复、明显提升安全拒绝，且大体保留通用能力。
- **值得追问 / 局限**：（1）"抑制有害续写特征"是否只是把有害方向压进了 SAE 未覆盖的残差空间——鲁棒性对更强的越狱包装是否会再次崩掉？（2）双向干预的强度需要在"安全"与"通用能力/过度拒绝"之间调，这个权衡的可控性与可迁移性还需更广评测。
