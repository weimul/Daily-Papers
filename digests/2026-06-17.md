## A. 核心方法 · 图原生多元时序 × 保形不确定性（滤波-椭球联合预测集）

### 1. Filtered Conformal Ellipsoids for Graph-Native Time Series
- 链接：https://arxiv.org/abs/2606.17014
- 作者：Yannick Limmer（据研究背景推断为牛津数学金融/机器学习相关，仅供参考）
- submit 日期：2026-06-15
- **TL;DR**：用一个**冻结的状态空间滤波器**为多元时序逐步输出一步预测均值与协方差，再对马氏距离分数做 split-conformal 校准，得到带覆盖保证的**联合（椭球）预测集**，天然适配"图结构上的多变量时序"。
- **解决什么问题 / 为什么重要**：正落在你方向 A 的交叉点——**多元/图结构时序 + 不确定性量化**。多数时序预测只给点估计或逐维区间，而真实的图原生场景（节点间相关）需要刻画变量间协方差的"联合"不确定集。它把状态空间滤波（连续/递推动力学）与 conformal 校准解耦组合：滤波负责动力学与协方差结构，conformal 负责无分布假设的覆盖保证——对你思考"时空/图时序如何带可靠不确定性"是干净的一块拼图。
- **核心方法**：① 冻结的状态空间滤波器在每步给出预测均值 + 协方差；② 以该协方差定义马氏距离分数；③ split-conformal 对分数校准，产出椭球形联合预测集（覆盖范围由协方差几何而非逐维盒子决定）。
- **主要结果**：在多元时序上给出具覆盖保证的椭球预测集；相对逐维/盒式区间，椭球能利用变量相关性给出更贴形、（在相关性强时）更紧的联合集合（具体增益见正文）。
- **值得追问 / 局限**：① "冻结滤波器"意味着协方差质量受预训练滤波器限制，模型失配时椭球虽仍有边际覆盖但可能偏大/偏保守；② 对显式图结构（邻接/时空图）的利用程度——是隐含在状态协方差里还是显式建模——需看正文，这决定它对你"时空图"场景的直接可用性。

## A. 核心方法 · 神经算子 × 动态/持久响应自发分离（横切"内生结构"）

### 2. Factorized Neural Operators Decompose Dynamic and Persistent Responses
- 链接：https://arxiv.org/abs/2606.16900
- 作者：Hao Tang, Yuechen Duan, Jiongyu Zhu, Zimeng Feng, Hao Li, Chao Li
- submit 日期：2026-06-15
- **TL;DR**：把神经算子的谱表示**因子化**为两支——等变的"动态响应"分支与不变的"持久响应"分支——两支在训练中**自发特化**为不同物理角色，且这种分工跨尺度、跨域保持一致。
- **解决什么问题 / 为什么重要**：方向 A 偏"连续动力学建模"一侧，且呼应你的横切重点——**内生/自组织的可解释结构**（不是事后归因，而是模型自己把表示分解成有物理意义的两支）。对建模时空/动力学系统而言，"哪部分是随条件变化的瞬态、哪部分是稳定的持久成分"是核心结构先验；它用算子分支的对称性（等变 vs 不变）把这一分解做进架构，可解释性是"自带"的而非外挂。
- **核心方法**：在谱表示上做因子化，分出等变（dynamic）与不变（persistent）两个算子分支；训练中两支无需显式监督即特化为不同物理作用，并在多尺度/多域上维持一致的角色分工。
- **主要结果**：两支算子分支自发承担不同物理角色，且该特化跨尺度与跨域保持稳定（动力学预测/重建的定量优势见正文）。
- **值得追问 / 局限**：① "自发特化"的稳健性——换初始化/换数据分布是否仍干净分离，摘要未给消融；② 框架以谱/算子学习为主（偏 PDE/连续场），迁移到你关心的"离散事件流/不规则采样图时序"还需额外适配。

## A. 核心方法 · 事件流 × 流式状态更新解耦（低延迟特征引擎的概率稀疏化）

### 3. Decoupling Inference from State Updates in Low-Latency Feature Engines via Probabilistic Thinning
- 链接：https://arxiv.org/abs/2606.16981
- 作者：Augusto Peres, Iker Perez, Pedro Valdeira, Guilherme Jardim, Ana Sofia Gomes, Hugo Ferreira, Pedro Bizarro（据作者背景推断为 Feedzai 相关，仅供参考）
- submit 日期：2026-06-15
- **TL;DR**：在线特征引擎里，**每个事件都打分（inference）**，但**只有"信息量大"的事件才触发持久化的状态更新**——用概率稀疏化（probabilistic thinning）把状态写入与推断解耦，可剔除多达 90% 的事件更新而几乎不损失特征质量。
- **解决什么问题 / 为什么重要**：贴你方向 A 的 **event stream / 异步事件** 一侧，同时偏向你方向 B 关心的"流式监控/在线系统"工程现实。高吞吐事件流（风控、监控告警）的瓶颈常在状态更新而非打分；把"更新"建成由事件信息量驱动的随机抽稀过程，是把"何时该记住一个事件"形式化的一种思路——和"时序点过程 / 选择性记忆"在精神上相通，对在线时序系统的效率-精度权衡有直接参考。
- **核心方法**：解耦"逐事件推断"与"耐久状态更新"两条路径；以事件信息量为准则的概率稀疏化（thinning）选择性触发状态写入，使绝大多数低信息事件不更新持久状态，仅打分。
- **主要结果**：可排除至多约 90% 的事件状态更新，同时维持特征质量与下游性能（在低延迟引擎上的吞吐/延迟收益见正文）。
- **值得追问 / 局限**：① "信息量"准则如何定义、对突发异常（恰恰是监控最关心的稀有事件）是否会误抽稀，需重点看；② 稀疏化引入的状态近似在长程依赖特征上的累计误差，摘要未量化。

## C. 机制/表征 · "价值轴"：LLM 内部是否编码"走在正确轨道上"（优先型）

### 4. The Value Axis: Language Models Encode Whether They're on the Right Track
- 链接：https://arxiv.org/abs/2606.17056
- 作者：Nick Jiang, Isaac Kauvar, Jack Lindsey（机制可解释性方向；据作者公开背景推断含 Anthropic 相关，仅供参考）
- submit 日期：2026-06-15
- **TL;DR**：用 RL 数据在 Qwen3-8B 里构造一条**"价值轴"**——模型内部对"当前策略最终能否达成目标"的估计方向——并证明**沿该轴引导激活**可以压制自我纠错或诱发回溯（backtracking），DPO 还会抬高被奖励行为的内部价值表示。
- **解决什么问题 / 为什么重要**：正是你方向 C 最偏好的"**机制/现象分析 + 表征几何（残差/方向结构）**"，且与"训练动态"挂钩——不是 prompt 技巧，而是定位模型内部计算的一个可干预方向。它把抽象的"模型知不知道自己在跑偏"落成残差空间里一条可读、可引导的轴，并把行为（自我纠错/回溯）与该轴因果联系起来；对你关心的"内部表征如何编码过程性判断、RL/DPO 如何重塑这些表征"有直接机制层面的启发。
- **核心方法**：① 利用 RL 轨迹数据在隐藏激活中辨识"价值轴"；② 沿轴做激活引导（activation steering），观测对自我纠错/回溯行为的因果影响；③ 对比 DPO 前后，量化被奖励行为在该轴上的内部价值表示变化。
- **主要结果**：价值轴可引导——压制自纠或诱发回溯；DPO 提升被奖励行为的内部价值表示；表明"是否走在正确轨道上"这一过程性信号在模型内部有可定位、可操纵的表示。
- **值得追问 / 局限**：① 结论主要基于 Qwen3-8B 单一模型，跨规模/跨架构的"价值轴"是否同样干净、是否同一方向，待验证；② "价值轴"与已知的真值/置信/拒答方向的纠缠程度——是否只是换名字的置信方向——需要更强的解耦实验。

## C. 机制/表征 · 神经表征中的相位重要性（表征几何，优先型）

### 5. The Importance of Phase in Neural Representations: An Internal Oppenheim-Lim Test of Image Classifiers
- 链接：https://arxiv.org/abs/2606.17037
- 作者：Alper Yıldırım
- submit 日期：2026-06-15
- **TL;DR**：自然图像里"相位携带身份、幅度信息较少"（经典 Oppenheim-Lim 现象）——本文把这一测试搬到**训练好的图像分类器内部**，发现各架构**共享一套相位/符号身份码**，但把它暴露在**不同的基（basis）**上，这个基由整流（rectification）与读出几何决定。
- **解决什么问题 / 为什么重要**：方向 C 的"**表征几何 / 内部计算结构**"一类，是难得的把信号处理经典结论用作内部探针的工作。"相位 vs 幅度"是异常干净的分解轴：它不改语义、只隔离"身份信息存在哪种几何成分里"，因此能纯粹度量网络表征对相位结构的依赖，并揭示"功能上共享、几何上各异"这一跨架构规律——对你关心的"不同模型是否学到同构表征、表征几何如何被激活函数/读出塑形"很贴。
- **核心方法**：把 Oppenheim-Lim 式的相位/幅度交换测试改造为分类器**内部**表征的探针；跨多种架构比较相位-符号身份码的存在性与其所在的基，分析整流与读出几何如何设定该基。
- **主要结果**：多种架构共享相位/符号身份编码，但暴露该编码的基随整流方式与读出几何而不同——即"功能等价、几何不等价"。
- **值得追问 / 局限**：① 结论基于图像分类器，能否迁移到序列/时序或图表征（你的主战场）尚未知；② "相位身份码"与已有的频域/纹理-形状偏置研究如何对接、是否给出新可操作量，需看正文。

## B. 应用 · 物理知识引导 LLM 的轴承故障诊断（工业监控/诊断邻域）

### 6. Progressive Knowledge-Guided Large Language Model Framework for Bearing Fault Diagnosis
- 链接：https://arxiv.org/abs/2606.16684
- 作者：Jinghan Wang, Gaoliang Peng, Yanjun Chen, Wei Zhang, Wentao Wu, Tianchen Liu（据作者背景推断为哈尔滨工业大学相关，仅供参考）
- submit 日期：2026-06-15
- **TL;DR**：从轴承运动学理论推出**物理测量描述子**，用它**渐进式地引导 LLM**做故障诊断，在四个基准上达 98.49% 准确率、并把计算成本降低约 12.6 倍。
- **解决什么问题 / 为什么重要**：当日主类缺生产级 AIOps/RCA 与 fNIRS，这篇是最贴你方向 B "**监控/诊断**"的——它处理的是设备健康监测里的故障识别，且方法上把**物理先验（运动学）显式注入**到 LLM 推断回路，而非纯数据驱动黑盒。对你思考"领域物理知识如何结构化地约束/引导大模型做时序诊断、并兼顾效率"有参考；与你横切关心的"自带结构/可解释先验"也相通。
- **核心方法**：由轴承运动学理论派生测量描述子（把故障特征频率等物理量编码为模型可用的描述）；以"渐进式知识引导"的方式把这些描述子接入 LLM 框架做诊断推断。
- **主要结果**：四个基准数据集上达 98.49% 准确率，同时相对基线计算成本下降约 12.6 倍。
- **值得追问 / 局限**：① 评测为标准轴承故障基准，跨工况/跨设备与真实噪声/变载荷下的稳健性未充分展示；② "渐进式知识引导"相对常规物理-启发特征工程 + 轻量分类器的净增益（是否值得上 LLM）需看消融——它离你真正想要的"在线时序异常/根因定位"仍有距离，仅作 B 方向占位收录。
