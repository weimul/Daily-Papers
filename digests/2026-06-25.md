## 1. Learning the Koopman Operator using Attention-Free Transformers
- 链接：https://arxiv.org/abs/2606.23957
- 作者：Mohammed Nagdi, Evangelos-Marios Nikolados, Alexey Yermakov, Mars Gao, Nathan Kutz, Filippo Menolascina
- 方向：A（连续/非线性动力学 + 无注意力隐记忆 + 长时程 rollout 漂移校正）
- **TL;DR**：给 Koopman 预测器配一个「无注意力（AFT）隐记忆块 + 动态再编码」，把非线性系统的长时程外推误差压住——AFT 用短窗口聚合历史隐状态补足局部时序上下文，再用在线变点检测把漂移的预测投影回流形。
- **解决什么 / 为什么重要**：Koopman 把非线性动力学线性化到隐空间，但一步步 rollout 时误差会指数式发散，长时程预测崩掉。这篇不是堆注意力，而是用线性时间、几乎零额外参数的方式注入「记忆」，正落在我关注的连续/非线性时序建模 + 内生结构（用 change-point 内生触发再编码，而非固定步长重置）这条线上。
- **核心方法**：AFT 块在短窗内线性地聚合过去隐状态，仅增约 30k 参数（$3d^2+T^2$，比同规模多头注意力还少），捕捉局部时序上下文；动态再编码用在线变点触发器检测隐空间漂移，把预测重新投影回流形，抑制误差累积。
- **主要结果**：在 Duffing 振子、Repressilator、IRMA 三个非线性系统上，跨 1000 步 rollout 一致地降低误差累积。
- **追问 / 局限**：(1) 变点触发的再编码阈值如何设、对噪声/缓变漂移是否会误触发或漏触发？(2) 只在低维基准系统验证，扩到高维时空场（我关心的传感网/脑信号）时 AFT 的短窗聚合是否还够用。

## 2. Weight-Space Geometry of Offline Reasoning Training
- 链接：https://arxiv.org/abs/2606.23740
- 作者：Aleksandr Nikolich, Igor Kiselev, Vladimir Platonov, Karina Romanova
- 方向：C（agent —— 训练动态 / 权重空间几何，"优先"类机制分析）
- **TL;DR**：在完全相同的数学 rollout 上，用 attention-only LoRA 训 6 种离线 RL/SFT 目标（RFT、RIFT、DFT、Offline GRPO、DPO），直接量它们的权重增量几何——结论是大多数"离线推理目标"在权重空间里几乎共线，只有 DPO 落在近正交子空间。
- **解决什么 / 为什么重要**：大家把 RFT/DFT/GRPO/DPO 当成机制不同的方法，但到底差在哪、是不是只是换了个损失壳子？这篇用「权重增量的余弦相似度」把问题落到可测的几何量上——这正是我看重的训练动态 / 表征(权重)几何视角，而非又一个刷分技巧。
- **核心方法**：固定 Qwen3-4B、固定同一批数学 rollout、固定 attention-only LoRA，只换训练目标；比较各方法相对基座的权重增量方向（余弦）与下游精度，把"机制是否真不同"还原成子空间是否正交的问题。
- **主要结果**：SFT/RFT/RIFT 的权重增量近乎共线（余弦 ≥ 0.97）、GSM8K 精度相当；DFT 偏离更远；Offline GRPO 多出一个显著正交分量；DPO 处在近正交子空间并取得最高精度（GSM8K 93.5%、AIME26 30.0%）。作者强调 DPO 用了 10× 更小的学习率，故精度差是「损失函数 + 优化器」联合作用，不能只归给损失形式。
- **追问 / 局限**：(1) 共线/正交的结论是否依赖 attention-only LoRA 这个受限参数化？放开到全量微调还成立吗？(2) DPO 的优势与小学习率纠缠，单凭权重几何无法判因——需要控学习率的消融才能把"几何差异"与"优化器差异"拆开。

## 3. Metis: Bridging Text and Code Memory for Self-Evolving Agents
- 链接：https://arxiv.org/abs/2606.24151
- 作者：Zijie Dai, Siuhin He, Hui Li, Qihui Zhou, Jiajun Li, Mingcong Song（等 12 人；含 James Cheng、Xiao Yan）
- 方向：C（agent —— 记忆机制，"优先"类）
- **TL;DR**：把 self-evolving agent 的经验记忆拆成「文本记忆」和「代码记忆」两种表示，先系统比较二者在构建成本/执行效率/可迁移性上的互补取舍，再用一个分层结构把两者合起来：文本经验分成执行计划/环境事实/常见坑，把高频复用的计划固化成可调用工具。
- **解决什么 / 为什么重要**：自进化 agent 靠"把过去执行蒸馏成经验"来变强，但经验该以什么形式存——自然语言还是可执行代码——一直没被认真比过。这篇把记忆表示当成研究对象（属于我关注的 memory 机制，而非 prompt 技巧），并给出"何时该把文本计划提升为代码工具"的内生准则。
- **核心方法**：在同一组经验上对照文本记忆与代码记忆，量化三类成本；Metis 分层组织——文本侧拆 plans / facts / pitfalls，代码侧把频繁使用的计划选择性转成可调用工具，按使用频率决定是否"代码化"。
- **主要结果**：AppWorld 基准上相对 ReAct 任务精度最高 +20.6%、执行成本最高 −22.8%；相比其它 self-evolving agent 系统，在精度 / 执行效率 / 记忆构建成本三者间取得更好平衡。
- **追问 / 局限**：(1) "高频计划→代码工具"的固化准则在长尾任务、分布漂移下会不会把过拟合的捷径也固化进来？(2) 只在 AppWorld 单一基准验证，跨环境的记忆可迁移性（论文自己强调的卖点）缺少跨 benchmark 的直接证据。
