## A. 核心方法

### 1. Explainable Anomaly Detection in 5G Networks through Continuous Time Graphs
- 链接：https://arxiv.org/abs/2611.06225
- 作者：Thomas Hoger, Philippe Owezarski
- 分类：cs.CR / cs.NE / cs.NI（pub 2026-11-04）
- **TL;DR**：把 5G 网络交互建模成动态图（连续时间图），用图学习方法做细粒度、可解释的异常检测。
- **解决什么问题 / 为什么重要**：5G 网络越来越像分布式系统，传统基于流量统计的检测难以捕捉多阶段、跨节点的复杂攻击。把交换过程形式化为动态图，可以同时保留包级语义内容、时序上下文与拓扑上下文——这正是 CTDG / 动态图在"安全监控"场景的典型落点。
- **核心方法**：提出一种将 5G 网络交换建模为动态图的形式化方案；在该表示上套用当前主流的几类动态图模型进行异常检测，并借助图结构给出可解释信号。
- **主要结果**：在该形式化上评估了多种主流动态图模型，验证了这一表示对 5G 异常检测的潜力（偏概念验证 / 可行性论证）。
- **值得追问 / 潜在局限**：文章更像"形式化 + 可行性"工作，缺乏与非图基线的强对照和统一数据集的横向评测；"可解释"具体以何种粒度（边级 / 子图级）呈现、是否经过人工可用性验证，值得追读原文确认。

### 2. LogCDM: Interpretable Log Anomaly Detection via Behavioral Graph Drift and Adaptive Signal Fusion
- 链接：https://arxiv.org/abs/2611.12775
- 作者：Suryansh Talukdar, Taha Sarwat, Jin Soung Yoo
- 分类：cs.AI（pub 2026-11-09）
- **TL;DR**：用一个 8M 级的小模型融合三路互补信号做日志异常检测，其中"行为图漂移"被证明等价于转移核之间的加权卡方散度，天然带边级可解释。
- **解决什么问题 / 为什么重要**：当前日志异常检测被 BERT 到 8B 级大模型主导，推理要 GPU，很难部署到真正产生日志的监控节点上。LogCDM 追求"小、可解释、可本地部署"——同时命中 A 方向（图结构 + 内生自解释）与 B 方向（AIOps / 日志异常）。
- **核心方法**：对每个日志会话打三路分：小型因果 Transformer 的"下一事件惊奇度"、会话自身转移图的图注意力嵌入与正常参考图的距离、以及一个转移漂移统计量（作者证明它恰好是转移核间频率加权的卡方散度，从而给出渐近零分布、长度标准化分数与可解释的逐边分解）；再用 sigmoid 门融合三路信号——在共享协方差高斯假设下该门正是贝叶斯后验，其学到的权重揭示每个数据集更依赖哪一路信号。
- **主要结果**：8.1–8.8M 参数、CPU 单会话 5.5–10.5ms、无需 GPU；F1 在 HDFS 0.984、按时间切分的 BGL 0.870、Thunderbird 0.850，与 8.1B 的 LLM 检测器仅差 0.013–0.12，并优于所有紧凑基线；消融显示结构信号在 BGL/Thunderbird 贡献 0.025–0.030 F1，在 HDFS 几乎无用（与学到的融合权重一致）。
- **值得追问 / 潜在局限**：三路信号的互补性高度依赖数据集（HDFS 上结构信号几乎无增益），"漂移=卡方散度"的等价推导依赖的分布假设在真实漂移/概念漂移下是否成立值得检验；边级解释的实际运维可用性仍需人因评估。

## B. 应用场景

### 3. MtReNIRS: A Self-Supervised Foundation Model for Transferable Neurovascular Representations
- 链接：https://arxiv.org/abs/2610.36159
- 作者：Tony Chae, Kleanthis Avramidis, Dimitra Emmanouilidou, Ivan J. Tashev
- 分类：eess.SP / q-bio.NC（pub 2026-10-26）
- **TL;DR**：用"蒙太奇感知"的掩码自编码器在 12 个公开 fNIRS 数据集上预训练，得到可跨受试者 / 任务 / 设备 / 探头布局迁移的神经血管表征基座模型。
- **解决什么问题 / 为什么重要**：fNIRS 建模长期受限于小规模、单次会话、低采样率，且采集设备与 optode 布局高度异质，导致难以判断"是否存在一个通用 fNIRS 编码器"。这正是 fNIRS / 脑功能时序这一应用方向的基础设施问题。
- **核心方法**：提出 montage-aware masked autoencoder，在 268 名受试者、567 小时录音、12 个公开数据集上预训练；通过把异质探头布局映射到共享解剖参考系，联合编码 fNIRS 的慢血流动力学特性、发色团身份与皮层位置。
- **主要结果**：在 3 个外部数据集上迁移；跨受试者性能与全监督基线持平或更好；在少样本的受试者内校准上超过既有 SOTA fNIRS 模型，且对稀疏探头布局鲁棒。
- **值得追问 / 潜在局限**：预训练数据仍以公开实验室数据为主，自然场景 / BCI 在线使用的分布漂移、以及"蒙太奇感知"映射在极端异质布局下的退化边界仍需验证；下游任务覆盖面与基线选择是否充分可追读原文。

### 4. Fast Unsupervised Anomaly Detection Methods on Software Logs — An Empirical Study
- 链接：https://arxiv.org/abs/2611.07760
- 作者：Jesse Nyyssölä, Mika Mäntylä, Yuqing Wang
- 分类：cs.SE（pub 2026-11-05）
- **TL;DR**：系统实证对比了四种快速无监督日志异常检测模型 × 三种表示 × 七个数据集，并用广义线性模型量化各因素对性能的影响。
- **解决什么问题 / 为什么重要**：实际运维里几乎拿不到标注日志，监督模型落地困难；这篇把"预处理方式、检测模型、数据集"三因素做成受控实验，直接服务于 B 方向的故障识别、根因分析与故障定位。
- **核心方法**：模型用 KMeans、IsolationForest、RarityModel、OOV Detector；表示用词、trigram、解析后事件；在 BGL/HDFS/Hadoop/Spirit/Thunderbird/Liberty/LO2Token 七个数据集上跑全组合，用 AUCROC 与 F1 度量，再用 GLM 建立因素-性能关系并分析执行时间。
- **主要结果**：跨数据集差异极大，难给普适建议（如日志解析在部分数据集提升、在另一些反而下降）；用"无异常数据"训练无监督模型通常更好但需额外成本；此前认为"打乱数据会导致数据泄漏/虚高性能"的说法在他们测试的无监督模型上**不成立**（但对同设置下的监督模型仍成立）；追求速度建议用词表示、避开 IsolationForest。
- **值得追问 / 潜在局限**：结论"因地制宜、无普适建议"对想要开箱即用管线的团队帮助有限；评测模型偏经典无监督方法，与近年基于图 / 序列的方法（如上文 LogCDM）缺乏同台对比。

## C. Agent / 机制与表征

### 5. A Geometric Invariant of Attention Predicts Head Specialization from Weights Alone
- 链接：https://arxiv.org/abs/2611.12206
- 作者：Miguel P. Bento
- 分类：cs.LG / cs.CL（pub 2026-11-09）
- **TL;DR**：推导出一个标量不变量 ρ，仅凭权重（无需前向传播）就能度量每个注意力头耦合旋转位置编码（RoPE）的能力，并预测该头是否为归纳头。
- **解决什么问题 / 为什么重要**：机制可解释性里"识别专门化的头"通常要大量前向激活分析；若能从权重几何直接判断，就开辟了"数据无关"地分析现代 LLM 的方向，命中 C 方向的表征几何 / 机制分析重点。
- **核心方法**：从注意力机制的连续对称性出发，导出标量不变量 ρ 刻画头对 RoPE 的耦合能力；全程只用权重、不跑前向。
- **主要结果**：在 4 个无 bias 的 RoPE 模型（135M–7B）上，ρ 与归纳头（机制可解释性里研究最多的电路类型）的 Spearman 相关在 -0.55 ~ -0.74；作为概念验证，仅对排名前 50% 的位置头施加 YaRN，困惑度退化小于均匀施加。代码已开源。
- **值得追问 / 潜在局限**：目前只在无 bias 的 RoPE 模型上验证，对带 bias / 非 RoPE / 其它位置编码的推广性未知；ρ 与归纳头是相关而非因果，是否能直接指导干预（而非仅诊断）仍待证。

### 6. Interpretability Is Not Model-Specific
- 链接：https://arxiv.org/abs/2611.12675
- 作者：Marcus Armstrong, Navid Ayoobi, Pradham Mummaleti, Alexander Chulzhanov, Arjun Mukherjee
- 分类：cs.AI（pub 2026-11-09）
- **TL;DR**：只用无标注提示拟合残差流之间的线性映射，就能把一个模型上找到的可解释性工具（拒绝方向、正确性方向、情感探针）迁移到另一个模型上。
- **解决什么问题 / 为什么重要**：可解释性工具通常"一个模型一套"，换模型就要重新用标注数据找方向/探针，成本高。若方向/探针能跨模型复用，机制可解释性的结论就具备了可移植性——直指 C 方向的残差流 / 机制分析。
- **核心方法**：在残差流之间拟合一个仅用无标注提示的线性映射；跨 5 个模型家族、1B–72B、base 与 instruct 共 110 对模型迁移"拒绝方向"（通过加法/消融做因果检验）和两个读出工具（正确性方向、情感探针），配特异性对照与 5 个随机种子；并证明只要两模型在映射覆盖的数据上线性对应，线性映射就会如此表现，由此导出一个无标注的覆盖度分数。
- **主要结果**：用普通问题拟合的映射能恢复目标模型自身 54% 的拒绝引导、16%–77% 的正确性增益；若加入"工具生效区域"的无标注提示，分别升至 102% 和 88%–98%，而对照方向最多恢复 1%；无标注覆盖度分数在 16000+ 次运行中能预测恢复度，并解释了此前"跨域映射失败"的报告。
- **值得追问 / 潜在局限**：迁移效果高度依赖映射拟合所用提示是否覆盖"工具生效区域"，实际新任务上如何先验地保证覆盖仍是开放问题；线性对应假设在能力差距很大的模型对（如 1B↔72B）上何时破裂值得追问。
