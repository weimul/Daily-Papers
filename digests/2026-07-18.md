## 1. GAttNHP: Group Attention Neural Hawkes Process for Extrapolation Reasoning in Temporal Knowledge Graphs
- arXiv: https://arxiv.org/abs/2607.14733
- 作者：Xiangni Tian, Kaixian Yu, Runpeng Dai, Niansheng Tang, Hongtu Zhu
- **TL;DR**：把时序知识图（TKG）的未来事件预测统一成一个连续时间点过程框架——自注意力编码长程激励、可学习 Hawkes 先验做"语义软分组"的跨链激励、非交叉分位数回归头处理重尾到达间隔，专治长尾事件链上现有模型的崩盘。
- **解决什么问题 / 为什么重要**：TKG 事件预测有三个老大难——长程时间依赖难编码、不同事件链之间的互激励/抑制在快照级模型里表达不出来、到达间隔重尾且统计稀疏使得确定性时间预测器不可靠。这正对 A 方向"时序图/事件流 + 连续时间 + temporal point process"的核心：不是把动态图当成一串静态快照，而是当成真正的连续时间点过程来建模。
- **核心方法**：三个互相咬合的组件——(1) 自注意力编码器把每条"主体-关系"链视为连续时间点过程，捕捉远端历史的持续激励；(2) 语义软分组模块把全局可学习的 Hawkes 先验转成一个解析式的跨注意力掩码，让事件链通过潜在的"组归属"共享激励模式，避免逐对计算；(3) 用非交叉分位数（NCQ）回归头替代基于均值的时间预测，给出校准且单调有序的分位数估计，在重尾到达分布下更稳。
- **主要结果**：在 6 个 TKG 基准上，实体预测与时间预测均超过 SOTA 基线；消融显示其最大增益恰恰出现在现有模型失效最严重的长尾事件链上。
- **值得追问 / 局限**：语义软分组的"组数/组归属"是数据驱动学出来的，其可解释性与对不同图规模的敏感度未展开；连续时间点过程 + 分位数回归的组合在推理与训练成本上相对快照级模型的开销，摘要未量化，落到超大规模 TKG 上的可扩展性待验证。

## 2. NeuroGRIP: Retrieval-Augmented Graph Refinement for Knowledge-Grounded EEG Seizure Diagnosis
- arXiv: https://arxiv.org/abs/2607.14314
- 作者：Lincan Li, Zheng Chen, Yushun Dong
- **TL;DR**：STGNN 学出来的 EEG 脑网络图往往含大量"数据驱动但医学上不成立"的伪连接；NeuroGRIP 用临床指南构建的知识图，通过检索给每条预测边打可信度分、剪掉不合理边，从而在提升癫痫检测精度的同时让每个预测都能落到临床证据上。
- **解决什么问题 / 为什么重要**：时空图 GNN 已推动 EEG 脑网络表征学习，但纯数据驱动学出的图结构临床可信度低、可解释性差。这篇同时命中三条线——A 的"时空图 GNN"、B 的"神经影像/脑网络"（今日无 fNIRS，以 EEG 替补）、以及横切重点"内生/自解释"（用外部知识校准而非事后归因）。
- **核心方法**：先从权威临床指南构建大规模领域知识库，用 LLM 抽取结构化生物医学实体与关系形成文本知识图（KG）作为临床先验；再做"对齐感知的查询构造"——把 STGNN 生成的 EEG 节点嵌入投影到 KG 语义空间，用 FAISS 相似检索知识三元组；每条预测边按"检索相似度 + 关系类型 + 来源可靠性"打置信分，据此剪除医学上不合理的边。
- **主要结果**：在 TUSZ 与 CHB-MIT 两个癫痫 EEG 数据集上，NeuroGRIP 不仅提升检测精度，还通过把每个预测锚定到临床验证过的知识来增强可解释性。
- **值得追问 / 局限**：KG 由 LLM 从指南抽取，抽取噪声/覆盖偏差会直接传导到"剪哪条边"，摘要未评估 KG 质量对结果的敏感度；"临床可信度提升"更多靠知识对齐论证，是否经过神经科医生的独立盲评（而非仅指标）未说明。

## 3. Scalable Training of Continuous-Time Spiking Neural Networks with Differentiable Spike-Time Discretization
- arXiv: https://arxiv.org/abs/2607.14672
- 作者：Yusuke Sakemi, Tomoya Takeuchi, Takeo Hosomi, Kazuyuki Aihara
- **TL;DR**：连续时间脉冲网络（SNN）精确放电时刻计算的显存开销随突触前脉冲排序爆炸；DSTD 把不规则的突触前脉冲映射成 M 个固定时间点上的可微加权事件，用固定网格替换"输入依赖的候选维度"，把激活显存从 O(N_out·N_in) 降到 O(N_out·M)。
- **解决什么问题 / 为什么重要**：连续时间 SNN 是事件驱动时序计算、计算神经科学与类脑硬件的天然框架，但精确 spike-time 计算的显存瓶颈让深层网络几乎训不动。这命中 A 方向"不规则采样/异步时间序列 + 连续时间模型 + 事件流"——本质是如何在保持连续时间语义的同时把不规则事件高效离散化，思路上与"把不规则时序投到固定隐点"的一类方法呼应。
- **核心方法**：面向具一般膜时间常数/突触时间常数的 leaky integrate-and-fire 神经元，提出可微分放电时刻离散化（DSTD）：把不规则突触前脉冲映射到 M 个固定时间点上的可微加权事件，准确逼近连续时间膜电位动态；再加"synfire-chain 启发的时间正则化"组织各层放电窗口，缓解死神经元、支持类流水线处理。
- **主要结果**：在稠密 LIF 层上，峰值显存最多降约 100 倍、训练时间最多降约 20 倍（相对精确 spike-time 计算）；据此得以训练 9 层卷积 SNN（CIFAR-10）与更深（20 层量级）的网络。
- **值得追问 / 局限**：固定 M 个时间点是精度/显存的核心权衡，M 偏小会牺牲对精细放电时刻的逼近，摘要未给出 M 的选取准则与在时间敏感任务上的退化曲线；结论主要在 CIFAR 类静态图像编码任务，迁到真正的异步事件流（如 DVS、神经信号）时的增益待验证。

## 4. How Far Can Root Cause Analysis Go on Real-World Telemetry Data?
- arXiv: https://arxiv.org/abs/2607.13548
- 作者：Athira Gopal, Ashwanth Krishnan
- **TL;DR**：在真实多模态遥测（指标/日志/追踪）的 OpenRCA 基准上，经典因果发现和现有 LLM 多智能体都做不好根因定位；本文提出结构化多智能体 RCA 流水线大幅超越基线，并用"逆向推理智能体"把每次失败归因为"推理缺口（证据在但没用）"或"数据歧义（证据确实缺失）"。
- **解决什么问题 / 为什么重要**：生产环境微服务故障的根因定位要在大规模多模态遥测上推理，一直顽固地难。这属于 B 方向"根因分析/AIOps/时序异常"的核心运维问题——而且它给出的诊断视角（瓶颈到底在数据还是在推理）对如何改进 AIOps 系统有直接指导意义。
- **核心方法**：结构化多智能体 RCA 流水线，支持"有领域知识"和"无知识"两种模式；关键设计是逆向推理智能体——给定正确答案，反查抽取到的异常里哪些信号支持它、并判断第一阶段是否拿到过这些信号，从而把每次失败分类为 Reasoning Gap 或 Data Ambiguity；再用自动规则挖掘从逆向推理报告里系统抽取判别规则，减少人工知识整理。
- **主要结果**：在所有配置下均显著超过 LLM 与经典基线；逆向分析揭示绝大多数失败中所需证据其实是存在的——瓶颈不是数据可得性而是智能体正确推理的能力；模型推理能力与领域知识是主要约束。
- **值得追问 / 局限**：结论"证据大多存在、瓶颈在推理"依赖 OpenRCA 这一特定基准，是否推广到证据本身更稀疏/更噪的生产遥测存疑；"逆向推理"需要已知正确答案才能归因失败类型，属离线诊断手段，如何转化为在线（无标签）时的改进闭环未展开。

## 5. xHC: Expanded Hyper-Connections
- arXiv: https://arxiv.org/abs/2607.14530
- 作者：Xiangdong Zhang, Xiaohan Qin, Sunan Zou, Tuo Dai, Xiaoming Shi 等
- **TL;DR**：超连接（HC）把 Transformer 残差流扩成 N 条并行流作为"宽度/深度之外"的记忆扩展轴，但现有方法卡在 N=4；xHC 用"时间特征增强做更丰富写回 + 稀疏残差流架构（N=16 只更新 k=4 条但保留对全残差态的稠密访问）"，首次把 HC 家族有效扩到 N>4。
- **解决什么问题 / 为什么重要**：残差流扩展被认为是一条有前景的缩放轴（N=1→4 收益大），但为什么扩到 4 以上就收益递减、成本飙升一直没讲清。这是 C 方向"表征结构/残差流/训练动态"的优先类机制工作——把"残差流该不该继续扩、卡在哪"讲成两个可定位的瓶颈并给出解法。
- **核心方法**：把瓶颈归结为两点——流数增多时写回信息不足、残差混合生成的成本随 N 立方增长；xHC 对症下药：时间特征增强提供更丰富写回，稀疏残差流架构在 N=16 中只更新 k=4 条流、同时保留对完整残差态的稠密访问，并引入对扩展残差态内存流量的控制。
- **主要结果**：在 18B 与 28B MoE 模型上带来一致的下游提升；18B MoE 上平均下游分比 mHC 高 4.0 分，而仅增加适度训练 FLOPs；缩放律实验显示 vanilla 与 mHC 需分别 1.50× 与 1.19× 的算力才能达到 xHC 同样的 loss。
- **值得追问 / 局限**："N=16 只更新 4 条"的稀疏更新如何选择被更新的流、是否引入固定偏置尚未细说；增益在 18B/28B MoE 上验证，是否在稠密模型或更大规模上保持同样的算力优势，以及对推理时的记忆带宽实际影响，值得进一步压测。

## 6. Muse: Representation Geometry of Muon Beyond Normalized Momentum
- arXiv: https://arxiv.org/abs/2607.14536
- 作者：Da Chang, Qiankun Shi, Lvgang Zhang, Di He, Yaoshuai Ma 等
- **TL;DR**：Muon 类优化器对矩阵动量做极分解，但其更新还取决于正交化之前每个参数块"怎么表示"；Muse 把这种表示选择当作一种"优化器几何"来研究，证明不同的 Frobenius 等距表示会诱导不同的极速降几何，其中较短的矩阵维度决定了支持的奇异通道数、拉回缩放与收敛界常数。
- **解决什么问题 / 为什么重要**：Muon 风格优化器现在很热，但它们的行为对"参数块表示方式"的依赖此前基本没被理论刻画。这是 C 方向"表征几何 / 训练动态 / 机制分析"的优先类工作——把优化器行为与曲率塌缩、奇异谱（Marchenko–Pastur）等表征几何量联系起来，属于机制层面的现象分析而非调参技巧。
- **核心方法**：提出 Muse——共享同一动量规则与 Newton–Schulz 后端、但在 native / nearest-square / skinny / vector 四种表示下运行的一族 Muon 优化器；每种 Frobenius 等距表示诱导一种极速降几何，较短矩阵维数决定奇异通道数、拉回缩放与随机非凸收敛界常数；在师生模型里，曲率塌缩与各向同性 Marchenko–Pastur 谱把早期耗散与"被表示的核范数/平方 Frobenius 范数之比"联系起来。
- **主要结果**：在 LLaMA2-130M 与 600M 预训练及固定动量诊断实验中，平衡的非原生表示能匹配原生表示的性能，而缩短较短维度会削弱缩放与奇异通道支持，使行为越来越像归一化动量。
- **值得追问 / 局限**：理论骨架建立在师生模型与 Frobenius 等距假设上，真实大模型里"表示选择"带来的几何差异能否稳定转化为可测收益仍需更大规模验证；四种表示的实际显存/计算开销差异，以及在非 MoE、非 LLaMA 架构上的普适性未充分讨论。
