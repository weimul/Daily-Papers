## A. 核心方法（连续时间世界模型的结构分离 · 概念瓶颈自解释的证伪）

### 1. Conservation Buys Stability and Factoring Buys Counterfactuals in Physical World Models
- 链接：https://arxiv.org/abs/2609.19674
- 作者：Yufeng Wang, Parivesh Priye, Lu Wei, Haibin Ling（4 位作者；机构未在元数据中给出）
- **TL;DR**：学习型物理模拟器有两种截然不同的失败——长时程 rollout 里误差累积漂移、以及对物理参数做干预后仍沿用训练时的旧定律；本文证明这两种失败需要两套不同的结构性修补，且二者可分离。
- **解决什么问题 / 为什么重要**：把"世界模型/连续时间动力学建模"的鲁棒性问题拆清楚——长时程稳定 ≠ 变定律泛化，二者常被混为一谈。这正落在核心方向 A 的"连续时间模型 / 结构先验"子线，并给出可操作的设计原则：想要哪种能力就显式加哪种结构，不必牺牲另一种。
- **核心方法**：用辛（symplectic）积分器演化学习到的能量，保持保守动力学的几何结构，使 rollout 在训练时域 100 倍范围内仍有界且物理合理；另一路用显式线性因子分解编码物理耦合，使模型能跟随训练中从未见过的耦合符号（反事实）。用"逐一移除/替换单个结构组件"的对照实验，证明去掉长时程稳定结构不影响反事实迁移、去掉因子分解耦合则破坏反事实但不破坏稳定——构成双分离。
- **主要结果**：辛积分保稳定的模型在 100× 训练时域仍不发散，而同容量预测器、能量正则预测器与调参后的 neural ODE 均发散；因子分解使模型能跟随未见符号的耦合，无约束参数化则锁死在训练定律。结论在三体系统之外仍成立，甚至在"物理状态需从像素推断"时也可见。
- **值得追问 / 局限**：① 双分离在更高维、更强非线性或含耗散（非保守）系统中是否仍干净可分？② 辛结构与线性因子分解都相对强，向学习型、部分可观测、含噪的真实动力学（如脑信号/传感器流）迁移时能否保持这一设计原则值得追问。

### 2. When Do Language-Grounded Explanations Help? A Graph-Bottleneck for Farm Monitoring Interpretable Sheep Facial Pain
- 链接：https://arxiv.org/abs/2609.20427
- 作者：Alam Noor, Miguel Gutiérrez Gaitán（2 位作者；机构未在元数据中给出）
- **TL;DR**：把疼痛识别模型接到临床描述子的文本嵌入上做"语言 grounding 解释"，结果发现这些注意力/门控/生成文本给出的解释几乎无意义；改用只读概念分数的概念瓶颈后，概念才真正被学到。
- **解决什么问题 / 为什么重要**：直击 A 的"内生/自解释横切"——用一个真实监控场景（羊面部疼痛评分，SPFES）严谨地证伪"注意力即解释"：这是自解释研究里最该被反复敲打的假象。同时它落在 B 的持续监控/福利评估应用面，属 A×B 交叉的方法与评测工作。
- **核心方法**：让每个检测到的面部区域对临床描述子的文本嵌入做注意力，测其解释是否成立——消融整条描述子只改变 logit 约 1e-4，最受关注线索与预测疼痛级别仅在 32.6% 区域一致。于是移除"外观旁路"，改用只读 SPFES 概念分数的概念瓶颈分类器，并用逐区域状态标注监督（图像级流程通常丢弃这些标注）。
- **主要结果**：概念瓶颈使 Cohen's κ 下降 0.05–0.10，但换来"可证明被学到"的概念：少数类疼痛指示状态以 3.5–8.3× 基率被恢复，耳/眼严重度排序无需严重度监督即涌现；仅去掉监督则 κ 不变但概念准确率跌到 0.109，说明"架构上的必要性 ≠ 语义有效性"。作者还指出临床类不均衡下"池化概念准确率"具误导性，并给出 7 方法的交叉验证基准。
- **值得追问 / 局限**：① 结论基于单一小众数据集（羊面部疼痛），向其它监控/医学模态的可推广性待验证；② "牺牲 0.05–0.10 κ 换真解释"的权衡是否值得，取决于下游是否真需要可干预的概念，实际部署中如何取舍需要场景化判断。

## B. 应用场景（AIOps 根因分析 · 脑功能：脑疾病分类与 EEG 解码）

### 3. EviRCA: Decoupling Evidence Extraction from Reasoning for Microservice Root-Cause Analysis
- 链接：https://arxiv.org/abs/2609.19825
- 作者：Yuhao Wang, Zhen Qin, Xingliang Wang, Guochang Li, Weize Li, Shuiguang Deng（6 位作者；含浙大 Shuiguang Deng 团队常见署名，机构未在元数据中明确给出）
- **TL;DR**：把 LLM 做微服务根因分析（RCA）里"检索证据 + 定位故障 + 推断根因"三合一的重活拆开——用确定性抽取阶段把原始遥测转成紧凑的多模态"证据卡"，LLM 只在结构化观测上、经少量只读工具推理，不碰原始遥测、不执行代码。
- **解决什么问题 / 为什么重要**：正中应用方向 B 的"监控告警 / 根因定位（AIOps）"。当前 agentic RCA 让一个模型边生成边执行代码去啃海量异构遥测，导致高成本、不稳定、准确率有限；本文用"证据抽取 / 推理解耦"给出一条更工程可用的路线。
- **核心方法**：系统无关的抽取阶段把原始指标、结构化 trace、机器日志转成一小组"忠实的多模态证据卡"；LLM 仅通过一组预定义只读工具在这些结构化观测上推理。作者还做了过程级失败分析，定位瓶颈所在。
- **主要结果**：在真实异构遥测基准 OpenRCA（三套企业系统）上，EviRCA 在两个不同 LLM 上达到 40.6%–43.9% 正确率，远超此前最高 15.2% 的基线，同时 token 消耗降 15–26×、执行时间降 3–20×；并能解决"需同时对时间、组件、根因联合推理"的硬案例（此前方法近乎零分）。过程分析表明瓶颈在"判断已被抽取出的证据"而非"检索证据"，说明 RCA 效果高度依赖证据抽取质量。
- **值得追问 / 局限**：① "证据卡"的抽取规则是系统无关但需人工设计的确定性流程，遇到抽取器未覆盖的新型故障/新遥测形态时会不会漏掉关键证据？② 40%+ 的正确率相对基线是大跨越，但离生产可信自动定位仍有距离，误定位的代价与人机协同边界值得追问。

### 4. HyperAMS-Net: Adaptive Multi-Scale Spatial Hypergraph Network for Brain Disorder Classification
- 链接：https://arxiv.org/abs/2609.19755
- 作者：Proloy Kumar Mondal, Md Kamran Hussin Chowdhury, Hoi Leong Lee（3 位作者；机构未在元数据中给出）
- **TL;DR**：面向脑疾病分类，提出融合自适应多尺度卷积、超图注意力、空间-通道注意力与自适应特征融合的框架，从静息态 fMRI / 结构 MRI 的功能连接与形态表征中建模高阶依赖。
- **解决什么问题 / 为什么重要**：落在应用方向 B 的"脑功能 / 神经影像时序 / 脑网络"面，且用超图（hypergraph）建高阶依赖，命中 A 的图方法面，是一篇 A×B 交叉工作——与我关注的 fNIRS / 脑网络方向邻近，可作为脑网络高阶建模的参考。
- **核心方法**：自适应多尺度卷积在多个感受野上学数据驱动权重以捕捉互补尺度模式；超图注意力经"节点—超边—节点"消息传递建模特征间高阶依赖；空间-通道注意力增强判别性特征；自适应特征融合聚合并行分支的互补信息。
- **主要结果**：在 ABIDE（自闭症）、REST-meta-MDD（重度抑郁）、ADNI（阿尔茨海默）三个基准、5 折分层交叉验证下取得 SOTA 准确率与 AUC；消融显示移除超图注意力时性能下降最大，佐证高阶依赖建模的贡献。
- **值得追问 / 局限**：① 超图结构（超边如何定义/学习）的构建细节与稳定性、以及是否引入额外过拟合风险未在摘要展开；② 三个数据集均为 MRI（fMRI/sMRI），能否迁移到 fNIRS 这类采样/通道结构不同的脑功能模态仍待检验。

### 5. Beyond Flattened Tokens: Structure-Preserving EEG Decoding with Reusable TriDim Blocks
- 链接：https://arxiv.org/abs/2609.19842
- 作者：Shiyue Su, Song Wang, Zekai Zhan, Junjie Zeng, Ziling Lu, Zongsheng Li, Xinyuan Ye, Zhiyuan Ma, Xinke Shen, Quanying Liu（10 位作者；南方科技大学 ncclab，代码开源）
- **TL;DR**：提出可复用的 TriDim 积木，显式保留 EEG 的三条轴——通道（空间）、patch 内采样位置（短时）、跨记录 patch 位置（长时），用逐轴前馈 + 跨轴注意力协调三者，堆叠成独立解码器 TriDimEEG。
- **解决什么问题 / 为什么重要**：命中 B 的脑功能时序方向。现有 EEG 架构要么用分散的专用模块、要么把结构压平成单一 token 序列，难以维持各结构的独立角色并协调其交互；本文给出一个"保持表征形状、三轴显式"的通用积木，兼顾时空结构与长程上下文。
- **核心方法**：每个 TriDim block 沿单条轴做前馈变换、并用跨轴注意力协调三轴信息交换；配多层 tri-axis readout 构成 TriDimEEG。也可直接替换现有 EEG 基础模型里的 Transformer block。
- **主要结果**：在跨被试严格评测、覆盖临床诊断 / 睡眠分期 / 运动想象 / 情绪识别的 8 个数据集上，TriDimEEG 在 15 个模型中综合最优，平均准确率相对次优提升 4.3%；把三个 EEG 基础模型的 Transformer block 换成 TriDim block，下游准确率平均相对提升 7.4%，参数量反降 17.0%–47.3%。
- **值得追问 / 局限**：① 三轴显式假设 EEG 的通道/patch 结构较规整，对通道数少、蒙太奇差异大或不规则采样的脑信号（如部分 fNIRS 设置）是否仍占优待验证；② "替换 Transformer block 即提升"的增益来源（结构先验 vs 参数效率）需要更细的归因。

## C. Agent / 机制分析（深度循环语言模型的深度利用诊断）

### 6. Beyond Depth Truncation: Controlled Evaluation of Depth Utilization in Recursive Language Models
- 链接：https://arxiv.org/abs/2609.19934
- 作者：Ha Van Dau, Thanh Tung Khuat, Nguyen Thanh Dung（3 位作者；机构未在元数据中给出）
- **TL;DR**：深度循环语言模型（反复套用一小层栈）常用"推理时截断深度、看质量随保留深度的斜率"来判断它是否真用到了深度；本文指出这个度量把三个同时被改变的因素混为一谈，并提出可拆解的深度控制协议（DCP）。
- **解决什么问题 / 为什么重要**：命中方向 C 的"机制/现象分析、训练动态、残差流结构"优先项——不是提出新 SOTA，而是把一个被广泛使用、却带缺陷的评测度量做严谨的因果诊断。截断深度会同时：减少 block 应用次数、减少"不同计算"的体量、把 readout head 推到分布外（OOD）的残差流上；观测到的斜率混杂三者，却常被当作只反映第二项。
- **核心方法**：DCP 是一套诊断组件——三个正对照分别隔离一个因子而变动其余，一个负对照把相同干预施加到 dense transformer 以排除"度量协议本身的伪影"，再加一个受控训练干预验证因果。其中最关键的对照——"跑满 block 应用预算但只执行单次不同迭代"——只有在深度权重共享架构里才严格可实现（dense 网络里重复一层会得到完全不同的模型，而非同一模型的另一种配置）。
- **主要结果**：给出把"深度是否被利用"这一标量拆成三个可分别度量的量的诊断框架，并强调只有权重共享架构能实现关键对照，从而把"斜率"背后真正的计算贡献与 OOD 伪影区分开。
- **值得追问 / 局限**：① 摘要侧重方法学与对照设计，具体在多大规模模型、多少任务上得到的定量结论仍需读正文核对；② DCP 的关键对照依赖权重共享结构，对非共享的普通深层网络其结论如何迁移、能否给出可比的"深度利用"度量值得追问。
