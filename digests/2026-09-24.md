## B. 应用场景（脑功能 / 神经影像）

### 1. AI-Driven Neural Surrogates for In Silico Design of Cognitive-Affective Neuromodulation Targets
- 链接：https://arxiv.org/abs/2609.27729
- 作者：Marco Rothermel, Madleen Stenger, Soroush Daftarian, Svenja Jule Francke, Bita Shariatpanahi, José C. García Alanis（10 位；q-bio.NC / cs.AI / eess.SY）
- **TL;DR**：受控制论启发，构建一个"AI 神经代理"框架——用 **fMRI 解码 + 深度生成模型 + 受约束的隐空间转向（latent-space steering）**，从"刺激诱发的 fMRI 快照"里提出候选表征变化、并预测其知觉效应，从而在**不做物理刺激**的前提下"在硅（in silico）"设计神经调控靶点。
- **解决什么问题 / 为什么重要**：命中应用方向 B 的神经影像 / 脑活动建模。神经精神病学的目标常不只是"解码"脑活动，而是"改变"它（如削弱负性情绪偏向或过强记忆）；本文把"提出可落地的表征目标 → 生成图像 → 行为验证"做成一个可证伪的上游流程，直接连接脑功能表示学习与临床干预设计。
- **核心方法**：以 Natural Scenes Dataset 中 4 名深度采样被试、共 3.6 万+ 图像-fMRI 观测训练被试特定模型；主模型用 VDVAE（后接 Versatile Diffusion 精修）从视觉响应皮层恢复生成结构，在隐空间做分级扰动并重建为图像；用自动评分器 + 人评（18 名被试、7,200 试次）评估情绪效价（valence）与记忆度（memorability）的位移。
- **主要结果**：两路辨识准确率 0.79–0.88（随机 0.5）；主模型中效价从 −0.61 移到 +1.03 SD、记忆度从 −1.34 移到 +1.45 SD；跨五个扰动等级，人评效价在预测方向上显著移动（线性时间校正模型斜率均值 0.038 SD/单位 alpha，95% CI 0.003–0.074，18 人中 16 人为正）；但**记忆度未可靠改变**，且极端扰动会偏离原刺激（保真度损失）。
- **值得追问 / 局限**：① 目前是**静态快照近似**（stimulus-evoked snapshot），缺乏时间动态建模，作者自陈是主要局限——脑功能"时序"维度尚未纳入；② 记忆度不可靠、自动评分器与人评基线一致性偏弱（valence r=0.30、memorability r=0.10），说明该"代理"对不同认知维度的可控性差异很大。

### 2. Deep Learning in Infant Functional Neuroimaging: Challenges, Advances, and Future Directions
- 链接：https://arxiv.org/abs/2609.26688
- 作者：Dan Hu, Jiale Cheng, Weiran Xia, Kangfu Han, Matthew Wu, Li Wang（8 位；q-bio.NC）
- **TL;DR**：系统综述**深度学习在婴儿功能性神经影像（fMRI）**中的进展——如何从"短扫描、结构化运动伪迹、扫描状态多变、脑快速成熟"这类噪声高维数据里学到发育有意义的表示，覆盖输入表示格式化、群体/个体化脑图谱、纵向轨迹预测、鲁棒且可解释的评估、以及生物学转化。
- **解决什么问题 / 为什么重要**：命中 B 的功能脑网络 / 神经影像时序。婴儿期是大规模脑网络涌现、个体化连接组签名形成的关键窗口，早期偏差可能塑造长期认知/临床结局；本文梳理了该领域从"描述性、群体级分析"向"可靠、个体化、发育根植的模型"的范式转变，对做脑功能时序 / 脑网络的人是一份有用的方法学地图。
- **核心方法**：综述性工作，按方法学环节组织——输入表示、群体与个体化脑映射、纵向轨迹预测（longitudinal forecasting）、鲁棒可解释评估、生物学翻译；强调深度学习在整合复杂时空信息、捕捉非线性快速演化组织上的能力。
- **主要结果**：指出未来进展取决于四点——更大更多样的纵向数据集、发育适配的模型设计、严格标准化的评估、以及"计算预测 + 生物机制"的整合；总体判断该领域正走向个体化、可用于神经发育风险早期精准评估的框架。
- **值得追问 / 局限**：① 综述而非新方法/新结果，缺乏统一 benchmark 上的定量对比，"哪类模型在哪类任务真正更好"仍需读正文细读；② 婴儿数据的短扫描 + 运动伪迹使"个体化纵向预测"的可靠性上限存疑，可解释性与临床可用性之间仍有较大距离。

## C. 机制 / 表征分析 + Agent（高优先级，取 4 篇）

### 3. Hidden not Deleted: How Networks Suppress Entangled Features
- 链接：https://arxiv.org/abs/2609.27593
- 作者：Akash Samanta, Manish Pratap Singh, Debasis Chaudhuri（3 位；cs.LG / cs.AI）
- **TL;DR**：线性投影式的"概念擦除（concept erasure）"假设特征占据可分子空间；本文证明在**稠密叠加（dense superposition）**下该假设失效——当两特征被压成共享单一子空间的对映对（antipodal pair）时，SOTA 线性擦除会**同时毁掉两者**；而梯度下降训练的网络用非线性方式解决此问题，但**并不唯一**：依初始化收敛到两种电路级解（作者称 **mirror 解与 shadow 解**），且两种解都会留下被擦除特征的可测残迹，仅靠"一个标量补丁"即可恢复，无需再训练。
- **解决什么问题 / 为什么重要**：正中 C 的机制/表征分析。它为近期在 **LLM unlearning（遗忘/擦除）中"抑制而非删除→被遗忘知识重现"**这一经验失效模式，给出了**机制性、经因果干预验证**的解释——把"擦除到底删没删掉"从经验现象上升为可刻画的电路结构与吸引子分岔。
- **核心方法**：在受控叠加设定下强制两特征进入共享子空间，刻画 mirror/shadow 两解随"特征纠缠度"的分岔；论证该分岔是稳定吸引子结构而非实验伪影；用**定向因果干预**证明残迹存在，并展示"单标量补丁"可恢复被擦除表示。
- **主要结果**：线性擦除在对映对下摧毁双特征；GD 网络按初始化落入 mirror 或 shadow 两类电路解；两解均保留被擦除特征的实质性可测残迹，可被单标量补丁恢复——机制上对应"抑制≠删除"的遗忘重现。
- **值得追问 / 局限**：① 结论建立在受控叠加的小规模设定，向真实大模型 unlearning 的定量外推仍需验证（作者以"镜像 LLM 经验现象"作为动机而非在大模型上直接证明）；② "单标量补丁即可恢复"意味着现有擦除方法的安全性可能被高估，但攻击者在真实系统中定位该补丁的可行性尚未讨论。

### 4. Complementary Roles of Activation and Parametric Memory in Few-Shot Learning
- 链接：https://arxiv.org/abs/2609.28250
- 作者：Miaohe Niu, Runsong Zhao, Xinyu Liu, Bo Jin, Yucheng Qiao, Chunliang Zhang（8 位；cs.CL）
- **TL;DR**：LLM 在测试期可用两种记忆存历史信息——**激活记忆（KV cache）**与**参数记忆（更新后的权重）**；本文用受控实验系统对比二者在小样本学习中的分工，并做**神经元级分析**，发现二者激活的是"不同的神经元集合"，且复合任务需要两者协同。
- **解决什么问题 / 为什么重要**：命中 Agent 方向的"优先：memory"以及机制分析。"激活记忆擅长事实召回、参数记忆擅长学新任务"是常见直觉但其相互作用不清楚；本文把这一问题落到**神经元级证据**，对 agent 长期记忆/上下文记忆的机制设计有直接启发（何时该用 KV，何时该更新参数）。
- **核心方法**：设计受控小样本任务对比两种记忆；引入复合任务 **Conditional Arithmetic** 检验协同需求；用神经元级分析比较"经激活 vs 经参数"访问同一历史信息时被激活的神经元集合，并观察二者组合时的招募模式。
- **主要结果**：① 激活记忆在事实召回上更优；② 参数记忆在任务学习上并**不稳定优于**激活记忆；③ Conditional Arithmetic 需要两者协同——模型会同时招募两套神经元；④ 单靠任一记忆机制都不足以解此复合任务。
- **值得追问 / 局限**：① 结论来自受控合成任务（如 Conditional Arithmetic），向真实长上下文 / 多轮 agent 任务的外推需验证；② "神经元集合不同"是相关性证据，两套记忆的因果性分工与容量边界（何时参数记忆才真正胜出）仍待更强干预实验。

### 5. Verifiable Hidden Dynamics Play: Generating Agentic RL Environments from Solved Mechanisms
- 链接：https://arxiv.org/abs/2609.27321
- 作者：Xinjie Shen, Wei Fan, Xudong Guo, Jianhong Tu, Yang Su, Chuqiao Kuang（8 位；cs.AI / cs.CL）
- **TL;DR**：面向"长时程、状态演化、决策相互依赖、结果延迟"的 agent 任务，提出 **VHD-Play**：**先采样并求解一个数学模型**，再由"语料接地的 setter"把其决策过程渲染成有状态工具——可执行动态与轨迹打分参照都**继承自同一个已解模型**，从而低成本量产可验证的 agentic RL 环境。
- **解决什么问题 / 为什么重要**：命中 Agent 方向的"机制/科学问题优先"（明确非 prompt 工程）。现有环境生成常"先建环境再补规则/标注"，导致动态与评估事后对齐、信号不可靠；VHD-Play **反转这一依赖**（先解出机制→再渲染环境），让结果信号天然可验证、且扩展成本极低（每个环境几美分），直击 agent 训练"环境多样性 + 可靠奖励 + 低扩展成本"的三难。
- **核心方法**：采样求解数学模型 → corpus-grounded setter 把决策过程渲染为有状态工具；可执行动态与轨迹评分参照同源；共生成 3,300 个多样 agentic 环境；对比"写成文字的问题"与"暴露/隐藏参数的有状态版本"以定位可学习差距。
- **主要结果**：在 Qwen3.6-35B-A3B 上，三个族训练把五族诊断的平均 agentic 分从 0.204 提到 0.815；对三训练族的留出实例、8 个未见机制族均有提升，并外推到通用函数调用、旅行规划、365 天电商等外部 benchmark；在 E-Commerce Bench 上无一次破产完成全部 run 并超过 Qwen3.7-Max；对比显示**大部分可学习差距在"有状态交互"而非底层解题能力**；冻结的 35B setter 可生成更大环境，规模匹配训练随机制规模/时程增长仍保留增益。
- **值得追问 / 局限**：① 环境由"可解数学模型"生成，其覆盖的任务分布与真实开放世界 agent 任务的差距、以及"可验证性"是否以牺牲多样性为代价，需看正文；② 主要结果在 Qwen 系列上，跨模型族的普适性、以及"有状态交互增益"是否随模型能力饱和仍待验证。

### 6. Nonequilibrium Phases of Repulsive Self-Attention: Chaos, Attention Condensation, and Emergent Locality
- 链接：https://arxiv.org/abs/2609.28448
- 作者：Qucheng Gao, Zuyi Yang, Xiao Chen（3 位；cond-mat.dis-nn / cond-mat.stat-mech / cs.LG）
- **TL;DR**：把一个极简循环 Transformer（$N$ 个归一化 token、$Q=K=I$、负值映射 $V=-I$）当动力系统研究：相似度注意力吸引邻近表示、负值映射又把 token 推离所选场，这一反馈会**持续重组表征几何与注意力网络**，随反馈强度 $\gamma$ 增大出现翻转分岔→周期二→混沌→簇交换/簇翻转等非平衡相。
- **解决什么问题 / 为什么重要**：命中 C 的表征几何 + 机制/现象分析。它从统计物理视角给出"自注意力更新如何塑造表征几何、何时产生局部化/凝聚/混沌"的可解析图景，把"注意力稀疏是否会冻结动力学"这类问题落成相图与标度律，对理解 Transformer 表征动力学有机制价值。
- **核心方法**：解析 + 数值研究该极简循环注意力系统；$d=2$ 时 token 落在圆上、正多边形是精确不动点，随 $\gamma$ 经翻转分岔失稳；分析有限 softmax 锐度 $\beta$ 下 $N\to\infty$ 的注意力弥散、以及 $\beta\sim N^2$ 标度下的**注意力凝聚（attention condensation）**；在硬路由极限与高维 $d=N\to\infty$ 下用高斯初值模拟考察凝聚相变。
- **主要结果**：① 温度复杂性下注意力在有限 $\beta$、$N\to\infty$ 仍保持弥散，凝聚出现在 $\beta\sim N^2$ 标度；② 硬路由极限下排斥更新放大局部扰动、路由伙伴切换弹道式传播，产生表征空间中的"蝴蝶锥（butterfly cone）"；③ 高维几何提供另一条局部化路径，$\beta=O(1)$ 处出现由动态生成的有限重叠间隙驱动的凝聚相变；④ 依 $\gamma$ 出现弥散单纯形态、共识翻转、带混沌特征的凝聚活跃路由、碎片化簇翻转等相——说明稀疏注意力可维持持续动力学而非冻结。
- **值得追问 / 局限**：① 模型极度简化（$Q=K=I$、$V=-I$、无 MLP、循环共享），与真实多层 Transformer 的表征动力学距离较大，结论更像"可解玩具模型的相图"而非对实用模型的直接刻画；② "注意力凝聚/混沌"等相在真实训练网络中是否可观测、以及对泛化/表达力的实际含义仍开放。
