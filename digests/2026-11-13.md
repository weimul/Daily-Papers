## A. 核心方法（时序图 / 动态图 / 内生可解释）

### 1. Edge-Gradient Augmentation under Reinforcement Learning for Temporal Graph
- arXiv: https://arxiv.org/abs/2611.16678 （cs.LG, cs.AI）
- 作者：Yongqing Zhou, Jiawei Chen, Wenjun Wang, Xinyu Wang 等
- **TL;DR**：把"边的出生/死亡"当作显式事件编码进时序图，再用 RL 策略自适应挑选最有信息量的边快照做增强，提升动态链接预测。
- **解决什么问题 / 为什么重要**：主流时序图方法大多直接吃原始快照序列，忽略了"边变化"本身携带的信号——而恰恰是边的生灭最能刻画演化网络的动态。把这部分信息显式用起来，对社交网络、推荐等动态链接预测是直接收益。
- **核心方法**：提出 EG-RL（edge-gradient reinforced learning）。用专门的 node/link 编码模块把 edge-gradient 事件（边增/删）编码出来；核心是一个 policy-driven 的 RL 机制，在 critic 反馈指导下动态选择并增强最有价值的边快照；整体由 node encoding、link encoding、token mixing、channel mixing 组成，经全局池化后接两层 MLP 分类。
- **主要结果**：在多个动态图数据集上 AUC-ROC 与平均精度（AP）显著提升；消融证实自适应 edge-gradient 增强和 RL 机制各自必要。
- **值得追问 / 局限**：(1) RL 挑快照引入额外训练开销与方差，相较纯 CTDG（如 TGN/TGAT）基线的"精度/算力"性价比如何未在摘要量化。(2) 把边生灭当离散事件编码，与连续时间点过程（TPP）建模相比，在高频事件流上的时间分辨率是否够。

### 2. A Dual-Branch Graph and Convolutional Network for Interpretable Movement EEG Classification
- arXiv: https://arxiv.org/abs/2611.16609 （cs.AI, cs.HC, cs.LG, eess.SP）
- 作者：Maryam Ostadsharif Memar, Behzad Nazari
- **TL;DR**：双分支（区域图分支 + EEGNet 卷积分支）解码上肢运动，图分支学到的脑区连接直接当作模型的内生、可对照解剖学的解释。
- **解决什么问题 / 为什么重要**：EEG-BCI 的深度模型普遍是黑盒，说不清"看了哪块脑区"。本文把可解释性做进结构里（self-explaining），而非事后归因——这正是横切重点里"内生可解释"的典型落点，且落在脑功能应用场景。
- **核心方法**：一支受 LGGNet 启发的 local-global 图分支，把 61 个电极按解剖分区分组、学习区域间空间关系，直接给出"模型强调了哪些脑区"；另一支 EEGNet 式卷积分支负责判别。两支融合做 movement-vs-rest 分类。用留一被试（LOSO）交叉验证评估。
- **主要结果**：Ofner 上肢数据集上跨被试平均 F1 = 0.74±0.06；更关键的是学到的图结构在所有留出被试上一致地把最强连接落在 Parietal Left Low（P1/P3），与右臂运动对侧、后顶叶上肢运动区的神经科学先验吻合——说明解释是"对得上"的。
- **值得追问 / 局限**：(1) F1≈0.74 在 BCI 里中等，可解释性是否以判别力为代价？(2) 电极到解剖分区的映射是人工先验，图分支的"解释"在多大程度上是学出来的 vs 被先验分组锁定，需要对照随机/数据驱动分区。

### 3. DySR-GNN: Dynamic Sensor-Relationship Graph Neural Network for Root Cause Analysis in Automotive HiL Multivariate Time Series
- arXiv: https://arxiv.org/abs/2611.16623 （cs.LG）
- 作者：Hamza Ouarrad, Mohammad Abboush, Andreas Rausch
- **TL;DR**：为每个时间窗独立重建一张稀疏的"传感器关系图"，让动态图消息传递直接预测故障根源位置（A×B：动态图 GNN × 根因定位）。
- **解决什么问题 / 为什么重要**：多变量监控里，故障会沿耦合信号传播，"最异常的传感器"往往不是真正的故障源。本文把动态图结构学习用在汽车 HiL 的多标签根因定位上，正好横跨方法 A（动态图）与应用 B（RCA/监控）。
- **核心方法**：每个传感器经共享时间编码器 + 可训练的传感器身份表征；据此为每个输入窗口独立重建一张稀疏关系图（window-specific structure），把这张显式图用于消息传递并直接预测根因位置，做监督式多标签识别。
- **主要结果**：在 recording-disjoint 协议下超过 CNN-LSTM、Static GCN、Static GAT 及 context-based 变体；recording 级 Macro-F1=0.9524、MCC=0.9302、严格 exact-match=0.8519。对学到图的分析显示既有持久关系也有随状态变化的关系。
- **值得追问 / 局限**：(1) 监督式多标签需要带根因标签的数据，工业现场这类标注稀缺，迁移到无监督/弱监督 AIOps 场景如何？(2) "每窗一图"的解释性虽好，但窗间图的时间一致性/稳定性未讨论，可能对噪声敏感。

## B. 应用（脑功能时序）

### 4. Your Vision Foundation Model Is Secretly an EEG Foundation Model
- arXiv: https://arxiv.org/abs/2611.17031 （cs.AI）
- 作者：Guoan Wang, Feng Liu
- **TL;DR**：把 EEG 画成图像喂给冻结的视觉基础模型（DINOv3 ViT），只学"怎么显示信号"的极少量参数，竟比七个专门的 EEG 基础模型更强。
- **解决什么问题 / 为什么重要**：EEG 基础模型砸了上千小时数据预训练，冻结特征却迁移很差，且不随规模稳定变好。本文给出反直觉发现——从没见过 EEG 的视觉模型，才是更好的冻结 EEG 编码器。对"脑信号是否真需要专用基础模型"是一次有力的现象级质疑。
- **核心方法**：SeeEEG 冻结视觉骨干，只学"如何把 EEG 显示成图像"：每个通道占一行 patch，画成固定增益的波形或频率跨 patch 高度的 scalogram，让任务相关模式落进单个 token；蒙太奇/滤波/对比度参数从标准临床蒙太奇初始化，经冻结骨干用任务损失优化——每个视图至多 1113 个可训练参数。
- **主要结果**：冻结 DINOv3 ViT-B 下，8 个临床/睡眠/情感/BCI 数据集的平衡准确率全面超过 7 个 EEG 基础模型，Cohen κ/AUROC 平均排名 1.3（最强基线 REVE 为 2.9）；显示方式零改动迁到视频编码器 V-JEPA 2.1 仍在 6/8 数据集领先；换成随机初始化 ViT-B 则平均掉 15.2 分——证明能力确实来自视觉预训练。
- **值得追问 / 局限**：(1) "渲染成图像"是否丢失了相位/高频等脑电关键信息，在更依赖时频细粒度的任务上会不会翻车？(2) 结论对"显示方式"的优化很敏感，这部分搜索成本和对新蒙太奇的泛化需进一步看。

## C. Agent（机制 / 训练动态，优先型）

### 5. Discovering Effective Agent Memory Designs through Program Evolution
- arXiv: https://arxiv.org/abs/2611.17068 （cs.CL, cs.AI）
- 作者：Xinheng Ding, Seyyed Saeid Cheshmi, Ziyang Zhang, Tairan Chen 等
- **TL;DR**：用程序进化从最小种子自动演化出"整套记忆程序"，并借此反推智能体记忆为什么有效的设计规律。
- **解决什么问题 / 为什么重要**：智能体记忆设计多靠人工拍脑袋，缺乏对"哪些设计选择真正起作用"的机制理解。本文把记忆设计当成可进化的程序来搜索，是对记忆机制的科学研究（而非 prompt 技巧），正中 C 类"优先"口径。
- **核心方法**：提出 MAPE，通过标准化生命周期接口 + "诊断-提案"迭代循环，从最小种子演化出完整记忆程序；在 LoCoMo、LongMemEval 上搜索，并把搜索目标里的 serving cost 与精度联合优化。
- **主要结果**：相比人工设计基线最高 +12% 绝对精度、仅 35% 服务成本，且跨骨干/基准可迁移。提炼出两条反复出现的有效模式：保留原始对话作为可检索证据能补回被抽取式记忆丢掉的细节；按 query 意图组合检索到的证据能让回答模型更好用上它——把该组合模块移植进 5 个现有记忆系统，5 个全部涨点。还发现优化目标会改变算力分配（省成本时把算力从构建期挪到查询期）。代码开源。
- **值得追问 / 局限**：(1) 程序进化的搜索成本本身可能很高，摘要未给搜索开销与可复现性细节。(2) 结论基于对话类长期记忆基准，是否迁移到工具调用/代码库等结构化记忆场景待验证。

### 6. Pretraining Data Statistics Shape the Phases of Learning Entity Comparison in Language Models
- arXiv: https://arxiv.org/abs/2611.16882 （cs.CL, cs.LG · NeurIPS 2026）
- 作者：Yik Siu Chan, Jing Huang, Yanai Elazar, Atticus Geiger
- **TL;DR**：实体比较任务的学习要经历"按频率→按位置→按正确答案"三个相变，而这三相是由预训练数据的统计性质因果驱动的。
- **解决什么问题 / 为什么重要**：这是一篇干净的训练动态/机制分析——用受控实验把"数据统计如何塑造模型行为相变"做成因果结论，还证明小规模合成实验能预测大模型的训练动态，对理解 LLM 学习过程很有价值。
- **核心方法**：在 5 类实体、9 个比较任务上训练 163M 小模型，混合自然语料与合成任务数据；识别三个学习阶段——早期按词频选、中期按在 prompt 中的位置选、后期才选正确答案；通过改变数据量与实体频率分布（Zipf→均匀）做因果干预。
- **主要结果**：少量合成数据只出现前两相、学不会任务；大量时直接从频率启发式跳到正解。把 Zipf 频率分布改成均匀会削弱"频率相"并加速学习。这三相也在开源的 OLMo-2 32B 中观察到——小规模受控实验可预测更大规模训练动态。
- **值得追问 / 局限**：(1) 结论建立在"实体比较"这一特定任务族上，对更复杂推理任务的相变是否同构有待验证。(2) "频率→位置→答案"的相序是否依赖架构/优化器，跨模型族的普适性还需更多证据。
