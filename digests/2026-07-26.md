## 1. Graph Distribution-valued Signals in Wasserstein Spaces: Theory and Applications
- arXiv: https://arxiv.org/abs/2607.20008
- 作者：Yanan Zhao, Feng Ji, Xingchao Jian, Wee Peng Tay（共 4 位；南洋理工 NTU 方向的图信号处理组）
- **TL;DR**：把图信号处理（GSP）里"每个顶点一个数值向量"的经典设定，推广为"每个顶点一个概率测度"——即 Wasserstein 空间中的图分布值信号（GDS），从而原生地容纳异步/不完整观测、信号相关的图结构与拓扑不确定性，并证明经典 GSP 只是其（Dirac delta）特例。
- **解决什么问题 / 为什么重要**：正对 A 方向"核心方法"，且横跨"不规则采样/异步时间序列"这一重点。经典 GSP 有两个硬约束——要求所有顶点同步完整观测、要求滤波器输入输出严格时间对齐——在真实系统里几乎不成立。本文用"顶点上放一个分布"来同时编码随机性与观测缺失，还把图结构本身建成"以信号实现为条件的分布"，为"信号相关图 + 拓扑不确定性"给出有原则的刻画。对做图上不规则/异步信号、以及需要显式建模不确定性的时空图任务，是一个可迁移的理论框架。
- **核心方法**：(1) 用 Wasserstein 空间中的概率测度表示每个顶点的信号，经典向量信号退化为 Dirac 测度；(2) 系统性地把 GSP 的基础概念（变换、滤波等）逐一对应到 GDS 版本，证明经典式子是特例；(3) 建立 GDS 变换的连续性/稳定性定理，给出对输入扰动与分布近似的稳定性保证；(4) 在图滤波器学习与异常检测等任务上做示例验证。
- **主要结果**：给出 GDS 变换的理论连续性与稳定性保证；在图滤波器学习、异常检测两类示例应用上验证有效性（摘要为方法/理论导向，未给大规模基准数字）。
- **值得追问 / 局限**：Wasserstein 空间上的测度运算计算代价与可扩展性（大图、高维分布）摘要未展开；"以信号为条件的图分布"在实践中如何估计、样本量需求如何，需看正文；示例应用偏演示性质，缺少与主流时空图/GSP 基线的系统对比。

## 2. Graph Learning on Ensembles of Cyclic Peptides: An Investigation of Molecular Ensemble Modeling
- arXiv: https://arxiv.org/abs/2607.21561
- 作者：Aaron Feller, Kris Deibler, Maxim Secor（共 3 位）
- **TL;DR**：分子性质预测常只用"单一代表构象"，但很多分子在溶液中是构象系综；EnsembleEGNN 先用共享的等变图神经网络（EGNN）编码每个构象，再用 Set Attention Block 把一组构象表示池化成单一"热力学感知"嵌入，并用多任务自监督预训练，在环肽性质预测上超过纯序列基线。
- **解决什么问题 / 为什么重要**：正对 A 方向"图表示学习/GNN"。它把"图 = 单构象"的静态假设换成"图 = 构象系综"，用集合注意力对系综做置换不变池化，是把"多视图/多状态"结构信息注入 GNN 表征的一个具体范式；对做分子/结构图、乃至更一般"同一实体多快照"的图学习者有借鉴。文中还给出一个很有说服力的对照：从零训练几乎学不动，自监督预训练是成败关键。
- **核心方法**：共享 EGNN 层逐构象编码 → Set Attention Block 池化为单一系综嵌入；在 CREMP 环肽系综数据集上用多任务自监督预训练（掩码 token 恢复 + 带噪坐标重建 + 成对距离重建）；下游可单独微调，也可与 BERT 序列编码器端到端联合训练。
- **主要结果**：在 CREMP-CycPeptMPDB 上，从零训练几乎失败（R²=0.005）；预训练后 R²=0.477、Pearson r=0.699，优于纯序列 BERT 基线（R²=0.439、r=0.667）；与 BERT 端到端联合的混合模型进一步升至 R²=0.538、r=0.737。
- **值得追问 / 局限**：结论限于环肽膜渗透性一类性质，向更广分子/更大系综的泛化未验；"系综 = 一批构象"的采样质量与数量对嵌入的影响、Set Attention 相比简单均值池化的实际增益，摘要未拆解；R²≈0.54 的绝对精度距下游可用仍有距离。

## 3. Quantifying Event-Related (De)Synchronization Variability for Brain-Computer Interface: A Unified and Interpretable Framework
- arXiv: https://arxiv.org/abs/2607.21119
- 作者：Simon Kojima, Fabien Lotte（共 2 位；Inria / 法国脑机接口方向）
- **TL;DR**：脑机接口（BCI）里 EEG 的用户内/用户间变异性是主要瓶颈；本文提出一套可解释指标，把 BCI 相关脑活动的时间、空间、频率变异性分别量化为"特征围绕其质心的离散度"，在 133 名被试的两个运动想象数据集上验证"变异性越低、BCI 性能越高"，并揭示不同分类器对变异性的敏感度差异。
- **解决什么问题 / 为什么重要**：正对 B 方向"神经影像时间序列 / brain"，且带 A 方向横切的"内生/可解释"味道——它不是事后归因，而是从设计上给出可解释、可分层的变异性度量。核心价值在于把笼统的"EEG 变异大"拆成时/空/频三个独立维度、并在试次内、试次间、试次组间多个层级量化，从而能定位"是哪种变异在拖累解码"、评估分类器对各类变异的鲁棒性，甚至把变异性写进目标函数或作为用户反馈。对 fNIRS 等其它脑功能时序的变异性刻画也有直接借鉴。
- **核心方法**：提取 EEG 特征，用合适的距离函数把变异性定义为特征围绕质心的离散度，分时间/空间/频率三类、并在试次内/试次间/试次组间多层级计算；在两个运动想象数据集（N=133）上，通过用户内与跨用户分类实验考察变异性指标与 BCI 性能的关系，并对比深度学习与黎曼几何分类器。
- **主要结果**：多数条件下变异性与性能呈负相关（约 −0.2 至 −0.4），即变异越低性能越高；指标揭示深度学习分类器对变异性的相关更弱（鲁棒性更强），黎曼类分类器更敏感；框架可用于刻画数据集变异、评估分类器敏感度、把变异性纳入目标函数或做基于变异性的用户反馈。
- **值得追问 / 局限**：相关系数量级中等（−0.2~−0.4），"低变异 → 高性能"更多是相关而非因果，能否据此干预提升仍待验；仅限运动想象范式，向其它 BCI/脑功能任务的迁移待看；"质心 + 距离"的离散度定义对距离函数选择的敏感性摘要未展开。

## 4. Transition-Related Potentials as Markers of Narrative Comprehension in Continuous EEG
- arXiv: https://arxiv.org/abs/2607.20720
- 作者：Bálint Csanády, Péter Vedres, Kristóf Zsolt Makó, Orsolya Papp-Zipernovszky, Márta Volosin, Dávid Apagyi 等（共 9 位）
- **TL;DR**：传统 ERP 靠"大量重复独立试次"压噪，却牺牲了自然情境；本文改在被试观看短片时采集连续 EEG，提取对齐到"镜头切换（cut）"的电位——转场相关电位（TRP），证明其具有典型 ERP 时程结构、且受叙事语境系统性调制，并能用一个紧凑深度网络直接从组平均连续记录中检出这些切换信号。
- **解决什么问题 / 为什么重要**：正对 B 方向"神经影像时间序列 / brain"，且方法学上把 EEG 分析从"人工打标 + 重复试次"推向"自然连续刺激 + 半自动检测"。关键点：用"电影硬切"这一天然的、密集出现的时间事件作为对齐锚点，既保留自然观影情境，又能像 ERP 一样叠加分析；并用连贯片 vs 打乱片（后切感觉输入匹配）的对照，把"叙事语境效应"与"低层感觉输入"分离。对做连续、不规则事件驱动的神经时序解析（含 fNIRS）是一个可迁移的范式。
- **核心方法**：采集观影连续 EEG，提取对齐到镜头切换的 TRP；用连贯片与场景打乱片（匹配切后感觉输入）对比以分离叙事语境效应；再训练一个紧凑 DNN，直接从组平均连续记录中恢复切换相关的 EEG signature，检验其跨片、跨被试组的泛化。
- **主要结果**：TRP 表现出典型 ERP 式时间结构、承载显著信息加工；响应受叙事语境系统性调制（连贯 vs 打乱有差异）；紧凑 DNN 检出的切换 signature 跨影片与跨被试组泛化，且复现了人工标注切换所观察到的主要语境依赖效应，构成一套半自动的自然叙事 EEG 分析框架。
- **值得追问 / 局限**：signature 主要在"组平均"连续记录上恢复，单被试/单试次级别的可检性与信噪比未展开；"镜头切换"作为事件锚点较为特殊，向更连续、边界不清的自然刺激（对话、阅读）迁移时锚点如何定义待看；叙事语境效应的神经机制解释仍偏描述性。

## 5. What, Where, and How: Disentangling the Roles of Task, Language, and Model in Code Model Representations
- arXiv: https://arxiv.org/abs/2607.21491
- 作者：Piotr Wilam（独立作者）
- **TL;DR**：独立训练的语言模型会不会以相同方式表征相同东西？本文在代码上用"概念-电路抽取"方法做了一个 2×2 设计（Python/Rust × Qwen2.5-Coder-7B/DeepSeek-Coder-6.7B），对全部语法概念逐一解剖，结论是"通用性"没有单一答案：**哪些概念**获得专属电路由任务决定（跨模型高度一致），而这些电路**在哪一层**、**如何跨层生长**由模型决定。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"里的机制/表征几何分析。它把"电路是否通用"这一含混问题，干净地拆成 What/Where/How 三问，并用最小可分离的 2×2 设计把"任务 / 语言 / 模型"三个因子的贡献解耦——这是很漂亮的机制实验设计范式。核心洞见"通用性是表征内容（What）的属性、而非计算组织（Where/How）的属性"，对表征对齐、跨模型可迁移解释、以及"不同模型是否学到同一世界模型"这类问题都有方法论意义。
- **核心方法**：扩展"概念-电路抽取"方法到 2×2（Python/Rust × Qwen/DeepSeek），对每种语言的全部语法概念（Python 58、Rust 57）在四个单元里用同一流程度量；用 Spearman 相关衡量"哪些概念获得电路"的跨模型一致性，定位电路所在层与跨层生长曲线；用消融与线性探针确认电路确有功能。
- **主要结果**：What——两模型对"哪些概念获电路"高度一致（Python ρ=0.638、Rust ρ=0.673，p<1e-7）；Where——Qwen 在晚层（约 L17-19）、DeepSeek 在 L6-7 处理概念，跨语言一致；How——Qwen 给原子概念一个 DeepSeek 没有的早期尖峰；此外 Rust 构件获得的概念专属电路是 Python 的 2-3 倍，DeepSeek 跨语言共享神经元比 Qwen 多 1.94 倍，Qwen 把 Rust 类型/trait 的九个关键字绑进一个紧簇（Jaccard 0.535 vs 零假设 0.112，p<0.001）。
- **值得追问 / 局限**：作者明确声明所有结论限于这个 2×2，"每模型剖面能否预测第三个模型"是设计中的下一步、尚未验证；仅两个 7B 级代码模型、且限语法概念，向更大模型、语义/推理概念的外推待看；概念-电路抽取方法本身的敏感性（阈值、粒度）对结论的稳健性摘要未展开。

## 6. Delivery, Not Storage: Cue-Anchored Working Memory as a Harness Property for Coding Agents
- arXiv: https://arxiv.org/abs/2607.20972
- 作者：Swapnanil Saha（独立作者）
- **TL;DR**：编码智能体现在只有一种记忆——"文档"（需刻意写入、刻意读取）；本文主张真正承重的是第二层"情境绑定的操作性事实"（gotcha、位置、局部约定），它应作为**harness 的属性**由环境在被线索触发时不自主地投递给智能体，而不是让智能体自己选择去写去读，并提出"线索锚定记忆"模型：记忆携带一等公民的触发条件（路径/符号/语义/事件/时间），由 harness 确定性求值后主动注入。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"里的 memory 机制/架构分析（非 prompt 工程）。它把 agent 记忆从"存什么、怎么检索"重构为"投递 vs 存储"的架构问题，并用认知科学（记忆卸载、附带编码、基于事件的前瞻记忆）逐条映射到架构需求，指出主动检索式记忆在长时运行智能体上几乎不被使用——这是对当前"给智能体一个记忆目录就行"主流做法的有力反驳。对做长时程编码/操作智能体、以及上下文压缩下的信息保持问题，是可操作的机制结论。
- **核心方法**：(1) 双层记忆设计理论，把"记忆卸载/附带编码/事件式前瞻记忆"映射到架构要求；(2) 线索锚定记忆模型——每条记忆带一等的触发条件，词汇可组合（路径、符号、语义、事件、时间），由 harness 确定性求值；(3) 在真实编码任务上做受控评测；(4) 一个"反复压缩"衰减探针，对比"只存在对话里"与"由 harness 拥有的存储注入"两种事实的存活率。
- **主要结果**：即便预置了记忆库，主动记忆使用近乎为零（114 回合中 0 次记忆操作）；确定性注入在每个预置运行中都成功投递、零误报；39% 的会话内重复读取是在重复"支付"压缩边界前已获取的内容；反复压缩衰减探针中，仅存于对话的十条事实在首次摘要即消失、在 108 次压缩里 106 次缺席，被剥夺的智能体只能去 grep harness 自己的会话文件重建，而从 harness 存储注入的同批事实则在全部 138 次"压缩-恢复"中完好抵达。
- **值得追问 / 局限**：评测围绕单一真实编码任务与单一 harness，结论向更多任务/其它智能体框架的外推待验；"线索锚定 + 确定性求值"的触发词汇如何避免误触发与规则膨胀，在大规模记忆库下的可维护性摘要未展开；独立作者的系统性工作，各组件（触发类型、注入策略）的独立贡献缺少消融。
