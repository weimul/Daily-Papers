## A. 核心方法（时空图信号恢复 / GNN 反事实，取 2 篇）

### 1. Unrolled Time-Varying Graph Signal Restoration under Spatiotemporal Smoothness Priors
- 链接：https://arxiv.org/abs/2610.11359
- 作者：Hayate Kojima, Hikari Noguchi, Koki Yamada, Yuichi Tanaka（4 位；eess.SP）
- **TL;DR**：传感器网络得到的信号在空间上非均匀分布、随时间观测成序列，还常带噪声与缺失；本文把"时变图信号恢复"写成一个由**空间 Sobolev 平滑 + 时间多抽头 FIR 平滑**组成的时空正则化优化问题，再把求解它的共轭梯度迭代**展开（unrolling）成可学习网络**，逐迭代学正则参数与滤波系数。
- **解决什么问题 / 为什么重要**：正中 A 的**时空图 + 不规则采样/缺失时序**。它不是黑箱回归，而是把"空间图平滑"和"时间平滑"这两个先验显式写进优化目标，再用深度算法展开（DAU）把迭代求解器变成可训练网络——既保留优化式方法的可解释结构（每层对应一次共轭梯度 + 可学参数），又获得端到端学习的拟合力。这正是"内生结构 + 可学"这条路线在时空信号上的干净样本，对缺失值插补、去噪、传感器网络重建有直接用处。
- **核心方法**：空间 Sobolev 算子 + 时间多抽头 FIR → 组合成时空正则项的恢复优化问题 → 展开共轭梯度迭代为网络、逐迭代学正则参数与滤波系数 → 支持有监督批处理、有监督在线、无监督批处理三种训练设置。
- **主要结果**：在多个合成与真实数据集上，**有监督批处理版几乎在所有情形取得最低 RMSE**；有监督在线版与无监督批处理版各自超越同设置下的现有方法，且常与现有批处理方法可比。
- **值得追问 / 局限**：① 平滑性先验（Sobolev + FIR）假设信号在图上与时间上都平滑，对突变/事件驱动的非平滑时空信号（如告警尖峰）是否仍占优，未见针对性评估；② 图结构被视为已知输入——图本身不确定或时变拓扑时，展开网络对错误图结构的鲁棒性是关键追问。

### 2. Amortized Counterfactual Prediction with Graph Neural Networks
- 链接：https://arxiv.org/abs/2610.13724
- 作者：Hendrik Stumpf, Francesco Quinzan（2 位；cs.LG / cs.AI）
- **TL;DR**：反事实推断（"若换一种处置，结果会如何"）通常要先知道因果图，而实践中常先从观测数据**估因果图再做推断**，估图误差会传到下游；本文提出 **Counterfactual Graph Neural Process（CFGNP）**，用 GNN **端到端**直接从观测数据回答反事实查询、不先估因果图，并通过把跨世界消息传递限制在"事实—反事实对应变量"之间来利用双图结构。
- **解决什么问题 / 为什么重要**：命中 A 的**图神经网络方法 + 结构化归纳偏置 + 泛化**。它的方法学看点在于：把反事实推断的"双世界（factual/counterfactual）"结构直接编码成 GNN 的消息传递约束（只允许对应变量跨世界传信息），从而把因果结构当作架构先验而非显式估计对象——这规避了"估图→推断"两段式的误差累积。对图方法在因果/反事实任务上的用法有示范价值。
- **核心方法**：双图（事实图 + 反事实图）结构 → GNN 消息传递，跨世界仅在对应 factual–counterfactual 变量间传递 → 端到端摊销（amortized）训练，直接从观测数据输出反事实预测，无需先估因果图。
- **主要结果**：在合成与图像基准上优于现有方法——在 German Loan 基准把 MSE 从 4.51×10⁻² 降到 0.19×10⁻²；在合成因果图上，**仅用 10 节点图训练的模型无需重训即可在至多 30 节点的图上保持强预测性能**（规模外推）。
- **值得追问 / 局限**：① 评测以合成/图像基准为主，真实观测数据里"对应变量"划分与无混杂假设是否成立，决定方法可用性；② 规模外推（10→30 节点）的上限与随图稠密度/异质性的衰减曲线未充分刻画，大规模稀疏图上的表现待验证。

## B. 应用场景（可解释脑解码 / 告警triage + 定位，取 2 篇）

### 3. Teaching neural decoders with language
- 链接：https://arxiv.org/abs/2610.12921
- 作者：Xuan Wen, Yonghao Song, Yuhong Zhang, Guoliang Li, Tzyy-Ping Jung, Xiaorong Gao（6 位；cs.AI）
- **TL;DR**：脑机接口（BCI）解码通常用"类别标签监督（CLS）"，把类别之间的关系隐式丢掉；本文提出 **Language as Supervision（LaS）**，把神经特征对齐到**类别的自然语言描述**、用候选文本原型（prototype）做分类，在视觉/运动/语音解码上评估七种编码器架构。
- **解决什么问题 / 为什么重要**：强命中 B 的 **neural decoding / BCI**，并横切 A 的**原型/内生可解释**。相比只给离散标签，语言描述把"类别间语义关系"显式注入监督信号，带来三个实用能力：候选集复用、跨被试/跨 session 适配、以及 **SSVEP 中对未见频率的条件解码**（zero-shot 味道）。更关键的是它自带**双向归因可视化**——对同一个"类别匹配分"同时给出神经侧与文本侧的贡献，属于"解码即解释"的内生可解释设计，而非事后归因。
- **核心方法**：学习投影把神经特征对齐到类别文本描述 → 用候选文本原型预测类别 → 七种编码器 + 头皮/颅内记录、视觉/运动/语音三域独立训练 → 双向（neural↔text）归因可视化刻画类别匹配分来源。
- **主要结果**：语音解码相对匹配的 CLS 基线**最高提升 17.15 个百分点**；表征支持候选集复用与标签监督的被试/session 适配；在 SSVEP 上实现**对未见频率的条件解码**，且正确的"类别—描述"对应是这种泛化的前提。
- **值得追问 / 局限**：① 增益高度依赖类别文本描述的质量与语义区分度——描述写得差或类别语义相近时，LaS 相对 CLS 的优势能保留多少，需系统消融；② 跨被试/跨 session 适配仍需标签监督，真正的免标注迁移未解决。

### 4. ObliVul: Alert-Conditioned Safety Obligation Modeling and Bidirectional Counterfactual Validation for Code Vulnerability Detection
- 链接：https://arxiv.org/abs/2610.11801
- 作者：Heyang Tan, Chengxin Gao, Xin Wen, Jiaxin Li, Rui Cao（5 位；cs.SE）
- **TL;DR**：真实软件开发里漏洞检测的主要难点往往不是"找出可疑代码"，而是**在静态分析产生的海量候选告警中判定哪些真正值得关注**；ObliVul 对每条候选告警从代码属性图（CPG）抽取"局部证据包（LEP）"、用 LLM 恢复候选安全义务、再把义务对齐到程序节点/依赖边/路径范围构成"局部安全义务图（LSOG）"，并做双向反事实验证来产出函数级漏洞判定。
- **解决什么问题 / 为什么重要**：虽属 cs.SE，但其核心问题——**在大量候选告警中做告警triage + 把证据定位到具体程序节点**——与 B 的**监控/告警（anomaly / root cause / 告警去噪）**高度同构：都是"报警太多、真正该看的少，还要能定位到哪个单元"。它把 LLM 的语义推断（风险源、危险操作、保护条件、状态前提）**强制对齐到图上的节点、依赖关系与传播路径**，以验证某条安全义务是否真的影响当前告警——这正是 AIOps 里"告警可信度判定 + 证据定位"所缺的可验证环节，方法思路可迁移。
- **核心方法**：每条候选告警 → 从 CPG 抽 Local Evidence Pack（LEP）→ LLM 恢复候选安全义务 → 对齐到程序节点/依赖边/路径范围构成 Local Safety Obligation Graph（LSOG）→ 双向反事实验证 + VAFI 聚合互补证据、抑制冗余弱证据 → 函数级漏洞预测。
- **主要结果**：能有效区分有漏洞版本与已修复版本，并**降低已修复代码上的持续性误报（false positive）**；消融实验确认安全义务恢复、风险响应验证、函数级推断三个组件各自必要。
- **值得追问 / 局限**：① 以漏洞检测基准评估，迁移到通用时序/日志告警triage时"安全义务→图对齐"这一范式如何重定义为通用"告警证据对齐"，需重新设计；② 依赖 LLM 恢复安全义务，义务recall不全或幻觉会直接削弱后续反事实验证的可靠性，鲁棒性边界未深究。

## C. 机制 / 表征分析（高优先级，取 2 篇，均为理论/机制）

### 5. Prediction Is Not a Sufficient Memory State
- 链接：https://arxiv.org/abs/2610.13881
- 作者：Robert Jenkinson Alvarez（1 位；cs.LG）
- **TL;DR**：一个能复现当前所有预测的记忆状态，可能已经"忘了如何从下一次观测继续学习"；本文对**精确累积学习与注意力**刻画这一区别——对平滑凸残差损失，固定维度的连续递归状态**当且仅当损失为多项式时精确存在**，并给出所需状态的精确维度与压缩误差下界。
- **解决什么问题 / 为什么重要**：强命中 C 的**记忆 / 训练动态 / 表征的理论机制**，是极干净的理论工作。它把"模型内部状态要保留什么才足以继续学习"这一含糊直觉变成可解析命题：区分"预测充分"（能复现当前预测）与"记忆充分"（能正确吸收下一次观测继续更新），并证明两者有本质缺口。对理解在线学习/序列模型的隐藏状态到底该编码什么、以及状态压缩的代价，有基础价值。
- **核心方法**：对平滑凸残差损失、无约束实特征与标签，证明固定维度连续递归状态存在 ⟺ 损失为多项式；度 D 的普通（无权）观测精确需要 r=C(d+D, D)−1 个坐标，且在固定当前预测子后仍可有 r−d 个坐标为"继续学习"所必需；非多项式损失在等预测历史上需求无界；岭回归的精确状态耗 dp+d(d+1)/2（vs. 仅预测的 dp）；给出 B-bit 压缩的平均单步误差阶 d⁻¹2^{−2B/s_d}；核注意力给出第二个精确闭包分类。
- **主要结果**：以上刻画本身即结论——明确"未来更新会揭示什么"，而非提出新回归算法或声称训练模型增益；多项式/非多项式损失、岭回归、核注意力三类都给出精确的记忆维度/闭包条件。
- **值得追问 / 局限**：① 结论建立在平滑凸残差损失 + 精确累积学习的理想设定上，对真实深层非凸网络、近似/随机优化下的"记忆充分性"外推性未知；② 给出的是精确维度/下界，距离"如何据此设计更省的序列模型状态"还隔着构造性方法这一步。

### 6. FlyHack: Stress-Testing Mechanistic Claims in a Connectome-Constrained Visual Model
- 链接：https://arxiv.org/abs/2610.13018
- 作者：Aashish Dhawan（1 位；q-bio.NC）
- **TL;DR**：连接组约束的神经网络让生物组件可直接干预，看似能给出机制性结论，但本文系统**压力测试**发现：这些结论会随**对照模型、干预方式、电路表示、训练解**而变——用果蝇运动视觉模型 flyvis 的 50 模型集成 + 任务匹配的因果 CNN 对照 + 复现干预来检验稳健性。
- **解决什么问题 / 为什么重要**：强命中 C 的**机制可解释性**，且是一篇难得的"机制方法学批判"。它不提新模型，而是拷问"连接组约束模型给出的机制结论有多可信"：很多被当作机制证据的现象（如 reverse-phi 反转）在任务匹配的 CNN 里同样出现、或强依赖刺激周期/速度；归因方法必须与干预方式匹配（held-out-mean 替换下一阶边归因 AUROC 0.970、Spearman 0.872，而零对齐评分对同一 ground truth 只有 0.933 / 0.126）。这对所有"用可解释结构声称发现了机制"的工作（含 LLM 机制可解释性）都是重要警醒。
- **核心方法**：在 flyvis（果蝇运动视觉模型）上用 50 模型集成 + 任务匹配因果 CNN 对照 + 复现干预 → 在行为层（reverse-phi 反转、对抗方向反转阈值）与机制层（边归因补丁、细胞类型集合、T4/T5 输出沉默、连接集合剪枝）分别检验结论对对照/干预/表示/集成成员的依赖。
- **主要结果**：三级 reverse-phi 反转强依赖周期与速度、且在 CNN 中也出现，两族都复现不了果蝇的 stationary-sawtooth 响应；对抗方向反转所需扰动界 flyvis 0.21–0.27、CNN 0.13–0.25，但相对更大 CNN 的差距基本消失；贪心细胞类型集合在 50 个模型中 25 个满足模型相对 T4/T5 调谐判据、但加上双侧响应幅度检验后，6 个首次成功者里只剩 2 个仍达阈值——**机制结论随表示与集成成员显著漂移**。
- **值得追问 / 局限**：① 结论为"应缩小连接组约束模型的机制声称范围"（scoped to 模型族/干预/表示/训练解），但未给出一套可操作的"稳健机制声称"判定协议，留给后续；② 结论基于单一体系（果蝇运动视觉），其"机制结论随对照/干预漂移"的教训在更大规模连接组或人工网络机制可解释性上的量级，仍需各自复核。
