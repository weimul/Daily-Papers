## A. 核心方法（神经时序点过程再评测 / 连续时间动态图异常检测，取 2 篇）

### 1. Flexible Intensities Matter: A Comprehensive Re-evaluation of Hawkes Processes and Neural Temporal Point Processes
- 链接：https://arxiv.org/abs/2611.06348
- 作者：Hendrik Mehrtens, Florian Buettner, Oliver Stegle（cs.LG / stat.ML）
- **TL;DR**：事件序列建模里，神经时序点过程（TPP）此前被报告"大幅超越"经典 Hawkes 过程，但这些对比把灵活的神经模型和**被限制到最简形式**的 Hawkes 放在一起比，且没用大规模医疗数据。本文做一次系统性公平再评测：让 Hawkes/Poisson 过程的灵活度逐级提升，和神经 TPP 在 5 个标准基准 + 两个大规模医疗任务（UK Biobank 疾病史、MIMIC-IV ICU）上以自回归下一事件预测对打。
- **解决什么问题 / 为什么重要**：正中 A 的**事件流 / temporal point process** 方向，且是方法论级的"打假 + 定位"。它回答了一个长期含糊的问题——神经 TPP 到底赢在哪里：把对数似然拆成时间项 $\log p(t)$ 与类型项 $\log p(d\mid t)$ 后，优势**几乎完全来自时间密度（事件何时发生）**，而非类型（发生的是哪类事件）。这对"要不要上神经 TPP、上哪种强度参数化"的模型选择有直接指导意义。
- **核心方法**：给 Hawkes 配上可学习的灵活 baseline 与 kernel，逐级提升灵活度 → 发现**强度参数化的灵活度**同样是此前神经 TPP 的瓶颈：一个带样条（spline）强度头的 Transformer 就能超过以往基于强度的神经 TPP、与 intensity-free 模型持平 → 在 5 基准 + UK Biobank / MIMIC-IV 上做似然分解分析，并开源统一实现框架 TorchPP。
- **主要结果**：① Hawkes 一旦配上灵活 baseline/kernel，与神经 TPP 的差距基本消失；② 灵活度优势几乎全在时间项，类型项不随灵活度提升；③ **只有在 MIMIC-IV ICU 这种复杂数据上神经 TPP 才在类型项上仍保有优势**——强调了用复杂数据集评测 TPP 的价值。
- **值得追问 / 局限**：① 结论基于自回归下一事件预测这一口径，对长程依赖、标记/类型数极大或带外生协变量的场景是否仍然"灵活度=时间项"待验证；② "神经 TPP 仅在 ICU 这类数据上赢类型项"的边界条件（数据规模、类型分布、事件稀疏性）尚未刻画成可操作判据。

### 2. Explainable Anomaly Detection in 5G Networks through Continuous Time Graphs
- 链接：https://arxiv.org/abs/2611.06225
- 作者：Thomas Hoger, Philippe Owezarski（cs.CR / cs.NE / cs.NI）
- **TL;DR**：5G 网络在设计上越来越像分布式系统，传统基于网络流的检测方法不够用。本文把 5G 网络交换**形式化为一张动态图**，在其上应用图学习（动态图/连续时间图）方法做异常检测，兼顾包级语义内容与序列/拓扑上下文。
- **解决什么问题 / 为什么重要**：同时命中 A 的**时序图 / 动态图（CTDG）** 与 B 的**监控告警 / 异常检测**。价值在"表示层"的建模选择：把网络交换建成连续时间动态图，使得既能做包级细粒度语义分析，又能捕获时序与拓扑上下文——这正是识别**多阶段攻击**所需的两类上下文，也是对"把动态图模型用到真实监控数据"的一次具体落地尝试。（与第 3 篇的区别：本文侧重 CTDG *表示/形式化* 这一方法侧，第 3 篇侧重把预训练图基础模型 *迁移适配* 到时序异常检测这一应用侧。）
- **核心方法**：提出将 5G 网络交换形式化为动态图的表示 → 在该表示上套用当前最流行的几类动态图模型 → 以此评估该形式化对 5G 异常检测的有效性与可解释性潜力。
- **主要结果**：实验表明该动态图形式化在 5G 异常检测上具备可行性与潜力，多种主流动态图模型均可在其上运行并给出可解释的检测结果（论文定位偏"证明表示有效"的探索性工作，而非刷 SOTA）。
- **值得追问 / 局限**：① 属较短的探索性工作，缺乏与非图基线的强对照与大规模多攻击类型的系统评测，"潜力"到"可部署"仍有距离；② 连续时间动态图的构建粒度（节点/边语义、时间戳分辨率）如何影响检测与可解释性，以及在高吞吐 5G 流量下的实时性开销，均未展开。

## B. 应用场景（图基础模型做时序异常检测 / 时变连接组维持跨发育期行为，取 2 篇）

### 3. Graph Foundation Models Can Become Effective Multivariate Time Series Anomaly Detectors
- 链接：https://arxiv.org/abs/2611.06441
- 作者：Zhuangyan Hu, Zhuoxuan Liang, Wei Li, Xiaohua Jia, Moustafa Youssef, Sumi Helal（cs.LG）
- **TL;DR**：多变量时序异常检测（MTSAD）要同时建模时间动态与传感器间依赖。图检测器虽显式建模传感器拓扑，却是在有限目标域数据上从头训练、易学到伪相关且无法复用可迁移先验。本文提出 **Gfm4Mtsad**，把预训练**图基础模型（GFM）** 的可迁移拓扑先验释放到 MTSAD 上。
- **解决什么问题 / 为什么重要**：命中 B 的**异常检测 / 时序告警**（监控侧），并带 A 的图结构建模味道。它要解决把 GFM 直接迁到 MTSAD 的三个障碍：跨模态的"特征-拓扑"错配、不可靠的伪异常监督、以及节点到窗口聚合时的决策畸变——对"想复用大图预训练先验、又要在真实多传感器系统上做可解释告警"的监控场景有参考价值。
- **核心方法**：**SICA**（结构-信息契约对齐）用主子空间 token 投影 + 正常先验引导的图构建 + 残差恢复，桥接连续时序与 GFM 空间、抑制伪边并保留细粒度时间细节 → **MAPS**（机制对齐伪异常筛选）做局部依赖打断、在正常边界附近挑硬负样本做定向监督 → **TGEC**（尾部门控证据校准）对齐多粒度图响应、消除节点到窗口聚合畸变，严格保序的同时精修尾部极端异常候选，给出可解释的传感器级证据。
- **主要结果**：在两种 GFM 骨干上的大量评测中，Gfm4Mtsad 的检测性能优于现有基线，并能输出可解释的"哪个传感器触发异常"的证据。
- **值得追问 / 局限**：① 论文以"优于基线"概述为主，缺少对各模块（SICA/MAPS/TGEC）单独贡献与对概念漂移/非平稳工业时序鲁棒性的系统拆解；② 依赖预训练 GFM 的拓扑先验，当目标系统拓扑与预训练分布差异大、或传感器数量级外推时，迁移收益是否保持待验证。

### 4. Learning Time-Varying Connectomes for Stable Behavior Across Development
- 链接：https://arxiv.org/abs/2611.06895
- 作者：Christof Fehrman, Jacob J. Morra, Eva A. Naumann（q-bio.NC / cs.NE）
- **TL;DR**：神经回路在发育中其规模、拓扑、几何与内在动力学都在变，却要持续维持能驱动有效行为的功能。本文问：**单一紧凑的生成式编码能否跨这些变化生成功能性的循环控制器**。基于 HyperNEAT，用一个把"发育时间"作为输入的组合式模式生成网络（CPPN）生成**随年龄变化的连接（time-varying connectome）**。
- **解决什么问题 / 为什么重要**：命中 B 的**脑网络 / 神经时间序列**，并强带 A 的"时变图 / 动态连接"味道。它研究一个有意思的科学问题——功能稳定性能否在**结构与动力学都不稳定**的前提下涌现：发育基质规定神经元出生、位置、感觉组织与内在时间常数，网络据此生成各年龄段专属连接，用于视动响应与趋光两个任务。
- **核心方法**：用 CPPN（HyperNEAT）以发育时间为输入生成年龄特异连接 → 在两种几何上不同的发育基质、两个视动任务上，对比"只在初始/成熟单一基质上优化"与"跨多个发育快照联合优化"的控制器 → 考察所得连接组随年龄的统计轨迹与对晚生神经元的依赖。
- **主要结果**：① 只在单一年龄优化的控制器换到其它年龄普遍失败；② **跨多发育快照联合优化**的控制器在训练与未见年龄上都更高、更稳；③ 仅用三个发育快照常足以覆盖整个发育区间；④ 所得连接组随年龄显著变化、并**不收敛到单一的稀疏度/权重统计轨迹**——说明功能稳定可不依赖结构或动力学稳定。
- **值得追问 / 局限**：① 工作在合成视动任务与模型回路上，距真实生物连接组数据与真实行为仍有距离，泛化到更大/真实回路待验证；② "共享时空时变连接程序"作为先验强度很高，它对任务多样性、噪声与扰动的鲁棒性，以及能否反过来解释真实发育数据，尚需实证。

## C. 机制 / Agent（MoE 路由作为推理行为接口 / 混合模型"写易读难"的记忆机制，取 2 篇；均为"优先"机制类，非 prompt 工程）

### 5. Routes of Reasoning: Reading and Reshaping Test-Time Compute in MoE Models
- 链接：https://arxiv.org/abs/2611.05919
- 作者：Shengjie Wang, Mohsen Fayyaz, Nanyun Peng（cs.AI / cs.CL / cs.LG）
- **TL;DR**：推理模型把测试期算力分配到规划、推导、验证等不同行为，却常"**overthinking**"——找到正确答案后仍长时间反复验证/重推，浪费算力甚至掉点。本文证明 **MoE 路由器**天然提供一个**免训练**的行为控制接口：既能读出当前处于哪种推理行为，又能据此改写行为。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / residual stream**（正中"优先"，非 prompt 工程）。它把"推理行为"从模糊概念做成可探测、可干预的对象：在路由器 logits 上做线性探针，预测"规划/执行/复述/事实/反思/结论"六类行为**几乎和在完整残差流上探测一样准，却只用约一半特征**，且该信号跨六个数据集五个领域可泛化——这是对"MoE 到底把什么路由信息编码进了专家选择"的机制级回答，并顺带给出轻量推理加速。
- **核心方法**：把推理轨迹切成句级片段、给每段打上六类行为标签，使每个 token 带上其片段行为 → 在路由器 logits 与残差流上分别训线性探针对比预测力 → 验证"某行为关联的专家"在跨数据集上预测同一行为 → 推理期**选择性编辑专家路由分数**来抑制 overthinking。
- **主要结果**：① 路由器 logits 探针预测行为接近残差流探针、特征量约减半；② 专家-行为关联跨六数据集/五领域泛化；③ 跨 4 模型 4 基准，路由编辑把生成 token 数中位数降 **30.4%（最高 63.3%）**，且是"解完就停"而非跳过必要步骤，**准确率跌幅从不超过 0.5 个百分点、常反而提升**。
- **值得追问 / 局限**：① 行为标签与片段切分带主观性，六类行为是否穷尽、标注噪声对探针/干预结论的影响待评估；② 方法依赖 MoE 架构的路由信号，对稠密模型不直接适用，且"编辑路由分数"对更难/更长链任务是否仍不伤正确步骤需更大规模压力测试。

### 6. Shallow Encoding Emits Deep Memories
- 链接：https://arxiv.org/abs/2611.06084
- 作者：Mingyuan Ma, Yangmin Li, Harris Nover, Zheyu Fu, Po-Han Huang, Alex Settle 等（cs.LG / cs.DC）
- **TL;DR**：混合语言模型把少量 softmax 注意力层与大量线性注意力/状态空间层交错，每层都为早先 token 维护一份记忆（KV cache 或定长 recurrent state），服务时花在这些记忆上的算力/高带宽内存超过输出所需。本文定位出两条可利用的机制性质，并据此做近无损的服务加速（SEED）。
- **解决什么问题 / 为什么重要**：命中 C 的 **memory / residual stream / 机制分析**（偏 technical report，但属"优先"的机制现象分析而非 prompt 工程）。两条性质本身就是机制洞见：① **写比读容易**——写入深层对某 token 的记忆，只需远少于"预测下一 token"的深层计算；② **recurrent state 存在 state sink**——其能量大多集中在每个头一个固定方向上的秩一项，其余是低秩工作记忆。这对理解"混合模型的记忆到底存了什么、在哪存"有直接意义。
- **核心方法**：训练深层写路径的副本（称 **emitter**），让它从更浅"锚层"的残差流写出 prompt 的深层记忆，使除最后一个 token 外所有 prompt token 只跑约 63% 的层（prefill 变浅）→ 把每个 recurrent state 存成"state sink + 低秩因子"（decode 表示变浅），并证明 Gated DeltaNet / Kimi Delta Attention / Mamba-2 的更新能精确延拓这一表示、周期性压回低秩的开环误差有与压缩次数无关的上界 → 冻结原权重、不压注意力 cache、每个生成 token 仍跑全部层。
- **主要结果**：在 30B 到 300B+ 的五个生产混合模型、六个 checkpoint 上，SEED 在 11 项官方考试上**近乎无损**；在 SGLang + NVIDIA GB300、agentic-coding trace 下，把 Qwen3.8-Flash-Next 的单卡吞吐提升 **1.2–1.4×**。
- **值得追问 / 局限**：① "写易读难"与 state sink 两条性质在不同混合架构/训练配方上的普适性需更多模型验证，emitter 训练本身的代价与泛化（跨 prompt 分布）尚待展开；② 加速评测集中在特定硬件（GB300）与 agentic-coding trace，长上下文、非编码负载下的吞吐与无损性是否保持待测。
