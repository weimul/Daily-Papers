## A. 核心方法（连续时间不规则采样 / 自解释图解释器，取 2 篇）

### 1. ContiLNN: Mitigating Slice Sampling Discontinuity with Liquid Neural Networks for Medical Image Restoration
- 链接：https://arxiv.org/abs/2610.12337
- 作者：Jialei He, Enhe Liu, Sifan Song, Pengfei Jin, Jionglong Su, Hongbin Wang（6 位；cs.CV）
- **TL;DR**：医学影像的相邻切片本应连续，但切片采样间隔不规则、各处解剖差异大；ContiLNN 用**双向闭式连续时间（Bi-CfC，液态神经网络一族）**模块做跨切片建模，用切片索引间隔去调制门控，从而在**不做数值 ODE 积分**的情况下让信息传播自适应采样变化。
- **解决什么问题 / 为什么重要**：正中 A 的「不规则采样时间序列 / 连续时间模型（Neural ODE 一族）」。它把切片序列当作一条采样不均匀的「空间时间轴」，用连续时间隐状态显式吃进「间隔」这一变量——这正是不规则采样时序建模的核心难点；而闭式 CfC 避开 ODE 求解器，兼顾连续时间表达力与工程可落地性，对把连续时间模型推广到「非均匀采样的序列 / 图信号」有方法价值。
- **核心方法**：2D 恢复骨干 + Bi-CfC 跨切片模块（切片索引间隔调制门控、局部特征与隐状态决定传播）→ 参考引导一致性对齐一阶/二阶跨切片强度差异 → 从冻结骨干蒸馏以保住面内保真。
- **主要结果**：五个随机种子下，CT 去噪 / MRI 超分 / 低计数 PET 恢复相对 Restore-RWKV 平均 PSNR 分别提升 0.19 / 1.02 / 1.25 dB，RMSE 全面更低；相近参数与算力下 Bi-CfC 优于 Bi-GRU，7 切片下延迟低 52.8%、峰值显存低 57.0%；混合间隔训练提升稀疏/不规则上下文表现。
- **值得追问 / 局限**：① 评测仍是「切片序列」这类准规则间隔，面对真正强不规则 / 大缺口（如漂移采样、长间断）时连续时间门控外推能力待验证；② CT 结果仅对一名留出患者做描述性分析，临床层面的统计证据较弱。

### 2. MPGE: A Multi-Perspective Graph Explainer for Molecular Classification Explanation
- 链接：https://arxiv.org/abs/2610.12039
- 作者：Mahtab Sarvmaili（1 位；cs.LG）
- **TL;DR**：GNN 能预测分子性质却说不清「图的哪部分支撑了这次决策」；MPGE 把**事实（prototype，保留边集）、反事实（最小改动翻转决策）、范例（非平凡删边但保持标签）** 三种视角统一进一个共享约束式，为冻结分类器同时刻画「支撑—敏感—容忍」。
- **解决什么问题 / 为什么重要**：对应 A 的「自解释 / 可解释性」横切重点——不过要**诚实说明**：MPGE 面向冻结分类器，本质仍属**后验解释**（按方向设定，纯 post-hoc 归因应降权）。它之所以仍值得一看，在于把通常割裂的事实/反事实/范例三类解释放进同一约束优化框架、并显式记录失败搜索，比单一归因图更接近「一个决策的完整可操作画像」，对图可解释性做结构化整合有参考意义。
- **核心方法**：共享约束式（预测行为 + 紧致性 + 编辑代价）→ 三套目标分别生成事实/反事实/范例；在 CF-GNNExplainer 上扩展到图分类，学对称边排序并验证离散候选；BBBP 片段后端返回 RDKit 规范化分子。
- **主要结果**：在 MUTAG / Mutagenicity / AIDS / COX2_MD / BBBP 上，成功事实掩码平均仅保留 8.6%–15.5% 的边；有界反事实覆盖率 4.8%–67.6%；范例保持覆盖率 98.9%–100%。
- **值得追问 / 局限**：① 作为冻结模型的后验解释，三视角之间的一致性与对模型真实因果机制的忠实度仍需外部验证（作者亦声明不等同化学机制）；② 反事实覆盖率区间极宽（4.8%–67.6%），在某些数据集上「找不到有界翻转删边」说明方法对部分决策几乎给不出反事实解释。

## B. 应用场景（脑功能 / 神经影像，取 2 篇；今日无 fNIRS / AIOps 新作）

### 3. MovieSTAGE: Scene, Transition, and Global Encoding for Movie-fMRI ADHD Classification
- 链接：https://arxiv.org/abs/2610.09306
- 作者：Boseong Kim, Haejun Chung, Ikbeom Jang（3 位；cs.LG）
- **TL;DR**：自然电影-fMRI 提供了时间结构化的脑动态探针，但多数模型只用整段功能连接（FC）或与叙事事件不对齐的通用时序表征；MovieSTAGE 用**多尺度**框架把「场景内超图结构 FC + 相邻场景间 FC 差异 + 全片 FC」结合起来做 ADHD 分类。
- **解决什么问题 / 为什么重要**：正中 B 的「neuroimaging time series / brain network / 脑功能」。它把「叙事事件（场景/转场）」作为对齐脑动态的结构先验，用超图神经网络刻画场景内的高阶功能连接，验证了「事件对齐的场景/转场表征」相对整段 FC 带来的增量预测价值——对把脑功能时序建模从「静态 FC」推向「事件对齐的动态脑网络」有实证意义，且与本方向的脑网络/功能连接兴趣直接相关。
- **核心方法**：场景内超图结构 FC-profile 组织（HGNN 场景编码器）+ 相邻场景无符号 FC 差异 + 全片 FC → 三分支融合；在 CMI-HBN《卑鄙的我》队列 260 人上做病例-对照 / ADHD 亚型 / 三分类，10 次分层五折交叉验证 + 配对自助与置换检验。
- **主要结果**：三类任务 AUROC 分别 0.69 / 0.73 / 0.75、平衡准确率 67.6% / 69.8% / 58.3%，均取得所评方法中最高均值；三分类下全模型优于各两分支变体，HGNN 场景编码器在同设定下优于 MLP / GAT / BNT，人工标注分段优于时长匹配随机与 GSBS 对照。
- **值得追问 / 局限**：① 结论基于单一队列单部电影（Despicable Me），跨刺激/跨队列的可迁移性未验证，平衡准确率（尤其三分类 58.3%）距离临床可用仍有距离；② 事件分段依赖人工标注，自动分段在何种粒度下仍保住增量价值是落地关键。

### 4. Cross-species representation learning aligns mouse and human neural dynamics and tracks clinical drug efficacy
- 链接：https://arxiv.org/abs/2610.11222
- 作者：Marko Tvrdic, Justin Richmond Domingo, Jae Ann Buenaluz, Jydell Ashley Palomo Penollar 等（6+ 位；q-bio.QM / cs.LG）
- **TL;DR**：临床前动物模型常难预测人类药效，神经活动是罕见的跨物种可测译介；本文用**双规则对比学习**直接从电生理数据学「按生物状态而非物种组织」的表征，对齐小鼠与人类对应状态、同时保持不同表型的分离。
- **解决什么问题 / 为什么重要**：对应 B 的 neuroimaging / neural dynamics / brain，并带有鲜明的「表征学习解决真实科学问题」色彩。它面对神经活动高维、物种/记录模态/实验情境混杂的难题，用对比学习把「保守的疾病相关结构」与「物种/模态噪声」解耦——这既是一个脑动态应用，也是一个表征几何问题（让表征按生物状态而非采集条件排布），与本方向「脑功能 + 表征」双重兴趣契合。
- **核心方法**：双规则对比学习（对齐跨物种对应状态 + 分离不同表型）→ 在冻结的跨物种表征里投影受试动物，用「向人类健康态移动的程度」追踪药效。
- **主要结果**：恢复了跨物种的保守感觉响应结构；在癫痫上解析了三种小鼠模型与异质人类患者群的不同关系；10 组模型-药物组合中，药物诱导的「朝人类健康态移动」回溯性地吻合已知临床疗效（含一例疾病特异的有害效应）；还在 Fmr1 敲除小鼠与人类 16p11.2 CNV 携带者间识别出共享的疾病相关神经动力学。
- **值得追问 / 局限**：① 药效追踪为回溯性、组合数偏少（10 组），前瞻性预测与更大样本验证仍缺；② 跨物种对齐的「保守结构」在多大程度上由对比学习的配对规则（人为定义的「对应状态」）所诱导、而非数据内在，需要对配对定义做敏感性分析。

## C. 机制 / 表征分析（高优先级，取 2 篇，均为机制 / 训练动态）

### 5. Probability-Signature Dynamics: Unpacking Modular Addition Learning Within Two-Layer Networks
- 链接：https://arxiv.org/abs/2610.11833
- 作者：Yunji Wang, Junjie Yao, Linyu Liu, Pinyan Lu, Zhi-Qin John Xu（5 位；cs.AI）
- **TL;DR**：两层网络学模数加法会长出支持精确泛化的 **Fourier 结构表征**，但「梯度训练为何、如何从数据分布中选出这些 Fourier 电路」一直不清楚；本文用**概率签名（probability signatures）**——把主导梯度交互表达为训练分布的条件统计量——给出机制解释。
- **解决什么问题 / 为什么重要**：强命中 C 的表征几何 + 训练动态 + 机制分析，纯理论、非 prompt 工程。对模数加法，概率签名恰是**循环移位算子**、被离散 Fourier 变换对角化，于是得到近似解耦的 Fourier 模态动力学——一举解释 Fourier 稀疏性、频率匹配与相位对齐的涌现。它还顺带解开一个反直觉现象：标签噪声下被污染样本早期损失反而下降更快（因为噪声增加条件标签碰撞、强化早期共享坐标的更新），把「grokking 式表征选择」落到可写出的动力学上。
- **核心方法**：用条件统计量定义概率签名 → 证明其为循环移位算子、被 DFT 对角化得解耦 Fourier 模态动力学 → 以此解释 Fourier 稀疏/频率匹配/相位对齐，并分析标签噪声下的早期共享坐标强化 → 推广到其它算子（以 XOR 为例预测并实验验证频率）。
- **主要结果**：给出 Fourier 电路涌现的分布层面机制解释，与实验一致；解释了噪声样本早期更快下降的反直觉现象；在 XOR 上成功预测被学到的频率。
- **值得追问 / 局限**：① 结论建立在两层网络 + 模数加法/XOR 这类代数结构任务上，能否推广到多层、非群结构任务（自然语言/视觉）尚是开放问题；② 「主导梯度交互 = 概率签名」是领头阶近似，高阶交互与训练后期（电路精修阶段）的动力学未覆盖。

### 6. Why On-Policy Distillation Sometimes Fails: Vanishing Learning Signals
- 链接：https://arxiv.org/abs/2610.11247
- 作者：Lei Zhao, Qichao Zhao, Bowen Zuo, Qishi Zhan（4 位；cs.LG）
- **TL;DR**：on-policy 蒸馏（OPD）能在语言模型间迁移能力，但为何有时失败并不清楚；本文发现**更大的教师反而更易早期损失停滞**（200 步后平均仅降 25.1%，而自我强化学习教师降 96.2%），并把 OPD 理想化为**小学习率极限下的连续时间动力系统**来分析。
- **解决什么问题 / 为什么重要**：命中 C 的训练动态 + 表征分析（机制导向），且连续时间动力系统视角与 A 相呼应。它不停留在「调方法」，而是追问「学习信号为何消失」：训练日志诊断显示损失仍高时、基于梯度的学习信号代理却已早衰，并在共享参数化下证明「教师足够接近初始学生」时的局部恢复保证，为自我-RL 教师的成功给出条件性解释——把蒸馏失败与「表征几乎不动」联系起来，是难得的机制级归因。
- **核心方法**：把 OPD 建模为小学习率极限的连续时间动力系统 → 训练日志诊断学习信号代理的早衰 → 在共享参数化、正则条件下证明局部恢复保证 → 用参数相对变化（0.025–0.098%）与逐层线性 CKA（>0.98）量化「表征几乎未适应」。
- **主要结果**：大教师 OPD 普遍早期损失停滞（降幅 25.1% vs 自我-RL 96.2%）；有无停滞的运行里参数变化都极小、蒸馏前后表征高度相似（CKA>0.98）；提出「有限表征适应导致学习信号坍缩」的假设并给出局部恢复的理论条件。
- **值得追问 / 局限**：① 作者明确标注多处为「相关性 / 假设」而非因果定论（诊断不能确立梯度为何变弱、表征不动与信号坍缩的因果方向待测）；② 实验以代码/数学推理为主，结论对更大规模、不同师生架构差距下的普适性仍需扩展验证。
