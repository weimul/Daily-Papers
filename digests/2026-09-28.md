## 1. More Sensors Only One Field: Rethinking Continual Spatio-Temporal Forecasting (STFO)
- 链接：https://arxiv.org/abs/2609.31325
- 作者：Lewei Xie, Haoyu Zhang, Jiajun Zhou, Yulong Chen, Guanxing Chen, Yu-An Huang 等（代码：github.com/Xielewei/Spatio-Temporal-Field-Operator）
- 方向：A（时空图 + 神经算子 + 不规则观测，正中"时空预测/连续场"核心）
- **TL;DR**：连续时空预测里，传感器网络会不断扩张，传统图式持续学习把预测表征"绑死"在当前传感器布局上，一扩传感器就改变已学的空间关系表征；作者提出 STFO，把预测知识参数化为一套**共享的"场演化算子"**，用观测/查询接口来应对布局变化。
- **解决什么 / 为什么重要**：关键洞见很对味——**传感器扩张改变的是"关于过程的证据量"，而非"要学的动力学本身"**。它用**归一化坐标聚合**把不规则的传感器历史抬升到一个固定的隐式网格上，从而在不同观测集之间复用已学的空间映射、不需要传感器专属参数；再用一个跨空间尺度的谱描述子（spectral descriptor）去调制 Fourier 传播与注意力，以适配当前空间态势。这套"把布局无关的动力学从具体采样点里解耦出来"的思路，对做节点数会变、采样不规则的动态图/时空图问题有直接借鉴。
- **核心方法**：场演化算子 + 观测/查询接口处理变布局；坐标归一化聚合把不规则历史升到固定隐式网格；谱描述子条件化 Fourier 传播与注意力；坐标解码在传感器位置查询演化后的场，并与局部历史预测融合。
- **主要结果**：在 PEMS-Stream、CA-Stream、AIR-Stream 上取得平均预测 SOTA；STFO-Large 相对 DOL 在 PEMS-Stream 上把平均 MAE 降低 8.4%、CA-Stream 上降 4.7%。
- **追问 / 局限**：(1) 把动力学假设成"布局无关的单一场"很优雅，但当传感器扩张同时伴随**真实动力学结构变化**（新区域机制不同）时，共享算子是否会欠拟合、如何与持续学习的塑性权衡值得追问。(2) 谱描述子对空间态势的刻画粒度、以及固定隐式网格分辨率对极稀疏/极密集布局的适配上限，摘要未展开。

## 2. LUCID: Learning Under Confounding for Inference and Discovery in Time Series
- 链接：https://arxiv.org/abs/2609.31315
- 作者：Mohammad Fesanghary（代码：github.com/bloomberg/causal-ts，Bloomberg）
- 方向：A（时间序列 + 因果图结构发现 + 去混杂，偏"从数据学动态结构"这条线）
- **TL;DR**：真实时间序列里普遍存在未观测共因，会诱发虚假关联被因果发现误判成直接边；LUCID 是一个**按"混杂态势"自适应的去混杂层**——先用 Marčenko–Pastur 谱路由器估计当前处于哪种混杂机制，再套用与该机制匹配的去混杂策略。
- **解决什么 / 为什么重要**：这条踩中我关心的"从时间序列里恢复图结构"，且做法克制——不绑死某个具体发现算法，而是作为一层去**包裹现有 discovery engine**。当谱显示存在普遍的因子型混杂时，它衰减因子主导的变化、从残差创新里恢复同期（lag-0）结构，并用数据驱动的"无边零假设"来校准选边。对做动态图/时空因果、需要在强共因下判"真边 vs 伪边"的场景有方法论价值。
- **核心方法**：Marčenko–Pastur 谱路由判混杂机制 → 因子型混杂下衰减因子主导变化、从创新中恢复 lag-0 结构 → 边选择对齐 data-driven edge-free null；可包裹多种发现算法。
- **主要结果**：在覆盖混杂强度/稀疏度/载荷密度/滞后结构/波动性/异质性等多轴变化的合成 OOD 基准上，取得 family-weighted 有向、含滞后的图 F1 = 0.60，比最强基线绝对高 0.19（约 +46% 相对）；在 lag-collapsed 更宽松打分下优势进一步扩大，且在间歇性、重尾混杂下稳健。
- **追问 / 局限**：(1) 主要在合成基准上验证，谱路由器对"混杂机制"的判别在真实（非因子结构）混杂下是否仍准确，需要真实数据检验。(2) 依赖 Marčenko–Pastur 的随机矩阵假设（近似独立、维度比适当），当变量强相关或样本极短时谱路由的可靠性存疑。

## 3. Bayesian Tensor Autoencoder with Physics-informed Predictive Prior for Multi-dimensional Time Series Anomaly Detection (PPPTAE)
- 链接：https://arxiv.org/abs/2609.31157
- 作者：Jianan Liu, Chunguang Li
- 方向：B（多维时间序列异常检测，正中"time-series anomaly"）
- **TL;DR**：多维时间序列本质是张量，但多数异常检测方法只面向单/多变量，处理张量时要 reshape，破坏内在相关；作者把**预测式先验**引入**重构式** AE，用张量 AE 做骨架、贝叶斯融合把"重构"和"预测"两种信息桥接起来，并把张量低秩分解当作物理定律注入先验，得到 PPPTAE。
- **解决什么 / 为什么重要**：这条正中我 B 的"时序异常检测"，且抓住一个真实工程痛点——**reshape 破坏张量内在相关**导致的性能退化。它的巧思是把重构式 AE（用当前观测重构）与预测式 AE（用历史预测当前）这两条互补信息，用贝叶斯融合而非简单拼接来结合，并用低秩分解规则约束预测先验以缓解 AE 的过泛化（把异常也重构得很好）。这套"张量结构保持 + 物理约束抑制过泛化"的范式，对我关心的多维监控信号异常检测可迁移。
- **核心方法**：张量 AE 作骨架保持多维相关 → 设计预测式先验并以贝叶斯融合并入重构式 AE（分析上可增强对正常数据的建模能力）→ 把张量低秩分解规则作为物理定律注入预测先验网络，缓解过泛化。
- **主要结果**：在多个真实数据集上验证有效性，贝叶斯融合 + 物理约束先验相对纯重构/纯预测 AE 与常规基线均有提升（摘要为定性陈述，具体数值待正文）。
- **追问 / 局限**：(1) "低秩即物理定律"是很强的先验，对本身高秩/强非线性的多维信号是否会抑制真实异常信号、造成漏检，需要看正文的秩选择与消融。(2) 摘要未给出与近期 Transformer/扩散式时序异常检测方法的直接对比，SOTA 定位与计算代价尚不清晰。

## 4. BeatGraph: Self-Supervised Heartbeat Graphs for Infant ECG Representations from the Home Environment
- 链接：https://arxiv.org/abs/2609.31546
- 作者：Mohammad Nur Hossain Khan, M. S. Krafczyk, Beverly G. Bolster, Nancy McElwain, Mark A. Hasegawa-Johnson, Bashima Islam 等
- 方向：B×A 交叉（B：生理/神经时间序列表征；A：把信号建成"图"并做图注意力传播）
- **TL;DR**：ECG 基座模型通常把信号切成定长 patch，忽略心脏结构、一个 patch 可能切断一次心跳且每 patch 心跳数随心率漂移；对心率更高、波形不同的婴儿尤其糟。BeatGraph 把**心跳本身作为表征单位**，把每个 30 秒窗口建成"心跳组成的图"。
- **解决什么 / 为什么重要**：虽然是 ECG 不是 fNIRS，但它正中我关心的两条线交叉——**生理时间序列 + 显式图结构**，而且方法论上很对味：以"事件（心跳）"而非任意 patch 作为 token，是"内生结构化表征"的一种朴素实现，对做脑网络/生理网络的"把信号先结构化再传播"有直接类比。共享心跳编码器 + 时序 Transformer + 残差图注意力层做全对全关系建模，再注意力池化出窗口嵌入；用"预测被 mask 心跳嵌入"做自监督预训练。
- **核心方法**：以心跳为单位建图（每 30s 窗口 = 一张心跳图）；共享心跳编码器从波形与心跳间隔嵌入每次心跳；Transformer + 位置编码给心跳排序；残差图注意力做全对全关系 + 注意力池化；掩码心跳嵌入预测做预训练，再各任务微调。
- **主要结果**：单一 backbone 支持睡眠-觉醒检测、婴儿状态分类、动作来源识别、情感识别，macro-F1 相对最强基线各提升 0.076–0.158；跨年龄迁移到 ZZU-pECG 儿科基准达 0.892 AUROC（与最佳自监督 ECG 模型差 0.001），在成人 PTB-XL 上线性评估亦持平——尽管只用婴儿数据预训练。并首次公开一个家庭/教室/实验室采集的婴儿 ECG 语料（143 名婴儿、3408 小时单通道）。
- **追问 / 局限**：(1) "以心跳为事件单位"依赖可靠的心跳检测/分割，噪声大的家庭环境下分割误差如何传导进图结构与下游表征，值得看鲁棒性。(2) 图注意力是全对全（窗口内所有心跳互连），对更长窗口或高心率下的可扩展性与信息冗余尚不清楚。

## 5. The Residual Stream's Effective Depth
- 链接：https://arxiv.org/abs/2609.31098
- 作者：Barak Gahtan, Ido Galil, Alex M. Bronstein
- 方向：C（表征几何 / 残差流机制诊断——"优先"类）
- **TL;DR**：作者提出**有效深度**（effective depth, $D_\text{eff}$）——把 Transformer 逐层的残差流看成一个离散时间过程，度量"表征相似度随层间距衰减"的剖面，再聚合成一个标量诊断量，用来刻画残差累积到底"用掉"了多少深度。
- **解决什么 / 为什么重要**：典型"表征几何"优先工作，直指残差流的内在结构。它给出一个可证的参照：即便是最大程度多样化的正交更新，也有闭式参考 $F_L = 2L/(L+1)<2$；而 16 个 decoder-only 模型里 15 个的默认测量都低于 $F_L$（Qwen3.5 约 32–44%、OLMo-2 约 40–41%、Pythia 约 23–28%）。作者用一系列匹配参照与控制（position-0、token 归一化、去 top-PC）说明这个"低于参照"的现象不是 BOS/持久初始态/更新幅度失衡/top-PC 伪影所致，而是**相关性残差更新的一种校准化签名**——即"深度没被浪费，只是更新彼此相关"。对理解残差流里信息如何累积/叠加很有价值。
- **核心方法**：把残差流当离散时间过程，测层间表征相似度衰减剖面并聚合成 $D_\text{eff}$；用闭式正交参照 $F_L$ 与多种匹配参照/控制隔离结构性 vs 经验性成因；用受控 residual-carry 干预验证机制；强调 $D_\text{eff}$ 是"全局累积态诊断"，非能力评分或剪枝指标。
- **主要结果**：16 个模型中 15 个默认低于 $F_L$；差距不由持久初始态或更新幅度失衡造成；token 归一化或去 top-1-PC 后 16 个模型全部低于参照；OLMo-2 该态势在训练早期建立并稳定至 5T tokens，Pythia-1.4B 则走一条递减轨迹。
- **追问 / 局限**：(1) $D_\text{eff}$ 是全局标量诊断，作者明确说它不是能力分数——那它与下游能力/可剪枝层的关系有多弱，需要更多验证才能当工具用。(2) 结论建立在 decoder-only 架构与特定相似度度量上，换度量（如 CKA/角度）或换架构（encoder、MoE）后"低于参照"的普遍性是否成立值得追问。

## 6. Probing Stability-Plasticity Tradeoffs in Agent Memory through Cognitive Experimental Paradigms (MemProbe)
- 链接：https://arxiv.org/abs/2609.30558
- 作者：Jiaqi Ding, Guorong Wu（代码：github.com/jq-ding/MemProbe）
- 方向：C（agent memory 机制/诊断——"优先"类，非 prompt 工程）
- **TL;DR**：agent 记忆系统越来越多地维护长期偏好、任务态与演化事实，但现有评测常把记忆行为压缩成"最终答案准确率"。MemProbe 借认知科学范式，把"记忆是重构性的、受干扰/来源可靠性/强化/再激活塑造"这一洞见，转成四类可复用实验范式来诊断记忆的**稳定性-可塑性权衡**。
- **解决什么 / 为什么重要**：正中"agent 机制/记忆"优先线，且方法学上跳出了"只看准确率"的窠臼。四类范式（干扰 interference、误信息 misinformation、巩固强度 consolidation strength、再巩固窗口 reconsolidation window）分别操纵"一条记忆应当被更新、保留还是标记为不确定"的时机，并把"正确率"分解成"如何更新/保留/归因/时间组织信息"的行为画像。结论很实用：**聚合分相近的系统，其行为画像可能截然不同**——这对我判断"某个记忆机制到底稳不稳、会不会被误信息污染"很有诊断价值。
- **核心方法**：把认知记忆研究洞见转为四类实验范式（干扰/误信息/巩固强度/再巩固窗口）；将 correctness 分解为更新、保留、归因、时间组织四类行为画像；在 56 集诊断套件上、统一协议下评测 6 个增量记忆系统。
- **主要结果**：聚合分数相近的系统表现出明显不同的行为画像；MemProbe 提供把"聚合性能"翻译成"可解释的记忆维护画像"的诊断透镜。
- **追问 / 局限**：(1) 56 集诊断套件规模偏小，范式设计（尤其"再巩固窗口"）对真实长程多轮 agent 的外推性需更大规模验证。(2) 认知科学范式到 LLM 记忆的映射是类比而非机制等价，"稳定性-可塑性"这类术语在 agent 语境下的操作化是否稳健，值得追问。

### 其它值得一看（同批次，未入选正文）
- **Neuralyzing the Trace: Selective Representation-Level Unlearning with Contrastive Sparse Autoencoders (SCALPEL)**（https://arxiv.org/abs/2609.31056，C/机制可解释）：指出重构式抽取存在"能量偏置"——偏好主导的背景结构而非低能量的目标特定成分，导致标准 SAE 对"单个人"这类窄目标选择性差；提出对比式 SAE（SCALPEL）学更有选择性的遗忘特征，理论上证明对比训练促成目标选择性、且选择分数可控背景知识扰动；在 TOFU（Qwen/Llama/Gemma）上显著优于 NMF 与标准 SAE 干预，与 Gradient Difference/RMU 相当。踩中"SAE/自解释 + 机制干预"优先线。
- **Towards Understanding LLM-Based Log Anomaly Detection: An Empirical Study**（https://arxiv.org/abs/2609.31371，B/AIOps）：在三个公开日志数据集上系统比较适配策略、架构、参数规模、量化设置对日志异常检测的影响；发现适配策略差异显著、模型放大收益随数据集而变、准确率相近的模型算力可差很多、低比特量化基本保留检测性能，并考察了结构/语义/标签噪声下的鲁棒性。对做监控告警/AIOps 选型有实证参考，但属实证研究非新方法，故置此。
- **Progressive Memory Transformer: Memory-Aware Attention for Time-Series**（https://arxiv.org/abs/2609.31351，A/时序表征）：给 Transformer 加"可写、窗口对齐的记忆"以显式暴露中程尺度表征，配三尺度自监督目标（token 连续性/窗口 motif/序列一致性）；在 7 个 UCR/UEA/UCI 基准 + 预测任务上，低标注（1–5%）分类强、预测有竞争力。多尺度时序表征的替补选项。
