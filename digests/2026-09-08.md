## A. 核心方法

### 1. A Comparative Study of Counterfactual Explainers for Graph Neural Networks Enabling Multiple Types of Graph Edit
- 链接：https://arxiv.org/abs/2609.05113
- 作者：Maria Myrto Villia, Filippos Gouidis, Theodore Patkos, Panos Trahanias（cs.LG）
- **TL;DR**：对 6 种 SOTA「图神经网络反事实解释器」（支持同时增删边）做统一横向评测，在真实与合成数据、二分类/多分类、图级/节点级任务上比较解释规模、覆盖率与质量，指出各方法的强弱边界。（A：图方法 × 可解释性横切；注意属反事实/post-hoc 一支，价值在系统对照而非新方法）
- **解决什么问题 / 为什么重要**：图反事实解释追求「对输入图做最小且真实的改动即翻转预测」，但支持增删两类编辑的方法仍缺乏通用高效方案，且在规模/覆盖/质量间反复权衡；一份把「谁在什么设定下更好」讲清的对照，正好对应我方向里图方法与解释性的交叉选型。
- **核心方法**：统一评测协议下比较 6 个 SOTA 反事实解释器，覆盖二分类与多分类的图分类与节点分类任务；数据集兼含真实与合成图；用「解释规模、覆盖率、质量」等定量与定性多维指标横向打分，定位各方法适用/失效区间。
- **主要结果**：作为对比研究无单一新 SOTA，结论是现有方法各有取舍——增删编辑的通用高效方案仍未成熟，规模-覆盖-质量三者难以兼顾，为后续方法设计给出明确空白点。
- **值得追问 / 局限**：① 反事实解释属 post-hoc，与我更偏好的「内生/自解释」路线仍有距离，能否把这些评测指标反过来约束内生可解释图模型的训练？② 评测多为静态图，若迁到时序/动态图（CTDG）上，「最小编辑」需同时定义在拓扑与时间维度，指标体系是否还成立？

### 2. NS-ST-GraphRAG: Neuro-Symbolic Spatio-Temporal GraphRAG for Literary Knowledge Processing
- 链接：https://arxiv.org/abs/2609.05139
- 作者：Zheng Kui Lin（cs.CL）
- **TL;DR**：把「时空图 + 神经符号约束」引入 GraphRAG——不是从单一语料级大图检索，而是按查询的时间/空间范围**选出当时有效的图状态**做动态子图检索，并用确定性约束校验与可溯证据支撑生成；配套发布古典文学多跳问答基准 Red-Chamber-QA。（A：时空/动态图 × 事件/时间演化建模）
- **解决什么问题 / 为什么重要**：长篇叙事里证据跨章节分布、人物关系随「叙事时间」演化，正确答案往往同时受时间、空间、关系约束——这与我方向「随时间演化的图状态、动态子图」概念同构，是把 CTDG 式「按时刻取图快照」思路落到检索侧的一个具体样例。
- **核心方法**：本体引导抽取 + 确定性约束检查 + 双时间坐标 + 空间场景属性 + 动态子图检索；查询到来时先按其时空范围挑选有效图状态，再在该子图上做可溯证据的生成；同时构建带「时间/空间/一般」三类问题、逐段证据跨度与确定性捷径控制的 Red-Chamber-QA 基准。
- **主要结果**：在 120 题留出集上，机械答案复现 0.733，优于冻结窗口基线 0.675 与闭卷模型 0.083（McNemar 精确检验 p=0.092，方向有利但不显著）；语义评审准确率 0.866 vs 0.850。作者也如实说明「受限类别」假设（H2）未获所交付对比支持。
- **值得追问 / 局限**：① 样本量与显著性偏弱（p=0.092、单一叙事域），跨作品/跨语言的泛化未验证；② 「按时空范围取图状态」目前依赖本体与确定性约束，能否推广到无显式本体、关系连续演化的一般 CTDG 场景是关键。

## B. 应用场景

### 3. ProCA: Progressive Contrastive Alignment for Robust EEG Visual Decoding
- 链接：https://arxiv.org/abs/2609.05094
- 作者：Kanglei Zhou, Chunyan Lan, Dongyang Li, Jun Zhu, Liyuan Wang（cs.AI）
- **TL;DR**：面向「从非侵入式脑电时序解码视觉语义」，指出用固定视觉/文本锚点做对比学习会与「随试次、被试、训练阶段漂移的 EEG 表示」错配；提出渐进式对比对齐（ProCA），把监督从冻结的视觉-语言先验逐步细化为「EEG 感知的语义关系」，并按通道/时间重要性做结构一致插值。（B：神经影像/脑功能时序，贴合我 fNIRS/脑网络方向）
- **解决什么问题 / 为什么重要**：脑信号噪声大、跨被试差异强，鲁棒对齐是高性能解码的关键；固定语义监督在 EEG 关系演化时会偏置优化、结构无关扰动会破坏语义重要成分。这类「时序脑信号 × 稳健表征对齐」的问题设定与我方向的脑功能时序建模高度一致。
- **核心方法**：模型无关框架 ProCA——① 渐进式细化类级对比监督，从冻结 VLM 先验过渡到 EEG 感知的语义关系；② 结构一致插值，按通道与时间重要性约束特征混合，避免破坏语义关键成分；并给出「固定语义监督会在 EEG 关系演化时偏置优化」的形式化分析。
- **主要结果**：在被试内、被试无关、严格跨被试迁移、持续自适应四种设定下，平均相对 Top-1/Top-5 增益分别为 7.4%/3.9%、10.0%/4.6%、**28.1%/17.8%**、16.8%/11.6%——越是严苛的跨被试/持续适应场景增益越大。
- **值得追问 / 局限**：① 「结构一致插值」依赖对通道/时间重要性的估计，估计偏差在低信噪比个体上是否反噬？② 结论基于 EEG，能否迁到 fNIRS（血氧、慢动力学、通道更稀疏）等其它脑功能时序模态仍待验证。

### 4. Adaptive Multi-Granularity Temporal Modeling for Weakly Supervised Video Anomaly Detection
- 链接：https://arxiv.org/abs/2609.05066
- 作者：Changyi Li, Yu Xiao（cs.CV / cs.AI）
- **TL;DR**：针对弱监督视频异常检测（WSVAD）中「异常时长与时序动态差异大、手工时序先验适应性差」的问题，提出跨多时间粒度的自适应时序建模：用时序细化模块建长程依赖并蒸馏稳定的视频级表示，用自适应事件分割按时序不连续性切分事件，再以基于相似度的自适应融合取代固定 top-k 聚合。（B：监控/异常检测 × 时序建模）
- **解决什么问题 / 为什么重要**：监控视频规模远超人工标注，弱监督成为主线；但主流 MIL 框架依赖僵硬的手工时序先验，难以覆盖真实异常在时长/频率上的巨大差异，导致片段级预测不稳。这正切我方向「监控告警/时序异常检测」的落地痛点。
- **核心方法**：① 时序细化模块（TRM）用动态位置编码 + 可学习 class token 建长程依赖并蒸馏全局视频级表示；② 自适应事件分割模块（ESM）经时序不连续性分析定位事件边界，把片段聚合为判别性的事件级表示；③ 自适应相似度融合动态整合片段级与事件级异常分，替代固定 top-k 启发式。
- **主要结果**：在两个基准上一致优于 SOTA（原文以「consistently outperforms」表述，未在摘要给出逐项数值）。
- **值得追问 / 局限**：① 「事件边界=时序不连续」的假设对渐变型/长持续异常是否成立？② 与告警时序（多维指标/日志事件流）场景相比，视频异常的粒度定义能否迁移到 AIOps 的根因/异常定位仍需检验。

## C. Agent（机制/科学问题优先）

### 5. Does Your Agent's Memory Survive a Model Upgrade? A Controlled Study of Memory Portability
- 链接：https://arxiv.org/abs/2609.05339
- 作者：Ankit Goyal, Jaideep Ray（cs.AI / cs.CL / cs.IR）
- **TL;DR**：一项关于「智能体记忆可移植性」的受控研究——模型升级是常态、记忆迁移却不是。同一份历史分别以长上下文原文（LC-RAW）、分块检索（RAG）、模型压缩成自然语言笔记（NOTES）、归一化到固定 schema 知识图谱（KG-fixed）四种形态保存，实测换模型后哪种记忆「扛得住」。（C：agent memory，机制/科学问题型，非 prompt 工程）
- **解决什么问题 / 为什么重要**：换模型后智能体可能「记忆还在却记不起」——新模型对旧笔记理解不同、混版嵌入破坏检索、缺原始证据则修复失败。这把「记忆表示的可移植性」做成可量化的科学问题，正是我方向 C 中「优先」的记忆机制类工作。
- **核心方法**：48 条随机化答案编码的合成历史、精确打分、两个 <10B 开源模型；对四种记忆形态做「写入方切换」「嵌入混版迁移（50/50）」「仅存储侧修复 vs 保留原始证据修复」等受控对比，并把误差诊断性分解为「构造时信息损失」与「检索失败」两部分。
- **主要结果**：固定 schema 的 KG-fixed 迁移最稳（换写入方仅 +0.0004±0.0020）；压缩 NOTES 与模型强耦合，随迁移方向不对称漂移 +9.91 / −13.28 个百分点；RAG 混版嵌入只拿到 11.90 分潜在增益中的 4.96 分，全量重嵌入才补齐。诊断归因：NOTES 缺口 80% 来自构造时信息损失，RAG 缺口 81% 来自检索失败；仅存储侧修复 NOTES 在全部 48 例都达不到 90% 恢复目标，而保留原始历史可在某方向 34/48 例成功修复。
- **值得追问 / 局限**：① 结论基于合成历史与 <10B 模型，能否外推到真实长程任务与更大模型？② 「KG-fixed 最稳」以固定 schema 为前提，开放世界里 schema 需演化时，稳态与表达力如何权衡？

### 6. Locating and Steering Refusal Beyond Attention
- 链接：https://arxiv.org/abs/2609.04721
- 作者：Preethi Carmel Bosco, Gopalakrishnan Srinivasan（cs.LG）
- **TL;DR**：Transformer 里「拒答」由残差流中单一方向支配已成安全/可解释工具的依赖前提；本文追问：换成不用注意力的状态空间模型（SSM）等架构，这个安全表示还在吗？结论是**在**——一个刚性旋转即可对齐两模型的表示空间，Transformer 上训练的有害探针能标记 SSM 的有害输入；真正随架构而变的不是「在哪施加」，而是「在哪读取」这个方向。（C：残差流/表征几何、机制分析与因果干预）
- **解决什么问题 / 为什么重要**：现有安全工具大量建立在「拒答=残差流单一方向」这一 Transformer 结论上；若换架构就得从头重建，可解释性/安全性工具的可移植性堪忧。本文用刚性旋转对齐 + 因果干预回答「安全表示是否跨架构守恒」，属我方向偏好的机制/现象型工作。
- **核心方法**：用只能重定向不能重塑空间的单一刚性旋转对齐不同模型的表示空间，验证二者确实共享表示；跨 SSM、Transformer、循环、混合四类架构做「移除对齐方向 → 模型回答本会拒答的攻击」「随机同尺度方向对照」「固定干预强度、只变估计位置」等干预，定位方向应在每层「写入点」（加回残差流之前）读取。
- **主要结果**：Transformer 探针可直接标记 SSM 有害输入，移除对齐方向显著提升越狱成功率而随机方向影响甚微；经探测器触发门施加该方向，四类架构越狱成功率均下降，SSM 上还能抵御针对防御自适应调优的攻击；关键结论是「跨架构可迁移的是方向本身，而非防御强度」，且方向须在各架构的写入点估计。
- **值得追问 / 局限**：① 刚性旋转对齐能否推广到能力/规模差异更大的模型对，还是仅在相近训练分布下成立？② 「写入点读取」的定位在深层/混合架构里是否稳定，能否据此做训练期的安全方向监测而非仅推理期干预？
