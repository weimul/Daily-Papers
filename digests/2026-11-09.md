## A. 核心方法（多模态动态图基准 / Neural-ODE 观测器 / 原型自解释，取 3 篇）

### 1. MM-DyGraph: A Dataset, Benchmark, and Model for Multimodal Dynamic Graphs
- 链接：https://arxiv.org/abs/2611.09240
- 作者：Zongyuan Wu, Pengjie Wang, Lingshan Chen, Tianhang Wan, Yuan Meng, Xin Wang（cs.AI / cs.LG）
- **TL;DR**：现实中大量动态图的节点 / 边都带文本、图像等多模态信号，但"动态图上的多模态学习"几乎没有专门的基准与方法。本文发布**首个多模态动态图学习基准 MM-DyGraph**（含多个真实数据集、细粒度时间演化、丰富多模态属性、三类评测任务），并指出**朴素特征拼接会带来"目标级不一致"**——多模态对某些预测目标有益、对另一些反而有害，据此提出**目标感知时空多模态融合 TST-MF**。
- **解决什么问题 / 为什么重要**：命中 A 的**时空图 / 动态图方法**。它把"多模态何时有用取决于具体预测目标、且随时间变化"这件事做成了可量化的基准发现，而非笼统地"多模态更好"；对任何做**时序图 / 动态图 + 异质属性**（含带文本 / 影像的脑网络、监控拓扑）的工作，提供了可直接对标的数据与融合范式。
- **核心方法**：构建覆盖多领域、带时间演化与多模态属性的真实数据集 → 设三类评测任务跑代表性 SOTA 动态图方法，暴露"拼接导致目标级不一致" → 提出 **TST-MF**：把多模态融合同时**条件化于"预测目标"与"时空关系"**，实现随上下文自适应的跨模态交互、得到面向特定目标的表征。
- **主要结果**：在多数据集多任务上，TST-MF 取得稳健且有竞争力的性能，在多模态设定下相对基线有明显增益；基准系统性揭示"模态信息量依赖目标且随时间漂移"。
- **值得追问 / 局限**：① 摘要未给与各单任务 SOTA 的逐项数值，"目标感知"相对简单门控 / 注意力融合的增益幅度需看正文；② "目标级不一致"是否在**连续时间动态图（CTDG）** 这类更细粒度事件流设定下同样成立、TST-MF 能否迁移到纯事件时间戳输入，论文以离散快照式动态图为主。

### 2. Provable State Estimation with Recurrent Models
- 链接：https://arxiv.org/abs/2611.09217
- 作者：Vincent Andrieu, Pauline Bernard, Lucas Brivadis, Laurent Praly, Christian Wolf（cs.LG / math.OC）
- **TL;DR**：循环模型做状态估计经验上很成功，却缺收敛性与鲁棒性的形式保证。本文从**非线性观测器理论**切入：把 RNN 视为连续潜在动力学（**Neural ODE**）的时间离散，证明只要对潜在流施加**收缩（contraction）条件**，就存在把真实物理状态光滑、单射地嵌入潜空间的映射；此时 RNN 就是一个**可调观测器**——只调一个标量增益放大潜向量场，估计误差即可**指数速率**收敛到零的任意小邻域。
- **解决什么问题 / 为什么重要**：命中 A 的 **Neural ODE / 连续时间模型**，并与机制分析交叉。它给"用循环 / 连续时间模型做状态估计"补上了可证明的地基，把深度序列模型与经典观测器理论打通；对任何**从不规则 / 高维观测恢复低维潜在动力学**（含脑 / 神经潜态、传感时序）、又关心"估计是否可证明收敛"的工作有方法学价值。
- **核心方法**：将 RNN 框为 Neural ODE 的离散化 → 证明潜在流收缩 ⇒ 真实状态到潜空间的光滑单射嵌入存在 → 证明"增益放大潜向量场 ⇒ 误差指数收敛" → 给出解码潜态所需 **MLP 复杂度的定量界**，并把保证扩展到**离散时间残差 RNN**实现 → 真实移动机器人任务上验证。
- **主要结果**：可证明收缩的模型在真实机器人状态估计上**优于 vanilla GRU 且训练显著更稳**；一个有意思的现象——**无约束 GRU 在该任务上也会自发收敛到收缩动力学**，提示"收缩性是训练良好的序列模型的一种涌现性质"。
- **值得追问 / 局限**：① 保证建立在"潜在流收缩 + 发射单射"等假设上，观测噪声强、系统非收缩或不可观测时能走多远未明；② "收缩是涌现性质"目前仅在单个机器人任务上观察到，跨任务 / 更高维系统是否普遍成立、是否可作为正则直接施加，待进一步验证。

### 3. Robust Deep Prototype Classifiers via Lipschitz Training
- 链接：https://arxiv.org/abs/2611.09327
- 作者：Adia Khalid Khan, Lukas Gehring, Benjamin Paaßen（cs.LG / cs.AI）
- **TL;DR**：鲁棒性与可解释性相关——对不可察觉扰动就改预测的模型，与人类可识别特征不一致、故不可解释。**原型分类器（如 GLVQ）** 通过"把输入与原型样本比较"的决策方式天然自解释，且其假设间隔给出**闭式鲁棒性证书**；但高维数据上它们需要深嵌入网络提精度，而无约束网络会把微小输入扰动放大成嵌入空间的大攻击，使证书失效。本文用一条定理闭合这个缺口：若嵌入网络在某点局部 **L-Lipschitz**、分类器在其嵌入处 ε-鲁棒，则整模型在输入空间 **ε/L-鲁棒**，并据此提出 **Lipschitz 训练**方案。
- **解决什么问题 / 为什么重要**：命中 A 的**内生 / 自解释**横切重点（原型 / prototype-based，非 post-hoc 归因）。它直面"自解释的浅层原型头 + 深嵌入"这一常见组合为何在高维上丢掉鲁棒性保证的结构性问题，把鲁棒性从嵌入空间"搬回"输入空间；对"想要**既按原型可读、又有鲁棒性量化**"的建模（含原型 / 概念瓶颈类自解释）是直接可用的训练配方。
- **核心方法**：证明 "局部 L-Lipschitz 嵌入 + ε-鲁棒分类头 ⇒ 输入空间 ε/L-鲁棒" → 提出用**采样**方式施加 L-Lipschitz 约束的训练方案 → 在 MNIST / CIFAR-10 / Imagenette-160 上，把三种分类头（线性、线性 SVM、GLVQ）× 两种嵌入（标准 / Lipschitz 约束）在 FGS、PGD、C&W 攻击下交叉评测。
- **主要结果**：**原型头（GLVQ）+ Lipschitz 约束嵌入**组合鲁棒性最强，说明 Lipschitz 约束在原型头自身优势之外还带来**额外**鲁棒性收益。
- **值得追问 / 局限**：① 约束由**采样**而非构造强制，故报告的是**经验鲁棒性而非可证明证书**——这弱化了原型分类器"闭式证书"的卖点，正文给的 L 估计可靠性是关键；② 评测限于中小图像基准，推广到高维 / 时序 / 图结构输入时 Lipschitz 约束的精度代价待考。

## B. 应用场景（跨被试 iEEG 癫痫检测 · 自适应脑连接图，取 1 篇）

### 4. MOSAIC: montage-agnostic self-distilled graph learning for subject-independent iEEG seizure detection
- 链接：https://arxiv.org/abs/2611.09496
- 作者：Arya Jalali, Mahsa Shoaran（EPFL，cs.LG / cs.AI）
- **TL;DR**：颅内脑电（iEEG）信噪比与空间分辨率高、利于检测癫痫活动，但**每个患者电极摆放不同**，导致通道数与导联（montage）差异巨大，严重限制"跨被试"检测器的泛化。本文提出轻量图学习框架 **MOSAIC**：用**共享卷积通道编码器** + **患者无关的通道注意力模块**，直接从编码特征推断一个**加权的通道间邻接矩阵**（无需固定导联图），再用**指数滑动平均的自蒸馏**把每次预测向缓慢更新的"每患者教师"对齐。
- **解决什么问题 / 为什么重要**：命中 B 的**脑 / 神经时间序列 + 脑网络**，并与 A 的**图学习方法**强交叉。它把"导联异质 ⇒ 无法共用固定图"这一脑电落地痛点，转化为"**从数据自适应学通道连接图**"的图学习问题；对任何**跨被试 / 跨设备的脑功能时序**（含 fNIRS / EEG，通道布局因人而异）的建模，提供了"montage-agnostic + 自蒸馏稳图"的直接范式。
- **核心方法**：共享卷积通道编码器提特征 → 患者无关通道注意力模块据特征推断加权**通道间邻接矩阵**（免固定 montage 图）→ **EMA 自蒸馏**：预测向缓慢更新的每患者教师正则，稳住跨植入的连接结构。
- **主要结果**：在四个公开 iEEG 语料（SWEC-ETHZ 长 / 短程、Mayo、FNUSA）上，MOSAIC 在 **F2 与 Cohen's κ** 上超过 SOTA 基线，且学到**更稳定的通道间邻接**，验证"自蒸馏连接学习可迁移到未见植入"。
- **值得追问 / 局限**：① iEEG 是侵入式、通道质量高，迁到**无创、信噪比更低、空间定位更弱的 fNIRS / 头皮 EEG** 时，"从特征推连接图"是否仍稳健需验证；② 评测以检测指标（F2 / κ）为主，学到的邻接是否对应**生理上可解释的脑连接**、能否支持内生解释，摘要未展开。

### 5. Cross-Layer TopK: Dynamically Allocating Sparsity Across Layers in Transcoders
- 链接：https://arxiv.org/abs/2611.09233
- 作者：Anyuan Zhuo, Shaohua Zhang, Tianle Li, Yuan Lin, Diandian Gu, Jun Wang（ByteDance-Seed）
- **TL;DR**：**跨层转码器（Cross-Layer Transcoders, CLT）** 把大模型激活分解为人类可解释特征、并追踪这些特征跨层交互形成的**电路**，是机制可解释性的关键工具，但训练难：除稀疏–重建权衡外还要一次建模所有层。常用 JumpReLU 只能靠惩罚间接控稀疏，直接扩展的 TopK 又给每层固定预算，而各层重建难度差异很大（中间层更难）。本文提出 **Cross-Layer TopK**：设**全模型单一 L0 预算**、训练中**跨层动态分配**。
- **解决什么问题 / 为什么重要**：命中 C 的**机制 / technical report**，正中"优先"机制类（非 prompt 工程）。它把"稀疏字典 / 转码器"这一机制可解释性基础设施的训练做得更优，直接改善**电路追踪的完整性**；对"想用 SAE / transcoder 做特征与电路级机制分析（含 residual stream、特征几何）"的研究是可复用的训练改进，且**已开源权重**。
- **核心方法**：设全模型单一 L0 预算 → 训练中按各层重建难度**动态分配稀疏预算**（替代每层固定 TopK / 间接惩罚的 JumpReLU）→ 固定的每 token 预算便于配合**稀疏解码**降算力 / 通信 → 在 Qwen3-8B-Base 上与 JumpReLU 等变体对比。
- **主要结果**：相比 JumpReLU，**FVU 更低且活跃 latent 少 20%**；更好的重建传导到电路追踪，得到**更完整的电路**（更高 replacement / completeness 分）；每训练步 **2.9× 加速**；并验证其在 latent 规模与稀疏度上都**服从缩放律**。权重已开源（HuggingFace: ByteDance-Seed/Cross-Layer-TopK-CLT）。
- **值得追问 / 局限**：① 实验主要在 Qwen3-8B-Base 单一模型族，跨架构 / 更大规模上"动态分配"的增益是否稳定、是否引入层间预算竞争的新不稳定性，待看；② "更完整电路"的 replacement / completeness 指标与**下游可解释结论的正确性**之间的关系仍需人工或因果验证。

### 6. Encoding Memory in World Models with Test-Time Model-Based Reinforcement Learning
- 链接：https://arxiv.org/abs/2611.09625
- 作者：Maxime Burchi, Fayaz Ali Dharejo, Radu Timofte（cs.LG / cs.AI / cs.CV）
- **TL;DR**：基于模型的强化学习（MBRL）能从轨迹学到准确世界模型，但在**需要长期记忆与规划**的任务上仍难超人。本文不走"改架构加记忆"的常规路线，而提出**测试时基于模型的强化学习 TT-MBRL**：在测试时用梯度下降把**本回合观测的记忆写进世界模型参数**，让智能体**为每个回合学一个专属世界模型**，从而超越仅靠上下文记忆的传统做法。
- **解决什么问题 / 为什么重要**：命中 C 的 **memory / planning** 机制（"优先"机制类，非 prompt 工程）。它把"长期记忆"从"更大的上下文 / 更复杂的循环架构"重新表述为"**测试时把记忆编码进权重**"，是对 agent 记忆机制的一个干净、可迁移的新视角；对"智能体 / 世界模型如何承载跨时段记忆"这一科学问题有直接启示，也呼应测试时训练（TTT）潮流。
- **核心方法**：测试时对世界模型参数做梯度下降，把本回合观测**编码进参数**（而非仅存上下文）→ 每回合得到一个专属世界模型 → 先在二维简化版 **Memory Maze 2D** 做概念验证（跨不同世界模型架构一致提升）→ 再推到 3D **Memory Maze** 基准。
- **主要结果**：在 **Memory Maze** 上取得新 SOTA；且在 **DeepMind Control、Atari 100k** 等**非记忆**基准上保持强性能，说明测试时写入记忆没有损害常规能力。
- **值得追问 / 局限**：① 测试时为每回合做梯度更新的**算力 / 延迟开销**，以及对部署实时性的影响，摘要未量化；② "记忆写进权重"相对"上下文记忆 / 显式记忆库"的可扩展上限（极长回合、灾难性遗忘）与可解释性，仍待进一步刻画。
