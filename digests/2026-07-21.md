## 1. Continuous Time Quantum Walk Propagation for Irregular Temporal Graph Forecasting
- arXiv: https://arxiv.org/abs/2607.17273
- 作者：Jiaqi Sun, Tianhao Li, Zhihao Bian
- **TL;DR**：把时序图上的信息传播换成基于图拉普拉斯的"连续时间量子游走"（CTQW），用量子干涉产生经典扩散做不到的非单调传播特征，并把不规则的有效观测间隔编码进传播核的谱相位调制里，得到一个物理动机明确、又能处理不规则时间间隔的时序图预测架构 QWTA。
- **解决什么问题 / 为什么重要**：正对 A 方向三条主线的交汇——时序图 + 不规则采样 + 连续时间传播。经典图扩散是单调平滑的、且天然假定规则时间步；现实的动态图信号往往采样不规则、又需要保留"传播过程中的干涉/回波"结构。本文给出一个把"时间间隔"直接写进谱相位、而非靠外部插值补齐的传播机制，属于把连续时间动力学原理化地塞进图传播的方法工作。
- **核心方法**：用 CTQW 型可参数化谱传播算子替换经典图传播；QWTA-Base 严格保留 CTQW 谱演化，作为"物理忠实"的传播参照；QWTA-GR 再加相位软裁剪（phase soft clipping）与门控残差融合（gated residual fusion）来稳定传播、抑制纯量子演化的发散/振荡。不规则的有效观测间隔被嵌入谱相位调制而不是重采样。
- **主要结果**：在不规则时序图预测设置下，显式把不规则时间间隔做相位编码、再配合稳定化模块，能提供优于经典扩散式传播的表现；消融显示相位编码与门控残差稳定化各自都有贡献。
- **值得追问 / 局限**：CTQW 谱传播需要对（时变）拉普拉斯做谱分解或近似，大图上的可扩展性与数值稳定性摘要未量化；"物理动机"的干涉传播相对经典时序 GNN 的实证增益幅度、以及在真正长程/高频不规则采样下是否稳健，需更多基准佐证；主类目挂在 quant-ph，与主流时序图基线的对照口径需留意。

## 2. DynImmune-BERT: Dynamic Immune Repertoire Modeling with Neural ODE Driven Continuous Transformers
- arXiv: https://arxiv.org/abs/2607.17244
- 作者：Rong Fu, Yongtai Liu, Xiaowen Ma, Haoyu Zhao, Shuo Yin 等（共 8 位）
- **TL;DR**：纵向 T 细胞受体（TCR）组库带有克隆扩张、收缩、消失、再出现的时间信号，但静态组库语言模型只把样本当成"一袋序列"、弱化了采样间隔与克隆出现模式；本文提出 DynImmune-BERT——用克隆存在门控的 Neural ODE 动力学 + 事件驱动状态重启，做连续时间的患者级免疫状态预测。
- **解决什么问题 / 为什么重要**：正对 A 方向"不规则采样时间序列 + Neural ODE/连续时间模型"，且这里的"不规则"是真实的临床纵向采样（间隔不齐、测序深度不一、克隆时有时无）。它示范了如何把连续时间隐状态与事件流（克隆出现/消失）耦合进 Transformer，对 fNIRS/脑功能等同样"不规则采样 + 事件驱动"的时序建模有很强的方法迁移性。
- **核心方法**：深度自适应的中心对数比（CLR）初始化；克隆存在门控的 Neural ODE 连续动力学刻画隐状态在采样间隔间的演化；有界邻域自注意力；基于事件的状态重启（clone reappearance 时触发）；混合传输目标同时监督主导克隆与稀有克隆的质量分布；低秩元适配器为再现的克隆型初始化、且参数量与观测克隆数解耦。
- **主要结果**：在患者级免疫状态预测上，连续时间 + 事件重启的建模优于把样本当静态序列袋的组库语言模型基线；评估刻意区分了"训练中见过 vs 未见过"的克隆型以检验泛化。
- **值得追问 / 局限**：方法组件较多（ODE 门控、事件重启、低秩元适配器、混合传输目标），各自的边际贡献与相互耦合的消融摘要未完全展开；面向 TCR 组库这一特定模态，能否迁移到脑/工业等其它不规则事件时序仍待验证；Neural ODE 求解的计算成本与长纵向序列的可扩展性未量化。

## 3. Interpretable Anomaly and Drift Detection with Gaussian Mixture Models
- arXiv: https://arxiv.org/abs/2607.16811
- 作者：Behnam Asadi
- **TL;DR**：把高斯混合模型（GMM）重新当作轻量、可解释的异常与"分布漂移"检测工具：用 BIC 自动定混合数、用极值理论（EVT）在目标误报率下定阈值，并把每个高斯分量当成一个"命名的运行 regime"，数据流窗口中"匹配不上任何 regime 的比例"直接既是漂移信号又是解释本身。
- **解决什么问题 / 为什么重要**：命中 B 方向"time-series anomaly detection / drift detection"，同时是 A 横切重点"内生/自解释"的干净范例——解释不是事后归因，而是检测统计量本身（unexplained mass）。对监控告警场景很实用：每条告警都能报"该点离最近 regime 几个 sigma"或"窗口中多少比例匹配不上已知 regime"，天然可审计。
- **核心方法**：对正常数据拟合 GMM，单点用负对数似然打分、阈值由 EVT 按目标误报率设定；混合分量数由 BIC 自动选择（k-means 初始化）；漂移检测复用同一模型，用"未解释质量"（匹配不上任何 regime 的窗口比例）作信号；并与无模型的 MMD 两样本检验、以及两种 GMM 间散度（闭式 Cauchy-Schwarz 散度、匹配式 KL 近似）对比。
- **主要结果**：在 7 个公开基准（3–64 维、5 次随机划分）上，GMM 点检测器与 Isolation Forest、LOF、one-class SVM、ECOD、COPOD、自编码器等有竞争力（很少更准），但唯一给出可解释模型；漂移方面 MMD 是最强纯检测器，但"未解释质量"在异常表现为新 regime 时与之持平（且在漂移只是已有 regime 重新加权时会诚实地失败，而 MMD 不会）；异常点中位落在最近 regime 外 3–10 sigma，正常点约 1 sigma。
- **值得追问 / 局限**：作者自己指出"未解释质量"在纯重加权型漂移下会漏检，适用边界清晰但也受限；GMM 的高斯假设在强非高斯/高维稀疏数据上的可解释性与准确率如何退化未深入；对比多为经典基线，未含时序专用的深度异常检测 SOTA。

## 4. Persistent Sparse Autoencoders: Learning Feature Timescales in Language Models
- arXiv: https://arxiv.org/abs/2607.17117
- 作者：Haoyan Luo, Mateo Espinosa Zarlenga, Mateja Jamnik
- **TL;DR**：标准稀疏自编码器（SAE）对每个 token 独立编码、暴露不出"跨序列持续存在"的信息；本文提出 Persistent SAE——给每个特征学一个"持久性系数"，让模型自己决定哪些特征该持续、持续多久，从而学出一个从快到慢的特征时间尺度谱。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"机制类（机制可解释性、表征、监控），同时是"内生/自解释"横切。它把 SAE 从"逐 token 静态字典"扩成"带时间尺度的特征"，让慢特征承载话题级、跨长上下文的持久语义状态——这对理解语言模型内部表征如何随序列演化、以及做长上下文监控都有直接价值。
- **核心方法**：在标准 SAE 基础上为每个特征引入可学习的持久性系数，控制该特征激活在序列中衰减/保持的时间尺度；训练在保持重构质量的同时让特征自然分化出快/慢两类；用 prompt-injection 监控案例检验慢特征的因果有效性。
- **主要结果**：Persistent SAE 保持了有竞争力的重构质量，同时学出特征时间尺度谱——快特征像局部可解释的探测器，慢特征把话题级信息浓缩进一个持久状态；在 prompt-injection 监控案例中，慢特征在长上下文里仍保留检测信号且保持因果有效。
- **值得追问 / 局限**："持久性系数"是否稳定对应可解释的语义单元、还是只是平滑了激活，需要更多机制验证；慢特征的因果有效性目前主要由单一监控案例支撑，跨任务/跨模型的普适性待扩展；与其它长上下文可解释性方法（如状态空间/记忆探针）的对照未展开。

## 5. The Geometry of Semantic Space: A Continuous Geometric Framework for the Transformer Architecture
- arXiv: https://arxiv.org/abs/2607.17146
- 作者：Zhihua Liang
- **TL;DR**：提出一个连续几何框架，把 Transformer 的离散代数运算建模成"语义纤维丛" $\mathcal{E}=\mathcal{M}\times\mathbb{R}^d$ 上的一个积分-微分方程（IDE）：从"token 序列构成带正则测度格的离散 1-流形"这一条几何公理出发，把 RMSNorm、RoPE、Softmax 注意力、FFN、残差流、SGD、权重衰减等核心组件统一翻译成微分几何 / 测度论 / 随机分析的语言。
- **解决什么问题 / 为什么重要**：正对 C 方向"表征几何、residual stream/结构、机制/现象分析"。它不是又一个可解释性探针，而是尝试给整套 Transformer 一个自洽的连续几何底座，并由此导出可定量检验的预测（如"注意力即 Schrödinger 桥/熵正则最优传输"、"SGD 即违反细致平衡的 Itô 扩散"），把残差流、归一化、位置编码放进同一套几何词汇里理解。
- **核心方法**：以语义纤维丛为载体，把每个 Transformer 组件映射为流形/测度/随机计算上的算子，得到一个 IDE 描述前向与训练动力学；由框架推出熵正则最优传输（注意力=Schrödinger 桥）与非平衡热力学（SGD=Itô 扩散）两类定量预测；在 Qwen3、LLaMA 等五种架构上做六部分实验验证。
- **值得追问 / 局限**：把工程化组件强行几何化，其"预测"多大程度是可证伪的新结论、多大程度是已有事实的重新表述，需要仔细甄别；单一作者、跨度极大的统一框架，实验对每条预测的支撑强度与可复现性摘要难以判断；框架的实际用途（指导设计/诊断）目前还偏理论。

## 6. Is Your Model Thinking or Just Stagnating? PUMA: Diagnosing Reasoning Pathology via Phase-Momentum Alignment
- arXiv: https://arxiv.org/abs/2607.17188
- 作者：Cheng Yan, Guangyang Ye, Wuyang Zhang, Fan Xu, Zhijun Fan 等（共 7 位）
- **TL;DR**：针对大推理模型（LRM）长链思考的"过度思考"悖论，提出"相位-动量对齐假说"——推理是否正确取决于潜空间几何动量与不确定性消解在时间上的同步；据此建立"认知能量模型"用两个正交维度（几何认知努力 vs 熵认知不确定性）刻画推理动力学，落成免训练框架 PUMA 实时区分"主动探索"与"被动空转"。
- **解决什么问题 / 为什么重要**：正对 C 方向"机制/现象分析 + 训练/推理动力学 + 表征几何"。现有 test-time 效率方法要么是信息论式的（易被"欺骗性收敛"——低不确定性掩盖幻觉），要么是事后的隐表征分析（缺乏实时敏感度）。PUMA 把"模型到底在想还是在空转"变成一个可实时监测的潜空间几何量，从而支持精准干预（自适应截断/纠偏），是把推理过程做机制化诊断而非只看最终答案。
- **核心方法**：提出相位-动量对齐假说与认知能量模型，用潜空间轨迹的"速度、迂曲度"量化几何认知努力、用熵量化认知不确定性；PUMA 采用分层诊断架构——轻量相位监测 + 事件触发的几何分析，在低开销下判别探索 vs 停滞，并触发自适应截断或纠正性干预。
- **主要结果**：在 1.5B–32B 的多个 LRM 与多类基准上，PUMA 一致优于 SOTA 基线，取得更优的准确率-效率折中，并展现跨域泛化；能有效区分主动探索与被动停滞两类推理相位。
- **值得追问 / 局限**：几何量（速度/迂曲度）与"推理正确性"的因果关系目前更多是假说 + 相关性支撑，机制解释需更强因果证据；分层诊断的阈值/事件触发超参对不同模型规模的敏感度未量化；"过度思考"判据在开放式、多分支推理任务上的误伤率有待考察。
