### 1. Improving the Intrinsic Interpretability of Differentiable Decision Trees through Euclidean Feature-Concentration Regularisation
- 链接：https://arxiv.org/abs/2610.39596
- 作者：Qiqi Yang（1 位；cs.LG）
- **TL;DR**：可微决策树（DDT）虽支持端到端优化且有显式决策路径，但稠密的斜向分裂会把"单个特征到底起多大作用"糊成一团；本文提出 **EU-DDT**，在每个内部节点对特征权重加一个"离均匀分布的归一化平方欧氏距离"正则，鼓励少数特征主导、同时保留概率化软路由，让树真正可读。
- **解决什么问题 / 为什么重要**：命中 A 的**内生/自解释横切重点**——不是事后归因，而是把可解释性做进模型结构本身。它直面"软决策树虽可微但不可读"的核心矛盾，用一个简单正则把节点级特征复杂度压下来，给出"可解释性 vs 预测性能"这一权衡的可量化刻画，方法论上干净、可迁移到 RL 策略网络。
- **核心方法**：在每个内部节点，用特征的相对绝对权重与均匀分布之间的归一化平方欧氏距离做正则（鼓励权重"集中"到少数特征）→ 保留概率软路由不破坏可微性 → 并用 EU-DDT 参数化 PPO 的 actor（搭配 MLP critic）验证在 RL 中的可用性。
- **主要结果**：在 Wine 上把"有效特征数"从 8.94 降到 1.54、Digits 从 45.28 降到 9.06；代价是数据集相关的精度变化（Wine 100%→93.9%，Digits 92.3%→94.6%，后者反而更好）；RL 中 CartPole-v1 / MiniPacman 达 100% 评测成功率，节点集中度从 0.13/0.04 升到 0.72/0.72。
- **值得追问 / 局限**：① 作者自述 RL 证据仅 2 个随机种子、尚属初步，稳健性待补；② "特征集中"≠"人类可理解的概念"，EU 正则只保证少数特征主导，是否对应语义上有意义的决策依据、与 concept/prototype 类自解释如何结合，值得追问。

### 2. NECA: Neighbor Event Curve Augmentation for Multi-Horizon ICU Deterioration Prediction
- 链接：https://arxiv.org/abs/2610.40420
- 作者：Chenyang Wang, Jiawei Theresa Tang, Xinran Liu, Xinyu Lu, Xulei Yang 等（cs.LG / cs.AI）
- **TL;DR**：ICU 器官功能恶化的早期预测受困于**不规则测量、异质临床变量、要预测多个未来时间窗**；现有监督模型把每个病人当孤立样本，没用上"相似历史病人的事件发生时机"。本文提出 **NECA**——一个模型无关的方法，检索早期画像相似的历史病人，把他们后续器官衰竭的**发病时间**转成 6h/12h/24h/42h 的**累积事件曲线特征**，拼到原始病人表征上供下游预测器使用。
- **解决什么问题 / 为什么重要**：同时命中 A 的**不规则采样时间序列**与 B 的**临床监控/早预警**。它把"相似病人的事件时机"显式建模为一种**结构化的时序风险信号**，而不是靠单病人序列硬学；且是 model-agnostic 的特征增强，可叠加到任意监督学习器上，工程落地友好。
- **核心方法**：对目标病人用早期窗口画像做相似检索 → 取邻居后续器官衰竭的发病时间 → 聚合成多时间窗（6/12/24/42h）累积事件曲线特征 → 与原表征拼接，喂给标准下游预测器（不改模型结构）。
- **主要结果**：在 PhysioNet 2012 与 4,000 入院量的 MIMIC-IV 子集上，跨 4 类器官衰竭任务、7 种监督学习器，平均 PR-AUC / ROC-AUC 均提升；神经系统功能障碍任务增益最大，PhysioNet 2012 上任务级平均 PR-AUC 从 0.461 升到 0.557；消融显示"临床有意义的检索 + 时间窗特定的邻居风险"贡献了主要增益。
- **值得追问 / 局限**：① 依赖"存在足够多相似历史病人"的假设，罕见表型或冷启动场景下检索质量如何，影响很大；② 完整累积曲线只带来"任务相关"的额外时序上下文，说明曲线形状的增益并不普适，哪些任务真正需要全曲线、哪些只需单点邻居风险，值得进一步拆解。

## B. 应用场景（神经影像联邦学习，取 1 篇；脑网络/fNIRS 与监控/AIOps 本窗无强相关新作）

### 3. Data Amount Heterogeneity Improves Performance in Federated Learning for Neuroimaging
- 链接：https://arxiv.org/abs/2610.38172
- 作者：Paul Kurian, Tamoghna Chattopadhyay, Abhijith Shaji, Greg Ver Steeg, Paul M. Thompson, Jose Luis Ambite（6 位；cs.LG / q-bio.NC）
- **TL;DR**：联邦学习（FL）能在不共享原始数据的前提下跨站点训练神经影像模型（如从结构 MRI 做阿尔茨海默病分类）；本文给出一个反直觉的实证结论——由**数据量异质的站点**（1 个大站点 + 若干小站点）组成的联邦，比各站点数据量均等的"同质联邦"**表现更好**，尤其在低数据量场景下，并能逼近集中式训练。
- **解决什么问题 / 为什么重要**：命中 B 的**neuroimaging / 脑功能影像**应用。多中心脑影像联盟（如 ENIGMA）天然就是"大站点+一堆小站点"的异质结构，这项工作直接回答了"这种现实异质性对 FL 是福是祸"，结论是福——有大站点时收敛更快、最终精度更高，为多中心脑影像协作的联邦设计提供了实证指导（同态加密保护参数、数据不出站）。
- **核心方法**：标准 FL 流程（各站点本地训练深度模型 → 同态加密上传参数 → 联邦控制器加密聚合 → 社区模型回传继续训练，多轮迭代）；系统对比异质 vs 同质联邦在不同数据规模下的精度与收敛，以结构 MRI 的阿尔茨海默病分类为任务。
- **主要结果**：异质联邦（1 大 + 多小）整体优于同质联邦，在**低数据量区间差距尤为明显**，且逼近集中式训练；拥有一个大站点常带来更快收敛与更高最终精度；异质联邦能更充分利用小数据站点——正是大型联盟的常见情形。
- **值得追问 / 局限**：① 结论基于结构 MRI 的 AD 分类，能否迁移到 fMRI/fNIRS 等功能性时序影像、以及回归类脑表型任务，待验证；② "大站点更好"可能把联邦性能与隐私风险耦合——大站点主导下，社区模型在多大程度上仍受小站点分布保护，值得从隐私/公平角度追问。

### 4. Implicit Reasoning in Transformers: Bridging the Compositionality Gap in GPT-2-like Models
- 链接：https://arxiv.org/abs/2610.39016
- 作者：Davide Venuto, Leonardo Venuto（2 位；cs.CL）
- **TL;DR**：Transformer 的组合泛化有个顽疾——模型在分布内（ID）学会了正确组合已知事实，同样的组合机制在分布外（OOD）知识上却失效（"组合性差距"）。本文在从零训练的 GPT-2 式模型、受控两跳推理任务上证明：这个差距**不是架构的根本缺陷**，而与"原子知识在训练中如何被结构性暴露"有关，可被机制化的训练分布设计弥合。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / 现象分析**（正中"优先"）。它建立在"已识别出与组合泛化相关的电路"的前人工作之上，做的是真正的机制级干预实验，而非换 prompt。结论对"组合泛化到底卡在哪"给出因果性证据：卡的不是架构，是训练时原子事实摆放的位置是否对齐了电路里第二跳检索步骤。
- **核心方法**：在受控两跳推理设置下从零训练 GPT-2 式模型 → 定位与组合泛化相关的电路 → 把 ID 与 OOD 原子事实都以"与第二跳检索步骤位置对齐"的格式呈现在训练分布里（不改架构、不加 OOD 组合监督）→ 观察 OOD 组合行为能否迁移。
- **主要结果**：在该机制化干预下，模型成功把 ID 学到的组合行为迁移到留出的 OOD 原子事实上，在受控设置中**闭合了组合性差距**；证明组合性差距可通过"机制知情的训练分布设计"克服，而非必须改架构或加组合监督。
- **值得追问 / 局限**：① 结论在 GPT-2 规模的受控合成任务上成立，能否放大到真实预训练语料与大模型、自然文本里"位置对齐"该如何自动实现，是关键外推问题；② "对齐第二跳检索步骤"需要先知道电路结构，实际数据上如何在不开电路的情况下设计这种训练分布，论文未给出通用方案。

### 5. Long-Term Agent Memory through Complementary Curation and Consolidation
- 链接：https://arxiv.org/abs/2610.39790
- 作者：Abhishek Gupta, Dongge Han, Daniel Madrigal Diaz, Wei-Ning Chen, Mayukh Das, Victor Rühle 等（cs.AI）
- **TL;DR**：长时程对话 agent 需要能从交互历史里回忆事实、事件与关系。本文提出一个**混合记忆架构**——情景记忆（episodic）+ 结构化关系记忆（relational），外加一个在保证效率的前提下做记忆巩固（consolidation）的机制，并实证证明两类记忆是**互补**的。
- **解决什么问题 / 为什么重要**：命中 C 的 **agent memory**（"优先"类，机制导向而非 prompt 技巧）。它不是堆一个更大的检索库，而是主张"不同性质的记忆要分型存储、再巩固"，用实验量化了情景记忆与关系记忆的互补性——这对"agent 长期记忆该怎么组织"是一个干净的架构级结论。
- **核心方法**：情景记忆 + 结构化关系记忆双通道存储 → 巩固机制在控制开销的同时整合/压缩记忆 → 在 LoCoMo 与 LongMemEval-S 两个长时记忆基准上做实证研究，对比单一记忆型与组合型。
- **主要结果**：两类记忆在各基准上**一致互补**，组合使用超过现有 SOTA 记忆框架，在 LoCoMo 上达 **90.2%** 准确率、LongMemEval-S 上达 **85.5%**。
- **值得追问 / 局限**：① 报告以端到端准确率为主，巩固机制带来的存储/延迟开销与长期可扩展性（记忆规模增长后的检索成本）缺少细粒度量化；② 情景/关系两型划分在更开放、非对话型 agent 任务（工具调用、长程规划）中是否仍是最优分型，待检验。

### 6. Don't Lose the Thread: Empowering Long-Horizon LLM Agents with Cognitive Resource Self-Allocation
- 链接：https://arxiv.org/abs/2610.40350
- 作者：Zheng Zhu, Xiaozhuan Liang, Xi Chen, Bei Yu, Jiaya Jia（5 位；cs.CL）
- **TL;DR**：LLM agent 在长时程任务上常因"认知过载"崩溃——工作记忆被不断膨胀的无关信息塞满，稀释注意力、拖垮规划与推理。本文提出 **CORAL**：把"认知资源自分配"做成一个 **agent 可调用的工作记忆管理工具集**，让 agent 自己给任务进度与已验证事实打检查点，并在上下文变乱时**重置上下文、只保留检查点信息**，从干净状态续推。
- **解决什么问题 / 为什么重要**：命中 C 的 **memory + planning 机制**（"优先"类，是推理范式/工作记忆机制而非 prompt 模板）。它把"上下文管理"从被动截断变成 agent 的**主动行为**，并用 RL 去训练"何时打检查点、留什么"，直面长时程 agent 的根本瓶颈（上下文膨胀），且带来显著的推理成本下降。
- **核心方法**：CORAL 实现为 agent 可调用的工作记忆管理工具（检查点任务进度 + 已验证事实 → 自适应开启新"问题求解 episode"，重置杂乱上下文、仅保留检查点）→ 用 **Multi-episode Agentic Reinforced Policy Optimization** 强化检查点能力。
- **主要结果**：在 GAIA 上，8B 模型配 CORAL 达 **42.8%** 平均准确率，在最难的 Level 2/3 长时程任务上增益尤为突出；且输入 token 消耗比 ReAct agent **少 6–7 倍**；还能泛化到多跳知识问答，并在更难的 BrowseComp 上把一个强专有 agent 提升 **8.0** 分。
- **值得追问 / 局限**：① "重置上下文只留检查点"可能丢弃日后才显重要的信息，检查点的召回/误删权衡（漏存关键事实）如何量化，是风险点；② 收益依赖 RL 训练出的检查点策略，跨任务分布迁移性、以及在没有明确"可验证事实"的开放任务上的适用性，待验证。
