## A. 核心方法（时空预测泛化 / 图结构时序轨迹，取 2 篇）

### 1. VaryST: Generalizable Spatio-Temporal Forecasting Beyond the Closed-World Setting
- 链接：https://arxiv.org/abs/2610.19813
- 作者：Shengnan Guo, Jinjun Cheng, Xiaowei Mao, Jianhao Zhang, Haochen Lv, Yang Jiang（10 位；cs.LG / cs.AI）
- **TL;DR**：现有时空预测模型往往被训练环境绑死——依赖节点专属表征、预定义的空间支撑集、以及始终可用的观测，一旦部署环境的时间分布、空间域或观测可得性发生变化就失效；本文提出 **VaryST**，一个从零训练的紧凑模型，通过**从可得的长期观测动态构造预测上下文**来获得强泛化。
- **解决什么问题 / 为什么重要**：正中 A 的**时空预测 + 不规则/缺失观测下的鲁棒性**。它把"闭世界假设"（训练与部署同分布、观测稳定、空间节点集固定）作为靶子，针对真实部署里"传感器时增时减、空间域漂移、关键观测缺失"这类常态设计归纳偏置——这与你关注的"不规则采样 / 观测缺失 + 时空结构"主线高度契合，是把时空 GNN 类方法往真实可部署方向推的一篇。
- **核心方法**：① 为适应时间变化，从**长期历史**导出节点表征，把当前行为放进更长周期模式的语境里；② 为适应空间变化，**超越预定义邻域动态选择功能相关的支撑节点**，与近期/长期目标状态及全局上下文融合；③ 为应对观测可得性变化，训练时**选择性遮蔽模型最依赖的历史 patch**，逼模型学会在关键观测缺失时利用替代的时空依赖。
- **主要结果**：在 **6 个真实数据集、对比 17 个基线**上，VaryST 取得强的域内预测精度，并**显著提升空间/时间变化下的 zero-shot 与 few-shot 泛化**，同时对观测可得性变化保持鲁棒。
- **值得追问 / 局限**：① "动态选择功能相关支撑节点"的计算开销与可扩展性（大图/高频场景下的选择成本）未在摘要中量化；② 主动遮蔽逼出替代依赖是很好的鲁棒化思路，但遮蔽策略本身（遮哪些、遮多少）是否需针对缺失模式调参、对"成片结构化缺失"是否同样有效，值得追问。

### 2. Graph-Enhanced Disease Trajectory Discovery and Temporal Endpoint Forecasting from Longitudinal Electronic Health Records
- 链接：https://arxiv.org/abs/2610.20502
- 作者：Jin-Jia Zheng, Vincent S. Tseng（2 位；cs.LG）
- **TL;DR**：纵向电子病历（EHR）能揭示疾病进展结构，但有用的预测需要**防泄漏的结构发现、删失感知的结局、可检视的轨迹证据**；本文在 MIMIC-IV v3.1 上构建图增强框架，在建图前先按患者切分、只用训练集学连续入院转移、并在验证集上冻结结局专属的"分支基序"策略，再用时间感知 Transformer 为每个结局检索至多 24 条患者兼容基序做预测。
- **解决什么问题 / 为什么重要**：命中 A 的**图结构 + 时序轨迹 + 内生可解释（分支基序作为可检视证据）**。它把疾病进展建成图上的"分支基序（branching motifs）"目录（99,527 条），并通过结局专属交叉注意力检索相关基序——基序本身即"结构化的轨迹上下文"，是**可解释的中间表示**而非黑箱打分。更值得学习的是其**方法学纪律**：患者级切分防泄漏、验证集冻结、删失/生存校正评估、以及对结论边界的诚实披露。
- **核心方法**：建图前按患者切分 → 只用训练集学连续入院转移、验证集冻结结局专属分支基序策略 → 时间感知 Transformer 经结局专属交叉注意力检索 ≤24 条患者兼容基序 → 预测事件时点与结局；另做有向、度匹配的 GNN 修复以改善未见边发现。
- **主要结果**：5 个训练种子下 micro-AUPRC 从 0.9330 升至 0.9357，事件时点 **MAE 从 676.9 天降到 657.7 天**（减少 19.2 天，95% CI 13.8–24.8）；时点收益**异质**——730 天内事件 MAE 反而变差、730 天后改善 58.9 天；内部时间切分下分支条件化把条件事件时点 MAE 再降 26.9 天。但校正后的生存评估（0–2,555 天）**未**在 macro C-index 或 integrated Brier 上超过仅用病史的离散风险基线；GNN 修复显著改善未见边发现，但在固定基序身份内替换 GNN 分数**不改善**下游预测。
- **值得追问 / 局限**：① 作者自陈分支基序的主要价值是**长程时点支持**，而非普遍更强的结局判别/生存预测/因果解释——这界定了方法的适用边界；② 单数据源（MIMIC-IV）、以及"短程事件反而变差"的现象，说明该框架对近期结局可能引入噪声，迁移到其它病种/医院需重新验证。

## B. 应用场景（异步脑信号检测 / 鲁棒时序异常检测，取 2 篇）

### 3. NeuroDETR: Multiscale Discrete Spatiotemporal Tokenization for Asynchronous EEG Event Detection
- 链接：https://arxiv.org/abs/2610.20349
- 作者：Yaozhi Wen, Kun Zhao, Wei Wei, Haoyang Chen, Kangning Wang, Yi Sun（10 位；cs.LG）
- **TL;DR**：异步 EEG 事件检测要在**不预设事件边界**的前提下，从连续记录里直接识别事件类别与时间边界，难点是把事件相关模式从持续的背景活动里抽出来；本文提出 **NeuroDETR**，一个结合结构化 tokenization 与事件感知特征精炼的**离散时空多尺度框架**。
- **解决什么问题 / 为什么重要**：强命中 B 的**脑功能/神经时序信号 + 监控式连续检测**（与 fNIRS/neuroimaging 同族的 BCI 应用），并横切 A 的**时空方法 + 异步/不规则事件时点**。它面对的是"连续流里事件何时发生未知"这一典型的**不规则时序 + 时空结构**问题，用多尺度时间码本 + 空间金字塔 VQ 构造紧凑"事件记忆"，方法层面与你关注的时空建模主线直接相关。
- **核心方法**：**多尺度时间码本**捕捉短时响应与持续动态；**Spatial-Pyramid VQ** 跨 EEG 通道分层编码空间结构；二者构成紧凑的事件记忆，联合做事件分类与起止点估计；tokenization 前先用 **FOCAL**（事件感知稀疏注意力）按预测的事件存在度引导时间特征精炼与空间聚合，突出可能的事件时段同时保留全程上下文。
- **主要结果**：在**跨多种范式的 8 个 EEG 数据集**上取得 SOTA 表现，验证了"在连续交互与监控中识别有意义神经活动"的 BCI 可行性。
- **值得追问 / 局限**：① 摘要只给出"SOTA"定性结论，未列具体指标与基线差距，离线/在线、被试内/跨被试的泛化差异需看正文；② 离散 VQ tokenization 对低信噪比、伪迹密集的真实连续 EEG 是否稳定，以及码本崩塌/利用率问题，是这类离散表征方法的常见软肋。

### 4. Retrieval Over Training: Similarity Search-based Model Selection for Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2610.20243
- 作者：Christos Panourgias, Roberto Stanzione, Adrien Petralia, Themis Palpanas, Paul Boniol（5 位；cs.LG / cs.AI）
- **TL;DR**：时序异常检测没有"通吃"的检测器，实用方案是为每条序列选最可能好用的检测器，但现有模型选择方法在 **OOD 设定下精度大幅下滑**；本文提出 **RAMSAD**——一个基于检索的模型选择框架：对新序列查询历史实例知识库、取 top-k 最相似序列、从它们的性能画像迁移检测器推荐。
- **解决什么问题 / 为什么重要**：命中 B 的 **anomaly detection + 监控/AIOps 现实痛点**。它直击一个运维真实问题：异常检测器的最优选择强依赖数据特性，而上线后数据分布必然漂移（OOD），"训练一个选择器"在漂移下会失效。RAMSAD 用**检索（而非训练）**做模型选择——更新知识库即可适应新分布，天然契合监控系统持续演化、且对可解释性/可审计友好（能指出"推荐来自哪些相似历史序列"）。
- **核心方法**：给定新序列 → 查询历史实例知识库 → 检索 top-k 最相似序列 → 从其性能画像迁移检测器推荐；框架既能用标准相似度度量、也能用基于嵌入的表征。
- **主要结果**：在 **ID 设定**下超过现有基线；在 **OOD** 下是最鲁棒的选择器——当只选一小撮检测器时，其效果**匹配甚至超过"跑完整个检测器池"的集成**，而成本只是后者的一小部分。
- **值得追问 / 局限**：① 效果强依赖知识库的覆盖与"相似度度量/嵌入是否真能对齐到检测器适配性"，对知识库里没有近邻的全新异常形态可能退化；② 摘要未报检索与画像维护的在线开销，以及知识库随时间增长后的检索延迟/存储成本，决定其在高基数监控场景的可用性。

## C. Agent / 机制分析（高优先级，取 2 篇）

### 5. Training Dynamics of Transformers on Unbounded Inputs: Attention Learning Can Lag Output Layer Learning
- 链接：https://arxiv.org/abs/2610.20337
- 作者：Yaomengxi Han, Debarghya Ghoshdastidar（2 位；cs.LG）
- **TL;DR**：Transformer 的成功部分归于注意力能聚焦相关特征、且能表达变长输入上的形式语言，但对**浅层 Transformer 如何解耦学习注意力与输出层**理解有限；本文证明"先一步梯度学注意力、再训输出层"这一前馈网络特征学习理论的自然外推**会失败**，正确的训练动态是**三阶段梯度下降**。
- **解决什么问题 / 为什么重要**：强命中 C 的**训练动态 / 机制理解**（非 prompt、非流程工程）。它以"识别无界长度输入上的 star-free 语言"为可分析载体，严格刻画注意力层与输出层在梯度下降中的**学习次序**，把"Transformer 训练时各组件何时、以何顺序学到东西"这一含糊问题变成可证明的对象——对理解表征/能力如何涌现有基础价值。
- **核心方法**：针对识别 star-free 语言（无界长度输入）的浅层 Transformer，证明可用**三阶段 GD** 训练成功：先更新输出层 → 再更新注意力 → 第三阶段微调输出层；并证明"只训注意力或只训输出层""或单步注意力更新后只微调输出层"均**学不会**该语言；进一步在其它语言识别、回归、in-context learning 任务上实证"注意力学习滞后于输出层学习"同样有益。
- **主要结果**：给出严格的可学/不可学分离——三阶段路径可成功、若干简化路径必失败；并以实验表明该"滞后"现象跨多种任务具普适的有益性。
- **值得追问 / 局限**：① 结论建立在浅层 Transformer + 特定形式语言的可分析设定上，向深层多头、真实语言预训练外推的程度存疑；② "注意力滞后有益"若成立，是否可转化为**可操作的训练日程/初始化策略**（而非仅事后解释），论文更偏机制刻画。

### 6. Which Knowledge Should LLMs Trust? Uncovering a Generalizable Steering Direction Across Knowledge Conflicts
- 链接：https://arxiv.org/abs/2610.20067
- 作者：Yibin Lou, Yi Hu, Jianhui Chen, Chenpeng Wang, Muhan Zhang, Liangming Pan（6 位；cs.CL / cs.AI）
- **TL;DR**：LLM 常在**内部参数知识与外部上下文知识**间冲突，但选择机制不清；本文发现"信上下文还是信参数"在模型**残差流里由单一方向线性表示、并可沿该方向可控**，且这一方向能跨设定泛化、还能迁移到 RAG/记忆/规则遵循等更复杂任务。
- **解决什么问题 / 为什么重要**：强命中 C 的 **residual stream / 表征几何 / 机制理解**。它把一个行为层面的现象（知识冲突时的取舍）定位到残差流中**一个线性可控方向**，并验证该方向在上下文格式、知识类别、数据集间**泛化**，更进一步从"简单事实冲突"学到的方向**零迁移**到 RAG、记忆、规则遵循三类任务——这是"单方向编码一种可迁移偏好"的干净证据，对理解与干预 LLM 的知识选择很有价值。
- **核心方法**：在事实冲突数据上定位控制"上下文 vs. 参数知识"的线性方向 → 验证其跨格式/类别/数据集泛化、且沿该方向 steering 能一致地在参数答案与上下文答案间切换 → 把该方向迁移到 RAG、记忆（交互历史）、规则遵循三个任务族做可控性测试。
- **主要结果**：在**4 个模型家族、多种迁移设定**下，沿该方向 steering **一致提升**模型对提示所提供信息（检索文档/交互历史/显式规则）的采用，优于未 steering 的模型；结果支持"该方向捕捉的是一种**可迁移的对外部知识的偏好**"，而非仅限事实冲突的专用机制。
- **值得追问 / 局限**：① "提升采用外部信息"是双刃剑——当检索文档含错误/对抗内容时，强行偏向上下文可能放大幻觉或被注入攻击利用，安全侧未充分讨论；② 单方向线性假设在更强冲突、多跳推理或长上下文下是否仍成立，以及 steering 强度如何自适应，值得追问。
