## A. 核心方法

### 1. Statistical Feature Augmentation for Anomaly Detection in Dynamic Graphs
- **链接**：https://arxiv.org/abs/2609.02965
- **作者**：Philipp Schlinge, Jean-Luc Schnipper, Martin Atzmueller
- **TL;DR**：动态图深度模型往往难以从原始事件流里学到"发送强度、交互惯性"这类短时行为信号；本文把这些经典网络统计**显式编码进输入特征空间**，在连续时间与离散时间图模型上一致提升异常检测，并因每个统计独占一维而支持细粒度的事后重要度分析。
- **解决什么问题 / 为什么重要**：这正落在我最看重的**动态图/事件流 + 时序异常检测**交集上。它不另造模型，而是指出主流 CTDG/离散时间图模型对短时行为统计学习不足，用"经典网络分析 + 深度学习"的融合补齐，兼顾性能与可解释性——与我关注的内生可解释也相通。
- **核心方法**：定义一组行为交互统计（如发送方强度、交互惯性等短时信号），显式追加到节点/事件的输入表征；在同一套模型上对比"原始 embedding"与"增强 embedding"两种输入；因每个统计占据一个专属输入维度，可对行为重要度做逐维事后分析。
- **主要结果**：在 Reddit、Wikipedia、MOOC 三个真实数据集、覆盖连续时间与离散时间共 7 个模型上评测，特征增强相对原始输入基线一致提升异常检测性能，并给出对行为重要度的细粒度解读。
- **值得追问 / 局限**：增强统计是手工设计的行为特征，其覆盖面与跨域可迁移性有限（换到无明显"发送/交互"语义的图上是否仍有效待验证）；"每维一统计"带来的是事后归因而非严格内生自解释，忠实性仍需与结构本身的因果做区分。

### 2. Witnesses Explain Anomalies (WAND)
- **链接**：https://arxiv.org/abs/2609.03826
- **作者**：Lamine Diop（与昨日 DIFFINT 为同一作者，延续其"内生自解释异常检测"线）
- **TL;DR**：无监督异常检测通常只给分不给理由，解释被事后用 SHAP/LIME 反复重查逼近；WAND 把计算组织在单位球面的方向上，用"投影超出亚高斯极值基线的程度"打分，而**触发某点的见证方向（feature 空间里的向量）本身就是它的解释**——逐特征归因零额外成本，且因分数可微可由梯度恢复。
- **解决什么问题 / 为什么重要**：直击我关注的**内生/自解释（intrinsic self-explaining）横切重点**在异常检测上的落地：把解释写进打分几何，而非训练完再套 SHAP/LIME。它与昨日 DIFFINT（可微区间瓶颈）是同一作者的姊妹思路，一个用轴对齐区间、一个用球面见证方向，对比来看很有意思。
- **核心方法**：其一，按单位球面上的方向组织计算，每点按其投影逃逸亚高斯极值基线的距离打分；其二，标记某点的"见证方向"即为其特征空间解释，给出逐特征归因；其三，打分对样本量线性，配"探针效率界"保证每个异常都有见证方向（即必有解释）。
- **主要结果**：在 47 个 ADBench 数据集上，与 16 个无监督基线在 ROC-AUC 打平的前提下取得最佳平均 Friedman 秩——即"以不损精度换可解释"；其原生解释比事后 SHAP/LIME 与 ECOD 更准确、更忠实，且查询成本仅为其零头。
- **值得追问 / 局限**：方法面向表格数据、依赖亚高斯极值基线假设，重尾/强相关特征下基线是否稳健待验证；"方向即解释"对人类而言仍需把方向映射回可读特征子集，其可读性与 DIFFINT 的区间超矩形孰优需实测比较。

### 3. PPO-STGNN: A Proximal Policy Optimization Approach with Spatio-Temporal Graph Neural Networks for DAG Task Scheduling in Cloud-Edge-End Computing
- **链接**：https://arxiv.org/abs/2609.03503
- **作者**：Yangshuo Qi, Chenwei Wang, Zihan Shen, Songlin Sun
- **TL;DR**：云边端异构环境下的 DAG 任务调度是 NP-hard，传统启发式与常规 RL 抓不住系统资源的时空动态；PPO-STGNN 用**时空图神经网络**同时从 DAG 任务拓扑和物理资源图抽取特征，再以 PPO 优化调度策略，兼顾完工时间、调度长度比与 CPU/内存负载均衡。
- **解决什么问题 / 为什么重要**：命中我的最高优先关键词**时空图 GNN（spatio-temporal GNN）**。虽是调度应用，但方法核心是用 STGNN 建模"任务依赖 + 资源"双图的时空演化，属于时空图表示学习落到系统决策的一个具体样本。
- **核心方法**：用 STGNN 对 DAG 任务拓扑图与云边端资源图分别提取时空特征；以 PPO 学习调度策略，目标为最小化 makespan 与 SLR、并改善 CPU/内存负载均衡；引入多教师行为克隆做预训练以加速收敛。
- **主要结果**：实验显示在保持较低完工时间的同时显著改善负载均衡，适配动态、异构的云边端 DAG 调度场景。
- **值得追问 / 局限**：评测局限于调度指标与仿真设定，缺少与最新 GNN-RL 调度基线的强横比与真实集群验证；"时空图"更多体现在资源状态随时间变化，是否真正利用了长程时序依赖（而非逐步快照）值得追问。

## B. 应用场景

### 4. Loom: Weaving Diagnostic Strands into Free-Text Consensus via Embedding-Space Reweighting
- **链接**：https://arxiv.org/abs/2609.02649
- **作者**：Ron Begleiter, Katya Egert Berg, Gilad Saban, Gil Shabat
- **TL;DR**：工业根因分析（RCA）里，单体 LLM 智能体表达力强但受上下文限制、幻觉累积、推理慢，而传统弱监督又只能处理离散类别；Loom 把模块化启发式产出的**开放式假设投影到连续嵌入空间**，用迭代质心重加权消解冲突信号，最终只用一次轻量 LLM 合成生成共识。
- **解决什么问题 / 为什么重要**：正对我关注的**监控告警 / 根因分析（AIOps）**，且是**已部署**的真实系统经验，直面"智能体深度 vs 推理延迟"的工程权衡——这类结果导向、落地可信的 RCA 工作对我很有参考价值。
- **核心方法**：模块化启发式（用事件级实体/时间/指标动态填充的诊断模板）产出开放式假设；将假设投影到连续嵌入空间，用基于质心的迭代重加权算法解决冲突并得到共识权重；共识权重再引导单次轻量 LLM 合成。
- **主要结果**：在 OpenRCA 基准上占据准确率-效率 Pareto 前沿——在 Bank、Market-2 上追平 SOTA 自主智能体，Market-1、Telecom 略逊；但每次事件仅一次 LLM 调用（约快 26×，换 8B 合成器约 33×）。作者还分享了冗余检测的负面结果与"确定性共识赢得领域专家信任"的部署心得。
- **值得追问 / 局限**：性能依赖诊断模板的质量与覆盖，模板未命中的新型故障下鲁棒性存疑；在 Market-1/Telecom 上落后 SOTA，说明纯嵌入共识在更复杂依赖链上仍有精度上限。

## C. Agent 机制 / 现象分析

### 5. Fresh Memory, Stale Plans: Dependency-Scoped Validation for Distributed LLM-Agent Memory (PlanFence)
- **链接**：https://arxiv.org/abs/2609.03340
- **作者**：Evan Chen, Shiqiang Wang, Christopher G. Brinton
- **TL;DR**：分布式 LLM 智能体即使能读到最新共享事实，仍可能照着**过时的计划**行动；本文命名这一"陈旧计划执行"问题，指出"状态新鲜 ≠ 授权该动作的计划仍有效"，提出 PlanFence：计划显式引用其所依据的公共记录，执行器只校验能影响当前外部动作的那些记录，必要时重规划一次或阻塞。
- **解决什么问题 / 为什么重要**：贴合我关注的 Agent"优先"型主题——**memory / planning 机制**。它把多智能体记忆的失效模式从"检索不够新"精确定位到"计划依赖失效"，是对"长程/分布式记忆到底要保证什么"的机制性刻画，而非 prompt 技巧。
- **核心方法**：计划引用其使用的确切公共记录（依赖）；执行外部动作前，执行器做依赖范围化校验——只校验可能影响该动作的记录，校验不完整则重规划一次或阻塞；对比"仅看新鲜度"的执行器与主动同步策略。
- **主要结果**：在 30 个含"事后修订"的受控实况工作流中，仅看新鲜度的执行器每个任务都会执行过时计划，而 PlanFence 全部完成且无非法动作；重放揭示两个条件边界：低变动下主动同步协调停顿更低，高变动/大键空间下 PlanFence 避免重复协调与无关状态校验。
- **值得追问 / 局限**：作者明确这是受控的安全与系统开销结果、非普适任务准确率提升；"计划引用确切记录"要求依赖可显式追踪，面对隐式/涌现式依赖或 LLM 自身推理引入的隐藏依赖时，范围化校验的完备性存疑。

### 6. Why Gated DeltaNet Survives 4-Bit Quantization: NVFP4 W4A4 for the Recurrent Half of a Hybrid 27B LLM (Minima)
- **链接**：https://arxiv.org/abs/2609.04098
- **作者**：Sergii Kozyrev, Davyd Maiboroda
- **TL;DR**：混合 LLM 里线性注意力层（Gated DeltaNet）的循环状态被普遍认为"误差会随长上下文累积"而在早期 4-bit 量化中被保留高精度；作者构建 Minima，把 496 个线性层（含 GDN 的衰减/写入门）全量 NVFP4 W4A4，实测在多基准上追平 BF16，并给出**机制性解释**为何循环半边反而最易量化。
- **解决什么问题 / 为什么重要**：命中我关注的**机制/现象分析 + 表征几何（residual stream/结构）+ 连续状态/SSM**。它不是调参而是回答"为什么"，其四段机制研究涉及残差流离群值、门参数化敏感度、delta-rule 递推的噪声动力学——对理解循环/状态空间层的数值稳定性有基础价值。
- **核心方法**：对 Qwen3.8-27B（48 GDN 层 + 16 注意力层）全线性层施加 NVFP4 W4A4；四段机制研究：(i) NVFP4 的 16 元素块缩放把残差流极端离群值局部化、均衡各层角色的激活误差；(ii) 被认为脆弱的门投影其实最不敏感（softplus/exp 与 sigmoid 参数化把约 11% GEMM 误差压到约 2% 输出误差）；(iii) delta-rule 递推把注入噪声维持在平台而非累积、并在数百步内遗忘状态脉冲（每次写入沿当前 key 方向覆盖状态）；(iv) 逐 token 量化成本随上下文摊薄而非复利累积。
- **主要结果**：在 4K/32K 困惑度、MMLU-Pro、GSM8K、AIME'25、GPQA-Diamond、LiveCodeBench、RULER(至 64K) 上，Minima 在种子噪声范围内追平 BF16（5 任务均值 -0.52），同时是所比方案中最小（17.5 GiB）、prefill 最快（+14–19%），且 32K 困惑度差距随位置缩小。
- **值得追问 / 局限**：结论基于特定混合架构（GDN + softmax 注意力）与 NVFP4 块缩放，能否外推到其它线性注意力/SSM 变体（如非 delta-rule 的门控递推）待验证；"每次写入沿 key 方向覆盖状态"带来的遗忘特性对需要长程精确记忆的检索任务是否有隐性代价，值得进一步压测。
