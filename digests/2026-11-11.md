## A. 核心方法

### 1. Causal Concept Explanations for Deep Neural Models
- 链接：https://arxiv.org/abs/2611.14407
- 作者：Josh Rountree, Pulkit Verma, Oswin So, Chuchu Fan, Julie A. Shah（MIT 等）
- 分类：cs.LG / cs.AI（pub 2026-11-10）
- **TL;DR**：提出 CCW-Net，首次把经济学/医学/流行病学里的"介入式中介分析"当成训练目标，强制概念解释对模型输出既必要又充分、且彼此独立，让概念级解释从"相关"升级到"可量化因果"。
- **解决什么问题 / 为什么重要**：现有概念解释大多是相关性的——一个概念解释可能既不必要也不充分，看起来对却在误导，这对自动系统的认证与部署是硬伤。把因果约束内生进训练，正是 A 方向"内生/自解释"的核心诉求（而非事后归因）。
- **核心方法**：用反事实概念表征锚定三条因果对齐准则——必要性（把无关概念效应逼近 0）、充分性（相关概念表征要能完整重建模型输出）、独立性（总效应在概念间线性分解）；中介分析同时用作训练目标与评估工具，可逐"概念标签组合"量化输出中有多少可因果归因于某概念。
- **主要结果**：在飞机控制、驾驶、图像分类三类任务上评估，给出了可量化因果的概念解释，支持更安全的评估/认证/部署（论文定位为"迈向因果概念解释"的方法学一步）。
- **值得追问 / 潜在局限**：线性可分解的总效应假设在概念高度纠缠时是否成立、三条准则间是否存在优化冲突，需看原文消融；对分类精度的代价、以及在更大规模/语言模型上的可扩展性尚待验证。

### 2. A Concept-Based Interpretable Framework for Clinical Text-based Prediction via Token-Concept Attention without Concept Supervision
- 链接：https://arxiv.org/abs/2611.13564
- 作者：Jifan Gao, Junjie Hu, John Caskey, Madeline Oguss, Simona Cristea, Anoop Mayampurath
- 分类：cs.CL / cs.AI（pub 2026-11-10）
- **TL;DR**：用一个"token-概念"交叉注意力瓶颈，在**不需要概念标注**的情况下，为临床文本预测提供概念级（队列级 + 患者级）解释，性能与黑盒仅差 0.02 AUROC。
- **解决什么问题 / 为什么重要**：概念瓶颈类方法通常要概念标注来训练，在临床文本上标注代价极高。本文让"自解释概念"摆脱概念监督，直接命中 A 方向的内生可解释，同时服务高风险医疗落地。
- **核心方法**：临床文本与医学概念的文字描述先经预训练语言模型 tokenize 并嵌入；交叉注意力模块逐 token 估计每个概念的存在度，得到概念相关性分数，刻画概念如何贯穿整篇病历；分数池化后进入线性预测层，以可解释方式建模临床结局。
- **主要结果**：两项任务——私有数据集上的胸外伤严重度分层、MIMIC-III 上的院内死亡率预测——AUROC 均落在对应黑盒模型的 0.02 以内；并能给出队列级（整体概念重要性）与患者级（个体概念贡献）两层解释。
- **值得追问 / 潜在局限**：无监督估计的"概念存在度"是否与临床真实概念一致、会否出现概念泄漏或虚假对齐，需人因/临床验证；概念池来自文字描述，其覆盖度和措辞偏差会直接影响解释质量。

## B. 应用场景

### 3. ScaleBrain: A Scale-Consistent Framework for EEG Foundation Models
- 链接：https://arxiv.org/abs/2611.14035
- 作者：Minyu Zhou, Yajing Wu, Yongqiang Tang, Wang Jia, Wensheng Zhang（中科院自动化所等）
- 分类：cs.LG / eess.SP / q-bio.NC（pub 2026-11-10）
- **TL;DR**：只用 5.0M 参数的脑电（EEG）基座模型，在输入侧和优化目标侧同时协调多尺度表征（多尺度 tokenization + 尺度专属重建），并用轴向时空注意力做空间/时间上下文融合。
- **解决什么问题 / 为什么重要**：现有 EEG 基座多在特征层构造时间尺度，导致"学到的特征"与"原始信号的尺度特性"对应关系隐式、且自监督目标与多尺度输入不对齐，某些时间尺度监督不足。这是脑功能时序（与我关注的 fNIRS 同属神经血管/脑信号时序）这一应用方向的表征基础设施问题。
- **核心方法**：多尺度 EEG tokenization——用不同时间跨度、共享时间锚点的分析窗表示同一段 EEG；配尺度专属重建，在自监督中对各时间分辨率都提供监督；再用轴向时空注意力沿空间与时间维度语境化融合后的多尺度表征。
- **主要结果**：在 6 个公开 BCI 基准、对比 12 个代表性基线，5 个数据集上取得最高平均 Balanced Accuracy、第 6 个排第三，且仅 5.0M 参数，参数效率优。
- **值得追问 / 潜在局限**：方法针对 EEG 的多尺度与电极空间结构，迁移到 fNIRS（慢血流动力学、发色团、探头布局异质）需验证"时空锚点/轴向注意力"是否同样适配；跨设备/跨受试者的外部泛化与下游任务广度可追读原文。

### 4. TimeSeek: Multi-Task and Multi-Domain Pretraining for Generalized Time Series Analytics
- 链接：https://arxiv.org/abs/2611.14491
- 作者：Peng Chen, Yihang Wang, Zhongwen Rao, Yang Shu, Yuying Qiu, Yuxuan Chen
- 分类：cs.LG（pub 2026-11-10）
- **TL;DR**：提出一个统一预测 / 异常检测 / 分类的时序基座模型，用"多域特征提取器 + 多任务协同训练"同时利用任务特异性与共性，而非单纯堆 Transformer 层。
- **解决什么问题 / 为什么重要**：现有时序基座要么靠堆层扩参、难以自适应建模多域复杂模式，要么只为单一任务（如预测或异常检测）预训练、不能兼顾任务共性与特异性。异常检测是我关注的监控/告警方向，统一基座若能零/少样本做 TS 异常检测很有落地价值。
- **核心方法**：多域视角——多域特征提取器按域特性自适应捕捉时间依赖与通道相关（含渐进多尺度建模、自适应槽通道建模）；多任务视角——多任务协同训练通过任务定制 + 跨任务训练，统一多任务预训练。
- **主要结果**：在大规模时序数据上预训练后，在预测、异常检测、分类三类任务上、且在少样本与零样本设置下均取得 SOTA，推理效率也较好。
- **值得追问 / 潜在局限**：异常检测具体用哪些数据集/指标、与专门的 TS 异常检测 SOTA 的同台对比强度，需看原文；"多域自适应"在分布差异极大的真实运维日志/指标上的迁移上限仍待检验。

## C. Agent / 机制与表征

### 5. Coding Agent Memory Post-Training II: Unlocking the Memory Potential of Pre-trained File Operations for Long-Horizon Tasks via On-Policy Distillation
- 链接：https://arxiv.org/abs/2611.14009
- 作者：Lirui Luo, Kelong Mao, Xinwei Yang, Rongqing Li, Luyu Chen, Kieran Wong
- 分类：cs.LG / cs.AI / cs.CL（pub 2026-11-10）
- **TL;DR**：让编码 Agent 把"写什么、读什么、何时读写"的记忆控制变成策略本身——不引入模型没见过的记忆工具，而是复用预训练里的**文件操作（Bash + 可持久工作区）**作为跨上下文的记忆，用全异步在策略蒸馏（OPD）训练。
- **解决什么问题 / 为什么重要**：长程任务的交互历史超出上下文，Agent 必须决定记忆的读写。此前 OPD 依赖模型预训练外的记忆工具/压缩协议，双向都被削弱——教师没用过该接口给不了有用指导，学生采到的有意义记忆动作太少。记忆是我关注的 Agent 机制"优先"主题，这篇正面攻它。
- **核心方法**：提出 CAMG-II 环境套件（Shop/Coding/AutoResearch/General/Visual，每个环境除原生接口外提供普通 Bash 访问与"按 episode 持久"的工作区，策略可创建/修改/检索/复用文件作为记忆）；CAMP-II 用全异步 OPD、从一个"带文件操作先验"的冻结教师出发，跨五个环境联合训练单一策略学习文件式记忆行为。
- **主要结果**：在 CAMG-II 上，CAMP-II 取得最强 OPD 基线 2.97 倍的增益；所学记忆行为能泛化到两个外部基准 Terminal-Bench 2.1 与 SWE-Bench Pro V2，成功率提升。
- **值得追问 / 潜在局限**：收益多大程度来自"文件操作是预训练分布内"这一先验、而非 OPD 本身，需与"同样复用文件但不蒸馏"的对照比较；跨环境联合训练是否存在任务间干扰、记忆策略在更长程/更异质任务上的稳定性仍待观察。

### 6. Transformers Provably Learn Graph Search: Training Dynamics and the Exponential Power of Depth
- 链接：https://arxiv.org/abs/2611.13594
- 作者：Xutao Ma, Somayeh Sojoudi（UC Berkeley）
- 分类：cs.AI（pub 2026-11-10）
- **TL;DR**：以有向图上的路径搜索作为多步推理的符号抽象，给出 Transformer 实现 DFS 的表达力刻画（两层必要且充分做近线性 DFS，深度每加一层 look-ahead 视野指数级扩大），并证明两层 Transformer 可经梯度流**可证地学会** DFS 并泛化到未见图。
- **解决什么问题 / 为什么重要**：LLM 怎样获得推理能力、推理效率由什么决定仍不清楚。本文从训练动态与深度角度给出机制性解释——同时命中 C 方向的"训练动态"与"机制分析"，并与我关注的图结构问题相接。
- **核心方法**：先做表达力分析——证明一层 Transformer 在稠密图上实现 DFS 子节点选择原语需 Ω(N²) 规模，而两层只需 O(N log N)；对 k≥3 层，k 层可实现 look-ahead 视野 1+2^(k-3) 的有界可达 DFS 策略，视野随深度指数增长；再超越表达力，证明在适当编排的训练数据下两层 Transformer 可经梯度流学会执行 DFS 并泛化。
- **主要结果**：给出"深度如何扩展有界 look-ahead""搜索算法如何经训练涌现"的可证机制账目；两层模型在精选数据上可学到 DFS 并泛化到未见图。
- **值得追问 / 潜在局限**：结论建立在精选训练数据与 DFS 这一特定算法上，自然语料训练出的真实 LLM 是否走同样机制、是否学到的是 DFS 而非近似启发式，仍需在更真实设置上检验。
