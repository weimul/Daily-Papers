## 1. BrainRiem: Riemannian Prototype Learning for Source-Free Cross-Site Brain Network Diagnosis
- 链接：https://arxiv.org/abs/2606.29200
- 作者：Kunyu Zhang, Tianxiang Xu（共 2 人）
- 方向：B（脑功能网络 / neuroimaging time series）+ A（横切：原型/内生可解释）——直击我对 fNIRS/脑网络的兴趣，且方法是内生原型而非 post-hoc
- **TL;DR**：多站点 fMRI 做精神疾病诊断时，扫描仪/人群/采集协议差异带来严重域漂移，而传统域适应要同时访问源域与目标域数据、违反临床隐私。作者提出 **BrainRiem**：在 SPD 流形上学一组**紧凑的黎曼脑原型**，只把匿名原型传到目标站点做无源域适应（source-free）。
- **解决什么 / 为什么重要**：功能连接矩阵本质是 SPD（对称正定）矩阵，欧氏运算会扭曲几何、损坏诊断模式——这正是脑网络分析里常被忽视的几何坑。BrainRiem 把"隐私合规（不传原始数据）"和"几何正确（原型始终是合法 SPD 矩阵）"两件事一起解决，而且原型本身可解释，是我关注的"内生自解释 + 脑网络"交叉点上少见的干净落点。
- **核心方法**：流形感知的双层优化学习黎曼脑原型；用 **Log-Euclidean 度量**保证原型保持合法 SPD 矩阵；用 **Dirichlet 能量谱校准**让原型的频率特性对齐真实脑网络；目标站点仅以收到的匿名原型为稳定锚点训练本地模型，无需源数据。
- **主要结果**：在 ABIDE 与 REST-meta-MDD 上，跨不同扫描仪/人群一致优于 SOTA 的 source-free、传统及图域适应方法；学到的原型呈现**生物可解释的连接模式**、与既有神经科学发现吻合，作者以此论证黎曼几何对脑网络分析的必要性；并称在所评估的攻击下降低了泄露风险。
- **追问 / 局限**：(1) 隐私论证只在"所评估的攻击"下成立，匿名原型对更强的重构/成员推断攻击是否仍安全，需要更对抗性的评测。(2) 方法绑定 fMRI 的 SPD 功能连接表示——能否迁移到 fNIRS 这类时间分辨率高、通道少、信噪比不同的脑功能近红外数据，是我最想追问的点。

## 2. Disentangling Continuous-Time Latent Dynamics: Identifiability of Latent SDEs via Diffusion Shifts
- 链接：https://arxiv.org/abs/2606.28228
- 作者：Yuanyuan Wang, Wenjie Wang, Haoxuan Li, Mingming Gong, Kun Zhang（共 5 人）
- 方向：A（连续时间模型 / 不规则采样隐动力学 + 因果表征可辨识性，横切自解释/解耦）
- **TL;DR**：离散时间隐因果模型的可辨识性已有不少结果，但**连续时间隐 SDE**的可辨识性基本是空白。作者用"环境诱导的扩散协方差漂移"补上这块：证明在加性噪声隐 SDE、共享 drift、环境特异扩散协方差的设定下，**两个对角扩散 regime（坐标方差比两两不同）即可把隐坐标辨识到置换+缩放**，且不需要对 drift 做任何稀疏假设。
- **解决什么 / 为什么重要**：这是我连续时间建模这条线的"地基性"结果——它不是又调一个 Neural/Latent ODE-SDE，而是回答"在连续时间隐空间里，到底什么条件下能把真实潜变量与因果结构唯一辨识出来"。把可辨识性从离散时间推进到连续时间 SDE，对所有用 latent ODE/SDE 处理不规则采样序列的工作都是底层支撑。
- **核心方法**：研究通过未知非线性微分同胚观测的加性噪声隐 SDE；先在线性 Ornstein–Uhlenbeck 系统上证明辨识结论，再推广到一般加性噪声隐 SDE；在温和光滑性下，瞬时 drift-Jacobian 因果图可辨识到同一置换；据此设计**两阶段估计器**（先解耦隐坐标、可选地再恢复因果图）。
- **主要结果**：合成系统实验证实了预测的可辨识性边界；并在 Hardanger 大桥的真实结构监测传感器轨迹上做了应用示范，说明该框架可落到真实连续时间传感数据上。
- **追问 / 局限**：(1) 核心假设是"环境间共享 drift、仅扩散协方差变"且需"两两不同的坐标方差比"——现实多环境数据未必满足，drift 本身随环境变时结论是否退化值得追问。(2) 大桥案例只是示范性应用，缺少与既有 latent-ODE/SDE 基线在下游任务（预测/插补）上的定量对比。

## 3. Estimation–Prediction Tradeoff in Causal Probabilistic Temporal Graphs
- 链接：https://arxiv.org/abs/2606.28225
- 作者：Aniq Ur Rahman（独作）
- 方向：A（时序图 / 时序链接预测 + 因果参数恢复）
- **TL;DR**：时序链接预测通常只看"在未见边上的预测准确率"，但在概率时序图里这会把**模型误差**和**不可约的内在不确定性**混为一谈。作者刻画了一个内在的**估计–预测权衡**：让 Fisher 信息最大、参数最可恢复的 regime，恰恰也是熵最高、单条边预测天然最难的 regime。
- **解决什么 / 为什么重要**：这条对我评估时序图模型很关键——它点破了"预测准确率高 ≠ 学到了底层因果机制"。换句话说，一个模型可能在链接预测指标上不漂亮，仅仅是因为该过程本身不可约不确定性高，而非它没学到机制。这直接质疑了现有 temporal link prediction 基准的评测哲学。
- **核心方法**：提出一个**概率因果框架**生成带瞬态边、且具有已知 ground-truth 因果结构的时序图，使得时序链接预测能与因果参数恢复**联合评测**；对所提的二元 logistic 参数化，推导 **Cramér–Rao 下界**，并验证参数估计误差与不可约预测损失之间的权衡。
- **主要结果**：实验证实预测准确率单独并不能反映模型是否学到了底层因果机制，呼吁设计**能区分"可约模型误差"与"内在过程不确定性"**的时序图基准。
- **追问 / 局限**：(1) 分析建立在二元 logistic 这一特定参数化上，结论能多大程度推广到主流 TGN/CTDG 这类高度非线性的时序图网络，仍需验证。(2) 是诊断性/理论性工作，给出了"该怎么评测"的方向，但还没给出可直接套用的标准化基准与协议。

## 4. GNBAN: Graph Neural Basis Attention Networks for Long-Horizon Forecasting over Large Entity Sets
- 链接：https://arxiv.org/abs/2606.27863
- 作者：Janak M. Patel, Anirudh Deodhar, Dagnachew Birru（共 3 人）
- 方向：A（异构图表示 + 内生可解释的时序预测，无 post-hoc 归因）
- **TL;DR**：零售底层需求预测要对成千上万条相关的长程序列联合建模，既要规模化又要可信可解释。**GNBAN** 把异构图表示学习与一个**可解释的基分解头**结合：不直接预测整段 horizon，而是把每条预测分解成趋势、季节、通用三类成分，并对每个基函数配一套**独立的注意力查询**去各自检索历史邻域。
- **解决什么 / 为什么重要**：这正中我"内生/自解释"横切重点——它的可解释性来自架构本身（per-basis attention 让不同基特化到不同时间模式），而非事后再贴归因。同时它用单一异构图模型覆盖整个目录，回应了"图预测器规模化"与"长程预测可信"这对矛盾，对带关系结构的多实体时序预测有直接借鉴。
- **核心方法**：直接由关系型 schema 构造异构图，单模型服务全目录；预测端用基分解（trend/seasonal/generic）替代直接回归 horizon；核心创新是 **per-basis attention**——每个基保留自己的可学习 query，独立地从实体历史邻域取信息，使各基特化到不同时间模式且保留可解释性。
- **主要结果**：在 M5 Walmart 与 Favorita Grocery 两个大规模基准、相同协议下，相对匹配的图基线**体量加权 WRMSSE 提升约 4–5%**；定性分析显示学到的分解能直接暴露趋势/季节/残差需求驱动因素，无需 post-hoc 解释方法。
- **追问 / 局限**：(1) 4–5% 的增益是相对"匹配的图基线"，与最强的非图长程预测器（如 patch/foundation 时序模型）的横向对比缺失。(2) 基分解的"可解释性"目前是定性展示，缺少对分解忠实度（faithfulness）的定量评估。

## 5. A Multi-Dataset Benchmark for Evaluating LLM Agents in Microservice Failure Diagnosis
- 链接：https://arxiv.org/abs/2606.29193
- 作者：Yuanhong Cai, Xiaohui Nie, Kanglin Yin, Changhua Pei, Yongqian Sun … Dan Pei（共 11 人；含清华裴丹组等）
- 方向：B（监控告警 / AIOps / 根因定位 RCA）+ C（agent 评测）
- **TL;DR**：LLM agent 正把微服务运维推向 **AgentOps**，但现有基准多是"只看最终答案"的结果导向，无法评估诊断过程中的系统性推理。作者放出两个大规模数据集（**AIOps2025、RCA100**），用"推理过程评测"范式从**定位（Localization）/ 识别（Identification）/ 依据（Reason）** 三个维度衡量 agent 的诊断能力。
- **解决什么 / 为什么重要**：这条对我监控告警/RCA 这条应用线很对口，而且它的角度正是我偏好的"机制/过程"而非"刷分"——它不满足于"根因猜没猜对"，还要看 agent 的推理轨迹**是否扎根在相关证据上**。over-500 例专家标注、跨资源/网络/运行时/中间件/应用逻辑五类故障，给 agent 的学习与过程评测提供了细粒度因果证据。
- **核心方法**：构建覆盖 HipsterShop 与 OpenTelemetry Demo Store 两套代表性微服务系统的 500+ 专家标注故障案例；定义三维评测（定位/识别/依据），对多模态可观测性数据（日志/指标/调用链）下的 agentic 诊断做过程级评分；数据集经大型竞赛（6000+ 参赛队）验证。数据已开源。
- **追问 / 局限**：(1) 两套系统都是 demo 级电商微服务，规模与真实生产环境（数百服务、噪声告警风暴）的差距，可能让"过程评测"的结论偏乐观。(2) "推理依据是否 grounded"如何自动、可复现地打分（靠人工还是 LLM 裁判）是这类过程评测的关键风险点，值得细看其标注与评分协议。

## 6. Symbolic Mechanistic Data Attribution: Tracing Training Influence to Learned Behavioral Policies
- 链接：https://arxiv.org/abs/2606.29171
- 作者：Reza Habibi, Darian Lee, Magy Seif El-Nasr（共 3 人）
- 方向：C（机制可解释 / 训练动态——"优先"类：把数据归因接到 SAE 符号化策略上，回答"训练数据如何塑造高层行为决策"）
- **TL;DR**：现有数据归因能指出"哪些训练样本搭起了某个机制回路"，但说不清"训练数据如何塑造模型学到的高层行为决策"。**SMDA** 在 SAE 特征上拟合闭式 Ridge 回归来建模目标行为，再**解析地**把每个 SFT 样本对该策略的影响拆成"特征激活位移 ΔX"和"输出概率位移 ΔY"两条通路。
- **解决什么 / 为什么重要**：这正是我最关心的机制线——把 mechanistic interpretability（SAE 特征）和 data attribution（训练影响）缝在一起，得到一个比黑箱影响函数更细粒度、又比手工回路分析更可扩展的诊断工具。它回答的是"行为（如拒答）是被哪些训练样本、经由哪些特征写进去的"，对理解训练动态与安全行为成因很有价值。
- **核心方法**：在 SAE 特征上对目标行为做闭式 Ridge 回归得到**符号化策略**；对每个 SFT 训练对，解析分解其经 ΔX（特征激活）与 ΔY（输出概率）两条通路对策略系数的位移；在 Llama-3.2-3B-Instruct 上蒸馏"拒答行为"的符号策略并分析 200 个 SFT 训练对。
- **主要结果**：(1) 符号策略系数暴露了 base 模型在"宗教刻板印象"等类别上的系统性安全空白；(2) 逐特征 ΔX/ΔY 分解能机制性地解释为何有害/无害样本对某些特征施加了**性质不同**的影响；(3) 单个训练对常存在**跨特征干扰**，SMDA 能识别出"主要效应落在非预期特征上"的训练对。
- **追问 / 局限**：(1) 闭式 Ridge + SAE 特征建模"行为策略"是一种线性近似，对更复杂、非线性的行为（多步推理、规划）能否同样保真，存疑。(2) 仅在单模型（Llama-3.2-3B）单行为（refusal）、200 个样本的小规模上验证，结论在更大模型/更大 SFT 集上的稳定性待考。
