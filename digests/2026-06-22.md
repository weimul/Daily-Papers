## 1. Anomaly Detection for Sparse and Irregular Multivariate Time Series with Latent SDEs
- 链接：https://arxiv.org/abs/2606.18898
- 作者：Martin Uray, Dominik Geng, Florian Graf, Stefan Huber, Roland Kwitt（PLUS Salzburg 等）
- 方向：A（不规则采样 + 连续时间）× B（监控 / 异常检测）
- **TL;DR**：用潜在随机微分方程（Latent SDE）把稀疏、不规则采样的多元时序投影到连续时间随机动力系统上做异常检测，原生处理缺测与不规则采样。
- **解决什么 / 为什么重要**：现实工业监控、网络安全、医疗里的时序往往稀疏、不规则、部分可观测，但多数 MTS 异常检测方法假设均匀采样。把"不规则"当一等公民处理，正好踩在我关注的连续时间 + 监控交叉点上。
- **核心方法**：以 Latent SDE 建模连续时间潜在动力，直接吸收缺测与不规则时间戳，同时天然刻画很多场景固有的周期性行为；以重构 / 似然偏差作为异常分。
- **主要结果**：6 个异常检测基准上综合排名第一；在严重稀疏化下仍稳健，而对比基线性能显著退化。
- **追问 / 局限**：(1) SDE 求解 + 似然估计的训练与推理成本相对离散基线如何？(2) "周期性 inductive bias" 对非周期突发型异常是否反而带来偏置。

## 2. Hierarchical ODE: Learning Continuous-Time Physical Prototypes for Early Link Failure Detection
- 链接：https://arxiv.org/abs/2606.14284
- 作者：Jiaen Lv, Leran Qi, Shaowei Wang
- 方向：A（Neural ODE + 原型 / 自解释 + 不规则采样）× B（监控 / 链路故障预警）
- **TL;DR**：用分层 Neural ODE 聚类网络把不规则时序的潜状态演化建成连续积分曲线，自动学出物理"原型"，用于链路早期故障检测。
- **解决什么 / 为什么重要**：离散架构难以把随机噪声和连续动态解耦，且固定闭集（预设原型数）假设难覆盖未见多样性。这篇把"连续动力学 + 原型自解释 + 不规则采样"三件我重点关注的事拧在一起，且落在监控告警场景。
- **核心方法**：Neural ODE 建模潜状态连续演化以强制时间连续性、剥离平滑趋势与随机噪声；自适应分层机制自动决定原型数量，无需刚性先验。
- **主要结果**：在不规则采样时序的早期链路故障检测任务上有效提取底层物理原型，实现稳健故障检测（已开源）。
- **追问 / 局限**：(1) 学到的"原型"在工程语义上是否真可解释、能映射到具体故障模式？(2) 分层原型数自适应在分布漂移下是否稳定。

## 3. INDEQS: Informed Neural controlled Differential EQuationS
- 链接：https://arxiv.org/abs/2606.19138
- 作者：Michael Detzel, Gabriel Nobis, Kristiyan Blagov, Juri Schubert, Jackie Ma, Wojciech Samek（Fraunhofer HHI 等）
- 方向：A（时空图 + 连续时间 CDE）
- **TL;DR**：把有向图结构先验注入 Neural Controlled Differential Equations，分离"节点间内部混合"与"向量场—控制信号外部混合"，得到既轻量受约束、又可自适应学习额外连边的两档变体。
- **解决什么 / 为什么重要**：图结构 + 连续时间控制微分方程，正对我"时空图 GNN × 连续时间模型"的核心方向；它系统讨论了把已知图先验融入 CDE 的方式。
- **核心方法**：内/外混合解耦，外层"informedness"用自适应图卷积学习额外连接；连续解码器替代离散解码。
- **主要结果**：合成平流仿真 + 真实任务（河流径流预测、交通预测）上，外层 informedness 一致提升性能，在更大图上尤其明显；连续解码优于离散。
- **追问 / 局限**：(1) "informed" 先验质量较差或图本身误设时，外层注入会不会反伤性能？(2) 与纯数据驱动自适应图相比，先验带来的样本效率收益有多大。

## 4. Existence Precedes Value: Joint Modeling of Observational Existence and Evolving States in Time Series Forecasting (Timeflies)
- 链接：https://arxiv.org/abs/2606.13571
- 作者：Yifan Hu, Hongzhou Chen, Peiyuan Liu, Yiding Liu, Zewei Dong, Jiang-Ming Yang（蚂蚁等）
- 方向：A（不规则采样时序 / 连续时间）
- **TL;DR**：指出现有 Neural ODE / 连续时间图网络在推理时偷偷假设"未来有效观测的时间戳已知"，提出把预测重构为"未来是否会有观测（observability）+ 数值"的联合问题。
- **解决什么 / 为什么重要**：传感器休眠、传输延迟、事件驱动采样让真实时序高度不完整；"未来某刻到底有没有有效观测"本身才是更根本的问题。这戳破了不规则时序建模里一个常被忽视的 oracle 假设，对监控类事件流场景尤其切题。
- **核心方法**：双流（观测流 + 数值流），通过可靠性感知嵌入、观测引导依赖建模、联合预测三模块耦合；提出 Shadow 基准与 Observation-Value Joint Entropy (OVJE) 指标。
- **主要结果**：在多数据集上一致优于现有方法，验证显式建模"未来可观测性"的重要性（已开源数据与代码）。
- **追问 / 局限**：(1) observability 预测错误如何向数值预测传播、是否有误差放大？(2) OVJE 指标与下游决策代价的对应关系。

## 5. RECTOR: Masked Region-Channel-Temporal Modeling for Affective and Cognitive Representation Learning
- 链接：https://arxiv.org/abs/2606.15278
- 作者：Jinhan Liu, Mahsa Shoaran（EPFL）
- 方向：B（脑网络 / 神经时序）× A（时空 + 自监督 / 内生可解释）
- **TL;DR**：面向 EEG/sEEG 的端到端自监督框架，联合做 region–channel–temporal 表征学习，用自适应功能分区取代固定解剖先验。
- **解决什么 / 为什么重要**：情感与认知障碍表现为跨脑区、跨通道、跨时间的动态脑网络，对鲁棒表征学习是难点。虽然是 EEG/sEEG 而非 fNIRS，但"脑功能时序 + 脑网络 + 自监督 + 可解释区域/通道洞察"这套思路可直接迁移到我做的 fNIRS / 脑网络分析。
- **核心方法**：RECTOR-SA 用自适应功能分区诱导分层块稀疏自注意力，让区域结构从静态解剖定义演化为自适应功能区；自监督联合优化 Masked Predictive、Topological Structure、Cross-View Consistency 三目标。
- **主要结果**：在多基准上取得 SOTA 的 EEG 情绪识别与 sEEG 任务参与度分类；对缺失通道鲁棒、跨蒙太奇泛化，并给出可解释的区域/通道级洞察。
- **追问 / 局限**：(1) 自适应功能分区学到的"功能区"与已知神经解剖/网络是否一致、可验证？(2) 这套 region-channel-temporal masking 在 fNIRS 这类通道更少、时间更慢的模态上是否仍有效。

## 6. Leverage Is Not Reach: A Control-Window Law for Single-Neuron Steering in Language Models
- 链接：https://arxiv.org/abs/2606.19831
- 作者：Hongliang Liu
- 方向：C（agent / 机制与表征分析 —— "优先"类）
- **TL;DR**：给"单神经元干预能否稳定操控模型行为"建立理论框架，提出"控制窗口律"：只有当行为触发点落在"坍缩天花板"之下时，相干可控才成立。
- **解决什么 / 为什么重要**：这是机制可解释 / 表征几何方向的工作，把单神经元 steering 从"固定剂量轶事"重述为"有预算、有类型的可控性审计"，对理解残差结构里单元—行为映射的边界有意义，符合我对 agent 类"优先机制/现象分析"的取舍。
- **核心方法**：分析单神经元干预的"杠杆（leverage）"与"触达（reach）"之差，给出 coherent control 存在的条件（trigger 低于 collapse ceiling）。
- **主要结果**：得出控制窗口律，论证单神经元可控性是受预算与类型约束的，而非任意可调。
- **追问 / 局限**：(1) 单作者、偏理论，需看实证覆盖多大模型/任务范围；(2) "collapse ceiling" 是否可在实际模型中先验测得、用于指导干预。
