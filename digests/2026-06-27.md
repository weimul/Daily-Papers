## 1. Explaining Temporal Graph Neural Networks via Feature-induced Information Flow
- 链接：https://arxiv.org/abs/2606.27201
- 作者：Ping Xiong, Thomas Schnake, Klaus-Robert Müller, Shinichi Nakajima（TU Berlin / BIFOLD 一系）
- 方向：A（事件型时序图 GNN + 内生信息流可解释，正是「时序图 × 自解释」的横切重点）
- **TL;DR**：现有针对事件型时序图 GNN（ETGNN）的解释方法只追踪"事件 embedding → 输出"这一小段信息流，漏掉了**事件诱导变量**（event-induced variables）这条中介长程时序依赖的关键通路；本文基于 Normalized Relevance Measure（NRM）框架，对**全部**事件关联变量上的信息流做归因。
- **解决什么 / 为什么重要**：这是我这条主线（时序图 GNN + 内生/自解释）上少见的正面命中。它不是又一个 post-hoc saliency，而是把"事件如何通过中介变量在节点间传播、捕捉长程依赖"显式量化出来，并保证跨层潜变量可比、支持事件间高阶交互分析——对理解动态图模型"为什么这么预测"很有价值。
- **核心方法**：以 NRM 为基础，显式拆出"源自事件 embedding"与"经由事件诱导变量"的两类信息流；再用一套**模块化分解流程**扩展 NRM，把复杂 ETGNN 架构系统地构造成可计算的 relevance 结构，从而支持整条信息流的归因与高阶交互分析。
- **主要结果**：在两个合成数据集（疫情溯源、社交动力学）和一个真实政治事件网络上，定性与定量均一致优于现有解释方法，且产出的解释更贴近人类可读。
- **追问 / 局限**：(1) 评测主要靠合成数据 + 单个真实集，缺少在大规模工业级时序图上的可扩展性与忠实度（faithfulness）压力测试。(2) NRM 的模块化分解需要对架构做人工拆解，换到异构 / 自定义 ETGNN 时这套"构造 relevance 结构"的工程成本与可迁移性如何，值得追问。

## 2. Zero-Shot Size Transfer for Neural ODEs on Sparse Random Graphs: Graphon Limits and Adjoint Convergence
- 链接：https://arxiv.org/abs/2606.26662
- 作者：Mingsong Yan, Zhida Wang, Sui Tang（UC Santa Barbara 一系）
- 方向：A（连续时间图动力学 / Graph Neural ODE 的理论，含 adjoint 训练分析）
- **TL;DR**：Graph Neural Differential Equations（GNDE）用 GNN 参数化 Neural ODE 速度场来建模连续时间图动力学；其局部、与规模无关的滤波器天然暗示"小图训练、大图零样本部署"。本文用 graphon 极限给这一**零样本尺寸迁移**原理建立了定量理论。
- **解决什么 / 为什么重要**：这条正好踩中我的两个核心词——**连续时间动态图 + Neural ODE**——而且是稀缺的理论侧工作。它把"训练在小图、迁移到更大同类图"从经验技巧变成有收敛率保证的命题，对处理规模随时间增长 / 节点数不固定的动态图系统有方法论意义。
- **核心方法**：把前向与 adjoint 的 GNDE 系统的无穷节点极限定义为 Graphon-NDE 与 adjoint Graphon-NDE 并证其适定性；对 $n$ 节点、稀疏参数 $α_n$ 的随机图，证明 GNDE 解逐轨迹收敛到 Graphon-NDE 解，速率 $O((α_n n)^{-1/2})$（对数因子内、高概率）；并给 adjoint 系统（隐状态 / 参数梯度）一致时间收敛界，进一步分析 DTO（先离散后优化）与 OTD（先优化后离散）的 Euler 离散一致性。
- **主要结果**：HSBM 与 tent graphon 实验支持理论速率；跨四类 graphon 的零样本迁移实验显示，学到的 GNDE 能准确部署到独立采样的更大图上。
- **追问 / 局限**：(1) 理论建立在 graphon（稠密极限的稀疏化）假设上，真实动态图常是异配、社团结构强、远非 graphon 可交换性的，迁移界在这些图上还剩多少。(2) 全程是连续时间但"图结构本身固定/由 graphon 采样"，并未覆盖边随时间增删的真正 CTDG 设定。

## 3. Multipath Adaptive Gated Bottleneck Latent ODE with Raman Data Fusion for Cell Culture Process Forecasting
- 链接：https://arxiv.org/abs/2606.26520
- 作者：Johnny Peng, Thanh Tung Khuat, Ellen Otte, Katarzyna Musial, Bogdan Gabrys（UTS 一系）
- 方向：A（不规则采样时间序列 + Latent ODE + mask-aware 瓶颈，应用在生物制药过程预测）
- **TL;DR**：细胞培养过程的测量**稀疏且不规则采样**、早期相似的轨迹后期可能分叉。作者在标准 Latent ODE 上加"变量级可学习门控 + mask-aware 瓶颈"（GB-Latent ODE），再配多路径即时微调（MP-JIT-FT）产出多条带置信度的预测路径，并融合 Raman 光谱作软传感器补稀疏观测。
- **解决什么 / 为什么重要**：直接命中我"不规则采样 / 异步时间序列 + 连续时间模型（Latent ODE）"这条线，而且把**信息瓶颈**思想（mask-aware bottleneck 压缩高维稀疏输入）和"一条相似前缀可能分叉成多个未来"的不确定性处理结合起来——这种"内生地建模多路径 + 置信度"而非输出单一平均预测的做法，比常规 Latent ODE 更贴近真实部署需求。
- **核心方法**：GB-Latent ODE 用变量级门控 + mask-aware 瓶颈在有限数据下学习稀疏不规则输入；给定部分观测的 run，MP-JIT-FT 检索相似历史轨迹、把局部邻域聚成候选 regime、每个 regime 微调一个模型产出多条带重构置信度的路径；再用 ML 软传感器把稠密 Raman 谱转成伪观测增强稀疏离线测量。
- **主要结果**：在 38 个 5L 流加批次（覆盖 14 种条件）上，MP-JIT-FT + Raman 融合取得最佳平均排名，在 9 个目标变量中的 8 个上超过全局 Latent ODE 基线；局部分叉度量显示，多路径增益在"相似前缀后期分叉"时最大，Raman 融合在"早期动态能代表后期"时帮助最大。
- **追问 / 局限**：(1) 数据量很小（38 run / 14 条件），"每 regime 微调一个模型"是否过拟合局部邻域、跨细胞系泛化能力存疑。(2) 多路径置信度来自重构误差，缺少对预测区间是否**校准**（calibration）的评估，工艺干预决策上更关心这个。

## 4. OpenRCA 2.0: From Outcome Labels to Causal Process Supervision
- 链接：https://arxiv.org/abs/2606.27154
- 作者：Aoyang Fang, Yifan Yang, Jin'ao Shang, Qisheng Lu, Junjielung Xu
- 方向：B（根因定位 / AIOps：给 LLM agent 的 RCA 基准，带逐步因果过程标注）
- **TL;DR**：现有 RCA 数据集只标"根因"、不标从根因到观测症状的**传播路径**，把任务简化成了模式匹配。作者提出 PAVE 逐步标注协议——借助故障注入的已知干预、用"从因到果的前向验证"重建因果传播路径——构造出首个带逐步因果标注的跨系统 RCA 基准 OpenRCA 2.0（500 例）。
- **解决什么 / 为什么重要**：正中我"监控告警 / 根因定位 / AIOps"这条应用线，而且抓住了一个我一直在意的痛点：**只看最终结果的评测会掩盖"答对了但推理路径错"的失败模式**。它把"是否答中根因"和"是否把该根因 grounded 到一条可验证的因果传播链"分开度量，对评判 LLM-based RCA agent 是否可信很有方法论价值。
- **核心方法**：PAVE 用故障注入中已知的干预作为"地面真相干预"，以**前向验证**（reasoning cause→effect）而非从症状反推的方式逐步重建因果传播路径；据此为跨系统的 500 个实例打上逐步因果标注，再在 11 个前沿 LLM 上评测精确根因集恢复、以及放宽标准后的"答中至少一个根因服务"与"grounded 到验证路径"两档。
- **主要结果**：11 个前沿 LLM 平均仅在 20.7% 案例中精确恢复根因集；放宽后 76.0% 能答中至少一个正确根因服务，但只有 61.5% 能把它 grounded 到通向症状的已验证因果链——作者称之为"未落地诊断"（ungrounded diagnosis），而 outcome-only 评测完全看不到这一失败模式。
- **追问 / 局限**：(1) 因果传播路径由故障注入的已知干预重建，属于受控注入场景，对真实生产中多故障叠加 / 噪声告警的"路径真值"是否同样可得存疑。(2) 500 例规模 + 跨系统，但每个系统的拓扑/可观测性差异大，逐步标注的一致性与跨系统可比性还需更多说明。

## 5. Structure Before Collapse: Transient semantic geometry in next-token prediction
- 链接：https://arxiv.org/abs/2606.26749
- 作者：Yize Zhao, Isabel Papadimitriou, Christos Thrampoulidis（UBC 一系）
- 方向：C（表征几何 / 神经坍缩 + 训练动态，"优先"类机制分析）
- **TL;DR**：神经坍缩（Neural Collapse）理论预测：在平衡 one-hot 分类下，表征会被推成彼此等距的对称构型、只依赖输出标签而忽略输入语义相似性。但语言模型几乎全程在 one-hot 标签下训练（同一上下文几乎不会带不同标签出现两次），却明显学到了语义结构——本文研究这一张力。
- **解决什么 / 为什么重要**：这是典型的"优先"类机制工作——表征几何 + 训练动态 + 神经坍缩，直指"梯度下降为何能在 one-hot 稀疏共现下找到类别化语义结构"。它把语义结构刻画成一种**瞬态**现象（先涌现、后坍缩），这种"训练中途的相变"视角对理解 LLM 表征如何组织、以及何时该早停 / 探针很有启发。
- **核心方法**：构造三个受控合成设定——输入有潜在语义因子但被映射到彼此不同的 one-hot 标签；观察训练中表征是否按共享属性聚类；用 Gram 矩阵分析刻画这一相变，并对常用的 unconstrained features model 提出初步修改以刻画涌现的语义几何。
- **主要结果**：语义几何在训练**早期**就涌现、表征按共享属性聚类（无任何显式监督）；但该结构是瞬态的——容量与时间足够时，模型最终收敛到理论预测的"全等距对称"坍缩态。
- **追问 / 局限**：(1) 结论建立在三个合成受控设定上，真实大规模 LM 训练中这种"先结构后坍缩"是否同样发生、相变点在哪，需要真模型验证。(2) 对 unconstrained features model 的修改是"初步"的，能否定量预测涌现几何的强度 / 持续时长仍开放。

## 6. Discovering Millions of Interpretable Features with Sparse Autoencoders
- 链接：https://arxiv.org/abs/2606.26620
- 作者：XinYang He, Wei Wang, Bing Zhao, Xuan Ren, WenBo Li
- 方向：C（机制可解释 / 残差流 SAE，"优先"类——附带可发布资源 + 因果干预案例）
- **TL;DR**：SAE 能把语言模型叠加（superposed）的表征拆成稀疏可解释特征，但训练昂贵、开源模型稀缺。作者发布 Qwen3-Instruct SAE 套件——覆盖 Qwen3-1.7B/4B/8B，在残差流、MLP 输出、注意力输出三类激活点训练层级 SAE。
- **解决什么 / 为什么重要**：属于"优先"类的机制 + technical-report 工作：它系统地在**残差流 / MLP / attention 三个站点**训 SAE 并比较稀疏-保真权衡，还做了因果 steering 案例，对研究特征级机制与行为干预是实打实的资源。残差流结构正是我关注的表征几何相关线索。
- **核心方法**：为 Qwen3-1.7B/4B 在三类激活站点训练逐层 SAE、为 Qwen3-8B 在部分残差流层训 SAE；用激活级重构指标与模型级恢复指标系统评测，揭示各层 / 各组件的稀疏-保真权衡；并做"拒答 steering"案例——选定 SAE 特征因果地把指令微调模型推向拒答行为。
- **主要结果**：得到一套覆盖三尺寸、三站点的开源 SAE；评测显示稀疏-保真权衡随层 / 组件显著不同；拒答 steering 案例验证选定特征可**因果**驱动模型行为。
- **追问 / 局限**：(1) 因果验证主要落在"拒答"这一单一行为上，所发现的"百万级特征"中真正单义 / 可干预的比例有多大未充分量化。(2) 评测以重构 + 模型恢复指标为主，特征的人类可解释性 / 单义性缺少大规模人工或自动审计。
