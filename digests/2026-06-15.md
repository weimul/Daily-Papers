## A. 核心方法 · 连续时间 ODE × 自解释原型（不规则采样）

### 1. Hierarchical ODE: Learning Continuous-Time Physical Prototypes for Early Link Failure Detection
- 链接：https://arxiv.org/abs/2606.14284
- 作者：Jiaen Lv, Leran Qi, Shaowei Wang（据 GitHub `NJ-LNN` 推断为南京相关机构）
- submit 日期：2026-06-12
- **TL;DR**：用神经 ODE 把潜状态演化建成"连续积分曲线"，在不规则采样时序上学出可解释的"物理原型"，再用层级聚类自适应决定原型个数，做早期链路故障检测。
- **解决什么问题 / 为什么重要**：几乎同时命中你方向 A 的三个核心点——**不规则采样时序 + Neural ODE 连续时间建模 + 原型式自解释**。它直指时序原型学习的"观测歧义"难题：离散结构无法把随机噪声与连续动力学解耦，且封闭集假设无法覆盖未见多样性。这正是你关心的"内生可解释 + 连续时间模型"如何结合的一个具体范例。
- **核心方法**：层级 ODE 聚类网络，用 neural ODE 将潜状态演化表示为连续积分曲线，借时间连续性把平滑特征趋势从随机噪声中分离；自适应层级机制无需先验约束即可自主确定原型数量；在不规则采样时序上提取底层物理原型用于鲁棒故障检测。
- **主要结果**：在早期链路故障检测（不规则采样时序）任务上有效抽取物理原型并实现鲁棒检测；代码开源（github.com/NJ-LNN/Hierarchical-ODE）。
- **值得追问 / 局限**：① 论文仅在"链路故障检测"单一任务上验证，"物理原型"的语义可解释性是否经人验证、跨域可迁移性未知；② 自适应原型数量机制对超参/初始化的稳定性，以及 neural ODE 在长序列/高维上的求解开销与可扩展性，摘要未给量化。

## A. 核心方法 · 非局部贝叶斯时空动力学（Neural ODE + 不规则稀疏观测）

### 2. Nonlocal Bayesian Modeling of Continuous Spatio-Temporal Dynamics
- 链接：https://arxiv.org/abs/2606.14313
- 作者：Jaeyeong Lee, Heeyoung Kim（韩国 KAIST 工业系统工程方向，据作者背景推断）
- submit 日期：2026-06-12
- **TL;DR**：把连续空间-连续时间的"非局部"动力学建成无穷维积分-微分方程（IDE），用坐标基展开 + 连续时间 ODE（含 Neural ODE 残差）做 Galerkin 降维，配 Kalman 式序贯更新，在不规则、稀疏观测下做带不确定性量化的时空预测。
- **解决什么问题 / 为什么重要**：真实时空预测要同时处理**不规则时间点、空间稀疏观测、不确定性量化**，外加**长程空间耦合（非局部）**——这把你方向 A 的"不规则采样 + 连续时间模型"从时序推广到了连续时空场，且显式建模非局部耦合（而非局部图卷积），方法论上对时空 GNN 是一种互补视角。
- **核心方法**：NLBST 分层贝叶斯框架；潜场用坐标基（coordinate-based）空间基展开，系数过程用连续时间 ODE 建模，其可学习线性算子对应非局部 IDE 的 Galerkin 降维，再叠 Neural ODE 残差捕捉非线性；线性-高斯观测模型支持缺失/不规则下的 Kalman 序贯更新，空间基表示支持对未观测位置的归纳预测（无需重训）；全局参数走变分推断，不确定性由贝叶斯层级处理。
- **主要结果**：合成 + 真实数据上预测与空间泛化均强、不确定性校准良好；在**强非局部、部分观测**的困难场景下相对基线有显著增益。
- **值得追问 / 局限**：① "可学习线性算子≈非局部 IDE 的 Galerkin 降维"是关键假设，当真实耦合远离线性 IDE 结构时，靠 Neural ODE 残差兜底的表达力边界在哪未明；② 坐标基展开的基数/分辨率选择对大规模空间域的可扩展性和计算成本，摘要未给。

## A. 核心方法 · 时空图 GNN（多周期预训练插件）

### 3. MP3: Multi-Period Pattern Pre-training for Spatio-Temporal Forecasting
- 链接：https://arxiv.org/abs/2606.13119
- 作者：Lilan Peng, Yandi Liu, Qingren Yao, Chongshou Li, Tianrui Li（西南交通大学，据作者背景推断）
- submit 日期：2026-06-11（v2）
- **TL;DR**：针对"短窗输入相似但未来走势分叉"的**时间幻象（temporal mirage）**，提出即插即用的多周期模式预训练插件，从长序列学多周期模式增强现有 STGNN，主流骨干上一致涨点。
- **解决什么问题 / 为什么重要**：直击你方向 A 的核心——**spatio-temporal GNN**。作者指出现有 STGNN 因短窗输入"周期观测不完整、全局空间相关异质、跨周期叠加因果"而无法识别时间幻象。"作为预训练插件挂到已有 STGNN 骨干上提性能"这一范式，对你做时空图建模时"如何注入长程周期先验"很有参考价值。
- **核心方法**：两大创新——(1) 多周期模式学习：多周期时序建模用边卷积识别不同周期模式，多周期空间建模用瓶颈投影 + 全局记忆库高效捕捉异质全局空间关系，跨周期模式交互用因果增强 Transformer 捕捉跨周期依赖；(2) 即插即用插件，可无缝接入现有 STGNN 骨干。
- **主要结果**：在 5 个 STGNN 基线 × 5 个真实数据集（含大规模 CA）上验证有效性、可扩展性与适配性；平均降低 MAE 4.7%、RMSE 5.0%，对所有评测骨干均带来一致稳健提升。
- **值得追问 / 局限**：① 平均 ~5% 的提升属稳健但不算颠覆，对哪些数据集/骨干增益最大、何时几乎无效，需看分项；② "记忆库 + 边卷积 + 因果 Transformer"三件套引入的额外参数/预训练成本，与收益的性价比摘要未充分讨论。

## A×B 横切 · 自解释时序异常检测（内生可解释）

### 4. ProtoX-AD: Self-Explainable Time Series Anomaly Detection and Characterization
- 链接：https://arxiv.org/abs/2606.13277
- 作者：Aitor Sánchez-Ferrera, Elisabeth Wetzer, Kristoffer Wickstrøm, Michael Kampffmeyer, Robert Jenssen（挪威 UiT 北极大学 Visual Intelligence/机器学习组，据作者背景推断）
- submit 日期：2026-06-11
- **TL;DR**：给自监督分类式时序异常检测（TSAD）补上"内生可解释"——学变换感知的潜表示 + 可解释原型，既检测异常又能用原型刻画"异常画像"，性能与黑盒相当但解释更一致、更有语义。
- **解决什么问题 / 为什么重要**：同时落在你方向 A 的"intrinsic / self-explaining + prototype-based"与方向 B 的"time-series anomaly"。自监督变换分类式 TSAD 性能强但**缺解释**（说不清被标异常的特征）；ProtoX-AD 用原型把"为什么是异常"显式化，且属于**内生可解释而非 post-hoc**，正是你横切重点偏好的那一类。
- **核心方法**：原型式自解释框架，学习"变换感知的潜表示 + 可解释原型"，通过原型解释识别不同的异常画像；并支持系统分析"变换设计如何影响检测性能与可解释性"。
- **主要结果**：合成 + 真实数据上检测性能与黑盒对照相当，同时比现有可解释基线给出更一致、更具语义的解释；代码开源（github.com/Aitorzan3/ProtoX-AD）。
- **值得追问 / 局限**：① 性能"与黑盒相当"意味着可解释性未带来准确率红利，原型解释的实用价值需结合下游运维场景评估；② 解释质量依赖所选变换族，变换设计本身又是超参，"解释稳健性 vs 变换选择"的耦合是开放问题。

## B. 监控/医学影像 · 脑图匹配做阿尔茨海默诊断（neuroimaging + brain graph）

### 5. GMN4AD: Graph Matching Network for Alzheimer's Disease Diagnosis with Test-Time Domain Adaptation
- 链接：https://arxiv.org/abs/2606.13919
- 作者：Chen Zhao, Huan Huang, Yixin Xie, Jiajing Huang, Weihua Zhou, Nandakumar Narayanan（含 Michigan Tech / Univ. of Iowa 神经科背景，据作者公开信息推断）
- submit 日期：2026-06-11
- **TL;DR**：不再把每个脑图独立处理，而用**图匹配网络**建模异质脑图之间的跨图交互做 AD 诊断，并加测试时域适应（对比学习）缓解多中心域偏移。
- **解决什么问题 / 为什么重要**：落在你方向 B 的 **neuroimaging / brain network**（虽是结构 MRI 而非 fNIRS，但同属脑图/脑网络时空建模脉络）。它的亮点对你有迁移价值：① 用**图匹配捕捉跨脑图关系**而非单图独立建模；② **测试时域适应**应对多中心异质——这两点在 fNIRS 跨被试/跨设备泛化里同样是痛点。
- **核心方法**：GMN4AD 对 neuroimaging（sMRI）衍生的异质脑图做图匹配，捕捉跨图关系以提升诊断精度；引入结合对比学习的测试时域适应策略，在推理阶段缓解域漂移。
- **主要结果**：在 3 个公开 AD 数据集上优于 SOTA，给出更鲁棒、可泛化的 AD（含 MCI 早期）诊断方案。
- **值得追问 / 局限**：① 用的是**结构 MRI** 衍生脑图、属静态结构网络，并非功能时序（fNIRS/fMRI 时间序列），对"脑功能时序结构建模"的直接迁移有限；② 图匹配在被试数增大时的两两匹配复杂度，及测试时适应对小目标域的稳定性，摘要未量化。

## C. Agent · 记忆是否真有用？（机制/现象分析 · 预注册负结果）

### 6. GitOfThoughts: Version-Controlled Reasoning and Agent Memory You Can Replay, Diff, and Merge
- 链接：https://arxiv.org/abs/2606.14470
- 作者：Pavan C Shekar, Abhishek H S, Aswanth Krishnan
- submit 日期：2026-06-12
- **TL;DR**：表面是"把 agent 推理树存成 git 仓库（每个打分 thought 是一次 commit，检索=git log）"，真正的硬核问题是——**记忆到底能不能提升准确率？** 在预注册复现下，对新问题答案是"基本不能"，只有当检索到的案例与当前问题近乎重复（相似度 ≳0.8）时才跳涨。
- **解决什么问题 / 为什么重要**：正中你方向 C 偏好的"**记忆 + 机制/现象分析 + technical report**"，且做了少见的**预注册复现 + 撤回早期结果**的诚实评估。结论对做 agent memory 的人很有冲击：跨 5 种记忆底物（none/markdown/vector/graph/git）、两个 benchmark、两种模型规模，**没有任何记忆格式可靠地帮上忙**；收益来自"答案检索"而非"方法迁移"——4.5× 大模型把近重复样本的收益翻倍，却仍无法从范例中抽出可迁移的方法。
- **核心方法**：GitOfThoughts 把推理树存为 git（thought=commit、score=note、outcome=tag、检索=git log），实现可回放/可审计/可跨 agent 合并；在此之上做对照实验，定义 **copyability threshold（可复制阈值）**——相似度 >~0.8 时准确率陡升，以下则几乎无增益；唯一普适的杠杆是 test-time sampling。
- **主要结果**：对新问题，五种记忆底物均无可靠增益，一个"早期亮眼结果"在自家预注册复现下崩塌（论文主动记录了撤回的结果与被证伪的假设）；git 作为底物的价值定位在"可审计 / 溯源 / 可合并"，准确率与其它底物持平。
- **值得追问 / 局限**：① 结论很可能与所选两个 benchmark 的"问题新颖度分布"强相关——若任务天然多近重复，记忆价值会被低估或高估，"copyability threshold"的普适性需更多任务验证；② "记忆只做答案检索、不做方法迁移"的判断针对当前检索/注入机制，是否换更强的抽象/泛化式记忆就能突破，是开放方向。
