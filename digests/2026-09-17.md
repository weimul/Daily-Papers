## A. 核心方法（连续时间图生成 · 信息瓶颈自解释）

### 1. Stable Filters for Generative Modeling of Graph Signals
- 链接：https://arxiv.org/abs/2609.18759
- 作者：Martin Schmidt, Gonzalo Mateos（2 位作者；机构未在元数据中给出）
- **TL;DR**：面向"在图上生成信号"的连续时间生成模型，分析当图结构被扰动时、漂移里"图滤波器 + 学习到的 GNN"这套动力学如何影响生成分布，推导出显式的 Wasserstein 稳定性界，并据此设计一类结构更稳的图滤波器。
- **解决什么问题 / 为什么重要**：图感知的 Schrödinger bridge 生成模型把拓扑直接写进参考动力学，但"图的相对扰动如何传播、如何改变生成分布"此前不清楚。本文正中核心方向 A 的"连续时间模型 / continuous-time generative"子线，把置换等变与结构稳定性做成可量化的界；且验证信号包含 fMRI 脑信号，落在 B 的神经影像/脑网络应用面，是一篇 A×B 交叉的方法工作。
- **核心方法**：针对漂移为"图滤波器 + 可学习 GNN"的图感知连续时间生成模型，推导相对图扰动对生成分布影响的显式 Wasserstein 稳定性界；受该界启发，提出一套设计原则——让图滤波器保留图热扩散的平滑行为，同时提升结构稳定性，得到"稳定滤波器"。
- **主要结果**：在合成信号与 fMRI 信号上，稳定滤波器增强了对结构扰动的鲁棒性，同时在生成质量上匹配或超过热方程基线。
- **值得追问 / 局限**：① 稳定性界建立在"图滤波器 + GNN"这一特定漂移形式上，换成更一般的可学习动力学时界是否仍紧、可用需验证；② fMRI 上的验证规模与被试/图构建方式未在摘要中展开，向 fNIRS / 脑网络时序等其他神经模态的迁移仍待检验。

### 2. Divide and Conquer: Mixture-of-Bottleneck Experts in Informative Ordinal Space for Video-based Multimodal Sentiment Analysis
- 链接：https://arxiv.org/abs/2609.18470
- 作者：Ronghao Lin, Qiaolin He, Zefeng Lu, Yichu Liu, Li Huang, Sijie Mai（8 位作者）
- **TL;DR**：把视频多模态情感分析（MSA）重构成有序回归，并解耦为"极性识别 + 强度预测"两个子任务；用信息瓶颈驱动的混合瓶颈专家（MoB）为不同模态、不同子任务分配不同隐变量，让每个专家学到紧凑、任务相关且去冗余的表征。
- **解决什么问题 / 为什么重要**：现有 MSA 多把情感当单任务、忽略其有序本质，融合策略也难以刻画各模态独有与协同的线索。本文命中核心方向 A 的"内生/自解释（信息瓶颈）"横切——用 IB 让专家表征天然紧凑、可归因，并声称能更可信地定位细粒度情感信号，属自解释而非纯 post-hoc 归因。
- **核心方法**：把 MSA 建成有序回归并拆成极性/强度两支；用信息瓶颈学习为不同模态分配极性专家与强度专家的不同隐变量，每个专家在压缩中滤除冗余与噪声；再用带难例挖掘的多模态瓶颈路由融合模块把专家隐变量融合，在有序情感空间中引导预测。
- **主要结果**：在 4 个 MSA 数据集、4 个语言模型上，MoB 能有效利用多模态信息隐变量并捕捉整体情感结构；除性能更强外，能更全面地刻画模态内/模态间细粒度动态，支持对细微情感信号更可信的定位。
- **值得追问 / 局限**：① 信息瓶颈的压缩强度（隐变量维度/正则权重）与"可信定位"之间的权衡如何设定、是否需按数据集重调；② "极性 + 强度"的二分解耦对更复杂/混合情感是否够用，向非情感类有序任务的通用性待验证。

## B. 应用场景（异常检测：图异常基础模型 · 可靠时序语言建模）

### 3. FoundAna: A GNN-assisted Foundation Model for Graph Anomaly Detection
- 链接：https://arxiv.org/abs/2609.18107
- 作者：Suprim Nakarmi, Chahana Dahal, Yue Zhao, Junggab Son, Zuobin Xiong（5 位作者；代码开源）
- **TL;DR**：针对图异常检测长期"一数据集一模型"、跨场景迁移差的问题，提出首个面向可泛化跨图异常检测的基础模型框架，用 GNN + Transformer 结合、以重构误差作为异常分。
- **解决什么问题 / 为什么重要**：图异常检测支撑欺诈、垃圾信息、入侵检测等监控告警场景，但任务异构、标签稀缺、域漂移让现有方法难迁移。本文落在应用方向 B 的异常检测（监控/告警型），并把"基础模型 + 跨图泛化"引入图异常检测，同时命中 A 的图方法面，是一篇 A×B 交叉工作。
- **核心方法**：把面向异常检测专门设计的 GNN 组件与标准 Transformer 编码器结合，后者用四种互补的位置编码增强，以同时捕捉局部与全局结构信息；位置编码增强后的节点表征分别过属性解码器与邻接解码器，用重构误差作为异常分。
- **主要结果**：在横跨金融、社交、引文网络三类域的 9 个基准上，FoundAna 一致优于当前最优基线。
- **值得追问 / 局限**：① 重构误差作为异常分对"结构性异常 vs 属性性异常"的区分能力、以及对高异常比例场景的稳健性未在摘要中展开；② "基础模型"跨域泛化是否依赖预训练图分布的覆盖，遇到与训练分布差异极大的新域时零样本表现待验证。

### 4. WaveTLM: Reliable Time-Series Language Modeling through Task Compilation
- 链接：https://arxiv.org/abs/2609.18812
- 作者：Jiahui Chen, Bingke Zhu, Hongyu Pan, Yingying Chen（4 位作者）
- **TL;DR**：面向"时序语言模型输出看似合理却不可靠"的问题（数值序列违反形状/尺度/通道序/时间对齐，或文本决策落到非法标签空间），提出把用户请求编译成带类型的任务状态、再由任务原生执行器构造合法输出的统一"编译器-执行器"模型。
- **解决什么问题 / 为什么重要**：时序语言模型提供跨任务的自然语言接口，但可读的文本不等于可靠的任务对象。本文落在应用方向 B 的时序建模（覆盖预测、插补、分类、**异常检测**、波形分析五类），把"任务对象可靠性"与"预测质量"分离，对监控/时序类落地是一个可靠性抓手。
- **核心方法**：形式化"可靠时序语言建模"，提出契约对齐基准 ExecTS-QA；WaveTLM 的任务编译器把用户请求、可见参数与波形证据转成带类型的任务状态，任务原生执行器据此构造数值张量、合法决策或结构化记录，从而把"看似合理的语言生成"约束为契约有效的时序输出。
- **主要结果**：在 ExecTS-QA 上单一 checkpoint 达到 99.40% 契约有效覆盖率（最强字符串优先基线仅 37.83%），同时在五类任务上保持均衡的预测性能；在 SciTS、TSQA、IRTS-ToolBench、ARFBench 上给出额外迁移证据。
- **值得追问 / 局限**：① "契约有效覆盖率"高不代表预测质量高，二者的实际权衡（尤其异常检测子任务的召回/精度）需看细分指标；② 编译器-执行器对任务契约的显式建模在遇到契约未覆盖的新任务/新参数组合时如何降级，泛化边界待检验。

## C. 机制 / 表征分析（高优先级，取 2 篇）

### 5. Weakening Neurons: An Input-Output Functionality in Transformers with Outsize Influence
- 链接：https://arxiv.org/abs/2609.18612
- 作者：Sebastian Gerstner, Hilal AlQuabeh, Kentaro Inui, Hinrich Schütze（4 位作者）
- **TL;DR**：用一个极简分析——对每个 GLU 神经元计算其"读（输入）权重"与"写（输出）权重"的余弦相似度——发现一类"削弱神经元"（强负相似度，即削弱它在残差流里检测到的方向），并揭示它们虽少却活跃、影响巨大，且在门值为负时反而强烈起作用。
- **解决什么问题 / 为什么重要**：本文正中核心方向 C 的机制分析 + 残差流结构 + 表征几何，给出一个可跨模型复现的读写权重几何视角，把"少数神经元的异常大影响"与"负门值仍编码功能"这两个反直觉现象摆到台面上，为理解 GLU/MLP 的功能组织提供抓手。
- **核心方法**：对基于 GLU 的神经元，计算输入（reading）与输出（writing）权重向量的余弦相似度；强负相似度记为"削弱神经元"，其反面（早中层常见的）为（条件）"强化神经元"；在 9 个 LLM 上统计其层间分布、激活频率与影响，并结合门值符号分析其功能。
- **主要结果**：9 个 LLM 呈现相似模式——削弱神经元主要在晚层、强化神经元多在早中层；削弱神经元数量虽少却激活频繁、对模型行为影响巨大；且在门值为负时对输出有强烈影响（反直觉，因负门值本不被认为编码功能）。
- **值得追问 / 局限**：① 余弦相似度是线性度量，"削弱/强化"二分是否会漏掉更复杂的读写交互（如多方向耦合）需更细刻画；② "负门值仍编码功能"的机制来源（激活函数形状、下游归一化）尚待因果层面的解释。

### 6. Flag Game: A Toy Model for Mechanistic Swarm Interpretability
- 链接：https://arxiv.org/abs/2609.19124
- 作者：Elizabeth Pavlova, Hidenori Tanaka（2 位作者；机构未在元数据中给出）
- **TL;DR**：提出"旗帜博弈"玩具模型研究多智能体集体信念的形成机制——隐藏的国旗是真值，每个有限视野的智能体只看到私有裁剪、但能交换信念并权衡同伴的社会证据；即便如此简单，也复现出丰富的群体现象，并给出从"社会电路归因 + 因果干预"到"统计力学相图"的双重机制解释。
- **解决什么问题 / 为什么重要**：AI 智能体的涌现协同行为正带来安全风险，而其背后"信念快速形成与扩散"缺乏机制理解。本文命中核心方向 C 的机制/现象分析（且是多智能体的表征/信念动力学），把单体机制可解释性的工具（电路归因、因果 patching）推广到"群体"层面，迈出机制化 swarm 可解释性的第一步。
- **核心方法**：构建旗帜博弈，观测"性能随种群规模非单调变化、社会意识提示与团队多样性带来的增益、组织结构的强影响"等现象；用两条互补路径解释集体信念坍缩与极化——① 社会电路归因：预测哪个智能体、哪种观点对集体动力学最关键，并用对智能体的因果干预（patching）验证；② 当种群变大、干预效力下降时，转而发展统计力学理论并用实证相图验证。
- **主要结果**：小种群下集体信念坍缩，随种群增大转为集体信念极化，后者导致大种群下性能下降但也带来信念多样性；社会电路归因的预测被因果干预验证，但其效力随种群增大而下降；统计力学理论与实证相图吻合。
- **值得追问 / 局限**：① 结论建立在"旗帜识别"这一受控玩具任务上，向真实语言智能体群体（开放目标、异构能力）的外推需谨慎；② 社会电路归因在大种群下失效、需改用统计力学描述，说明"个体级机制解释"存在规模上限，如何在中间尺度衔接两套解释仍是开放问题。
