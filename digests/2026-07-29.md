## 1. MR-TGN: A Meta-Role Temporal Graph Network for Team-Level Intent Prediction in Multi-Agent Systems
- arXiv: https://arxiv.org/abs/2607.25316
- 作者：Nagarani Brammanayagam, Devaprakash Muniraj（共 2 位）
- **TL;DR**：多智能体的"集体意图"从复杂交互、演化的协作结构与长期行为依赖中涌现，而各 agent 的功能角色往往是隐的、会随时间变、且几乎没有显式标注。MR-TGN 把智能体建成"动态演化的图实体"，用时序记忆编码历史交互，再用记忆增强的元角色学习从行为表征里无监督地导出隐角色，用于早期集体意图预测。
- **解决什么问题 / 为什么重要**：正对 A 方向"时序图网络 / 动态图"核心重点。它把两件难事叠在一起：动态、部分可观测环境下的群体协作建模，以及"角色隐且时变、无标签"的表征学习；并额外提出面向"早期预测"的评测方法，强调不仅要准、还要"及早"预判集体目标——这对做动态图/事件流上的行为预测、以及监控类"早期告警"场景都有迁移意义。
- **核心方法**：把 agent 建为随时间演化的图节点，用时序记忆机制编码历史交互与协作行为；引入"记忆增强的元角色（meta-role）学习"，从以 agent 为中心的行为表征中导出隐角色表示，无需显式角色标签；并配一套"早期集体意图预测"的评测（同时看准确率与时效性）。
- **主要结果**：在代表性多智能体场景（含动态、对抗环境）上一致优于有竞争力的基线，并能在任务执行早期就有效预测集体意图。
- **值得追问 / 局限**：摘要未给具体量化数字与对比幅度，"consistently outperforms"的强度需看正文；"元角色"是否真的对应可解释、稳定的语义角色（还是仅是有用的隐变量）待验；主类目为 eess.SY、评测多在仿真多智能体场景，向真实事件流/社交时序图的迁移性未展开。

## 2. Contrastive Representation Learning of Longitudinal Disease Trajectories on Temporal Graphs
- arXiv: https://arxiv.org/abs/2607.25609
- 作者：Bastian Pfeifer（共 1 位）
- **TL;DR**：纵向临床数据的疾病轨迹难在时间动态复杂、患者队列异质。本文把多变量疾病轨迹建成时序图——节点是"患者随时间的观测"、边刻画时间连续性与轨迹间结构相似性——再用对比 GNN 学表征，让相似进展模式的患者聚到一起并显露潜在结构。
- **解决什么问题 / 为什么重要**：正对 A 方向"时序图 + 不规则临床时序"。它给"把纵向 EHR 当图、用对比学习学轨迹级表征"提供一个简洁范式：不靠标签、靠结构感知随机游走引导对比，得到既保时间上下文又保轨迹拓扑的嵌入，适合做患者分层/亚型发现——对做疾病进展建模、以及一般"轨迹即图"的时序表征都有参考。
- **核心方法**：将多变量疾病轨迹建为时序图（节点=时序患者观测，边=时间连续性 + 轨迹间结构相似）；用结构感知随机游走（structure-aware random walks）引导对比学习，生成保留时间上下文与轨迹拓扑的嵌入；下游用于患者聚类与潜在结构发现。
- **主要结果**：得到的表征支持对"相似疾病进展模式"患者的稳健聚类，并能揭示纵向数据中的潜在结构（摘要为方法/概念性描述，未列具体基准数字）。
- **值得追问 / 局限**：单作者短文，摘要偏概念、无量化对比与数据集细节，实证强度需看正文；"边=结构相似"的构图对相似度度量与阈值可能敏感；对比目标学到的聚类是否对应真实临床亚型、而非仅是数据几何，需要外部验证。

## 3. Loss Invariance Determines What Concept Layers Encode: Volume Grounding in Echocardiography
- arXiv: https://arxiv.org/abs/2607.25748
- 作者：Hyunkyung Han, Min Jung Kim（共 2 位）
- **TL;DR**：概念瓶颈模型（CBM）把预测经由可解释中间变量走，通常只用"中间变量预测得准不准"来判其有效性。本文以"左室容积→射血分数"为例指出：这套判据不够——由于射血分数是比值、对两个容积同时缩放不变，只用射血分数损失训练会让概念层"只到尺度可辨"，预测容积塌缩到 0.1 mL（真实分布约 35.7/45.7 mL），却仍保持相关性、EF 误差也不升。
- **解决什么问题 / 为什么重要**：正对 A 方向"内生/自解释（概念瓶颈式）"横切重点，同时落在 B 方向的临床影像时序。它给自解释模型敲了一记警钟：概念准确率可以掩盖"概念层没有物理尺度"这一事实；应当对照训练目标的不变性结构来验证可解释中间变量，而非只看预测精度。这对任何做 concept/prototype 内生可解释的人都有直接方法论含义。
- **核心方法**：用视频 Transformer 编码器在公开超声心动图数据上训练；以收缩末/舒张末容积构成概念层、由其解析计算射血分数（无残差旁路到输出）；对比"只用射血分数目标"与"额外以毫升为单位监督容积"两种训练，在 1276 例留出研究上评测；并从理论上说明损失的比值不变性只能确定概念层至一个尺度。
- **主要结果**：概念瓶颈相对直接回归不增大 EF 误差（MAE 6.89 vs 7.13）；但无容积监督时预测容积的展布塌缩到 0.1 mL；加毫升级绝对监督后容积误差从 89.8 降到 25.8 mL，代价是 EF 误差增加 0.4。
- **值得追问 / 局限**：结论建立在"EF 是比值"这一特定不变性上，向其它概念结构（非比值、多概念耦合）的推广需另证；"补绝对尺度监督"以 EF 精度换概念保真的取舍在别的临床任务里未必同价；是否有既保尺度又不损下游精度的目标设计，是自然的后续问题。

## 4. CogEEGAgent: Toward Autonomous Cognitive EEG Analysis with Grounded Execution and Selection-Aware Verification
- arXiv: https://arxiv.org/abs/2607.25045
- 作者：Dengzhe Hou, Lingyu Jiang, Fangzhou Lin, Kazunori D Yamada（共 4 位）
- **TL;DR**：认知 EEG 分析需要专家在对比、通道、时间窗、统计检验之间做大量"各有道理"的选择。CogEEGAgent 把 LLM 智能体建在 MNE-Python 上做自动化，但关键是设计了一套"语义权威与科学权威分离"的科学化 harness：LLM 只负责解释意图、提出已注册的分析，确定性组件负责校验类型契约、控制"确证访问"、并授权"有证据支撑才发布"，避免流畅报告掩盖"是否真做了被要求的分析、结论是否独立于自适应搜索"。
- **解决什么问题 / 为什么重要**：正对 B 方向"neuroimaging / 脑时序分析"，同时带 C 方向的 agent 机制色彩（把可靠性做成 fail-closed 的科学控制，而非纯 prompt）。它触及科学智能体的真问题：如何在保留自然语言灵活性的同时，对推断与发布做可审计、防"自适应搜索假阳性"的约束——对把 agent 用于脑信号/科学数据分析、以及一般"可信科研 agent"都有借鉴。
- **核心方法**：LLM 解释意图并提出已注册（registered）的分析，确定性模块做类型契约校验、控制对"确证集"的访问、授权"证据绑定的发布"；在预设路由 benchmark 上比对匹配的确定性路由器；在外部模型撰写、结果盲化的实验里检验"发布受支持分析、用参与者互斥的确证、拦截预设能力风险与生命周期复用请求"；并做策略压力测试看留出确证如何抑制假阳性。
- **主要结果**：在路由 benchmark 上比匹配的确定性路由器更准地把语言映射到已注册分析，且两者在需要时都会正确弃权；完整系统能以"参与者互斥的确证"发布受支持分析、并阻断预设的能力风险与复用请求；留出确证有效抑制了未校正自适应搜索带来的假阳性。
- **值得追问 / 局限**：方法强调"受限自治 + fail-closed 控制"，其代价（灵活性/覆盖面下降、需要预注册分析库）在开放式探索场景可能明显；评测偏"路由准确率 + 安全阻断"，对最终科学发现质量/发现率的正面贡献着墨较少；能否迁移到 fNIRS 等其它脑功能模态（分析流程与统计惯例不同）待验。

## 5. Emergent Latent-State Computation under Stochastic Volatility
- arXiv: https://arxiv.org/abs/2607.25459
- 作者：Xiaoyu Huang, Lulu Wang（共 2 位）
- **TL;DR**：机制可解释性大多研究语言模型和确定性玩具任务，对"序列模型如何在噪声、部分可观测下内部表征潜在随机动态"知之甚少。本文用可控的多变量随机波动率设定（模型只看到收益率、真实潜在波动率状态研究者已知）做 benchmark，发现跨架构/损失/输出头都存在"两阶段计算"：隐表征编码了大量关于下一潜在波动率状态的信息，输出头再把它映射到平方收益预测。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"里的机制/表征几何分析，且天然贴 A 方向"潜在状态 / 连续时间随机动态"。它提供一个"潜在状态对研究者可见、对模型隐藏"的干净 benchmark，把机制可解释性从确定性任务推进到"噪声潜在动态 + 部分可观测"，并给出可定位的架构阶段与显式滤波结构——对想理解序列模型如何做隐状态估计（含不规则/随机时序）的人很有价值。
- **核心方法**：在多变量随机波动率的受控设定下训练不同架构/损失/输出头的序列模型；用"潜在状态可解码性"探针定位信息在网络中的出现阶段；在长周期区间把该计算化简为显式的"潜在状态滤波器"（学到的线性投影 + ℓ² 归一化）；并用"输出头替换"分离表征失败与读出错配。
- **主要结果**：隐表征对下一潜在波动率状态有实质可解码信息，输出头负责映射到平方收益预测；Transformer 中潜在状态可解码性在可识别的架构阶段涌现、其位置随波动率周期而变；长周期下计算简化为"线性投影 + ℓ² 归一化"的显式滤波；输出头替换表明噪声 MSE 训练下的部分退化来自读出错配而非表征失败。
- **值得追问 / 局限**：结论建立在合成的随机波动率生成过程上，向真实金融/生理噪声时序的外推性待证；"两阶段"叙事在更复杂、非线性或多尺度潜在动态下是否仍成立未展开；探针式可解码性是"存在信息"而非"因果使用"的证据，机制主张仍需干预实验加固。

## 6. The Physics of Multi-Turn Long-Horizon Planning: From Pre-training to Post-training via Single- and Multi-Teacher On-Policy Agentic Distillation
- arXiv: https://arxiv.org/abs/2607.24720
- 作者：Tianyi Men, Zhuoran Jin, Kang Liu, Jun Zhao（共 4 位）
- **TL;DR**：多轮长时程规划是 agent 的关键能力，但现有模型都在不可控、不透明的互联网数据上训练，很难说清规划能力是怎么被获得、塑形、整合的。本文造了一个统一、可控的多轮环境，把长时程规划拆到预训练/后训练/整合三阶段系统研究，得到一批关于"数据格式、GRPO/OPD 后训练、以及多教师蒸馏"的机制性结论。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"——训练动态 + 机制/现象分析，且直击 agent 的核心能力（多步、带分支的长时程规划）。它把"规划能力从哪来、如何被后训练塑形、多能力如何整合"从玄学变成可控实验的对象，对"该怎么训 agent 内化流程/规划"给出直接方法论含义——与近期"过程性知识不是低秩"等发现互补。
- **核心方法**：构建可精确控制的统一多轮环境；(1) 预训练阶段研究数据格式/分布/质量，比较显式世界模型（CoT 状态转移建模）与原子技能；(2) 后训练阶段用互信息区分"通用规划模式"与"任务特定规划知识"，对比 GRPO 与 OPD（on-policy distillation）的有效区间；(3) 整合阶段用多教师 on-policy 蒸馏（MOPD）研究跨环境能力整合。
- **主要结果**：显式世界模型（CoT 状态转移）带来更强的长时程泛化，仅有原子技能不足以组合泛化、而少量长时程数据即有效，次优轨迹因误差沿长时程放大而严重损害性能；OPD 在低质量/长时程设定下有效区间比 GRPO 更宽（更新方向更一致）；蒸馏"教师的不同过程知识"可能在未确立新知识前先损害学生已有世界建模；MOPD 通过收敛到跨环境共享的规划模式来整合能力——兼容模式支持跨环境泛化、部分共享支持持续学习、完全冲突则造成严重干扰。
- **值得追问 / 局限**：结论多在受控合成环境得到，向真实开放式 agent 任务的外推性需验证；"世界模型 CoT / 规划模式"等构念的度量（如用互信息区分模式与知识）其稳健性与阈值敏感性待正文确认；MOPD"冲突模式致干扰"的边界（何时兼容、何时冲突）缺乏可先验判定的准则。
