## 1. Memory as a Controlled Process: Learned Adaptive Memory Management for LLM Agents
- arXiv: https://arxiv.org/abs/2607.13591
- 作者：Eric Hanchen Jiang, Zhi Zhang, Yuchen Wu, Levina Li, Dong Liu
- **TL;DR**：把 LLM 智能体的记忆读写建模成马尔可夫决策过程（MDP），在线学一个策略，自适应决定"何时检索、取什么、取多少、何时注入计划、何时整合/遗忘"。
- **解决什么问题 / 为什么重要**：现有智能体记忆（图结构记忆、反思洞察库等）几乎都靠固定的手工启发式访问，而最优记忆行为本质上是上下文相关的——任务早期记忆稀疏宜少检索、重复目标宜复用计划而非泛泛近邻查找、卡住时宜换查询重检索、长任务流下记忆库本身要整合剪枝。这正对应 Agent 的"记忆"优先机制方向。
- **核心方法**：MemCon 把记忆操作建成 MDP，用轻量的表格化上下文老虎机（contextual bandit）+ UCB 探索学在线策略；后端无关（可包裹任意已有记忆实现），仅靠任务级二值反馈学习，无需预训练、无额外 LLM 调用，几十个任务内收敛。
- **主要结果**：跨 6 个基准、3 种智能体框架、3 个 LLM 底座，相比多个记忆基线任务成功率最高提升 15.2 分，同时 token 消耗降低 5–20%。
- **值得追问 / 局限**：表格化 bandit 依赖对上下文状态的手工离散化，状态空间设计对效果的敏感度未知；"几十个任务内收敛"意味着冷启动阶段策略仍近随机，在短任务流或高代价领域可能吃亏。

## 2. MxGPS: Multiplex Graph Transformers for a Power Grid Foundation Model
- arXiv: https://arxiv.org/abs/2607.13763
- 作者：Charilaos Papaioannou, Ioannis Tsantilas, Dimitris Giannakakos, Vasilis Michalakopoulos, Sotiris Pelekis
- **TL;DR**：指出电网 GNN 的单任务微调存在"拓扑过拟合"——在分布内误差最低的模型在拓扑漂移下退化最狠，并用多路复用图 Transformer + 多任务联合训练把它压下去。
- **解决什么问题 / 为什么重要**：这是对图神经网络泛化失效的一次机制性拆解：任务专用梯度会让模型编码训练拓扑特有的关系结构而非底层物理，导致在未见电网上崩盘。对"图方法到底学到了什么、为何不泛化"很有参考价值。
- **核心方法**：MxGPS 在共享节点编码器上跑 K 个任务专用的 GPS 分支，通过自监督预训练 + 多任务微调，在静态状态估计（SSE）与交流潮流（AC PF）上联合训练；互补的梯度信号迫使共享编码器不再对拓扑特有结构过拟合，跨分支注意力模块以消融方式评估。
- **主要结果**：在 14/24/162/300-bus 四个未见拓扑上做 3 折滑窗交叉验证，零样本潮流的边界违约率（BVR）为 0%；分布内潮流误差更低的模型在拓扑漂移下退化 190%–1400%，而 MxGPS 仅退化 39%——这一"反转"直接把失效归因于拓扑过拟合而非模型容量不足；参数仅 1.6M（比 GridFM 基线少 12 倍）。
- **值得追问 / 局限**：结论建立在电网这一物理约束极强、任务（SSE/PF）互补性明确的场景，"多任务联合训练抗拓扑过拟合"能否迁到缺乏物理约束的一般时空图（交通、社交、脑网络）存疑；退化 39% 仍不小，零样本可用性边界待看。

## 3. How Far Can Root Cause Analysis Go on Real-World Telemetry Data?
- arXiv: https://arxiv.org/abs/2607.13548
- 作者：Athira Gopal, Ashwanth Krishnan
- **TL;DR**：在真实微服务遥测（OpenRCA）上，用一个结构化多智能体 RCA 流水线显著超越经典因果发现与已有 LLM 方法，并用"逆向推理"诊断出瓶颈在推理而非数据获取。
- **解决什么问题 / 为什么重要**：生产微服务故障根因要在指标/日志/链路的大规模多模态遥测上推理，经典与 LLM 方法在 OpenRCA 上准确率都很低。这是监控/根因定位（AIOps/RCA）方向绕不开的硬基准。
- **核心方法**：提出结构化多智能体 RCA 流水线，支持有/无领域知识两种模式；引入"逆向推理智能体"——给定正确答案，回溯哪些异常信号支持它、并判断第一阶段是否拿到了这些信号，从而把每个失败归类为"推理缺口（证据在但没用）"或"数据歧义（证据确实缺失）"；再用自动规则挖掘从逆向报告里提取判别规则，减少人工知识策展。
- **主要结果**：跨所有配置均超经典与 LLM 基线；分析显示绝大多数失败的所需证据其实都在，瓶颈是智能体对证据的正确推理能力；即便证据抽取做到完美，推理性能仍存在实际上限——脚手架工程与更好的数据管道无法弥合，进步需在模型层面。
- **值得追问 / 局限**：核心诊断依赖"逆向推理智能体"本身可靠（它拿着标准答案回溯），其判定"推理缺口 vs 数据歧义"的准确性未独立验证；结论主要基于 OpenRCA 单一基准，跨部署环境的可推广性待考。

## 4. Experience Memory Graph: One-Shot Error Correction for Agents
- arXiv: https://arxiv.org/abs/2607.13884
- 作者：Wenjun Wang, Yuchen Fang, Fengrui Liu, Zibo Liang, Kai Zheng
- **TL;DR**：把智能体的失败纠错重构成"图匹配"问题——从失败与专家轨迹的动作决策图中抽取成功子图与"图编辑路径"，测试时一次性、无试错地纠正错误。
- **解决什么问题 / 为什么重要**：长程任务里智能体常因误差累积而难以从失败中恢复；现有自纠错靠基于提示的反思，脆弱、迭代试错的时间与 API 成本高、且记忆任务专用难泛化。这篇用结构化图表示替代 prompt 反思，属 Agent 记忆/规划的机制方向，也与图方法交叉。
- **核心方法**：训练时把失败探索轨迹与成功专家轨迹都转成有向动作决策图，通过图匹配抽取公共子图（成功工作流）与图编辑路径（在给定观测下该增/删/改哪些动作），存入带"任务内节点 + 跨任务边"的记忆图；测试时检索相关洞察，指导智能体单次、无循环执行。
- **主要结果**：在 ALFWorld 与 ScienceWorld 上，成功率与平均回报持续优于 SOTA 反思基线，且测试时无需任何试错。
- **值得追问 / 局限**：图匹配质量依赖动作/观测能被离散成可对齐的图节点，动作空间连续或观测高维时抽取"图编辑路径"的可行性存疑；专家轨迹的获取成本，以及跨任务边在真正异构任务间的泛化程度，摘要未充分量化。

## 5. Activity Regeneration from Silent States in Neuronal Networks with Transient Synaptic Memory
- arXiv: https://arxiv.org/abs/2607.14000
- 作者：Mozhgan Khanjanianpak, Alireza Valiadeh（q-bio.NC）
- **TL;DR**：在有限寿命突触的极简神经元网络里，证明"完全静默瞬间的残余突触状态快照"已足以预测网络活动会终止还是自发再生，无需继续仿真。
- **解决什么问题 / 为什么重要**：瞬态突触记忆被认为能在无持续神经元放电时保存短期信息，但隐藏的突触状态是否足以预测网络未来演化一直不清楚。这是关于"记忆到底编码在哪里"的机制性问题，对脑网络/短期记忆建模有理论意义（今日无 fNIRS，作为脑/神经方向替补）。
- **核心方法**：构建带有限寿命突触的最小神经元网络模型，研究完全静默后自发活动再生的机制；分析首个静默态的突触配置快照，定义"潜在兴奋招募（LER）容量"（累计可招募的新鲜兴奋性神经元数）作为多周期动力学的预测量。
- **主要结果**：残余突触配置即决定活动是单周期后终止还是自发再生一个周期；LER 容量是多周期动力学的近乎完美预测子，无需继续仿真即可判定；且这些不同结局出现在同质网络中，说明瞬态突触记忆本身足以生成多样的未来动力学。
- **值得追问 / 局限**：结论基于高度简化的最小模型与同质网络，能否外推到真实异质、含抑制性回路与噪声的皮层网络未知；"LER 容量"作为预测子在更复杂拓扑与多次静默-再生循环下的稳定性待验证。

## 6. RF Spectrogram Anomaly Detection with Quantum Kitchen Sinks: Architecture, Representation, and Hardware Validation
- arXiv: https://arxiv.org/abs/2607.13897
- 作者：Abdallah Aaraba, Alexis Vieloszynski, Remon Polus, Ola Ahmad, Soumaya Cherkaoui
- **TL;DR**：把量子随机特征（Quantum Kitchen Sinks）扩展到射频频谱异常检测，做了从表示到真机的五阶段消融，并在 IBM 真实 QPU 上验证。
- **解决什么问题 / 为什么重要**：无线信道的广播特性使射频网络暴露于异常/恶意传输，异常检测是安全频谱管理的基本需求；同时它检验了一个轻量混合量子特征映射在结构化信号数据上的真实行为——属监控/异常检测方向，附带近期量子 ML 可行性的实证。
- **核心方法**：在标准 QKS 模板上引入多深度数据重上传与环形纠缠，配一套"验证锁定"的五阶段消融协议，逐一分离浅层架构、重上传深度、episode 预算、输入表示与经典读出的影响；数据用真实测得的 sub-6 GHz 蜂窝信号。
- **主要结果**：DCT 表示稳定优于原始与 PCA 输入；中等深度纠缠 QKS 为最强工作区间，且在所有表示-读出组合上都超过匹配的经典直接读出基线；最佳配置测试 AUROC 0.8778、F1 0.7995；在 ibm_quebec 真机上 AUROC 与仿真偏差小于 0.013。
- **值得追问 / 局限**：任务设定为"受控"频谱异常，最佳 AUROC 0.88 距实用告警仍有距离，且未与强经典深度基线（而非仅"匹配的直接读出"）对比；量子优势更多体现为特征映射差异，规模化到更大频谱与更多异常类型的收益未知。
