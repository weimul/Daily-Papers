## A. 核心方法 · 不规则/连续时间时序 · 神经算子

### 1. Existence Precedes Value: Joint Modeling of Observational Existence and Evolving States in Time Series Forecasting
- 链接：https://arxiv.org/abs/2606.13571
- 作者（前几位）：Yifan Hu, Hongzhou Chen, Peiyuan Liu, Yiding Liu, Zewei Dong, Jiang-Ming Yang（据代码仓库 `ant-intl` 推断为蚂蚁集团相关团队）
- **TL;DR**：提出 Timeflies，把"未来到底有没有有效观测"和"未来值是多少"联合建模——直接戳破现有连续时间/Neural ODE 方法在推理时偷偷假设"未来时间戳已知"的隐形 oracle。
- **解决什么问题 / 为什么重要**：真实时序因传感器休眠、传输延迟、事件驱动采样而高度不完整、不规则。方法虽已从"先插补后预测"演进到 Neural ODE、连续时间图网络，但它们普遍依赖"未来有效观测的时间戳已知"这一不现实假设。这正中你方向 A 的"不规则采样 / 连续时间"核心，且把问题重述为"先判存在、再估值"，视角新。
- **核心方法**：双流结构——观测流（observation stream）+ 值流（value stream），通过三个模块耦合：可靠性感知嵌入、观测引导的依赖建模、联合预测；从而显式刻画"观测动力学 × 状态演化"的相互作用。配套提出 Shadow 基准（公开数据自然缺失 + 真实工业数据）与 Observation-Value Joint Entropy（OVJE）度量来评估这种耦合可预测性。
- **主要结果**：在含缺失值的时序预测上一致优于现有方法，验证"显式建模未来可观测性"的必要性。代码与数据已开源（GitHub: ant-intl/Timeflies）。
- **值得追问 / 局限**：① "未来观测是否发生"本身是个高度依赖业务/采样机制的标签，OVJE 与 Shadow 的构造是否会把"可观测性"与"值"的耦合定义得对自家方法有利，需看跨域稳健性；② 双流耦合相比单纯 Neural ODE 的额外开销，以及在观测极稀疏时观测流的可学性。

### 2. How Much Memory Do We Need? Adaptive Memory Gate for Neural Operators
- 链接：https://arxiv.org/abs/2606.13443
- 作者（前几位）：Jihyeon Hur, Yongseok Kwon, Min-Gi Jo, Jeongwhan Choi, Noseong Park（KAIST 等，据作者公开信息推断）
- **TL;DR**：给"记忆增强神经算子"装一个可学习的门控，按观测分辨率/物理参数自适应调节"该用多少历史"，而非固定记忆权重。
- **解决什么问题 / 为什么重要**：神经算子解时变 PDE 时，引入历史状态（memory）能在低分辨率观测下大幅涨点，但现有做法用固定记忆权重，无法兼顾不同分辨率与黏性。这与你方向 A 的"连续/动力系统建模 + 历史依赖如何取舍"相通——"需要多少记忆"本质是时序依赖范围的自适应问题。
- **核心方法**：提出 AMGFNO，用一个可学习 gate 动态调制记忆权重；预实验先证明最优记忆权重随分辨率与黏性变化，再让门控自动学出这种调度。
- **主要结果**：在 Kuramoto–Sivashinsky 与 Burgers 方程上，低分辨率下 nRMSE 降低 55–79%；学到的门控值随分辨率升高自动从 g≈0.7 衰减到接近 0——即高分辨率时几乎不需要历史，符合直觉。
- **值得追问 / 局限**：① 仅在两个经典 1D PDE 上验证，跨更高维/更刚性系统的门控行为是否仍单调、可解释待看；② 门控学到的"分辨率→记忆量"映射是物理规律还是数据集偏置，缺少跨数据集交叉验证。

## A×B 横切 · 图-时序 + 根因分析（AIOps）

### 3. NetCause: Counterfactual Learning for Root Cause Analysis in Large-Scale Networks
- 链接：https://arxiv.org/abs/2606.13543
- 作者（前几位）：Fabien Chraim, Jian Zhang, Dominik Janzing, Xiang Song, Christos Faloutsos, John Evans（含 Faloutsos / Janzing，背景指向 Amazon AWS）
- **TL;DR**：把网络故障建模成"图-时序过程"，再用反事实模拟对候选根因排序——一套自监督、可解释的大规模网络根因分析框架。
- **解决什么问题 / 为什么重要**：传统 RCA 靠静态规则、相关性启发或局部拓扑推理，在故障跨复杂物理/逻辑依赖传播的动态环境里难泛化。NetCause 同时命中你方向 A 的"temporal graph / graph-temporal process"与方向 B 的"root cause analysis / AIOps"，是标准的 A×B 结合点，而且是真·生产数据。
- **核心方法**：自监督学习刻画故障如何在网络图上随时间传播，用反事实模拟（若某节点未故障会怎样）对候选根因打分排序，产出可解释的根因假设排名，并能自然对接运维方的缓解/修复动作。
- **主要结果**：在某头部云厂商生产网络 6 个月、1500+ 起事件上训练，31 起专家标注事件上评测；在最贴近运维决策的区间，根因排序准确率较规则启发基线提升 16.1%。训练偏重，但推理轻量——每起事件仅需数秒 GPU，远低于遥测采集延迟。
- **值得追问 / 局限**：① 评测集仅 31 起专家标注事件，规模偏小，16.1% 的相对提升其统计稳健性需更多标注支撑；② 反事实"若未故障"依赖学到的传播模型本身正确，模型错误会让反事实归因系统性偏移——这类因果 RCA 最该被压力测试的点。

## B. 应用场景 · 神经时序（EEG / 被动 BCI）

### 4. Deep Sleep Classification via EEG Signal Criticality: A Passive BCI Approach for Sleep-Improvement Neurofeedback
- 链接：https://arxiv.org/abs/2606.13017
- 作者：Stanisław Narębski, Tomasz Komendziński, Tomasz M. Rutkowski
- **TL;DR**：用去趋势波动分析（DFA）的"临界性"特征做深睡（N3）识别，证明这类神经时序特征落在一个非线性流形上，简单概率分类器反而最强。
- **解决什么问题 / 为什么重要**：自动睡眠分期是被动 BCI 的基础应用——解码自发神经状态以驱动闭环干预。今日**无 fNIRS 新文**，这篇作为脑功能时序（neuroimaging time series）方向的覆盖；其"临界性/标度特征 + 非线性流形"的思路，对你 fNIRS/脑网络的特征工程有迁移价值。
- **核心方法**：从 290 名老年女性的 347,232 个 EEG epoch 提取 DFA 临界性特征，用 UMAP 可视化状态转移；再用 10 折交叉验证基准 6 种分类器，以平衡准确率挑"状态感知"引擎。
- **主要结果**：朴素贝叶斯平衡准确率最高（87.17%±0.24%），显著优于全连接深网（81.58%）与随机森林（80.97%）；线性模型（LDA 57.21% / SVM 51.01%）很差——说明 DFA 临界性特征处于一个独特的非线性流形上，可支撑状态依赖的神经反馈（如定向听觉刺激）。
- **值得追问 / 局限**：① 被试全为老年女性，跨年龄/性别泛化未知；② "朴素贝叶斯 > 深网"更多反映特征已高度可分而非深网无用，特征本身的可迁移性（到 fNIRS/其它任务）才是关键，文中未涉。

## C. Agent · 机制分析 + 记忆（均"优先型"）

### 5. Beyond the Commitment Boundary: Probing Epiphenomenal Chain-of-Thought in Large Reasoning Models
- 链接：https://arxiv.org/abs/2606.13603
- 作者（前几位）：Daniel Scalena, Sara Candussio, Luca Bortolussi, Elisabetta Fersini, Malvina Nissim, Gabriele Sarti（格罗宁根大学 / 的里雅斯特大学 / 米兰比可卡大学等，据作者背景推断）
- **TL;DR**：用 early-exit 估每个 CoT 步骤的"因果重要性"，发现推理常在某一步骤骤然跨过"承诺边界（commitment boundary）"锁定答案，之后的步骤多为不改变答案的"附带现象（epiphenomenal）"。
- **解决什么问题 / 为什么重要**：CoT 是推理时扩展的主流范式，但单个步骤对最终答案的因果影响一直没说清。这篇是你 C 方向偏好的"机制/现象分析"——把"答案到底什么时候、在哪一步形成"做成可测量、可线性解码的现象，远离 prompt 技巧。
- **核心方法**：以 early-exit 概率作为每步因果重要性度量，刻画答案在推理轨迹中的形成过程；用 attention probe 证明"答案形成阶段"可从中间步骤高精度线性解码，并能泛化到未见推理任务；进而利用该信号在承诺边界处提前退出。
- **主要结果**：跨多个模型族与任务，答案常在推理块远未结束时的单一步骤完成跃迁；据此在承诺边界 early-exit 平均可缩短 CoT 长度达 55%，性能几乎无损。
- **值得追问 / 局限**：① "承诺边界后即 epiphenomenal"是否在需要回溯/自我纠错的难题上同样成立，还是只在模型本就答对的样本上显著？② early-exit 作为因果度量会与模型置信度自相关，"因果"解读需与单纯置信度上升区分。

### 6. Learning What to Remember: A Cognitively Grounded Multi-Factor Value Model for Agentic Memory
- 链接：https://arxiv.org/abs/2606.12945
- 作者：Zhibao Chen, Qian Cheng
- **TL;DR**：给 agent 记忆的"遗忘决策"建一个认知心理学启发的多因子价值函数 V(m)=Σ wᵢfᵢ(m)，用单一标量统一控制编码深度、遗忘风险与检索排序。
- **解决什么问题 / 为什么重要**：长程 agent 的交互历史远超上下文窗口，必须在**消费查询出现之前**就决定"什么深编码、什么遗忘、什么可检索"。生产系统常用语义相似度或时近性——但这两者对"消费前的遗忘决策"本就错配。这正是你 C 方向偏好的"memory 机制"，且方法可解释、强调"遗忘 ≠ 检索"的方法论区分。
- **核心方法**：定义 7 个可解释因子（情绪强度、目标相关、价值对齐、自我/用户相关、任务效用、可靠性、使用历史），权重由下游目标经无梯度优化器学出；用一个标量统一驱动编码、遗忘、检索三件事。
- **主要结果**：作者指出在 LongMemEval 上"拿留出的评测问题去算目标相关性"会把金证据保留率刷到 ≈0.98——那是在测检索而非遗忘；在更真实的盲设定（消费查询未知）下，学到的多因子价值保留 0.770±0.011 金证据，优于均匀权重 0.657、最佳单因子 0.518、时近性 0.368，各配对差的 95% bootstrap CI 均 >0。学到的权重可解释：可靠性、情绪强度、自我/用户相关占主导，而查询期目标相似度被正确下调权重。合成对照（植入混淆因子）下学习器恢复出可分权重（保留 1.00），均匀权重失败（0.62）。全程单 CPU、无 API 调用，开源。
- **值得追问 / 局限**：① 7 因子里"情绪强度 / 价值对齐"等如何从原始交互可靠打分，其分数本身可能又依赖 LLM 自评，引入新噪声；② "盲设定保留 0.77"相对 0.66 是真实增益，但绝对值仍意味着约 1/4 金证据被遗忘，对强多跳任务的下游影响需端到端验证。
