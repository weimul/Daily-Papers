## A. 核心方法

### 1. Liquid Gated Attention
- **链接**：https://arxiv.org/abs/2608.30695
- **作者**：Yiheng Jiang, Yuanbo Xu, Yongjian Yang（吉林大学团队）
- **TL;DR**：一个"免解算器、可并行"的连续时间时序算子，把观测时间间隔当作门控信号写进状态演化，既保留连续时间归纳偏置又拿到线性复杂度。
- **解决什么问题 / 为什么重要**：真实时序常常不规则采样且时间跨度很长。离散方法把变长间隔压成固定步位；依赖 ODE 解算器的连续时间模型能保结构但必须串行积分、无法并行；已有免解算器近似又没有把"观测时间间隔"和"输入驱动的状态调制"耦合起来。这篇正好补上这一空缺——是我最关心的不规则采样 / 连续时间那一支的正面方法工作。
- **核心方法**：用观测时间间隔参数化一个输入驱动的门控机制，引入连续时间归纳偏置，并把隐状态演化写成"快权重联想记忆"（fast-weight associative memory）。非因果编码用矩阵结合律、因果编码用前缀扫描（prefix scan），两种模式都做到序列长度上的线性时间复杂度；再加序列级归一化约束累计时间衰减以稳定长程优化。基于 LGA 搭出模块化骨干 LFormer。
- **主要结果**：跨 6 类任务、16 个数据集（序列长达 17,984 步），在长程依赖、细粒度状态跟踪、从稀疏含噪观测重建轨迹上表现良好；相对 SOTA 的离散/连续时间基线保持竞争力，同时具备线性扩展效率。
- **值得追问 / 局限**：把连续时间动力学简化为"门控 + 快权重"是否会在强非线性/多尺度动力系统上损失表达力？"竞争力"的具体量化（相对纯 Neural ODE 的精度—吞吐权衡）需要看正文表格核实。

### 2. TSPFN: A Temporal Tabular Foundation Model for Physiological Time Series Classification
- **链接**：https://arxiv.org/abs/2608.31013
- **作者**：Jérémie Stym-Popper, Clément Rambour, Federica Granese, Nicolas Thome, Olivier Bernard 等
- **TL;DR**：把表格基础模型 TabPFN 重新设计为面向时序的版本，引入结构化时间表示与位置编码来捕捉样本内的时间与通道依赖，走上下文学习路线服务中低数据量的生理信号分类。
- **解决什么问题 / 为什么重要**：医疗 ML 里最难的就是中低数据量下的泛化，而生理时序分类尤甚。TabPFN 这类"用上下文学习替代微调"的表格基础模型很有吸引力，但天生不建模时间依赖。TSPFN 想在保留免微调优势的同时补上时空结构——对我在生理/脑信号方向做小样本分类有直接借鉴。
- **核心方法**：在 TabPFN 架构上加入结构化时间表示与位置编码，以刻画样本内时间与通道（spatio-temporal）依赖；在跨多个医疗领域的 14 万条真实生理时序上做预训练，得到一个统一、可泛化的框架。
- **主要结果**：在多个生理基准上稳定优于标准表格基线与 TabPFN，且跨领域泛化优于专门的深度时序模型；代码、消融与预处理流程已开源（GitHub: Jeremstym/TSPFN）。
- **值得追问 / 局限**：TabPFN 式上下文学习对序列长度/上下文规模较敏感，长程生理信号（如整夜 EEG/长时段监护）能否直接吃得下？"优于专门深度时序模型"是否在特定信号族（心电 vs 脑电 vs 呼吸）上不均衡，需看分领域结果。

## B. 应用场景

### 3. Benchmarking External Generalization of SPD Matrix Learning for Resting-State fMRI Connectome Prediction
- **链接**：https://arxiv.org/abs/2608.30418
- **作者**：Ce Ju, Antoine Collas, Florent Bouchard, Bertrand Thirion（含 Inria 团队）
- **TL;DR**：为静息态 fMRI 连接组的 SPD 矩阵学习方法建了一个"留一数据集"的跨队列外部泛化基准，戳破"单队列内高分即好"的错觉。
- **解决什么问题 / 为什么重要**：脑功能连接（FC）矩阵广泛用于个体级预测，但同队列内的强表现常常无法迁移到新队列。作者直接问：当测试数据完全来自被留出的另一个 fMRI 数据集时，性能还剩多少？这对我关心的脑网络建模的可复现性/外部效度是很务实的一记提醒。
- **核心方法**：每次扫描表示为正则化的对称正定（SPD）相关连接组，从而可利用 SPD 流形几何；在 COBRE、ADNIDOD、Cam-CAN、ABIDE、OASIS-3、ADNI 六个数据集上建可复现的年龄预测基准，比较向量化相关基线、切空间岭回归（Tangent-Space Ridge）、SPDNet 与分块 Riemannian 调和化，评测协议涵盖组内 GroupKFold、汇合 GroupKFold 与留一数据集（LODO）。
- **主要结果**：组内与汇合评测明显更好看；一旦整队列留出（LODO），预测误差上升、各方法差距收窄，且性能强烈受年龄区间错配与队列异质性影响。基准公开了统一输入、模型设置、数据划分与分析脚本。
- **值得追问 / 局限**：结论主要基于"年龄预测"这一相对易迁移的任务，换成临床诊断标签（跨站点采集协议差异更大）时差距可能更严峻；SPD 几何方法在 LODO 下并未拉开优势，值得思考几何先验到底在哪一层带来收益。

### 4. TAMI: Temporally Aligned, Missingness-Aware, and Interpretable Multimodal Fusion for Mental Health Assessment in Older Adults with MCI
- **链接**：https://arxiv.org/abs/2608.30857
- **作者**：Merna Bibars, Bolaji Omofojoye, Allan I. Levey, Rachel Hershenberg, Gari D. Clifford, Hyeokhyen Kwon（Emory 团队）
- **TL;DR**：面向轻度认知障碍（MCI）老人的远程临床访谈，提出一个"时间对齐 + 缺失感知 + 内生可解释"的多模态融合框架，用于抑郁/焦虑筛查。
- **解决什么问题 / 为什么重要**：这篇同时命中我三个横切关注点——**不规则采样/缺失**、**内生可解释**、**神经健康应用**。远程访谈里语音/语言/面部/生理特征分辨率不同会带来时间错位（诱发虚假跨模态关联），模态掉线又常被零填充（与真实近零值混淆），且现有方法难以把预测同时归因到"模态 / 问题 / 访谈时刻"三个层级。
- **核心方法**：在问答片段（Q-A segments）内把语音、语言、面部、生理特征对齐到共享时间线；显式编码"随时间变化的模态缺失"；并以问题上下文为条件做融合，从而支持模态级、问题级、时刻级的联合归因（内生可解释而非纯事后归因）。
- **主要结果**：49 名 MCI 老人访谈上，抑郁 AUROC 0.68、焦虑 0.69；细粒度时间对齐带来最大增益（ΔAUROC ≥ 0.1）。可解释分析显示抑郁分类主要依赖眼动与开放式问题、焦虑依赖眼动与头部姿态；仅用开放式问题回答（约 5.1 分钟）就能达到与全访谈（19 分钟）无显著差异的抑郁 AUROC（0.67，p>0.05）。
- **值得追问 / 局限**：样本量仅 49 人、AUROC 0.68–0.69 偏低，临床可用性还早；"缺失感知编码"相对简单零填充的增益未单独消融凸显，值得追问缺失机制（MNAR）建模的稳健性。

### 5. Measuring Memory and Generalization as Separable Geometric Channels: The Topo² Framework
- **链接**：https://arxiv.org/abs/2608.30487
- **作者**：Zhanbo Zhang, Ming Liu, Qing Wang
- **TL;DR**：用表示空间的持续同调（H1）结构，把"记忆噪声标签"与"在干净数据上泛化"拆成两条可分离、可测量、可干预的几何通道。
- **解决什么问题 / 为什么重要**：噪声标签训练下网络同时泛化又记忆，二者常被混为对同一容量的争夺。这篇提供了一个把"记忆化"从模糊概念变成可测量、可分离、可逆的拓扑分层的测量框架——正是我偏好的机制/现象分析类工作，对理解训练动态与表征几何很有价值。
- **核心方法**：对表示空间做持续同调，H1 结构分解为"类内流形通道"（训练停点的函数）与"跨类通道"（对被记忆的翻转样本的单调读出）；提出 FM0 干预（从第 0 轮起对翻转样本置零损失），在几乎不记忆的情况下逼近各设置的泛化上限；并给出一组带分级证据的"定律"（记忆化成本律，参考容量下有效斜率系数 C≈0.38）。
- **主要结果**：跨 CIFAR-10/100、SVHN、VGG 等给出可复现的分离结果，记忆被证明是"因果可加、可锚定、可逆、可计量"的拓扑层；并公开了九条死路的证伪清单与排除六类全局统计量的"仪器辩护"。
- **值得追问 / 局限**：结论建立在标签噪声这一受控设定与持续同调 H1 这一特定几何探针上，能否推广到真实脏数据、大模型或非分类任务仍待验证；C≈0.38 是否具备跨架构普适性也需更多容量点。

### 6. Kathleen Remembers: Length-Invariant One-Shot Recall Without Attention
- **链接**：https://arxiv.org/abs/2608.30376
- **作者**：George Fountzoulas
- **TL;DR**：给无注意力的循环序列模型挂上一个约 2.5 万参数的"笔记本"记忆层（全息 HRR 联想存储 + 学习写门），实现长度不变的一次性精确召回，并顺带获得可选择遗忘与逐 token 归因。
- **解决什么问题 / 为什么重要**：循环/无注意力模型有个结构性弱点——衰减的状态无法对"很久以前只见过一次"的内容做精确召回。作者不靠注意力、而用联想记忆机制补上这一能力，且天然带来可控遗忘与可解释归因，契合我关注的记忆机制/表征结构这条 Agent 优先线。
- **核心方法**：在 "Kathleen" 主干的 logits 上附加一个固定键的全息（HRR）联想存储，配学习到的局部写门、自门控原始读取与"写触发遗忘"，寻址按构造对长度不变；因为存储是线性叠加，选择性遗忘（一次减法擦除一条事实、不伤其余）与逐 token 归因（反事实擦除定位每个正确字节的来源事实，100% 溯源）由算术自然导出。
- **主要结果**：受控"大海捞针"任务上，笔记本在 4× 训练长度处达 80–82% 一次性召回（裸主干约 4%，参数匹配的注意力头在训练长度外掉到 0%）；WikiText-2 字节级上对重复稀有词的预测提升 +0.15–0.27 bits/byte，且随两次提及间距增大而增大、在 4× 训练长度零样本仍成立；全部实验预注册、种子公开、单张免费层 GPU 可复现。
- **值得追问 / 局限**：作者自己承认参数匹配的注意力头在自然文本重复上也能泛化，笔记本的独特卖点收缩为"O(L) 复杂度下的精确召回"；固定键 HRR 存储的容量上限与多事实干扰在真实大规模语料上的表现仍需检验。
