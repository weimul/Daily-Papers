## A. 核心方法

### 1. Temporal Memory-Aware Online Test-Time Adaptation on Dynamic Graphs (DGOTTA)
- 链接：https://arxiv.org/abs/2608.27948 （cs.LG，ICDM 2026）
- 作者：Bo Li, Xin Zheng, Ming Jin, Can Wang, Shirui Pan
- **TL;DR**：第一个专门面向**动态图 GNN（DGNN）**的在线测试时自适应框架，用"时序记忆"在结构与语义都随时间漂移时抵抗灾难性遗忘。
- **解决什么问题 / 为什么重要**：测试时自适应（TTA）此前只在静态图上研究，而现实里的动态图连边结构和节点语义都在持续演化，训练好的 DGNN 部署后一旦分布漂移就掉点。这是你核心关注的 temporal/dynamic graph 方向里少见地把"分布偏移下的鲁棒推理"讲清楚的工作。
- **核心方法**：三个模块——（1）时序感知增强，扩充测试动态图多样性以覆盖复杂时空偏移；（2）记忆感知预测，用记忆缓解在线适应中的灾难性遗忘；（3）一致性引导的在线适应，强制时序对齐与记忆平滑。
- **主要结果**：在 3 个真实数据集 × 4 种 DGNN 主干上，DGOTTA 在多种分布偏移与多种架构下都显著提升泛化。
- **值得追问 / 局限**：（1）在线适应对连续时间事件流（CTDG）而非离散快照是否同样成立，记忆平滑会不会拖慢对突变结构的响应？（2）"记忆感知"与既有记忆型时序图网络（如 TGN）的记忆模块是互补还是重叠，未见直接对比。

### 2. Scalable dynamic community detection on temporal graphs using graph neural networks
- 链接：https://arxiv.org/abs/2608.28342 （cs.SI，投稿 Trans. KDD）
- 作者：Peijie Zhong, Raul Mondragon, Richard G. Clegg（Queen Mary University of London）
- **TL;DR**：把动态社区发现重述为"给每个 node-time 实例打簇标签"，用扩散引导的对比学习在时序交互流上学表征，兼顾质量与可扩展性。
- **解决什么问题 / 为什么重要**：动态社区发现要在允许成员随时间变动的前提下识别演化中的社区结构，直击你关注的 temporal graph 表征学习。其"time-node 级"建模比传统按快照聚类更贴合连续交互流。
- **核心方法**：以局部**时序扩散亲和矩阵**构造正/负 node-time 对，按时序结构关系组织表征（对比学习），再在嵌入空间上跑聚类得到动态社区。
- **主要结果**：合成时序网络上 AMI/ARI 优于静态社区发现基线，并与现有动态方法持平或更好，且保持良好可扩展性；进一步在 2016–2025 的 OpenAlex 计算机科学合作大图上，还原出持续且演化的科研合作社区。
- **值得追问 / 局限**：（1）主要定量评测仍靠合成网络，真实图上只有定性还原，缺少带真值的大规模定量验证；（2）扩散亲和的时间窗口尺度如何选、对社区突现/消亡的敏感度未细谈。

### 3. Self-Explainable Multi-Label Graph Neural Network for Correlated Evidence Attribution (SEMGNN)
- 链接：https://arxiv.org/abs/2608.27574 （cs.LG / cs.AI）
- 作者：Yingqi Feng, Yufei Tang, Min Shi, Xingquan Zhu
- **TL;DR**：把"预测器 + 稀疏边掩码解释器"合进一个端到端训练目标，让多标签 GNN 在分类每个节点的同时，指出各标签各自依赖哪些边——内生自解释而非事后归因。
- **解决什么问题 / 为什么重要**：多标签图学习里一个节点常同属多个群组/多个对象，而已有方法都没有训练期解释能力；事后解释器又无法显式建模"标签间证据如何共享/分离"，尤其当标签对弱相关甚至负相关时会失真。这正是你横切重点"内生/自解释"在图与多标签场景的落地。
- **核心方法**：SEMGNN 在统一框架与训练目标下联合学习预测器和稀疏边掩码解释器；利用标签-标签相关性同时提升多标签分类与单标签解释，使一个节点的不同标签由**各自独立却彼此一致**的结构/相关证据支撑。
- **主要结果**：在社交网络、娱乐、生命科学等合成与真实多标签网络上，预测性能有竞争力或更优，同时给出比事后方法更忠实、更紧凑的"标签条件化"解释。
- **值得追问 / 局限**：（1）稀疏边掩码的稀疏度超参如何在无解释真值下校准，会否为了紧凑而牺牲忠实度？（2）负相关标签对的"证据分离"是否真达因果意义，还是仅统计层面的掩码差异？

## B. 应用场景

### 4. The Von-Neumann State-Space Transformer for neural decoding (VN-SST)
- 链接：https://arxiv.org/abs/2608.25088 （cs.LG / cs.AI / q-bio.NC）
- 作者：Morteza Sarafyazd
- **TL;DR**：受冯·诺依曼"取指-执行"启发，让 Transformer 的前馈块不是对每个 token 用同一算子，而是由携带的状态空间记忆当"指令指针"、逐 token 合成专属权重矩阵，从而在运动皮层神经解码上极其数据高效。
- **解决什么问题 / 为什么重要**：皮层计算高度低维——少数潜变量驱动高维神经响应；目标是**样本高效**地从有限数据、小参数量里解码。直接命中你关注的神经/脑时序解码方向，且方法本身对"低维动力学如何路由计算"给出可解释假设。
- **核心方法**：VN-SST 是记忆增强 Transformer，前馈块为低秩"指令库"（共享基算子 + 一小组学到的低秩指令）；每个 token 的 code 从状态空间记忆的低维投影读出，用来合成该 token 实际使用的权重矩阵——慢变潜轨迹充当指令指针，对应低维动力学路由皮层计算的设想。
- **主要结果**：在 3 个运动皮层解码基准上（同时预测脉冲与解码行为），比现代 Transformer 数据高效得多，在最稀缺基准上大幅领先、另两个也领先，且**更长上下文带来精度上升而非下降**；网络把大指令库压到每 token 几比特——"程序容量"是控制通道而非精度杠杆。同一模型在两个小型文本基准上也更参数高效，暗示机制具通用性。
- **值得追问 / 局限**：（1）单作者、以运动皮层为主，跨到 fNIRS 这类更慢、信噪更低的脑功能时序是否仍数据高效有待验证；（2）"指令库→几比特/ token"的压缩解释很吸引人，但程序容量与解码精度解耦的因果证据仍偏经验性。

### 5. Multiscale Community-Based Fingerprinting of Signed Functional Networks
- 链接：https://arxiv.org/abs/2608.27483 （q-bio.NC / cs.LG / eess.SP）
- 作者：Sema Athamnah, Selin Aviyente（Michigan State University）
- **TL;DR**：不用对噪声敏感的边级特征，而用**带符号多层社区结构（含正相关与反相关）**的介观结构给每个被试做"功能连接组指纹"，更稳、更可解释、更跨任务泛化。
- **解决什么问题 / 为什么重要**：功能连接组含被试特异性"指纹"可跨会话/任务识别个体，但既有边级方法噪声敏感、难解释、跨任务泛化弱。这切中你的脑功能网络 / neuroimaging 时序方向，且强调可解释与跨会话稳健。
- **核心方法**：提出多尺度、基于社区的指纹框架——引入**带符号多层社区检测**，同时利用正相关与反相关脑活动识别被试特异的社区结构；再从联合社区结构上算图论指标，得到低维"社区级"指纹表征。
- **主要结果**：在 HCP 的 810 名健康被试上评测，社区级指纹为跨会话/跨任务的个体化脑刻画提供了可靠且可解释的基底；介观社区结构本身即具判别性。
- **值得追问 / 局限**：（1）全为健康被试，用于临床/疾病人群（个体变异更大）时指纹稳定性未知；（2）"带符号多层社区检测"的分辨率参数与层间耦合如何选，对指纹判别力影响多大未细究。

## C. Agent（机制/训练类）

### 6. ContextPilot: Teaching Agents for Proactive Context Management via Fine-grained RL
- 链接：https://arxiv.org/abs/2608.28476 （cs.CL，EMNLP 2026 Main）
- 作者：Zhuoshi Pan, Qizhi Pei, Junru Lu, Honglin Lin, H. Vicky Zhao, Di Yin, Xing Sun（Tencent 等）
- **TL;DR**：给长程 agent 加上"会规划、有长期记忆、能软压缩"的上下文管理工具集，并用**细粒度信用分配**的 RL 训练它在多轮里主动编辑自己的工作上下文，用更小的上下文拿到更好性能。
- **解决什么问题 / 为什么重要**：长程 agentic 任务要跨多轮检索、整合、维护分散信息，保留全部历史会让工作上下文无限膨胀。现有主动上下文管理有三大短板：工具集只有搜索/删除/摘要、缺全局规划与长期记忆；对异质影响的编辑动作一视同仁地探索；把轨迹级奖励粗暴摊给所有中间编辑动作。这属于你优先的 agent 机制/训练动态类（记忆、规划、信用分配），非 prompt 工程。
- **核心方法**：（1）系统性扩充工具集——加入规划、长期记忆、软上下文卸载；（2）为上下文管理定制 RL——用上下文与熵变化识别关键编辑决策做分支采样，并从经过该编辑动作的所有分支轨迹估计**动作级优势**，实现细粒度信用分配。
- **主要结果**：在长上下文 QA 与深度搜索任务上，ContextPilot 用更紧凑的工作上下文取得更强性能，跨多种基座模型与基准稳定超过现有基线；已开源（github.com/Tencent/ContextPilot）。
- **值得追问 / 局限**：（1）"上下文/熵变化识别关键动作"的启发式在噪声轨迹上是否稳健，会不会漏掉低熵但高影响的编辑？（2）分支采样带来的额外 rollout 开销与收益的性价比、以及对更长（数十轮以上）任务的可扩展性未充分展开。
