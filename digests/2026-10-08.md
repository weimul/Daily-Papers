## A. 核心方法（图学习 / 连续时间动力学 / 自解释，取 3 篇）

### 1. Oscillatory Neural Dynamics over Sheaves (ONDA)
- 链接：https://arxiv.org/abs/2610.10018
- 作者：Jan-Willem Van Looy, Alessandro Trenta, Alessio Gravina, Alessio Borgi, Ferdinando Zanchetta 等（8 位，含 Pietro Liò / Davide Bacciu / Rita Fioresi；cs.LG）
- **TL;DR**：图神经网络的"长程传播"顽疾在于——加深层数并不保证远处节点真的能相互影响；本文让 sheaf（层）上的 stalk 表征按**二阶（波动式）动力学**演化、并由可学习的 sheaf 传输算子驱动，用"信息波"而非扩散来实现不衰减的长程通信。
- **解决什么问题 / 为什么重要**：正中 A 的时空/连续动力学图学习。它把"矩阵值传输（sheaf 的表达力）"与"波动传播（避免过平滑/信息衰减）"显式耦合，并给出 stalk 级敏感度分析**证明跨节点影响永不消失**——这是对 GNN 长程瓶颈的一个有原理的回答，而非堆层数或加残差的工程 trick。
- **核心方法**：stalk 表征在学到的 sheaf 传输算子下按二阶 ODE（波动方程类）演化 → 波式传播 + 局部矩阵值几何 → 用 stalk-wise 敏感度分析刻画长程影响下界（cross-influence 不消失）。
- **主要结果**：在长程传播、严重图瓶颈（bottleneck）、graph transfer、异配（heterophilic）等多类基准上，一致优于标量波传播、扩散式 sheaf 基线及 SOTA 模型。
- **值得追问 / 局限**：① 二阶动力学 + 算子值传输的计算/内存开销与可扩展性（大图、长积分步数）文中以基准胜负为主，训练稳定性与成本细节值得追问；② "cross-influence 永不消失"是存在性/下界结论，实际任务里该影响是否足够**有用**（而非仅非零）仍依赖具体数据的信号强度。

### 2. Broadly Applicable Approximate MCMC for Switching Stochastic Differential Equations (SSDE)
- 链接：https://arxiv.org/abs/2610.10194
- 作者：Shion Hosoda, Michiaki Hamada（2 位；stat.ML / cs.LG）
- **TL;DR**：切换随机微分方程（SSDE）用一个连续时间马尔可夫链（CTMC）控制"何时切换动力学参数"，能刻画异质系统行为；但其贝叶斯推断一直受限（要求无噪声观测、单变量、线性漂移或状态无关扩散）。本文用 **uniformization + 时间条件化的因子化神经似然估计（FNLE）**做近似 MCMC，摆脱对解析可解转移密度的依赖。
- **解决什么问题 / 为什么重要**：命中 A 的"连续时间模型 / 不规则采样动力学 + 模拟推断"。uniformization 给出 CTMC 的精确表示但需要任意时间区间的 SDE 转移密度，作者用**时间条件 FNLE** 训练一个可对任意间隔求值的似然代理，从而把推断器推广到此前方法够不着的多变量、非线性漂移、状态相关扩散等一般 SSDE。
- **核心方法**：uniformization 表示 CTMC → 训练 time-conditioned FNLE 近似 SDE 跨区间转移密度 → 组合成对一般 SSDE 都适用的近似 MCMC 采样器，联合恢复 regime 路径与参数。
- **主要结果**：在三类此前方法适用性受限的合成 SSDE 上均能恢复 regime 切换路径与参数；在一个真实数据集上检测到一次 regime 切换。
- **值得追问 / 局限**：① "近似"MCMC 的误差来自 FNLE 的拟合质量，论文未必给出后验校准/覆盖率的严格评估，实际置信度需谨慎；② 真实数据仅演示"检测到一次切换"，面向高频/高维、切换频繁的工程时序（如监控信号）其可扩展性与可靠性尚待验证。

### 3. DisParQ: Self-Supervised Part Concepts for Interpretable Vision Foundation Models
- 链接：https://arxiv.org/abs/2610.09802
- 作者：Adam Pardyl, Siddhartha Gairola, Sukrut Rao, Adam Wróbel, Bartosz Zieliński 等（7 位，含 Bernt Schiele / Dawid Rymarczyk；cs.CV / cs.AI / cs.LG）
- **TL;DR**：概念瓶颈类模型要么概念类别固定、要么靠语言来定义概念。DisParQ 从一个冻结的纯视觉自监督骨干中，**无需类别标签、无需语言监督**地学出"空间落地的离散部件概念"：每个图像 patch 恰好分到一个可学习原型字典里的概念，且每图只允许稀疏子集激活。
- **解决什么问题 / 为什么重要**：强命中 A 的内生 / 自解释（prototype-based、built-in interpretability），且刻意避开 post-hoc 归因与语言对齐依赖。它用"概念 + 属性能否重建骨干表征"作为**信息保真度的内生判据**——重建成功即说明离散表征保住了骨干信息，从而让"模型依赖什么"可直接追溯到可人审的部件概念。
- **核心方法**：冻结 DINOv2 骨干 → 每 patch 硬分配到原型字典中的单个概念（每图稀疏激活）→ 对每个概念学连续残差再**量化为离散属性**（刻画如"轮子"的类型变化）→ 空间解码器仅凭概念+属性重建骨干表征。
- **主要结果**：在 ImageNet 线性探测上 83.2% top-1，贴近其冻结 DINOv2 teacher；概念一致性高于语言对齐模型；在 CUB/Cars/Dogs/Flowers 等细粒度基准保持竞争力，并支持跨类别的部件检索。
- **值得追问 / 局限**：① 概念"可人审"主要靠定性检索/一致性指标佐证，缺乏与人类部件标注的大规模定量对齐，概念语义的客观性仍有空间；② 硬分配 + 稀疏激活对骨干质量依赖强，换用更弱/领域外骨干时概念是否仍稳定、是否迁得到时序或图信号尚未展开。

## B. 应用场景（脑网络 fNIRS 同族 / 监控告警处置，取 2 篇）

### 4. MovieSTAGE: Scene, Transition, and Global Encoding for Movie-fMRI ADHD Classification
- 链接：https://arxiv.org/abs/2610.09306
- 作者：Boseong Kim, Haejun Chung, Ikbeom Jang（3 位；cs.LG / q-bio.NC）
- **TL;DR**：自然观影 fMRI 提供有时间结构的脑动态探针，但预测模型多用整段功能连接（FC）或与叙事事件无关的"时间通用"表征。MovieSTAGE 做**多尺度**建模：场景内用**超图结构**组织 FC 画像、相邻场景间取无符号 FC 差分（转场）、再叠加整片 FC。
- **解决什么问题 / 为什么重要**：命中 B 的脑网络 / 神经时序应用（与 fNIRS 同属脑功能成像家族），并带 A 的动态图味道——超图 + 场景/转场即一种事件对齐的时变图结构。它直接验证了"把表征对齐到叙事事件（场景、转场）相比时间通用表征能带来增量预测价值"。
- **核心方法**：场景内 HGNN 超图编码 FC 画像 + 相邻场景无符号 FC 差分（转场）+ 整片 FC，三分支多尺度融合做分类；用人工标注的场景切分对比时长匹配随机/定数 GSBS 控制。
- **主要结果**：在 CMI-HBN《卑鄙的我》队列 260 人上，case-control / ADHD 亚型 / 三分类的 AUROC 分别 0.69 / 0.73 / 0.75，平衡准确率 67.6% / 69.8% / 58.3%，为所评方法中最高均值；三分类下全模型优于各双分支变体，HGNN 场景编码器在同设置下优于 MLP / GAT / BNT，人工场景切分优于随机/定数控制。
- **值得追问 / 局限**：① 绝对精度仍偏中等（三分类平衡准确率 58.3%），临床可用性有限，且结论绑定单一影片/单一队列，跨影片与跨站点泛化未知；② "事件对齐带来增量"依赖人工场景标注，自动切分（GSBS）更弱，落地时标注成本与自动化质量是瓶颈。

### 5. Constrained-Action AI Remediation for SIEM/XDR via a NeMo-Guardrails Proxy
- 链接：https://arxiv.org/abs/2610.09906
- 作者：Georgios Koutidis, Nikolaos Kekatos, Tom Nianios, Alexios Lekidis（4 位；cs.CR / cs.AI / cs.CL）
- **TL;DR**：SOC 面对海量关联告警、分析师稀缺，于是让 LLM 直接推理并下达"封 IP / 杀进程 / 隔离文件"等处置命令——但这引入新风险：**一条对抗性告警**可经由 LLM 推理变成远程代码路径。本文提出"受约束动作"架构：把 LLM 输出**限制到封闭意图词表**，由瘦端点代理执行模板化命令，并加参数校验器兜底。
- **解决什么问题 / 为什么重要**：正中 B 的监控告警-根因-处置闭环（AIOps / SOC），且是**机制 / 架构导向而非 prompt 工程**——它不是靠提示词让模型"别乱来"，而是用控制平面 + 封闭意图词表 + 护栏代理把 LLM 的不可控输出在越过信任边界前就物理收敛，直面"自主处置 LLM 的注入与误动作"这一安全痛点。
- **核心方法**：① SIEM/XDR 控制平面把处置锚定到关联主机事件，并把 LLM 输出限制为封闭意图词表（模板命令 + 参数校验器）；② NeMo-Guardrails 代理给 SOC 分析 LLM 套输入/输出 rail 策略，用作者发布的 SOC 专用对抗语料做开箱评测。
- **主要结果**：现成护栏代理把注入召回率从 25.0% 提到 94.5%（0.1% 假阳率）；实弹红队确认封闭意图词表 + 参数校验器能在命令越界前遏制观察到的 LLM 失效模式；定位为"架构契合"而非已测的 OT 实部署，建议人在环或延迟执行（实测 rail 延迟使内联控制暂不在范围内）。
- **值得追问 / 局限**：① 封闭意图词表的表达力上限决定了可自动处置的故障/攻击类型覆盖，词表外情形仍需人工扩展；② 结论基于作者自建对抗语料 + 红队，尚无真实 OT/生产环境的在线处置评测，延迟也暂不支持内联自动闭环。

## C. 机制 / 表征分析（高优先级，取 1 篇）

### 6. LayerRoPE: Dynamic Depth-wise Magnitude & Angular Superposition
- 链接：https://arxiv.org/abs/2610.09179
- 作者：Shikhar Srivastava, Christopher Kanan（2 位；cs.LG / cs.AI / cs.CL）
- **TL;DR**：Transformer 隐状态范数随深度暴涨（"深度诅咒"）几乎总被当作要压制的病态。本文反其道：跨 9 个家族 16 个预训练 LLM 发现，这种增长其实是一种**涌现的深度位置编码**——由残差流上唯一的逐层可学习增益（归一化权重 γ）承载，γ 随深度既增幅又转向，联合编码了层索引。
- **解决什么问题 / 为什么重要**：强命中 C 的表征几何 / 训练动力学 / 机制分析（残差流、涌现结构、跨模型现象），且非 prompt 工程。它把一个被普遍"修正"的现象重新解读为**功能性结构**，并据此给出可落地的架构改动，连接了"机制发现→设计改进"。
- **核心方法**：把逐层 γ 向量替换为单个共享向量 + 深度条件标量（沿深度轴的 RoPE 隐式类比），净减参数、FLOPs 变化 <0.02%；在最长 512 层、最高 100B+ token 的模型梯度上验证其可扩展性与收敛性。
- **主要结果**：LayerRoPE 一致优于 Pre-/Post-/Peri-Norm 与 Layer-Norm Scaling，以 3.4× 更少算力达到 Pre-Norm 的 1.3B loss；是唯一在深度扩到 512 层时仍强收敛并近单调改善者；学习率敏感度改善 3–10×，并可直接迁移到 looped latent 模型与 ViT 并一致提升。其学到的调度"拓宽而非收缩"残差流——抑制每块的读取、放大其写出。
- **值得追问 / 局限**：① "范数增长 = 深度位置编码"主要是相关性 + 干预（替换 γ）证据，是否存在其它同样解释该现象的机制（如优化动力学副产物）仍可追问；② 改进主要在预训练 loss / 收敛性与可扩展性上展示，对下游任务质量、长上下文外推的直接增益需更多端到端评测。
