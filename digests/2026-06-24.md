## 1. Reconstructing GRACE Terrestrial Water Storage with Spatio-Temporal Graph Neural Networks
- 链接：https://arxiv.org/abs/2606.23833
- 作者：Lukas Arzoumanidis, Lara Johannsen, Klara Middendorf, Annette Eicker, Youness Dehbi（HCU Hamburg）
- 方向：A（时空图 GNN + 可解释图结构）
- **TL;DR**：把原本给城市交通/传感网设计的多变量时序图网络（MTGNN）迁到卫星大地测量任务上，用一张「可解释的混合邻接矩阵」把日尺度气象强迫映射成月尺度 GRACE 陆地水储量异常，并外推到 1940 年。
- **解决什么 / 为什么重要**：GRACE/GRACE-FO 是唯一全球一致的陆地水储量直接观测，但记录只从 2002 年起，太短，做不了气候尺度分析。过去重建多用逐格点回归 / CNN / LSTM，丢掉了空间耦合与遥相关。这篇把「时空依赖」显式编码进图，正落在我关注的 spatio-temporal GNN + 内生可解释结构方向。
- **核心方法**：MTGNN 架构；空间依赖编码为一个静态、可解释的混合邻接矩阵——结合测地邻近度与气候时序的滞后相关，同时刻画局部水文耦合与大尺度遥相关；输入日尺度 ERA5（降水、蒸散、径流），输出月尺度 TWSA。
- **主要结果**：格点 Pearson 相关 0.69、流域均值相关 0.94、近零偏差；能重现 2015/16 El Niño 与 2020/21 La Niña 的空间指纹；在流域尺度与既有重建方法（GTWS-MLrec、RM-REC、GRAiCE）相关性差距仅 0.025，却只用其约 1/2 到 1/10 的预测变量。代码开源。
- **追问 / 局限**：(1) 邻接矩阵是「静态」的——slowly time-varying 的水文耦合用动态/可学习图是否更优？(2) 各模型在干旱区都暴露系统性弱点，混合邻接的滞后相关在弱信号区是否反而注入噪声。

## 2. Low-rank Updates in Slowly Time-varying Graphs for Spatial-Temporal Signal Interpolation
- 链接：https://arxiv.org/abs/2606.24011
- 作者：Saghar Bagheri, Gene Cheung, Tim Eadie, Antonio Ortega
- 方向：A（动态图 / 时变图信号处理）
- **TL;DR**：当节点间相似度随时间缓慢漂移时，静态空间图不够用；把相邻两时刻邻接矩阵之差建成「低秩」结构，联合插值信号并估计下一时刻的图，再把迭代展开成轻量网络。
- **解决什么 / 为什么重要**：图信号处理默认有一张固定的底层图来刻画节点相似度，但时空数据里这种相似度本身在演化。把「图的变化」显式建为低秩更新，是处理 slowly time-varying graph 的干净抽象，正对我 dynamic graph / 时空信号方向，也可迁到传感网监控的缺失值插补。
- **核心方法**：把 $P=W^{(2)}-W^{(1)}$ 建模为低秩；交替优化——固定图时用图信号平滑先验解线性系统插值 $x_2$，固定信号时用近端梯度更新 $W^{(2)}$；秩项的近端映射用「以 $W^{(1)}$ 特征向量外积为原子的字典 + 快速 OMP」在线性时间内近似；最后把若干次迭代展开成轻量网络做少量数据驱动调参。
- **主要结果**：在时变图信号插值上优于现有时变图模型；展开式网络兼顾可解释优化结构与少量可学习参数。
- **追问 / 局限**：(1) 「相邻时刻图差为低秩」对突变/换拓扑场景（监控里的故障切换）是否成立？(2) 只演化一步（t=1→t=2）的两帧设定，扩到长序列、误差是否累积。

## 3. GRACE: Gated Refinement for Accurate Causal Edge Discovery in High-Dimensional Time Series
- 链接：https://arxiv.org/abs/2606.23880
- 作者：Mohammad Fesanghary, Abhinav Havaldar
- 方向：A（高维时序 + 内生稀疏门控 / 自选择结构）× B（因果定位，可迁 RCA）
- **TL;DR**：用 Hard Concrete 门 + $L_0$ 正则给约束式因果发现「补刀」——每条候选边一个独立门，取值向 0/1 集中形成干净双峰，把"二值化阈值"这件脏事变成可学习的内生决策。
- **解决什么 / 为什么重要**：几十上百个交互变量时，约束式方法的非线性 CI 检验跑不动，打分式方法又要人为阈值切边。GRACE 的门控是一种「built-in 稀疏选择」——边的去留由"是否真正改善预测"内生学出来，而非事后阈值，契合我对自解释/内生结构的偏好；高维时序因果边发现也直接对应监控告警里的根因定位。
- **核心方法**：先用快速线性 CI 骨架给高召回候选，再用单个门控模型剪假阳——每条边一个 Hard Concrete 门、$L_0$ 正则按问题维度与骨架密度自动调；门值双峰分离让二值决策鲁棒（对比 $L_1$/注意力法那种窄而重叠的分数分布）。
- **主要结果**：合成基准（scale-free / ER / small-world，维度到 d=100）F1 显著超基线并保持高精度；与昂贵非线性 CI 检验持平或更好且快 75×；真实 Elbe 河流量数据上，时序 bootstrap 变体在 11 条因果边中找回 9 条、仅 1 个假阳（F1=0.86，AUROC=0.99），把骨架的 106 个假阳削掉 99%。
- **追问 / 局限**：(1) 门控的双峰分离依赖"边是否改善预测"，强混杂/同步驱动下能否区分真因果与共因？(2) 真实数据只验证了单一河流系统，扩到更高维、非平稳监控指标的稳定性待验。

## 4. Uncertainty-Aware Longitudinal Forecasting of Alzheimer's Disease Progression Using Deep Learning
- 链接：https://arxiv.org/abs/2606.24604
- 作者：Arya Hariharan, Shreyank N Gowda, Anala M R
- 方向：B（神经影像/临床纵向时序）× A（多步轨迹 + 分解式不确定性）
- **TL;DR**：把阿尔茨海默进展从"单步分类"升级为"概率轨迹"——Temporal Fusion Transformer 编码器 + CORAL 有序输出 + 自回归混合密度网络，生成五年的诊断/生物标志物概率轨迹，并把不确定性拆成偶然性与认知性两部分。
- **解决什么 / 为什么重要**：临床上有用的不是"下一次最可能的诊断"，而是"会怎么演化、这个预测有多可信"。多数深度模型把 CN/MCI/痴呆当扁平类别做单步分类，看不出不确定性如何随未来访视累积。这篇把有序结构、多时程轨迹、不确定性分解拼齐，正对我关注的不规则纵向脑健康时序 + 标定不确定性。
- **核心方法**：TFT 编码器加 CORAL 有序输出层、非对称损失加权与转化者过采样，尊重疾病分期顺序、提升 MCI→痴呆敏感度；以学到的患者上下文表示为条件，自回归 MDN 生成诊断状态、CDR-SB、MMSE、海马体积的五年概率轨迹；用解析混合方差 + 五成员 bootstrap 集成分离偶然性/认知性不确定性。
- **主要结果**：ADNI 上下一访视诊断优于线性/循环/Transformer 基线，MCI-vs-痴呆区分增益最大；生成轨迹达近名义 90% 可信区间覆盖、不确定性随时程展宽；认知性不确定性在罕见进展型、MCI/痴呆患者及外部 OASIS-3 上更高且随误差同增。
- **追问 / 局限**：(1) 偶然/认知不确定性的分解依赖五成员 bootstrap，集成规模偏小，认知性信号是否稳健？(2) 轨迹评估主要看覆盖率，长时程多步生成的校准是否会过宽（牺牲锐利度换覆盖）。

## 5. NeuroSonic: Conditional Flow Matching for EEG-to-Speech Reconstruction
- 链接：https://arxiv.org/abs/2606.24087
- 作者：Wenhao Gao, Yifan Wang, Yijia Ma, Carl Yang, Wen Li, Chenyu You
- 方向：B（脑信号解码 / 神经时序，可迁 fNIRS）× A（连续时间 ODE 传输 / 流匹配）
- **TL;DR**：不做波形回归、也不做随机多步去噪，而是学一个确定性的概率流速度场，在 EEG 条件下把含噪声学状态"传输"成干净语音——把 EEG→语音重建写成连续时间 ODE。
- **解决什么 / 为什么重要**：EEG 是弱、空间弥散、个体差异大的皮层活动测量，语音却是强谐波/时间结构的声学轨迹，二者错配让波形回归不稳、随机生成对伪迹条件敏感。NeuroSonic 用确定性连续时间传输绕开迭代随机采样。虽是 EEG 而非 fNIRS，但"多通道脑信号 + 连续时间 ODE + 跨被试条件生成"这套范式可直接迁到我做的 fNIRS / 脑功能时序解码。
- **核心方法**：条件流匹配；EEG 与音频嵌入到共享 token 空间，由时间条件门控 Transformer 参数化传输 ODE 的速度场；学确定性概率流速度场把噪声扰动的声学态运到干净语音，避免迭代随机采样。
- **主要结果**：CineBrain、EAV 两个基准跨被试评测，在分布真实性、谱保真、感知质量上均超 GAN / 扩散 / mean-flow 代表性基线，整体感知质量最高提升 26.3%；在伪迹密集（条件变化最强）片段优势最明显。代码开源。MICCAI 2026 接收。
- **追问 / 局限**：(1) fNIRS 时间分辨率低、是血氧动力学而非电活动，确定性传输的"强时间结构"假设是否还成立？(2) 跨被试泛化主要靠共享 token 空间，对新被试零样本迁移的下界未知。

## 6. Reasoning as Attractor Dynamics: Latent Memory Retrieval via Gibbs-Weighted Energy Minimization
- 链接：https://arxiv.org/abs/2606.24543
- 作者：Kanishk Awadhiya
- 方向：C（agent —— 机制/表征几何，"优先"类）
- **TL;DR**：把 LLM 不再看成自回归生成器，而是高维稠密联想记忆——正确推理链对应能量地形里又深又宽的吸引子盆地（flat minima），幻觉是尖锐不稳的局部极小；据此用 Gibbs 权重把多条采样路径"驰豫"到稳健解。
- **解决什么 / 为什么重要**：这是我看重的 agent 机制/表征几何视角（而非 prompt 技巧）——用集体计算/能量地形重新解读推理，把"为什么自洽采样有效"落到吸引子盆地的几何上，和近来 residual stream / 联想记忆 / neural collapse 这条线一脉相承。
- **核心方法**：把推理建模为联想记忆的驰豫过程；采样多条推理路径，按其轨迹谱熵构造的 Gibbs 测度 $P\propto e^{-\beta E}$（逆能量加权）近似联想记忆的平衡分布，从而把系统"松弛"到稳健解，而非贪心逐 token 预测。
- **主要结果**：在 Microsoft Phi-3.5 上，GSM8K 准确率从 84.7% 提到 90.1%（+5.38%），支持"推理更像动力学沉降进吸引子盆地"的论点。ICLR Workshop 2026 接收。
- **追问 / 局限**：(1) "flat minima = 正确、sharp = 幻觉"是颇强的经验假设，谱熵能量是否在更难/对抗题上仍与正确性单调对应？(2) 只在单模型单数据集（Phi-3.5 / GSM8K）验证，且需多路径采样，推理成本与可扩展性待评。
