## A. 核心方法（长时时序 Transformer · 时序基座数据均衡 · 内生自解释 CNN）

### 1. SETTer: Sparse-Encoder Transformer for Long-term Multivariate Time Series Forecasting
- 链接：https://arxiv.org/abs/2609.20086
- 作者：Abraham Ezema, Chijioke Eze, Ferdinanda Ponci, Antonello Monti（4 位作者；机构未在元数据中给出）
- **TL;DR**：面向电力、交易等高维多变量长时预测——Transformer 虽因注意力擅长长时依赖，但在复杂高维输入下会过平滑、容量受限且不透明；SETTer 用"解耦自注意力 + 混合掩码"在**单层** Transformer 上同时抓住时间维与通道维的主导短/长期模式，并在层内嵌入可解释结构指示判别性模式。
- **解决什么问题 / 为什么重要**：命中核心方向 A 的多变量时序预测，且把"内生可解释结构"直接织进骨干，呼应 A 的自解释横切——不是事后归因，而是让模型层本身给出可读的判别模式，对时序/图时序预测骨干有借鉴意义。
- **核心方法**：① 解耦自注意力，把时间维与通道（变量）维的注意力分开建模，缓解高维输入下的过平滑；② 混合掩码机制，兼顾短期与长期模式；③ 层内加入简单可解释结构以指示 SETTer 学到的判别性模式；整体仅用单层 Transformer 架构即可建模长时依赖。
- **主要结果**：在多个真实长时多变量预测基准上，SETTer 在 88% 的场景下超过 SOTA 模型。
- **值得追问 / 局限**：① "解耦时间/通道注意力"在变量间强耦合（如路网、脑网络等强空间依赖）场景下是否会牺牲跨变量交互建模，值得看消融；② 内嵌可解释结构的"可读性"到底提供了多少可验证的解释力，摘要未给量化，需正文佐证。

### 2. QUALS: Corpus Equilibrium for Universal Forecasting via Pattern Quantization and Learnability Synchronization
- 链接：https://arxiv.org/abs/2609.20156
- 作者：Yujie Li, Zezhi Shao, Chengqing Yu, Yisong Fu, Weijie Zhu, Yifan Du 等（10 位作者；机构未在元数据中给出）
- **TL;DR**：时序基座模型多在架构上做文章、却用简单采样喂数据，导致对复杂分布利用不充分；QUALS 从**数据侧**入手，用"模式量化 + 可学习性同步"做大规模语料均衡，让现有模型只用一小部分训练数据就拿到更好的零样本预测。
- **解决什么问题 / 为什么重要**：命中 A 的时序建模面，但视角是"数据分布均衡"而非又一个骨干——对交通、电网等跨域时序基座的训练效率是通用增益，且提示时序基座的瓶颈可能在数据组织而非架构。
- **核心方法**：① 模式量化框架，用向量量化 + 均匀分箱把混合语料里的异质模式系统解码出来；② 可学习性同步框架，为异质模式校准采样权重，弥合"简单 motif 与复杂 motif"之间的优化差距，最大化整体训练效率。
- **主要结果**：在多项基准上，用 QUALS 预训练即便在大幅缩减训练预算下也一致取得更优的零样本预测表现。
- **值得追问 / 局限**：① 模式量化的码本粒度与分箱方式对不同域（强周期 vs 强突变）的鲁棒性如何，摘要未展开；② "可学习性同步"给复杂 motif 加权，是否会在噪声主导的数据上放大坏样本，值得看权重校准的稳定性分析。

### 3. TetrisCNN for interpretable detection of phases of matter from experimental quantum simulator data
- 链接：https://arxiv.org/abs/2609.20693
- 作者：Kacper Cybiński, Björn van Zwol, James Enouen, Guillaume Bornet, Thierry Lahaye 等（9 位作者；机构未在元数据中给出）
- **TL;DR**：用神经网络无先验地定位相变虽已可行，但多是黑箱、只报"有没有相变"、且遇噪声实验数据就崩；TetrisCNN 用"俄罗斯方块式"多形状并行卷积分支学到**稀疏可解释**的潜表征，并把决策边界写成由可测自旋关联子构成的**符号公式**。
- **解决什么问题 / 为什么重要**：这是一篇正面的"内生/自解释"方法论工作，正中 A 的自解释横切——不做事后归因，而是让模型的潜表征与决策边界本身以可验证的符号形式呈现，且在含噪的真实实验数据上验证。虽落地在量子相变，但"稀疏可解释潜空间 + 符号化决策"的思路对时序/图上的自解释建模有直接迁移价值。
- **核心方法**：并行的多种形状卷积滤波器（形似 Tetris 方块）→ 稀疏、以自旋关联子表达的可解释潜表征；应用于二维 Ising 与 XY 量子模拟器在多个测量基下的实验快照，不仅检测相变/渐变，还把潜表征与决策边界表达为由可测量关联子构成的符号公式。
- **主要结果**：在真实（含噪）实验快照上成功检测相变与 crossover，并给出可读的符号化判别规则；证明"可解释神经网络 + 量子模拟器"可用于发现并理解新相。
- **值得追问 / 局限**：① 符号公式的表达力受限于"预设的关联子基"，对无已知序参量的全新相是否够用需进一步验证；② 多分支 Tetris 滤波器的可解释性能否扩展到更高维/更长程关联（更接近图/时序场景）尚待检验。

## C. Agent / 机制分析（观测监督改变探索动态 · LLM 群体高估共识）

### 4. Don't Mask the Environment: Observation Supervision Changes How Agents Explore Under RL
- 链接：https://arxiv.org/abs/2609.20715
- 作者：Juzheng Zhang, Disha Makhija, Manoj Ghuhan Arivazhagan, Vinayshekhar Bannihatti Kumar, Rashmi Gangadharaiah（5 位作者；机构未在元数据中给出）
- **TL;DR**：标准 SFT 只对 agent 自己产出的动作 token 算损失、把环境观测当上下文却不当预测目标；本文提出 **ActObs**——把轨迹里本就存在的观测 token 也纳入监督，让策略学会"预测动作后果"，并从**梯度正交性**角度解释它为何改变后续 RL 的探索行为。
- **解决什么问题 / 为什么重要**：命中方向 C 的"训练动态 / 机制现象分析"优先项，且刻意避开 prompt 技巧——核心贡献是把"要不要监督观测"这一训练约定当科学问题拆开，用梯度分析给出机制解释，对理解 agent 表征在 SFT→RL 间如何演化有普适价值（不加数据、参数、token 或前向）。
- **核心方法**：在既有轨迹上对观测 token 追加监督（ActObs），使策略在不新增任何计算/数据的前提下学会建模动作后果；对比 action-only SFT 与 GRPO 后的行为，并追踪 SFT 阶段动作梯度与观测梯度的方向关系。
- **主要结果**：SFT 后两者相近、GRPO 后分化：Qwen3-4B 上 ActObs 在各采样预算下 pass@k 均更高（Terminal-Bench 2.0）；Qwen3-8B 上以少量 pass@1 换取更高 pass@k（pass@16 +3.4pp）并解出更多任务；跨域代码编辑（aider-polyglot）pass@1 +4.2pp。机制上：action-only 训练会让动作/观测梯度迅速正交、并把环境预测能力压到基座模型以下，而联合监督避免这种"单边特化"，保留后果预测、为下游探索保留更多熵且策略移动更小。
- **值得追问 / 局限**：① "保留更多熵、策略更贴近 SFT 初始化"是否在更长时程、更强奖励塑形下依旧带来 pass@k 优势，需更多规模验证；② 观测监督对观测极长/噪声大的环境（如真实网页、终端）是否会引入无用的后果建模负担，值得看代价分析。

### 5. Language-model groups overstate consensus when replaying human deliberation on a reasoning task
- 链接：https://arxiv.org/abs/2609.20543
- 作者：Tengfei Shao（1 位作者；机构未在元数据中给出）
- **TL;DR**：用同一套评分代码，把 100 组"留出"的人类 Wason 推理讨论用匹配的 LLM agent 群回放（每个参与者的赛前答案各锚一个信念的 agent），结果 agent 群体系统性地比人类**更容易达成一致**，而且常常一致在错误答案上。
- **解决什么问题 / 为什么重要**：命中 C 的"机制/现象分析"优先项——这是把"多智能体是否等于集体认知"当实证科学问题来拆的工作，直接量化了 LLM 群"过度共识"这一现象，对用多智能体模拟人类审议、群体决策的做法是重要警示。
- **核心方法**：回放 100 组人类 Wason 小组，每个参与者赛前答案各种一个"信念锚定"agent，agent 与人用同一评分口径打分；跨多种人类评分定义、两种揭盲后敏感性分析（基于提交的 n=98、参与度匹配的 n=45），并做去除"可记忆答案"的重参数化对照。
- **主要结果**：人类全一致率随评分口径在 24.0%–57.0% 间波动（约五分之一参与者从不发言，而 agent 几乎总发言）；agent 群在两种敏感性分析下都更一致——chat 与 reasoning 模式分别高出 34.0/43.9 个百分点（提交口径）与 34.1/44.4 个百分点（参与度匹配口径），两条路径收敛在 0.5pp 内；去掉可记忆答案后 reasoning 模式几乎全体一致、且多一致在错误答案上。关键结论：模拟共识**不追踪**集体正确率，信念锚定的 agent 群是人类群体结局分布的有偏估计。
- **值得追问 / 局限**：① 结论基于单一任务范式（Wason 选择任务）与"每人锚一 agent"的设定，向更开放、多议题的审议迁移性待验证；② "reasoning 模式更一致却更错"提示推理增强可能加剧从众——这一因果机制（是趋同压力还是共享错误先验）值得进一步拆解。
