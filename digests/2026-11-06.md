## A. 核心方法（时序图未来链接预测 / 连续时间耦合场景图，取 2 篇）

### 1. MambaTG: Candidate-Aware State Space Modeling for Future Link Prediction on Temporal Graphs
- 链接：https://arxiv.org/abs/2611.07569
- 作者：Nguyen Hong Quan, Sitao Luan, Yilun Zheng, Lihui Chen（cs.LG）
- **TL;DR**：时序图上的未来链接预测既包含"老节点对再次互动（重复边）"也包含"从未互动过的节点对首次互动（首次边）"。现有时序图模型大多吃"历史复现 / 历史重叠"信号，这对重复边极有用、对首次边却基本失效，导致首次边预测大幅掉点。MambaTG 用 **Mamba 状态空间模型**把两类互补信号一起建模。
- **解决什么问题 / 为什么重要**：正中 A 的**时序图 / dynamic link prediction**。它点出"现有方法在首次边上退化"这一被历史复现信号掩盖的痛点，并把未来链接的序列动态显式拆成两项：① **历史序列演化**（源节点按时间排序的互动之间的依赖）；② **候选–历史兼容性**（一个候选对象与源节点"正在演化的历史"匹配得多好）。对"要不要用、怎么用历史信息做时序图预测"给出了结构化的建模视角。
- **核心方法**：把未来链接按上述两项分解 → 用 Mamba 的**选择性递归**建模有序互动历史的演化，用其**输入依赖的状态转移**让历史状态随不同候选输入自适应（这正是"候选感知 candidate-aware"的机制来源）→ 在 13 个时序图数据集、对比 13 个代表性基线做评测。
- **主要结果**：MambaTG 在**重复边与首次边上都取得强且一致的性能**，同时保持计算高效——即它在不牺牲效率的前提下缓解了首次边掉点问题。
- **值得追问 / 局限**：① "历史序列演化 + 候选兼容性"的两分法在超长历史、超大节点度分布下是否仍够用，Mamba 的定长状态会不会成为长程依赖瓶颈，未展开；② 13 数据集多为常见基准，面对真实高吞吐事件流（时间戳分辨率、冷启动节点比例）时的表现与首次边增益是否保持待验证。

### 2. Coupled Scene Graph Anticipation: When With-Constraint Recall Hides Structural Inconsistency
- 链接：https://arxiv.org/abs/2611.06738
- 作者：Zeno Nongmaithem, Anushttha Srivastava, Anshit Sinha, Apoorv Sisodia 等（cs.CV / cs.LG）
- **TL;DR**：场景图预测（SGA）要预测未来视频帧里的物体关系。连续时间 SGA 模型用**独立的 Neural ODE** 演化每一对"主体-客体"关系，导致共享同一实体的关系在积分时互不影响，也拦不住对同一对给出互斥预测（如同时"坐在…上"和"站在…上"）。CoupledSGA 让这些关系在 ODE 向量场里**通过图注意力相互耦合**，并加一个基于互斥谓词矩阵的**结构一致性损失** $\mathcal{L}_{SC}$。
- **解决什么问题 / 为什么重要**：命中 A 的**时空图 / Neural ODE / 连续时间模型**。价值不只在方法，还在它**揭露了评测协议的系统性缺陷**：常用的 With-Constraint 评测每组只保留一个谓词，作者证明——只要每组获胜谓词及其分数不变，R@K / mR@K 就恒定不变，因此**根本无法反映 $\mathcal{L}_{SC}$ 要治理的组内矛盾**。这对"连续时间关系演化该怎么建模、又该怎么公平评测"都有警示意义。
- **核心方法**：在 ODE 向量场内部用**关系互动图（Relationship Interaction Graph）+ 图注意力**耦合相关关系 → 加 $\mathcal{L}_{SC}$ 惩罚互斥谓词共激活 → 作者进一步分析 $\mathcal{L}_{SC}$ 的梯度**依赖谓词分数而非真值标签**：两谓词规则下它放大模型已有的排序，组内分数全相等时则更强地压制出现在更多互斥规则里的谓词——这解释了为何该惩罚会"降低 recall 却提升一致性"。
- **主要结果**：在 Action Genome 上，预热两轮后激活 $\mathcal{L}_{SC}$ 把 R@20 从 42.21% 降到 35.18%，但 No-Constraint 矛盾率从 **45.92% 大幅降到 4.07%**（等预算 R@20：CoupledSGA 40.48% vs. SceneSayerODE 44.78%）。作者明确定位为"测试床而非 SOTA 主张"，并建议对约束谓词共激活的方法**同时报告 No-Constraint 结果 + 矛盾率**。
- **值得追问 / 局限**：① 一致性与 recall 之间是硬权衡，论文未给出"在不牺牲 recall 的前提下消除矛盾"的路径，耦合强度 / 预热时机如何调仍偏经验；② 结论基于 Action Genome 单一数据集与特定互斥谓词表，换到更密集或更长时程的关系图上耦合是否仍稳定、是否引入新的过度抑制，未验证。

## B. 应用场景（LLM 特征做多变量时序异常检测 / E/I 脑网络模块化调控计算能力，取 2 篇）

### 3. Evaluating Language Model Features for Zero-Shot Time-Series Anomaly Detection Under Isolation Assumption
- 链接：https://arxiv.org/abs/2611.07720
- 作者：Romain Hermary, Nesryne Mejri, Djamila Aouada（cs.LG / cs.AI）
- **TL;DR**：时序异常检测（TSAD）天生难——无监督、要高局部精度、标注稀缺。近期把 LLM 跨模态迁移到时序的做法多依赖预测 / 重构这类辅助目标，但模型越强就越可能**把异常也一并重构 / 预测出来**，反而拆了自己的台。本文主张把 **LLM 纯当特征提取器**，直接分析其诱导的特征空间来做**多变量 TSAD（MTSAD）**。
- **解决什么问题 / 为什么重要**：命中 B 的**时序异常检测 / 监控告警**。它绕开"重构 / 预测"这类随模型容量增大而失效的代理目标，转而在"**异常特征应当与正常特征隔离**"这一隔离假设下，直接检验 LLM 特征空间的可分性——对"想复用基础模型做多传感器系统异常检测、又担心大模型把异常学没了"的监控场景给出了一条更稳的评估路线。
- **核心方法**：用**逐时间步 tokenisation（一步一 token）** 保留细粒度局部信息，避免常规 tokenisation 抹掉时间 / 变量结构 → 把 LLM 当冻结特征提取器，用**无监督 Isolation Forest** 直接评估所得表示的质量（时间维与上下文维的判别力）→ 进一步追问：这种可分性究竟来自 LLM 的语言预训练，还是与语言预训练无关地独立涌现。
- **主要结果**：给出 LLM 为多变量时序提供异常检测表示能力的实证画像，并借"性能是否源于语言预训练"的消融，指向跨模态基础模型在 TSAD 上更广的应用空间（论文定位偏"表征质量评测 / 机理归因"，而非刷检测 SOTA）。
- **值得追问 / 局限**：① 隔离假设（异常必与正常可分）在渐变漂移、集体异常、上下文异常等类型上是否成立，Isolation Forest 的线性隔离能力是否成为新瓶颈，未充分展开；② "一步一 token"在长序列 / 高维多变量下的算力与上下文长度开销，以及不同 LLM 骨干间可分性差异的来源，仍需更系统的刻画。

### 4. Cell-type-specific modularity in E/I networks shapes dynamical regimes and computational capabilities
- 链接：https://arxiv.org/abs/2611.06720
- 作者：Emmanouil Giannakakis, Victor Buendía, Oleg Vinogradov, Anna Levina（cond-mat.dis-nn / q-bio.NC）
- **TL;DR**：结构模块化是脑网络的普遍特征、会塑造神经动力学与信息处理，但兴奋性（E）与抑制性（I）群体的模块化组织可以不同，这种不对称如何影响动力学与计算一直不清楚。本文用**动力学平均场理论 + 复杂时序任务仿真**证明：**独立调节 E / I 的模块化程度**可以控制平衡 E/I 网络的动力学区制。
- **解决什么问题 / 为什么重要**：命中 B 的**脑网络 / 神经时间序列（动力学）**。它回答一个机制性科学问题——在整体 E/I 平衡下，结构的细胞类型特异不对称如何决定网络落在哪种动力学区制、又如何影响其计算能力。对"用网络结构先验去理解 / 设计具计算能力的循环系统"（含类脑储备计算、动态图上的动力学建模）有参考价值。
- **核心方法**：用动力学平均场理论刻画平衡 E/I 网络 → 独立调 E 与 I 的模块化强度，观察频谱结构变化 → 在**混沌时间序列预测任务**上测量不同区制下的计算性能，并与皮层连接性对照。
- **主要结果**：① 独立调模块化能在整体 E/I 平衡下**制造出主导性的频谱离群值**，触发"体谱主导 ↔ 低秩主导"的拓扑受控相变，分别经由不同分岔走向**混沌与双稳**；② 在混沌时序预测任务上，**计算性能在这些动力学边界附近（混沌起始、双稳转变）显著增强**；③ 表现最佳的配置是**兴奋强模块化 + 抑制相对均匀**，与皮层连接观测一致。
- **值得追问 / 局限**：① 结论基于平均场理论与仿真网络、合成混沌预测任务，距真实脑连接组数据与真实神经时间序列仍有距离；② "最优配置近似皮层连接"是一个诱人但相关性的观察，是否有因果 / 功能意义、以及对任务类型与噪声的鲁棒性，尚待实证。

### 5. Neural Collapse on Imbalanced Datasets and Open-Set Scenario
- 链接：https://arxiv.org/abs/2611.07753
- 作者：Qiufu Li, Huibing Xiao, Linlin Shen, Yongdong Huang（cs.LG）
- **TL;DR**：神经坍缩（NC）刻画了分类模型损失取到极小时特征与分类器向量呈现的优雅几何结构，但类别不平衡通常会扭曲标准 NC。本文从理论上在**不平衡数据集与开集设定**下重新刻画 NC——关键是把分析建立在**逐类平均损失**（而非以往的全局平均损失）的优化问题上。
- **解决什么问题 / 为什么重要**：命中 C 的**表征几何（neural collapse）**，正中"优先"机制类、非 prompt 工程。它解决一个长期含糊的问题：为什么不平衡会破坏 NC、以及"换一种损失聚合口径"后标准 NC 能否恢复——对理解不平衡 / 长尾 / 开集下学到的表示结构到底长什么样有直接意义。
- **核心方法**：把目标从全局平均损失改为**逐类平均损失**的优化 → 证明当逐类平均损失取极小时，无论数据平衡还是不平衡，**CE 与 BCE 损失下标准 NC 都成立** → 扩展到开集启发场景（部分类无训练样本但仍分配分类器向量）→ 再分析用逆样本频率重平衡的 Softmax / Sigmoid 对比损失。
- **主要结果**：① 逐类平均损失视角下，平衡 / 不平衡数据上 CE、BCE 均达成标准 NC；② 开集场景下，**有样本的已知类仍形成标准 NC，而无样本的未知类分类器向量相互重叠、并与已知类正交**；③ 逆频率重平衡的对比损失在极小时同样让不同类样本特征形成标准 NC。
- **值得追问 / 局限**：① 结论是极小值点处的理论刻画（layer-peeled / 无约束特征类分析），真实训练的有限容量、优化轨迹与早停是否逼近该几何未实证；② "未知类向量相互重叠且与已知类正交"是否可直接转化为开集识别 / 拒识的可用准则，需在真实开集基准上验证。

### 6. Localization Does Not Imply Steerability: A Mechanistic Study of Sign Errors in LLM Mathematics
- 链接：https://arxiv.org/abs/2611.07478
- 作者：Shradha Agarwal, Tariq J., Deepak Rajbhar（cs.LG / cs.AI / cs.CL）
- **TL;DR**：LLM 做多步数学时有个典型失败——中途写错一个符号（代数余子式的正负、分部积分递归里的负号），其余算术都对，答案却错。本文追问"这个错符号是在网络的哪里被写下的"，并给出一个克制而重要的结论：**能定位，不代表能操控（Localization ≠ Steerability）**。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / residual stream**，正中"优先"机制类。它把"符号错误"做成可探测、可因果干预的对象，且**核心主张在看到留出数据前就用 git 冻结做了预注册**（29 项检查过 23 项，未过的全部如实报告）——这种方法论严谨度本身就值得关注；更重要的是它给机制可解释性泼了盆冷水：电路位置相同的两个模型，可操控性可以天差地别。
- **核心方法**：对 6 个 14B–675B 开源模型做**逐层读出**定位错符号的写入位置 → 在残差流上**减去单一"符号方向"**做因果干预、检验能否翻转错误 → 对比随机方向 / 对照层干预是否为零效应 → 全程预注册 pass 标准。
- **主要结果**：① 错符号在**网络最后四分之一的 MLP 层**被晚期写入（各模型 70–100%），Qwen 上该模式在指令微调前的基座模型里就存在；② 机制各异——有的模型有固定"盖负号章"的层，有的放大已选符号，Qwen 还有下游"救援层"对抗盖章层；③ 干预有因果性：在 Llama-3.3-70B 上减去单一符号方向翻转了 14 个留出分部积分错误中的 13 个，且**表征层面有特异性**（同剂量会破坏"本应为负"的正确答案、却不碰"本应为正"的，Llama 上 0/72），随机方向 / 对照层干预为零；④ **反例 Phi-4**：电路同样良好定位在相同晚期深度，同样的干预却几乎翻不动任何东西——符号被**冗余地写在约 15 层**、margin 大数倍（中位 17.8 logits）。
- **值得追问 / 局限**：① "定位≠可操控"提示单方向线性干预对冗余编码的电路无效，但如何**事先判断**一个电路是否可操控（冗余度、margin 的可测代理）尚无操作化判据；② 研究聚焦符号错误这一特定失败模式与数学任务，结论能否外推到其它推理错误类型与非数学领域待验证。
