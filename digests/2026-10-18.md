## A. 核心方法（生成式时序路径预测 / 电网图模型边端蒸馏，取 2 篇）

### 1. PathFM: Fast Generative Forecasting of Multivariate Trajectories
- 链接：https://arxiv.org/abs/2610.22358
- 作者：Jiachen Yao, Xiyuan Zhang, Annan Yu, Boran Han, Abdul Fatir Ansari, Shuai Zhang, Michael Bohlke-Schneider 等（8 位；cs.LG）
- **TL;DR**：主流时间序列基础模型只预测**边际分位数**、不刻画未来各时刻之间的**依赖结构**，对"累计需求、峰值负荷、事件时点"这类**轨迹依赖量**无能为力；PathFM 用**流匹配（flow matching）生成完整的未来路径**，并蒸馏到 1–2 步 + 跨样本共享历史注意力缓存，使"为一条序列生成多条路径"的耗时接近"向分位数模型查询一次"。
- **解决什么问题 / 为什么重要**：命中 A 的**时间序列建模（核心方法）**。它把时间序列基础模型从"逐点/逐分位"范式推向"**对联合分布的路径采样**"——这正是不规则采样、事件时点、长程相关等你关注场景的要害：很多下游量（峰值、累计、首次越限时刻）只有在**路径层面**才有定义，边际预测天然看不见。蒸馏后的快速采样器还让"直接优化校准损失"变得可行。
- **核心方法**：① 以流匹配学习未来轨迹的生成模型，输出完整路径而非边际分位；② 蒸馏到 1–2 步采样、并在多条抽样间**共享历史注意力缓存**，把多路径生成压到接近单次查询的开销；③ 蒸馏采样器使**直接优化校准损失**成为可能；④ 提出 **fps-bench**（在 fev-bench 任务上加 energy / variogram 分数与下游指标）评测路径质量。
- **主要结果**：在 fev-bench、TIME 上边际精度与强基线相当；在 fps-bench 的**聚合路径分数**上高于所有被评外部基线；在混沌系统实验中**长程保持变异性**，而强基线迅速塌缩为近似确定性。
- **值得追问 / 局限**：① "边际精度持平、路径分数更高"说明其价值在**依赖结构与下游轨迹量**，而非单点精度——纯点预测任务是否值得换成生成式采样需按用例权衡；② 流匹配 + 多路径采样即使蒸馏到 1–2 步，相对单次分位查询的真实延迟/显存在超长预测窗与高维多变量下的扩放性，摘要未给端到端数字。

### 2. Physics-Aware Distillation of a Grid Foundation Model for Real-Time Edge Inference
- 链接：https://arxiv.org/abs/2610.21833
- 作者：Vlad Alexandru Sănduleac, Shahariya Rasheed Rayamarakkarveettil Puthanpurayil, Noman Khan, Remus Teodorescu（4 位；cs.LG）
- **TL;DR**：电网基础模型（GridFM）是在**掩码潮流**目标上预训练的**图 Transformer**，比迭代求解器快几个数量级，但体量面向数据中心；本文把 20.1M 参数、12 层的教师蒸馏到 0.62M 参数、6 层的学生（参数缩 32.5×、消息传递深度减半），用"掩码潮流 + 输出 + 物理残差 + 隐状态 + 注意力迁移"的复合目标，目标是在**单个同步相量（PMU）上报帧内、batch=1**做边端推理。
- **解决什么问题 / 为什么重要**：命中 A 的**时空图 / 图 Transformer（GNN）**。它一方面示范了"图基础模型 → 边端小模型"的蒸馏管线，另一方面给出一个对方法学很有价值的**负结果**：在typed 电网图上**新引入的"物理残差迁移项"按本文的层级聚合形式反而稳定有害**，作者归因于它把"母线级残差场"做了空间平均。对任何想把"物理先验/残差"塞进 GNN 蒸馏的人都是直接警示。
- **核心方法**：① 复合蒸馏目标 = 掩码潮流损失 + 输出匹配 + 物理残差匹配 + 隐状态迁移 + 注意力迁移；② 在 IEEE 118 母线可再生变体上（26 台同步机换成带电池灵活性与 IEEE 1547 无功限的逆变器电源，共 97,529 个 AC-OPF 可行场景）评测；③ **消融全部 8 种迁移项组合**，分别报告"对真值的精度"与"对教师的保真度"。
- **主要结果**：蒸馏在四个预测量上都降低学生误差（有功调度最多降 48%），且每个蒸馏学生在无功调度上都比教师更准；**增益主要由输出匹配项贡献**；而**物理残差项（层级聚合形式）一致有害**；学生参数缩 32.5×、消息传递深度减半，是边端部署候选。
- **值得追问 / 局限**：① 只在 IEEE 118 母线单一基准 + 合成可再生场景上验证，跨拓扑/跨规模电网的泛化未知；② "物理残差项有害"是否只是**当前层级聚合实现**的问题（作者已暗示母线级残差场不该空间平均），换成母线级逐点残差能否翻盘，是值得追问的开放点——它关系到"物理先验到底该怎么注入图模型"。

## B. 应用场景（头皮 EEG 想象言语：被试间零迁移 + 检测地板审计，取 2 篇）

### 3. Cross-subject decoding of imagined speech from scalp EEG: a leakage-controlled evaluation on three public corpora
- 链接：https://arxiv.org/abs/2610.20954
- 作者：Blessing Isoyiza Adeika, Onyema Osuagwu（2 位；eess.SP，兼 cs.LG / q-bio.NC）
- **TL;DR**：一个"无需校准即可用于新用户"的想象言语解码器才能让无创语音接口实用；本文在三个公开语料（ds003626、KaraOne、2020 国际 BCI 竞赛 Track 3）上、用**严格防泄漏协议**（精确二项阈值、组检验、bootstrap 置信区间）系统检验**想象言语内容能否跨被试迁移**，并解剖"被试内准确率为何长期偏低"。
- **解决什么问题 / 为什么重要**：直击你的**脑信号解码主线**（头皮 EEG 与 fNIRS 同属无创神经时间序列解码），而且是一篇难得的、**把"泄漏/对照/效应量"做到位的负结果**。它提醒：很多"想象言语解码成功"可能来自评测泄漏或 post-stimulus 状态混入，而非真正解出了想象内容——这对你设计 fNIRS/EEG 解码实验的 split 完整性与对照具有直接借鉴。
- **核心方法**：① 在每位被试上训练、在其他所有被试上测试（482 个有序被试对）；② 不经分类器**直接比较被试间表征几何**；③ 施加被试级对齐；④ 对"被试内天花板"检验五种解释（含试次数、音节计数/频率剖面等）。
- **主要结果**：482 个被试对中**无一对在多重比较校正后存活**，平均跨被试迁移精度在每个语料上都落在距随机 0.006 以内，而被试内参照都在随机之上；"想象 vs 静息"对比虽能到约 0.61，但解码器**把想象前的间隔也同样频繁地标成想象**——说明对比反映的是 post-stimulus 状态而非想象本身；被试内只有竞赛语料对每个被试都显著（0.3147，随机 0.200），且**唯一能排序语料难度的变量是每类试次数**，这favors"做更大的单条件数据集"而非继续堆模型。
- **值得追问 / 局限**：① 结论限于这三个公开语料与所考察的表征，"任何表征下都不迁移"不等于"原理上不可迁移"，更高密度/更干净采集或新范式仍待验证；② "试次数是唯一有效变量"是对当前数据的经验结论，对数据采集优先级是强提示，但不排除更精细的个体化对齐在更大数据下带来迁移。

### 4. How large an effect would we have seen? Positive controls, detection floors and dataset pitfalls in scalp-EEG speech decoding
- 链接：https://arxiv.org/abs/2610.20942
- 作者：Blessing Isoyiza Adeika, Onyema Osuagwu（2 位；eess.SP，兼 q-bio.NC / q-bio.QM）
- **TL;DR**：头皮 EEG 想象言语研究常用"朗读（overt speech）"做阳性对照、报告 null 结果却不说明管线**本可检测到多大的效应**；本文审计三套语料的 overt/发音准备/想象言语解码，**向真实录音注入已知幅度的类相关效应**以测各类解码器的**检测地板**，并核对 ds003626 的标签与采集协议。
- **解决什么问题 / 为什么重要**：与上一篇配套，是**脑信号解码的方法学基础设施**。它把"阴性结果到底说明了什么"从模糊断言变成**可量化的检测地板 + 明确的对照有效性**，并揭露"阳性对照被肌电（myogenic）主导"这一普遍陷阱——对 fNIRS/EEG 解码同样适用：先证明管线能检测到注入效应，再谈"解到/没解到"。
- **核心方法**：① 用伪迹通道子集、带限解码、试次筛选审计三套语料的 overt/articulator/imagined 解码；② **注入已知幅度的类相关效应**，在预先固定的判据下测五类解码器家族的检测地板；③ 核对 ds003626 标签与采集协议一致性。
- **主要结果**：在 ds003626 上，**两个嘴唇电极**把朗读解到 0.7430、八个外部通道 0.7068，而 128 通道头皮montage 只有 0.4231，且 8–30 Hz 带内无可解信号——说明阳性对照**被肌电主导、无法验证解码管线**；另两套语料被试内精度随频率单调升高进入肌电主导频段；带功率 logistic 回归能在预设判据下检出注入的 0.54 µV 8–30 Hz 去同步，而紧凑 CNN（EEGNet）在被试内直到 4.31 µV 都检不到任何东西；ds003626 的条件码还与直觉相反、类编码在不同公开版本间变过、且条件是**会话内时间的确定性函数**（泄漏风险）。
- **值得追问 / 局限**：① 结论基于这三套具体语料与所选解码器家族，"检测地板高"既可能是信号弱也可能是解码器/预处理不当，区分二者仍需更强管线对照；② 其核心贡献是**报告规范**（带限精度、精度随频率方向、实测检测地板），能否被社区采纳、以及在 fNIRS 上的等价"阳性对照陷阱"是什么，值得迁移思考。

## C. Agent / 机制（人类干预作标签定位 agent 失败 / 代码模型句法回路的"局部化"方法学，取 2 篇）

### 5. Human Interventions as Labels: Localizing, Steering, and (Sometimes) Editing the Computations Behind LLM Agent Failures
- 链接：https://arxiv.org/abs/2610.21708
- 作者：Cesare Zavattari, Alessandro Tommasi, Giuseppe Prencipe（3 位；cs.LG，兼 cs.AI / cs.CL）
- **TL;DR**：LLM agent 出错时人类介入纠正，这类干预通常被丢弃或当训练数据回放；本文把**人类干预当作一种"测量"——指向失败内部计算的标签**，在受控 agent 环境里研究一种失败（请求本已明确却仍去追问澄清），用规则监督者（经盲测人工校验）生成标签，在**残差流**里定位、操控、（有时）编辑这一行为，并诚实报告方法的**失效边界**。
- **解决什么问题 / 为什么重要**：正中 C 的**agent 机制分析 + residual stream（优先类）**，而非 prompt 技巧。它提供一条"**从人类纠正反推内部故障计算**"的范式：把运维中廉价、现成的"人类接管"信号转成**因果可定位的方向**，并区分失败的**机制签名**——这对理解和干预 agent 行为远比再贴 prompt 有价值。更可贵的是它在多处**报告失败并停手**而非硬凑规律。
- **核心方法**：① 从干预标签学一个方向，在确定的残差流深度翻转留出集上 72–100% 的"过度追问"（位点与剂量在训练集上选），随机方向在同流程下最多翻转 1 例；② 刻画"过度追问"的两种机制签名：四个模型族中"**模型其实知道请求无歧义**（该信念可解码、但对决策因果惰性且正交），却仍追问"，第五族则由不同世界表征驱动；③ 以探针读出**门控的 steering** 去掉大部分模拟监督负担、同时保住合法提问（bootstrap 95% 区间排除零），而 prompt 指令反而更糟；④ 把修复固化进权重得到"**一张图而非一条规则**"：某模型上限定因果带的 LoRA 通过所有预设判据、而同数据的行为克隆破坏保持，另三族相反，第五族随种子跨界。
- **主要结果**：ask-vs-act 决策在每个合格模型族里都**因果可定位**；探针门控 steering 有效且不误伤合法提问；权重固化的效果**因模型而异、无统一规律**，作者预先写下的几何规则在两个 out-of-family 测试上失败，于是**报告失败并停止**，不去拟合替代规律。
- **值得追问 / 局限**：① 只在一种失败（无谓追问）、小规模受控环境、13 个模型中 5 个合格上成立，能否推广到更复杂的多步 agent 失败（工具误用、规划错误）未知；② "修复固化是一张图不是一条规律"虽诚实，却意味着**没有可跨模型迁移的编辑配方**，实际部署仍需逐模型定位——这对"用干预标签做自动修复"的工程化是真实障碍。

### 6. Causal Syntax Circuits in CodeLMs: Budget and Probe Decide What Looks Localised
- 链接：https://arxiv.org/abs/2610.20683
- 作者：Harsh Kumar, Tanmay Shailesh Joshi, Rahul Maity, Anusa Saha（4 位；cs.LG，兼 cs.SE）
- **TL;DR**：代码模型在不指定语言时倾向写 Python；本文问一个机制问题——这种偏好是否由模型内部一小撮**可定位的组件**产生？用同一条管线（均值消融、激活 patching、贪心回路抽取、随机对照显著性检验、激活 steering）跑遍 **55 个"模型×语言"设置**（10 个开源代码模型、3 种目标语言、2 套 prompt、2 档组件预算），得出**"一个行为看起来是否'局部化'，很大程度上取决于分析预算与探针选择"**的方法学教训。
- **解决什么问题 / 为什么重要**：正中 C 的**机制/现象分析（优先类）**，且是一篇难得的**对机理可解释性自身方法学的审计**。它系统地揭示：很多"我们找到了负责某行为的回路"的结论，可能是**探针与预算的产物**而非模型的真实属性。对任何做 circuit discovery / 内生可解释的人，这是必须内化的 caveat——也直接呼应你对"内生可解释"稳健性的关注。
- **核心方法**：① 单一管线跨 55 设置（5 个 base + 5 个 instruction-tuned 模型，目标语 Rust/C#/PHP，两套 prompt，组件预算 12 与 40）；② 以随机对照 + 多重比较校正判定"回路是否真的打败同规模随机对照"；③ 比较对齐 prompt 与 XLCoST 平行函数两种探针对**同一测量**的影响；④ 用 patching 与 steering 验证干预是否真能改变输出语言。
- **主要结果**：① Python 偏好随模型增大而增强、且**指令微调后更强**（平均比 base 高 12%）；② 其"大小"**主要是探针的属性**——把对齐 prompt 换成 XLCoST 平行函数，同一模型同一测量从约 1.6 掉到约 0.01；③ "是否局部化"**取决于预算**：预算 12 时 15 个设置仅 1 个的回路在校正后胜随机对照，预算 40 时 6 个胜；④ 小预算研究报告为"一律失败"的干预其实有时成功（patching 45 设置中 2 个、steering 9 个改变最可能 next token）；⑤ 凡"显著但指向错误语言"的回路都来自回路抽取失败的设置——是**诊断信号而非现象**。
- **值得追问 / 局限**：① 结论围绕"默认写 Python"这一相对狭窄行为，是否推广到更语义化的代码行为（类型推断、API 选择）未验证；② 它给出的是**强有力的否定性/方法学警示**（局部化主张可被分析选择左右），但没有给出"该用多大预算、哪种探针才算可信"的**正面规范**——如何把这套审计固化成 circuit discovery 的标准报告项，是留给社区的开放问题。
