## A. 核心方法 · 时序预测的反事实重构（全局一致干预 × 自解释/可操作性）

### 1. ConTex: Reformulating Counterfactual Generation For Time Series Forecasting
- 链接：https://arxiv.org/abs/2606.18049
- 作者：Jan Voets, Hasan Tercan, Tobias Meisen, Sebastian Baum
- submit 日期：2026-06-16
- **TL;DR**：把时序预测的反事实生成从"逐实例求解"改写成**学习一套全局一致的干预策略**，按时间相关性与修改强度生成"可操作的"反事实指导，计算成本相比逐实例方法降低至少 12–36 倍，并支持实时推断。
- **解决什么问题 / 为什么重要**：贴你方向 A 的"时序建模 + 内生/可操作可解释"横切点。反事实是比纯 post-hoc 归因更"可执行"的解释形式（"改哪些输入、改多少，预测才会变成期望值"），但传统逐实例优化既慢又前后不一致。ConTex 把干预策略学成全局函数，使解释具有跨样本一致性与实时性——对你关心的"时序模型如何带自解释/可操作结构、而非外挂归因"是直接相关的一块。
- **核心方法**：① 不再对每个实例单独求解反事实，而是学习一个全局一致的干预策略函数；② 显式参数化时间相关性（在哪些时间步干预）与修改强度（改多少）；③ 由此生成可操作的反事实指导，单次前向即可，支持实时。
- **主要结果**：相对逐实例反事实生成，计算成本降低至少 12–36 倍；保持全局一致性的同时支持实时推断（各数据集质量指标见正文）。
- **值得追问 / 局限**：① "全局一致策略"可能牺牲单实例最优性——对分布尾部/罕见模式的反事实是否仍可信，需看；② 干预的"可操作性"是否经过领域/因果约束校验，还是纯数据驱动相关性，决定它能否真用于决策。

## A. 核心方法 · 连续时间动力学模型（边缘稳定性下 GD 的可解析 ODE，横切训练动态）

### 2. Edge Flow: A Tractable and Predictive Continuous-Time Model for Gradient Descent at the Edge of Stability
- 链接：https://arxiv.org/abs/2606.18080
- 作者：Pierre Marion
- submit 日期：2026-06-16
- **TL;DR**：用**三条耦合 ODE**把"边缘稳定性（Edge of Stability）"下的梯度下降建成一个可解析、可预测的连续时间模型，把动力学分解为中心、振荡方向、振荡幅度三部分，能解释 sharpness 在临界点处的振荡起因，且每步只需两次梯度评估 + 一次 Hessian-向量积。
- **解决什么问题 / 为什么重要**：双重相关——既是你方向 A 关心的"**连续时间 / ODE 建模**"，又落在你方向 C 的"**训练动态**"优先项上。EoS 是当前优化理论里最反直觉的现象之一（学习率超出稳定阈值后 sharpness 反而被压住、loss 仍下降），此前多为经验观察；本文给出可积、低成本的连续时间近似，把"中心漂移 / 振荡方向 / 振荡幅度"解耦，是把训练动态做成可解释结构的范例——对你思考"用连续时间/ODE 视角刻画离散迭代过程"有方法论价值。
- **核心方法**：构造三条耦合 ODE 分别描述参数中心、振荡方向、振荡幅度；以此连续时间系统逼近 EoS 区的 GD 轨迹；计算上每步仅需两次梯度 + 一次 Hessian-向量积，保持可处理性。
- **主要结果**：模型解析地再现 sharpness 在 EoS 起点处的振荡，并对动力学有定量预测能力；以极低的二阶信息开销获得可解析性（具体拟合/预测精度见正文）。
- **值得追问 / 局限**：① 三-ODE 近似主要面向 EoS 这一特定相区，离开该区（如自适应优化器、超大 batch）是否仍成立未知；② Hessian-向量积虽便宜，但在超大模型上叠加每步开销是否实用，需看规模实验。

## C. 机制/表征 · 推理轨迹到可复用模块（SFT/RL 角色分工，组合泛化机制，优先型）

### 3. From Reasoning Traces to Reusable Modules: Understanding Compositional Generalization in Language Model Reasoning
- 链接：https://arxiv.org/abs/2606.18089
- 作者：Lingjing Kong, Xin Liu, Guangyi Chen, Martin Q. Ma 等（共 11 位）
- submit 日期：2026-06-16
- **TL;DR**：用一个**层次化潜在选择模型**形式化"组合泛化"，揭示 SFT 与 RL 在推理中扮演**非对称、互补**的角色——SFT 提供"原料模块"，RL 负责把这些轨迹**分解并重组**成可复用的原子模块。
- **解决什么问题 / 为什么重要**：正中你方向 C 最偏好的"**机制/现象分析 + 训练动态**"，且明确不是 prompt 技巧，而是从理论模型角度解释"为什么 SFT+RL 的组合能带来组合泛化"。它把"模型如何从轨迹里抽出可重用推理子例程"落成可分析的潜变量选择过程，并给出 SFT/RL 分工的因果叙事——对你关心的"训练范式如何塑造内部可复用表征/模块化结构"有机制层面的启发。
- **核心方法**：① 提出层次化潜在选择模型，把推理建成"选择并组合原子模块"的潜变量过程；② 在该框架下刻画 SFT（供给原料模块）与 RL（分解 + 重组）的不同作用；③ 实验验证 RL 能从 SFT 生成的轨迹中抽取并重新组合原子模块。
- **主要结果**：SFT 与 RL 角色非对称互补——SFT 供给模块材料、RL 完成分解与重组；实证显示 RL 可从 SFT 轨迹中提取并重组原子模块，支撑组合泛化（定量增益见正文）。
- **值得追问 / 局限**：① "原子模块"是否真有可识别、可解释的内部对应物，还是仅为拟合数据的潜变量构造，需更强的机制证据；② 结论的可迁移性——换任务族/换模型规模时，SFT/RL 的这种分工是否稳定。

## C. 机制/表征 · 为具身智能体记忆定价（记忆机制 × 区制依赖价值，优先型）

### 4. Memory as a Wasting Asset: Pricing Flash Endurance for Embodied Agents, and the Limits of Doing So
- 链接：https://arxiv.org/abs/2606.18144
- 作者：Josef Liyanjun Chen
- submit 日期：2026-06-16
- **TL;DR**：把机器人闪存当成**会折旧的资本**、为其耐久寿命定一个"影子价格"，据此在 RAM/NVM/云的层级间优化"写哪、记什么"；分析发现**"价值-写入"关联高度依赖部署区制**——在长程递归操作里为正，其它区制下可能为零甚至为负。
- **解决什么问题 / 为什么重要**：你方向 C 明确点名的"**memory**"优先项，且是一篇把"记忆该不该写、值不值得记"做成机制/经济学分析的工作，而非堆 memory 模块的工程文。它给出"记忆价值随部署区制变号"这一反直觉现象——即"多记"并非总有益——对你思考"智能体记忆的写入策略、选择性记忆的代价与收益"很有参考（与时序点过程/选择性状态更新的'何时该记住一个事件'在精神上相通）。
- **核心方法**：把闪存耐久建模为带影子价格的折旧资本；以该价格为信号，在 RAM / 非易失存储 / 云的存储层级间做成本最小化的记忆放置；分析"记忆价值-写入行为"关联在不同部署区制下的符号与强度。
- **主要结果**：价值-写入关联在长程递归操作任务上为正，在其它部署区制下为零或负——揭示记忆价值的区制依赖性，并给出成本最小化的放置策略含义。
- **值得追问 / 局限**：① 结论以闪存耐久/成本为核心，能否抽象到通用"软记忆"（上下文/向量库）的写入价值，还需迁移论证；② "区制依赖"的边界如何提前判别——部署前能否预测某任务属于"记忆有正价值"的区制，是实用关键。

## C. 机制/表征 · 灾难性遗忘是低秩的（NTK 函数空间理论 × 谱结构，表征几何）

### 5. Catastrophic Forgetting is Low-Rank: A Function-Space Theory for Continual Adaptation
- 链接：https://arxiv.org/abs/2606.18024
- 作者：Ido Nitzan Hidekel, Dan Raviv
- submit 日期：2026-06-16
- **TL;DR**：在 NTK 区给出"遗忘向量"的**闭式预测**，并证明**遗忘集中在少数旧任务 NTK 特征模态上**（即遗忘是低秩的）；由此指出参数空间正则可能漏掉输出空间的干扰，主张做**有针对性的谱正则**。
- **解决什么问题 / 为什么重要**：方向 C 的"**表征几何 / 内部计算结构**"一类，难得地把持续学习的遗忘现象做成可解析的函数空间理论而非经验缓解。"遗忘是低秩的"是一个干净、可操作的结构性结论——它把"模型忘了什么"定位到少数 NTK 谱模态上，从而解释为何参数空间正则（EWC 一类）会失配（它约束的是参数而非输出函数）。对你关心的"表征/函数几何如何决定知识保持、谱结构作为可解释轴"很贴。
- **核心方法**：① 在 NTK 区推导遗忘向量的闭式表达式；② 证明遗忘能量集中在少量旧任务 NTK 特征模态（低秩）；③ 据此论证参数空间正则的盲区，提出面向输出空间干扰的针对性谱正则方向。
- **主要结果**：遗忘向量有闭式预测且呈低秩（集中于少数 NTK 特征模态）；揭示参数空间正则会遗漏输出空间干扰，指明谱正则的改进路径（实证验证见正文）。
- **值得追问 / 局限**：① 结论建立在 NTK/惰性区，跨到特征学习区（真实大模型微调）后"低秩"是否仍成立，是核心存疑；② "针对性谱正则"是否实际可计算/可扩展（需要旧任务 NTK 谱信息），落地成本待评估。

## B. 应用 · 多源安全日志的 ATT&CK 标注数据集 + 小模型评测（异常/告警/日志分析邻域）

### 6. Multi-Source Cybersecurity Logs: An ATT&CK-Labeled Dataset and SLM Evaluation
- 链接：https://arxiv.org/abs/2606.18190
- 作者：Abir Ashab Niloy, Ahmed Ryan, Imamul Hossain Rafi, Md Erfan, Md Rayhanur Rahman
- submit 日期：2026-06-16
- **TL;DR**：构建一个跨**系统/网络/浏览器**三类日志、来自 870 个会话、带 MITRE ATT&CK 标签的多源数据集；微调小语言模型把日志块分类准确率从基线约 8% 提到 90–97%，但"具体攻击技术识别"仍难（精确匹配仅约 42%）。
- **解决什么问题 / 为什么重要**：当日主类缺生产级 AIOps/RCA 与 fNIRS，这篇是最贴你方向 B "**监控告警 / 日志分析 / 异常识别**"的——它处理的正是多源日志的攻击/异常归因，且把"块级分类（有无可疑）"与"技术级精确识别（具体是什么）"分开评测，暴露出"能发现、难定位"这一与根因定位高度同构的难点。对你关心的"日志/告警驱动的异常检测与根因/技术归因"是直接相关的数据与基线参考。
- **核心方法**：汇集系统、网络、浏览器三类日志（870 会话）并以 MITRE ATT&CK 打标；以微调小语言模型（SLM）做日志块分类与攻击技术识别两级任务，对比基线/微调前后。
- **主要结果**：日志块分类准确率由基线约 8% 提升至 90–97%；但攻击技术的精确匹配识别仅约 42%，表明"检测易、精确归因难"。
- **值得追问 / 局限**：① 42% 的技术识别说明"块级可疑→具体技术"这一步（最接近根因定位的环节）仍是瓶颈，缺多步关联/时序上下文是可能原因；② 数据来自受控会话采集，跨真实生产环境、噪声与对抗规避下的迁移性未验证——离你真正想要的"在线时序异常 + 根因定位"仍有距离，仅作 B 方向占位收录。
