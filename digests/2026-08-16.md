## 1. Represent, Then Generate: Multimodal-Conditioned Time-Series Generation under Irregular Missingness
- **链接**：https://arxiv.org/abs/2608.12592 （arXiv:2608.12592，cs.LG，2026-08-12）
- **作者**：Haochen Zhang, Jiaheng Guo, Yu-Chao Huang, Nicholas Knoz, Tianlong Chen
- **TL;DR**：把「多模态条件的表征」与「目标信号的生成」拆成两段——先给每种条件模态训一个抗缺失的掩码自编码器蒸馏成 token，再用 flow-matching 生成器融合这些 token 与静态协变量，从而在异构、不规则缺失的临床数据里合成缺失/侵入性信号。
- **解决什么问题 / 为什么重要**：连续生理时序是临床监护的基础，但最有信息量的信号常是侵入性、昂贵或干脆缺失的。已有条件生成器多围绕单一条件模态设计，一旦面对「时变信号 + 静态协变量、且不规则缺失」的真实混合就退化。这篇正落在你重点关注的「不规则采样 / 异步时序」与「内生条件表征」交叉点，且给出可直接落地的临床价值。
- **核心方法**：ReCoGen（Represent Conditions, then Generate）两阶段——阶段 I 对每个时变条件模态各训一个掩码自编码器，蒸馏成紧凑、容忍缺失的 token 序列；阶段 II 训一个 flow-matching 生成器，通过「对冻结的逐模态编码器做可学习交叉注意力」融合这些 token，并用「token + AdaLN」双通路注入静态条件来合成目标信号。
- **主要结果**：在三个生理基准（AI-READI 连续血糖、MIMIC-III/IV 动脉血压生成）上，全部 16 个（数据集, 任务, 指标）设置的下游效用均最优，超过六个代表性条件生成器；其中 13 个设置的效用达到或超过「用真实信号测得的效用」这一近似锚点。消融把增益归因到条件通路（冻结编码器上的可学习交叉注意力 + 静态条件的双通路）。
- **值得追问 / 潜在局限**：(1) 「合成信号效用 ≥ 真实信号效用」需谨慎解读，作者自己也把真实效用称作「近似锚点而非上限」，是否有下游任务过拟合到生成分布的风险值得看；(2) flow-matching 生成器对「真正不规则采样的连续时间轴」是显式建模还是靠 token 化吸收，摘要未细说，迁移到更长/更稀疏的异步序列需验证。

## 2. Dual Spatial-Temporal Attribution: Architecture-Aligned Post-Hoc Explainability for Recurrent Graph Anomaly Detection
- **链接**：https://arxiv.org/abs/2608.12441 （arXiv:2608.12441，cs.LG，2026-08-12）
- **作者**：Iyad Assaad Nekka, Hamida Seba, Khaled Walid Hidouci, Karima Amrouche
- **TL;DR**：给动态图边级异常检测的奠基框架 AddGraph（GCN+GRU）配上一套「三个归因分量分别对齐三个架构模块」的解释机制——空间用邻接结构上的梯度相关性、短期时序直接读推理时已算好的注意力权重、长期时序用对循环隐状态的梯度回滚——在完全冻结检测器、AUC 零损失下补齐它此前完全没有的可解释性。
- **解决什么问题 / 为什么重要**：动态图异常检测精度已高但极不透明——边被标记异常时分析员只拿到一个分数、没有理由，这在受监管、需审计的协作信息系统里不可接受。这篇同时踩中你「时空图 / 动态图」核心方法与「监控告警—异常检测 / 可审计」应用两条线；虽属 post-hoc 归因（你会降权），但它「与循环图架构模块一一对齐」的设计比通用归因器更贴机制。
- **核心方法**：X-AddGraph，基于 Dual Spatial-Temporal Attribution（DSTA）——(1) 空间：对当前邻接结构做基于梯度的相关性归因；(2) 短期时序：直接读取推理时已计算的上下文注意力权重，零额外开销；(3) 长期时序：对 GRU 循环隐状态做梯度回滚。检测器冻结，故检测性能被精确保留（ΔAUC=0，实证到小数点后十位）。
- **主要结果**：在 UCI Message 基准上，其复现的 AddGraph 基线平均逐快照 AUC 0.8705，超过原论文；X-AddGraph 在逐位保留所有分数的同时补上解释。在四类边（高置信真阳、低置信真阳、假阳、随机）上评估，长期时序归因识别出的历史快照携带的反事实信号显著高于随机（0.127 vs. 0.074），这是任何「空间盲」解释器都给不出的能力。
- **值得追问 / 潜在局限**：(1) 只在单一基准（UCI Message）+ 单一检测器（AddGraph）上验证，跨其它动态图异常框架与更大规模网络的普适性未知；(2) 反事实信号 0.127 vs 0.074 的绝对差不大，长期归因对分析员真实排障的可用性（能否定位到「根因快照」）还需人评或下游任务证明。

## 3. EEG-PRIME: Prototype-Aligned Representation Learning with Multi-Level Conditioning for EEG Decoding
- **链接**：https://arxiv.org/abs/2608.13072 （arXiv:2608.13072，cs.AI，2026-08-13）
- **作者**：Shuailei Zhang, Muyun Jiang, Wei Zhang, Jinbo Chen, Zhiwei Guo, Yong Li, Yi Ding, Cuntai Guan（含南洋理工 BCI 团队）
- **TL;DR**：EEG 解码模型跨数据集/被试泛化差，本文提出两阶段 EEG 基座——先掩码预训练学可迁移表征，再用「原型对齐的指令微调」把任务语义、数据集、被试不变性三级条件注入，用类别标签的冻结文本嵌入当原型做余弦相似度预测，实现跨异构标签空间的指令化、被试不变解码。
- **解决什么问题 / 为什么重要**：采集协议与个体神经生理差异带来的域漂移，让 EEG 解码难以跨数据集/被试迁移。这篇一头是你关注的「原型 / 概念自解释」内生可解释方向（用原型做预测头），一头是「脑功能 / 神经影像时序」应用（虽是 EEG 非 fNIRS，但跨被试域漂移与多范式统一的思路高度同构），是 A×B 的交叉收录。
- **核心方法**：EEG-PRIME 两阶段——预训练阶段 EEG 编码器通过「带频率截断谱增强的掩码重建」学可迁移表征；指令微调阶段注入任务语义、数据集特定、被试不变三种条件，条件信号经 Layer-wise Query Modulation 调制 Q-Former，而类别标签的冻结文本嵌入充当原型、用余弦相似度在异构标签空间上预测。
- **主要结果**：在 16 个数据集（运动想象、情绪识别、ADHD 检测、隐性言语、心理负荷）上跨被试设置一致超过 SOTA 基线与既有 EEG 基座；在两个额外留出数据集上，无需目标域优化/校准/线性探针即可达到与「会话内校准模型」相当的平衡准确率，展现较强零样本迁移。
- **值得追问 / 潜在局限**：(1) 「原型 = 冻结文本嵌入」提供的是标签语义对齐，是否等价于「概念级自解释」（能否读出每个原型对应的神经生理概念）还需可解释性证据；(2) 跨范式统一靠指令条件，但各范式样本量/难度差异极大，零样本增益在小样本罕见范式（如隐性言语）上的稳健性需看逐数据集拆分。

## 4. Geometric and Behavioral Stratification in Transformer Residual Streams
- **链接**：https://arxiv.org/abs/2608.12447 （arXiv:2608.12447，cs.LG，2026-08-12）
- **作者**：Nelson Guda
- **TL;DR**：以「当前预测 token 的解嵌入方向」为「内容定义的特权锚」，把残差流按「到该预测方向的距离」做分层——发现一个窄、尺度不变的「预测接口」集中了读出相关结构，而随模型放大而膨胀的「预测远端」补集虽每方向弱对齐读出，却在因果与时间上承重，且行为由方向而非幅值驱动。
- **解决什么问题 / 为什么重要**：已知训练后的 transformer 会长出「特权基」，但这种基到底选了什么方向？本文给出的答案——预测方向是不同于坐标轴的特权锚，并据此解释「高维计算如何与线性读出共存」——正是你偏好的「表征几何 / residual stream 结构 / 机制与现象分析」核心问题，且结论在 18 个模型上普适。
- **核心方法**：以预测方向（模型当前所预测 token 的 unembedding 方向）为锚，测量残差流变化相对该锚的几何与行为分层；在 18 个模型（dense 与 MoE、7B–120B、base 与 instruct）上验证。关键观察是预测方向近乎正交于主方差轴，故纯方差分析只能部分恢复该组织、且随 prompt 异质性上升而失真更多；再用「扰动最靠近预测的方差方向 vs 扰动下一层级」的因果实验区分二者作用。
- **主要结果**：分层在全部 18 个模型上成立；预测近端区域高度结构化、把相关 prompt 聚类，补集更平、反而在 prompt 组间「反判别」。扰动最靠近预测的方差方向导致立即发散与频繁「任务框架」漂移；扰动次一级则延迟发散并保留框架。补集每方向弱对齐读出，却在因果与时间上承重；行为由方向而非幅值驱动。预测接口是窄切片但功能上决定性。
- **值得追问 / 潜在局限**：(1) 分析以「当前预测 token 的解嵌入方向」为锚，是逐 token 单方向视角，对多 token/长程规划类计算是否仍是主导锚需验证；(2) 单作者工作、以现象刻画与扰动实验为主，「预测接口」能否转化为可操作的干预/编辑手柄（如更精准的激活引导）是下一步。

## 5. SAEVerbalizer: Generating Explanations for Sparse Autoencoder Features via Representation Verbalization
- **链接**：https://arxiv.org/abs/2608.13538 （arXiv:2608.13538，cs.CL，2026-08-13）
- **作者**：Weihan Meng, Hongzhu Guo, Yi Jing, Dewen Liu, Zijun Yao, Xiaozhi Wang, Lei Hou, Juanzi Li（清华等）
- **TL;DR**：稀疏自编码器（SAE）能从 LLM 表征里抽出大量特征，但解释这些特征此前几乎全靠「外部行为观察」；本文把 SAE 解码方向直接注入模型表征、微调其下游层，训出一个能「直接从解码方向口述特征含义」的 verbalizer，绕开昂贵的行为证据收集。
- **解决什么问题 / 为什么重要**：依赖外部观察的 SAE 特征解释既肤浅又昂贵（需大规模采集行为证据）。这篇属你偏好的「机制可解释 / 表征」类，思路很干净：把「解释特征」从「观察模型行为」变成「让模型口述自己被注入的方向」，是一次范式转换而非增量技巧。
- **核心方法**：SAEVerbalizer 把 SAE 解码方向注入 LLM 表征并微调其下游层，使模型对被注入特征生成自然语言解释；训练后即可仅凭解码方向直接解释 SAE 特征。干预实验：注入多个方向得到含义组合的解释，反转单个方向产生相应含义翻转。
- **主要结果**：学到的口述能力可泛化到未见特征、跨独立训练的 SAE 字典迁移，并通过轻量适配器扩展到不同 LLM 的 SAE 特征；干预实验证实解释与被注入方向的语义因果对应（组合注入→含义组合，反转→含义翻转）。
- **值得追问 / 潜在局限**：(1) 「模型口述的解释」是否忠实于该特征的真实因果作用，仍需与下游行为/激活干预交叉验证，口述可能只反映方向的表层语义而非计算角色；(2) 跨 LLM 迁移依赖轻量适配器，不同规模/架构模型间的解码方向可对齐程度未量化。

## 6. The Impact of Temporal Context Length and Encoding Strategies on Self-Supervised ECG Representation Learning
- **链接**：https://arxiv.org/abs/2608.12695 （arXiv:2608.12695，cs.LG / eess.SP，2026-08-13）
- **作者**：Ahmed Sameh, Ramzi Al-Sharawi, Yogatheesan Varatharajah
- **TL;DR**：一项控制变量实验，系统考察自监督 ECG 表征学习中「输入时间窗长度（16s/1min/5min/10min）」与「前端编码方式（连续卷积 patch 嵌入 vs 固定向量量化 token）」的影响，发现更长上下文 + 连续编码显著更好。
- **解决什么问题 / 为什么重要**：自监督 ECG 模型常只训几秒信号、并越来越多地用离散 token 序列，但这些选择是否牺牲了节律推断与纵向一致性所需的信息一直不清楚。对你的生理时序应用与「时序基座建模」方向，这篇提供的是关于「上下文长度 / 连续 vs 离散编码」的干净证据，与「不规则/长程时序表征」的关切相邻。
- **核心方法**：在 Icentia11k 单导联数据集上做控制实验，仅变化 (i) 输入窗长（16s、1min、5min、10min）与 (ii) 前端表征（连续卷积 patch 嵌入 vs 固定向量量化 token），保持 Transformer 主干与训练协议不变；用下游异常节律检测与「患者级检索」（探测跨会话稳定性）评估表征。
- **主要结果**：把时间上下文从 16 秒延长能带来更强迁移与更高检索准确率，5 分钟与 10 分钟模型最优，说明更好地捕获了慢变节律动态与个体特异结构；在所有窗长下，连续 patch 嵌入均优于离散 token，提示量化会丢弃临床相关的波形细节。作者据此主张 ECG 基座应强调「更长上下文 + 连续编码器」。代码与预训练模型已开源。
- **值得追问 / 潜在局限**：(1) 结论基于单一数据集（Icentia11k）与单导联，多导联/多病种下「长上下文 > 短」是否仍成立、以及算力代价的性价比需评估；(2) 「连续优于离散」与近期时序基座偏爱 token 化的趋势相左，是否因量化码本/训练目标未充分调优所致，值得对更强的 VQ 方案再比。
