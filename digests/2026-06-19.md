## A. 核心方法 · 轻量时序异常检测（多尺度编码 × 跨变量注意力，A 时序 × B 监控双归口）

### 1. PaAno+: Multiscale Encoding and Cross-Variable Attention for Time Series Anomaly Detection
- 链接：https://arxiv.org/abs/2606.20055
- 作者：Youji Zhu, Hongbing Wang, Wenchao Liu, Xiaodong Liu, Xiangguang Xiong
- submit 日期：2026-06-18
- **TL;DR**：在 patch 表示学习范式下做一个**轻量**时序异常检测器——多尺度卷积主干抓分层时间特征、跨变量融合注意力显式建模多变量相关性，再加一个"patch 窗口排序"自监督预训练任务 + 三元组损失优化嵌入空间；在 TSB-AD 上单/多变量均刷到 SOTA，且算力开销小、可上资源受限终端做实时推断。
- **解决什么问题 / 为什么重要**：同时压住你方向 A（时序建模）和 B（监控/异常）的交点。当前 Transformer/大模型路线的异常检测算力太重，轻量替代又卡在"特征提取不足 + 多变量依赖建模差"两处。PaAno+ 用差异化感受野的卷积 + 跨尺度自适应注意力聚合解决前者、用跨变量融合注意力解决后者，并以"时间 patch 窗口排序"这一自监督 pretext 任务挖时序内在结构——对你关心的"在线/边缘部署的时序异常检测基线"是直接可用的参考。
- **核心方法**：① 编码器用差异化感受野卷积建多尺度主干，跨尺度自适应注意力聚合 + 残差稳定特征；② 嵌入跨变量融合注意力显式刻画变量间相关；③ 自监督预训练任务为"时间 patch 窗口排序"，配三元组损失优化 patch 嵌入判别性。
- **主要结果**：TSB-AD 基准上单变量与多变量任务均达 SOTA，VUS-PR 等指标相对原版（PaAno）有显著增益；紧凑网络设计带来良好计算效率，支持资源受限终端的实时异常推断。
- **值得追问 / 局限**：① "patch 窗口排序"自监督是否对非平稳/概念漂移场景仍稳健（与今日另一篇概念漂移检测可对读），需看在线设置；② SOTA 主要在 TSB-AD 离线基准，缺真实生产流的延迟/告警风暴/根因定位环节——离你想要的"在线时序异常 + RCA"仍隔一层。

## A. 核心方法 · 隐式思维链的信息论分析（互信息/信息瓶颈横切 × 隐空间表征漂移）

### 2. What Makes Effective Supervision in Latent Chain-of-Thought: An Information-Theoretic Analysis
- 链接：https://arxiv.org/abs/2606.20075
- 作者：Xinghao Chen, Chak Tou Leong, Wenjin Guo, Jian Wang, Wenjie Li, Xiaoyu Shen（共 6 位）
- submit 日期：2026-06-18
- **TL;DR**：从**信息论**视角剖析隐式思维链（在连续隐状态里推理）为何难训：把失败归因为"**双重塌缩**"——优化路径上的梯度衰减 + 隐空间表征漂移；进而把过程监督拆成"轨迹监督（注入逐步密集信号）"与"空间监督（保住隐流形语义结构）"，并用一个统一隐空间探针（ULP）度量隐轨迹与显式推理步之间的互信息，发现"信息-性能绑定"：推理准确率取决于隐链里保留的信息保真度。
- **解决什么问题 / 为什么重要**：贴你方向 A 的"**信息瓶颈/自解释横切**"，也落在 C 的"机制/表征"上。它给出一个干净论断——"**别做刚性几何压缩，要做互信息最大化**"：刚性几何压缩会把推理空间压塌，生成式重构反而是更灵活的语义锚。对你思考"内生可解释/隐表征该用什么目标来约束（信息瓶颈 vs 几何对齐）"有方法论价值，且把"表征漂移"这一表征几何问题量化成可测的互信息指标。
- **核心方法**：① 信息论框架把隐式 CoT 失败拆为梯度衰减 + 表征漂移；② 过程监督分解为轨迹监督（密集步级信号）与空间监督（保隐流形语义）；③ 提出统一隐空间探针 ULP，量化隐轨迹与显式推理步的互信息，验证"信息保真↔推理准确"的绑定关系。
- **值得追问 / 局限**：① 结论建立在"互信息可由 ULP 较好估计"上，互信息估计本身在高维隐空间偏差大，指标可靠性需更多对照；② "生成式重构优于几何压缩"是否随模型规模/任务族稳定，还是依赖具体重构器设计。

## B. 应用 · ICU 脑电突发-抑制检测的 EEG 基础模型评测（脑功能时序/床旁监控，最贴 fNIRS 方向）

### 3. Evaluation of EEG Foundation Models for Event-Based Burst-Suppression Detection in ICU
- 链接：https://arxiv.org/abs/2606.20074
- 作者：Elisa Vasta, Thorir Mar Ingolfsson, Andrea Cossettini, Luca Benini, Tilman Beck, Emanuela Keller（共 7 位）
- submit 日期：2026-06-18
- **TL;DR**：首次系统评测 **EEG 基础模型**在 ICU 减少导联脑电上的"突发-抑制（burst suppression）"检测，且**无需病人特异性标定**；最佳模型 REVE-base 取得事件级 F1 0.868，相对 EEGNet/自适应阈值把"每分钟 burst 计数误差"分别降 52.1%/36.2%；并用"事件级（episode）"而非纯窗口分类来贴临床真实判读。
- **解决什么问题 / 为什么重要**：今日最接近你方向 B "**脑功能时序 / 神经成像时间序列 / 床旁监控**"的工作——虽是 EEG 而非 fNIRS，但同属"脑功能电生理时序 + 临床监控"，方法学高度相通（基础模型预训练 → 小标注下游迁移、窗口级 vs 事件级评测、减少导联部署）。它给出一个对你直接有用的结论：**标注极稀缺时，预训练 FM 表征价值巨大**——在 25% 队列规模下 REVE-base 比随机初始化高出 +0.723 事件级 F1。对你做 fNIRS/脑网络时序的"小样本 + 基础模型迁移"路线是强参考。
- **核心方法**：① 对比 REVE-base / LUNA-large / LuMamba-Tiny 三个 EEG FM 与自适应阈值、EEGNet 两条基线；② 在减少导联 ICU 脑电、无病人特异标定条件下做 burst 检测；③ 引入事件级（burst episode）评测以降低标注变异影响；④ 系统比较全量微调 / 冻结主干 / 两步微调 / LoRA 等适配策略。
- **主要结果**：REVE-base 事件级 F1 最高（0.868±0.167），每分钟 burst 误差较 EEGNet/自适应阈值降 52.1%/36.2%；**全量微调最有效**（较冻结主干，LUNA-large 事件级 F1 提升达 +0.102），LoRA/两步微调次之；低标注下预训练优势极显著（25% 队列 +0.723）。
- **值得追问 / 局限**：① 全量微调最优意味着算力/部署成本不低，床旁/可穿戴端能否承受未验证；② burst suppression 是相对结构化的 EEG 模式，迁移到更细的脑功能连接/fNIRS 血氧动态时序时，FM 表征是否仍占优需另证。

## C. 机制/表征 · 单神经元操控的"控制窗口定律"（残差流几何 × 可控性分型，优先型）

### 4. Leverage Is Not Reach: A Control-Window Law for Single-Neuron Steering in Language Models
- 链接：https://arxiv.org/abs/2606.19831
- 作者：Hongliang Liu
- submit 日期：2026-06-18
- **TL;DR**：给"单神经元操控何时能**连贯**地控住一个行为、何时会让输出塌掉"建一个**预算归一化的控制窗口**理论：沿某写方向的剂量被约化成一个控制坐标（残差流与写方向的对齐度），沿一条普适饱和曲线演化，单位是由"残差范数/写范数"定的相干预算；当行为触发点落在塌缩天花板之下时存在连贯控制——天花板可由权重 + 一次前向算出，触发点在 rollout 时测得。
- **解决什么问题 / 为什么重要**：正中你方向 C 最偏好的"**残差流/结构、表征几何、机制分析**"。它解释了一个反直觉现象——**局部梯度归因会"反向预测"可控性**：真正的控制器写在读出轴之外、一阶梯度近零，所以归因看不见它；作者用"前向-only 对比筛查"把归因漏掉的控制器找回来。更关键是把"干预成功"从标量改成**分型**：refusal 上"连贯绕过"与"严格可执行触达"分离——一个神经元可以在流畅、切题但无可执行内容的文本里翻转拒绝，而真正的"可执行触达"只在 6 个被审计 Llama 枢纽中的 3 个、且只在较晚 rollout 时段出现。对你思考"内部计算的可控轴、残差几何如何决定可解释/可操控性"极有启发。
- **核心方法**：① 预算归一化控制窗口框架，把单神经元剂量约化为单一控制坐标（残差-写对齐），沿普适饱和曲线演化；② 由权重 + 一次前向算"塌缩天花板"，rollout 测触发点判连贯控制是否存在；③ 前向 contrastive 筛查替代梯度归因定位真控制器；④ 把可控性分型（连贯绕过 vs 可执行触达）。
- **主要结果**：15 个留出神经元上，天花板预测平均绝对误差 0.14（主体层约 0.07），开/闭判定 11/15 命中（多数基线 10/15）；闭合案例归为三类失败模式（触发前塌缩 / 深度不足 / 归一化封顶），而非定律违例。
- **值得追问 / 局限**：① 理论以"单写方向 + 单控制坐标"为核心，多神经元/多方向叠加时（与今日 GEMS 的"多语义叠加"问题相关）是否仍可解析未知；② 验证集中在 refusal/语言路由等稀疏 FFN 门控行为与少数模型，跨更分布式编码的行为是否成立待证。

## C. 机制/表征 · 能力溯源（训练数据归因定位"社会推理 vs STEM 推理"来自语料何处，优先型）

### 5. Where Does Social Reasoning Come From? Capability Provenance in Language Models
- 链接：https://arxiv.org/abs/2606.19625
- 作者：Glenn Matlin, Chandreyi Chakraborty, Saehee Eom, Mika Okamoto, Rayan Castilla, Louis Jaburi（共 11 位）
- submit 日期：2026-06-17
- **TL;DR**：把**训练数据归因**当成"能力发现"的可解释工具，在 OLMo3-7B 上回答"模型的社会推理 vs STEM 推理分别来自预训练语料的哪些区域"；用梯度归因（TrackStar/Bergson）在 WebOrganizer 的 24 格式×24 主题（576 桶）上聚合影响，发现**社会推理与 STEM 推理来自语料中性质迥异的区域，且这种区分在"推理"层比"知识"层更锐利**；定向 unlearning 给出部分因果验证（遗忘高归因主题桶会更多损害对应基准）。
- **解决什么问题 / 为什么重要**：你方向 C 的"**机制/现象分析 + 训练**"优先项，且明确不是 prompt 技巧，而是用训练数据归因这一工具把"某能力源自语料何处"做成可测、可因果验证的问题。难点在于文档级归因分数太噪、且以往多关注事实知识而非推理——本文用"格式×主题"分桶聚合压噪、用 2×2 设计（领域 social/STEM × 类型 reasoning/knowledge）对比，把"能力来源"定位到语料区域级。对你关心的"训练语料结构如何塑造模型内部能力/表征、用归因做机制定位"很贴。
- **核心方法**：① 在去重 Dolma3 工作集上算梯度归因（TrackStar via Bergson）；② 按 WebOrganizer 576 桶（24 格式×24 主题）聚合影响矩阵；③ 2×2 对比 SocialIQA/MMLU-Social vs ARC-Challenge/MMLU-STEM，分离领域与能力类型；④ 定向机器遗忘（forget 高归因桶，如 SocialIQA 的"文学"桶）做因果验证。
- **主要结果**：社会推理与 STEM 推理来自语料中性质不同的区域，且在推理层的对比比知识层更尖锐；遗忘高归因主题桶比桶内随机基线更显著降低对齐基准；全套代码、采样清单、桶级影响矩阵、unlearning 检查点已开源。
- **值得追问 / 局限**：① 归因到"格式×主题桶"是相关性强、因果偏弱的定位，unlearning 仅"部分因果验证"，桶粒度可能掩盖更细的因果单元；② 结论基于 OLMo3-7B + Dolma3 单一模型/语料，跨模型族与跨语料的可迁移性未验证。

## C. 机制/记忆 · 多智能体可迁移记忆（群体级轨迹存取，memory 优先项）

### 6. Multi-Agent Transactive Memory
- 链接：https://arxiv.org/abs/2606.19911
- 作者：To Eun Kim, Xuhong He, Dishank Jain, Ambuj Agrawal, Negar Arabzadeh, Fernando Diaz
- submit 日期：2026-06-18
- **TL;DR**：把检索增强从"检索人类写的资料给单个 agent"推广到"**检索 agent 自己产生的轨迹给一群 agent 复用**"：提出 MATM 框架——生产者 agent 把交互轨迹贡献到共享库，消费者 agent 检索这些轨迹来改进任务执行；在 ALFWorld / WebArena 上无需协调或联合训练即可提升下游表现并减少交互步数。
- **解决什么问题 / 为什么重要**：你方向 C 明确点名的"**memory**"优先项，且切的是一个真问题——agent 轨迹里编码了可复用的程序性知识，但通常用完即弃或只留给生产者自己，导致新实例反复重新发现已有解。MATM 把"群体级经验共享"做成一个检索设计模式（agent 生成物的"搜索引擎"）。对你思考"智能体记忆的写入/复用、把轨迹当可检索经验、跨 agent 群体的记忆组织"有参考，与时序点过程/选择性记忆里"何时该记住并复用一段经历"精神相通。
- **核心方法**：① 共享库存储 agent 生成的交互轨迹（生产者贡献、消费者检索）；② 聚焦轨迹长、程序性结构丰富的交互环境（ALFWorld、WebArena）；③ 检索复用轨迹改进任务执行，无需 agent 间协调或联合训练。
- **主要结果**：从 MATM 检索轨迹可提升下游任务表现并减少交互步数（无需协调/联合训练），定位为开放 agent 生态里"群体级经验共享"的设计模式。
- **值得追问 / 局限**：① 偏"基础设施/设计模式"工程，缺对"何时该写入、轨迹质量/陈旧/冲突如何治理"的机制分析——与今日"灾难性遗忘/记忆定价"类机制工作相比理论深度较浅；② 共享轨迹的可迁移性与污染风险（错误/过时轨迹被群体复用放大）未充分评估。
