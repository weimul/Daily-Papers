## A. 核心方法（图链接预测 / 时序基座模型注意力理论，取 2 篇；本窗 A 方向偏薄）

### 1. Bridging Semantics and Structure: A Theoretically Grounded Framework for Link Prediction on TAGs
- 链接：https://arxiv.org/abs/2610.40192
- 作者：Chen Shao, Ruirui Wang, Tobias Käfer, Danai Koutra（4 位；cs.AI）
- **TL;DR**：文本属性图（TAG）上的链接预测既要用 GNN 的结构信号、又要用语言模型（LM）的语义信号，但两者归纳偏置迥异、最优融合方式悬而未决；本文提出 **Bridge-LP**——一个简单、高效、有理论支撑的跨模态统一框架，用三个可证明的设计把图与语言表征对齐。
- **解决什么问题 / 为什么重要**：命中 A 的**图方向**。它把"GNN×LM 怎么融合"从工程试错重新拉回到可论证的设计原则：三个组件各有理论动机——(D1) 文本邻近的 jumping connection 稳住 LM 训练，(D2) 压缩嵌入把经典链接预测启发式长期利用的邻域信息以可学习方式编码进来，(D3) 缓存嵌入训练策略降复杂度、让框架能 scale 到大图。对"结构信号与语义信号如何在一个端到端框架里互补"给出了干净的方法论样本。
- **核心方法**：D1 文本邻近跳接（鲁棒 LM 训练）＋ D2 压缩邻域嵌入（把结构启发式学进来）＋ D3 缓存嵌入训练（降算力），三者组成端到端跨模态框架。
- **主要结果**：在 9 个数据集上对比 40 个现有模型，Bridge-LP 一致超过 SOTA，MRR（平均倒数排名）最高提升 **43.06%**，刷新语言-图融合基准。
- **值得追问 / 局限**：① 当前针对静态 TAG 的链接预测，若迁移到时序/动态图（边随时间演化）这三个设计是否仍成立、压缩邻域嵌入如何纳入时间信息，值得追问；② "理论支撑"的三个组件各自增益需更细的消融来区分，43% 的大幅提升有多少来自 D2 的结构启发式、有多少来自 LM 本身，尚待拆解。

### 2. Understanding axial attention in TSFMs through single location regression
- 链接：https://arxiv.org/abs/2610.40188
- 作者：Andrei-Tiberiu Pantea, Aymeric Dieuleveut（2 位；cs.AI / cs.LG / stat.ML）
- **TL;DR**：时间序列基座模型（TSFM）越来越依赖**轴向注意力**（沿时间轴与变量轴分别做注意力），但其理论性质几乎空白；本文把"单点回归"分析框架扩到 2D 结构数据，构造一个可解析的轴向注意力预测器，严格刻画其统计性质与训练动态。
- **解决什么问题 / 为什么重要**：命中 A 的**时序方法**，且是少见的、对 TSFM 架构做可证明分析的理论工作。它处理"目标只依赖少数 token 的稀疏信息"这一时序建模常见情形，回答了两个基础问题：轴向注意力里的**内层非线性是否必要**、以及**梯度下降能否收敛到最优**——对"为什么轴向注意力有效、该怎么调"从理论上给出依据，而非仅靠经验。
- **核心方法**：将 Marion et al. (2025) 的单点回归框架扩展到二维结构数据 → 构造可解析的轴向注意力型预测器 → 在特定渐近机制下分析其统计性质与训练动态 → 对投影梯度下降（PGD）的收敛性做证明。
- **主要结果**：在特定渐近机制且已知 oracle 参数时，该预测器达到**贝叶斯最优**，而一类半线性简化版**严格达不到**（凸显内层非线性的作用）；在特定温度缩放下 PGD **全局收敛**到最优 oracle 参数；数值实验验证理论，并凸显**逆温度调度**对经验收敛的关键作用。
- **值得追问 / 局限**：① 结论建立在"已知 oracle 参数 + 特定渐近机制 + 单点稀疏依赖"的理想设定上，真实 TSFM 的多点依赖、深层堆叠、跨变量耦合下能外推多少，待验证；② 逆温度调度被证关键，但如何在实际预训练里自动设定、与数据统计的关系，论文未给出可操作方案。

## B. 应用场景（LLM–人脑对齐的低维几何 / 脑对齐预测编码，取 2 篇；均带表征几何）

### 3. A Low-Rank Space Captures Linear Alignment Between LLM and Human Neural Activity During Naturalistic Language Listening
- 链接：https://arxiv.org/abs/2610.40511
- 作者：Zach Paris, Emily Finn（2 位；cs.CL / q-bio.NC）
- **TL;DR**：LLM 常被当作人类语言处理的计算模型，但"表征的哪一部分真正驱动了与大脑的对齐"始终不清楚；本文用**降秩岭回归**找出 LLM 表征中可线性预测神经活动的"脑可预测子空间"，发现它只占原嵌入维度的 **1–3%**。
- **解决什么问题 / 为什么重要**：同时命中 B（**neuroimaging 时序 / 脑功能**：颅内电生理 + fMRI 自然聆听）与 C 的**表征几何**。它把"LLM-脑对齐"从一个黑箱相关性拆成可定位的结构问题：脑可预测方向只落在一个**紧凑、跨被试（部分跨数据集）可泛化**的低维子空间里，且这些方向与 PCA 主成分（表征自身方差最大的方向）**明显不同**——即"最能预测大脑的方向"并非"LLM 内部变化最大的方向"。这对"用 LLM 当脑模型时到底该看哪部分表征"给出了方法与证据。
- **核心方法**：用 ridge 降秩回归求解脑可预测子空间 → 在 3 个自然语言聆听数据集（颅内电生理 + fMRI）、6 种模型条件（自回归 / 双向掩码 / 随机初始化）上评估 → 与 PCA 主轴对比 → 刻画子空间以浮现"在神经活动中被过度表征"的可解释特征。
- **主要结果**：仅用 **1–3%** 的嵌入维度即可恢复全量线性编码性能；该低维子空间**跨留出被试泛化**、跨数据集泛化稍弱；PCA 需多得多的维度才能恢复同等神经预测，证明脑可预测方向 ≠ 方差主方向；并能借此surface出在神经活动中被过度表征的可解释特征（已开源代码）。
- **值得追问 / 局限**：① 全程基于**线性**对齐（线性编码 + 线性子空间），脑-模型关系中的非线性成分是否也集中于低维，无法由此判断；② 跨数据集泛化明显弱于跨被试，提示该子空间部分依赖具体数据集/刺激，普适性需更多模态与语言验证。

### 4. Local learning is all you need: brain-aligned predictive coding networks
- 链接：https://arxiv.org/abs/2610.37327
- 作者：Dirk Gütlin, Ryszard Auksztulewicz, Adrien Doerig（3 位；q-bio.NC）
- **TL;DR**：预测编码（PC）用分层、局部、自监督的"预测误差"学习解释大脑表征如何涌现，无需全局误差反传，但历来 PC 模型在性能与脑对齐上都追不上主流深网；本文提出**预测脑网络（PBN）**，一个实现局部 PC 学习的分层循环框架，首次把脑对齐做到追平甚至超越主流视觉模型。
- **解决什么问题 / 为什么重要**：命中 B 的**脑功能 / brain network**，并对"生物可信学习机制能否兼得表征能力"这一横跨计算神经科学与深度学习的老问题给出正面答案。关键点在于它用的是**局部学习**（无全局反传），却能复现 PC 的核心特征（高层预测塑造低层视觉响应，与灵长类皮层一致），还支持不确定性估计——对"不依赖反向传播的脑启发学习"提供了可扩展的研究载体。
- **核心方法**：构建分层循环框架 PBN，实现局部 PC 式学习 → 与人类腹侧视觉流做表征对齐 → 分析自上而下预测所编码的、自下而上特征提取未捕获的脑对齐信息 → 在下游分类、PC 特征复现、不确定性估计上评估。
- **主要结果**：PBN 与腹侧视觉流的表征对齐**追平或超过**既有视觉模型；自上而下预测编码了独特的脑对齐信息，且在局部训练变体中贡献更大；在下游分类上**大幅超过**已有 PC 启发网络，并复现"高层预测塑造低层响应"的 PC 特征、支持不确定性估计。
- **值得追问 / 局限**：① 验证集中在视觉（腹侧流）领域，局部 PC 学习能否迁移到语言/时序等其他模态与脑区，尚待检验；② "追平/超越主流视觉模型"的对齐度量依赖所选 benchmark 与对照模型，局部学习相对反传在更大规模/更难任务上的可扩展性需进一步压测。

## C. 机制 / 表征分析（高优先级，取 2 篇，均为机制分析）

### 5. Your LR Schedule May Not Be Principled: Effective Learning Rate Scheduling in Weight-Normalized Training
- 链接：https://arxiv.org/abs/2610.40362
- 作者：Qifan Yu, Xinyu Ma, Xingyan Bin, Di He（4 位；cs.LG）
- **TL;DR**：权重归一化（WN）训练近来被报告在预训练损失上明显优于传统权重衰减（WD），本文证明这些收益**主要来自它诱导的有效学习率（ELR）轨迹**、而非归一化本身——匹配 ELR 轨迹后 WN 与 WD 的训练损失动态基本重合；据此提出按 ELR 设计的 AIR 调度。
- **解决什么问题 / 为什么重要**：强命中 C 的**训练动态**，是干净的机制澄清 + 可操作方法。它把"WN 为什么更好"从"归一化魔法"归因到一个可量化的调度对象（ELR），进而指出**调度设计应瞄准 ELR 而非名义学习率**，并识别出**后期 ELR 调度**是收益的关键来源（共享的后期调度会削弱早期 LR 选择的影响）——这对大规模预训练的学习率设计是直接可用的原则。
- **核心方法**：证明 WN 收益由诱导的 ELR 轨迹驱动、匹配 ELR 即可令 WN/WD 动态重合 → 提出 **AIR（Affine Inverse-square-Root decay）**：理论导出的 1/√t 衰减 + 仿射调整以满足有限训练步内的峰值/终值 LR → 指出后期 ELR 调度为增益关键。
- **主要结果**：在 128B-token 的 MoE 预训练上，AIR 在训练损失、下游性能、超参鲁棒性上均优于 cosine 等候选，在累计 LR 匹配下相对 cosine **把终端训练损失降低约 0.01**；把同一 ELR 轨迹施加到 WD 可复现对应训练动态，确立 ELR 为"有原则的"调度对象。
- **值得追问 / 局限**：① 实验集中在 MoE 预训练与特定 token 规模，ELR 原则在稠密模型、不同优化器/批大小下的普适性需更多验证；② "降低约 0.01 终端损失"的实际下游收益幅度，以及 ELR 视角与既有 μP/学习率缩放律的关系，值得进一步对照。

### 6. Interventional Training Reduces Causal Bypass in In-Context Introspection
- 链接：https://arxiv.org/abs/2610.38911
- 作者：Zilu Tang, Jongin Kim, Kerem Sahin, David Atkinson, Aaron Mueller, Derry Wijaya（6 位；cs.CL）
- **TL;DR**：语言模型"自省"（读取并推理自身内部信号）被认为对自洽与可扩展可解释性很关键，SFT 也被认为能增强它；但本文发现朴素 SFT 会导致**因果旁路**——自我报告依赖的是与报告对象相关、却因果无关的信号；他们提出**反事实干预训练**来修复。
- **解决什么问题 / 为什么重要**：强命中 C 的**机制可解释性**。它点出内省研究的一个根本陷阱：模型看似能报告自身状态，实则可能走旁路（蹭相关信号）。通过在可精确干预的**低层信号（如单个神经元激活）**上做实验，他们把"内省是否因果锚定"变成可检验、可训练的问题——结论是"因果锚定的内省可能、但不被保证，必须训练在机制上而非行为上"，对如何构建可信的内省/自解释系统给出方法论警示。
- **核心方法**：在 3 类低层信号、8 个 LM 上训练数百个"内省器" → 诊断朴素 SFT 产生的因果旁路 → 提出**反事实干预训练**：让模型报告"被反事实扰动后的值"，而非仅拟合行为 → 在内生信号与注入信号、分布内外（OOD）上评估。
- **主要结果**：朴素 SFT 导致因果旁路；反事实干预训练在内生与注入信号上都让内省更准确，**尤其在 OOD 数据上**；该机制跨 token 位置泛化、并随数据量 scale——表明因果锚定的内省可实现但需显式训练在机制上。
- **值得追问 / 局限**：① 聚焦可精确干预的**低层信号**（单神经元等），能否上升到高层概念的内省（难以干预）仍是开放问题，作者将其定位为"最小前提"；② "报告反事实扰动值"的训练范式对真实部署中不可枚举的扰动空间如何泛化、是否引入新偏置，待进一步考察。
