## A. 核心方法（异步/缺失传感的稀疏感知 / GNN 解释保真度，取 2 篇）

### 1. Fault-tolerant shallow recurrent decoders for sparse sensing with missing sensor measurements
- 链接：https://arxiv.org/abs/2611.04893
- 作者：Matteo Romilio Pasqual, Matteo Tomasetto, J. Nathan Kutz, Andrea Manzoni（cs.LG / cs.AI）
- **TL;DR**：真实传感系统里传感器会失效、间歇掉线、采样率异步、带噪，导致测量流**不规则、不完整、异构**；而主流实时状态重构方法却默认传感器同步且持续在线。本文在**浅层循环解码器（SHRED）**上引入容错稀疏感知策略，用一个二值"数据可用性掩码"让模型显式感知"此刻哪些传感器在线"。
- **解决什么问题 / 为什么重要**：**正中 A 的"不规则采样 / 异步时间序列"**这一核心方向，且不是玩具设定，而是把"传感器随时可能缺失/异步"当成一等建模对象。相比把缺失当作预处理问题（先插值再重构），它把可用性信息直接喂进时序编码器，并提出四种基于 transformer 的掩码机制，使高维状态估计在稀疏、异步、缺失测量下仍可实时进行——对任何"从少量不可靠传感器反推全场"的时空重构任务（流体、海洋、监测网）都有直接借鉴。
- **核心方法**：对比三类策略——朴素插值、容错循环时间编码器、以及四种让 SHRED 通过二值可用性掩码感知传感器在线状态的 transformer 掩码机制 → 另引入**多步解码训练目标**，使潜在轨迹更平滑、预测在异构缺失模式下更鲁棒 → 在合成基准与三个真实问题（水动力/海洋建模）上评测。
- **主要结果**：① transformer 掩码机制优于标准插值与容错循环架构；② 多步解码目标在异构缺失下提升重构保真度与鲁棒性；③ 保持 SHRED 的计算效率，推理阶段**无额外开销**。
- **值得追问 / 局限**：① 评测集中在流体/海洋等具强物理结构的高维场，掩码机制对"缺失与信号相关（非随机缺失 / MNAR）"或传感器系统性偏置的鲁棒性未充分展开；② 多步解码目标的步长、以及"可用性掩码"在极端稀疏（在线传感器极少）时是否仍能支撑稳定重构，值得压力测试。

### 2. What Does It Mean to Remove an Edge? Intervention-Aware Fidelity for Graph Neural Network Explanations
- 链接：https://arxiv.org/abs/2611.04751
- 作者：Rocco Mattia Di Mauro, Marco Grassia, Giuseppe Mangioni（cs.LG）
- **TL;DR**：GNN 解释常用"**删除保真度**"评估：删掉排名靠前的边、看输出变化多大。但在消息传递 GNN 里，"删一条边"并不唯一——**结构删除**（把边移出图、重算度归一化与注意力）与**消息抑制**（保留结构、只屏蔽该边携带的消息）是两种不同干预。本文把这一区分**形式化**，并给出两者精确等价的充分条件。
- **解决什么问题 / 为什么重要**：命中 A 的 **GNN + 内生/可解释横切**。它指出一个被长期含糊对待的方法论漏洞：**保真度不是边排名本身的属性，而取决于评估时用的干预语义**。论文证明在"加性消息传递 + 系数与边集无关"时两种干预重合，但当聚合依赖零消息的存在、或删边改变了对存活消息的系数时就会分叉——这对"用保真度比较解释器"的整条评测范式提出了可证伪的修正。（注：本文属解释评估/post-hoc 范畴，按研究口径已降权，但因其把干预语义做成可证明的形式化结果而非又一个归因分数，故作为方法论收录。）
- **核心方法**：形式化"结构删除 vs 消息抑制"两种干预并推导等价充分条件 → 构造**干预专属的边归因**，在两种干预下分别评估各自排名 → 在 9 个数据集、GIN/GCN/GATv2、深度 2–5 的面板上检验"相对保真度是否随评估干预而变"。
- **主要结果**：9 个 GIN 对照全部满足理论预测的等价；在目标 logit 上，GCN/GATv2 的 11 个可报告单元里有 **10 个**的相对保真度依赖于评估干预，其中 9 个里"每个排名在它自己所依据的干预下删除面积更大"——即排名好坏会被评估口径反转。作者据此建议评测协议必须显式报告"干预 / 输出泛函 / 目标 / 扰动单元"。
- **值得追问 / 局限**：① 结论是"评测口径敏感"的负面/规范性结果，本身不提供更好的解释器，对下游"到底该信哪种干预"仍需按科学问题具体定夺；② 实验限于节点/图分类的几类标准数据集与三种骨干，对异质图、时序图或更深网络上两种干预的分叉程度尚无刻画。

## B. 应用场景（边缘时序异常检测 / 多模态神经记录动力学，取 2 篇）

### 3. Anomaly Detection on Resource-Constrained Devices with Reservoir Computing
- 链接：https://arxiv.org/abs/2611.04835
- 作者：Marco Angioli, Mathias Persson, Hiroto Tamura, Hadi Banaee, Amy Loutfi, Gouhei Tanaka, Alberto Giaretta, Denis Kleyko（cs.LG）
- **TL;DR**：边缘侧异常检测要在竞争性性能与极小算力/内存之间取舍。本文研究无监督**时序异常检测**方法 **MDRS（储备池状态的马氏距离）**在资源受限设备上的可行性，并提出两项优化把它的计算量压下来。
- **解决什么问题 / 为什么重要**：命中 B 的**异常检测 / 时序告警**（监控侧），且走的是"小而省"的路线。它把储备池计算（一种轻量循环动力系统）的**时间记忆**用来简化输入预处理，并证明整条时间序列的异常分数可**仅由末态储备池状态**算出——这对"要在 MCU 上实时跑、又不能用大模型"的监控/告警场景很有现实意义。
- **核心方法**：把 MDRS 的随机储备池连接（MDRS-Rand）换成**循环移位（MDRS-Circ）** → 证明整序列异常分数可由最终储备池状态单独计算 → 利用储备池时间记忆做更高效的输入预处理 → 在 MLPerf Tiny 异常检测基准上对比参考自编码器等方法，并把推理核部署到 NUCLEO-F401RE 单片机上实测时延/能耗/内存。
- **主要结果**：评测方法中只有 MDRS 与自编码器达到基准性能目标，而 MDRS 运算更少、模型更小；优化预处理后 MDRS 达 **ROC AUC 0.869、模型 24 KB、单次推理约 24 µJ、时延 0.32 ms**，相对"标准预处理自编码器"实现 **75.9× 加速**。
- **值得追问 / 局限**：① 基准（MLPerf Tiny）与单一 MCU 平台上的结论，迁移到更复杂/多变量工业时序或概念漂移场景时性能是否保持待验证；② 储备池超参（谱半径、泄漏率、维度）与循环移位结构对不同异常类型的敏感性未系统给出，ROC AUC 0.869 距离高可靠告警仍有差距。

### 4. Learning Behaviorally Relevant Dynamics in Multimodal Neural Recordings
- 链接：https://arxiv.org/abs/2611.05167
- 作者：Parastoo Azizeddin, Eray Erturk, Maryam M. Shanechi（cs.AI / cs.LG / cs.NE）
- **TL;DR**：多模态神经数据（spiking、局部场电位 LFP、行为）从不同时空尺度刻画脑过程，但以往"分离变异来源"的神经-行为模型多只用单一模态。本文提出 **BREM-NET**：一个非线性多模态**动力学**模型，把行为与多种统计特性/时间分辨率各异的神经模态融合，并在推理期做多模态融合、同时把**行为相关**与**残余**神经动力学分离。
- **解决什么问题 / 为什么重要**：命中 B 的**脑网络 / 神经影像时间序列**，并带有 A 的"动力学建模"味道。它解决两个现实痛点：一是多模态融合（spiking 与 LFP 时间分辨率/统计特性不同），二是把"与行为相关的神经计算"从背景动力学中结构化地剥离——对可解释脑状态建模与脑机接口的行为解码都有参考价值。
- **核心方法**：构建非线性多模态动力学模型，推理期融合多神经模态 → 用结构化学习框架分离"行为相关"与"残余"两类动力学 → 在公开的非人灵长类多模态数据集（同时记录 spiking 与 LFP 的 2D 够取任务）上评测。
- **主要结果**：BREM-NET 能把两类动力学分离并学得更准，体现在**更好的行为解码、更好的神经预测、潜变量与行为更强对齐**；且在神经模态**异步或 dropout**（真实记录的主要挑战）时仍保持这些能力。
- **值得追问 / 局限**：① 验证限于单一非人灵长类够取任务数据集，跨任务/跨个体/跨脑区的泛化尚未展示；② "行为相关 vs 残余"的分离依赖结构化假设，残余成分里是否仍混有行为相关但非线性耦合的信息，需进一步的因果或扰动验证。

## C. 机制 / Agent（ICL 电路的因果拆解 / SFT 普遍能力退化的特征干涉理论，取 2 篇；均为"优先"机制类，非 prompt 工程）

### 5. A Circuit for In-Context Learning
- 链接：https://arxiv.org/abs/2611.05344
- 作者：Andrew Gao, William Gao（cs.CL / cs.LG）
- **TL;DR**：上下文学习（ICL）让预训练模型靠 prompt 里的示例完成任务、不更新参数；用**任意标签**时模型必须在**单次前向**里现学一个无法记忆的映射。此前工作找到了候选零件但不知如何组合。本文在三个 3–4B transformer 上给出"任意标签少样本句子分类"的**完整电路组成**。
- **解决什么问题 / 为什么重要**：命中 C 的**机制分析 / residual stream / circuit**（正中"优先"）。它不止定位零件，而是把 ICL 讲成一条**"键值记忆 + 门控关联查找"**的可执行电路，并对每一步都做因果验证——这是对"ICL 到底是怎么在一次前向里完成学习"这一核心问题的机制级回答，且展示了该电路在规模、从头训练、指令微调下的保守性。
- **核心方法**：发现模型在标签 token 位置实现**键值记忆**（标签 token 残差流编码标签身份，中层注意力头把"前一个示例的类别"作为 key 写入）→ 查询处上层头用 query 的类别匹配已存 key 并复制出匹配标签 → 一个早层"是否出现过重复标签"的信号**门控**该读出（缺失时读者转而注意 prompt 开头、不偏向任何标签）→ 另有一组头抑制最近见过的标签 → 全程用激活补丁、对随机头基线的头消融、以及用模型自身信号做 steering 逐步建立因果。
- **主要结果**：用两常数/头的 softmax 读出模型在一个 prompt 分布上拟合、可预测另一个分布；电路在三模型间**保守**，仅命名的那些头即可复现行为；从头训练的 transformer 会长出同样的零件；电路可迁移到语义概念与有意义标签，同一批零件（带因果门）在同一家族 **0.6B–8B** 均出现并**挺过指令微调**。
- **值得追问 / 局限**：① 结论基于"少样本句子分类 + 任意标签"的受控设定，能否推广到多步推理、长链 ICL 或生成式任务中的"隐式学习"仍待检验；② 电路在 3–4B/单一家族上刻画最细，跨架构（非标准 transformer、MoE）的零件对应关系尚未给出。

### 6. Unifying and Beyond the Theory of Pervasive Capability Degradation in LLM Post-training: SFT from Feature Interference
- 链接：https://arxiv.org/abs/2611.05003
- 作者：Hang Chen, Jiaying Zhu, Wenya Wang（cs.LG）
- **TL;DR**：**普遍能力退化（PCD）**指 SFT 在适配目标任务时侵蚀预训练获得的通用能力。主流解释归因于宏观分布漂移，缺乏微观可操作性。本文从 **superposition 下的特征干涉**出发自底向上建立 PCD 的几何理论：窄域 SFT 数据破坏预训练形成的近正交特征结构，干涉把激活推过输出 Laguerre-Voronoi 几何中的决策超平面，从而在通用任务上翻转预测。
- **解决什么问题 / 为什么重要**：命中 C 的**训练动态 / 表征几何 / 机制分析**（正中"优先"，非 prompt 工程）。它把"SFT 为何伤通用能力"从模糊的分布漂移说法下沉到**可操作的特征干涉几何**，并用该理论把已有缓解方法统一成六个范式、指出其有效性来源与理论上限；进而**证明**单靠 one-hot 下的交叉熵无法独立解决 PCD，据此设计新损失。
- **核心方法**：建立基于 superposition 特征干涉的 PCD 几何理论 → 证明 one-hot 交叉熵不能独立解决 PCD → 提出 **AEGIS 损失**，直接约束激活 margin 沿所有竞争 token 方向的漂移，把"干涉抑制"与"任务适配"解耦 → 在 3 个模型家族、14 个 SFT 任务上评测。
- **主要结果**：AEGIS 在目标任务与通用能力上**同时**优于每一范式的代表方法，计算成本仅约标准 SFT 的 **1.3×**；理论把现有方法归并为六范式并解释其有效性与边界。
- **值得追问 / 局限**：① "特征干涉几何"依赖 superposition 与近正交结构假设，这些假设在不同规模/架构上成立到何种程度、Laguerre-Voronoi 刻画的可测性需更多实证支撑；② 评测以 SFT 为主，理论/AEGIS 对 RLHF、持续学习、LoRA 等其它后训练范式的适用性尚待验证。
