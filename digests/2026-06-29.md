## 1. Localizing RL-Induced Tool Use to a Single Crosscoder Feature
- 链接：https://arxiv.org/abs/2606.26474
- 作者：Andrii Shportko, Shubham Bhokare, Ahmed Zeyad A Alzahrani, Bowen Cheng, Gustavo Mercier, Jessica Hullman（共 6 人）｜ICML 2026 Mechanistic Interpretability Workshop **Spotlight**
- 方向：C（机制可解释 / 训练动态 / 表征——"优先"类，直击"RL 微调到底改了表征里的什么")
- **TL;DR**：RL 微调让 LM 学会工具调用，但"内部到底变了什么"一直说不清。作者用 **Dedicated Feature Crosscoders (DFC)** 把 RL 引入的能力**定位到一组极小的、可 steer 的特征**上，并能在运行时无重训地操控 agent 的工具调用行为。
- **解决什么 / 为什么重要**：这正是我最关心的那条机制线——agentic 能力（这里是 tool use）在网络内部以何种表征形式出现、能否被定位与干预。它不是又训一个更强的 agent，而是回答"RL 把能力写进了哪儿"。"能力溢出（capability spillover）"现象尤其有意思：把定位到的特征装回**冻结的 base 模型**，base 也凭空获得了工具调用能力——说明该能力被压缩进了一个可迁移的特征子集，而非弥散在全网。
- **核心方法**：在 Qwen2.5-3B 上对 RL 模型与 base 模型训练 crosscoder，做 48 组超参扫描；用 DFC 把"RL 特有特征"与"RL/base 共享特征"分离开；通过对这组 RL 特异特征做 encode-decode 重构来验证其因果作用，并尝试把它们注入 frozen base 实现 retraining-free 的行为控制。
- **主要结果**：(1) 对 RL 模型做 encode-decode 重构，工具调用正确率提升 **+31.1 ± 9.7 pp**；(2) 把这组特征被动迁移到冻结 base 模型，base 工具调用能力提升 **+6.8 ± 5.0 pp**（"capability spillover"）；(3) 结论：DFC 划分把 RL 引入的能力**集中到一个最小、可 steer 的特征集**，支持对 agentic LLM 的运行时行为控制。
- **追问 / 局限**：(1) 仅在 Qwen2.5-3B 单模型、单一 tool-use 能力上验证，是否对更大模型、更复杂 agentic 行为（多步规划、记忆）同样"能定位到紧凑特征集"，存疑。(2) "+6.8 pp 溢出"绝对值不大且方差不小，"能力被压进单一/少数特征"这个叙事的强度，需要看在更多能力维度上是否仍成立、还是 tool-call 这种结构化输出本身特别"可定位"。

## 2. Memory Depth, Not Memory Access: Selective Parametric Consolidation for Long-Running Language Agents
- 链接：https://arxiv.org/abs/2606.26806
- 作者：Haoliang Han
- 方向：C（agent memory 机制 / 训练动态——"优先"类，区分"检索访问"与"参数固化"两种记忆）
- **TL;DR**：长程 language agent 光有"检索访问（memory access）"不够。作者把另一个被忽略的问题拎出来叫 **memory depth**——把哪些经验**固化进一小块参数存储**、使其在工作上下文卸载后仍持续塑造行为。提出 surprise+valence 门控的 LoRA 固化机制 **EVAF**，并设计 loop-drift 压力测试来量化它。
- **解决什么 / 为什么重要**：这条线直接对应我对"agent 的 memory / 训练动态"的兴趣，而且它把"记忆"拆成两个**正交且互补**的维度——检索擅长浅层事实召回，参数固化擅长**目标导向倾向的持久化与卸载后恢复**——这种机制层面的因式分解比"又加一个记忆模块"更有信息量。loop-drift 协议（保留检索索引、卸载工作上下文、在长循环干扰下看目标行为能否存续）是个干净的隔离实验设计。
- **核心方法**：EVAF = 由 surprise 与 valence 双重门控触发的 LoRA 固化（selective parametric consolidation）；机制对照实验把固化拆成 **selection（选哪些经验写）** 与 **actuation（写多强）** 两个可控维度——用 matched-random 门隔离"选择"的贡献、用 fixed-inner 对照看"写入强度"的模型依赖性；以公开 Memora event stream 作外部诊断。
- **主要结果**：在 GPT-2 / TinyLlama 上，检索在**短事实召回**最强（0.956–0.973），而 EVAF 在**目标持久化与卸载后恢复**最强（0.812–0.904），且每 200 个事件只需 **2–3 次参数写入**；机制对照显示 selection 与 actuation 可分别控制，inner-loop 写入强度依模型而变（GPT-2/TinyLlama/Mistral-7B），Mistral-7B 的 matched-gate inversion 还揭示了在 actuation 失准时 selection–actuation 的**非对称耦合**；stale-memory 失效被标为尚未解决的边界。
- **追问 / 局限**：(1) 主体实验在 GPT-2 / TinyLlama 这类小模型上，Mistral-7B 只做了对照；"参数固化补充检索"的结论在真正大模型 + 长程部署下是否稳健、写入会不会累积性损伤通用能力，需要验证。(2) 作者自己点出 stale-memory invalidation（固化下来的旧倾向何时该作废）仍未解决——这恰是把它用进实际 agent 的关键风险点。
