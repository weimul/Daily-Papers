## 1. In Terms of Explainability: Refining Requirements for Self-Explainable Systems
- arXiv: https://arxiv.org/abs/2608.06049 （cs.SE；首版 2026-08-06）
- 作者：Arno Leue, Akhila Bairy, Maike Schwammberger
- **TL;DR**：自主/软件密集型系统对"透明性、可解释性"的要求越来越硬（EU AI Act、IEEE 7001-2021 已点名），但至今**没有一个通用的"自解释系统"定义与开发指南**；本文综合既有定义给出统一术语，并整理出构建"（自）可解释系统"所需的结构化需求，还把"解释优度/正确性"纳入定义。
- **解决什么问题 / 为什么重要**：正中我"**内生 / 自解释（intrinsic / self-explaining）**"这条横切重点。它不提新模型，而是回答一个更底层、常被跳过的问题——"我们说的**自解释到底指什么、需要满足哪些需求才算数**"。价值在于：其一，把碎片化的可解释性定义收敛成一套统一术语与需求清单，为后续"内生可解释模型"的评判提供可对齐的标尺；其二，明确把**解释的"好坏/正确性"**写进定义，呼应我对"纯 post-hoc 归因降权、要求解释本身可被检验"的偏好——解释不能只是"给了个理由"，还要能被审计/认证。
- **核心方法**：分析并合并现有可解释性定义 → 提出统一定义；据此拆出构建（自）可解释系统所需的**结构化可解释性需求**；分析所得分类法后，主张把**解释优度（explanation goodness）与解释正确性**纳入统一定义；目标是支撑形式化标准、便于对可解释系统做认证/审计。
- **主要结果**：产出一套统一的可解释性定义 + 一份"自解释系统需求"分类法（taxonomy），并论证其可作为标准化、认证与审计的基础。
- **值得追问 / 局限**：这是**需求工程/标准化视角的概念性工作，非 ML 方法**——它给"自解释该满足什么"划了框，但没给"某个内生可解释模型如何构造/训练"的具体机制；"解释正确性"如何**可操作地度量**（尤其对时序图/动态模型这类结构化输出）、以及该分类法能否真正驱动可证伪的评测，仍待后续落地。

## 2. MPP-GNN: Subject-Adaptive Community Detection for fMRI-Based Alzheimer's Disease Classification
- arXiv: https://arxiv.org/abs/2607.28681 （cs.LG / cs.AI / q-bio.NC；首版 2026-07-29，近期在 q-bio.NC 公告可见）
- 作者：Yang Zhang, Xiao Zhou, Jonathan Warrell, Avram Holmes, Xuan Zhang, Mark Gerstein
- **TL;DR**：用 GNN 分析脑功能连接做阿尔茨海默（AD）分类的现有方法，通常**给所有被试预设相同数量的功能模块**、且发现的模块很少反过来指导连接学习；MPP-GNN 用"元概率池化"把任务写成**双层优化**，先自适应地为每个被试发现专属脑模块，再把模块当**显式先验**去精修边、学表示。
- **解决什么问题 / 为什么重要**：这是今日**打通 A（GNN 结构建模）与 B（脑功能网络/神经影像）的交叉点**。方法学上它切中我关心的两件事：其一，**结构不是预设而是被学出来的**——自适应图划分按被试差异发现社区/模块，摆脱"统一模块数"的强假设；其二，**"发现的结构"反哺"表示学习"**——把模块作为显式先验引导边精修，正是"显式结构先验 + 数据驱动表示"的耦合，与我在时序图/动态图上想要的"可控结构注入"思路同源。应用面则直接落在脑网络分析（B 的 fNIRS/neuroimaging 邻域）。
- **核心方法**：Meta Probabilistic Pooling GNN——把模型任务框成**耦合的双层（bilevel）优化**，分层做自适应图划分以发现**被试特异**的功能模块；再把发现的脑模块作为**显式先验**指导边精修与表示学习；两级目标端到端耦合。
- **主要结果**：在两个公开 AD 数据集上均取得**最高 AUC**（优于既有基线）；且学到的模块与 **Yeo 脑图谱**定义的经典功能网络组织显著对齐，并揭示 AD 的"网络级去分化（dedifferentiation）"模式。
- **值得追问 / 局限**：任务是 fMRI（非我 B 首选的 fNIRS 慢血氧信号，噪声结构/时间尺度不同，迁移需另证）；双层优化的**训练稳定性与计算开销**、被试特异模块在小样本/跨站点下的鲁棒性，摘要未展开；与 Yeo 图谱"对齐"是佐证而非独立验证，模块的因果/生理可解释性仍需谨慎对待。

## 3. Why Ranking Anomaly Detection Algorithms Isn't as Reliable as You May Think
- arXiv: https://arxiv.org/abs/2608.04613 （cs.LG；首版 2026-08-05）
- 作者：Simon Klüttermann, Jérôme Rutinowski, Frederik Polachowski, Alice Kirchheim
- **TL;DR**：异常检测新方法层出不穷、人人自称 SOTA，但各家**基准设置互不对齐**；本文用 7 个代表性算法 × **OddBench 的 690 个数据集**，系统量化"数据集选取、评测指标、超参、随机种子"对算法排名稳定性的影响——结论是**排名高度不稳定**。
- **解决什么问题 / 为什么重要**：直击我 **B 方向"异常检测/监控告警"**的评测方法论痛点。它的价值不在提新算法，而在给一个**可证伪的可靠性判断**：他们定义**排名不稳定性（rank instability）指标**，发现"几乎任何一个有竞争力的算法都能在某种基准配置下被评成第一"。对做 anomaly detection / AIOps 的人，这是一个必须正视的现实——**你读到的 SOTA 很可能是基准选择的产物**；其中"数据集选取"与"超参"贡献了最大的排名不确定性，而随机种子与指标影响相对小，这直接指向"多数据集、大规模、多样化评测"才可信。
- **核心方法**：选 7 个代表性异常检测算法，在 OddBench 的 690 个数据集上，系统变动**数据集子集选择、评测指标、超参配置、随机种子**四类因素；提出 rank instability 指标度量排名在不同基准设置下的波动。
- **主要结果**：算法排名**高度不稳定**——多数情形下几乎每个竞争算法都能在某配置下成为"最优"；**数据集选取与超参**是排名不确定性的主因，随机种子/指标影响有限；可靠的基准需要**比现有工作大得多、也更多样**的数据集集合。
- **值得追问 / 局限**：结论基于**表格/通用异常检测（OddBench）**，未必直接推广到**时序异常检测**（时间依赖、概念漂移会带来额外的排名脆弱性，值得专门复验）；7 个算法覆盖面有限，rank instability 指标本身对"数据集采样方式"的敏感性也需交代；对我更关心的时序 AIOps 场景，如何据此设计"抗排名波动"的评测协议是可追问的下一步。

## 4. Detecting high-frequency brain disorder signals using dynamic mode decomposition from EEG
- arXiv: https://arxiv.org/abs/2608.02804 （q-bio.NC / cs.LG / eess.SP；首版 2026-08-03）
- 作者：Jacob Kang, Jong-Hyeon Seo
- **TL;DR**：脑疾病（如癫痫发作）与特定刺激下，EEG 的**高频段**存在可辨识的动力学变化；本文用**动态模态分解（DMD）**从神经相关的 EEG 通道里抽取"持续一致"的高频动力学模态作为特征，做脑疾病分类。
- **解决什么问题 / 为什么重要**：作为今日 **B 方向脑信号/神经影像**的补位（fNIRS 无直接命中，EEG 为最近邻），同时它的**方法侧命中我 A 的"连续时间/动力学"兴趣**——DMD 是把时间序列分解成一组"模态×增长/振荡率"的**线性动力系统近似**，与 Neural ODE/latent ODE 那套"用动力学结构刻画时序"的思路同源，只是走的是数据驱动的谱分解而非可学习 ODE。对想在脑信号/一般时序上引入"可解释动力学表示"的人，这是一条轻量、可解释的路线。
- **核心方法**：对神经相关 EEG 通道做 DMD，提取高频段的一致/持久动力学模态 → 构成特征表；后处理用**随机分布检验**筛出"确有一致高频动力学"的样本，再对通过检验的特征表做 PCA，用主成分做分类。
- **主要结果**：约 **70%** 的样本在某特定通道信号内表现出一致的高频动力学；通过检验的 PCA 成分形成一致模式，能区分**酒精依赖组与对照组**。
- **值得追问 / 局限**：样本量/统计效力、以及"酒精依赖 vs 对照"这一二分类的临床代表性摘要未交代；DMD 对噪声与非平稳性的敏感（EEG 高频段信噪比低）、通道选择的先验性、以及相对深度时序基线的定量优势都待补；迁到 **fNIRS 慢血氧信号**时高频动力学假设基本失效，需换低频/血流动力学建模。

## 5. TRAJDEBUG: Tracing Error Lifecycle to Identify Critical Failures in Long-Horizon Agent Trajectories
- arXiv: https://arxiv.org/abs/2608.06346 （cs.AI；首版 2026-08-06）
- 作者：Yunjia Qi, Zehua Yin, Xintong Shi, Hao Peng, Songyuanyi Lu, Yixian Liu 等（13 位）
- **TL;DR**：LLM agent 在长程任务里会**级联出错且极难调试**；"关键错误检测"要在失败轨迹里定位**最早那个"要为最终失败负责"的步骤**。本文指出两大难点——长轨迹里判据证据被打散、失败轨迹含多个局部错误但只有部分真正致命——并提出 **TrajDebug** 用"错误生命周期追踪"来做归因。
- **解决什么问题 / 为什么重要**：命中我 C 方向"**优先**"型的**机制/现象分析**（agent 失败的结构、错误传播与归因），而非 prompt 工程。它的两个洞见很实：其一，**"多粒度历史压缩 + 基于证据的错误识别"**——直面"证据散落在遥远的指令/观测/上下文里"这一长程难题；其二，把"错误"当成有**生命周期**的对象——追踪每个错误的**是否被后续修复（resolution status）与最终影响（terminal impact）**，从而区分"局部小错"与"真正致命的关键错"。这把 agent 调试从"看哪步不对"升级为"哪步的错**没被消化、且一路影响到终局**"。
- **核心方法**：TrajDebug = 多粒度历史压缩（应对长轨迹）+ 基于证据的错误识别 + **错误生命周期追踪**（记录每个错误的修复状态与终局影响以支持关键归因）；并构建 **TrajErrBench**——486 条人工标注的失败轨迹，取自 Tau2Bench 与 SWE-Bench Pro，覆盖真实工具使用与编码场景。
- **主要结果**：在多个 agent 基准上**整体优于既有基线**；应用研究显示其诊断能给出**可操作反馈**，进而提升下游 agent 成功率。
- **值得追问 / 局限**：TrajErrBench 486 条为人工标注，规模与标注一致性/主观性、以及"关键错误"标签的客观性需交代；方法依赖"多粒度压缩"是否会**丢掉致命证据**、在超长轨迹上的可扩展性，摘要未量化；"提升下游成功率"的因果链（诊断→修正→提升）有多稳、跨骨干模型是否可迁移，值得追问。

## 6. EnvACE: Internalizing Environment Dynamics via World Rehearsal for Agentic Reinforcement Learning
- arXiv: https://arxiv.org/abs/2608.06197 （cs.AI；首版 2026-08-06）
- 作者：Zishan Xu, Zhiyuan Yao, Yuxin Chen, Yifu Guo, Zhengxi Lu, Yuquan Lu 等（12 位）
- **TL;DR**：训练长程工具使用 agent 通常要么依赖真实/合成的可执行环境（构建与验证都贵），要么用难以对齐的外部模拟器；EnvACE 用**"世界排演（world rehearsal）"取代训练期的外部环境交互**——策略先出一个工具调用，再**自己扮演环境**产出该动作诱发的响应，并据此条件化后续决策，两个角色端到端联合优化。
- **解决什么问题 / 为什么重要**：命中我 C 方向"**优先**"型的**机制/训练动态**（agent 世界模型、把环境动力学"内化"进参数），非 prompt 工程。它的核心主张很有意思：**让策略把"动作↔环境响应"的关系压进自身参数**，等于得到一个直接服务于决策的"agent 世界模型"；这与我关心的"表征里到底内化了什么结构/动力学"是同一类问题——只不过对象是**环境转移**而非语言结构。更实用的一点：测试时可先"私下排演"再提交执行，在有限排演预算下白拿收益，且**无需额外外部交互**，直指"agent 训练受制于环境构建成本"这一瓶颈。
- **核心方法**：策略在"行动"与"排演"两个角色间交替——先生成工具调用，再扮演环境产出被该动作诱发的响应，并以排演出的响应条件化后续决策；两角色用**任务成功奖励**端到端联合优化，从而把环境动力学内化为参数化的世界模型；测试时支持"提交执行前先私下排演"。
- **主要结果**：在 BFCL-v4、τ²-Bench、VitaBench、FinMCP-Bench 上取得**强且可迁移**的表现，整体评测**优于"扩环境"基线**；受控实验证明世界排演在**不同模型规模**下都稳定改善策略学习；测试时中等排演预算即可进一步提升。（代码已开源。）
- **值得追问 / 局限**：策略"自扮演环境"存在**自洽幻觉**风险——若排演出的环境响应系统性偏离真实转移，内化的世界模型会把偏差固化，摘要未量化"排演保真度"及其对最终成败的影响；在**动态/对抗性环境**或分布外工具上，内化世界模型的泛化边界、以及测试期排演预算与收益的权衡曲线，都值得进一步追问。
