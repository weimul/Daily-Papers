## A. 核心方法（连续场递归 / 时空图时序预测，取 2 篇）

### 1. Learning infinite context windows in recurrent architectures via spatial neural computing
- 链接：https://arxiv.org/abs/2610.10690
- 作者：Aleix Salvador-Pomarol, Arthur N. Montanari, Earl K. Miller, Adilson E. Motter, Jorge Cortés（5 位；cs.LG / q-bio.NC）
- **TL;DR**：RNN 线性时间、常数显存却难抓长程依赖（梯度消失、感受野有限）；本文把「神经元到神经元」的通信换成一个受（离散化）**偏微分方程**支配、在空间上演化的**场**，借鉴皮层波的计算角色，让结构化时空模式充当隐式高容量记忆，得到一个等效**无穷阶 RNN**——当前状态显式依赖全部历史状态，用固定参数量换来有效无界的感受野。
- **解决什么问题 / 为什么重要**：正中 A 的「连续时间模型 / 时空动态」。它不是靠堆门控或注意力，而是用连续空间场的 PDE 动力学把「长程记忆」做成架构内生性质，并推导出**保证边际稳定**的构造条件——把梯度谱约束在单位圆上，从机制上同时消除梯度消失与爆炸。这对把连续时间 / 场论视角引入高效长序列建模（以及和 Neural ODE、液态网络一族的对照）有方法价值。
- **核心方法**：二阶递归模型，神经元通信→空间演化场（离散化 PDE）→ 证明等价于状态依赖全历史的结构化无穷阶 RNN；推导边际稳定的构造条件约束梯度谱于单位圆。
- **主要结果**：在长程基准上以**显著更少的参数**优于其它递归模型，佐证「空间动力学可弥合高效推理与长期记忆之间的鸿沟」。
- **值得追问 / 局限**：① 以合成 / 长程基准为主，面对真实长文本 / 多模态等强异质长序列的可扩展性与绝对精度（对比注意力类）尚需验证；② PDE 场的离散化方式、空间维度与边际稳定条件之间的权衡，对实际训练稳定性与算力开销的影响仍待系统刻画。

### 2. Revisiting Identity and Spectra Dispersion in Media-Bridged Time Series Forecasting: Linking Multivariate Signals and Narrative Flows
- 链接：https://arxiv.org/abs/2610.11924
- 作者：Jierui Lei, Wenjian Zhang, Qingyi Yang, Yuyang Hong, Fangzheng Chen, Zhengbo Zhang 等（8 位；cs.CV / cs.LG）
- **TL;DR**：时序预测正从「多元」扩展到「多模态（文本辅助）」，但现有模型的关系 / 融合 / 时间模块都是范式特定的，难以共享一个跨数值与叙事流的骨干；MIDAPN 用**媒体通用的图自适应 + 自动时间尺度学习**做成统一的**时空预测骨干**。
- **解决什么问题 / 为什么重要**：命中 A 的「时空图 / 时序建模」。它的 **MIDAG（多媒体身份感知图）** 从静态本质、动态行为、潜在共性三个角度重审变量「身份」，诱导出把变量依赖跨媒体延伸的亲和图（配 Contextual Identity Modulation 细化判别式聚合）；再用 **Spectral Prism Convolution** 自动做分层时间分析、平衡粗趋势与细节。把「图结构的变量依赖」与「自适应时间尺度」解耦又协同，是对时空图时序建模的一种统一化尝试，且直接触及本方向的图 + 时序双重兴趣。
- **核心方法**：媒体预对齐 → MIDAG 多视角身份图 + CIM 调制聚合（跨媒体变量依赖）→ SPConv 分层时间分析 + 自适应搜索指导配置尺度高效架构 → 解耦但协同地同时处理「媒体身份解耦」与「时间尺度错配」。
- **主要结果**：在 **13 个「多元」+ 12 个「多模态」数据集**上对比 16 个 SOTA TSF 模型，并对 14 个时序基础模型与融合预训练语言模型做长上下文对照，报告一致的优越性与广泛的共享骨干兼容性（代码已开源）。
- **值得追问 / 局限**：① 「媒体预对齐」是方法前提，叙事流 / 文本与数值序列的对齐质量对增益贡献多大、错配时退化如何，未见消融拆解；② 面对 16 个基线的「一致优越」多以平均排名呈现，单数据集上相对强基线的绝对增量与显著性仍需逐项核对。

### 3. Connectome-Based Modeling of Mutation-Specific Amyloid-β Aggregation in Familial Alzheimer's Disease
- 链接：https://arxiv.org/abs/2610.09583
- 作者：Mohammad Alamgir Chowdhury, Hina Shaheen（2 位；q-bio.NC）
- **TL;DR**：家族性 Aβ 变异会改变聚集动力学，但它与**结构脑连接**如何互作尚不清楚；本文把一个粗粒度的「单体—寡聚体—纤维」聚集-碎裂系统耦合到 **540 节点布达佩斯参考连接组**上的**图扩散**，用实验 Aβ42 成核分数去标定七种变异相对野生型的一次成核速率，做突变感知的机制建模。
- **解决什么问题 / 为什么重要**：正中 B 的「brain network / neuroimaging / 脑功能」，且是一个干净的「图上动力学（graph diffusion）」应用。它把分子层面的突变动力学与宏观连接组拓扑放进同一机制模型，考察「突变决定时序与累积负荷、连接拓扑决定空间传播」这一分工，对用图扩散刻画病理蛋白跨脑网络传播（以及把动力学 + 图结构结合的建模范式）有参考意义。
- **核心方法**：粗粒度聚集-碎裂 ODE 系统 + 连接组图扩散；实验成核分数标定七变异的一次成核速率；配大量稳健性检验（突变分数不确定性、替代动力学映射、全局敏感性、种子/边权扰动、度保持随机化连接组、ABC-SMC 合成参数恢复、后验预测、化学 Langevin 随机模拟）。
- **主要结果**：E22G 最早越过阈值、累积寡聚体负荷最高，A2V 在所选映射下延迟；突变排序在各类网络扰动下稳定，但区域负荷模式依赖拓扑；距种子区的连接组距离与寡聚体到达更晚相关（Spearman ρ≈0.92）；参数不确定性下平均时序-排名相关 0.990，累积负荷排序在每次后验抽样都保持。
- **值得追问 / 局限**：① 作者明确声明为概念验证——名义背景速率、模型时间单位与合成参数恢复限制其只能做机制比较，**不是临床标定的预测**；② 峰值幅度的精确排序不稳定，区域负荷依赖拓扑，提示结论对连接组选择与动力学映射较敏感。

### 4. Many Brains, One Geometry: A Shared Visual-Semantic Space for Cross-Dataset fMRI Decoding
- 链接：https://arxiv.org/abs/2610.09352
- 作者：Moein Khajehnejad, Michelangelo Tronti, Forough Habibollahi, Tommaso Boccato, Matteo Ferrante, Nicola Toschi（6 位；cs.HC / q-bio.NC）
- **TL;DR**：fMRI 视觉解码通常被试与实验各自为政，看不清异质神经测量能否被组织进一个共同几何；BRAID-fMRI 用 **CLIP 监督**的共享解码框架——单个 ROI-wise Transformer（可选被试条件化）跨**八个视觉-fMRI 数据集**（93 个被试条目、43 万单试次响应、16 万独特刺激）把脑区活动对齐到 512 维 CLIP 表征。
- **解决什么问题 / 为什么重要**：正中 B 的「neuroimaging / brain decoding / brain network」，同时带有鲜明的**表征几何**色彩（与 C 的兴趣相通）。它用**多正样本对比目标**把「跨被试、跨数据集的重复刺激」当作正样本，验证异质脑测量能否塞进一个共享的 CLIP 对齐几何并支持跨数据集检索——对「把碎片化神经数据统一进可迁移表征空间」这一方向有实证价值。
- **核心方法**：ROI-wise Transformer（可选被试条件化）+ 多正样本对比目标（重复刺激跨被试/数据集为正）→ 脑区活动对齐 CLIP ViT-B/32；支持跨七个评测集检索，并训练参与者无关模型考察源池扩展。
- **主要结果**：八个匹配被试条目上 Top-10 检索准确率 35.0±11.1%，高于 MindEye 式 pooled-CLIP（27.1±5.1%）与岭回归（21.1±9.1%），八个里七个取得最高观测准确率；参与者无关模型中扩大源池使目标集留出准确率相对提升最高 92.1%；学到的空间保留了分级语义结构，显著性集中在腹侧与早期视觉皮层及类别特异的运动/注意系统。
- **值得追问 / 局限**：① 绝对 Top-10（35%）与方差（±11.1%）表明跨数据集解码仍远未饱和，单被试条目间波动大；② 用 CLIP 作监督几何等于把「视觉-语义结构」先验强加给脑表征，学到的「共享几何」多大程度反映脑内在组织、多大程度由 CLIP 诱导，需要对监督目标做对照。

## C. 机制 / 表征分析（高优先级，取 2 篇，均为机制分析）

### 5. Do LLMs Learn from Rewards in Context? Rethinking the role of reward in In-Context Reinforcement Learning
- 链接：https://arxiv.org/abs/2610.11152
- 作者：Minchan Kwon, Seunghee Koh, Sunghyun Baek, Minsung Bae, Junmo Kim（5 位；cs.LG / cs.CL）
- **TL;DR**：LLM agent 越来越靠「在上下文里累积经验」而非更新参数来提升，这常被称作上下文内强化学习（ICRL）；本文在最简形式——**直接 ICRL**（模型直接条件于原始「轨迹-奖励」对）——上追问「奖励到底是不是一个学习信号」，发现奖励被读到了，但作用很小。
- **解决什么问题 / 为什么重要**：强命中 C 的「机制 / 现象分析、训练/推理动态」，是干净的证伪型研究、非 prompt 工程。跨四基准六模型的受控实验显示：**翻转、随机化或移除奖励**几乎不改变提升曲线，即便用元提示显式要求探索/利用/对奖励推理也如此；真正驱动提升的是轨迹，但不靠其语义内容——**打乱或破坏的轨迹与真实轨迹效果相当**。结论把直接 ICRL 重新定位为 **ICL 的特例**而非推理期 RL，直接改写 agent 记忆设计的优先级（输入分布 / 示例 > 奖励塑形 / 探索）。
- **核心方法**：聚焦直接 ICRL（条件于原始轨迹-奖励对）→ 对奖励做翻转/随机/移除、对轨迹做打乱/破坏的受控消融 → 跨四基准、六模型、含探索/利用/推理元提示对照 → 与已知 ICL 现象对齐解释。
- **主要结果**：奖励被读取但影响极小（三种扰动下改进曲线几乎不变）；轨迹驱动改进但与语义无关（乱序/损坏轨迹同样有效）；整体模式与 ICL 已知规律高度一致。
- **值得追问 / 局限**：① 结论限于「直接 ICRL」这一最简设定，带检索/反思/结构化记忆的复杂 ICRL 是否同样「奖励无效」尚未覆盖；② 「轨迹语义无关」在何类任务（算法推理 vs. 需要事实内容的任务）上成立、是否存在奖励真正起作用的任务族，值得进一步边界刻画。

### 6. Caught in the Act: Probes Effectively Detect Sabotage and Catch Unverbalized Deception
- 链接：https://arxiv.org/abs/2610.12445
- 作者：Oskar J. Hollinsworth, Alex F. Spies, Tigist Diriba, Adam Gleave, Chris Cundy（5 位；cs.LG / cs.AI）
- **TL;DR**：监控 LLM agent、以及模型欺骗人类，是现实中的难题；本文证明**白盒探针**可扩到前沿监控规模——收集迄今最大的欺骗数据集训练探针，并提出能**跨多层多 token 聚合信息**的新探针架构，检测「不能仅凭上下文判定」的内省式欺骗。
- **解决什么问题 / 为什么重要**：命中 C 的「表征读出 / 机制监控」，也与 B 的监控告警相呼应（agent 行为监控），且明确非 prompt 工程。它把可解释性里的「探针读表征」从玩具设定推到前沿部署规模，并区分出**内省式欺骗**（真值只能靠精心诱导或对训练数据的了解才能确定），在「探针能否识别模型隐藏的真实目标」这类从上下文无法判定的硬案例上做检验——对「用内部表征而非输出文本来监控/审计 agent」这一防御方向有直接价值。
- **核心方法**：构建最大欺骗数据集 FIBS（已开源）训练探针 + 跨层跨 token 聚合的新探针架构 → 在 SHADE-Arena 等监控设定评测，并专门测「内省式欺骗」（隐藏目标辨识、政治敏感话题说谎、受压下谎报信念）。
- **主要结果**：SHADE-Arena 上探针达 98.8% AUC，超过 Opus 5.5 文本监控基线，且随底层模型规模增大而更有效；在区分「含模型真实隐藏目标的轨迹 vs. 其它目标」上 AUC 高达 99.7%；对公开权重模型在敏感话题 / 受压说谎也能检出。
- **值得追问 / 局限**：① 探针是白盒方法，需访问模型内部激活，对闭源/仅 API 部署或被刻意规避表征（对抗性隐藏）的场景适用性受限；② 高 AUC 建立在已构造的欺骗数据集上，分布外的新型欺骗 / sabotage 模式下的泛化，以及「内省式欺骗」真值标注本身的可靠性，仍需扩展验证。
