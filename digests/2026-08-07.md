## 1. Dynamic Graph Prompting via Topology-Routed Mixed-Curvature Experts
- arXiv: https://arxiv.org/abs/2608.06031
- 作者：Quanxin Wang, Xuanting Xie, Bingheng Li, Xingtong Yu, Shuo Wang, Ruiyi Fang
- **TL;DR**：动态图 prompting 通常冻结预训练时序骨干、只学轻量 prompt，但都困在"单一固定嵌入空间"里。本文指出局部聚集度与度异质性的时间漂移会重排边曲率谱——即最优表示几何本就应随局部拓扑随时间演化，据此提出 CurvPrompt：维护一组曲率各异的黎曼专家，用拓扑感知门控把每个"节点—时刻"路由到稀疏专家子集，构造个性化的混合曲率表示。
- **解决什么问题 / 为什么重要**：几乎正中 A 方向核心，且踩中"时序/动态图"与"表征几何"两个我最关心的点。它把一个少被点破的错配——"图在演化，但表示空间的曲率被钉死"——形式化为 geometry under-adaptation，并给出可操作的解法：不是换更大的骨干，而是让几何随拓扑自适应。对做 CTDG / 动态链接预测、又关心表示几何（曲率、双曲/球面混合）的人，这是一个把"混合曲率专家 + 拓扑路由"接进 prompt 范式的清晰样例。
- **核心方法**：维护一组曲率多样的黎曼专家，每个配一个可学 prompt；拓扑感知门控把每个节点—时刻实例路由到稀疏 Top-K 专家；预训练阶段用软路由建立"拓扑—几何"连续映射以保稳定，下游极端标签稀缺时切换为均匀权重的硬 Top-K 路由以保参数效率。
- **主要结果**：在四个基准数据集上，CurvPrompt 显著提升少样本链接预测，同时在节点分类上保持稳定一致的强表现，验证"几何自适应 prompting"的必要性。
- **值得追问 / 局限**：摘要未给与非几何动态图 prompt / 主流 CTDG 基线的量化差距，也未报专家数、曲率谱与计算开销的折中曲线；"边曲率谱随拓扑演化"是很好的观察，但曲率估计在稀疏/噪声图上的稳健性、以及硬路由在分布外时刻的路由错配风险，需看正文消融。

## 2. Align-RAG: Alignment Is All You Need for TSFM In-Context Learning
- arXiv: https://arxiv.org/abs/2608.05571
- 作者：Mohammad Asadi, Soheil Hor, Bardiya Akhbari, Jack W. O'Sullivan, Tahoura Nedaee, Layne C. Price
- **TL;DR**：检索增强预测想把冻结的时序基座模型（TSFM）无微调地迁到新域，主流做法却依赖"训练好的融合适配器"，其隐含假设是冻结骨干无法自行动态吸收检索上下文。本文证明这个假设不必要：Align-RAG 用免训练的闭式"逐对幅度重标定 + 整数滞后相位平移"，在检索窗进入冻结骨干上下文前先对齐，即可无任何可学参数地追平甚至超过训练式融合。
- **解决什么问题 / 为什么重要**：属 A 方向"连续时间/时序建模"的时序基座这条线，落点是"检索增强预测的正确默认基线该是什么"。它的价值在于把一类被普遍相信的必要性（必须训融合模块）用一个闭式对齐直接证伪，并给出机制性解释——对齐后的示例诱导的预测偏移，与同批样本上闭式岭回归预测偏移相吻合，且用 future-shuffle 对照排除了"未来值平均"的平凡解释。对做 TSFM in-context / RAG-forecasting 的人，这提示先跑闭式对齐再谈训练融合，能省一大截工程且更透明。
- **核心方法**：对每个检索到的"过去—未来"窗做闭式逐对幅度重标定与整数相位平移后再送入冻结骨干上下文；无可学参数、无 per-backbone 调参；并通过与闭式岭回归预测偏移对比、future-shuffle 对照来验证"对齐即诱导类岭回归的上下文利用"。
- **主要结果**：在冻结 Chronos-Bolt 上，Align-RAG 于标准基准全部 7 个数据集超过 SOTA 训练式检索适配器（平均 MSE −3.75%）；在另 4 个不同架构的冻结 TSFM 上无需 per-backbone 调参即把零样本 MSE 改善 2.5%–13.7%。代码开源（github.com/masadi-99/align-rag）。
- **值得追问 / 局限**：闭式对齐仅做幅度+整数相位，遇到非平稳形变、多尺度或强非线性域移时是否仍够用需看更难基准；"应作为训练融合前的默认基线"结论建立在给定基准与骨干族上，跨更多域/更长 horizon 的稳健性有待验证。

## 3. Enhancing Anomaly Resilience in Research Networks: A Large-Scale Forecasting Benchmark for Dynamic Security Baselining
- arXiv: https://arxiv.org/abs/2608.05605
- 作者：Mohammad Arafath Uddin Shariff, Byrav Ramamurthy
- **TL;DR**：科研教育网（REN）有个安全悖论——其正常流量的巨型突发"大象流"在统计上与 DDoS 等体量攻击难以区分，导致传统监控误报率极高。本文用 Internet2 独家 57 天、十台骨干路由器、137 亿包的数据，做首个大规模"异常感知预测"基准，以高保真流量预测建立可随时间变化的动态安全基线，把合法科研突发与潜在攻击区分开。
- **解决什么问题 / 为什么重要**：正对 B 方向"anomaly detection + AIOps + time-series anomaly"，且是难得的大规模真实骨干网基准工作。它把"异常检测"重构成"动态基线预测"问题：与其对固定阈值报警，不如让预测模型学出随时间演化的正常态，从而降低把科研突发误判为攻击的高误报。对做多指标监控 / 网络 AIOps、苦于"突发即误报"的团队，这份跨 6 个模型族、960 组配置的系统对比与"异常整合"训练策略有直接参考价值。
- **核心方法**：在 57 天 Internet2 骨干流量上系统评测 6 个模型族——从 SARIMA 到 TiDE、PatchTST 等长序列 SOTA 架构，共 960 组配置；并提出一种"异常整合"策略，在噪声存在下提升模型鲁棒性。
- **主要结果**：先进长序列架构（尤以 TiDE）相较传统方法把基线预测误差降低 30–42%（p<0.001），显著改善"合法科研突发 vs 潜在异常"的可分性；异常整合策略在噪声下把鲁棒性再提 3.3%。
- **值得追问 / 局限**：数据单一来源（Internet2 REN），结论能否迁到企业/云骨干或更细粒度指标待验证；"更低预测误差"到"更少实际误报/漏报"的端到端映射，以及在线部署时延，摘要未量化；把异常直接注入训练可能引入标签定义敏感性。

## 4. Complexity and Stability of Neural Activity Across Aging and Neurodegenerative Disease
- arXiv: https://arxiv.org/abs/2608.05882
- 作者：Junjie Yu, Jianyu Zhang, Zian Pei, Xue Shi, Yumei Liu, Xin Jiang
- **TL;DR**：EEG 即使在固定认知状态下也持续起伏，问题是大脑是否仍在复用相似活动模式来表征信息。本文把 EEG 建成"窗口化活动模式的分布"，用 Wasserstein 距离量化其时间稳定性、用内蕴维度刻画表征复杂度，得到一个分布层面的框架，用于跨认知、老化与疾病理解神经稳定性，并探索作为生物标志的潜力。
- **解决什么问题 / 为什么重要**：属 B 方向的"神经影像时序 / 脑活动"（fNIRS 的近邻场景）。它方法论上很对我的口味——把时序不看成单条轨迹而看成"活动模式的分布"，再用最优传输度量分布随时间的漂移，这套"分布级稳定性 + 内蕴维度"的刻画对 fNIRS 等其它脑功能时序也可迁移。发现也有结构性意义：更高内蕴维度一致对应更低稳定性（更丰富的表征更难复现），且有可复现的空间组织（后部维度高、稳定性低）；健康老化表现为维度升、稳定性降，而 MCI/AD 则是二者联合塌陷——提示一个双指标生物标志。
- **核心方法**：把 EEG 建为窗口化活动模式的分布；用 Wasserstein 距离度量分布的时间稳定性，用内蕴维度度量表征复杂度；在多任务、跨生命周期与临床数据集上对比。
- **主要结果**：神经表征表现为"受约束的、条件特异的稳定性"而非无约束漂移；高内蕴维度一致伴随低稳定性；两指标均有可复现空间组织（后部维度高/稳定性低于额部）；健康老化=维度升+稳定性降，MCI 与 AD=两者联合塌陷。
- **值得追问 / 局限**：为 EEG 结论，能否迁到 fNIRS（血氧慢信号、时间尺度与噪声结构不同）需另证；窗口长度、内蕴维度估计器与被试个体差异对两指标的敏感性，以及作为临床生物标志的判别阈值与纵向可重复性，摘要未展开。

## 5. Convergent Evolution in Neural Representation Space: Emergent Order in Deep Belief Networks
- arXiv: https://arxiv.org/abs/2608.05996
- 作者：Patrick Krauss, Achim Schilling, Andreas Maier, Thomas Kinfe, Claus Metzner
- **TL;DR**：深度信念网（DBN）以无类别监督学层级生成模型。本文追问：这一纯无监督过程是否仍会按"未知的数据类别"来组织内部表征？在 MNIST / Fashion-MNIST / KMNIST 上逐层分析发现——类特异聚集普遍随深度增强、表征渐趋紧致与原型化，尽管训练全程无标签。
- **解决什么问题 / 为什么重要**：属 C 方向"优先"里的表征几何 / 涌现现象分析（非 prompt 工程），且与 neural collapse、原型化表征的主题高度呼应。它是那种"发现一个反直觉现象并做严格对照"的工作：无监督逐层生成学习会自发揭示并逐层放大类相关结构，且这种效应依赖学到的特征结构，无法由随机变换、权重边缘分布、降维或 sigmoid 饱和解释。对关心"类结构/表征几何在无监督训练中如何自组织涌现"的人，这提供了一个干净的现象学证据与度量工具箱（GDV、重建抽象距离、有效维度）。
- **核心方法**：在训练后用广义判别值（GDV）、事后监督探针、基于重建的抽象距离度量、有效维度与自由采样生成，逐层分析 DBN；并设多组控制实验排除随机变换等平凡解释。
- **主要结果**：类特异聚集随深度普遍增强（跨数据集与网络宽度）；前几隐层常使类身份对线性/非线性探针更可及；更深处表征更紧致、原型化（神经元获得相关特征方向）；但 GDV 与探针精度揭示互补面——平均聚集改善可与少数困难类对的可及性下降并存。
- **值得追问 / 局限**：仅在三个小图像数据集与 DBN 上验证，能否外推到更大规模、更现代的自监督/生成架构存疑；"类结构自发涌现"与监督 neural collapse 的机制关系、以及该现象对下游可用性（而非仅可分性）的意义，值得进一步追问。

## 6. Causal Episodic Memory for Feedback-Driven Agent Repair (MERIT)
- arXiv: https://arxiv.org/abs/2608.05906
- 作者：Khang Nhat Hoang Vo, Tam Minh Chu, Anh Trac Duc Dinh, Thuyen Vinh Ha Bui, Tho Quan
- **TL;DR**：会自我修复的 LLM agent 常把成功的纠正随手丢弃，导致后续 episode 反复重新发现相似解。本文研究"已完成的修复结果能否免参数改善后续 Text-to-SQL"，提出免训练的 MERIT：维护一份在线双极性记忆（既存 oracle 验证过的成功纠正，也存观察到的失败方向），检索时先由确定性分类器给出粗粒度失败类型再做混合词法—稠密检索，最后冻结模型生成修订。
- **解决什么问题 / 为什么重要**：属 C 方向"优先"里的 agent memory（非 prompt 工程），直击一个真实痛点：反馈驱动的修复经验没被沉淀复用。它的思路——把"成功纠正 + 失败方向"都记下、按失败类型条件化检索、全程冻结模型——是一个可工程落地的情景记忆设计。更可贵的是它对结果很诚实，明确区分"何时因果性跨查询记忆真的有用、何时更宽泛的记忆表示反而更好"，而非只报正面数字。
- **核心方法**：在线维护双极性记忆（成功纠正 + 失败方向），只允许更早已完成 episode 的记忆被检索；确定性分类器赋粗粒度失败类型，条件化一个混合词法—稠密检索器；冻结 Qwen2.5-7B-Instruct 在相同初始预测与修复预算下生成每次修订。
- **主要结果**：相较无状态迭代修复，执行准确率在 Spider 从 66.34% 升至 69.79%、BIRD 从 47.35% 升至 48.44%；配对分析对 Spider 增益证据清晰、BIRD 较弱；MERIT 在两基准上均未能可靠区别于"无类型的动态检索"，而 Reflexion 式记忆在 BIRD 达 51.24% 但推理成本高得多；消融显示负向记忆贡献有限、类型条件化与词法—稠密排序的价值依数据集而定，schema 局部经验带来最一致的收益。
- **值得追问 / 局限**：作者自划边界——类型条件化与双极性设计的增益并不稳健地超过朴素动态检索，贡献更像"厘清适用条件"而非确立新 SOTA；仅在 Text-to-SQL 两基准、单一 7B 骨干上验证，迁到其它 agent 任务/更强骨干时记忆的净收益需重估。
