## A. 核心方法

### 1. Lévy Attention: Single-Pass Predictive Uncertainty for Continuous-Time Attention
- arXiv：https://arxiv.org/abs/2608.19171 （cs.LG）
- 作者：Sotirios P. Chatzis, Loukas Papadoulas
- **TL;DR**：把不规则采样时间序列的注意力层重构成"对非齐次泊松随机测度的随机积分"，让同一次前向在给出预测的同时、以闭式零成本吐出该预测该被信任多少。
- **解决什么问题 / 为什么重要**：面向任意连续时间戳查询的深度模型能给答案，却不报告置信度；作者证明注意力层本身就能补上这一环——直接对应你关注的"不规则采样时序 + 内生/自解释"两个横切点，且不需额外训练的不确定性头。
- **核心方法**：query-key 相容性在连续（时间×通道）索引空间上组装出一个强度场，泊松测度在其下撒点，输出对插值值场在这些点上做平均；期望上退化为一层被平滑的余弦核注意力，可直接替换 softmax 并用精确梯度训练。softmax 丢弃的两个量被闭式保留：证据 Λ_q（总相容质量）与分歧 tr Σ_V(q)（值的离散度），二者组合出预测的均方根偏差 σ̂(q)。
- **主要结果**：在 t-PatchGNN 上替换算子相对匹配对照最多损失 5.6% 精度、在最稀疏数据集上零损失；免费的"分歧"信号在五种子实验里胜过 20 次 MC dropout；σ̂ 标定的高斯其零采样 CRPS 优于 50 次采样器；split-conformal 包装在各置信水平达名义覆盖；单次前向 1.4 秒按可信度给 3383 名未见患者排序。
- **值得追问 / 局限**：①"证据因子"在稠密数据上几乎无信息、只有稀疏时才强，实际部署需判断数据稀疏度落在哪一端；②只在特定回归/插值任务验证，分类或多模态查询下的标定是否同样成立待考。

### 2. Multi-Source Wasserstein Distributionally Robust Graph Learning
- arXiv：https://arxiv.org/abs/2608.19914 （cs.LG）
- 作者：Chuansen Peng, Yifan Xia, Jinshan Zhong, Xiaojing Shen
- **TL;DR**：从图信号推断网络拓扑时，用加权 Wasserstein 重心融合异构多源数据、再套一个不确定性球做最坏情形稳健化，在目标域样本稀缺时显著优于朴素聚合。
- **解决什么问题 / 为什么重要**：脑网络/传感网/社交网的拓扑推断常是"目标域样本少、异构源域多"，欧氏平均会把不同几何塌成有偏共识。这正对上你的"脑网络 + 图学习"应用点，也给"样本稀缺下的图结构学习"一个有理论保证的范式。
- **核心方法**：以各源的加权 Wasserstein 重心作为几何上更合理的名义分布，围其构建歧义球，最小化最坏风险得到可用 ADMM 高效求解的正则化拉普拉斯估计；再把求解器展开（unroll）成可微架构端到端训练，实现超越交叉验证的数据自适应超参标定，同时保留可解释性。
- **主要结果**：给出有限样本浓度界、朴素聚合次优性的下界、以及对源数量仅取对数依赖的样本外超额风险界；在合成基准与多站点 ABIDE I 脑影像数据上，在图恢复、样本效率与下游诊断效用上稳超 7 个基线，样本稀缺时增益最大。
- **值得追问 / 局限**：①Wasserstein 重心在源域数目很大或分布极端异构时的计算与稳定性代价；②方法针对静态图拓扑，若目标是时序/动态脑网络还需扩展到时变设定。

## B. 应用场景

### 3. SCORE: Subject Coordinate Recovery for Label-Free Cross-Subject EEG-to-Image Retrieval
- arXiv：https://arxiv.org/abs/2608.19134 （cs.LG）
- 作者：Zhenyao Cui, Siyuan Kan, Siyang Li, Ziwei Wang, Dongrui Wu
- **TL;DR**：发现不同被试的 EEG 特征"概念间关系相似、但坐标方向不同"，据此提出无需目标标签/校准的跨被试对齐框架，把新用户 EEG 坐标恢复到公共图像空间。
- **解决什么问题 / 为什么重要**：现有 EEG→图像检索对无标注新用户远逊于被试内水平，制约真实部署。作者把跨被试差异刻画成"坐标系旋转"，给出免标定的部署方案——对你关注的神经影像时序解码、以及跨被试泛化难题很有借鉴。
- **核心方法**：训练阶段用"恢复感知"的源域训练，把源被试 EEG 对齐到公共图像空间并以 source-only episode 模拟未见被试恢复；部署阶段两端编码器冻结，通过 hubness 校正匹配挑选可靠的 EEG-图像地标，估计一个正交变换恢复目标被试坐标，全程不用源数据或目标标签。
- **主要结果**：200-way 检索中对每个目标被试都超过未适配基线；THINGS-EEG2 上 Top-1/Top-5 达 53.23%/83.55%，Alljoined-1.6M 达 12.01%/32.16%，分别较最强基线高 17.45/15.70 与 3.08/4.62 个百分点。
- **值得追问 / 局限**：①"正交变换即可对齐"的假设在被试间差异更大或非视觉任务下是否成立；②方法思路能否迁移到 fNIRS（通道更少、时间常数更慢）值得一试。

### 4. LLM as Detector: An In-context Learning Approach for Tabular Anomaly Detection
- arXiv：https://arxiv.org/abs/2608.19463 （cs.LG）
- 作者：Tu Anh Hoang Nguyen, Dang Nguyen, Thuc Duy Le, Trung Le, Sunil Gupta
- **TL;DR**：不微调、不训网络，用 LLM 的上下文学习把正常数据的统计摘要/因果依赖/蒸馏原型组织成提示，让 LLM 生成打分代码来做表格异常检测。
- **解决什么问题 / 为什么重要**：表格异常常是"跨特征依赖被违反"而非单变量偏离，几何/重构类检测器难以捕捉。这对你的监控告警/AIOps 方向是一条低成本、可解释的路径（打分逻辑显式成代码）。
- **核心方法**：把正常训练数据转成统计摘要、因果依赖与蒸馏原型，拼进用于代码生成的提示；生成的打分引擎综合统计偏离、结构不一致与基于密度的异常性，为每个测试样本算异常分；整条链路无需 LLM 微调或神经网络训练。
- **主要结果**：在 24 个表格数据集、对比 15 个 SOTA 基线，在混合类型与纯连续两种设定下均一致提升。
- **值得追问 / 局限**：①依赖 LLM 生成"因果依赖/打分代码"的可靠性与可复现性，跨数据集稳定性如何；②生成式打分对高维、强时序相关的告警日志（非独立同分布表格）是否仍适用。

## C. Agent / 机制与表征

### 5. MemTrapBench: Benchmarking Cognitive Traps in LLM Memory Use
- arXiv：https://arxiv.org/abs/2608.20202 （cs.AI / cs.CL / cs.LG）
- 作者：Mengru Wang, Haozhe Luo, Zhenqian Xu, Zhixiang Cui, Haoming Xu
- **TL;DR**：指出"即便被忠实记录、语义相关的记忆也会扭曲当前推理"，提出针对两类记忆认知陷阱（推理固着、信念扭曲）的基准，并给出一个推理时的缓解方法。
- **解决什么问题 / 为什么重要**：现有记忆基准只考"存取是否正确"，忽略了"取回的记忆如何反过来重塑推理并拖累当前任务"。这正属于你偏好的 agent"机制/现象分析"，对 agent 记忆可靠性有直接含义。
- **核心方法**：定义并构造两类陷阱——推理固着（Reasoning Fixation）与信念扭曲（Belief Distortion）——组成 MemTrapBench；提出 AdaptiveMem，一个简单的推理时方法，指示 LLM 主动规避记忆陷阱。
- **主要结果**：横跨两个模型族、五个代表性记忆框架，所有记忆策略都低于"无记忆"设定，最强方法也掉超过 10%；AdaptiveMem 在缓解陷阱的同时，于标准记忆基准上保持或提升性能。
- **值得追问 / 局限**：①"无记忆反而更好"部分源自任务构造对记忆的对抗性，真实长期交互中净收益的量级需另测；②AdaptiveMem 靠提示式规避，是否只是把陷阱推迟而非从检索/存储机制上根治。

### 6. Mechanistic Tomography: Designed Measurement for Control-Oriented Interpretability
- arXiv：https://arxiv.org/abs/2608.19338 （cs.LG / cs.AI）
- 作者：Vijay Erramilli
- **TL;DR**：把 patching、梯度、Hessian-向量积、子集干预等机制可解释性手段统一成"设计化测量" y = Ax + w，给出一套由廉价测量起步、逐步扩展测量族的实操流程。
- **解决什么问题 / 为什么重要**：不同可解释性测量在不同访问假设下针对不同量、彼此难比较。作者用测量/层析（tomography）语言把它们统一，并以"控制"作为苛刻验证场景（用估计去指导干预，估计本身就成了观测者）——对你关注的机制分析/表征几何很对味。
- **核心方法**：对选定基与干预族，测量写作 y=Ax+w（A 描述干预、x 为目标映射、w 含非线性响应/采样误差/基误设）；流程为先做最省测量、在目标尺度的留出干预上检验、标定简单失配、当残差仍有结构时再扩展测量族。
- **主要结果**：两-HMM 模型中控制误差随观测者误差上升；前向-only 访问下稀疏聚合测量比坐标 patching 用更少干预即恢复有限效应图；GPT-2-small IOI 上 Name Mover–Negative Name Mover 交互是三对跨组中最大的留出预测项；Qwen-2.5-7B 上有限标定使加性拒答-响应图已足够，留出误差不支持成对提升。
- **值得追问 / 局限**：①"测量族需匹配所选基"意味着方法论强但需大量任务特定设计，通用性/自动化程度如何；②当前案例偏小规模/受控任务，扩展到大模型多机制耦合时 w 的处理是核心难点。
