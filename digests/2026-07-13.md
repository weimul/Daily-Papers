## 1. Event Stream based Multi-Modal Video Anomaly Detection: A Benchmark Dataset and Algorithms
- arXiv：https://arxiv.org/abs/2607.09114 （cs.CV, cs.AI, cs.MM）
- 作者：Peipei Zhu, Yueqing Niu, Lin Zhu, Guanchong Niu, Yang Yu
- **TL;DR**：只靠可见光视频的视频异常检测（VAD）在强弱光、快速运动、复杂背景下很脆弱；本文用仿生事件相机的异步事件流补上高时间分辨率的运动线索，提出事件增强的 EVAD 框架，并放出大规模「可见光 + 事件」基准。
- **作者 / 机构**：第一作者 Peipei Zhu 等（含天津大学相关，评测集名为 TJUTCM-Pha）。
- **解决什么问题 / 为什么重要**：这命中 A 方向「event stream / 时序线索」与 B 方向「anomaly detection」的交叉——事件相机异步记录亮度变化、对运动模糊与极端光照鲁棒，恰好补足视频缺失的运动显著性，是把事件流引入监控异常检测的资料集 + 方法双贡献。
- **核心方法**：① 构建大规模可见光-事件基准，含 63 亿事件与 376,368 帧，覆盖多光照/多运动/多背景；② 对比式多模态预训练——在事件流、可见光视频、文本描述三者间对齐语义嵌入学判别性事件表征；③ 自适应融合模块动态整合事件时序线索与视频空间语义，提升对环境扰动的鲁棒性。
- **主要结果**：在公开基准与自建 TJUTCM-Pha 上，EVAD 一致优于现有方法，验证事件感知对真实场景 VAD 的有效性。
- **值得追问 / 局限**：需要事件相机硬件，落地成本与已有可见光监控基建的兼容性？「异常」标注在事件模态上的一致性与偏差如何控制；跨场景（新机位/新背景）的泛化与阈值迁移未系统展开。

## 2. Federated Low-Rank Koopman Learning for Multivariate Time-Series Anomaly Detection in IoT Systems
- arXiv：https://arxiv.org/abs/2607.08978 （cs.LG, eess.SP）
- 作者：Tung-Anh Nguyen, Van-Phuc Bui, Anh Tuyen Le, Kim Hue Ta, Minh Thuy Le
- **TL;DR**：分布式 IoT 的多元时序异常检测受困于去中心化非-IID 数据、带宽受限与边缘算力/内存约束；本文提出 FedKAD，用轻量滑窗 Koopman 表征学习「正常时序动力学」，把联邦训练化为低秩共识问题，只交换紧凑子空间变量。
- **解决什么问题 / 为什么重要**：这是 A 方向「continuous-time / 动力学建模」与 B 方向「time-series anomaly」的交叉——用 Koopman 算子把非线性时序升维成近线性演化来刻画正常动力学，相比要训练/通信大神经网的深度异常检测器，更契合资源受限边缘设备。
- **核心方法**：① 每个客户端在滑动窗口上学 Koopman 表征刻画正常时序动力学，推理时用「观测未来轨迹 vs Koopman 预测」的残差判异常；② 联邦训练建模为低秩一致性问题，原始传感流与本地约简动力学留在设备端，仅上传紧凑子空间变量；③ 在 Stiefel 流形正交约束下开发联邦 Stiefel-ADMM 算法，并给出部分客户端参与下的收敛与稳态性分析。
- **主要结果**：在四个常用多元时序异常检测基准上，检测性能持平或优于联邦深度学习基线；训练最高快约 2.1×10³ 倍、通信降 80 倍、推理延迟降 79 倍，适配边缘部署。
- **值得追问 / 局限**：Koopman 线性化对强非线性/突变工况的表达力上限？滑窗长度与低秩秩数对不同资产类型的敏感性；「只学正常动力学 + 残差」范式对缓变漂移（概念漂移）导致的伪告警如何抑制。

## 3. Log-Insight: Automating Microservice Incident Diagnosis via Neuro-Symbolic Log Analysis
- arXiv：https://arxiv.org/abs/2607.08529 （cs.IR）
- 作者：Carlos Garcia-Hernandez, Aymane Abdali, Guangyu Wu, Mingxue Wang, Fei Shen（华为）
- **TL;DR**：大规模微服务一次 30 分钟事件窗可产出 200 万+ 行日志（约 12 亿字符）远超 LLM 上下文，直接喂 LLM 做根因分析（RCA）不可行；本文提出并已在华为生产部署的 Log-Insight，用神经符号流水线把 SRE 的人工分诊固化成可复现步骤，再把压缩后的证据交给 LLM 生成假设。
- **解决什么问题 / 为什么重要**：这是 B 方向监控告警/AIOps 的真·生产落地——直击「模板解析缺语义、深度检测器只给黑盒二值、纯 LLM 管线上下文溢出且幻觉」三大缺口，把系统从「不透明神谕」变成「可查证的调查助手」。
- **核心方法**：六阶段流水线，符号阶段复刻 SRE 的结构化调查——采样、schema 理解、模式聚类、统计异常排序，把百万级原始事件压缩 1000–7000 倍并保留统计显著的失败信号，最后把预排序的紧凑「证据卷宗」交给 LLM 合成带假设的诊断报告；并给出「取证证据」段（精确日志模板 + 偏斜统计）。
- **主要结果**：在 11 起历史生产事件（110 次运行、SRE 校验的真值）上 MRR=0.790，>90% 的运行在一分钟延迟内把正确根因放进 top-3；运营人员反馈「取证证据」段是关键采纳因素。
- **值得追问 / 局限**：11 起事件、单公司环境，跨系统/跨栈泛化与外部复现待验证；符号阶段的采样/聚类阈值对新型/罕见故障是否会漏掉弱信号；MRR 之外对「完全新根因」的召回边界未细化。

## 4. Latent graph encoding of multimodal neuroimaging features with generative AI architectures
- arXiv：https://arxiv.org/abs/2607.07027 （cs.LG, cs.AI, cs.CV）
- 作者：Ishaan Batta, Meenu Ajith, Vince Calhoun
- **TL;DR**：生成模型能编码复杂神经影像做特征生成与重建，但架构（编码方式、潜空间融合、生成模型选型）决定能否刻画脑的结构-功能属性；本文系统评测后提出多模态图 VAE（gMMVAE），把功能连接做「模态感知图编码」进低维潜空间。
- **解决什么问题 / 为什么重要**：这是 A 方向「图/图编码」与 B 方向「brain network / neuroimaging」的交叉——用结构灰质体积（GMV）与静态功能网络连接（sFNC）两模态，验证「把功能连接组当图来编码」优于向量化或直接数据空间编码，对 fNIRS/脑网络的图建模思路有直接迁移价值。
- **核心方法**：在大规模神经影像数据集上系统比较 VAE / Transformer / GAN / 扩散模型作为生成骨干，以及不同编码策略与潜空间多模态融合；提出的 gMMVAE 对功能连接采用模态感知图编码映入低维潜空间，再与结构模态在潜空间融合。
- **主要结果**：采用图编码功能连接的架构在生成保真、重建质量、效率与潜空间可判别性多个指标上优于向量化/数据空间编码；gMMVAE 全面超过其它生成变体。
- **值得追问 / 局限**：用的是静态功能连接（sFNC），未纳入动态/时序连接（时空图那一支）——对时序脑网络是否仍占优待验证；「潜空间可判别性」到下游临床/认知预测的真实增益未展开；单数据集，跨站点/图谱稳健性待测。

## 5. Neural Collapse Is Forbidden: Information Floors in Language Models
- arXiv：https://arxiv.org/abs/2607.09487 （cs.LG, cs.CL, stat.ML）
- 作者：Bruno Abrahao
- **TL;DR**：语言模型表征里的类内方差常被读作「不完全的神经坍缩」；本文反过来论证它是「被分配的信息存储」，且分配服从一条定律——类内离散度至少正比于条件互信息 I(token; context | category)，因此神经坍缩被禁止。
- **解决什么问题 / 为什么重要**：这是 C 方向「优先」的表征几何/机制现象工作——不是又一个下游指标，而是给出可证的信息地板，把「类内方差 = 冗余」这一常见解读纠偏为「方差在承载语境信息」，对研究 LLM 表征结构、单纯形 ETF 假设的人是直接的理论修正（作者甚至用一行居中恒等式否证了包括自己此前在内的一族 simplex-ETF 断言）。
- **核心方法**：① 一行居中恒等式否证一族 simplex-ETF 断言；② 在 14 个模型上做无量纲方差份额分解——宏类别结构仅占 4–12%，token 内语境占 79–91%，在 100 倍参数跨度上稳定；③ 理论上 token 级权重衰减按「类型数」而非「出现质量」惩罚，把下一 token 预测约化为不平衡 K 类问题；④ 对二元类别证明一个下界地板，强制类内离散度 ≥ 正比于条件互信息。
- **主要结果**：在所测每个模型与划分上，是「身份离散度」而非总方差在追踪该信息，甚至跨模型——一个模型的信息可预测另一个模型的离散度；预训练中类别份额呈「过冲-衰减-部分恢复」，因它必须承载的信息从未离开。
- **值得追问 / 局限**：下界仅对二元类别严格证明，多类一般情形是否成立？「无模型」的互信息估计精度对结论稳健性的影响；这套定律对表征干预/可解释操作的可操作性尚待落到应用。

## 6. Shared Selective Persistent Memory for Agentic LLM Systems
- arXiv：https://arxiv.org/abs/2607.09493 （cs.AI, cs.MA, cs.SE）
- 作者：Sanjana Pedada, Aditya Dhavala, Neelraj Patil
- **TL;DR**：多轮工具调用生成代码的 agentic LLM 系统有个根本上下文问题——每次会话从零开始，丢掉了之前让会话高效的配置、领域约束、数据 schema 与工具用法；而朴素地保留整段历史又低效且反受污染。本文提出「共享选择性持久记忆」，只留可复用上下文、弃掉会话专属推理轨迹。
- **解决什么问题 / 为什么重要**：这是 C 方向「优先」的 agent 记忆机制工作——把「记什么/弃什么」形式化为四类可复用上下文（任务规格、数据 schema、工具配置、输出约束）的选择性保留，并支持跨用户共享 + 基于角色的访问控制，直击长时程/协作式 agent 的上下文成本与质量退化，而非纯 prompt 技巧。
- **核心方法**：① 识别并保留四类可复用上下文、丢弃会话专属推理轨迹；② 记忆可共享——封装选择性记忆的 workspace 可带 RBAC 跨用户迁移，实现协作复用；③ 配「零 token 数据刷新」机制把生成程序与运行时数据解耦，让产物（仪表盘/报告/数据文档）无需重新调用即可复用；已部署在支持 git 版本化产物、异构数据源（CSV/SQL/REST/MCP）的协作平台上。
- **主要结果**：三个企业场景下任务完成率 96%（无记忆 79%、全历史 71%）；零 token 刷新对重复更新省去 LLM 重调用（任务耗时降 14 倍）、摘要驱动生成把单次调用 token 成本降 97 倍；四个公开数据集复现，零 token 刷新 12/12 成功；且朴素全历史持久化会因陈旧轨迹主动拉低完成率。
- **值得追问 / 局限**：「四类可复用上下文」的边界与自动识别的错分风险（误留/误弃）如何量化？共享记忆的跨用户信息泄露/权限越界面（RBAC 之外）需安全审计；企业场景为主，开放/长尾任务上选择性记忆的收益是否仍稳。
