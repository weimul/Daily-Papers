## 1. Causal Discovery on Irregular Time Series
- arXiv: https://arxiv.org/abs/2607.18226
- 作者：Martim Penim, Ricardo Ribeiro Pereira, Jacopo Bono, Hugo Ferreira, Mário A. T. Figueiredo, Pedro Bizarro（共 6 位；含 Feedzai / IST-Lisbon 方向的作者）
- **TL;DR**：把时序因果发现的 SOTA 方法 PCMCI+ 从"规则、离散滞后"的假设里解放出来——不再用固定滞后建模因果，而是在预定义时间窗口上聚合因果影响，从而能直接在传感器流、医疗记录、金融交易这类不规则采样的事件流上恢复因果图。
- **解决什么问题 / 为什么重要**：正对 A 方向"不规则/异步采样时间序列"主线。现有时序因果发现几乎都假定固定采样间隔与固定滞后阶，但真实世界的事件流采样不齐、滞后不定，直接套用会失真。本文给出一条不靠重采样/插值、而是用时间窗聚合来处理不规则性的路径，对监控告警、脑功能等"不规则 + 需因果解释"的场景有直接迁移价值。
- **核心方法**：以 PCMCI+ 为骨架，把"固定滞后依赖"替换为"在预定义时间窗口上聚合因果影响"的条件独立检验框架，使 constraint-based 因果发现能容纳不规则时间戳的多变量事件流。
- **主要结果**：在已知因果结构的合成不规则事件流上、跨不同信噪比，方法能稳定恢复底层因果图，并在不规则采样数据上显著优于直接使用的标准 PCMCI+。
- **值得追问 / 局限**：时间窗大小是"预定义"的超参，窗宽选择对因果方向/滞后识别的敏感度、以及窗聚合是否会掩盖窗内的快因果，摘要未展开；目前验证以合成数据为主，真实高维不规则流（含隐混杂、非平稳）上的稳健性待检。

## 2. ClouDens: Operational Context-Aware Anomaly Detection for Large-scale Cloud System Monitoring
- arXiv: https://arxiv.org/abs/2607.18127
- 作者：Thu T. H. Doan, Mohammad Saiful Islam, Andriy Miranskyy, Ngoc-Thanh Nguyen, Rogardt Heldal, Patrizio Pelliccione（共 6 位）
- **TL;DR**：面向大规模云系统（LCS）遥测日志的高维、稀疏、组件强依赖，提出 ClouDens——把日志按领域切分成子集、用遥测 schema 里的"运营上下文"属性构建服务依赖图，再用时空图神经网络（ST-GNN）做预测式异常检测，实现更准、更早、覆盖更广的告警。
- **解决什么问题 / 为什么重要**：一箭双雕命中 A×B——A 方向"时空图 GNN / 预测式时序建模"，B 方向"time-series anomaly detection + AIOps + 大规模监控"。现代云平台持续吐出高维多变量遥测时序，维度爆炸、组件间复杂依赖、间歇活跃服务带来的严重稀疏，让通用异常检测难以落地；本文的卖点是把"运营上下文"显式编码进图结构，让检测器理解服务拓扑而非只看数值时序。
- **核心方法**：先对 IBM Cloud Console 平台遥测日志做实证研究；再把高维遥测按领域切成子集，用日志 schema 的运营上下文属性构建"上下文感知"的服务依赖图；在图上用 ST-GNN 做预测，以预测残差作异常分数；系统性检视特征子集、上下文建模、打分策略、稀疏插补各自对检测性能的影响。
- **主要结果**：在新发布的 IBM Cloud Telemetry Dataset 上，ClouDens 在计数型遥测特征上取得比 GRU 基线更高的 NAB 分数，意味着更准、更早、覆盖更广的异常识别；消融表明特征子集、上下文建模、打分与稀疏插补都会实质影响性能，为该场景的公平基准设计给出实操指引。
- **值得追问 / 局限**：主要对照是单一 GRU 基线，与更强的时序异常检测 SOTA（含其它 ST-GNN、Transformer 类）对比未展开；结论较依赖 IBM Cloud 单一数据集与其 schema，"运营上下文"属性对无此类结构化 schema 的遥测系统的可迁移性存疑；预测式检测对突发型 vs 渐变型异常的敏感度差异未量化。

## 3. ConceptTree: Bringing Semantic Transparency to Black-Box Decision Making for Robotic Manipulation
- arXiv: https://arxiv.org/abs/2607.17861
- 作者：Yongyan Wen, Feifan Liu, Jinyi Chen, Bo An, Peng Liu, Siyuan Li（共 6 位）
- **TL;DR**：长时程机器人操作里的技能选择通常是"观测→动作"的黑箱映射；ConceptTree 把高层技能选择重写成"在人可读概念谓词上的推理"——先学一个归一化、视觉 grounding 的概念空间，再在其上训练决策树来预测技能，得到既可追溯又可干预的透明决策过程。
- **解决什么问题 / 为什么重要**：正对 A 方向横切重点"内生/自解释、concept-/prototype-based"——解释不是事后归因，而是决策结构本身（概念谓词序列 + 决策树）。对需要人类监督、随时介入的长时程系统尤其关键：可以直接改单个概念来定向纠错，而无需重训。这类"built-in interpretability"范式对时序/图模型的可解释设计也有方法启发。
- **核心方法**：把高层策略表示为对视觉观测的一串概念级谓词；学习一个由视觉输入 grounding 的归一化概念空间，在其上训练决策树预测高层技能；决策过程可逐概念检视与修改，支持细粒度干预。
- **主要结果**：在一组难度递增的真实机器人操作任务上，ConceptTree 一致优于既有 concept-based 基线，在复杂长时程场景优势尤为明显；定性案例显示可通过修改单个概念做定向纠错、无需重训。
- **值得追问 / 局限**：概念集合与谓词的定义/标注成本，以及概念是否覆盖全部决策相关因素（覆盖不足会牺牲性能或"看似可解释实则漏因"），摘要未展开；决策树在概念空间上的表达力对更长时程、更高维技能库是否够用待验；领域限于机器人操作，向时序/图任务迁移仍需适配。

## 4. KernelDiag: Agent-Based Root Cause Diagnosis for Kernel Crashes
- arXiv: https://arxiv.org/abs/2607.17722
- 作者：Weijing Wang, Zan Wang, Dong Wang, Haichi Wang, Junjie Chen（共 5 位；天津大学方向）
- **TL;DR**：自动化模糊测试每天在 Linux 内核暴露上千崩溃，但根因诊断仍是耗时的人工瓶颈；KernelDiag 用"结构化因果推理"的多智能体框架——先做日志到代码的对齐，再由按证据类型分工的智能体在源码语义与崩溃配置上迭代推理，把推出的因果依赖增量组织成"证据图"，实现方法级故障定位与因果解释。
- **解决什么问题 / 为什么重要**：正对 B 方向"root cause analysis / localization"，且是把 RCA 从分布式系统推进到更难的内核调试。内核 RCA 的难点在于低层线索稀疏、诊断证据异构（syscall、日志、崩溃报告）、故障非线性传播需方法级细粒度推理——现有面向分布式系统的 LLM-RCA 难以直接迁移。它示范了用"证据图 + 专职智能体"做结构化因果定位的范式。
- **核心方法**：日志到代码映射对齐异构诊断证据；证据专职智能体（syscall/日志/崩溃报告等）迭代地在源码级程序语义与崩溃相关内核配置上推理；把推断出的因果依赖增量组织成结构化 Evidence Graph，支撑 faulty-method 定位与因果解释。
- **主要结果**：在真实世界 KGYM 基准上，KernelDiag 在文件级与方法级定位上一致超过 SOTA，Top@k 显著提升，无显式提示的困难设置下最高取得约 4×（文件级）/2×（方法级）增益；人类与 LLM 辅助评估均认为其诊断解释准确、连贯、可执行。
- **值得追问 / 局限**：多智能体 + 证据图的推理成本（token/时延）与可扩展性未量化；对 KGYM 之外、非 syzkaller 生态的崩溃类型泛化性待验；"因果解释"由人评/LLM 评判定，与真实开发者最终定位的一致性缺客观 ground truth 的部分需谨慎解读。

## 5. Induction in Both Directions: A Mechanistic Analysis of In-Context Learning in Masked Diffusion Language Models
- arXiv: https://arxiv.org/abs/2607.15893
- 作者：Andy Catruna, Emilian Radoi（共 2 位）
- **TL;DR**：自回归 Transformer 的内部机制已被研究得较透，但扩散语言模型（DLM）少有机制性刻画；本文对比架构对齐的 attention-only 自回归模型与吸收态掩码 DLM，发现 DLM 学到的是一个"方向对称的双向归纳回路"，并给出因果证据：DLM 会算出全局掩码比例、把它当作没有显式 embedding 的隐式时间步。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"机制类（机制可解释性、residual stream/结构、现象分析）。归纳回路（induction head）是理解 in-context learning 的经典机制，此前几乎只在自回归模型上研究；本文把这套机制分析法搬到正在兴起的扩散语言模型，揭示其上下文学习靠"前一 token / 后一 token 头把局部上下文写入残差流、归纳头再据此定位并复制答案"，且回路对源在过去或未来都对称工作。
- **核心方法**：构造架构匹配的 AR 与 absorbing-mask DLM 做对照；用机制可解释性手段（注意力头功能归因 + 因果干预）分离前一/后一 token 头与归纳头的分工；通过因果实验证明 DLM 计算全局掩码比例并将其用作隐式时间步。
- **主要结果**：DLM 具双向、方向对称的归纳回路；仅给左侧上下文（与 AR 可见范围一致）时，DLM 归纳能力并不优于 AR 对照；但两侧上下文都可见时归纳更强，说明优势来自双向上下文访问而非更强的单侧机制；并有因果证据支持"掩码比例=隐式时间步"。
- **值得追问 / 局限**：结论建立在小规模、架构匹配的受控模型上，能否外推到大规模生产级扩散 LM 待验；"隐式时间步"是否在所有层/所有任务上被一致使用，摘要仅给出存在性证据；双向归纳的优势在真实生成质量上的净收益未量化。

## 6. Measuring Monosemanticity in Sparse Autoencoders via Latent Activation Coherence
- arXiv: https://arxiv.org/abs/2607.17770
- 作者：Katarzyna Filus, Sebastian Pokuciński（共 2 位）
- **TL;DR**：机制可解释性常用稀疏自编码器（SAE）从神经表征里抽"更可解释的特征"，但如何量化其单义性（monosemanticity）一直难办——现有指标要么依赖外部概念标签、要么依赖预训练嵌入模型而对编码器几何敏感；本文提出 TMS（Tversky Monosemanticity Score），一个免标签、不需外部嵌入编码器、把单义性定义为二值化 SAE 潜元"激活集合一致性"的度量。
- **解决什么问题 / 为什么重要**：正对 C 方向"优先"机制类（mechanistic interpretability、表征、训练动态）。SAE 是当前 LLM/视觉模型可解释性的主力工具，但"这个 latent 到底是不是单义的"缺乏稳健、可复现、不受编码器各向异性污染的度量。TMS 用 Tversky 相似度刻画激活集合一致性，绕开外部标签与嵌入模型，让单义性评估更内生、更可比。
- **核心方法**：将单义性操作化为二值化 SAE 潜元的激活集合一致性，用 Tversky 指数度量；在 DINOv3、CLIP、BLIP2 等视觉/视觉-语言模型特征上训练的 SAE、两种稀疏 regime（TopK、BatchTopK）、多档稀疏度与扩张因子上评估。
- **主要结果**：TMS 比基于嵌入的替代指标更少受编码器各向异性影响，同时与既有单义性指标保持一致；能揭示不同基座模型下 SAE 训练动态的差异；在编码器各向异性情形下，TMS 对"基于探针的概念删除有效性"给出更强指示，其余情形亦具竞争力。
- **值得追问 / 局限**：验证集中在视觉/视觉-语言 SAE，向语言模型 SAE 的迁移性摘要未直接给出；"激活集合一致性"高是否总等价于人类可理解的单一语义，仍需与人评/因果干预交叉验证；Tversky 参数（非对称权重）的选择对分数的影响未展开。
