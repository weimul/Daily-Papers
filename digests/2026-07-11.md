## 1. Spatio-Temporal Scheduling Prediction Under Backhaul Delay for Resilient Coordinated Beamforming
- arXiv：https://arxiv.org/abs/2607.08454 （cs.NI, cs.AI）
- 作者：Prashant Kumar Singh, Shubham Vaishnav, Ahmet Hasim Gökceoglu, Li Wang
- **TL;DR**：分布式 5G 协同波束成形靠跨小区调度信息交换，但回传时延让信息"过期"，哪怕一个 TTI 的延迟都会让协同性能跌破不协同基线；本文用谱时序图神经网络（StemGNN）从延迟历史预测未来 UE 调度状态，用预测值替换过期输入喂给预编码器。
- **解决什么问题 / 为什么重要**：这是"时空图 GNN"在真实系统里的直接落地——把跨小区调度建成图上时序信号并做多步预测，正好命中 A 方向 spatio-temporal GNN 的核心范式；"基于过期信息协同不如不协同"这一反直觉结论也值得记录。
- **核心方法**：两阶段预测框架——① StemGNN 把多小区的 UE 调度状态当作时空图信号，从带回传时延的历史观测预测未来调度状态；② 用预测状态替换 CBF-SLNR 预编码器的过期输入，避免把干扰抑制指向已不活跃的用户。
- **主要结果**：在三小区大规模 MIMO 下行（60 UE、每基站 64 天线、Quadriga UMi 信道、比例公平调度）上，预测替换过期输入后恢复了协同波束成形相对不协同基线的增益（原文报告显著优于直接用过期信息的协同）。
- **值得追问 / 局限**：StemGNN 的预测误差在更长回传时延/更高移动性下如何退化？是否与更简单的时序外推基线做过对照？跨拓扑（小区数、天线数变化）泛化未验证。

## 2. Write-Protected Discrete Bottlenecks for Language-Grounded World Models: A Structural Limitation and Sufficient Fix
- arXiv：https://arxiv.org/abs/2607.08312 （cs.LG）
- 作者：Jiayi Fang
- **TL;DR**：RT-2/Octo/PaLM-E 这类"把 LLM/VLM 特征端到端注入机器人世界模型"的做法默认语言梯度能直接塑造物理符号表示；本文证明这不安全——任何语言梯度进入 Gumbel-softmax 离散符号瓶颈都会逼出结构性权衡，并给出防坍缩的最小架构约束。
- **解决什么问题 / 为什么重要**：这是"信息/离散瓶颈"的结构性分析（横切的内生可解释/瓶颈重点）——不是调参问题而是架构层面的不可能性刻画，对任何用离散码本/概念瓶颈做可解释表征的人都有警示价值。
- **核心方法**：在语言接地世界模型里研究语言梯度经 Gumbel-softmax 离散瓶颈的行为；系统比较 vanilla 估计器与五种防坍缩策略，刻画"符号多样性"与"语义标签可学"二者不可兼得的结构性权衡，并给出能同时满足两目标的充分架构约束（写保护式瓶颈）。
- **主要结果**：vanilla 估计器坍缩到 2.2/64 个符号（5 个种子中 4 个）；五种防坍缩策略虽保住多样性却学不到语义标签（准确率全 ≤9.2%）；所测 GumbelBottleneck 变体无一能同时达成两目标——证明该失败是结构性而非优化性的，"写保护"约束是充分修复。
- **值得追问 / 局限**：单作者、以受控实验为主，结论在更大规模真实机器人世界模型上是否复现？"写保护"修复对下游控制性能的代价未量化；离散瓶颈之外（如连续 VQ）的边界仍开放。

## 3. Who Broke the System? Failure Localization in LLM-Based Multi-Agent Systems
- arXiv：https://arxiv.org/abs/2607.07989 （cs.CR, cs.AI, cs.IR, cs.LG, cs.MA）
- 作者：Yufei Xia, Anjun Gao, Yueyang Quan, Zhuqing Liu, Minghong Fang
- **TL;DR**：多智能体系统执行失败时，"哪个 agent 该负责、轨迹在哪一步首次不可逆地跑偏"极难定位；AgentLocate 把失败同时归因到"具体 agent + 最早的决定性步骤"，用 LLM 评判 + 多视角独立验证 + 置信度加权聚合来做。
- **解决什么问题 / 为什么重要**：这是监控告警里 root cause analysis/localization 的 agent 版——长时程、强耦合交互下的责任归属与首错步定位，正是 AIOps"根因定位"思路迁移到 LLM 多智能体的自然延伸，对可观测性/事后复盘很实用。
- **核心方法**：AgentLocate 结合 LLM 评判机制与"多个独立评估者的多视角验证"，用置信度感知策略聚合各方判断，得到"责任 agent + 最早决定性步骤"的双重归因；反馈进一步用于自适应地调整评判阈值。
- **主要结果**：论文报告在多智能体失败定位任务上，双重归因（agent + 最早决定性步）优于把失败仅归到单一维度的基线（具体数值见原文表）。
- **值得追问 / 局限**：LLM 当裁判存在自偏与成本问题，多视角验证能否真正消解？"最早决定性步"的地面真值如何标注、是否可靠？在几十步以上超长轨迹里定位精度衰减多少未知。

## 4. What to Keep, What to Forget: A Rate–Distortion View of Memory Compaction in LLMs and Agents
- arXiv：https://arxiv.org/abs/2607.08032 （cs.LG）
- 作者：Ashwin Gerard Colaco, Nada Lahjouji
- **TL;DR**：KV 缓存驱逐/量化、提示剪枝/蒸馏、架构状态压缩、agent 记忆整合——四个原本各做各的社区其实在解同一个问题：在资源预算下，为保住下游效用，该保留哪些"上下文派生信息"、以何种保真度保留。本文用率失真给出统一目标与下界。
- **解决什么问题 / 为什么重要**：这是 C 方向"优先"的记忆机制工作——不是又一个压缩技巧，而是把碎片化的记忆压缩方法统一到一个可量化的率失真决策框架，直指长时程 agent"记什么、忘什么"的核心问题，有很强的组织性与理论价值。
- **核心方法**：提出单一"压缩目标"把各类记忆压缩形式化为率失真决策，给出一个层无关（layer-agnostic）的下界；据此构建七轴分类法，把跨社区的方法统一归位、揭示它们在"保留率—失真—预算"三角上的取舍位置。
- **主要结果**：以统一目标 + 下界为骨架，给出覆盖 KV 缓存、提示、架构状态、agent 记忆四类方法的七轴分类（评述/框架型贡献，非单点 SOTA）。
- **值得追问 / 局限**：率失真下界在真实任务上是否紧、能否指导具体算法设计？"下游效用"作为失真度量如何可计算地定义？框架的预测力仍待用新方法验证而非仅回溯归类。

## 5. Linear Attention Architectures: Mechanisms, Trade-offs, and Cross-Layer Routing
- arXiv：https://arxiv.org/abs/2607.07953 （cs.LG, cs.AI）
- 作者：Tommaso Cerruti, Tim Rieder, George Rowlands, Lingfeng Jin, Imanol Schlag
- **TL;DR**：把 softmax 注意力与四种近期循环线性注意力（DeltaNet、Gated DeltaNet、Kimi Delta Attention、Gated DeltaNet-2）写进同一套"循环记忆"记法，显式对比它们在表达力、记忆衰减、擦除/写入控制、训练吞吐、实现复杂度上的差异。
- **解决什么问题 / 为什么重要**：这是 C 方向"技术报告 / 机制分析"的典型——不追新 SOTA，而是把一堆看似不同的线性注意力还原到统一机制视角，厘清"记忆读写控制"这一表征/训练动态问题，对想理解长上下文架构权衡的人是很好的地图。
- **核心方法**：用统一循环记忆记法表达五种机制，逐项拆解记忆衰减、擦除与写入控制等设计维度；实验以 350M 参数、15B token 训练为主，含优化器/学习率对比、混合栈 vs 纯栈对比、序列长度运行时测量、以及 1.3B/3B DeltaNet 放大实验与少量下游评测。
- **主要结果**：给出跨架构的训练吞吐、序列长度运行时与下游表现对比，量化"混合栈 vs 纯线性栈"及不同擦写控制设计的权衡（具体数值见原文）。
- **值得追问 / 局限**：主实验规模偏小（350M/15B token），结论到十亿级以上是否稳定？下游评测集偏少，表达力差异是否转化为真实任务差异未充分展开；跨层路由（cross-layer routing）部分的收益边界待明确。

## 6. Certified Interventional Fidelity: Anytime-Valid, Adaptive Evaluation of Causal Claims in Mechanistic Interpretability
- arXiv：https://arxiv.org/abs/2607.08349 （cs.LG）
- 作者：Amir Asiaee
- **TL;DR**：机制可解释性常靠"交换隐状态、打补丁激活、消融组件、压缩模型对比"来评估解释，却只报一个点估计——即便实验是边跑边看、还会朝疑似失败自适应地调；CIF 给这类干预评估补上"随时有效"的统计置信层。
- **解决什么问题 / 为什么重要**：这是 C 方向"机制/科学问题"的方法学工作——把"报告的 fidelity/patching 效应到底是稳健因果结论还是有限采样与评估选择的产物"变成可判定的统计问题，直接改善 mechinterp 结论的可信度，对做电路/表征分析的人是基础设施。
- **核心方法**：CIF 先把被报告量写成一个因果估计量——在给定输入分布与给定干预分布上、一个有界打分的期望；再为之提供置信区间与随时有效（anytime-valid）的置信序列，从而允许"边监控边评估、朝疑似失败自适应"而不破坏统计有效性。
- **主要结果**：把点估计式的干预保真度升级为带随时有效置信序列的估计，使自适应/持续监控下的因果主张仍受统计保证（方法学贡献，见原文示例）。
- **值得追问 / 局限**：随时有效置信序列通常比固定样本区间更宽，实际会牺牲多少统计效率？"输入分布与干预分布"需事先声明，选择本身如何影响结论？在大规模真实电路分析中的计算开销未知。
