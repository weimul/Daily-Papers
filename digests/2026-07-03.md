## 1. Efficient Temporal Point Processes via Monotone Alternating Splines
- 链接：https://arxiv.org/abs/2607.01752
- 作者：Cheng Wan, Quyu Kong, Feng Zhou（共 3 人）
- 方向：A（时序点过程 / 连续时间建模——核心方法方向正对口：把 CCIF 的参数化从单调神经网络换成单调交替样条）
- **TL;DR**：时序点过程（TPP）里，直接建模**累积条件强度函数（CCIF）**比建条件强度更省算、且避免数值积分近似误差；但现有 CCIF 参数化清一色依赖单调神经网络（MNN），作者指出 MNN 有三个结构性"死锁"——凸性限制、饱和上限、以及对 CCIF 建模要求的违背——从根上限制了对复杂时间动态的表达力。为此提出 **Monotone Alternating Splines（MAS）**：用分离的插值与外推组件来灵活高效地建 CCIF。
- **解决什么 / 为什么重要**：这条正中我"连续时间 / 事件流建模"主线。它不是又堆一个网络，而是从**表达力的结构性瓶颈**入手——先把 MNN 为何"表达力不足"讲清楚（凸性/饱和/建模约束三重死锁），再用样条的插值段保证拟合精度、外推段保证泛化，从理论上缩小 MNN 那块"不可约近似间隙"。对我判断"连续时间强度模型到底卡在哪、该怎么换掉黑箱单调网络"很有方法论价值。
- **核心方法**：以 CCIF（而非条件强度）为建模对象；用单调交替样条替换 MNN，插值组件负责区间内高精度拟合、外推组件负责区间外稳健泛化；理论上论证插值给出强拟合、外推支撑鲁棒泛化，从而降低 MNN 的不可约近似误差。
- **主要结果**：在合成与真实世界数据集上均取得优于现有方法的性能，验证了 MAS 对复杂时间动态的表达力与效率优势。
- **追问 / 局限**：(1) 样条的插值/外推分段依赖节点（knot）布置，事件在时间轴上高度不均或长尾时，节点自适应策略与外推稳定性如何权衡，摘要未展开。(2) 主打 CCIF 单变量时间维，对**空间/多维标记**（marked / spatio-temporal）事件是否同样解决三重死锁、能否接空间解码，值得追问。

## 2. Self-explainable Operator Learning for Discovering Spatial Patterns in Functional Data
- 链接：https://arxiv.org/abs/2607.02203
- 作者：Mojgan Alishiri, Amirhossein Arzani（共 2 人；University of Utah）
- 方向：A（内生 / 自解释——横切重点：把可解释性直接嵌入算子学习结构，而非事后归因）
- **TL;DR**：算子学习（operator learning）在函数空间建模复杂物理系统很强，但神经网络架构让它变成不透明模型。作者把算子学习**重构成"广义泛函线性模型的线性叠加"**（用积分方程表达），利用积分方程的可加分解，把输入域切成子域、算局部积分，从而直接量化每个空间区域对预测的贡献——解释性内建于算子结构本身，不需外挂工具。
- **解决什么 / 为什么重要**：这条对我"内生 / 自解释（intrinsic / self-explaining）"这个横切重点是模板级案例。它不做 post-hoc 归因（我一贯降权的那类），而是**把可解释性写进模型的数学形式**：因为积分方程可加分解，"哪块输入区域驱动了哪块输出模式"是模型结构直接吐出来的量，而非事后拟合。这种"重构成可分解的线性/积分形式来换取内生透明"的思路，正是我想在时序/图模型上借鉴的。
- **核心方法**：把算子重写为若干广义泛函线性模型（积分方程）的线性组合；利用积分的可加可分解性，将输入域划分为子域并计算局部积分，逐区域评估其对最终预测的贡献，直接把输入区域链接到输出模式；在函数→标量、函数→函数两类映射上实现内生解释。
- **主要结果**：在血流、非定常空气动力学等流体问题上，模型最常"优先关注特征梯度大的区域"，给出物理上有意义的决策洞察；与既有 post-hoc 解释方法定性一致，但优势在于**解释无需外部工具、直接来自算子结构**。
- **追问 / 局限**：(1) "线性叠加 + 子域积分"的自解释以牺牲部分非线性表达力为代价，摘要未给出可解释性增益 vs 预测精度损失的定量权衡曲线。(2) 子域划分的粒度直接决定解释分辨率与稳定性，划分方式（固定网格 vs 自适应）对解释一致性的影响需要核查。

## 3. Fast and Accurate Anomaly Detection in Time Series
- 链接：https://arxiv.org/abs/2607.02046
- 作者：Emanuele Mele, Massimo Cafaro, Angelo Coluccia, Italo Epicoco（共 4 人；University of Salento）
- 方向：B（时序异常检测——监控告警线正对口：无监督、面向安全关键场景，强调低误报）
- **TL;DR**：时序异常检测里，真实场景的核心困难是类别极不平衡（异常稀有）+ 有监督缺标注、而无监督在安全关键部署下误报率高。作者提出一个**基于 Haar 离散小波 + 精心设计的 t 检验**的新无监督算法，为该 t 检验建立了理论基础，并在 343 个数据集上大规模验证。
- **解决什么 / 为什么重要**：这条对我"监控告警 / 时序异常检测"应用线直接对口，且难得地**给了统计理论支撑而不是纯经验网络**。亮点有二：(1) 用 Haar 小波做多尺度分解 + 一个有理论保证的 t 检验来判异常，方法轻量、可解释、天然对"快"友好（对应标题 Fast）；(2) 评测规模非常大（343 个数据集），比常见 anomaly benchmark 只跑几个数据集的说服力强得多，能更公允地压 SOTA。对工程落地里"要低误报、要能讲清楚为什么报警"的诉求契合。
- **核心方法**：对时序做 Haar 离散小波变换获得多尺度表示；在其上设计并从理论上刻画一个 t 检验统计量来判定异常；全程无监督、无需标注；强调在类别极不平衡与安全关键场景下控制误报。
- **主要结果**：在 343 个数据集上做广泛实验，性能超越当前无监督与自监督 SOTA 基线；同时兼顾速度（Fast）与准确性（Accurate）。
- **追问 / 局限**：(1) Haar 小波对**突变/阶跃型**异常敏感，但对缓慢漂移、周期性微弱异常（near-normal）是否同样有效，摘要的"Accurate"需要看分异常类型的细粒度结果。(2) t 检验依赖对正常段分布的假设，真实监控数据常非平稳/非高斯，理论保证在分布假设被违背时的鲁棒性是最想追问的一点。

## 4. SABER: A Semantic-Aligned Brain Network Analysis Framework via Multi-scale Hypergraphs
- 链接：https://arxiv.org/abs/2607.01901
- 作者：Yidan Xu, Xiangmin Han, Rundong Xue, Huihui Ye（共 4 人）
- 方向：B（脑功能网络 / neuroimaging——脑网络线正对口：把 LLM 语义主动注入脑网络决策层做可解释诊断；含多尺度超图建模高阶依赖）
- **TL;DR**：脑疾病诊断需要脑连接模式 + 高层语义知识协同，但现有方法多把 LLM 语义当辅助特征或监督，语义没能直接参与决策，限制了分类稳定性与鲁棒性。SABER 提出一个**语义对齐的脑网络框架**：ROI 级语义经全局自注意力丰富节点表示、多尺度超图显式建模功能子网与多 ROI 交互、并在**决策层**选择性注入病人特异文本嵌入来直接引导预测。
- **解决什么 / 为什么重要**：这条落在我"脑功能网络 / neuroimaging time series"应用线上（虽是 fMRI/连接组而非 fNIRS，但脑功能网络的建模范式相通，可迁移）。两个点对我有价值：(1) **多尺度超图**突破传统 GNN 只建成对边的局部性限制，显式刻画功能子网络与多 ROI 高阶依赖——这与我关心的时空/高阶图结构一脉相承；(2) 语义"决策级对齐"而非"特征级拼接"，让 LLM 知识**直接指导预测但不扰动底层网络结构**，在小样本下还能提稳定性与可解释性，思路值得借鉴到别的图诊断任务。
- **核心方法**：ROI 级语义经全局自注意力注入节点表示、提供全脑上下文；构造多尺度超图显式建模功能子网络与多 ROI 交互，捕获高阶依赖；决策级语义对齐机制选择性地把病人特异文本嵌入注入图表示，语义直接引导预测而不改动网络结构。
- **主要结果**：在公开脑网络数据集 ABIDE、ADHD-200 上取得 SOTA，稳定性与可解释性均提升，**小样本设置下优势尤为明显**。
- **追问 / 局限**：(1) "LLM 语义注入决策层"引入了对文本嵌入质量的强依赖，语义来源的偏差/幻觉是否会污染诊断、如何审计，摘要未讨论。(2) 多尺度超图的构造（超边如何定义、尺度如何选）通常引入较多超参，在 ABIDE/ADHD-200 之外的数据集/疾病上的可迁移性与超参敏感性需实测。

## 5. Conditional Co-Ablation: Recovering Self-Repair Backups in Transformer Circuits
- 链接：https://arxiv.org/abs/2607.01940
- 作者：Zhiren Gong, Zihao Zeng, Chau Yuen, Wei Yang Bryan Lim（共 4 人；NTU Singapore）
- 方向：C（机制可解释 / 现象分析——"优先"类：直击 self-repair 导致的孤立单元归因失效，是机制而非 prompt 工程）
- **TL;DR**：机制可解释常靠"逐组件消融打分"来做归因/能力剔除/剪枝，但这套**一阶打分在 Transformer 自修复（self-repair）时会误导**——主组件被移除后休眠的备份头顶上，掩盖了主组件的效应、而备份头在完整模型上又显得无关紧要。作者把它重构成一个恢复任务（条件电路补全），提出 **Conditional Co-Ablation（CoAx）**：一个无标签、以输出为锚的分数，衡量"主组件集被移除后，每个剩余单元的消融效应增长多少"，从而暴露被一阶打分丢弃的二阶交互。
- **解决什么 / 为什么重要**：这条是我"机制 / 现象分析"最想要的那类——它不新增能力，而是**指出并修好一个被广泛依赖的方法学缺陷**：单元重要性并非孤立属性，在鲁棒电路里"真正重要的组件只有在使其变得必要的干预下才可见"。这对我理解 residual stream / 电路里的冗余与自修复、以及所有基于消融的归因/剪枝结论的可信度，都有直接的纠偏意义。
- **核心方法**：把问题重构为条件电路补全（先移除一个主组件集，再问哪些剩余单元的消融效应因此增长）；CoAx 是无标签、output-grounded 的条件增长分数，捕获二阶交互；用反事实 patching 验证被恢复的头因果承载了修复。
- **主要结果**：在 GPT-2-small 的 IOI 电路上，备份头恢复的 ROC-AUC 从 0.33 提到 **0.91**，超过所有基线（含 self-repair 感知的梯度打分 0.82）；同一无标签流程在 8 个模型上迁移到 induction；进一步用于纠正被自修复掩盖的归因、识别能力剔除所需组件、并做修复感知的结构化剪枝，规模从 124M 扩展到 7B。
- **追问 / 局限**：(1) 条件共消融需先选定"主组件集"，这个先验集怎么选会影响暴露出的二阶交互，选偏了是否会漏掉别的备份路径，摘要未展开。(2) 二阶条件消融的组合搜索代价高于一阶打分，7B 规模的可扩展性与计算开销、以及是否需要近似都值得核查。

## 6. Finite-Lag Operator Geometry of Recurrent Representations
- 链接：https://arxiv.org/abs/2607.01746
- 作者：Kanishka Reddy（共 1 人）
- 方向：C（表征几何 / 现象分析——"优先"类：把循环隐状态当**轨迹**而非静态快照来度量其表征几何，含理论）
- **TL;DR**：循环表示本质是轨迹，但表征几何往往用静态快照来测量。作者为循环隐状态开发**有限滞后算子几何**：从观测到的"源-后继"对 $(X_t, X_{t+Δ})$ 出发，估计条件输运律 $Q_Δ$，导出可精确分解为"条件扩散 + 相干位移"的源中心输运张量 $G_Δ$，以及概括有向滞后流的反对称环量 $W_Δ^ρ$。
- **解决什么 / 为什么重要**：这条命中我"表征几何 + 时间动态"的交叉点。它的核心立场——**表征是轨迹、要用有限滞后的有向输运来测，而非无穷小/静态几何**——恰好把我对连续时间/序列动态的兴趣与表征几何工具接了起来。它证明了有限滞后分离结果：源中心输运能探测到无穷小 carré-du-champ 几何记录不到的**确定性循环运动**，等于给"循环网络内部到底在做什么样的有向流动"提供了一把新尺子。
- **核心方法**：以有限滞后条件输运律 $Q_Δ(dy\mid x)$ 为基元，用稠密高斯源平滑算子估计；导出源中心输运张量 $G_Δ$（分解为条件扩散与相干位移）与坐标环量 $W_Δ^ρ$；证明仿射协变性、稠密估计在有界轨迹云上的稳定性、以及有限滞后分离定理；给出线性-高斯闭式解，用更新矩阵 $A_Δ$、源协方差、创新协方差标定各量。
- **主要结果**：受控实验验证了分解、环量、协变性与稳定性预测；在性能匹配的 repeat-copy 网络上，框架揭示了不同架构在总输运尺度与相干位移迹上的差异，而相干位移分数依赖度量与分辨率。
- **追问 / 局限**：(1) 结论建立在受控实验与 repeat-copy 任务上，能否迁移到大规模真实序列模型（长程依赖、非平稳）的隐状态轨迹仍待验证。(2) "相干位移分数依赖度量与分辨率"意味着若干标量总结量不是坐标无关的，跨架构比较时如何固定度量以保证可比性，是使用该工具的关键前提。
