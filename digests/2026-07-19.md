## 1. NeuronSoup: Evolving Asynchronous, Shared-Neuron Temporal Graphs without Backpropagation
- arXiv: https://arxiv.org/abs/2607.15217
- 作者：Subodh Kalia
- **TL;DR**：把"同步逐层前向"换成"异步、延迟中介的信号在一池共享神经元里传播"——每条路径把连续值信号经若干中间神经元从输入送到输出，路径共享同一神经元时后到信号会撞上前者留下的累积态、按极性与到达时序产生建设/相消干涉；整套拓扑/权重/延迟/连接由遗传算法在一条 14602 基因的实数基因组上协同进化，全程不需要可微计算图。
- **作者/机构**：Subodh Kalia（单作者）。
- **解决什么问题 / 为什么重要**：命中 A 方向"事件流 / 异步时间序列 / 连续时间信号传播"这条主线——它把网络当成一张真正异步的时序图：计算深度按样本自适应、路径间的横向交互（干涉）是涌现出来的而非人工工程化的。同时它质疑了当前深度学习两条隐含前提：必须可微、必须同步分层。
- **核心方法**：路径式连续信号传播 + 物理共享的隐神经元（干涉由极性与到达时序决定）+ 变长中间层（per-sample 自适应深度）；用遗传算法（而非梯度）协同进化拓扑、权重、延迟与连接，并论证为何该问题类适合 GA、为何 CMA-ES 在此规模失败。
- **主要结果**：在以冻结 ResNet18 特征为输入的 10 类 MNIST 上，进化出 204 条活跃路径穿过 266 个隐神经元（其中 156 个被多路径共享、有一个参与 11 条路径），1 万代后测试精度 85.9%，模型仅 115 KB。
- **值得追问 / 局限**：结果目前只在 MNIST（且已用 ResNet18 特征打底）这一玩具规模上验证，85.9% 远低于常规基线，能否扩到真实异步事件流（如 DVS、神经信号）与更大规模是最大问号；GA 在 1.4 万维基因组上的进化成本与可扩展性、以及"干涉式横向交互"是否稳定可控，摘要未量化。定位更像机制探索/立场论证而非即用方法。

## 2. RTS Smoother-Guided Learning of Physics-Based Neural Differential Models
- arXiv: https://arxiv.org/abs/2607.15180
- 作者：Ahmet Demirkaya, Georgios Stratis, Tales Imbiriba, Zachary D. Danziger, Deniz Erdogmus（Northeastern 等）
- **TL;DR**：很多物理/生物/神经系统只有部分方程已知、且只测得到部分状态变量；本文把已知 ODE 分量保持显式、未知分量用神经网络表示，交替做"RTS 平滑器估状态 / 反传估网络参数"直到收敛，从而在不完整观测下学出缺失动力学、又保留可解释的力学结构。
- **作者/机构**：Deniz Erdogmus 组（Northeastern University 等）。
- **解决什么问题 / 为什么重要**：正对 A 方向"Neural ODE / latent ODE / 连续时间模型 + 不规则/部分观测"，同时命中横切重点"内生可解释"——不是黑箱拟合整条动力学，而是只让神经网络补上未知那块、把已知机理留在方程里。这类"物理已知 + 神经补全 + 隐状态推断"的组合对神经科学/生理这类"方程半已知、状态半可测"的场景很实用。
- **核心方法**：两阶段交替优化——(1) 固定参数，用 Rauch–Tung–Striebel 平滑器从可得测量推断潜在状态轨迹；(2) 固定平滑轨迹，用反传估计神经网络参数；迭代至预设判据。已知 ODE 分量显式保留，未知分量由 NN 表示。
- **主要结果**：在线性、非线性、刚性动力学等基准上、且在部分状态观测下，方法都能从不完整测量里学出缺失 ODE 分量，同时利用并保留可解释的机理结构，改善潜在状态重建与长时程预测。
- **值得追问 / 局限**：RTS 平滑器基于（扩展）卡尔曼式高斯假设，强非线性/强刚性下平滑质量与整体收敛稳定性存疑；交替优化的收敛性/局部极小、以及"已知/未知分量如何切分"对结果的敏感度，摘要未展开；均为仿真基准，真实噪声与模型误设下的表现待验证。

## 3. A Minimal Interpretable Architecture for Zero-Shot Reconstruction of Dynamical Systems
- arXiv: https://arxiv.org/abs/2607.14937
- 作者：Christoph Jürgen Hemmer, Florian Plaswig, Daniel Durstewitz（中央心理健康研究所 / 海德堡）
- **TL;DR**：动力系统零样本重建的基础模型泛化强但说不清"为什么能预测"；本文把 SOTA 模型 DynaMix 迭代"减配"到一个两参数的可解释最小形式 DynaBase——预测就是"当前潜状态"与"in-context 最近邻及其时间后继"的线性混合，却在混沌/周期系统上仍给出高度有竞争力的零样本重建，参数量比其它基础模型低好几个数量级。
- **作者/机构**：Daniel Durstewitz 组（Central Institute of Mental Health, Heidelberg）。
- **解决什么问题 / 为什么重要**：这是 A 方向"动力系统 / 连续时间"与 C 方向"机制/现象分析"的交叉优先类工作——通过把大模型剥到只剩必要机制，暴露 DS 领域 in-context learning 的最小要件，并在一个可解析的数学框架里调和文献里相互矛盾的观察（例如把 (Zhang & Gilpin, 2026) 的 context-parroting 算法作为一参数映射族的一个端点复现出来）。是"自解释/内生可解释"而非事后归因的典型。
- **核心方法**：从 DynaMix 出发迭代化简得 DynaBase：预测 = 当前潜状态与最近 in-context 邻居及其时间后继的线性混合（两参数）；极简形式允许直接对 DS 重建度量做优化、并给出预测 MSE 的闭式一步解析解；进一步导出一参数映射族，一端复现 context-parroting、另一端进入有界混沌行为，并区分"短期预测最优"与"DS 重建最优"两种训练策略。
- **主要结果**：在混沌与周期系统上，DynaBase 以极小参数量取得与大型基础模型高度竞争的零样本 DS 重建；理论与实证分析把文献中分歧的现象统一进一个可分析框架。
- **值得追问 / 局限**："两参数线性混合"本质高度依赖 in-context 近邻质量，对高维、强噪声、观测稀疏的真实系统能否保持竞争力存疑；作为"最小可解释形式"，它揭示机制的价值可能高于其作为通用预测器的上限，两者边界摘要未完全界定。

## 4. Adaptive Sampling for Spatiotemporal Anomaly Monitoring in Wireless Sensor Networks
- arXiv: https://arxiv.org/abs/2607.15235
- 作者：Guoqing Lu, Yixuan Sun, Yiwen Jiang, Bernard Butler
- **TL;DR**：无线传感网为省电常用稀疏采样，却因此漏掉短时、局部、可能扩散的异常；本文提出"哨兵辅助自适应采样"——正常期由卡尔曼滤波的预测不确定性驱动稀疏采样，异常期由持续采样的哨兵节点做混合 GLR 检测并触发一跳邻域唤醒与恢复感知的告警控制，在保持低采样成本的同时大幅提升异常窗口的可见度。
- **解决什么问题 / 为什么重要**：正对 B 方向"时序/时空异常检测 + 监控告警"，同时命中 A 的"spatiotemporal"。它把"省电的稀疏感知"与"别漏掉稍纵即逝的局部异常"这对运维老矛盾，做成一个感知-控制协同的闭环，思路可迁移到更一般的时空监控/AIOps 采样调度。
- **核心方法**：感知-控制协同流水线——正常期各节点按 KF 预测不确定性做稀疏采样；异常期哨兵节点持续采样、用带节点相对阈值的混合 GLR 检测，局部检测触发一跳邻域唤醒 + 恢复感知的告警传播，以在成本与可见度间取舍。
- **主要结果**：在 Intel Berkeley 实验室温度数据集（注入突发随机时空异常）上，异常窗口采样比 AWSR 从 0.439 提升到 0.933；相对 AAS 与 Adapted e-Sampling 两个基线在提升 AWSR 的同时分别降低总成本 15.4% 与 2.1%。
- **值得追问 / 局限**：结论基于单一室内温度数据集与人工注入的"突发随机"异常，面对真实缓变/相关/多模态异常时 GLR 与 KF 假设是否成立存疑；哨兵节点位置与数量、一跳唤醒策略对拓扑与异常扩散模式的敏感度，摘要未系统评估。

## 5. Steering Robustness into World Action Models via Mechanistic Interpretability and Optimal Control
- arXiv: https://arxiv.org/abs/2607.14943
- 作者：Jihoon Hong, Julian Skifstad, Qiyue Dai, Alice Chan, Glen Chou
- **TL;DR**：世界-动作模型（WAM）在分布漂移下很脆；本文用机制可解释性对比"成功/失败 rollout"的激活，发现部分 WAM 架构对鲁棒性关键特征存在低维线性可分性，据此提出无需训练的对比方向 steering，并用激活动态的局部线性性做基于模型的最优控制反馈 steering（WA-LQR，一个极简侵入的降阶 LQR 控制器）。
- **作者/机构**：Jihoon Hong, Glen Chou 等。
- **解决什么问题 / 为什么重要**：这是 C 方向"机制分析 / 表征几何（激活空间线性可分、低维结构）"的优先类工作，明确不是 prompt 工程——它把"WAM 为何脆、鲁棒性特征长在激活空间哪里、能否直接在表征上纠偏"讲成可定位、可干预的机制问题，并用可解释性预测哪些模型可 steer。
- **核心方法**：对比成功/失败 rollout 的激活，度量鲁棒性关键特征的低维线性可分性；用对比激活方向做训练-free steering；利用激活动态的局部线性性，通过基于模型的最优控制得到 WA-LQR（降阶 LQR）做反馈式最小侵入 steering；并用机制评估预测各模型的可 steer 性。
- **主要结果**：机制评估预测 Cosmos-Policy 与 DiT4DiT 强可 steer、LingBot-VA 弱可 steer，与实际 steering 干预结果一致；在 Cosmos-Policy 与 DiT4DiT 上，WA-LQR 把对比方向泛化到新任务，并在相机、夹爪、视觉噪声扰动下比"未 steer"与"prompt steering"基线更鲁棒。
- **值得追问 / 局限**：结论"有些架构线性可分、有些不"提示该方法的适用性强依赖具体 WAM 结构，普适性有限；对比方向 + 局部线性 LQR 的 steering 在更大扰动/更长时程或安全关键场景下是否仍最小侵入且不引入副作用，值得进一步压测。
