## A. 核心方法

### 1. Dynamic Heterogeneous Graph Representation Learning: A Survey
- 链接：https://arxiv.org/abs/2609.04779
- 作者：Huan Liu, Pengfei Jiao, Jie Yin, Hongjiang Chen, Zhidong Zhao（cs.LG / cs.AI / cs.SI）
- **TL;DR**：首篇系统性梳理「动态异构图（DHG）」表示学习的综述，给出统一形式化定义（离散时间与连续时间统一在「时间粒度」视角下），并提出以算法为中心的分类法把嵌入式、GNN 式、Transformer 式方法归位。
- **解决什么问题 / 为什么重要**：现实系统往往同时是「异构」（多类型节点/边）且「动态」（随时间演化）的，静态或同构建模难以刻画；这正对应我方向中「时序图/时空图 GNN、连续时间动态图（CTDG）」的核心关切，一份统一 taxonomy + benchmark 清单适合作为方法选型与占位对照的参考底座。
- **核心方法**：以时间粒度统一 discrete-time 与 continuous-time DHG 的形式定义；据此提出算法中心分类（早期 embedding → GNN → 近期 Transformer），并明确指出各类方法对「动态粒度」的内在建模偏置；汇总代表性应用、常用数据集与基准。
- **主要结果**：作为综述无实验指标，价值在于统一定义、可比较的分类框架，以及对 discrete/continuous 两条技术路线偏置的显式对照与未来方向梳理。
- **值得追问 / 局限**：① 「连续时间 DHG」一支目前方法与基准仍稀疏，综述能否给出可操作的评测协议（而非罗列）？② Transformer 式 DHG 在长时程/大图上的可扩展性与 CTDG 事件流建模的融合路线值得进一步追问。

### 2. SMILE: Self-Explainable Multimodal Information Bottleneck for Medical Diagnosis
- 链接：https://arxiv.org/abs/2609.05174
- 作者：Yuqing Yang, Alexander Schmatz, Zhaozhao Ma, Changkyu Choi, Robert Jenssen, Shujian Yu（cs.CV / cs.LG）
- **TL;DR**：把「多模态医疗诊断的自解释」直接建模为信息瓶颈问题——在每个模态内部辨识出对诊断决策最有信息量的元素，联合优化预测性能与逐模态可解释性，属内生（设计上即解释）而非事后归因。（A 横切「内生/自解释 + 信息瓶颈」× B 医疗应用）
- **解决什么问题 / 为什么重要**：主流医疗可解释方法多为 post-hoc、且面向单模态，难以适配日益普遍的多模态诊断；这正契合我方向中「内生/自解释优先、post-hoc 归因降权」与「信息瓶颈」的偏好。
- **核心方法**：在 IB 框架下统一学习范式，联合优化预测与模态特定可解释性，识别各模态内最具信息量、驱动诊断的元素；为实现可解、稳定的优化，采用基于矩阵的 Rényi α 阶熵泛函（在编码器足够表达力的假设下），使 IB 项可估计。
- **主要结果**：在多个异构模态的医疗数据集上诊断性能稳定占优，在 iCTCF 上准确率绝对提升 9.1 个百分点；学到的解释给出透明、模态感知的特征相关性洞见，且改善泛化。
- **值得追问 / 局限**：① 矩阵熵 IB 依赖「编码器足够表达力」的假设，在小样本/弱模态下该假设失效时解释是否仍可靠？② 「模态内元素相关性」作为解释与临床可用的因果证据之间仍有距离。

## B. 应用场景

### 3. GLASS: Graph-Language Alignment with Spherical Scoring for Transferable Graph-Level Anomaly Detection
- 链接：https://arxiv.org/abs/2609.05253
- 作者：Xudong Wang, Chris Ding, Tongxin Li, Jicong Fan（cs.LG）
- **TL;DR**：面向「图级异常检测（GLAD）」的跨域可迁移框架：在单位超球面上把结构感知的图编码器与指令感知的文本嵌入对齐，用文本作为跨域桥梁，实现零样本/少样本的异常检测。（B 监控/异常 × A 图方法 交叉）
- **解决什么问题 / 为什么重要**：图级异常检测通常需按域重训，跨域迁移差；而监控/AIOps 场景常面临新域少标注甚至零标注。用「图—语言对齐」把异常打分做成域无关，直接对应我方向的异常检测与可迁移诉求。
- **核心方法**：把图的局部/全局/语义属性序列化成紧凑的 Graph Descriptor Prompt（GraphDP），与文本嵌入用多切片软余弦目标对齐，并借 Matryoshka 表示切片强制多尺度一致；打分侧把异常检测化为超球面上的密度估计，提出 Spherical Multi-Modal Scoring（在图与文本空间各放 von Mises–Fisher 核密度估计），其高集中极限恢复角度 k-NN 打分，实现结构与语义异常信号的有原则融合。仅凭目标域的 GraphDP（无目标域训练数据）即可零样本检测，少量正常样本即可少样本校准。
- **主要结果**：在 12 个基准、3 个 meta-domain 上取得最佳平均 AUROC 与排名，优于近期 GLAD 基线，并实现有效跨域迁移。
- **值得追问 / 局限**：① 「文本桥」的效果高度依赖 GraphDP 对结构/语义的序列化质量，对高度非文本化的工业图（如告警拓扑）是否仍成立？② vMF 密度估计对超球面上多簇/重尾正常分布的鲁棒性。

### 4. A Generalizable Feature Extractor for Alzheimer's-Related Brain MRI Tasks
- 链接：https://arxiv.org/abs/2609.05400
- 作者：Reza Rajabli, D. Louis Collins（cs.CV / q-bio.QM）
- **TL;DR**：把一个仅 718 万参数、监督预训练于「脑龄预测」的 3D CNN 冻结，用 LoRA（仅约 +1% 可训练参数）适配到多个阿尔茨海默相关下游任务，验证其能否充当神经影像可复用的「基础模型」。（B 神经影像/脑网络方向）
- **解决什么问题 / 为什么重要**：神经影像标注稀缺，迁移学习在该领域的有效性、以及「适配后能否不重训直接迁到新队列」都尚不清楚；这与我方向 fNIRS / 脑功能时序 / neuroimaging 的落地关切一致，尤其是小样本下的可复用骨干问题。
- **核心方法**：冻结脑龄预测 3D CNN 的全部 718 万权重，对每个任务用 LoRA 只增 ~1% 参数适配；在 6 个实验中评估泛化性，包括跨数据集（ADNI→OASIS-3）不重训直接应用，以及把输出 logit 与年龄/认知分联用做 MCI 进展预测、淀粉样阳性预测、海马/白质体积回归等。
- **主要结果**：ADNI 上正常 vs 痴呆分类 AUC 0.964；不重训迁到 OASIS-3 仍达 AUC 0.871；稳定 vs 进展型 MCI 区分 AUC 0.828；结构 MRI 预测淀粉样阳性 AUC 0.804；直接从 T1w 回归 ICV 归一化海马/白质低信号体积 R² 分别 0.80 / 0.91（通常需大得多的 U-Net）。
- **值得追问 / 局限**：① 「脑龄」作为预训练监督信号可能偏向宏观萎缩特征，对早期/细粒度病理是否迁移受限？② 结论来自结构 MRI，能否迁移到功能/时序模态（如 fNIRS、rs-fMRI 脑网络）仍待验证。

## C. Agent（机制/现象优先）

### 5. How Does mHC Use Its Residual Streams? Selective Routing and Near-Identity Mixing
- 链接：https://arxiv.org/abs/2609.05309
- 作者：Pengxiang Zhao, Xing Li, Xianzhi Yu, Wei Guo, Zhenhua Dong（cs.LG / cs.AI；分析对象为 DeepSeek-V4-Flash）
- **TL;DR**：Hyper-Connections/其流形约束变体 mHC 把残差通路从 1 条拓宽到 n 条，本文用「有效流数、跨流残差权重、流间余弦相似度」实测训练后的模型到底用了多少这份容量，结论是：大部分容量未被真正利用。（C 表征几何 / residual stream / 机制分析）
- **解决什么问题 / 为什么重要**：多流残差是近期扩展残差通路的一类结构改动，但「模型是否真的需要这么宽」缺乏机制证据；这类对残差结构/表征几何的现象级分析正是我方向 C 中「优先」的类型。
- **核心方法**：在 DeepSeek-V4-Flash 的四流残差通路上，用有效流数、跨流残差权重、流间余弦相似度刻画读写路由与混合强度；再做针对性干预（把后段 mixer 换成 identity、把早段 mixer 固定为 C4 诊断均值、每站只保留 top-k 路由权重）验证各模式的功能重要性。
- **主要结果**：典型注意力/FFN 站点有效只用约 2 条流，主导流随层变化且表示方向上仍可区分；残差混合主要发生在早层，22–42 层基本各流独立前传。把后段 mixer 换 identity，C4 困惑度仅升 1.9%、六任务均分不变；而换早段 mixer 困惑度升 41%。每站只留 top-3 路由权重，困惑度至多升 2.7%。即四流 mHC 的灵活性只被部分兑现，后段残差混合几无可测收益。
- **值得追问 / 局限**：① 结论基于单一模型（DeepSeek-V4-Flash）与 C4/六任务评测，是否随规模/训练配方而变？② 「后段混合无益」可能与该模型收敛到的解有关，能否据此在训练早期就剪掉多余流、省算力？

### 6. Fractal basins trap latent reasoning
- 链接：https://arxiv.org/abs/2609.04963
- 作者：Jeffrey Lai, Anthony Bao, John Quinn, William Gilpin（cs.LG）
- **TL;DR**：把推理模型的「思考链条」当作动力系统来看，发现难任务上推理会呈现「瞬态混沌」，其状态空间存在分形吸引盆——推理被困在鞍点附近（对应「接近正确但未完成」的尝试解）而长时间打转，这是问题难度的必然物理后果。（C 训练/推理动力学、机制分析）
- **解决什么问题 / 为什么重要**：推理模型「越难越想得久」是普遍现象，但慢下来的一般机制未知；本文给出动力系统层面的解释，把推理轨迹确立为一类新的可分析动力对象，对理解 test-time 计算与长程规划的机制很有价值。
- **核心方法**：把多种前沿推理模型的隐式推理过程建模为动力系统，度量其状态空间的分形维数随任务难度变化；跨 Sudoku、迷宫求解、视觉谜题、数理逻辑等任务观察分形吸引盆，并定位瞬态混沌来自推理长期滞留在鞍点附近，且这些鞍点对应「几乎正确」的候选解。
- **主要结果**：分形性随任务难度上升；推理放缓被解释为鞍点附近的长时间滞留；结论在多个领先推理模型与多类任务上一致，表明推理放缓是问题难度的内在后果。
- **值得追问 / 局限**：① 「分形维数/瞬态混沌」的度量对提示措辞、解码温度是否稳健，能否成为可靠的难度/停机预测指标？② 若滞留鞍点对应「近正确解」，能否据此设计早停或跳出机制加速推理而不损正确率？
